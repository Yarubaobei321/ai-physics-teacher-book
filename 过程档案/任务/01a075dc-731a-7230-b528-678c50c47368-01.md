核心区别是：**wechat-article-exporter 在你的电脑上运行，偏向资料库整理；wechat-download-mcp 调用第三方远程服务，偏向直接下载多种格式。**

根据你提供的两个技能说明：

| 对比项 | wechat-article-exporter | wechat-download-mcp |
|---|---|---|
| 运行位置 | 本机，需要启动本地服务 | 第三方服务器，需要联网调用 |
| 输出格式 | 主要工作流生成 Markdown；底层支持 JSON、HTML、文本 | Markdown、HTML、PDF、Word、TXT、MHTML |
| 文章信息 | 明确整理标题、作者、发布时间、公众号，写入 YAML 元数据 | 保留服务导出结果，不额外统一元数据 |
| 合集处理 | 编号、索引、进度记录，支持失败后继续补抓 | 支持合集下载，技能未说明断点续抓和索引整理 |
| 正文处理 | 合集脚本会清洗正文 | 默认不清理、不改写原始导出 |
| 图片 | 保留微信远程链接 | 默认保留微信远程链接 |
| 依赖与可控性 | 需要维护本地服务，但脚本可以检查、修改 | 使用省事，质量和可用性由服务提供方控制 |
| 链接流向 | 通过本机服务处理；实际外部请求需检查代码确认 | 明确发送给 changfengbox.top |

对你的用途：

- **偶尔保存文章，或需要 Word、PDF**：用 `wechat-download-mcp`。
- **长期收集公众号资料、批量整理合集、导入 Obsidian**：`wechat-article-exporter` 的现有流程更合适。

刚才 MCP 下载的文章确实保留了“微信扫一扫”“取消／允许”等页面杂项。不过，**还不能据此断言本地 exporter 提取更干净**——需要用同一篇文章对照测试。两者默认也都不等于包含图片的完整离线存档。
