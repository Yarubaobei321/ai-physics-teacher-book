结论：论文最小工作流可以迁移，但不能简单改名为“写书 M0—M5”。书稿更适合采用两层循环：

> 全书方向控制 + 章节持续生长

期刊 M5 的“压缩到目标栏目和字数”应当取消，替换为“整书统合与深度补足”。20万字是全书体量区间，不是要求每章平均灌满的配额。

## 一、目前哪些环节贡献最大

从论文复盘和旧书稿情况看，贡献排序大致是：

| 贡献 | 判断 |
|---|---|
| 作者持续理解、否决和裁决 | 最高。它真正改变方向、主张、结构和语言 |
| 回到原始材料，区分事实、候选和假设 | 最高。决定书里有没有真实内容 |
| 核验关键物理关系、项目状态和材料归属 | 很高。阻止“网页能运行＝物理正确”等错误 |
| 把数字、原话、图片、失败和案例写进解释链 | 很高。让读者看到作者真正做过什么 |
| 先完成一个完整样章，再决定全书章法 | 很高。能够及早发现文风、深度和材料密度问题 |
| 教师第一次连续阅读 | 很高。能清除项目黑话、编务语言和AI式空话 |
| 跨章检查概念、案例和作者声音的生长关系 | 写书特有的高贡献环节 |

当前复盘已经明确指出，作者裁决、原始材料、独立核验和读者能理解的证据链，才是真正改变成果的部分。论文02全流程复盘（本机成果；原路径保留在来源记录中）

## 二、贡献有限或容易反噬的环节

| 环节 | 处理建议 |
|---|---|
| M1—M5每阶段都安排多个AI独立完成 | 取消默认配置。只在方向、样章写法或重大分歧处启用 |
| 先规划18章、30万字，再让AI逐格填满 | 停止。这正是旧稿“完整但没有生命”的主要原因 |
| 每章固定一万多字 | 改为范围控制，允许材料密集章明显更长 |
| 为补字数建立“第X章再加3000字”清单 | 不作为写作任务。应先说明要新增什么材料和认识 |
| 87幅图片占位、几十个附录和工作表 | 占位不等于图文书稿；附录只保留读者确实会使用的内容 |
| HTML、哈希、静态检查数量 | 保留为可靠交付工具，但不能当作内容质量 |
| 大规模文献筛查在每章重做 | 只在理论、核心主张和高风险事实处启用 |
| 把证据限制、待核状态反复写进正文 | 审核材料保留，读者正文自然叙述事实、条件和行动 |
| 同一规则复制进许多提示词和登记表 | 保留一个权威规则入口，减少同步和版本噪声 |

## 三、建议的新写书最小工作流

```text
B0 材料地图
→ B1 图书方向池
→ 作者裁决书的核心价值
→ B2 全书宪法
→ B3 纵向样章试点
→ 作者裁决文风、深度和图文方式
→ B4 全书生长地图
→ B5 每批2—3章持续生长
→ B6 整书统合与20万字审查
→ B7 出版准备（有明确出版社后再启动）
```

### B0｜材料地图

只盘点真实存在的项目、实验、课堂、数据、代码、失败、教师经验、学生作品和可用图片。

输出：

- 材料能支持什么；
- 不能支持什么；
- 来源、作者和版权；
- 哪些空缺必须通过实验、访谈、复测或补拍来解决。

旧书稿只作为线索和反例，不作为新书正文底稿。

### B1｜图书方向池

不同方向分别回答：

- 这本书主要写给谁；
- 读者遇到的真实困难是什么；
- 本书最不可替代的材料是什么；
- 为什么值得写成一本书；
- 预计哪些材料能够继续生长；
- 哪些方向看似宏大，实际材料不足。

此阶段可以使用多个AI独立提出方向，但不写全书正文。

### B2｜全书宪法

作者确认后只冻结这些内容：

- 一句话核心命题；
- 目标读者和读者承诺；
- 作者声音；
- 主要材料边界；
- 明确不写什么；
- 判断一章是否值得保留的标准。

此时不必冻结完整目录，更不能冻结每章精确字数。

### B3｜纵向样章

先完整做一章，大约1万—1.5万字。若全书存在“案例章”和“方法章”两种明显不同类型，再增加第二个样章。

样章必须走完整链条：

> 真实问题 → 原始材料 → 作者判断 → 关键转折或失败 → 图表共同解释 → 读者可采取的行动 → 证据与版权复核 → 教师首读

样章通过后，作者裁决的不只是“好不好”，而是：

- 哪种开头有吸引力；
- 技术细节讲到什么程度；
- 作者声音是否真实；
- 图文比例是否合适；
- 哪些内容明显像AI填充；
- 完成一章需要多少作者审阅时间。

### B4｜全书生长地图

通过样章反推全书结构。每章必须有一个“章节发动机”：

- 一个真实矛盾；
- 一组核心材料；
- 一次判断、失败或转折；
- 对读者新增的理解或行动；
- 与前后章节发生的关系。

没有章节发动机的内容不独立成章，可以合并、降为短节或暂不写。

### B5｜分批生产

每批只推进2—3章。每章使用一个轻量循环：

```text
章节承诺
→ 少量材料包
→ 结构与图表任务
→ 完整内容稿
→ 事实／物理／版权／教师首读
→ 作者裁决
→ 把本章新增认识沉淀到全书地图
```

如果写到一半只能继续补概念、意义和流程套话，就暂停写作，转成“材料生长任务”：做实验、找原题、核对代码、补访谈、整理失败记录或让教师试读。

### B6｜整书统合

这是书稿对论文 M5 的替代，不做期刊式压缩，重点检查：

- 全书是否兑现同一个读者承诺；
- 前章提出的问题是否在后章继续生长；
- 概念、术语和案例是否前后重复或矛盾；
- 每位作者的经验纹理能否被读出来；
- 有没有材料薄弱却靠语言拉长的章节；
- 图、表、题干和装置图能否脱离网页独立阅读；
- 哪些章节需要增加真实材料，哪些需要大幅裁剪；
- 全书能否让一位不了解项目历史的高中物理教师连续读懂。

### B7｜出版准备

现在不启动。等出版社、开本、体例和交稿要求明确后，再处理Word样式、图片规格、索引、参考文献和版权文件。它不负责把内容“写厚”。

## 四、20万字怎样控制

建议把目标定义为：

> 正文18万—22万字，编务文件、提示词、审核记录和图片占位说明不计入。

控制方法：

- 样章通过前，不确定最终章数；
- 预计可采用12—15章，但不要求平均长度；
- 核心案例章可以1.3万—1.8万字；
- 理论或过渡章可以6000—10000字；
- 附录只保留读者会实际使用的材料；
- 每增加一节，都必须至少增加一种东西：新对象、新证据、新关系、新判断、新行动；
- 如果只是把已有结论换一种方式再说，计入待删内容，不计为生长。

20万字应当来自更多真实案例、实验、失败、作者访谈、比较和综合，不来自把一段话拉长。

## 五、建议的最小目录

确认实施后，可以在“图书出版”中新建一个独立项目：

```text
新书项目/
├── 00-任务书与全书宪法.md
├── 01-方向池与作者裁决.md
├── 02_SOURCE/        材料、来源、版权、图片
├── 03_PILOT/         样章和样章审阅
├── 04_MANUSCRIPT/    当前分章正文
├── 05_BOOK/          当前整书母稿
├── review/           阶段性作者审阅
└── history/          淘汰方向和旧版本
```

不再为每个阶段复制一整套多AI任务包，只保留一个当前母稿、一个作者裁决入口和必要的候选目录。

本轮只完成了只读设计，没有修改“图书出版”里的任何文件。若你认可，下一步建议只建立这套最小母版并启动B0、B1；暂不确定目录、不生成章节，也不碰现有书稿。
