## 复制给WorkBuddy的完整任务说明

```text
请先阅读 input/机械能守恒实验观察单要求.md。

目标：为高中物理“验证机械能守恒定律”分组实验制作一张本地可用的实验观察单，帮助学生分清研究对象、系统边界、测量量、计算量、能量变化和误差解释。

输入：只使用当前工作区中的 input/机械能守恒实验观察单要求.md。

动作：先用不超过8条复述你理解的教学目标、关键物理边界和验收标准。若没有关键冲突，继续制作页面；若发现物理要求矛盾或缺少会改变结果的信息，停下来提问。

约束：
1. 只读取input目录，只在output目录新建或修改文件；不要改动input文件。
2. 不删除、移动或重命名现有文件。
3. 不使用外部图片、字体、脚本、样式库或网络接口。
4. 不虚构实验数据、学生表现或课堂效果。
5. 页面不得把“实验误差较小”写成“机械能绝对守恒”。
6. 页面需要明确研究对象与系统边界，区分直接测量量和根据模型计算的量。

输出：
1. output/机械能守恒实验观察单.html：单文件HTML，内嵌CSS和JavaScript，本地双击可用。
2. output/交付说明.md：说明文件用途、打开方法、已实现功能、物理边界和待教师检查项。

页面功能：
1. 学生可以填写小组、日期、实验方案和研究对象；
2. 可以勾选系统边界、近似条件、直接测量量、计算量和误差来源；
3. 显示重力势能减少量与动能增加量的比较关系，并写清符号口径；
4. 提供“打印或保存为PDF”和“清空填写”按钮；清空前要二次确认；
5. 适合电脑和平板阅读，A4打印时不截断主要内容；
6. 使用简洁蓝白配色，不放学校标志，不采集或上传数据。

验收：
1. HTML文件双击可打开，断网后仍能使用；
2. 所有输入、勾选、打印和清空操作有效；
3. 页面无外部网络请求；
4. 研究对象、系统边界、公式、单位和误差表述由教师逐项可检查；
5. 页面内容适合一节高中物理分组实验，不替学生直接给出实验结论。

完成后请列出新建或修改的文件，并按上述5项验收逐条自查。不要声称已经完成你无法实际验证的浏览器或打印测试。
```

## 第一版怎样检查

WorkBuddy交付后：

1. 在结果区打开`output/机械能守恒实验观察单.html`，保存E04；
2. 再到Finder中双击HTML，确认浏览器能够打开；
3. 断开网络不是本轮必须动作，可用浏览器开发者工具或源文件检查确认无外部依赖；
4. 逐项试填、勾选、打印预览和清空按钮；
5. 按以下五项写下真实判断：
   - 文件：是否生成在正确目录，能否独立打开；
   - 操作：输入、勾选、打印和清空是否工作；
   - 物理：对象、系统、公式、符号和误差解释是否正确；
   - 课堂：学生是否看得懂，教师是否能在实验环节使用；
   - 隐私：是否没有上传、保存或显示不必要的个人信息。

不要为了完成文章而刻意制造错误。第一版如果确实没有明显问题，就提出一项真实的教学改进，例如“减少学生在实验前看到的提示”或“把误差来源按本实验方案调整”。
