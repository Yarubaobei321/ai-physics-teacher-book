# 《机械能守恒实验观察单》教师要求

## 使用情境

- 对象：高中物理“验证机械能守恒定律”分组实验；
- 使用者：高中学生，每组使用一台电脑或平板；
- 使用时机：实验开始前确认模型，实验过程中记录判断，实验结束后解释结果；
- 输出形式：单文件HTML，本地双击打开，可打印为A4纸。

## 学生需要完成的判断

1. 写明本组采用的实验方案，例如落体法、曲面下滑法或气垫导轨法；
2. 写明研究对象，并说明选择“物体”还是“物体与地球组成的系统”；
3. 勾选机械能近似守恒所需的条件，例如空气阻力或摩擦相对较小；
4. 区分直接测量量和根据模型计算的量；
5. 比较两个状态之间重力势能的减少量与动能的增加量；
6. 记录主要误差来源，判断误差方向或可能影响；
7. 用有限定条件的语言写结论，不使用“实验完全证明机械能绝对守恒”。

## 物理表述

- 若物体下降，重力势能减少量采用正值表示：
  `ΔEp,减 = mg(h1 - h2)`，其中`h1 > h2`；
- 动能增加量采用正值表示：
  `ΔEk,增 = 1/2·m(v2² - v1²)`；
- 在阻力做功可以忽略的近似条件下，比较`ΔEp,减`与`ΔEk,增`是否在实验误差允许范围内接近；
- 不默认所有实验方案都直接测量速度或高度，页面应让学生根据本组方案勾选或填写；
- 页面不自动生成“守恒”结论，只提供学生填写判断与依据的位置。

## 页面需要包含

- 标题与一句使用说明；
- 小组、日期、方案、研究对象填写区；
- 系统边界与近似条件检查区；
- 直接测量量与计算量检查区；
- 两个能量变化公式及符号说明；
- 误差来源勾选与补充填写区；
- 结论与证据填写区；
- 打印或保存为PDF按钮；
- 清空填写按钮，执行前二次确认；
- 页脚提示：本页面不上传或保存数据，关闭页面后填写内容不会保留。

## 视觉与技术约束

- 蓝白配色，清楚、克制，适合课堂投屏与A4打印；
- 电脑和平板上都能阅读，主要内容不横向溢出；
- 所有CSS和JavaScript写在同一个HTML中；
- 不访问网络，不调用外部字体、图片、脚本或样式；
- 不放学校、教师或学生个人信息；
- 不增加登录、账号、数据库、云端保存和AI自动评价功能。
