## 模拟网页文章为什么选动量模型

数智育才网站当前保存六个动量模拟网页：弹簧—小球、小球—圆环、悬绳小球—滑环、小球—半圆槽、小球—曲面小车和滑块—曲面。它们都围绕可移动系统中的水平动量守恒，同时把共速、分离、离轨、返回和模型切换放进可暂停的过程。

弹簧—小球页面适合作为模拟网页文章的贯穿对象。它把两类容易混淆的过程放在同一页面：物体接触弹簧后分离，以及两物体由弹簧始终连接。页面已有动画、参数调节、速度箭头、能量分配、速度—时间图、守恒检查、关键状态跳转和观察任务，读者可以从一张真实页面看到“物理规格怎样变成交互网页”。

这篇文章不承担六个模型的完整教学分析，也不讲整站架构。重写时集中回答一件事：一位没有专业编程经验的物理教师，怎样在WorkBuddy中把一个物理难点说清楚，生成第一个模拟网页，并完成第一次物理与交付验收。
