# 《机械能守恒实验观察单》交付说明

## 一、用途

面向高中物理"验证机械能守恒定律"分组实验的**课堂观察单**，供每组学生用一台电脑或平板填写。

它不替学生做判断，而是把一条完整的判断链固定下来：

> 定方案 → 定研究对象与系统边界 → 定近似条件 → 区分直接测量量与计算量 → 比较 ΔE_p,减 与 ΔE_k,增 → 分析误差方向 → 写出带限定条件的结论

三个使用时机：

| 时机 | 用哪几节 |
|---|---|
| 实验开始前 | 一（方案与对象）、二（近似条件）、三（测量量与计算量） |
| 实验过程中 | 四（公式与符号）、五（状态数据与计算） |
| 实验结束后 | 五的判断与依据、六（误差与方向）、七（结论与证据） |

**关键设计取向：页面不做任何"守恒 / 不守恒"的判定。** 第五节只按公式做四则运算，"误差允许范围"由学生依据仪器精度自己给出，"是否接近"由学生自己勾选并说明理由。

---

## 二、打开方法

1. 双击 `机械能守恒实验观察单.html`，用 Chrome / Edge / Safari / Firefox 打开即可。
2. 无需联网、无需服务器、无需安装任何软件。所有 CSS 与 JavaScript 都写在同一个文件里。
3. 平板使用：把文件拷到平板上用浏览器打开；页面在窄屏下自动改为单列，主要内容不横向溢出。
4. **留存方式**：点"打印 / 保存为 PDF"，在打印对话框中选择"另存为 PDF"。页面**不做任何本地保存**，关闭或刷新后填写内容即丢失（与页脚提示一致）。

## 三、已实现功能

### 1. 页面结构（共七节）

| 节 | 内容 | 主要控件 |
|---|---|---|
| 一 | 基本信息与实验方案 | 小组 / 日期 / 成员；方案单选（落体法、曲面下滑法、气垫导轨法、其他填写）；研究对象单选（物体 / 物体与地球组成的系统 / 未确定）+ 理由 |
| 二 | 系统边界与近似条件 | 6 项条件复选（含"其他"填写）+ 阻力做功处理方式说明 |
| 三 | 直接测量量与计算量 | 10 行量表逐行三选一（直接测量 / 由模型计算 / 本组未涉及）+ 关键计算式来源 |
| 四 | 两个能量变化量与符号说明 | 两个公式展示 + 6 个符号的含义、单位、本组取值来源填写 |
| 五 | 状态数据与能量变化计算 | 6 个数值输入 → 自动算出 ΔE_p,减、ΔE_k,增、差值、相对偏差 + 学生判断（是/否/数据不足）+ 判断依据 |
| 六 | 误差来源与影响方向 | 10 项误差复选（含"其他"填写）+ 影响方向单选（偏小/偏大/不确定/基本抵消）+ 理由 |
| 七 | 结论与证据 | 结论（带限定条件）、支持证据、适用范围与不足 + 6 项交卷自检 |

### 2. 物理表述

- `ΔE_p,减 = mg(h₁ − h₂)`，明确标注要求 `h₁ > h₂`，即**物体下降**情形；
- `ΔE_k,增 = ½m(v₂² − v₁²)`；
- 两者均为**正值表示的变化量**（页面明确写出"不是矢量，也不是末减初的代数量"）；
- 每页都强调：比较是否在**实验误差允许范围内**接近，而"允许范围"由学生给出；
- 研究对象两种取法（"物体" vs "物体与地球组成的系统"）都列出，页面说明二者物理等价、表述路径不同，**不预设哪一种正确**；
- 零势能面由学生自定，页面说明只涉及高度差、参考面选择不影响结果。

### 3. 边界提示（不静默出错）

当输入触发公式失效时，页面给出提示而不是硬算：

| 触发条件 | 提示 |
|---|---|
| `h₁ ≤ h₂` | 本页公式适用于物体下降，要求 h₁ > h₂，请检查状态设定或高度读数 |
| 算得 `ΔE_p,减 < 0` | 状态设定与"下降"不符，请核对 h₁、h₂ |
| 算得 `ΔE_k,增 < 0` | 该过程为减速，本页"减少量 / 增加量"比较方式不适用，请重新选取状态 |

### 4. 交互

- **打印 / 保存为 PDF**：调用浏览器打印；打印前自动把文本框撑高到实际内容高度，避免长答案被截断；打印时自动隐藏按钮与虚线提示框。
- **清空全部填写**：**两次确认**才执行（第 1 步确认 → 第 2 步"确认清空"），支持 Esc / 点击遮罩 / 取消按钮随时中止。清空后所有输入、勾选、计算结果一并复位。
- **数值实时计算**：改动 m、g、h₁、h₂、v₁、v₂ 任一格即更新四个输出；数据不全时显示"—"，**不补零、不编造**；输出统一 4 位有效数字。

### 5. 视觉与技术

- 蓝白配色，深蓝标题条 + 浅蓝底，克制、适合投屏；
- A4 打印样式（`@page size:A4`，页边距 14mm/13mm），各节尽量不跨页断开；
- 响应式：≤720px 自动单列，表格整体可横向滚动而**主体内容不溢出**；
- 单文件、零外链：无 `http(s)`、`//` 协议、无 `@import`、无 `url()`、无外部字体/图片/脚本/样式（已逐项核对，均为 0）；
- 无 `localStorage` / `sessionStorage` / `IndexedDB` / `fetch` / `XMLHttpRequest` / `WebSocket`（已逐项核对，均为 0）；
- 无登录、账号、数据库、云端保存、AI 自动评价；
- 不含学校、教师或学生个人信息；成员栏允许只填代号。
