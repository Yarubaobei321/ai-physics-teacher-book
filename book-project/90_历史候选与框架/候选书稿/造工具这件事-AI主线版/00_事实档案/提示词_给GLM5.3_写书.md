# 提示词 · 给 GLM 5.3（ZCode）独立写书

> 用法：先粘【块A】建立任务与硬约束；再把【块B 项目资料】分批粘入（或让 GLM 读本地文件）；参考书按需粘贴。GLM 会先给详细计划，你确认后再逐章写。  
> 关键：本提示词**不预设书名、命题、章节结构**，全部由 GLM 根据项目资料独立设计。

---

## 块A　任务 + 硬约束（喂一次即可）

```
你是中学物理教育图书的资深编辑兼执笔人。

【任务】
基于我提供的项目资料，独立撰写一版图书（Markdown 格式，配图用占位说明，不生成真图）。
主题范围：高中物理可视化教学与教师自研教学工具。
关键要求：不要沿用任何现成的书名、核心命题、篇章结构或章节标题——这些都要你根据项目资料重新独立设计，不能套用、不能照抄。

【参考书（仅作参考，禁止照抄/修改）】
我另有一版已写好的书稿《从用到造：高中物理可视化教学的自研之路》（12 章，约 10.8 万字，四位教师合著）。规则：
- 可以参考它用了哪些素材、写作深度如何；
- 禁止照抄它的书名、章节名、段落文字；
- 禁止在它基础上修改；
- 书名、命题、结构、章节标题必须独立重想。

【项目资料（你的全部事实来源，正文由我分批粘贴）】
资料分两类：
A. 物理论文 8 篇：论文01 科学思维可视化教学设计 / 02 学生AI协作评价 / 03 网页版DIS设计 / 04 光电门测速辨析 / 05 ESP32Blockly平台 / 07 生成式AI辅助H5资源开发 / 08 AI赋能教师开发教学网页 / 09 物理AI协作任务表现评价方法。
B. 项目资源：ESP32Blockly（图形化智能硬件编程平台，三端架构 + 8 类积木）；数智育才网站（shuzhiyucai.cn，四类可交互教学工具站）；静电场描绘仪专利；继续教育课程设计（AI 赋能零基础教师建站，4 课时）；特聘岗位考核台账；广东高考真题汇编；45 篇核心文献；同侪资源（王硕 / 严力耕 / 丁龙的教学设计与教具）。
（正文我会分批粘给你，写作以正文为准。）

【硬约束（逐条遵守）】
1. 证据纪律（最高优先级）：
   - 只写材料支撑的事实；不确定或无证据的，写"待补""拟观察""尚待验证"，绝不把设想写成已发生的结果。
   - 涉及学生表现、学习效果、课堂数据，必须有真实材料依据，不凭直觉推断。
   - 物理、教育领域的准确事实以素材为准；素材没有的标"待补"并写明需要哪类证据，禁止编造精确数字、人名、期刊卷期页码。
2. 开头直接进入真实对象、教学问题或矛盾，禁止"随着 AI 技术飞速发展""在核心素养背景下"式空泛开场，禁止"某天一位学生问我"式虚构。
3. 小标题呈现现象、冲突、结果或读者行动，禁止"AI 如何赋能""本节的理论意义"式汇报标题。
4. 少用"不是 A，而是 B"等对称裁判句，直接写结论、条件、证据。
5. 技术名词只保留到教师能理解设计取舍的程度，不展开协议、源码细节。
6. 正文不得出现"据原始文稿""已核验""以下待核实"等编务措辞。
7. 配图占位格式：
   > **图X-X　图题（占位）**
   > 画面说明：这张图要呈现什么对象、什么状态。
   > 制作建议：实拍 / 截图 / 重绘 / 数据图，关键要素。
   > 图源：待补（真实照片 / 项目截图 / 本书绘制）
8. 体例：# 第X章　章名；## 一、标题；### 1. 标题。

【流程（必须遵守）】
第一步：先给我一份详细计划，包含：你定的书名（含副标题）、核心命题、篇章结构、每章小标题、每章配图占位数量估算、全书预估字数。
等我确认计划后，再开始逐章写正文。不要跳过计划直接写正文。
```



---

## 块B　项目资料正文（分批粘贴）

把你选定的论文初稿、项目总览、关键事实贴在这里。宁可分批贴，不要一次塞太满；每批贴完可让 GLM 先复述关键事实，确认没读错再继续。

---

## 块C　参考书（按需粘贴）

如想让 GLM 参考 V1 修订稿的素材用法，贴相关章节；不贴也可，不影响独立设计。
