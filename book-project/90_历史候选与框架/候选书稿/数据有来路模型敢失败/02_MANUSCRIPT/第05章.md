# 第5章　三套装置，守恒式的三种读法

人教版必修第二册第八章第五节，"实验：验证机械能守恒定律"。这一节的计算负荷在高中物理里排得进前列：纸带上的计数点要逐个换算成速度，重力势能减少量与动能增加量要逐点对照，误差趋势要随着下落距离展开才看得出来。一节实验课，往往一半时间在算数，真正的思维环节——偏差从哪来、往哪边偏、哪个方案更可信——排在下课后，多数学生等不到那一刻。

支撑这一节的资源历来分属两拨。课堂一拨交给数字化实验系统：采集稳定，界面和数据格式由厂商固定，测量表格进不了教师自己的分析框架，围绕误差的论证常常在数据导出后就断了线。课后一拨交给课件、微课和公众号推送：学生看到的是别人算好的数。我们在自己的网站上给这一节做了第三种东西——机械能守恒在线实验室，三套装置方案、每套一页网页资源、二十八道分层习题，课堂与课后用同一份。这一章讲这份资源的结构，以及它为什么长成这样。

## 一、落体、曲面、气垫：证据各走各的路

同一个守恒式，三套装置给出三条证据路径。

方案一，落体法。重锤拖动纸带穿过打点计时器，五十赫兹的交流电在纸带上留下点迹。速度藏在点迹里：取计数点，用中间点定理 vₙ=(xₙ₊₁−xₙ₋₁)/(2T) 把位置序列翻译成速度序列，再逐点比较 mg(xₙ−x₁) 与 ½m(vₙ²−v₁²)。这条路径的证据是纸带本身——点迹清晰不清晰、起始端完整不完整，决定了整组数据的成色；隔点取计数点时T要相应改成0.04秒或0.10秒，这一处填错，全表皆错。

方案二，沿曲线运动。金属圆柱体从圆弧轨道的A、B、C三点静止释放，滑到最低点D，D点附近架着第1章那台双头光电门，前缘先后遮挡两条光路，v=L/Δt直读速度，L为1厘米的固定间距。比较释放点到D点的势能减少量mgΔh与动能增加量½mv²，A、B、C三点重复，还可作v²对Δh的图线。这条路径的证据是一次过门的时间差——圆柱直径在页面里只作记录，不进公式。

方案三，气垫导轨。滑块水平，重锤经细绳滑轮牵引，"滑块加重锤"作为系统：绳上张力是内力，作用与反作用做功之和为零，比较mgh与½(M+m)(v₂²−v₁²)。前后两只双头光电门同时给出两点速度。这条路径的证据是两次过门，但它多了一个前置环节——调平：先开气源从两端反向释放滑块看漂移是否对称（粗调），再推动滑块比较前后两门速度（细调）；前门还要布置在释放点下游五到十厘米，避开释放瞬间的扰动。

三条路径各有各的误差主因，而这正是三方案并置的教学价值：纸带的命门在点迹与频率，曲面的命门在滚动——圆柱体沿弧面滚下，½mv²只计平动动能，一部分能量进了转动动能，这是曲面方案ΔEk系统性偏小的主因；导轨的命门在调平与扰动。学生在三个方案之间迁移时，守恒式没变，变的是证据的来路与偏差的性格。第1章表1-2的三种位移段定义，在这里对应成三套真实装置。

## 二、六要素：一页网页收下一堂实验课

三套方案的页面共用同一个结构，六个要素：**原理讲解、交互演示、数据表、误差分析、分层习题、实验回顾**。每个实验页从上到下依次是：实验目的与器材，步骤，可填写可计算的数据表格与能量图像交互区，实验回顾（目的、器材、步骤、公式、参数、注意事项的清单），配套习题。

这个结构有两条认知科学的线索托底。双重编码理论指出，信息经言语与视觉两种编码表征后更利于存储与提取；多媒体学习理论进一步表明，言语与视觉双通道协同、并及时组织整合，能降低工作记忆负荷。六个要素按此分工：原理讲解承担言语通道，交互演示与数据表承担视觉通道，误差分析、分层习题与实验回顾承担组织与整合。

更要紧的是要素与难点的对应。六要素各锚定这一课题的一类具体困难：

| 要素 | 锚定的难点 |
|---|---|
| 原理讲解 | 守恒的条件与系统边界——从哪个点起算能量、系统划在哪里 |
| 交互演示 | 运动过程与能量转化的表象建立 |
| 数据表 | 逐点换算、自动计算、即时成图的计算负荷 |
| 误差分析 | ΔEk为何总略小于ΔEp、偏差随下落距离怎么变 |
| 分层习题 | 课后差异化巩固 |
| 实验回顾 | 复习与考试情境的提取需要 |

表里第三、四行值得多说一句。误差分析对应的"偏差方向与趋势"，是这个课题里思维含量最高的部分，也是两拨旧资源断裂时最容易丢失的部分——厂商软件导出数据后就不管论证，微课视频里又是别人算好的结论。六要素把它从"数据处理之后的尾巴"提为页面的固定栏目，与数据表并排。

## 三、数据表与误差分析，排在演示前面

页面要素的顺序就是价值排序：数据表与误差分析排在交互演示前面。这个顺序背后的判断是，这一课题的课堂时间应该从重复计算转向误差论证。

数据表的自动化做到了位：录入位置或时间，速度、ΔEp、ΔEk、相对误差δ=|1−ΔEp/ΔEk|（以动能增加量为比较基准）逐点自动算出，能量对比图即时生成。质量单位克、高度单位厘米，页面自动换算国际单位——这些小地方省下的课堂分钟数，比任何炫技的动画都多。

误差分析栏则把第1章的道理接到了图上。弦长效应、阈值吞宽这类遮光宽度的系统偏差，在能量图上呈现为"动能增加量稳定高于势能减少量"；曲面方案的滚动损耗则呈现为反向的"ΔEk系统性偏小"。偏差方向是机制的指纹——这句话在光电门那一章说过，在这里变成学生眼前的图线。默认参数也印在页面上：重锤100克，当地重力加速度取9.788米每二次方秒，相邻计数点间隔0.02秒。参数透明，算出的每一个数才可复算。

注意事项栏目同样照实写，不回避模型的近似：曲面方案的Δh应取圆柱体质心的高度变化；光电门触发对应前缘还是后缘，需要在数据解释里说明近似；滚动状态下平动动能偏小的原因，直接写成一句话结论。这一栏的存在本身就在示范：每条公式旁边都站着它的适用条件。

## 四、28道分层习题：课后还是这份资源

三方案各配一组习题：落体法10道，曲面下滑9道，气垫导轨9道，合计28道。题型四种——单选、多选、填空、简答——每道都带解析，学生作答即时判分。落点在课后：学生用手机打开同一页面，往下滑就是习题区。

"同一份资源"的含义在这里变得具体。课堂上学生亲手采的数据，长在页面上方的数据表里；课后的习题，考的正是这张表的逻辑——其中有一道概念辨析题，问的就是第1章那个总开关：v=d/Δt测的到底是哪一段的速度。课堂与课后之间没有换乘，数据与练习同源。

习题的维护方式也值得一提。二十八道题的内容没有写死在页面里，全部抽取成独立的结构化数据文件，展示由统一组件承担。教师增删一道题、修正一处表述，改动的是数据文件，页面自动更新；实验回顾同样如此。这一步把"AI生成的一次性页面"变成"教师可持续维护的资源库"——结构化程度决定了网页资源的寿命，这个话题在第11章还会以更大的尺度重现。

## 五、四类工具站是怎么长出来的

把镜头从一节实验课拉远到整个网站。数智育才（shuzhiyucai.cn）现在是一个拥有二十三个路由的静态站点，学生用手机或平板的浏览器打开就能用。它提供四类可交互教学工具：**在线编程**，经Web Serial直连ESP32，选MicroPython模板一键写入程序与库文件，页面上就能看串口输出；**网页版DIS**，第2章的主角，蓝牙连ESP32采力、距离、光电门数据；**在线实验室**，本章的三方案实验报告；**模拟实验室**，下一章的动量模型。另有两个项目式板块：项目式学习与科创天地，放智能小车、火星车这些科创课程的作品档案。

四类工具各回应一类需要，长的顺序也各有先后，但组织原则一致：每一类都在"数据带着来路"这件事上有明确的岗位。在线实验室的入口页把三个入口摆成三张卡片——两张实验工具、一张案例实验，光电门对比教程页从DIS页内链直达：到底测的是哪个时间？示意图对应到真实光电门、依次遮挡而非同时遮挡、从信号图看公式为什么不同、为什么小球更适合双头——教程页的这几节标题，本身就是第1章的浓缩版。

## 六、一个人，一条提交时间线

这个网站是一个人做的。一名没有前端背景的物理教师，2026年4月18日写下第一次提交，到7月2日共六十四次提交，全程git版本管理。三方案的页面代码，大量来自与对话式生成模型的往返打磨；整站的搭建、部署与维护，则由编程智能体协作完成。开发方法论整章留给第11章，这里只看这条时间线本身：六十四次提交，平均每两三天一次，每次提交对应一个具体的教学决定——加一道题、修一处公式、换一个默认参数。资源生长的过程全部可回溯，谁想知道某个页面三周前长什么样，翻提交记录就行。

一条完整的提交时间线，本身就是资源的档案。它与第4章教具的文书袋、第3章平台的四十三次提交，属于同一种东西：过程留下的痕迹。等到本书哪一章需要说明"这份资源是怎么来的"，答案都在版本库里，用不着凭记忆重构。

## 七、真题库给三套方案供题

资源与考试的关系，我们用一套题库来接。手里有一套2021—2026年广东高考物理分类汇编：十五个专题、约五百三十题，题干配图近六百张，每题一行索引，十五份考情分析全部完成。其中功与能专题三十八题、动量专题三十六题、实验专题四十五题，是三方案资源最对口的三座矿。

供题的方式很朴素。编写分层习题时，从真题库里取情境的形态与设问的角度：实验专题里光电门、纸带、导轨的设问方式，直接决定数据表栏目的措辞；功与能专题里"偏差来源判断"一类选择题，是误差分析栏的题源。反过来，真题汇编的索引里"难度、关联资源"两列还空着，等着由三方案资源的使用情况回填——题库给资源供题，资源给题库补注脚，两边互相成全。
