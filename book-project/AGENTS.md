# 图书出版 Agent 工作规则

## PROJECT_SUMMARY

- **目标**：把真实物理教学实践、材料、认识与方法组织成教师可理解、可跟做、可核验的作品；按具体作品决定叙事、操作深度和交付形式。
- **现役新书**：[新书项目](10_新书-AI时代物理教师实践与技术手册/AGENTS.md)保留网站部分“指导为主、案例为证”的重启路线；网站任务书与三样章身份由子项目说明。本父层不把全部任务退回B0。
- **独立文章**：[真实实践文章池](真实实践文章池/README.md)按实践、文章、反馈与修订生长；当前WorkBuddy入门停在首轮核查与第二轮修改要求，实际进度先读其反馈总账。成熟文章是否回流书稿由作者决定。
- **旧版图书**：[旧《从用到造》V1](<旧版图书/从用到造：高中物理可视化教学的自研之路 V1/00_CONTEXT/README.md>)及`旧版图书/`其他版本作为原有项目保存。十二章正文、合订脚本与PDF构建只在旧书自己的AGENTS和入口下生效，不成为新书与文章池的前置。
- **公共材料**：`../项目资源库/00_AGENT入口/`负责项目与证据导航；`新项目推进/`保存研发候选，存在原型不等于成熟案例。进入具体作品先读其AGENTS、当前任务与必要来源。
- **验证与恢复**：本轮规则修改以准确文件副本和指纹保护；路径/版本/链接、物理事实、实际操作、目标教师跟做与作者终审分别验证。不对无记录的课堂效果、出版状态或WPS显示作保证。
- **技能入口**：本项目 `.agents/skills/` 提供 `book-material-mining`、`physics-visualization-ai-researcher`、`resource-digest` 的短入口，引用上级写作技能真身；按当前作品与阶段选择，不强制旧书目录或六模型全检。2026-09-05已核验本机可发现。

## 写作与裁决

- 先说清读者的具体问题、能增加的认识或动作，再读取对应原件。已有任务与授权直接复用，不因多文件、新章节或使用技能重复确认；新的章前价值、科学结论、合著归属和正式采用仍依作者裁决。
- 按任务需要完成策划、取材、表达与核验，不强制五角色或G0—G6依次出独立文档。B0—B6和章前门只在当前子项目及实际阶段使用，不因独立文章任务重建全书流程。
- 新书任务书与文章池并行，作者想法记录不自动合并路线。保留作者和合著者的声音，王硕、严力耕、丁龙等材料不转写为黄灿斌亲历。
- 面向高中物理教师写具体对象、操作、现象、解释和边界。实践叙事保留理解选择所需细节；操作手册保留复现、验收和排错所需的连续步骤，不把开发日志直接搬入正文。
- 每段、案例或图表增加读者理解或行动，字数、图数、模板完整不代替价值。已有可靠材料卡可复用，具体事实仍回原件。
- 使用`../docs/agents/AI-Agent文本写作表达门禁.md`与本目录`AI写作反模式指南.md`；英文表达问题再查英文版，不要求中文稿逐项套英文专属规则。

## 证据与图件

- 区分作者真实实践、合著者材料、结构参考、待核材料和AI假设。教学设计、课题预期和软件运行不能冒充课堂实施或学习效果。
- 参考资料保留原位、归属与授权；公开学生作品、课堂照片与截图前按真实要求脱敏。AI插图不得冒充真实现场、装置、学生作品或数据。
- 根据解释需要选择真实照片、结构图、流程图、表格、公式或文字；纯文字不需另写“为何不配图”的审批说明。拟用图须有读者问题、读图动作、来源和适用边界。
- 正文直接表达事实与必要条件；过程核验和待办进入来源/审核材料。会改变理解或行动的真实限制保留，不能为表达流畅删掉科学限定。

## 修改与交付

- 保留旧稿、阶段记录和原始素材，只改当前授权范围；正文候选与正式稿身份分明，不自动发布或改写其他项目。
- 运行与本次改动相关的已有检查。完整导出按具体项目检查图号、图片、引用、字体和版式；局部修订不机械全书重建。
- 跨文件成果按review-protocol复用一份审阅说明，需要视觉对照或复杂导航时提供HTML，可合并总览与证据，不强制双页。
- 遵守既定人工HTML视觉审阅方式：未获作者另行要求时只检查文件、链接和基本结构，不自动生成浏览器或移动端截图。
