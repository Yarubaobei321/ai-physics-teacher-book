## R.11 三张验收表

### 物理验收

- [ ] 对象、变量、单位和关系正确；
- [ ] 模型条件和边界明确；
- [ ] 原始数据与处理量对应；
- [ ] 结论没有超过证据。

### 教学验收

- [ ] 学生知道问题和产物；
- [ ] 有预测、解释或反驳空间；
- [ ] 有迁移或不适用任务；
- [ ] 失败可以推动下一步。

### 工程/合规验收

- [ ] 多设备和异常状态可处理；
- [ ] 有版本、维护和离线方案；
- [ ] 图片、代码和学生材料有授权；
- [ ] 安全和隐私边界明确。

## R.15 结论语气检查

把每个结论改写为以下三种之一：

1. “在本次记录中观察到……”；
2. “在当前装置、范围和条件下，数据与……相容”；
3. “可以设计一项任务，让学生进一步检验……”。

如果只能写“显著提高”“普遍有效”或“完全证明”，先回到主张—证据—推理表。
