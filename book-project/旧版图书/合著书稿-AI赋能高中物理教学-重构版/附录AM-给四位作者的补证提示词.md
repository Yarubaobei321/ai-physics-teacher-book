# 附录AM 给四位作者的补证提示词

作者后续可以把以下提示词交给自己的记录、文件或访谈助手，但所有输出仍需本人核对，不得让AI代替事实确认。

## AM.1 课堂案例

```text
请根据我提供的课件、任务单和原始记录，先列出能够确认的事实、只能确认的设计意图、缺少的学生证据和不能写成效果的句子。不要补写学生原话、数据或课堂情节。最后给出我需要本人确认的十个具体问题。
```

## AM.2 装置与数据

```text
请把下面的装置材料整理成“结构—直接测量量—处理量—模型条件—安全—版本—授权”七栏。若文件中没有参数或功能证据，标记待核实；不要根据代码或图片推测尚未实现的功能。
```

## AM.3 学生作品

```text
请只做学生作品证据索引，区分学生、AI、教师和不确定角色，列出成品可评、过程可评和缺失材料。不要根据页面复杂度推断学生能力，不要展示姓名、账号、链接或独特文字。
```

## AM.4 作者规划

```text
请把我的口述规划整理为“已发生事实、正在推进、未来设想”三类。未来设想保留第一人称但不要写成已经完成；涉及共同作者和学校的内容标记待确认贡献归属。
```

## AM.5 贡献确认

```text
请根据版本、照片、任务卡和访谈材料列出设计者、制作人、实施者、数据提供者、代码贡献者、图片权利人和审校者。不能根据文件名或章节主笔自动分配贡献。
```

## AM.6 出版前自问

```text
请搜索本章所有数字、效果性词语、学生原话、图片、代码、网页版本和安全描述，生成“证据位置—来源—授权—待确认—建议语气”表。不要直接把缺口填成完整句子。
```

## AM.7 使用原则

这些提示词帮助作者整理，不帮助作者逃避确认。作者本人必须回到原始文件、装置、数据和共同作者；AI的摘要、表格和问题清单不自动构成来源。补证完成后，更新章节正文、来源台账、贡献台账和审稿记录。
