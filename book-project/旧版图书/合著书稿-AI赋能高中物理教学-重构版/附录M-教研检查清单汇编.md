# 附录M 教研检查清单汇编

本清单汇编用于备课、试用、审稿、评价和出版。勾选只是开始，关键项目要附证据位置；不能确认时写“待核实”，不要用空白掩盖不确定性。

## M.1 现象与问题清单

- [ ] 学生在工具出现前能够观察到共同现象；
- [ ] 现象描述没有提前塞入结论；
- [ ] 学生可以提出至少一个可检验问题；
- [ ] 问题包含对象、变量或比较关系；
- [ ] 情境不依赖学生接触不到的隐含信息；
- [ ] 问题与章节功能一致，而非工具展示；
- [ ] 学生留下初始预测和理由；
- [ ] 教师知道何时可以暂缓解释；
- [ ] AI没有在观察之前给出标准答案；
- [ ] 现象的安全和隐私边界已写明。

## M.2 变量与测量清单

- [ ] 研究量、改变量、控制量和测量量分别写出；
- [ ] 直接量和处理量没有混淆；
- [ ] 每个字段都有单位和来源；
- [ ] 测量位置、时间窗和采样口径明确；
- [ ] 量程、分辨率和响应速度适合问题；
- [ ] 有零点、重复和边界测试；
- [ ] 原始记录不会被处理结果覆盖；
- [ ] 失败测量有备注和状态；
- [ ] 代表值定义在各组之间一致；
- [ ] 需要复测时知道只改哪一个变量。

## M.3 模型清单

- [ ] 研究对象和系统边界清楚；
- [ ] 参考系和正方向明确；
- [ ] 初始条件、参数范围和近似写出；
- [ ] 公式中的量与字段对应；
- [ ] 图像、动画、表格和文字使用同一模型；
- [ ] 有一个不适用或反例情境；
- [ ] 结论强度不超过证据；
- [ ] 零值、缩放和边界测试已经运行；
- [ ] AI生成公式经过手算或实物核验；
- [ ] 学生能够用自己的话解释关键变量。

## M.4 网页与程序清单

- [ ] 页面信息结构先于完整代码；
- [ ] 空值、错误单位和极端输入有提示；
- [ ] 设备未连接、丢包和超时不会被显示成0；
- [ ] 原始数据、处理数据和结论分层；
- [ ] 公式、状态变量和图表共享数据链；
- [ ] 处理参数可查看和修改；
- [ ] CSV或其他数据格式可导出；
- [ ] 有离线或纸面替代；
- [ ] 在目标设备和备用设备上测试；
- [ ] 版本、依赖和回退说明完整。

## M.5 AI协作清单

- [ ] AI承担的子任务具体；
- [ ] 提示中包含物理和工程约束；
- [ ] AI没有被要求编造事实、数据或经历；
- [ ] 输出被标记为草稿、建议或示例；
- [ ] 学生/教师完成了人工验收；
- [ ] 错误建议和拒绝理由被保留；
- [ ] 过程和成品分开保存；
- [ ] 对话角色可辨认；
- [ ] 隐私和第三方材料没有不必要上传；
- [ ] AI停止或失效时任务仍可继续。

## M.6 项目与课程清单

- [ ] 每节课写清输入、过程、输出；
- [ ] 下一节课真实读取上一节课的产物；
- [ ] 项目有固定目标、开放路径和明确证据；
- [ ] 学生决策权与先修能力匹配；
- [ ] 过程档案不等于文件堆；
- [ ] 失败记录能推动下一轮任务；
- [ ] 器材、文件和版本有编号；
- [ ] 有交接和维护说明；
- [ ] 安全、授权和隐私从设计阶段进入；
- [ ] 课程版本能够回退和替代。

## M.7 学科周清单

- [ ] 每个活动写观众看到什么、学生解释什么、留下什么；
- [ ] 有原理卡、风险卡和学习卡；
- [ ] 场地动线、人数、供电和隔离明确；
- [ ] 高风险现象有低风险替代或取消决定；
- [ ] 外部嘉宾和医学/校外材料有授权；
- [ ] 学生参与以观察、记录和判断为主，不以冒险为主；
- [ ] 活动问题可回到课堂或项目；
- [ ] 区分参与证据、学习证据和系统证据；
- [ ] 记录近失和设备故障；
- [ ] 下一次活动有删减和修订依据。

## M.8 学生作品评价清单

- [ ] 提交前公布A轨和B轨；
- [ ] 问题卡和模型卡完整；
- [ ] 对话角色和来源可核验；
- [ ] 至少有一项边界测试；
- [ ] 至少保留一个错误或回退版本；
- [ ] 页面物理、交互和可访问性分开检查；
- [ ] 只有源码时不推断过程能力；
- [ ] 证据缺失触发上限、暂缓或口头复核；
- [ ] 评审者保留证据位置和修改理由；
- [ ] 评价结果被用于下一次任务设计。

## M.9 出版清单

- [ ] 每章功能和主张与总纲一致；
- [ ] 数据、照片、网页和代码来源可追溯；
- [ ] 作者贡献、材料贡献和实施贡献分开；
- [ ] 学生身份、文件名、账号和分享链接已脱敏；
- [ ] 图片、字体、库和截图有许可；
- [ ] 占位符有后置补证台账；
- [ ] 结论语气与证据等级匹配；
- [ ] 术语、公式、标题和编号统一；
- [ ] Word/PDF从源文件重新构建；
- [ ] 人工通读后才称为交付稿。

## M.10 红线清单

出现以下情形，立即停止公开或扩大使用：

- 物理公式、单位或数据来源无法确认；
- 高风险装置没有负责人和撤销条件；
- 学生或患者信息未脱敏；
- 图片、代码或网页没有授权；
- AI输出被当作实测数据或学生原话；
- 自动处理覆盖原始记录；
- 章节把设计意图写成普遍效果；
- 贡献归属存在争议；
- 资源没有回退或维护人；
- 评价者无法解释分数依据。
