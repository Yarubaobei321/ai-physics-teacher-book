# 《智启格物》全书交叉审读报告

> 审读日期：2026-07-11
> 审读范围：`分章稿/`十八章、书稿根目录附录与现有章节写作包
> 审读目的：确认全书主线是否连续、相邻章节是否越界、待补证是否可追踪，并为下一轮作者补证和出版审校建立入口

## 一、总体判断

当前书稿已经从“十八章结构稿”推进为“可连续试读的纯文本初稿包”。六篇的总体递进能够成立：第一篇提出问题和认识框架，第二篇把框架落到现象、证据和测量，第三篇讨论工具、资源与模型，第四篇把模型带入迁移和复习，第五篇处理从工具使用到课程与项目创造，第六篇回到作品评价、教师自主权和伦理边界。

全书反复使用的主线是“现象—证据—模型—迁移—创造—评价”，但不是把每章强行写成六段流程。各章承担的重点不同：第4章重点是多证据互校，第8章重点是系统边界与守恒模型，第10章重点是学生作品中的模型错误，第17章重点是协作过程的证据归属。这个区分需要在终稿中继续保持。

## 二、篇章衔接检查

| 衔接 | 已形成的关系 | 终稿需特别检查 |
|---|---|---|
| 第1章→第2章 | 第1章提出“工具变而格物不变”，第2章给出证据—模型—进阶框架 | 第1章的导论例子不要提前替代第2章理论解释 |
| 第2章→第3章 | 第2章提出六级过程，第3章说明如何组织认知路径和大单元 | 进阶层级应被写成可调整假设，不写成统一标准 |
| 第3章→第4章 | 从理论框架进入完整课例，第4章承担首个三证据样章 | 第4章需回收第2章术语，同时保留课例自身的现场性 |
| 第4章→第5—6章 | 三证据链展开为测量进阶和定量关系实验 | 避免把“证据链”再次解释成抽象口号 |
| 第7章→第8章 | 第7章讲工具怎样产生数据，第8章讲数据怎样进入守恒模型 | 第8章不重复光电门技术细节，只保留对模型有用的部分 |
| 第8章→第9章 | 第8章的资源使用转入第9章的教师—AI资源开发流程 | 第9章写开发方法，不重新讲完整机械能课堂 |
| 第9章→第10章 | 教师开发资源转到学生使用AI制作作品 | 第10章要以学生模型和错误为中心，不变成平台介绍 |
| 第10章→第11—12章 | 作品中的模型问题回到概念课和大单元复习 | 第11章写模型建立，第12章写迁移与复习组织，边界要清楚 |
| 第12章→第13—16章 | 从课内进阶进入跨课时课程、平台、校本课程和学科周 | 四章要形成“任务—平台—课程—项目”的递进，不写成活动汇编 |
| 第16章→第17章 | 项目成果进入评价，活动热度转为证据档案 | 第17章要承接作品过程，不把活动总结改写成学习效果 |
| 第17章→第18章 | 评价边界回收到教师专业自主权和伦理治理 | 第18章要保留“不知道”和“暂缓裁定”的专业语言 |

## 三、主要重复与处理决策

### 1. 第4章与第8章

两章都使用实验和多种证据。第4章的不可替代功能是展示一节课如何从身体体验、图像/示数和传感器数据长出三条证据链；第8章的不可替代功能是展示同一守恒模型在纸带、光电门、气垫导轨和在线模型之间如何迁移。终稿中，第4章保留课堂叙事和证据互校，第8章保留系统边界、原始量和模型判断。

### 2. 第7章与第9章

第7章讨论活版电路、光电门和网页DIS作为“会被追问的工具”；第9章讨论教师如何提出需求、生成原型、校验公式、试用和维护资源。第7章的关键词是测量模型和数据链，第9章的关键词是资源生命周期和教师责任。两章可以交叉引用，但不复制完整操作流程。

### 3. 第10章与第17章

第10章关注学生AI网页作品中的物理模型、变量、边界和错误；第17章关注作品与协作档案如何进入评价、申诉和熔断。第10章回答“作品哪里错、为什么错”，第17章回答“评价者凭什么这样判”。

### 4. 第13—16章

第13章是跨课时任务的课程接口，第14章是物理测量与编程平台，第15章是校本课程和开放项目，第16章是学科周与项目式学习。它们的共同主题是“从使用到创造”，但尺度不同：课时、平台、课程、校园活动。终稿应保留这种尺度递进。

## 四、统一口径检查

当前稿已统一采用以下区分：

- 设计建议：说明“可以怎样安排”，不等于已实施事实；
- 功能验证：说明设备、网页或代码在指定条件下能否运行，不等于学习效果；
- 课堂观察：说明一次或一组课堂中记录到的现象，不等于普遍规律；
- 学习效果证据：需要样本、任务、方法、时间范围和替代解释；
- 作者补证：必须回到作者、原始文件、数据、照片、作品或授权记录。

涉及“显著、普遍、有效提高、推广价值、验证成功”等强词时，正文应优先写条件、范围和证据等级；附录中的反向审查条目不能替代正文降格。

## 五、下一轮优先事项

作者补证按照现有约定后置，不作为当前继续推进的阻塞条件。下一轮建议按以下顺序进行：

1. 先完成全书术语、章节交叉引用和公式口径的内部统一；
2. 依据《来源与授权台账》整理正式文献题录、网页版本、图片来源和学生作品编号；
3. 对第4、8、10、17章做一次重点反向审查，逐条区分设计、功能、课堂和效果证据；
4. 组织小范围试读，记录读者在哪些术语、表格或任务处停顿，不把试读反馈写成学习效果；
5. 作者材料到齐后，优先回填高风险主张、关键数据、贡献归属和授权，不要先用补充文字掩盖证据缺口；
6. 最后再进行Word/PDF构建、图表排版、目录页码、隐私脱敏和人工校样。

## 六、审读结论

本轮未发现需要立即拆分或重排的章节。当前最重要的风险不是篇章数量不足，而是后续补证时同一案例被多章重复使用、论文结论被扩大到全书、功能验证被误写成学习效果，以及作者贡献和学生材料的公开边界没有同步更新。只要按上述边界继续推进，当前版本可以作为下一轮作者补证、内部试读和出版准备的稳定底稿。
