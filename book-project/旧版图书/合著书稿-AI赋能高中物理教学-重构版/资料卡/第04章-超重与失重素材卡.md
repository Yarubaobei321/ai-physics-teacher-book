# 第4章素材卡：超重与失重的三条证据链

## 一、章节增量

现有三章分别写丁龙课堂设计、王硕逆向设计和严力耕智能超失重仪。重构后不再并列介绍三位教师，而是回答一个问题：学生关于“体重秤示数为什么变化”的认识，怎样从身体感觉，进到可解释的图像，再进到可校准的传感数据？

三条证据链：

1. **体验证据**：蹲起、纸带重锤、漏水瓶和生活经验；
2. **图像与评价证据**：电梯运动图像、预期理解、表现任务和量规；
3. **传感证据**：可控运动、压力传感、原始曲线、校准、误差和模型比较。

## 二、素材分层

### 第一条：丁龙教学设计

已核验事实：

- 课时40分钟；情境是“不改秤、不额外施力，怎样让示数变化”。
- 探究阶段包含体重秤蹲起、纸带重锤、电梯模型与Phyphox、漏水瓶和航天情境。
- 原教案设置知识掌握、技能运用、思维品质、情感态度四维量规，并配自评、互评、师评。
- 作业分基础、拓展和实践三类，实践任务建议记录电梯体验并尝试使用Phyphox。

需要复核：

- 文稿“预设与生成”中的学生反应是否来自真实课堂记录。
- 手机使用的是加速度实验还是经积分得到的速度图；原稿写“加速度传感器记录v-t图”，表述存在技术疑点。
- 自制电梯教具的实际结构、图片和测量方式。

### 第二条：王硕逆向设计

已核验事实：

- 无实施证据前，不写“模式促进学生核心素养综合提升”。

### 第三条：严力耕智能超失重仪

已核验事实：

- 正式名称为“基于ESP32的智能超失重现象演示仪”，登记表列三名作品作者。
- 作品文稿列出2040铝型材、闭环42步进电机、2GT同步带、ESP32、应变梁和HX711等材料。
- 制作方法包含框架、同步带、滑车、电机、控制器、传感器、程序和标准砝码校准。
- 现有`main.py`实现BLE接收0—3索引并通过UART发送四组固定TTL指令；网页实现Web Bluetooth连接和四按钮发指令。

关键证据缺口：

1. 提供的网页只负责发TTL指令，没有压力数据接收、实时曲线或CSV导出。
2. 提供的`main.py`没有压力传感器采集、HX711、运动参数计算或滤波代码。
3. 程序实际初始化UART为115200，但打印信息写9600，出版前必须确认真实波特率。
4. 作品文稿所称“AI低通滤波算法”目前表现为“数据导出后上传AI工具处理”，没有算法、截止频率、采样率、参数和前后数据证据。
5. 闭环步进能改善位置跟踪，不自动证明加速度准确；仍需运动指令、位移—时间或速度—时间验证。
6. “极大提升”“显著提升”“易于复制”等效果性表述没有改进前后数据，正文删除或改为待验证目标。

## 三、物理科学性清单

### 1. 研究对象与受力

以秤上的物体为研究对象，竖直方向受重力`mg`和支持力`N`。取竖直向上为正：

`N - mg = ma`，即`N = m(g + a)`。

当`a > 0`时`N > mg`；当`-g < a < 0`时`0 < N < mg`；自由落体时`a = -g`，`N = 0`。下降不必然失重，上升不必然超重，状态由加速度而非速度方向决定。

### 2. 体重秤测到什么

传感器直接响应接触力，经标定后显示质量单位或力单位。教学中要区分：

- 重力：地球对人的作用力；
- 支持力：秤对人的力；
- 压力：人对秤的力，与支持力成牛顿第三定律关系；
- 秤面示数：经仪器标定后的显示量，不应含糊写成“就是体重”。

### 3. 传感数据链

`运动控制 → 物体加速度 → 支持力变化 → 应变梁形变 → HX711数值 → 去皮/标定 → 时间序列 → 模型比较`

任何“平滑”必须在保留原始数据后进行，并说明采样率、窗口或滤波参数。不得用平滑曲线替代实验误差讨论。

## 四、样章拟定结构

1. 开场：秤面示数是一种什么证据；
2. 证据链一：先让身体和低成本实验说话；
3. 从体验到模型：重力、支持力、压力和示数；
4. 证据链二：逆向设计先规定“理解的证据”；
5. 图像任务：速度/加速度、运动阶段与视重；
6. 证据链三：智能演示仪怎样把过程变得可控、可测；
7. 原始数据、校准、误差与“AI滤波”的审查；
8. 三条证据链比较；
9. 三档课堂方案与实践工具包；
10. 限制、授权与下一轮改进。
