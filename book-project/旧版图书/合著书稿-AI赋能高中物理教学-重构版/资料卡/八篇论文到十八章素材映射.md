## 三、跨章复用规则

### 1. 一个事实只设一个主落点

- “30份作品中10份可信、20份暂缓”只在第17章完整报告；第10章引用个案时回指第17章。
- “三端架构、36人8组”只在第14章完整展开；第13、15章只说明课程接口。
- “六要素网页体系”只在第9章完整解剖；第8章只说明其中哪些要素承载证据和模型。
- “单头与双头光电门完整推导”只在第7章；第8章只引用其测量结论和误差边界。

### 2. 同一案例跨章时更换问题，不复制叙述

以机械能守恒为例：

| 章节 | 使用同一案例时只回答 |
|---|---|
| 第7章 | 数据是怎样被光电门和网页采集的，测速模型有什么边界 |
| 第8章 | 三套真实装置怎样产生证据，证据怎样支持或挑战守恒模型 |
| 第9章 | 教师怎样把学科理解转化成可用、可验收的网页资源 |
| 第17章 | 若学生制作类似页面，怎样区分学生能力与AI产物质量 |

### 3. 论文结构必须拆解

论文中的摘要、问题提出、文献综述和结论不直接进入书稿。优先拆出：

- 可核验事实；
- 原始数据和数据口径；
- 课堂或开发关键决策；
- 可复用图表；
- 失败与限制；
- 正式参考文献线索。

### 4. 待补证不阻塞蓝图，但阻塞定稿

作者课堂原话、学生反应、实施效果、实验数据和贡献归属可以在蓝图与初稿阶段标记后置；进入正式审阅版前必须回到原材料核验。当前不因补证后置而虚构过渡性事实。
