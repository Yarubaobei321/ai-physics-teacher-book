## 二、六项可迁移写法

### 1. 全书进阶不是目录顺序，而是能力叠加

教材从“拖动积木”走到“系统编程”，后阶段没有否定前阶段：积木形成的结构直觉继续存在于代码、状态机和任务图中。新专著也要让“观察—证据—模型—迁移—创造—评价”逐层叠加，而不是每篇另起炉灶。

迁移位置：全书六篇递进、第2章理论框架、第18章收束。

### 2. 每课时都有可验证的工作节奏

教材统一采用“问题→知识→接线→程序→验证→迭代”。真正值得迁移的不是接线与程序两个技术词，而是“从问题出发、让证据出现、按标准验收、根据失败继续迭代”。

新专著改写为：

`真实问题 → 证据设计 → 实验/活动 → 模型解释 → 验证 → 迭代与迁移`

迁移位置：所有实践章，尤其第4—10章。

### 3. 分层任务让同一项目拥有认知坡度

第15章电子秤用L1—L5组织任务：能称、可信、能判、能记、能测力。其核心链是：

`传感（应变片）→转换（HX711）→处理（去皮/校准/滤波）→应用（显示/报警/记录）`

这套结构能直接增强第4章样章。超重失重实验可分为：

1. 看见示数变化；
2. 区分重力与支持力；
3. 用图像判断加速度和视重关系；
4. 校准传感器并比较理论值；
5. 设计新的运动程序或评价方案。

边界：教育专著不在每章机械使用L1—L5标签，只保留“有起点、有台阶、有升级任务”的方法。

### 4. AI素养必须从使用进到审查和负责

教材的AI素养三级线是：L1会提问、L2会审查、L3会指挥。第32章把L3写成三条纪律：任务拆解权在人、上下文由人管理、关键决策留痕；核心表达是“AI提议，我们验证并拍板”。

新专著采用相同立场：

- 初阶：把现象、接线、数据和问题描述清楚；
- 中阶：发现AI的物理错误、证据缺口和越界建议；
- 高阶：让AI承担明确子任务，教师或学生制定验收标准并对结果负责。

迁移位置：第2、9、10、14、17、18章。

### 5. 真实器材与真实限制进入正文

教材明确批量器材、零星器材、默认引脚、校内/校外工具双轨和不设置AI视觉章的原因。它证明“没有某种器材，所以不写某章”同样是高质量设计。

新专著的器材章节必须回答：数量够不够全班使用、型号和量程是什么、低成本替代是什么、浏览器/系统兼容性如何、维护由谁负责。

迁移位置：第4—9章、第14—16章。

### 6. “常见坑”不是附属说明，而是证据教育

附录C把故障按症状分类，并坚持一次只改一个变量、单件验收、相信仪器、不相信感觉、保留日志和照片。它与物理实验的控制变量、证据意识完全同构。

新专著每个装置/平台章节增加“失败与排查”表，字段统一为：症状、最低成本检查、可观察证据、下一步、停止条件。

迁移位置：第4—10章、第14—16章。

## 三、不能机械照搬的部分

1. 教材章节以2—4课时和操作步骤为主，教育专著单章需要补足理论争点、文献位置、课堂证据与反思。
2. 教材九栏目适合学生任务书，专著统一使用六段式；“挑战任务、组合创想、工程师视野”按章节需要选用。
3. 代码、平台字段和在线服务会快速变化，专著只保留能解释教学决策的关键技术，版本细节放延伸资源。
4. 教材中的工程验收不能直接证明学生物理理解；新专著需要额外设计概念辨析、模型解释和证据论证任务。
5. 版面字数约24万包含代码和Markdown字符，不能用来证明中文论述已经达到同等字数。
