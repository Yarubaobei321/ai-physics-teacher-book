# 来源与授权台账

> 用途：先判断“谁的材料、能证明什么、能写到什么程度”，再进入正文。

## 状态词

- **证据等级A**：原始材料完整，可回溯。
- **证据等级B**：材料存在，但叙述、数据或效果仍需作者复核。
- **证据等级C**：关联研究或合作者成果，须按原课题、原作者和授权边界使用。
- **本人材料**：由本书作者本人形成，仍需核对共同作者、单位和公开权限。
- **合著者确认后可用**：四位作者内部确认材料贡献和表述。
- **需课题团队/相关权利人确认**：涉及课题报告、论文合作者、学生或其他权利人。
- **公开文献规范引用**：只按学术引用使用，不复制受版权保护的大段内容或图表。

## 第一批授权动作

1. 丁龙确认教学设计中的“实际课堂生成”段落哪些来自真实课堂记录，哪些是设计反思。
2. 王硕确认逆向设计材料是否实际用于《超重与失重》课堂，以及可提供的学案、课件或评价样例。
3. 严力耕确认超失重仪的三位作品作者、数据采集页面、运动参数、压力曲线和滤波过程。
4. 第4章只使用前三项确认前已核验的结构、原理与操作事实，不写量化学习效果。
5. 马平课题和学生网页在完成课题团队确认、授权与匿名检查前，只进入资料卡和理论/方法分析，不进入公开审阅版的可识别材料。
