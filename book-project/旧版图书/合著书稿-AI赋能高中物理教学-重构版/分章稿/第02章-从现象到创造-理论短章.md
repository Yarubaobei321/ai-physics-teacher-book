# 第2章 从现象到创造：“证据—模型—进阶”框架

> 主笔：黄灿斌
> 本稿性质：第一批理论短章，供四位作者审阅。正式成书时将扩充案例、图表与参考文献。

## AI已经能解释，学生还需要经历什么

把一道高中物理题交给生成式人工智能，它往往能在几秒内列出公式、代入数据并生成一段结构完整的解释。让它设计一节课，它也能迅速给出情境、问题链、实验和评价表。再进一步，它还能编写一个会动的网页，画出一条看上去平滑而准确的曲线。

效率的提高是真实的，但一个更重要的问题随之出现：**当解释、图像和程序都可以被迅速生成时，学生是否还经历了物理知识形成的过程？**

一条曲线可能来自真实传感器，也可能只是代码根据理想公式绘制的图像；一个答案可能来自学生对研究对象和运动过程的分析，也可能来自把题目原文交给AI；一个交互网页可能凝结了学生对模型边界的反复修正，也可能只是一次提示词生成的成品。它们在屏幕上看起来相似，代表的学习却完全不同。

物理学并不只负责给出现成解释。它还要追问：现象是怎样发生的？我们测量了什么？数据是否可靠？模型作了哪些假设？结论能解释到哪里？什么新证据可能推翻它？这是一种“证据责任”。学生不只是知道结论的人，还应逐步成为能够说明结论从何而来、为何可信、在何种条件下成立的人。

因此，AI时代的物理课不是要在“使用AI”与“禁止AI”之间二选一，而是要重新设计学习过程：让真实实验提供现象与约束，让数据成为可以追溯的证据，让模型组织和解释证据，让AI扩展表征、方案与反馈，让评价看见学生在其中承担了什么判断。基于这一立场，本书提出“证据—模型—进阶”框架，并把它展开为六类相互关联的学习活动：**现象、证据、模型、迁移、创造、评价。**

这六类活动不是每节课必须按顺序走完的固定六步。概念课可以重点经历现象、证据、模型和迁移；实验课可能在证据与模型之间多次往返；项目学习则可能从一个失败作品开始，倒逼学生重新测量和修正模型。所谓进阶，不是教学环节越来越多，而是学生承担的认识责任逐步增加。

## 物理学习首先是一种证据责任

科学教育研究长期强调，科学学习不仅是掌握知识结论，还包括生成和评价证据、建构解释、理解科学知识如何形成，并参与科学实践与论证。学习进阶也不是把教材章节从易到难排成一列，而是描述学生围绕核心概念和科学实践，如何在持续的教学支持下形成更精细、更有解释力的理解。这样的进阶需要经验检验，不能只凭教师对“难度”的直觉设想。

对物理教学而言，证据责任至少有四层含义。

第一，区分现象与解释。“体重秤示数变大”是现象，“人处于超重状态”是基于模型作出的判断；“小球越滚越快”是观察，“重力势能转化为动能”是对系统和过程的解释。如果教师一开始就把术语覆盖在现象上，学生便失去了从差异和矛盾中提出问题的机会。

第二，区分数据与证据。数据是读数、时间、位置、图像或视频帧；当它们被用于支持或反驳一个明确主张时，才成为证据。相同的一组压力数据，可以支持“支持力随时间改变”，却未必足以独立证明装置的加速度准确；一条光滑曲线可以便于观察趋势，却可能因为滤波过强而掩盖真实波动。

第三，区分模型与现实。受力图、质点模型、理想斜面和能量守恒关系都是对现实的选择性表达。模型之所以有用，是因为它舍弃了一些因素并保留了决定性关系。学生需要知道模型为何这样简化，而不是把公式当作脱离对象和条件的运算模板。

第四，区分生成与判断。AI可以快速生成解释、表格、代码和评价意见，但生成速度不能自动转化为科学可靠性。近期物理教育研究发现，多模态AI在运动图像、电路图、场图等视觉表征任务上，可能给出语言流畅、策略看似合理而结论错误的回答。AI越擅长表达，课堂越需要保留可复核的证据和独立判断。

由此可见，AI最适合进入的不是“替学生完成认识”的位置，而是帮助师生放大现象、整理数据、比较表征、生成变式、提出备选方案和暴露疑点的位置。决定哪些数据可信、模型是否适用、证据能否支持结论，仍然是教师和学生的物理责任。

## 六级学习过程：学生做什么，AI做什么

### 一、现象：从“听到结论”走向“发现值得解释之处”

现象层的核心不是热闹导入，而是形成可比较、可追问的共同经验。学生要观察、体验、描述差异，并提出一个可以继续调查的问题。教师的任务是选择能暴露认知冲突的情境，并暂缓给出结论。

数字工具可以慢放高速过程、放大微小变化、同步呈现多个视角；AI可以帮助教师生成观察清单、预判学生可能混淆的物理量。但工具不应在学生观察之前先给出标准解释。若学生只会复述“这是超重”“这是机械能守恒”，却说不出看见了什么、哪些量发生了变化，现象层就已经被结论替代。

这一层的证据产物可以很朴素：一张观察记录表、一段现象描述、一组相互冲突的预测、一个尚未解决的问题。它们的价值在于保存学生认识的起点。

### 二、证据：从“我觉得”走向“我测得”

证据层要求学生测量、记录、比较和讨论不确定性。教师必须帮助学生明确：要判断什么，需要测量哪个物理量？仪器怎样校准？采样频率和量程是否合适？重复测量是否一致？误差可能来自哪里？

传感器、网页DIS、手机视频和数据处理程序可以显著扩展证据：高速变化得以连续记录，多组数据可以快速叠加，原本难以捕捉的过程可以转化为图像。但数字化实验的价值不在于“曲线更漂亮”，而在于增加可比较、可复核的证据。

AI可以帮助清洗格式、生成图表、检查异常值和提出可能的误差来源；使用时必须先保留原始数据，说明处理方法、参数和处理前后差异。如果课堂只剩一条光滑曲线，却找不到原始读数、校准记录和异常点，学生得到的不是更强证据，而是一个更难质疑的黑箱。

### 三、模型：从“数据有变化”走向“关系能够解释”

证据不会自动说话。模型层要求学生选择研究对象，识别过程，画图、列式、建立变量关系，并用模型解释数据。教师要设计从证据到表征的桥梁：哪一段数据对应哪个过程？正方向怎样规定？哪些量是外界作用，哪些量属于系统？怎样的简化是合理的？

AI可以同时生成受力图、运动图像、能量图景和文字解释，帮助学生比较不同表征；也可以针对学生的模型提出遗漏项。它不能代替学生确定研究对象和边界条件。判断一个模型是否成立，至少要经受研究对象、受力或相互作用、过程、量纲、极端情况和实验数据的共同检查。

模型层的失败信号很常见：公式在现象之前出现；学生会写 `N-mg=ma`，却说不清正方向和加速度含义；网页中的物体会运动，却没有对应的物理量和约束。此时需要退回证据甚至现象层，而不是继续增加习题数量。

### 四、迁移：从“会做原题”走向“识别条件和边界”

迁移不是换一组数字再计算，而是在改变对象、条件或表征之后，仍能识别模型的适用范围。教师可以改变运动方向、初始状态、系统边界、摩擦条件或证据形式，让学生解释哪些关系保持不变、哪些需要修正。

生成式AI适合快速产生变式、模拟反例、扮演持不同观点的同伴，并给出即时反馈。但AI生成的变式要经过教师审查：条件是否完整，答案是否唯一，图像与文字是否一致，难度改变究竟来自物理思维还是无关计算。

迁移层的证据产物不只是正确答案，还应包括模型选择理由、条件比较和边界说明。若学生只会在熟悉题型中替数，换成图像、实验现象或开放情境便无法判断，就尚未真正拥有模型。

### 五、创造：从“使用现成工具”走向“提出约束并迭代”

创造可以是一台改进的教具、一个物理网页、一段采集程序、一套开放实验或一份新的任务单。它不是在学习结束后附加的“做作品”，而是让学生把模型用于改变现实，并接受材料、测量、代码和使用者的约束。

教师要在创造之前给出验收标准：作品要解决什么问题？必须正确表达哪些物理关系？需要保存哪些数据？怎样测试边界情况？哪些个人信息不得上传？AI可以生成草案、代码和多种方案，但学生必须能解释为何选用、如何修改、哪些建议被否决。

《从积木到智能体》的课程实践把AI素养概括为“会提问、会审查、会指挥”。在本书中，这三个层次进一步落到物理证据上：会提问，是把模糊愿望变成有变量、条件和验收标准的任务；会审查，是用物理模型和实测数据发现AI错误；会指挥，是组织多轮生成、测试、修改和复测，使工具服务于明确的科学目的。

创造层最危险的假象，是作品完成度很高，学生却无法解释代码、参数和模型取舍。判断创造是否发生，不能只看成品，还要看问题定义、版本差异、测试失败和修订理由。

### 六、评价：从“判断对错”走向“复核证据与责任”

评价并不只在六级过程的末端发生。学生每次判断异常值、选择模型、反驳AI建议和修改装置，都在评价。把评价单列出来，是为了突出AI时代一个新的教学任务：不仅评价作品，还要评价人与AI的协作过程。

本书采用“双轨评价”。第一条轨道评价最终作品：物理模型是否正确，实验或网页是否能运行，数据与结论是否一致，表达是否清楚。第二条轨道评价协作过程：学生怎样定义问题，向AI提供了哪些约束，如何识别错误，如何用证据验收，是否保留版本和反思。

AI可以执行初步检查，例如找出量纲疑点、比较页面参数、标记缺失的测试记录；但最终评价不能把另一个AI的分数当作裁决。本书所说的“对抗性审查”，是有意识地反向寻找证据：若结论不成立，会出现什么现象？评分依据能否回到原始作品？AI是否因语言流畅而高估了科学性？学生能否提出反例并推动修订？

评价层的产物可以是证据索引、复核意见、反驳记录和修订稿。它们让“谁作出了什么判断”重新变得可见。

## 六级过程与A/B/C学习进阶的关系

马平主持、黄灿斌和王硕参与的课题团队，在“基于学习进阶的大单元教学在高三物理复习中的应用策略研究”中，围绕高三复习把学习表现概括为A、B、C三个层次：A层侧重复述与模仿，B层强调在熟悉情境中识别模型并应用，C层指向复杂或陌生情境中的建模、迁移、整合与评价。这一结构提醒我们，高三复习不能只是章节知识的再次播放，而应组织学生认知能力向更高水平发展。

本书借鉴的是这一“认知路径设计”思想，并根据实验与AI场景作了再组织。六级过程不是马平课题原表的改名，也不把该课题中的成绩和问卷结果转写为AI教学效果。

大致而言，现象与证据帮助学生从A层走向B层：学生不再只复述结论，而开始用可观察事实约束判断。模型与迁移构成B层的核心，并向C层过渡：学生能够在熟悉与变化的情境中调用模型。创造与评价更接近C层：学习者需要面对不完整条件，综合知识与工具，设计方案，判断证据并为结论负责。

这种对应不是整齐的一一映射。一个学生可以在公式运算上达到B层，却在实验测量上停留于A层；也可能在网页设计上很有创造力，却无法审查其中的物理错误。真正的学习进阶更像多条相互作用的路径，而不是所有学生沿同一把梯子匀速上升。教师需要用多种证据判断学生卡在哪里，并决定是补现象经验、补测量技能、补模型表征，还是增加迁移和反驳任务。

## 三个微型案例：框架怎样改变课堂判断

### 案例一：超重与失重——同一概念可以拥有不同强度的证据

学生站在体重秤上完成下蹲和起立，能够直接感到脚底压力变化。身体体验构成第一层证据，但感觉强弱因人而异，也难以对应完整运动过程。若记录秤面示数或运动视频，再把速度、加速度与支持力变化对齐，证据变得可比较。若进一步使用经过校准的压力传感装置，保留原始曲线、采样设置和误差分析，学生便能检验 `N=m(g+a)` 在不同阶段的适用情况。

三种证据不是“低科技”到“高科技”的简单升级。身体体验负责提出问题，图像负责分段和关联，传感数据负责定量检验。AI可以帮助对齐数据、标记阶段和比较模型预测，但不能把一条根据公式预绘的理想曲线冒充测量结果。第4章将完整展开这三条证据链。

### 案例二：机械能守恒在线实验室——网页应组织证据，而不是播放答案

机械能守恒的动画很容易制作：小球下落，速度增加，柱状图中的势能减少、动能增加。如果所有变化都由程序按照守恒关系预先绘制，学生看见的只是模型演示，尚未获得实验验证。

一个真正服务于证据学习的在线实验室，需要把真实装置、测速数据、初末状态选择、能量计算和误差分析连接起来。网页可以帮助学生切换落体、曲面下滑和气垫导轨等情境，比较系统边界和非保守力的影响；但每一个图像都应说明是实测、计算还是理想模拟。学生的任务也不应止于“观察能量条变化”，而应预测、测量、解释偏差并判断守恒关系的条件。

在这里，AI最有价值的角色不是直接宣布“机械能守恒”，而是帮助教师开发交互资源、帮助学生比较多组数据、生成边界情境，并提示可能遗漏的误差来源。真实装置提供现实约束，网页组织证据，模型给出解释，三者缺一不可。

### 案例三：学生AI物理网页——页面质量不等于学生能力

在学生使用AI制作物理网页时，一个视觉完整、交互流畅的页面很容易获得高分。但这样的评分可能同时犯两种错误：把AI的界面生成能力算给学生，又忽略页面中隐蔽的物理错误。

双轨评价会分别检查成品与过程。成品轨道关注运动关系、参数边界、图像含义、交互反馈和运行稳定性；过程轨道关注学生的初始问题、提示词迭代、AI输出、测试记录、错误诊断、版本选择和反思。若页面把速度方向误当作加速度方向，学生能否用受力与实测数据发现并修正？若AI生成了一段复杂代码，学生能否说明关键变量和验收方法？

由此，AI作品不再只是展示技术熟练度，而成为观察学生能否定义问题、建立模型、审查证据和组织迭代的一扇窗口。

## AI进入物理课堂的四条边界

第一，**真实测量不能被生成内容冒充。** 仿真适合放大、重放、改变参数和探索理想模型；真实实验负责呈现噪声、误差、摩擦、延迟和器材限制。两者都重要，但必须明确标识数据来源。

第二，**物理建模责任不能外包。** AI生成的解释要经过研究对象、过程、受力或相互作用、量纲、边界条件和极端情况复核。教师不能因为语言流畅而降低科学性门槛，学生也不能用“AI这样说”终止论证。

第三，**数据处理必须可追溯。** 原始数据先于平滑数据保存；校准、采样、滤波、删点和拟合方法需要记录。AI建议删除异常点时，要说明判断依据，并比较保留与删除对结论的影响。

第四，**评价权必须回到证据。** AI初评可以扩大检查范围，却不能成为不透明的最终裁决。教师和学生应能查看评分依据、提出反例、复核原始材料并修订结论。涉及未成年人时，还必须遵守隐私保护、适龄使用和最小化上传原则。

这四条边界并非为了限制创新，而是为了让创新仍然属于物理教育。没有真实测量，AI容易把实验变成演示；没有建模责任，解释容易变成套话；没有可追溯数据，曲线容易变成装饰；没有证据复核，评价容易被表达风格支配。

## 如何用这套框架阅读全书

本书后续章节并不平均使用六个层级，而是围绕不同教学矛盾展开。实验篇重点讨论现象如何转化为证据；模型篇讨论可视化、仿真和AI如何帮助学生解释数据；学习进阶篇把单节课组织成跨课时、大单元的认知路径；创造篇让教师和学生从使用工具走向改教具、开发网页与形成课程；评价篇则追问，在人机共同完成的作品中，怎样识别学生的真实贡献并守住科学与伦理边界。

阅读每一章时，可以持续追问五个问题：

1. 学生面对了什么真实现象或真实问题？
2. 结论依赖哪些可以追溯的证据？
3. 哪个物理模型组织并解释了这些证据？
4. AI在哪一步扩展了人的观察、比较或创造，而没有代替人的判断？
5. 学生用什么迁移、作品或复核行为证明自己向前走了一步？

如果一项技术无法回答这些问题，它可能仍然方便，却不一定构成教学创新。如果一个案例能够回答这些问题，即使器材简单、代码朴素，也可能触及AI时代物理教学最重要的变化：学生不再只是消费答案，而是在教师与工具的支持下，逐步学会以证据认识世界、以模型解释世界，并为自己的判断负责。

## 一张课堂决策卡：什么时候该让AI进来

“AI应该在什么时候进入课堂”不能只由工具熟悉度决定。教师可以在备课时填写一张课堂决策卡，把工具出现的时间与学生的认识责任对应起来。

| 学习阶段 | 学生必须先完成的动作 | AI可以承担的任务 | 不能交给AI的判断 |
|---|---|---|---|
| 现象 | 描述观察、提出差异和问题 | 慢放、并列呈现、整理观察词 | 现象是什么、哪些差异值得追问 |
| 证据 | 选择量、记录原始数据、说明单位 | 表格整理、单位提醒、图表初稿 | 数据是否真实、仪器是否测到目标量 |
| 模型 | 确定对象、变量、边界和表征 | 生成候选图、反例和表述 | 采用哪个模型、公式条件是否满足 |
| 迁移 | 比较新旧情境、判断变化 | 生成变式、模拟质询 | 模型是否仍适用、结论能否迁移 |
| 创造 | 提出需求、方案和验收标准 | 原型代码、结构草图、测试建议 | 方案是否解决问题、是否安全可维护 |
| 评价 | 提供证据、反驳、复核和修订 | 初步整理、标记疑点 | 评分、公平裁定和最终结论 |

这张卡不要求每节课都使用AI，也不规定固定顺序。它的作用是把“使用AI”从目标降为一个受约束的教学决策：当AI能够扩大观察、比较或表达，而不会替学生完成关键判断时，才值得引入。

## 框架的三个误读及其修正

第一种误读是把六级过程理解为六个固定环节。这样做会让教师为了“凑齐六级”而强行给每个案例安排创造和评价。修正办法是按章节功能选择核心层级，并明确哪些层级作为前置证据、哪些层级作为后续迁移。

第二种误读是把“证据”理解成数据越多越好。数据只有在对应明确主张、来源清楚、处理可追溯时才成为证据。十张没有单位的截图不一定比一张保留原始数据和条件的表格更有价值。

第三种误读是把“创造”理解成使用了最新工具。创造的判断依据应是学生或教师是否提出了约束、改变了方案、测试了边界并对选择负责。一个用纸板做出的可维修教具，若能够解决真实测量问题，可能比一个功能复杂但不可解释的AI网页更接近创造。

## 一个最小闭环：从问题到复核

本书各章可以用一个最小闭环互相连接：

1. **提出主张**：我要解释什么现象或解决什么问题？
2. **选择证据**：我需要测量、观察或保存什么？
3. **建立模型**：哪个对象、变量和条件能够组织这些证据？
4. **进行迁移**：改变一个情境或边界后，模型还成立吗？
5. **留下创造**：我改造了什么工具、任务或表达方式？
6. **接受复核**：别人能否根据原始材料复算、反驳和提出修订？

闭环中的“接受复核”并不是最后才发生，它可以在每一步提前出现。学生在选择传感器时就在评价证据，教师在决定是否公开网页时就在评价工程和伦理。六级框架的价值，不在于规定一条流水线，而在于提醒我们：任何结论都应该能够回到问题、证据和模型。

## 给教师的章节阅读量规

读完本书后，教师可以用下面的量规检查一个新案例是否值得纳入课程：

| 检查项 | 是/否 | 若为“否”的处理 |
|---|---|---|
| 现象或问题真实且可观察 |  | 回到情境，不先写结论 |
| 原始证据有来源和单位 |  | 补测量或标记待补 |
| 模型写明对象、变量和条件 |  | 先完成模型卡 |
| 至少有一次迁移或反例 |  | 增加新情境或边界任务 |
| AI承担的工作可被说明 |  | 分离生成、处理和判断 |
| 过程和成品能够分开评价 |  | 建立证据包和版本记录 |
| 安全、隐私、授权和维护可交代 |  | 暂不公开或改用替代方案 |

量规不是新的形式主义，而是帮助教师在工具热潮中保留物理学科的最低判断。若一个案例大部分项目都只能填“待核实”，它仍可以作为研究草稿，但不应被包装成已经验证的教学模式。

## 2.10 证据链的最小可行版本

在课时、器材和学生基础都有限时，六级框架可以压缩为一个最小可行版本：一个真实现象、一份原始记录、一张模型卡、一个边界问题和一次人工复核。这个版本足以让学生经历从“我看到了”到“我为什么这样解释”的基本闭环。

例如，教师不必先开发完整超重传感器，可以用体重秤和分段表记录启动与制动；不必先建成机械能在线实验室，可以用纸带数据和手算比较能量变化；不必先让每个学生制作网页，可以给出一个存在单位错误的页面截图，要求学生找出模型问题。

最小可行版本的作用是检验问题是否值得扩大。如果学生连现象、直接量和模型条件都不能分开，增加AI和交互只会把问题藏得更深。只有当最小任务能够产生可讨论证据，工具升级才有明确方向。

## 2.11 框架不是新的章节清单

“证据—模型—进阶”框架的作用，是帮助教师在不同章节之间建立连接，而不是要求每节课都按同样的标题写。一个章节可以重点处理测量证据，另一个章节重点处理模型迁移；只要两者能够在全书主线中互相回收，框架就发挥了组织作用。

读者使用框架时，应先问本地问题是什么，再选择最小节点。若学生已经有可靠数据，课堂可以从模型冲突开始；若学生连测量量都不清楚，就需要退回证据。框架允许回退，正因为真实学习不是一条只能向前的流水线。

## 本章小结

本章把“现象—证据—模型—迁移—创造—评价”规定为一条可以回退、可以复核的学习过程，而不是固定的六步课堂流程。AI的作用被放在可视化、整理、比较、反馈和资源开发等支架位置；现象的真实性、证据的取得、模型的适用条件和结论的责任仍由学生与教师共同承担。

后续章节将分别把这条主线落到测量、实验、网页资源、项目课程和作品评价中。阅读者可以用两个问题检验任何案例：它究竟改变了哪一段认识过程？它留下了什么可以复核的证据？如果两问都回答不了，技术的新颖性就不能替代教学价值。
