# 附录AS 结稿后记

这份书稿从总纲、样章、论文初稿、课件、装置、网页、学生作品和作者补证问题中逐步长出。它没有把每份材料都直接拼在一起，而是尝试用“证据—模型—进阶”重新组织：实验为什么要保存原始数据，网页为什么要保留边界，项目为什么需要交接，评价为什么要区分成品和过程，AI为什么只能提议而不能替人拍板。

作者补证可以在后续继续完成，章节也可以根据真实数据和读者反馈修订。重要的是，当前版本已经把待核事实、待授权材料、待确认贡献和待数据支持的位置明确写出。读者可以据此知道哪里可以直接使用方法，哪里需要本地化，哪里暂时不能下结论。

一本实践书的完成，不是把所有问题写得像已经解决，而是让问题、证据、模型、边界和下一步都能够被别人看见。愿这份书稿成为一份可以继续实验、继续失败、继续改写的工作底稿。

书稿的下一版应当由新的证据推动，而不是由字数或工具数量推动。

因此，当前交付的重点是让作者、编辑和读者都能继续工作，而不是让所有未决问题在一轮文字生成中消失。

当作者补入新的课堂数据、装置照片、学生作品或正式文献时，应同步更新章节正文、证据台账、贡献归属、授权状态和版本记录。新增材料如果改变了原来的判断，应诚实改写主张，而不是只把新材料作为装饰性附录。这样，书稿的扩充才是知识和责任的扩充。
