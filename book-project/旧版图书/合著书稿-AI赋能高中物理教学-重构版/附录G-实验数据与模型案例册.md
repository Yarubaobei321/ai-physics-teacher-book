# 附录G 实验数据与模型案例册

本案例册不提供可冒充课堂实测的“标准数据”，而提供数据阅读和模型审查的结构。数字位置可以由教师替换为真实记录；若使用下列示例，必须标明“示例数据”，不能用它证明某项教学效果。

## G.1 单摆数据阅读

### 任务背景

给出若干摆长、全振动次数和总时间。学生先计算周期，再比较(T-l)、(T-l^2)和(T-\sqrt l)三种表示。数据表中有一行计时次数为29.5，备注为空。

### 学生任务

1. 标出直接读数和处理量；
2. 说明29.5次记录为何不能直接与30次记录并列；
3. 选择一个复测方案；
4. 判断哪张图最适合当前猜想，但不能只写“最直”；
5. 写出小角度、摆长定义和阻力忽略等条件；
6. 说明如果摆幅增大，模型可能怎样改变。

### 教师观察点

学生能否区分计时次数、总时间和周期；能否把异常记录回溯到操作；能否在图像、公式和条件之间建立联系。不要把拟合优度直接当作模型选择的唯一依据。

## G.2 纸带与小车数据阅读

### 任务背景

一组纸带上相邻点间距逐渐增大，但中间有一段点距突然变小，纸带边缘有斜向摩擦痕迹。学生已经得到一张近似直线的(v-t)图。

### 学生任务

- 画出原始点距与速度表的对应；
- 指出异常段可能影响哪几个计算点；
- 比较短区间和对称区间估计瞬时速度的误差；
- 判断是否可以直接用整条纸带拟合加速度；
- 设计一次只修正纸带方向的复测。

### 证据要求

学生必须保留原始纸带照片、计数点选择、时间间隔和一项失败记录。若只交一条拟合线，教师可以评价图表形式，不能评价数据可靠性。

## G.3 电磁感应峰值数据阅读

### 任务背景

三组线圈匝数不同，传感器输出一段有噪声的周期曲线。每组数据的转速、线圈位置和峰值提取窗口不完全一致。

### 任务

1. 先判断哪些字段缺失会阻碍比较；
2. 统一峰值或时间窗规则，重新计算代表值；
3. 比较重复测量的离散程度，而非只比较平均值；
4. 说明匝数与感应电压关系为何只能在当前范围内表述；
5. 提出一个减少位置变化的装置改进。

### 讨论重点

学生常把磁铁数量、磁通量变化量和变化率混为一谈。教师要要求他们写出控制量和代理量，不能用“磁场变大”代替可测定义。

## G.4 莱顿瓶与电容变量

### 任务背景

外箔完整贴合、抬起一半、抬起更多三种状态下，静电计示数不同，但每次充电等待时间略有差异。

### 任务

- 画出内外铝箔、瓶壁和导线；
- 说明当前实验试图保持哪个量近似不变；
- 区分电容、电荷和电压；
- 列出漏电、等待时间和接地的竞争性解释；
- 设计一个更稳定的计时与重复方案。

### 边界

若电容器连接理想电源，电压和电荷的变化关系会不同。学生不能把“面积变小，电压一定变大”写成没有接线条件的普遍结论。

## G.5 光电门测速

### 任务背景

同一小球通过单头光电门，学生用球直径除以遮光时间；另一组使用双头光电门的两门间隔。两组算出的速度不同。

### 任务

1. 画出单头遮光宽度和小球实际弦长；
2. 判断直径代弦长的偏差方向；
3. 说明双头光电门的平均速度对应哪个时间和位置；
4. 设计一个不更换整套设备的对照测试；
5. 把两种方法写成同一张“平均量近似瞬时量”的比较表。

## G.6 超重与失重曲线

### 任务背景

一条压力曲线与电梯速度曲线时间轴存在偏移。曲线有启动峰值和制动峰值，但原始ADC值、校准参数和采样率没有同时提供。

### 任务

- 先判断纵轴究竟代表什么；
- 估计时间对齐缺口会如何影响超重/失重分段；
- 说明(N=m(g+a))需要的正方向和系统；
- 列出恢复证据的最小材料；
- 不在缺失校准的情况下给出精确最大支持力。

## G.7 机械能三方案

### 任务背景

纸带落体、曲面下滑和气垫导轨给出不同形式的能量差异。网页提供了自动计算，但原始数据可导出。

### 任务

1. 为每种方案画系统边界；
2. 标出直接测量量、处理量和模型结论；
3. 说明曲面下滑中平动动能不足可能来自什么；
4. 选择一个变量做单项改进；
5. 用“主张—证据—推理”写结论，不只写相对误差。

## G.8 超声波测距与采样

### 任务背景

ESP32记录回波时间，网页显示距离。学生改变采样间隔后，速度图像出现不同程度的抖动。

### 任务

- 写出距离由回波时间换算的关系；
- 说明温度、目标表面和角度的影响；
- 比较采样间隔与速度差分的误差；
- 区分硬件计时、无线传输和网页显示时间；
- 设计一个固定距离和一个运动目标测试。

## G.9 学生网页模型测试

### 任务背景

页面显示动量、能量和轨迹。质量、速度和摩擦滑块可以改变，但公式区、动画区和结果表可能使用不同的状态变量。

### 任务

运行零值、缩放和边界测试，记录：输入、预期、实际、截图、代码位置和修订。若AI生成的建议被拒绝，要求学生写出拒绝理由。页面完成度高不能替代模型测试。

## G.10 数据阅读的共同语言

所有案例都可以用五句话复盘：

1. 我直接测了什么？
2. 我把它处理成了什么？
3. 我想支持哪一个主张？
4. 哪个条件或竞争性解释还没有排除？
5. 下一次只改哪个环节？

教师可以把这五句话印在实验记录、网页任务和项目答辩单上。它们不替代具体物理知识，却能帮助不同章节保持同一条证据主线。
