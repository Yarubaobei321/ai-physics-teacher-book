# 术语与写作规范

## 一、核心术语

| 术语 | 本书定义 | 禁止混用 |
|---|---|---|
| 证据—模型—进阶 | 证据产生、模型建构与认知挑战递进的全书主线 | 不等同于“技术使用流程” |
| 六级学习过程 | 现象、证据、模型、迁移、创造、评价 | 不写成所有课都必须执行的固定六步 |
| 网页DIS | 浏览器连接传感器、显示或导出实验数据的自研网页系统 | 不泛指所有在线动画 |
| ESP32Blockly | 浏览器中的ESP32图形化编程与设备管理平台 | 不写成通用Blockly产品名 |
| 双轨评价 | 分别评价学生的AI协作过程与最终作品质量 | 不把AI生成质量直接算作学生能力 |
| 对抗性审查 | 对AI初评、材料标注和评分证据进行反向核验 | 不等同于让第二个AI简单重评 |
| 学习进阶 | 学生围绕核心主题从较低水平理解走向建模、迁移和评价的路径 | 不等同于题目由易到难 |
| 从用到造 | 教师由选用工具走向改实验、开发资源与形成课程 | 不把“会写代码”作为唯一标准 |

## 二、全书统一立场

1. AI可以提出方案、解释代码、整理数据和执行初评，但物理科学性、教学判断和最终责任属于教师与学生。
2. 统一使用“AI提议，人来验证并拍板”。不写“AI自动保证正确”。
3. 真实实验与数字仿真互补。仿真可以放大、重放和改变参数，不能替代真实测量中的误差、噪声和器材限制。
4. 评价AI协作不能只看成品。必须保留问题定义、迭代诊断、版本选择、验收和反驳证据。
5. 一项工具只有改变证据产生、模型建构或学习进阶时，才进入正文核心论证。

## 三、统一章法

每章以六段式组织：

1. 真实问题：课堂困境、实验矛盾或评价难题。
2. 进阶目标：学生起点、终点和中间台阶。
3. 证据设计：需要采集的现象、数据、作品或过程记录。
4. 教学/开发过程：关键决策、失败、修订和操作步骤。
5. 模型与解释：物理规律、认知变化和适用边界。
6. 迁移工具包：任务单、材料表、量规、检查表或复用模板。

借鉴《从积木到智能体》的成熟写法，每章必须体现“问题→知识/模型→验证→迭代”。涉及实验与装置时，增加“常见坑/先查什么”；涉及开放任务时，采用分层任务，但不机械复制L1—L5编号。

## 四、证据等级

| 等级 | 定义 | 正文边界 |
|---|---|---|
| A 已核验 | 原始教案、课件、装置文稿、代码、数据、网页、已发表论文、版本记录 | 可写为事实，注明作者和时间 |
| B 待复核 | AI旧稿中的课堂对话、学生反应、效果数字或二手转述 | 作者确认前不进入定稿事实句 |
| C 关联研究参照 | 马平主持、黄灿斌和王硕参与的课题，以及同事论文、理论文献、竞品案例 | 按原课题或原合作者规范署名；区分原始结论与本书再组织 |

每章末附“证据来源表”：材料、作者/权利人、日期、等级、授权状态、正文落点。

## 五、隐私与授权

- 特优生网页和对话记录统一使用S01—S31，不出现学生姓名、班级、账号、文件名和可反查身份的信息。
- 马平课题须注明“马平主持，黄灿斌、王硕为成员”。使用成绩、问卷比例或研究结论前，核对原始统计口径，并按课题团队和原报告的授权边界使用；本书再组织的框架不得冒充课题原结论。
- 王硕已发表论文涉及其他合作者时优先规范引用；重用原图、表或大段内容前核对再发表许可。
- 教具、课件和平台由对应作者确认材料贡献；主笔不等于权利人。
- 网络截图、软件界面和AI平台版本在出版前复核时效与授权。

## 六、物理科学性

1. 概念边界先审：重力与视重、质量与重量、速度与加速度、热量与内能等不得混用。
2. 解题与模型遵循“先理后数”：先说明研究对象、过程和受力，再列式。
3. 公式中的正方向、符号和条件必须在首次出现时说明。
4. 装置章节必须成对提供原理图和实物图；宣称改进效果时提供改进前后数据。
5. 传感器数据写明校准、采样、滤波、量程、误差和不适用条件。
6. 不将“现象更明显”“页面更好看”直接写成“学生理解显著提升”。

## 七、可操作性

- 器材写型号或关键参数；替代件说明等效条件。
- 操作步骤按首次使用者能够复现的颗粒度书写。
- 每个实验给出最低成本版本、标准版本和可选升级，但不承诺所有学校都有同样设备。
- 每个开放项目写明确“不做什么”，防止任务失控。
- 排障顺序从低成本证据开始：供电、接线、共地、端口、单件验收、日志，再检查代码和系统结构。

## 八、语言与格式

- 面向一线教师，使用有温度的书面语；真实课堂叙事必须可核验。
- 少用“赋能、抓手、闭环、深度融合、多维度”等大词。必须使用时紧接具体机制和证据。
- 不写目录式导读，不用“首先、其次、最后”机械排列整章。
- 术语首次出现给中文、英文和本书含义，后文保持同一写法。
- 连续长段应由图、表、公式、任务单或小标题打断；图表必须承担论证任务。
- 本地图片和材料链接使用原样绝对路径，不做URL编码。

## 九、旧稿使用规则

旧Fable5/Grok稿件只能用于发现线索和保留已形成的表达。凡涉及课堂、装置、数据、学生和项目状态的陈述，必须回到原始材料复核。旧稿中的【需作者补充】不得直接搬入新正文；事实缺口进入资料卡和审稿记录。
