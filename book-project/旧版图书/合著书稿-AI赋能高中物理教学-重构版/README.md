## 这本书要回答什么

AI进入物理课堂以后，最容易发生的变化是答案来得更快；最值得追求的变化，却是学生的思维过程变得更可见、更可检验。本书以“证据—模型—进阶”为学习主线，讨论真实实验怎样产生证据、物理模型怎样组织证据、AI怎样在可视化、数据处理、资源开发和评价中提供支架，以及学生怎样从观察、解释走向迁移、创造与反思。

教师实践采用“从用到造”副线：选择工具、改进实验、开发资源、组织课程、评价作品。所有工具与项目都必须回到物理学习问题，不能写成成果陈列。
