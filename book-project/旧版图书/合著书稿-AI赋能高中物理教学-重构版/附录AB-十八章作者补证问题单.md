# 附录AB 十八章作者补证问题单

作者补证后置时，按章节回答以下最小问题即可启动核验。若暂时无法回答，写“未知/待查”，不要用推测代替。

## AB.1 第1章

1. 四位作者为什么共同写这本书，各自带来哪条实践线？
2. 总纲中的书名、读者和六篇结构是否仍然准确？
3. 哪些作者经历可以使用第一人称，哪些必须客观叙述？
4. 哪些工具、项目和图片仍未确认授权？

## AB.2 第2章

1. 六级过程是作者框架、课题框架还是文献框架？
2. A/B/C与六级之间哪些是本书再组织？
3. 是否有正式文献支持学习进阶和AI边界？
4. 哪些段落只能作为设计假设？

## AB.3 第3章

1. A/B/C原始材料具体来自哪份课题和哪一版表？
2. 是否有学生任务、错误解或复盘材料可支撑进阶例子？
3. 哪些大单元路径已经实施，哪些只是设计？
4. 是否有真实数据能够支持效果性表述？

## AB.4 第4章

1. 体重秤、纸带、漏水瓶和压力装置实际使用过吗？
2. 压力曲线的原始数据、采样率、校准和运动时间轴在哪里？
3. 哪些学生预测、对话和任务是原始记录？
4. 高风险演示有哪些审批、替代和取消记录？

## AB.5 第5章

1. 单摆视频、纸带和小车课例的日期、班级和作者是谁？
2. 异常点和复测是否有原始表格？
3. 使用了哪些计时、光电门和视频设备？
4. 公开数据能否提供原始文件和授权？

## AB.6 第6章

1. 光盘调速版、齿轮版和掌控板版各自是否实际使用？
2. 三组电磁感应数据的匝数、磁铁、转速和峰值规则是什么？
3. 莱顿瓶实验的充电、漏电和安全条件如何记录？
4. 哪些关系是观察、近似还是理论推导？

## AB.7 第7章

1. 活版电路模块数量、内部走线和专利状态是什么？
2. 单头、双头光电门的型号和遮光宽度如何确认？
3. 网页DIS的设备、协议、浏览器和离线版本是否仍可运行？
4. 结构图、实物图和代码的权利人是谁？

## AB.8 第8章

2. 哪些数据是真实课堂，哪些来自示例或仿真？
3. 曲面方案的转动动能、光电门位置和高度如何说明？
4. 公开课中的学生作品和全班汇总是否可用？

## AB.9 第9章

## AB.19 统一提交

作者提交补证材料时，附上原文件、版本、贡献者、使用范围、隐私状态和希望保留的叙事。编辑只把能够确认的内容写成事实；其余内容保留设计建议或待补标记。
