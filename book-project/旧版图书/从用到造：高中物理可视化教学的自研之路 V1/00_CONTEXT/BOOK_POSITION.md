# 本书定位与边界

## 核心命题

高中物理中的许多困难来自过程不可见、模型难建立、数据难获取和教师难以自主开发资源。AI、网页技术、数字传感器与自制教具降低了创造门槛，使一线教师可以围绕真实课堂问题设计、验证和改进自己的教学工具。

全书以“从用到造”为主线，讨论三件事：

1. 可视化如何帮助学生建立模型、展开推理和使用证据；
2. 一线教师怎样从使用现成工具走向改造和创造工具；
3. 自研工具如何回到课堂、评价与教师共同体，形成可持续实践。

## 目标读者

- 希望改进概念课、规律课、实验课和习题课的高中物理教师；
- 想尝试自制教具、网页资源或智能硬件，但缺少技术背景的教师；
- 负责物理教研、科技教育、校本课程与教师培训的管理者和教研员。

默认读者懂高中物理和日常教学，不要求具备编程、网页开发或电子工程背景。

## 本书提供什么

- 真实装置、真实项目和已有课堂材料；
- 从教学问题到工具设计的决策过程；
- 图、表、照片、公式、数据和正文共同形成的解释；
- 可迁移的章节模板、教具设计思路、资源开发方法和审查边界；
- 对失败、限制、版本差异和待验证设计的如实说明。

## 本书不承担什么

- 不写成 AI 工具百科、软件操作手册或编程教材；
- 不把四位作者拼成一条虚构的个人成长史；
- 不把课题计划写成已经发生的教学成效；
- 不用未经核验的学生反馈、课堂数据、专利状态或奖项增强叙事；
- 不复制参考书的案例、段落和图片。

## 纸质定稿前必须保留的未决问题

### 作者人数与分工冲突

蓝图首页写“四位教师分章合著”，署名顺序为丁龙、黄灿斌、王硕、严力耕；十二章的“负责作者”和文末分工汇总只出现黄灿斌、王硕、严力耕，未给丁龙分配章节。这不是排版小问题，会影响署名、材料归属和采访安排。

处理规则：

- 资料索引继续为四位作者保留入口；
- 章节地图照录当前蓝图分工，不替作者重新分配；
- 正式统稿前建立一项“待作者裁决”；
- 在裁决前，不把丁龙排除出作者范围，也不虚构其章节贡献。

### 第11章效果评价证据

第11章已将承诺调整为“证据能把结论带到哪里”。正文使用25份物理AI作品的脱敏汇总和P06个案说明过程—成品双轨观察，同时明确缺少基线、比较、迁移和延时测查，不能据此声称科学思维提升。若课题后续形成正式结题数据，应另建证据版本，不直接覆盖当前口径。

### 王硕、严力耕材料成熟度

第3—12章均已形成事实档案、材料矩阵或等价证据记录。设计、页面功能、课堂实施和学习效果分层表述。王硕与严力耕提供的课堂时间、学生产物、图片授权和作者口径仍需按全书作者确认清单集中裁决。

### 出版规模口径

十二章正文目前为113,592字符，位于蓝图估算的106,000—131,000字范围内。早期策划曾提出“约30万出版字”，两者不是同一生产口径。纸质定稿前需要由四位作者与出版社选择：采用当前蓝图规模，或另行启动扩充版策划；系统不以重复案例、空泛理论和技术说明凑字数。

## 出版判断优先级

当内容价值、叙事效果和证据边界发生冲突时，按以下顺序处理：

1. 物理与事实准确；
2. 作者归属和隐私合规；
3. 读者能否理解；
4. 全书结构一致；
5. 文句精美与视觉效果。
