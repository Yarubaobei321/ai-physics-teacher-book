# 《从用到造》Agent 入口

这里是本书最小必要上下文。任何 Agent 进入项目后，先按任务类型选择读取路径，不要一次性加载全部文件。

## 一句话定位

四位一线高中物理教师分享如何利用可视化、数字技术、自制教具和 AI，解决真实教学问题，并逐步从工具使用者成为教学资源创造者。

## 五个角色

```text
总编策划
   ↓ 章节任务书
素材挖掘
   ↓ 事实档案与素材考古表
视觉策划
   ↓ 内容结构与视觉策划单
章节写作
   ↓ 图文正文
事实审查
   ↓ 审稿结论与作者问题
```

这些角色是顺序责任，不要求同时启动多个 Agent。一个 Agent 可以承担多个角色，但不得绕过前一阶段的交付物。

## 状态词

系统只使用以下确定状态：

- `已核验`：原件或事实档案可以直接支撑表述。
- `半核验`：有材料，但出版信息、版本、授权或口径未完全确认。
- `待作者确认`：必须由对应作者回答。
- `仅作结构参考`：只学习组织方式。
- `暂不纳入`：当前章节不读取。

“可能有”“应该是”“看起来像”不能自动升级为正文事实。
