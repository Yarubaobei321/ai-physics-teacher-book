# 全书视觉策略

## 视觉材料的任务

本书中的图不是装饰。每幅图至少承担以下一种任务：

| 读者困难 | 优先媒介 | 典型内容 |
| --- | --- | --- |
| 不知道对象长什么样 | 真实照片、界面截图 | 装置整机、模块、课堂布置、网页界面 |
| 不知道被分析的题目或系统长什么样 | 必要题干、原题装置图或准确重绘 | 高考题装置、对象位置、已知条件与关键符号 |
| 看不懂内部关系 | 结构图、剖解图、架构图 | 模块连接、三端架构、力学对象关系 |
| 跟不上过程变化 | 分镜、流程图、时间线、动画二维码 | 实验步骤、迭代过程、参数变化 |
| 无法比较条件 | 对照图、矩阵、表格 | 实物与仿真、不同方案、版本差异 |
| 不理解证据怎样支持结论 | 数据图、原始记录、误差图 | 曲线、散点、测量位置、误差来源 |
| 不知道教师或学生做什么 | 任务单、操作路径、课堂组织图 | 分组、角色、提交与复核流程 |
| 抽象机制难想象 | 自绘机制图、公式链 | 电场模拟条件、传感器数据链、模型转换 |

## 选图顺序

1. 先确定本节要解决的读者问题。
2. 查 `01_SOURCE/视觉证据索引.md`。
3. 回到原始文件确认来源、人物、时间、对象和分辨率。
4. 判断真实图片能否直接解释；不足时再做裁切、标注、拼图或机制重绘。
5. 为纸质书和二维码扩展资源分别分配内容。
6. 在视觉策划单中登记图号、用途、来源、状态和图注要点。

仿真案例的第一幅图优先让读者看清具体物理对象、初始状态和待解决问题。读者尚不知道为什么需要仿真时，不先放软件层次、页面结构、测试框架或抽象方法卡。

## 四类视觉来源

### A. 真实证据

装置照片、课堂照片、学生作品、网页截图、原始数据和实验记录。它们可以证明对象或事件存在，但证明范围必须与拍摄内容一致。

### B. 证据加工

对真实照片做裁切、编号、箭头、局部放大和并列拼图。不得改变装置状态、数据或人物行为。加工后仍需保留原始路径。

### C. 解释性重绘

结构图、机制图、流程图、系统架构和数据链。重绘必须基于已经核验的事实，并在视觉策划单登记依据。读者必须区分实拍与重绘或公开署名时，另用统一的“图源：……”句说明“结构示意”或“根据××材料绘制”。

### D. 概念性插图

AI生成或艺术化插图。只用于封面、篇章页或明确的概念表达，不进入装置证据、课堂实录、学生作品和实验结果。

## 一个案例的常见图序

不规定每章固定图数。材料充分时，一个完整装置或数字项目通常按下列阅读顺序选择：

```text
真实外观
→ 结构拆解
→ 工作机制
→ 操作或课堂过程
→ 数据与结果
→ 误差、限制或迭代
```

缺少某一环节时，在视觉策划单标为“缺证”，不生成一张看似真实的替代图。

高考题作为分析案例时，常见图序是：

```text
必要题干与装置图
→ 对象、条件和设问定位
→ 过程或空间关系重绘
→ 模型、变量与推理图
→ 结果检验
```

分析图不能替代装置图。读者尚不知道题目系统长什么样时，不先展示只有作者看得懂的阶段图、变量链或结论图。

## 纸质书与二维码资源

优先进入纸质书：

- 决定读者能否理解正文的实物、结构、关键数据和对照图；
- 黑白打印后仍能区分的图表；
- 能在单页或跨页内读完的信息。

优先进入二维码扩展：

- 动画、视频、完整网页实验；
- 大量连续过程图、源文件、完整数据集；
- 会频繁更新的网站界面和软件操作；
- 受篇幅限制的学生作品画廊。

二维码只能扩展正文，不能承载理解核心论证所必需的唯一证据。

第3章的17幅图已经由作者确认全部进入纸质正文。它们共同承担装置外观、结构、机制、操作、仿真、观察视角与误差边界的解释任务，不分流到二维码扩展页。图3-6、图3-7和图3-8分辨率相对较低，排版时宜采用小幅或组合版式，不宜放大整页。

十二章现有164幅正文图均按纸质正文配置，已经复制或生成到`../02_MANUSCRIPT/assets/ch01/`—`ch12/`。二维码只承载可选的动画、网页交互、视频、源码和完整数据，不承担理解正文所必需的唯一图件。最终印前仍需由出版社按开本、成品尺寸和印刷方式复核低分辨率原图。

## 出版与可访问性检查

- 重要信息不能只靠红绿颜色区分。
- 图中文字在常见书页缩放下仍可阅读。
- 截图去除浏览器无关界面、个人账号、学生姓名和通知信息。
- 人物照片必须检查肖像与使用授权。
- 第三方软件、论文和参考书图片需登记版权状态；无法确认时重新绘制或不使用。
- 图号、图题、来源和正文引用保持一一对应。
- 导出前检查相对路径、文件缺失和图片分辨率。
- 路线图、流程图和架构图中的全部节点必须完整落在画布内；按纸质书常用阅读尺寸检查文字、连线、先后关系、异常空白和裁切。
- 图题声称呈现若干部分或步骤时，图内必须逐项清楚呈现。例如“四篇路线”要同时看见四篇及其关系，不能只用一句总主线代替。
- 概念框架图必须包含具体物理对象、变量关系、学生动作或可检查产物中的至少一项。仅把三个以上抽象词放入卡片并用箭头相连，不能证明图片比正文更有效。
- 圆点大小、颜色、形状、线宽、透明度等只要表达信息差异，就必须在图内或图注中说明含义、等级和判断依据。
- 没有数据或可核验分级依据时，不用面积、颜色深浅或线宽制造强弱、多少和重要性的定量印象；改用等大符号表达“存在联系”，或明确标为作者的定性示意。

## 明确禁止

- 用AI生成的教具图片冒充实物；
- 依据文字猜测装置内部结构并绘成确定图；
- 把竞赛报名表当作获奖证明；
- 把课题方案中的预期图表当作实验结果；
- 为了“图文丰富”重复放置同一信息；
- 未脱敏展示学生姓名、对话、学号或人脸。
