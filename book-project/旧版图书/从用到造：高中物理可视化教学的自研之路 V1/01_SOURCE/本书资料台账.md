# 《从用到造》资料总台账

更新时间：2026-08-12

本台账管理“哪些材料值得进入写作流程”。15,600条机械清单负责回答文件在哪里；本台账负责回答材料有什么出版价值、能服务哪章、使用时要守住什么边界。具体句子和图件的证据关系放入各章深挖矩阵，不在总台账重复堆放。

## 一、资料工作采用两层前置

### 现在完成的全书层

- 维护全书定位、十二章资料路由、高价值项目块和视觉入口；
- 只对跨章节、高复用材料建立摘要；
- 标出作者归属、课堂状态、版权、版本冲突和待采访问题；
- 不批量深读全部文件，不为尚未确定的章节提前制造大量摘要。

### 每章写作前完成的章节层

- 回到少量原件逐项核验；
- 建立“主张—原件位置—证据状态—允许表述—禁止越界”；
- 建立逐图来源、解释任务、版权和分辨率记录；
- 形成作者确认问题；
- G1—G3完成前不写G4正文。

5.6 Terra可承担批量入口定位、材料归并、图件候选、版本差异和初步证据映射；主Agent负责物理正确性、证据强度、作者口吻和最终取舍，作者负责课堂事实、个人经历、授权和版本裁决。

## 二、登记单位与状态

一条可进入写作的资料单元至少记录：

| 字段 | 要求 |
| --- | --- |
| 资源ID与名称 | 能稳定引用，不只写模糊文件夹名 |
| 原始绝对路径 | 指向原件或已经核验的事实档案 |
| 作者与所有权 | 四位作者、学生、第三方资料不得混同 |
| 可服务章节 | 说明主落点和可能复用章 |
| 可支撑主张 | 写到具体对象、动作、数据或结构 |
| 不能支撑 | 课堂效果、奖项、专利、推广等常见越界 |
| 视觉资产 | 图片、截图、视频、数据、可重绘关系 |
| 版本与冲突 | 不同稿件、不同装置或不同软件版本分开登记 |
| 引用与授权 | 署名、隐私、版权及出版前动作 |
| 下一步 | 深读、采访、补拍、补数据、停用或等待确认 |

## 三、使用等级

| 等级 | 含义 | 使用方式 |
| --- | --- | --- |
| A 核心证据 | 直接支撑本书中的装置、项目、课堂或作者事实 | 写正文前回到原件，并建立事实档案或章节矩阵 |
| B 结构参考 | 支撑全书定位、章节结构、图文密度或解释方式 | 只读必要章节，不复制案例、段落和图片 |
| C 待确认 | 有价值但存在事实、版本、作者、授权或运行状态缺口 | 进入问题单，不写成确定结论 |
| D 暂不纳入 | 与当前章节无直接关系或会稀释主线 | 不读取；出现明确写作问题后再复评 |

状态词统一为：`已核验`、`半核验`、`待作者确认`、`仅作结构参考`、`暂不纳入`。

## 八、维护规则

1. 每增加一个正式案例，先建立章节深挖矩阵和事实档案，再写正文。
2. 图片先确认原始出处、作者、表现对象、分辨率和授权；真实外观优先真实照片。
3. 同一主张出现不同版本时进入C类。正文直接写稳定事实和版本边界，不向读者汇报资料拼接过程。
4. 课题目标、竞赛文稿中的预期效果、教学设计和评价表不能自动升级为课堂实证。
5. 只有实际跨章节复用的材料进入本总台账；单章细节留在章节矩阵。
6. 章节完成后更新“十二章资料进度”，不扩大无关必读范围。
