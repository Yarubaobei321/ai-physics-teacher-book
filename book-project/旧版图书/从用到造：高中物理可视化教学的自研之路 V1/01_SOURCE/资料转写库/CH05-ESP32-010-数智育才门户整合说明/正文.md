# 整合进「数智育才」门户

目标：把学生端 PWA 接入 [shuzhiyucai.cn](https://shuzhiyucai.cn)（Astro + Tailwind，托管在阿里云 + Cloudflare），
作为「在线编程」板块的一个工具，同时教师 Mac 上的服务器通过 Cloudflare Tunnel 暴露给学生端。

## 二、服务器经 Cloudflare Tunnel 暴露
教师 Mac 上：
```bash
brew install cloudflared
cloudflared tunnel login
cloudflared tunnel create esp32class
# 在 Cloudflare DNS 把 class.shuzhiyucai.cn 指向该隧道，配置 ingress 到 http://localhost:8080
cloudflared tunnel run esp32class
```
学生端 PWA 连 `wss://class.shuzhiyucai.cn/ws`；ESP32 仍连局域网 `ws://<Mac内网IP>:8080/ws`。
服务器无需改动（HTTP 后端，Cloudflare 负责 TLS）。

## 三、学生端接入门户（两种方式，二选一）

### 方式 1（最快）：静态文件原样发布到 `/esp32`
把 `server/public/` 整个目录放到门户的 `public/esp32/`：
```bash
cp -r server/public/* "/Users/yaril/个人文档/物理实验项目课题/数智育才网站/public/esp32/"
```
- 访问 `https://shuzhiyucai.cn/esp32/` 即学生端，真证书 → PWA 安装/离线全可用。
- 在 `app.js` 顶部把 `DEFAULT_SERVER` 设为 `wss://class.shuzhiyucai.cn/ws`（或让学生在「设置」里填）。
- 二维码生成时 PWA 地址用 `https://shuzhiyucai.cn/esp32`：
  `node tools/gen-roster.js 20 https://shuzhiyucai.cn/esp32`
- 在 `src/data/site.ts` 的 `nav` 或在线编程页加一个入口链接到 `/esp32/`。

> 注意：Blockly 工作区是全屏应用式 UI，与 Astro 的 `BaseLayout`（含 Header/Footer）不搭。
> 作为独立全屏页发布最合适，从门户用链接/卡片跳转进入。

### 方式 2（更原生）：包一个 Astro 页面用 iframe 嵌入
新建 `src/pages/esp32/index.astro`，用 `BaseLayout` 包一个全屏 iframe 指向 `/esp32-app/`（静态文件放这里），
保留门户头部导航。适合希望"留在门户框架内"的体验。多数情况方式 1 已足够。

## 四、复用门户已有的 ESP32 资源
门户 `public/esp32-libraries/` 已有 `OLED/ssd1306.py`、`phyphoxBLE/` 等库，
`src/data/esp32-programs/` 有现成 DIS 程序。本项目固件的 OLED/网络积木依赖 `ssd1306` / `urequests`，
可直接复用门户这套库分发（见 firmware/README.md 的 mip 安装步骤，或预置到固件文件系统）。
