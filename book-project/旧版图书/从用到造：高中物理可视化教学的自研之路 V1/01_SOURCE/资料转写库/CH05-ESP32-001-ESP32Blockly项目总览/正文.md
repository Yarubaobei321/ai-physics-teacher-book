## 一、项目是什么

**ESP32Blockly** 是一个面向**高中科创选修课**的平板图形化编程教学系统。学生在平板/iPad 的浏览器 PWA 里用 Google Blockly 拼积木 → 前端生成 MicroPython → 经教师 Mac 上的中央服务器按设备编号**无线下发**到教室里的 ESP32（MicroPython）运行并回显串口。

- **技术栈**：网页端是原生 HTML/CSS/JS（无前端框架、无打包，Blockly 从 CDN 加载）；服务器是 Node + Express + ws（CommonJS）；固件是 MicroPython；安卓端是原生 Kotlin。
- **完成度**：核心管线（WS 无线下发 + Blockly→MicroPython 生成 + WiFi/有线 USB/蓝牙 BLE 三种传输模式 + 教师管理台 + 有线烧录页）已实现并经真机与 headless 测试。
- **开发周期**：2026-06-15 首次提交，至 2026-07-05 共 43 次提交，约 3 周高度集中开发，单人项目。
- **界面设计**：沿用"数智育才"门户的"育才蓝"设计系统，目标是后期整合进 shuzhiyucai.cn。

### 三端架构（核心特色）

| 端 | 角色 | 运行环境 | 关键文件 |
|---|---|---|---|
| **学生端 PWA** | 拼积木 → 生成 MicroPython → 上传 | 平板/iPad 浏览器（PWA） | `server/public/index.html`、`server/public/js/app.js` |
| **教师端服务器** | 托管 PWA + 管理台 + WebSocket 路由（按设备编号下发代码） | 教师 Mac（Node + Express + ws） | `server/server.js`、`server/lib/registry.js` |
| **设备端固件** | 连 WiFi → 注册 → 收代码 → 运行 → 回显串口 | ESP32 / ESP32-S3（MicroPython） | `firmware/supervisor.py`、`firmware/ws_client.py` |

## 二、三种传输模式（核心特色）

| 模式 | 技术原理 | 适用场景 | 文档 |
|---|---|---|---|
| **WiFi 模式**（现网默认） | 学生 PWA → 教师 Mac 服务器（ws）→ ESP32（自写最小 RFC6455 WebSocket 客户端） | 教室有 WiFi，多组并发 | 现网默认 |
| **有线 USB 模式** | 平板/电脑 → Web Serial 直连 ESP32（MpRepl 读写 + EspFlasher 烧录） | 无 WiFi 或初始化固件 | `docs/有线模式使用说明.md` |
| **蓝牙 BLE 模式** | 平板 → Web Bluetooth 直连 ESP32（BLE GATT） | 无 WiFi 的简化场景 | `docs/蓝牙模式使用说明.md` |

## 三、8 类 Blockly 积木（覆盖 30+ 自定义块）

积木定义在 `server/public/js/blocks/esp32.js`，按颜色分 8 类：

| 分类 | 代表积木 | 支持的外设 |
|---|---|---|
| **引脚 IO** | 板载 LED、数字读写、PWM、占空比滑条 | GPIO 基础 |
| **时间** | 一直重复（while True）、延时 | — |
| **传感器** | 模拟读、按钮、DHT 温湿度、超声波 HC-SR04、**HX711 称重**、旋转编码器 | DHT、超声波、称重、编码器 |
| **显示** | OLED 清屏/文字（SSD1306）、**TM1637 四位数码管**、I2C 扫描 | OLED、数码管 |
| **网络** | HTTP GET、JSON 解析、MQTT 发布 | 联网类（刻意不开放 WiFi 连接/断开给学生） |
| **串口** | 串口打印、带标签打印 | 回显 |
| **执行器** | 蜂鸣器、**舵机 SG90 转角度**、继电器、电机、角度盘 | 舵机、继电器、电机 |
| **RGB** | 普通 RGB 三色灯、WS2812 彩灯填充/单灯/全灭 | RGB LED、WS2812 |

**设计取舍值得强调**（论文可写）：
- **只生成 MicroPython，不走 C++ 编译**——避免多人并发编译卡死。
- **绑定只用设备编号，无密钥**——课堂场景的极简设计。
- **WiFi 积木刻意不开放给学生**——避免误操作断网。
- **隐私红线**——不落盘学生代码正文。

## 五、教学/物理关联点

本项目与物理教学的关联是**数据采集与控制工具层**，而不是某个具体物理定律：

1. **传感器化物理实验数据采集**：DHT 温湿度、光敏、超声波测距（HC-SR04）、HX711 称重、旋转编码器计数——这些是物理实验的常用传感器。
2. **phyphox BLE 联动**：项目自带 phyphoxBLE MicroPython 库，ESP32 采集的物理数据可经 BLE 传到手机 phyphox 做力学、运动学分析。
3. **科创编程教学平台**：服务于物理创新实验室的科创选修课，36 学生 / 8 组 / 每组 1 平板 + 2 ESP32 的课堂实情。
4. **与数智育才网站的整合**：UI 沿用育才蓝设计系统，安卓包名 `cn.shuzhiyucai.espworkshop`，二维码编码 `https://shuzhiyucai.cn/esp32`，规划整合进 shuzhiyucai.cn（见 `docs/INTEGRATION.md`）。

> **写作切入点建议**：本项目最自然的论文角度是"**用 ESP32 + 图形化编程改造高中物理实验教学**"或"**传感器化物理实验数据采集的工具创新**"。目前未列入 4 篇物理论文，但可作为新增项目线或跨论文的背景素材。

## 六、安卓 app 现状

- **架构**：原生 Kotlin + WebView 桥的薄封装（从测试类名 `bridge.UsbFramerTest`、`bridge.JsChannelTest` 推断），把网页 PWA 装进 app，并用原生桥补齐 Web Serial/Web Bluetooth 能力（因安卓浏览器不支持这两者）。
- **包名**：`cn.shuzhiyucai.espworkshop`；versionName `0.1.0`；minSdk 26，targetSdk 35。
- **权限**：USB host、Bluetooth LE、BLUETOOTH_SCAN/CONNECT。
- **注意**：`mobile-app/` 目录下**只有构建产物，源码未入库**。写作时如需引用安卓实现细节，需另行获取源码。
