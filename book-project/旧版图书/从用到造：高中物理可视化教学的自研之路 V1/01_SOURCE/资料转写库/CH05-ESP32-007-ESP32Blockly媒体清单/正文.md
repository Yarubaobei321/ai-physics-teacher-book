## 生成方式备忘（便于后续重新生成）

积木截图用以下命令生成（2026-07-08 执行成功，耗时约 1 分钟）：

```bash
cd /Users/yaril/个人文档/ESP32Blockly
node tools/generate-textbook-block-assets.js \
  --textbook "/Users/yaril/个人文档/3 写作/项目资源库/ESP32Blockly"
```

依赖：本机 Chrome（`/Applications/Google Chrome.app`）、`server/node_modules/` 下的 playwright-core、blockly、@blockly/field-angle/field-slider。脚本用 `file://` 协议加载，**无需启动本地服务器**。生成物含 36 张 PNG + `manifest.json`（每张图的标题、说明、源文件锚点）。

如需重新生成（教材例程更新后），重跑上述命令即可覆盖。
