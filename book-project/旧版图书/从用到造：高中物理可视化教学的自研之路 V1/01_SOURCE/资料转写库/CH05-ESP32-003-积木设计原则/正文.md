# 积木设计原则

> 学生端 PWA 自定义 Blockly 块的约定。与 `AGENTS.md` / `CLAUDE.md` 中「改三处」流程配套阅读。

## 1. 通用化优先，避免过度集成

**一块只做一件事**，通过参数暴露可配置项，由学生在工作区**组合**完成场景。

| 推荐 | 不推荐 |
|------|--------|
| `读取模拟引脚 GPIO32 平均 5 次`（引脚 + 次数可调） | `打印环境亮度到串口`（读+打印+固定引脚写死） |
| `串口打印` + 插入上面的数值块 | `环境亮度`（无引脚、无次数的专用名块） |
| `设置数字引脚` + 下拉选 GPIO | `打开 P32 的 LED`（仅适用于一节课） |

**理由：**

- 教学上要看见「读传感器 → 打印 → 循环」的分解步骤，而不是黑盒。
- 同一套块能复用到温度、距离、其他 ADC 引脚，而不是每接一个传感器就加一个专用块。
- 与 Blockly 内置块风格一致：Reporter（数值）与 Statement（动作）分开，用凹槽/圆洞连接。

## 2. Reporter 与 Statement 不混用

| 类型 | 外形 | 典型块 | 用法 |
|------|------|--------|------|
| **Reporter（数值/布尔）** | 左侧圆凸 | `读取光敏亮度`、`读取模拟引脚平均 N 次` | 插进 `串口打印`、`如果`、数学运算的**输入槽** |
| **Statement（动作）** | 上下凹槽 | `串口打印`、`一直重复`、`延时` | 放进 `一直重复`、顺序堆叠 |

**不能**把 Reporter 直接塞进 `一直重复` 的语句槽——这是 Blockly 的类型系统，不是 bug。

## 3. 参数怎么暴露

- **引脚**：`field_dropdown`，选项遵守硬件约束（ADC 仅 32~39；输出块不含 34~39 等）。
- **次数 / 延时 / 阈值**：`field_number` 或 `input_value`（需接变量/表达式时用后者）。
- **课堂默认**：用 `optD(pins, 32)` 等把**常用默认值排下拉第一项**，但不删除其它选项。

工具箱里可以提供**已嵌套好的示例块**（如 `串口打印 [读取模拟 GPIO32 平均 5 次]`），那是快捷入口，不是新的块类型。

**完整课堂程序**应放入 **例程区**（顶栏「例程」），见 [docs/课程例程区.md](课程例程区.md)，不要在工具箱控制类里堆预拼 forever 栈。

## 4. 何时才做「场景块」

仅当同时满足以下条件，才考虑专用集成块：

1. 课堂上**每班必用**且组合步骤**固定不变**；
2. 通用组合**明显过长**（例如 5 层嵌套），平板拖拽成本过高；
3. 仍保留通用块，场景块作为可选快捷方式。

当前项目：**不做**「打印某某到串口」类集成块；光敏/亮度走 `esp32_ldr_read`、`esp32_analog_avg` + `esp32_print`。

## 5. 与串口示波器的配合

- 曲线视图按行解析**数字**；`串口打印` 纯数值最利于绘图。
- 需要文字说明时用 `串口打印 标签 值`；曲线仍能解析出行内数字。
- 示波器不负责区分物理量含义——积木侧保持「打印数值」的通用语义即可。

## 6. 半积木课：只封装可迁移动作

第二、三篇进入 MicroPython 和联网物联网后，不把整段项目代码封成一个大积木。半积木只服务两个目标：

1. 保留学生已经熟悉的结构，让他们能对照右侧代码看见“积木形状 → Python 缩进/语句”。
2. 封装容易绊住新手、但不是本课核心概念的通用动作。

适合做成通用块：

- `联网获取网址内容`：演示 HTTP GET，不负责 WiFi 连接/断开。
- `从JSON文本取字段`：把接口返回文本转成字典字段。
- `MQTT主题 前缀/设备/名称`：显式展示主题命名规约。
- `MQTT发布 broker/client/topic/message`：做一次发布，帮助理解发布四要素。

不适合封成黑盒：

- 第 9 章的变量、判断、循环。
- 第 13-17 章的函数、状态变量、状态机、异常处理。
- 第 20-22 章的完整云端项目流程。

这些内容应通过代码视图和代码例程学习；积木只做桥，不替代代码课。

## 7. 新增块检查清单

1. 能否用现有块组合实现？若能，优先不加新块。
2. 新块是 Reporter 还是 Statement？tooltip 是否写清「需插入 xxx 槽」？
3. 同步改：`blocks/esp32.js`、`generators/micropython.js`、`blockly-setup.js` 工具箱。
4. 生成代码是否可 `exec`、是否重复注入 helper（用 `P.definitions_` 去重）。
5. 是否违反 `AGENTS.md` 红线（WiFi 积木、secret、非 MicroPython 等）。

## 8. 示例：环境亮度 → 串口曲线

推荐拼法（GPIO32 + 5 次平均 + 200ms 循环）：

```
一直重复
  ├ 串口打印 [读取模拟引脚 GPIO32 平均 5 次]
  └ 延时 200 毫秒
```

对应生成代码核心：

```python
while True:
    print(adc_avg(32, 5))
    time.sleep_ms(200)
```

工具箱「控制」类第一个 flyout 块即上述组合的快捷示例，拖出即可测。
