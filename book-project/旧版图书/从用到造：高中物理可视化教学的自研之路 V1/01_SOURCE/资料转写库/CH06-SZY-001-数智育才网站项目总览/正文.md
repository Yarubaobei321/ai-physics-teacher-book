## 一、项目是什么

**数智育才网站**是一个高中物理教师**个人独立开发**的教学工具站 + 作品档案站，线上运行于 shuzhiyucai.cn。它不是资料展示网站，而是**四类可交互教学工具的统一入口**，学生用手机/平板浏览器打开就能做物理实验、采集数据、完成习题。

- **技术栈**：Astro 5 静态站点 + Tailwind + TypeScript；火星车地面站为 React island（岛屿组件）。
- **部署**：阿里云硅谷（初期）→ 腾讯云广州 + 个人 ICP 备案（2026-06 迁移）；Nginx + Cloudflare CDN。
- **开发方式**：零基础教师用 ZCode + GLM（DeepSeek 辅助）协作开发，全程 git 版本管理。
- **开发周期**：2026-04-18 首次提交，至 2026-07-02 共 64 次提交，单人项目。

### 四类教学工具（网站的四大支柱）

| 工具 | 入口路由 | 用途 | 核心技术 |
|---|---|---|---|
| **在线编程** | `/programming/` | 浏览器里直连 ESP32，选 MicroPython 模板一键写入程序和库 | Web Serial API |
| **网页版 DIS** | `/dis/` | 浏览器连 ESP32 蓝牙，实时采力、距离、光电门数据，绘图+导出 CSV | Web Bluetooth API |
| **在线实验室** | `/online-lab/` | 机械能守恒三方案的网页实验报告：填数据→自动计算→能量图分析 | Astro 原生交互 |
| **模拟实验室** | `/simulations/` | 动量章节 6 个演示模型（教师作品）+ 学生 AI 作品复核页 | 单文件 HTML |

外加两个项目式板块：**项目式学习**（`/project-learning/`）、**科创天地**（`/maker/`）。

## 二、教学价值与独特性

这个网站的独特性在于它**不是一个工具，而是一个完整的教学闭环生态**：

1. **从课堂到课后**：同一份机械能守恒资源，课堂用平板蓝牙接 ESP32 光电门采集真实数据（2026.4 区公开课已用），课后学生在手机上完成 28 道分层习题。
2. **五要素成体系的资源结构**：不是单个动画演示，而是"原理讲解 + 交互演示 + 数据表 + 误差分析 + 分层习题 + 实验回顾"的多要素组合。
3. **真实硬件联动**：网页不是孤立的模拟，Web Serial/Web Bluetooth 让浏览器直连 ESP32 采集真实传感器数据。
4. **零基础教师自建**：整个网站由一名物理教师（无前端背景）借助 AI 协作开发，本身是 D5 论文的核心实证案例。
5. **学生 AI 协作的档案化**：网站保留的30份作品与两轮审查属于D3方法形成期的历史材料；当前论文已切换到“2026特优生评选”中的25份物理作品，并采用v4双轨评分、教师异常项复核和浏览器深度验收。

## 三、机械能守恒在线实验室（C1/C2 论文的核心案例）

人教版必修二第八章 §5「实验：验证机械能守恒定律」。网站提供**三套互补方案**：

| 方案 | 路由 | 测速原理 | 核心公式 | 习题数 |
|---|---|---|---|---|
| 落体法 | `/online-lab/falling-body/` | 中间点定理（打点计时器纸带） | vₙ = (xₙ₊₁ − xₙ₋₁)/(2T) | 10 题 |
| 曲面下滑 | `/online-lab/curved-ramp/` | 双头光电门（DIS 机械能实验器） | v = L/Δt | 9 题 |
| 气垫导轨 | `/online-lab/air-track/` | 两双头光电门（前/后各一） | v = L/Δt | 9 题 |

每个实验页统一结构：实验目的 → 器材 → 步骤 → 数据表格与能量图像交互区 → 实验回顾 → 配套习题（单选/多选/填空/简答，带解析）。

## 六、技术栈与工程亮点（写作可引用）

- **Astro 静态站点**：每个 `.astro` 文件一个页面，共 23 个路由。构建产物纯静态，部署简单、访问快。
- **Web Serial / Web Bluetooth**：浏览器原生 API，无需装客户端即可连 ESP32。**兼容性限制**：仅 Chromium 系（Chrome/Edge）支持，Safari/Firefox 不支持——这是必须做安卓原生壳的技术动因。
- **React island**：火星车地面站是唯一的 React 岛屿组件，其余都是 Astro 原生组件。
- **自建访问计数微服务**：Nginx 反代 `/api/visits` → systemd 管理的 Python 服务，读写计数文件。
- **学生作品复核数据（历史层）**：`src/data/student-ai-audits.json`（30份旧样本），只用于回溯早期方法；当前D3数据在“2026特优生评选”项目及论文02研究数据目录。
- **ICP 备案与"去机构化"**：2026-06 迁腾讯云广州做个人备案，过程中做了"去机构化"处理（学生作品原始文件下线、改脱敏展示）。
