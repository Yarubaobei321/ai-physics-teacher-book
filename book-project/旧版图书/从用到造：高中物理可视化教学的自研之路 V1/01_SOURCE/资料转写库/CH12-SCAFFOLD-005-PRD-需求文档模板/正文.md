# 需求文档（PRD）模板

> 用法：先把本模板填好，再把内容发给 ZCode 中的 AI，并要求它"先复述需求、待确认后再写代码"。
> 把验收标准前置写清，可避免大量返工。

## 1. 基本信息

| 项目 | 内容 |
|---|---|
| 课题 / 主题 | 例：波的叠加与驻波 |
| 学科·学段 | 例：高中物理·高二 |
| 使用场景 | 课堂演示 / 课后自学 / 两者 |
| 使用设备 | 平板（横屏为主）/ 电脑 / 一体机 |

## 3. 页面结构与功能（按三段式）

**原理讲解区**
- 需讲清的概念 / 公式：____________

**交互演示区**
- 可调参数：____________（如频率、振幅、摆长……）
- 显示要素：____________（如分波/合成波可分别显隐、暂停、逐帧、自动标注……）
- 演示要直指的难点：____________

**配套习题区**
- 题量与分层：基础 ___ 题 / 中等 ___ 题 / 挑战 ___ 题
- 必含的误区辨析题：____________
- 反馈方式：即时判分 / 查看详解 / 错题重做
