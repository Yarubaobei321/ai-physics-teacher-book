# 有线模式使用说明（教师 PC）

有线模式让你在**电脑**上用数据线直接给 ESP32 烧固件、配编号、看文件系统，
也能让学生端在电脑上不经服务器直接上传运行。**安卓平板不支持**（Web Serial 限制），
平板继续用 WiFi 模式。

> 浏览器要求：**电脑版 Chrome 或 Edge**（macOS / Windows）。Safari、安卓 Chrome 不支持。

## 一、准备固件 .bin

烧录需要一份官方 MicroPython ESP32 固件 `.bin`（如 `ESP32_GENERIC-xxxxxxxx.bin`，
从 micropython.org/download 下载）。两种给法：

- **每次手选**：在 `/flash` 页点「选择固件 .bin」。
- **自动加载**：把固件放成 `server/firmware-bin/micropython.bin`，`/flash` 打开自动读取。
  （该目录已 gitignore，不会提交大文件。）

## 二、启动服务器并打开烧录页

```bash
cd server && npm install && npm start
```

电脑浏览器打开：

```
http://<Mac内网IP>:8080/flash
```

（也可从学生端右上「保存/设置」弹窗里的「有线烧录页」链接进入。）

## 三、烧录与配编号（/flash 页）

### 1. 连接并识别设备
点「读取 MAC 并识别编号」，在弹窗里选对应串口（macOS 多为 `cu.usbserial-xxxx`）。
页面只会进下载模式读 **MAC**，并判断：

- **旧板**（MAC 在台账里）：显示「沿用编号 N01」，自动填入编号框，保持兼容。
- **新板**（不在台账）：给**临时编号** `T-xxxx`，不写台账。需要转正式时见下文。

> MAC→编号 映射来自 `server/data/aliases.json`，由 `node tools/gen-aliases.js`
> 从 `tools/board-ledger.json` 台账生成。台账或编号变动后记得重跑这条命令。

### 2. 详细设置并初始化固件
识别完成后，页面会自动填入设备编号、无线名称、WiFi 账号、隐藏的 WiFi 密码和服务器地址。
确认这些设置后，点「开始初始化固件」。流程：全片擦除 → 写 MicroPython → 复位 →
写入应用文件（`boot/main/supervisor/wifi/ws_client.py`）+ `config.json`。

> WiFi 密码来自本机项目的默认配置，页面用密码框隐藏显示；初始化时会写入板子的
> `config.json`，用于设备上电后自动连接课堂 WiFi。请不要把 `firmware/configs/`
> 或 `firmware/config.json` 提交到公开仓库。

### 3. 文件系统 / 分区
点「读取设备」（设备需正在运行 MicroPython），查看：
文件系统占用、文件列表（可删除单个文件）、分区表（标签/类型/偏移/大小）。

## 四、把新板转成正式编号 Nxx

临时编号是一次性的。要把一块新板登记为正式 `Nxx`：

```bash
python3 tools/register.py        # 读 MAC、分配下一个 Nxx、写台账、出二维码
node tools/gen-aliases.js        # 刷新 server/data/aliases.json
```

之后再到 `/flash` 识别这块板，就会显示沿用的正式编号。

## 五、学生端有线模式（电脑上）

学生端 `http://<Mac内网IP>:8080/` 在**电脑 Chrome/Edge** 打开后：
右上「保存」→ 设置弹窗 →「传输模式」选「有线 USB 直连」→ 保存（页面会重载）。
此时「绑定设备」按钮变为「连接 USB」，点它选串口；之后「上传运行」直接经 USB 把
代码送到设备执行，串口输出（含曲线）照常显示，**不经服务器**。

平板上不会出现「有线」选项，继续走 WiFi。

## 六、常见问题

- **识别失败 / 端口选不到**：换粗短数据线、换 USB 口；有源 HUB 更稳（见 `docs/ESP32批量健康测试.md`）。
- **烧录中途失败**：看页面日志；CH340 线在高波特率可能不稳，重试或换线。
- **读文件系统提示失败**：设备要先烧好并正在跑 MicroPython；刚进下载模式的板需先复位。
- **多块板批量烧录**：`/flash` 面向单块逐台；整批健康分拣仍用 `tools/batch_health.py`。
