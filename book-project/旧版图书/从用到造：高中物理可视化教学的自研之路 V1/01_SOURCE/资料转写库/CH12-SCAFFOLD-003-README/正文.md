# 教学网页脚手架 · 使用说明

这是一套"开箱即用"的本地项目脚手架，体现 harness engineering（智能体工程化）思想：
与 AI 协作的质量，不取决于某一条聪明的提示词，而取决于你为 AI 搭建的整套"工装"——
**规则、技能、模板、验收、版本管理**。把这套工装放进项目，零基础教师也能像工程师一样管理开发过程。

## 一、目录结构

```
教学网页脚手架/
├── AGENTS.md              ← 项目规则文件（给 AI 的"班规"，自动生效）
├── PRD-需求文档模板.md     ← 起新页前先填它，把需求与验收标准想清楚
├── 验收清单.md            ← 网页做完后逐条核对（科学性 / 交互 / 适配）
├── 三问选题卡.md          ← 拿不准做什么时，用三问筛选题
├── index.html            ← 三段式网页骨架（原理→演示→习题）
├── README.md             ← 本说明
├── 参考/                  ← 喂给 AI 的高质量参考
│   ├── 育才设计令牌.md      ← 配色/版式/无障碍规范（从真实网站提炼）
│   └── 优秀模拟实验拆解.md  ← 6 个动量模型的结构与套路拆解
└── skills/               ← 可复用的技能说明书
    ├── 生成分层习题/SKILL.md
    ├── 新建实验页/SKILL.md
    ├── 物理交互模拟/SKILL.md     ← 进阶：SVG+守恒量面板+观察任务（从动量实验提炼）
    ├── frontend-design/SKILL.md  ← 开源前端技能（Apache 2.0），让界面专业度上一档
    └── 部署上线/SKILL.md
```

## 二、在 ZCode 中怎么用（五步）

1. **打开项目**：ZCode 中"打开文件夹"，选中本"教学网页脚手架"。AI 会自动读取 `AGENTS.md`。
2. **改规则**：把 `AGENTS.md` 第二节的学校 / 学科信息改成你自己的（只改一次，长期生效）。
3. **填需求**：复制 `PRD-需求文档模板.md`，填好你的课题需求。
4. **起页面**：在对话区对 AI 说"按 skills/新建实验页 的 SKILL 新建一个【课题】实验页"，并附上 PRD。让它先复述需求、确认后再做。
5. **验收与存档**：对照 `验收清单.md` 逐条检查，问题截图发回让 AI 修；满意后用 Git 一键提交保存版本。

## 三、harness 五件套与本目录的对应

| 工装 | 对应文件 | 作用 |
|---|---|---|
| 规则 | AGENTS.md | 统一标准，免去重复交代 |
| 技能 | skills/*/SKILL.md | 固化重复流程，写一次受益每次 |
| 模板 | PRD-需求文档模板.md | 把验收前置，减少返工 |
| 验收 | 验收清单.md | 学科 + 可用性把关 |
| 版本管理 | ZCode 的 Git 功能 | 改坏了能一键回退 |

## 四、为什么"技能(Skill)"是一次重大升级

- **它是什么**：一个"模块化能力包"——一个文件夹，里面是一份说明书 `SKILL.md`（必需）＋可选的脚本/参考/模板。每个技能只做一件事，AI 需要时自动加载。
- **提示词是"一次性口头交代"**：说一次、做一次，换个课题又要从头说，质量全看当下这条。
- **技能是"沉淀下来的标准作业流程"**：把"怎么做才算做好"写进 `SKILL.md`，AI 每次照同一套高标准走——稳定、可复用、可改进。从"碰运气"到"工程化"。
- **装很多也不拖慢（渐进式披露）**：平时只加载"名字＋用途"，匹配到任务才加载完整内容，脚本只回传结果不占对话。
- **零基础也能拥有**：你不必会写代码——套路来源于你，让 AI 帮你写成 `SKILL.md`。**知识来源于你，格式交给 AI。**
- **单一职责＋可组合**；**从 20 行起步逐步迭代**；只用**可信来源**的技能。
- **在网页开发上差距很明显**：不挂技能风格随机、易遗漏；挂上技能（如本目录自带的 `frontend-design`，或《物理交互模拟》）结构、视觉、自检更专业，更接近成熟作品。`frontend-design` 是开源社区技能（Apache 2.0 许可），**已随本脚手架自带**，打开项目即可用，不必另装。
- 一句话：**提示词决定这一次，技能决定每一次。**

### 推荐学习资源：宝玉《图解 Skill —— AI 提效实战指南》

想把"技能"学透、并且是从零起步，强烈推荐这本书：

- **微信读书已上架**，搜书名即可阅读——大量图解，对老师最友好。
- **配套代码与示例在 GitHub 完全开源**：`github.com/JimLiu/baoyu-skills`（中文圈最火的技能集合之一，两万多 stars）。在 ZCode 里用一句命令即可整套装入：
  ```
  /plugin marketplace add JimLiu/baoyu-skills
  ```
- **为什么值得学**：所谓技能，本质就是"固化的工作流"——人机协作的一种组织方式。这种组织方式是**通用的**，不管模型怎么升级换代，你沉淀下来的技能都还能用。学技能，学的是一种不会被模型迭代淘汰的能力。

## 五、进阶主线：提示词 → 工装 → 循环 → 钩子

这套脚手架对应的是当前 AI 编程的四级进阶，越往后越省心：
1. **提示词（Prompt）**：把需求说清楚。
2. **工装（Harness）**：规则、技能、模板、验收、版本——就是本目录。
3. **循环（Loop）**：让 AI 自己跑"计划→修改→验证→修复"的闭环，你设计循环、它自动推进。
4. **钩子（Hooks）**：在"保存""提交"等节点自动触发检查（如提交前自动跑验收），把规范变成自动执行、不靠记忆。

> 提示：若你用 Claude Code 而非 ZCode，把 `AGENTS.md` 内容复制为 `CLAUDE.md` 即可，其余完全一致。
