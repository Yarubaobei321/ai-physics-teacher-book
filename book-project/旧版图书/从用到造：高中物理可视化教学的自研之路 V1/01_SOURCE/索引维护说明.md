# 资料索引维护说明

## 两层索引

### 策划层

- `全书资源地图.md`：按问题找入口。
- `章节资源索引.md`：按章确定读取顺序。
- `视觉证据索引.md`：按解释任务找图像、数据和视频。
- `本书资料台账.md`：登记已经判断与本书有关并实际使用的材料。

策划层由编辑维护，只收录高复用或已经进入章节决策的内容。

### 机械层

- `外部资源根目录.md`：允许扫描的根目录与所有权边界。
- `外部资源文件清单.csv`：候选文件的路径、类别、格式、大小和修改时间。
- `../tools/build_resource_index.py`：重建机械清单并检查系统结构。

机械清单只用于发现。文件出现在清单里，不代表它与本书有关、已经授权或可以支持某项主张。

### 内容转写层

- `资料入口.md`：把机械发现、出版策划和内容转写三个层级集中在一个页面。
- `资料转写台账.csv`：记录原件哈希、转写工具、结果路径、状态和重复关系。
- `资料转写索引.md`：供作者和Agent快速查看已经处理到什么程度。
- `资料转写库/`：按资源ID保存`正文.md`、`图片索引.csv`、`材料卡.md`和`meta.json`。

内容转写层由`book-material-mining`技能维护。每次处理前先查路径与SHA-256，未变化的材料直接复用。

## 什么时候更新

| 变化 | 更新动作 |
| --- | --- |
| 新增或移动一批外部文件 | 修改根目录配置（如有需要），重建CSV |
| 新发现一个值得进入某章的材料 | 补章节素材考古表；跨章复用时再补全书资源地图 |
| 一幅图片确定进入正文 | 补视觉策划单、事实档案和视觉证据索引 |
| 作者确认了版本或课堂事实 | 更新事实档案与本书资料台账 |
| 材料被排除 | 在章节工作包说明原因，不从机械清单强行删除 |

## 重建机械清单

在项目根目录运行：

```bash
python3 -B tools/build_resource_index.py
```

脚本只读取外部目录的文件名和元数据，写入本项目的 `01_SOURCE/外部资源文件清单.csv`，不会修改外部文件。

## 校验

运行：

```bash
python3 -B tools/build_resource_index.py --check
```

检查内容：

- 系统要求的文件是否存在；
- 所有外部根目录是否可访问；
- CSV中的绝对路径是否仍然存在；
- 清单是否包含重复路径；
- 第3章基准正文、事实档案和图片是否仍在。
- 第5章基准正文、事实档案和15幅正文图是否仍在。

## 维护边界

- 不手工编辑数千行CSV；重新生成。
- 不为了索引完整而读取文件正文。
- 不自动转换Office、PDF或视频；章节需要时再选择 anydoc、MinerU 或人工查看。
- 不把摘要层重复摘要。项目总览、项目卡片、目录说明和已有结构化摘要直接复用。
- 不把第三方参考书图片复制进本书。
