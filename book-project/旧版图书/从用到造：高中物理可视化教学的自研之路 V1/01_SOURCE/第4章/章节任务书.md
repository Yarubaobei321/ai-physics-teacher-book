# 第4章章节任务书

更新时间：2026-08-12

## 章节定位

- 章名：计算机仿真与可视化：让模型可以操控、比较与检验
- 章节承诺：帮助物理教师判断一项数字资源是否真正承载模型、推理和检验，并给出从教学问题到可发布仿真的设计方法。
- 主要作者：黄灿斌；蓝图中原定王硕参与，现有王硕资料未发现能够独立支撑本章的计算机仿真原件，正文不虚构其项目经历。
- 目标篇幅：9,000—11,000字。

## 本章回答的五个问题

1. 动画、交互仿真和可检验模型有何区别？
2. 参数、假设、输出和任务怎样形成同一个学习工作台？
3. 怎样把原题数据、标准化输入和开发者扩展分开？
4. 怎样用特殊点、极端值、不变量和否决性条件检查模型？
5. 教师何时使用现成软件，何时需要定制网页或自研工具？

## 案例分工

- 核心案例：薄膜冲击发光与压缩时间。展示“视频读数—物理量反演—力时程假设—冲量计算—警告与测试”。
- 对照案例：小球滑上曲面小车。展示“临界值上下的反事实比较—关键帧—多表征同步”。
- 方法案例：高考实验仿真模型组。展示19个计算模型、77项回归与否决性测试及书稿输出门控。
- 边界案例：COMSOL静电场输出图。说明数值场图适合比较边界条件；当前仅保留输出图，没有可复算工程文件，因此不写成可复现实验。
- 文献支点：刘健智、程婷（2021）关于GeoGebra的数据拟合、动态推导、三维临界分析等功能地图。

## 跨章边界

- 第3章讲实物教具与模拟实验，本章只取COMSOL结果说明数字模型的边界。
- 第5章讲ESP32Blockly系统，第6章讲网站平台；本章不展开技术架构。
- 第8、9章讲课堂使用；本章提供可直接调用的预测、比较、解释任务，不编造课堂反馈。
- 第12章讲教师与AI协作开发；本章只强调AI生成后仍需物理验收。
