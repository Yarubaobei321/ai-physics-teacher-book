# 第7章物理审查

审查对象：莱顿瓶电容概念教学装置  
审查日期：2026-08-12

## 审查结论

原件的核心装置思路可用，面积—电容结论存在确定错误，必须修正后进入正文。

## 关系与条件

1. 理想平行板近似：

   \[
   C=\frac{\varepsilon S}{d}
   \]

   介质和距离不变时，有效正对面积增大，电容增大。

2. 莱顿瓶更接近同轴圆柱电容器。忽略边缘效应时：

   \[
   C=\frac{2\pi\varepsilon L}{\ln(b/a)}
   \]

   圆柱半径和介质不变时，有效重叠长度增大，电容增大。

3. 静电计读数链必须写明状态。充电后断开起电机，漏电可忽略，系统电荷量近似不变：

   \[
   U=\frac{Q}{C}
   \]

   有效面积减小 → 电容减小 → 电势差增大 → 静电计张角增大。

## 必须保留的误差与限制

- 潮湿表面、瓶口与支架可能形成漏电通道，`Q`只能在短时间内近似不变。
- 静电计本身与引线形成附加电容，实际观察的是整个连接系统。
- 外层铝箔升降会改变边缘电场、导线位置和杂散电容，不能只用理想公式作精确定量解释。
- 瓶体和铝箔通常不是严格同轴圆柱，结构图只表达变量关系。
- 起电机未断开时，系统不能按`Q`不变分析，实验操作必须明确断开步骤。

## 原件冲突

原件写“正对面积增大，电容减小；正对面积减小，电容增大”，与上述关系相反。判定为不通过表述。正文固定采用修正关系，作者确认是否为笔误。
