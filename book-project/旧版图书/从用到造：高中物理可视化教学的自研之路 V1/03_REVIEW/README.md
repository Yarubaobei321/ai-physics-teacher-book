# 书稿审查区

`03_REVIEW/` 保存图书生产过程中的审查、作者确认和修改记录。它与 `review/` 的职责不同：

| 目录 | 面向对象 | 保存内容 |
| --- | --- | --- |
| `03_REVIEW/` | 作者、总编与审稿 Agent | 事实、物理、版权、隐私、可读性审查；作者裁决 |
| `review/` | 非技术审阅者和阶段验收 | 一次任务的一份 `review.md` 与可视化 `index.html` |

## 推荐结构

```text
03_REVIEW/
└── 第XX章/
    ├── 章节审稿表.md
    ├── 作者确认.md
    └── 修改记录.md
```

## 审查顺序

1. 事实审查；
2. 物理审查；
3. 视觉与图文对应；
4. 版权、隐私与作者归属；
5. 可读性和跨章重复；
6. 作者确认。

前一项存在红线时，不用润色掩盖问题。所有结论只使用：

- `✅ 通过`
- `⚠️ 待作者确认`
- `❌ 不通过`

模板位于 `../00_CONTEXT/templates/章节审稿表.md`。

## 作者确认最小记录

`作者确认.md` 至少记录：

- 具体问题；
- 作者原话或明确选择；
- 日期；
- 影响的事实ID、图号或正文位置；
- 是否需要回到原始材料补证。

聊天中的口头确认应及时写入项目文件，避免后续 Agent 看不到裁决。
