**【本章导读】**

一节 40 分钟的《超重与失重》，可以讲得很快：给定义、划条件、列公式、做练习，20 分钟足够。但这样的课堂里，学生记住的是"加速度向上超重、向下失重"八个字，遇到"电梯里的体重秤"仍然会犹豫——示数到底是哪个力？本章完整呈现笔者的一次尝试：用一个近乎玩笑的真实问题——"丁老师想短暂'减肥'，怎样让体重秤的示数变小？"——把整节课串成一条问题链，让学生在蹲起、拉纸带、看电梯模型的 v-t 图、观察漏水瓶的过程中，自己走到"支持力随加速度变化"这个结论跟前。章末附本节课的评价量表、两个课堂生成性事件的处理复盘，以及一份可直接取用的实践清单。

## 3.1 一个"减肥"问题引发的课堂

上课铃响，我没有翻开教材，而是向全班求助：

> "丁老师最近在减肥，但效果不明显。我想利用物理知识，短暂地'改变'一下体重秤的示数，拍张照片发朋友圈'晒'一下。大家帮我想想办法？"

紧接着补上两条规则：第一，不能改装体重秤；第二，不能在身体上额外施力——不许别人扶着，也不许自己拽桌子。

教室里先是笑，随后猜想冒了出来：有学生说"跳起来的瞬间"，有学生说"下蹲试试"，也有学生直接喊"去电梯里称"。我把这些猜想一一写上黑板，然后顺势追问一句：

> "体重秤的示数，到底反映的是哪个力？它有没有可能不是重力？"

这一问，课堂安静了几秒。多数学生此前从未怀疑过"体重秤称的就是体重"。这个瞬间恰恰是本节课真正的起点——**认知冲突出现了，而且是学生自己的动作把它引出来的**。

为什么用这样一个问题开场？我的考虑有三层。

其一，它足够"真"。减肥、拍照、发朋友圈，都是学生日常世界里的元素，没有一丝实验室的疏离感。学生不需要先理解任何物理概念，就能对这个问题产生立场和猜想。

其二，它足够"物理"。这个问题的实质，是"支持力（视重）与重力（实重）在什么条件下不相等"——正是本节课的核心。趣味外壳之下，问题的骨架严格对准了教学目标。

其三，它自带一条完整的探究路径。要回答"怎样让示数变小"，就必须依次解决：示数是什么力→什么动作能改变它→改变的规律是什么→极端情况（示数为零）会怎样。这四问恰好对应本节课的四个教学阶段。

## 3.2 教材、学情与素养目标

### 3.2.1 教材中的位置

《超重与失重》是人教版高中物理必修第一册第四章《运动和力的关系》第 6 节，也是这一章的收尾。它的特殊性在于：前五节建立起牛顿运动定律的完整框架，这一节则要求学生**用**这套框架去解释一类日常现象。换句话说，这是一节典型的"应用课"——学生不缺新知识，缺的是把已有知识组织起来解决真实问题的经验。教材本身也强调让学生在探究超重和失重现象的过程中获得直观体验、完成自主发现。

正因为如此，这节课最忌讳的处理方式，就是把它上成"新概念课"：先给超重失重的定义，再给判定条件，再做题。定义先行，探究就死了。

### 3.2.2 学情：三个已有与两个缺口

学生已有的：重力、质量的概念；牛顿第二定律与第三定律的内容；对"电梯里身体忽轻忽重"的生活体验。

学生缺的：其一，"体重秤示数=支持力"这层辨析，几乎所有学生都默认示数就是重力；其二，把生活体验翻译成受力分析与动力学方程的能力——感觉"心里一沉"容易，说清"沉"对应加速度方向难。

高一学生的抽象思维正处在发展阶段，对抽象概念的建构需要先借助演示实验获得感性认知。这决定了本节课的策略：**每一个结论出场之前，先安排一次可看、可做、可感的活动。**

### 3.2.3 素养目标

按照物理学科核心素养的四个维度，本节课的目标定为：

- **物理观念**：通过体验和实验认识超重和失重现象；理解其发生条件；能运用牛顿运动定律分析其动力学原因。
- **科学思维**：能从实际情境中捕捉问题、提出问题；会用超重失重的条件对现象进行推理与判断。
- **科学探究**：经历"观察现象—猜想假设—实验验证—总结应用"的完整过程，增强证据意识。
- **科学态度与责任**：经历从亲身感受到科学结论的过程，养成用科学知识解释生活现象的习惯；借助航天情境体会物理与国家科技发展的关联。

值得说明的是，这四条不是贴在教案开头的装饰。后文的评价量表（3.4 节）会逐条回收它们——目标写了什么，量表就评什么。

## 3.3 四阶段教学过程实录与解析

整节课 40 分钟，分四个阶段：情境创设与问题驱动（约 5 分钟）、探究与建构（约 24 分钟）、迁移与应用（约 8 分钟）、反馈与总结（约 3 分钟）。探究阶段内部又含四个环节。下面逐段呈现，并在每段后补一段"设计解析"，说明这样安排的理由。

### 3.3.1 阶段一：情境创设与问题驱动（约 5 分钟）

开场的"减肥"求助如 3.1 节所述。这一阶段教师要做的事只有三件：抛出问题并立规则；把学生的猜想（下蹲、起立、跳跃、乘电梯……）板书留存；追问"示数反映的是哪个力"。

学生的活动则丰富得多：小组讨论提出猜想；部分学生上台，在体重秤上示范下蹲、踮脚，直观感受示数变化；尝试回答"示数是不是重力"，并提出新的疑惑。

**设计解析**：把"改变体重秤示数"设为主线问题，是整节课的关键决策。它的作用不只是激趣——板书上留存的那排猜想，就是后面三个探究环节的任务清单：蹲起对应环节一，电梯对应环节三，"上天"对应环节四。学生自己提出的猜想，由学生自己逐一验证，课堂的探究感由此而来。

### 3.3.2 阶段二·环节一：体重秤上的蹲起——体验与初步归纳

**验证猜想（1）：在体重秤上做下蹲或快速站起的动作。**

学生上台演示，全班观察示数变化并记录。随后围绕三个问题展开讨论：

1. 体重秤的示数反映的是哪个力的大小？
2. 上述过程中，哪几段运动过程示数比人的重力小？
3. 这些过程有什么共同特征？

三个问题是有意排成"阶梯"的。第一问解决概念辨析：体重秤直接承受的是人对秤的压力，由牛顿第三定律，其大小等于秤对人的支持力——所以示数是**支持力**（视重），不是重力（实重）。第二问把观察结果整理成证据：下蹲的启动段、站起的结束段，示数偏小。第三问逼近本质：这些阶段的共同点是**加速度方向向下**。

在此基础上引导学生做受力分析：人受重力 mg 与支持力 F<sub>N</sub>，取竖直向上为正方向，由牛顿第二定律：

F<sub>N</sub> − mg = ma

当加速度 a 向上时，F<sub>N</sub> = m(g + a) > mg，示数大于实重，称为**超重**；当 a 向下时，F<sub>N</sub> = m(g − a) < mg，示数小于实重，称为**失重**。至此，超重与失重的概念和发生条件由学生的蹲起动作"长"了出来。

**设计解析**：注意顺序——先有现象和数据，再有受力分析，最后才出现"超重""失重"这两个名词。概念是归纳的终点而非讲授的起点，这是本节课与"定义先行"式处理的根本区别。

### 3.3.3 阶段二·环节二：纸带拉重锤——动力学原因的强化

**教师挑战**：用纸带拴住一个重物，用手提着纸带拉动重物，看哪一组能最快把纸带拉断。

学生很快发现：缓慢地拉，纸带安然无恙；猛地一拉，"啪"一声就断。为什么猛拉更容易断？

小组讨论后归纳：猛拉意味着重物获得向上的大加速度，纸带除平衡重力外还需提供 ma 的"额外"拉力，F = m(g + a)，a 越大拉力越大，超过纸带能承受的极限就断了。

**设计解析**：这个环节在知识上没有新增内容——仍是 F − mg = ma——但它的价值在于**换一个物理量再走一遍逻辑**。环节一变的是支持力，这里变的是拉力；学生由此意识到，超重失重的本质不在"哪个力"，而在"加速度改变导致接触力改变"。用一个几毛钱的耗材实验完成动力学思想的强化，性价比极高。这也是全章想传达的一个立场：**素养课堂不等于高成本课堂。**

### 3.3.4 阶段二·环节三：电梯模型与 v-t 图——从定性到定量

**验证猜想（2）：在运动的电梯里称体重。**

真电梯没法搬进教室，我用自制电梯教具替代：小车沿竖直导轨做"启动—匀速—制动"的完整运动，配合手机 Phyphox 软件调用加速度传感器，实时记录并投屏"电梯"上升、下降全过程的 v-t 图像。

学生协助完成演示；台下学生的任务是：在 v-t 图上标出加速段与减速段；分段讨论支持力的变化；最后画出一张"体重感觉变化图"——横轴是电梯运动阶段，纵轴是"感觉体重"的大小。

以上升过程为例，师生共同完成如下分段分析：

| 阶段 | v-t 图特征 | 加速度方向 | 支持力与重力关系 | 状态 |
|---|---|---|---|---|
| 启动加速 | 斜率为正 | 向上 | F<sub>N</sub> = m(g + a) > mg | 超重 |
| 中段匀速 | 斜率为零 | 无 | F<sub>N</sub> = mg | 不超不失 |
| 制动减速 | 斜率为负 | 向下 | F<sub>N</sub> = m(g − a) < mg | 失重 |

下降过程学生自行完成，正好反过来。分析完毕，我把当堂的实验现象改编成一道物理试题，学生现场作答。

**设计解析**：这个环节承担着本节课"从定性到定量"的关键一跃。前两个环节的证据都是"感觉"和"断没断"，这里第一次出现了**图像证据**。v-t 图的斜率对应加速度方向，加速度方向对应超重失重——图像、动力学方程、身体感觉三者在这里对齐了。Phyphox 的引入成本极低（学生手机人人都有），却让"自制教具"有了数字化实验的品质。这也为本篇第 5 章严力耕老师的智能超失重演示仪埋下伏笔：同一个教学诉求，还可以用更精密的自制装置来实现，两章对读会很有意思。

### 3.3.5 阶段二·环节四：漏水的瓶子——完全失重

**验证猜想（3）：把丁老师送到外太空称体重。**

学生大笑，但问题是严肃的：如果 a 向下且恰好等于 g，F<sub>N</sub> = m(g − g) = 0——体重秤示数为零。这就是**完全失重**。

演示实验：一只侧壁扎孔的塑料瓶装满水，静止托在手中，水从孔中喷出；让瓶子自由下落——水流戛然而止。再看一段对比视频：装水的杯子做自由落体和竖直上抛，均不漏水。最后播放航天员在空间站生活的视频：漂浮的身体、悬停的水球。

这里必须处理一个高频误区。总有学生说："完全失重就是不受重力了。"我请学生对下落的瓶子做受力分析：重力还在吗？在——正是重力提供了 a = g 的加速度。消失的不是重力，是水与瓶壁之间、人与秤面之间的**相互挤压**。"失重"失去的是视重，不是重力。

**设计解析**：完全失重是本节概念链的极限情形，也是误区高发区。瓶子实验的妙处在于它把"看不见的挤压"变成了"看得见的水流"：水喷出，说明瓶内水层之间存在挤压；水流停止，挤压消失。证据的直观程度决定了纠偏的力度。而航天视频则完成了另一重任务——把课堂与中国载人航天的真实成就连接起来，科学态度与责任的目标在这里自然落地，无需喊口号。

### 3.3.6 阶段三、四：迁移应用与反馈总结（约 11 分钟）

迁移阶段的任务有两个：其一，学生举出生活中的超重失重现象（过山车、蹦极、荡秋千、跳床……）并用条件判断；其二，**把实验现象改编成物理试题**——这是本节课的特色作业形态，学生从"解题者"变成"命题者"，必须先想清楚考什么、给什么条件，实际上完成了一次更深的模型调用。

总结阶段回收三个问题：什么是超重和失重？发生条件是什么？动力学原因是什么？三问对应板书的三个层次，也对应素养目标中"物理观念"的三条。

## 3.4 评价量表的设计与使用

一节强调素养的课，如果评价只看"答案对不对"，目标就落空了一半。本节课配套的评价量表从四个维度展开，每个维度给出可观察的行为指标，采用学生自评、同伴互评、教师评价三栏并行：

| 评价维度 | 行为指标（节选） | 自评 | 互评 | 师评 |
|---|---|---|---|---|
| 知识掌握 | 能正确说出"体重秤示数是支持力"；理解超重、失重、完全失重的概念及判定条件 | | | |
| | 能根据给定情境（如电梯运动）判断某阶段是否超重或失重，并说明理由 | | | |
| 技能运用 | 能对"站在体重秤上的人"进行受力分析并正确列出牛顿第二定律方程 | | | |
| 思维品质 | 会区分"重力"和"支持力"，能清晰表达"失重≠无重力"的本质理解 | | | |
| | 能在讨论中提出见解，或对同学的解释进行合理质疑与补充 | | | |
| 情感态度 | 积极参与实验和讨论；愿意用物理语言解释生活现象；小组合作中有责任意识与倾听习惯 | | | |

使用时有两点提醒。第一，评价采用"优秀/良好/合格/需改进"四级记录，不打分数——量表的目的是让学生知道"好的表现长什么样"，不是再造一次排名。第二，我特别要求学生在自评与互评时关注"建模思路是否清晰""表达是否有逻辑"，而不只看答案对错。指标里"能说明理由""能清晰表达"这些字眼，就是为此设置的。

从素养目标到评价指标的对应关系值得一提：四个评价维度并非另起炉灶，而是 3.2.3 节四条素养目标的"可观察化"。目标—活动—评价三者对齐，这正是当下强调的教学评一致性；本篇下一章，王硕老师将以同一节课为例，把这种一致性用逆向设计的方式做得更加彻底。

## 3.5 预设与生成：两个课堂意外的处理

教学设计写得再完整，课堂总会长出计划之外的东西。这节课有两个生成性片段，值得复盘。

**片段一：学生抢跑到了电梯。** 预设中，"乘电梯"的体验要到环节三才展开。但在开场讨论时，就有学生主动说出"电梯启动时感觉变重"。我当时的选择是不压回去，而是把这句话写上黑板，标注"待验证"，并在环节三开始时点名请这位学生复述他的体验，再用 v-t 图检验。事后看，这个处理让环节三的分析有了一个"学生自己的锚点"——图像不再是教师给的，而是来验证他的话的。课堂的真实感和参与感明显增强。

**片段二："完全失重就是重力消失了。"** 讲完全失重时，仍有学生把"失重"理解为"重力没了"。这促使我临时增加了一段受力分析：让全班对自由下落的瓶子重新画受力图——图上只有一个力，恰恰是重力。"重力始终存在，只是支持力为零"这句话，由画图的学生自己说了出来。

这两个片段给我的启示是一致的：**素养课堂需要教师既有清晰的结构预设，又敢于把学生的生成当作资源**。前者保证课堂不散，后者保证课堂是活的。判断一个生成值不值得接，我的标准是——它是否指向本节课的核心模型。指向的，接住并放大；不指向的，记下课后处理。

## 3.6 改进方向：让学生自己采集数据

复盘这节课，有两处明确的升级空间。

**其一，把数据采集的权力交给学生。** 目前电梯模型的 v-t 图由教师演示、全班观看。下一轮迭代，可以让学生用自己的手机装 Phyphox，在真实电梯里（或用教具分组）采集加速度数据，自主绘制并分析图像。作业设计中"记录一次乘电梯的体验并用 Phyphox 采数"的实践性作业，就是这一方向的第一步——课堂演示、课后实测，先看后做。

**其二，接入更精密的自制装置。** 手机传感器方便，但控制不了运动过程——电梯什么时候加速、加速度多大，都不由我们决定。本篇第 5 章将介绍严力耕老师的智能超失重演示仪：闭环步进电机让"电梯"严格按设定的加速度运动，压力传感器实时回传视重曲线。届时读者可以对照本章思考一个问题：当装置可以精确控制变量时，这节课的探究环节可以再往定量深处走多远？

配套的作业设计同样按三个层次展开：基础性作业巩固 F − mg = ma 的分析方法；拓展性作业让学生选一个游乐设施情境（秋千、蹦极、过山车、跳床）分析各阶段的超失重状态；实践性作业即上述电梯体验记录与 Phyphox 采数。三层作业的共同点是：都要求学生**说明分析思路**，而不只给结论——这与评价量表中"思维品质"维度一脉相承。

**【实践清单】**（可直接取用）

1. 驱动问题模板："老师想短暂'减肥'，如何让体重秤示数变小？"附加两条规则：不改装秤、不额外施力。
2. 器材清单：体重秤 1 台（示数投屏更佳）、纸带与重锤若干组、自制电梯教具（导轨+小车）或真实电梯视频、侧壁扎孔的塑料瓶、装有 Phyphox 的手机、航天员太空生活视频。
3. 问题链（探究环节一）：示数反映哪个力？→哪些过程示数偏小？→这些过程的共同特征是什么？
4. 分段分析表：阶段 × v-t 图特征 × 加速度方向 × F<sub>N</sub> 与 mg 关系 × 状态（见 3.3.4 节表格，可直接印在学案上）。
5. 评价量表：四维度 × 三主体（见 3.4 节），四级记录。
6. 三层作业：基础（教材练习）＋拓展（游乐设施情境分析）＋实践（电梯体验 + Phyphox 采数）。
