## 写作约定（摘要）

1. 第一人称「笔者」；不编造细节；缺口标【需作者补充】。
2. 章内件套：导读、二级节、实践清单、延伸资源、插图占位。
3. 学生化名；他人资料署名引用。
4. 「减肥」开场梗仅篇二第 3/4/5 章。
