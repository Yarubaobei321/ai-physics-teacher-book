# 书稿插图目录

所有进入纸质正文或PDF导出版的图片，都在本目录保存一份书稿副本。

## 目录规则

```text
assets/
├── ch03/
├── ch05/
├── ch06/
└── ……
```

- 每章使用独立的`chXX/`目录。
- 正文从`02_MANUSCRIPT/`出发使用相对路径，例如`assets/ch05/student-workspace.png`。
- 正式书稿不引用项目资源库、教材目录或其他外部位置的绝对路径。
- 原图的绝对路径、作者、版权、哈希、证据边界和采用状态保留在`01_SOURCE/第XX章/`的视觉资产索引中。
- 更新原图时先核对视觉台账，再替换本目录副本，避免同一图件出现无法识别的不同版本。
- SVG保留可编辑源文件；进入正文时可同时保存PNG导出版。
