## 本书对第三方默认规则的覆盖

### 宝玉插图与封面

- 生成前确认、先保存提示词和保留参考图记录的做法继续使用。
- 图位和图量只能来自本书G3视觉策划，不能由技能按篇幅自动决定。
- 生成图不能自动插入正式正文；G5、G6通过后才能采用。
- 第一次真正调用生成技能时，再按相应 `SKILL.md` 完成 `EXTEND.md` 偏好设置。当前只完成安装，不预设图片服务商或密钥。

### 宝玉图解

`baoyu-diagram`默认深色背景、霓虹色、网格和等宽字体，适合技术草图，不适合直接进入纸质教育专著。正式书稿图应改为浅底、中文字体、灰阶可辨、线型兼容黑白印刷，并在图注注明“示意图”或“根据××材料绘制”。

### 花叔审校

保留三遍审校：第一遍查事实与逻辑，第二遍查套话和机械句式，第三遍查标点、排版与节奏。下列内容不进入本书标准：

- “AI检测率低于30%”；
- “保持花生风格”；
- 花叔个人素材库的绝对路径；
- 强制口语化、强制手机短段落或虚构个人经历。

本书审校的判断标准是事实可追溯、物理正确、作者口吻自然、图文互相解释、版权与隐私合规。

### 内部PDF

隔离运行环境位于Git忽略目录：

`/Users/yaril/个人文档/3 写作/.scratch/skill-runtimes/huashu-md-to-pdf/.venv/`

调用示例：

```bash
"/Users/yaril/个人文档/3 写作/.scratch/skill-runtimes/huashu-md-to-pdf/.venv/bin/python" \
  "/Users/yaril/个人文档/3 写作/.agents/skills/huashu-md-to-pdf/scripts/convert.py" \
  "待审读书稿.md" -o "内部审读样.pdf"
```

该技能的目录提取要求标题带数字。若书稿标题体系不同，只把它用于临时阅读样，不为迁就工具而改动正式章节标题。

## 网页审阅

本项目的 HTML 审阅页由作者人工查看。除非作者明确提出，不调用 Playwright 或其他浏览器自动化工具生成审阅截图，不生成桌面端或移动端截图，也不检查移动端适配。Agent 只检查文件、链接和 HTML 基本结构，并交付可直接打开的审阅入口。
