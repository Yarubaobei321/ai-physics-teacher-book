# 教学网页验收清单

> 用法：网页生成后逐条核对。任何一条不过，把问题（最好附截图或报错原文）发回 ZCode 让 AI 修复。
> 三查：科学性、交互、适配。

## 一、科学正确性（学科教师把关，最重要）

- [ ] 原理表述、文字描述无知识性错误
- [ ] 公式、单位、上下标正确
- [ ] 交互演示的物理行为正确（用"取特殊点核对"：选一两个可手算的特殊状态验证）
- [ ] 习题答案与详解全部正确
- [ ] 误区辨析题确实针对真实学生误区

## 二、交互有效性

- [ ] 所有可调参数都能调，且演示随之实时更新
- [ ] 暂停 / 逐帧 / 重置等控制可用
- [ ] 即时判分、查看详解、错题重做正常
- [ ] 交互直指教学难点，不是为动而动

## 三、可用性与适配

- [ ] 平板触屏操作顺手，按钮够大（≥44px）
- [ ] 横屏、竖屏均可正常显示
- [ ] 字号在课堂投影下清晰可读
- [ ] 主流浏览器可打开，加载速度可接受
- [ ] 断网状态下仍可正常打开（验证"不依赖外网"）

## 四、合规与署名（发布前）

- [ ] 引用素材已标注来源 / 版权
- [ ] 不收集学生个人隐私信息
- [ ] 师生作品已署名并取得授权

## 五、版本与记录

- [ ] 满意版本已保存 / 提交（Git）
- [ ] 关键提示词与需求文档已留档
