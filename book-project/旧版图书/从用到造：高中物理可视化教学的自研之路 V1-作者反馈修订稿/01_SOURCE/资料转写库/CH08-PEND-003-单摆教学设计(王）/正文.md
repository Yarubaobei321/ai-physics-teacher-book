# 以新教材为基，从单元整体视域的单摆教学设计

以新教材选择性必修一“单摆”教学为例

摘要：本文从新旧教材对比进行教材分析，从单元整体看学情分析，从物理核心素养认识本节教学目标，进而设计本节教学流程。本节教学从荡秋千入手，以展示人体单摆引出本节课的内容，从演示自制的气球摆和铁球摆，通过观察分析引导学生逐步得出单摆为理想化模型并提出单摆作为理想化模型的条件。理论推导单摆沿圆弧方向的运动为简谐运动，体会物理学近似思想在物理中的应用。展示单摆图像演示器，客观演示单摆的振动图像，从运动学角度说明单摆运动特征。探究单摆周期与哪些因素有关，通过演示实验定性分析单摆周期与振幅、质量无关，通过定量实验探究单摆周期与摆长的关系。介绍惠更斯单摆周期公式来源以及演绎推理过程，并进行实际应用，例如利用单摆的周期公式解决生活中钟摆计时不准的问题。

关键词：单摆  新教材  物理核心素养

**一、从新旧教材对比进行教材分析**

在教材中的地位，《单摆》这节教学内容，是学生在学习了简谐运动及其图像、简谐运动的描述及回复力和能量等内容之后学习的内容，是简谐运动的典型应用实例。既是对本章所学知识和方法的应用，又是对简谐运动具体模型的拓展，同时也是高中物理机械振动中的重要内容, 具有较强的教学价值。在旧教材中，先研究单摆振动的图像，进一步提出问题“单摆的振动是不是简谐运动？”，然后提出了单摆的回复力，研究其是否满足简谐运动的动力学特征。然而在新教材中两块内容顺序发生了调换，相比于旧教材，更符合人们的认知习惯。体现新教材对中学生物理学科核心素养科学探究能力的培养，内容显得也更为严谨。新教材中将影响单摆周期的因素先通过演示实验进行定性探究：“通过实验表明：单摆做简谐运动的周期与摆长有关，摆长越长，周期越大，单摆的周期与摆球质量和振幅无关。“进而再研究单摆周期与摆长之间有什么定量关系。这样设计突出实验探究的逻辑性，考察学生实验方案设计以及处理实验数据的能力。新教材把旧教材中“利用单摆测定重力加速度”内容单列一节，有效地避免了原教学内容的臃肿，又突出了对该科学探究实验的重视。

**二、从单元整体视域看学情分析**

本章内容为机械振动，分为六小节，单摆为第四节内容。前三节介绍简谐运动的运动特征和能量特征，因此学生在学习单摆之前已经学习了弹簧振子，对简谐运动模型、做简谐运动物体的受力特征和能量特征已经有所认识。初步建立研究简谐运动的一般思路，这为“单摆”的学习打下了扎实的理论和实验的基础。后两节为机械振动的应用，学生通过学习单摆这一典型简谐运动，对后续了解机械振动的其他应用也会更清楚明了。同时在高一的学习中，关于控制变量法、转化等物理思想和方法已经有所应用，为本节课的实验探究提供了方法的支撑。通过本节课的学习有利于进一步巩固学生对简谐运动的认识。在单摆简谐运动动力学特征理论推导过程中，有利于强化学生对简谐运动特征更深刻的认识，同时培养学生的科学思维、科学探究能力以及严谨的科学态度。

**三、从物理核心素养认识本节教学目标：**

**物理观念**：通过体验感悟，认识单摆是一种理想化模型，进而形成物理观念；通过实验探究，感知单摆的运动性质和单摆周期的影响因素，进而形成运动与相互作用观念。

**科学思维**：能从多维的具体情境中，抓住本质特征，构建单摆模型，学会理想化物理模型法；能从定性和定量两个方面，科学推理出摆角很小时单摆做简谐运动，体会数学近似法在物理中的应用；能通过实验，科学论证影响单摆周期的因素；能应用单摆周期公式解释现象和解决实际问题。

**科学探究**：能够通过观察、猜想、设计实验与制定方案获取并处理信息，得出单摆的运动性质和影响单摆周期的因素，并对结果进行交流、评估和反思；能够通过定量实验，结合证据得出单摆的周期公式。

**科学态度与责任**：通过了解伽利略、惠更斯等物理学家对单摆研究的经历和贡献，感悟实事求是、持之以恒的态度和勇于开拓创新的精神；在实验探究过程中，培养严谨细致的科学态度。通过小组合作，培养团队合作意识。

**九、教学反思**

对这节课内容的设计是从新教材出发，以学生为主体，老师作为引导来进行设计。在本节课的开头展示“人体单摆”，以学生亲身体验进行导入，引起同学们的共鸣，之后进行单摆模型建模，经过演绎推理和实验探究证明单摆小角度下为简谐运动，再由学生分组实验探究单摆的周期与哪些因素有关，数据现场用EXCEL进行处理，使学生体会研究的过程与方法。并且在单摆周期公式部分设置演绎推理，形成科学探究的思维链。整节课结束之后，也有许多不足，比如在学生处理数据那一部分，在有时间的情况下，可对有问题的数据再次进行检验，同时在讲课的语言方面还需要多加锤炼，做到精炼到位。
