# P1 块真机验证记录

> 日期：2026-06-24
> 板子：ESP32-DevKitC，MicroPython **1.28.0**
> 方式：`mpremote connect /dev/cu.usbserial-210 run <程序>`，运行**块生成器产出的 MicroPython**。
> 程序经 RAM 瞬态执行，**未覆盖板上 supervisor 固件**（boot.py/main.py/config.json）。

自动化测试（`npm test`，14 项全绿）证明生成**正确**；本记录证明生成的代码在**真硬件上跑通**。

| 硬件 / 引脚 | 涉及的块 | 结果 |
|---|---|---|
| LED P2 | `led_builtin` / `digital_write` | ✅ 闪烁 |
| 无源蜂鸣器 P14 | **`buzzer_tone` / `buzzer_off`** | ✅ 奏出 do-mi-sol |
| 舵机 SG90 P5 | **`servo_write`** | ✅ 0→180 两极到位、无抖 |
| WS2812 灯条 P13 ×10 | **`rgb_fill` / `rgb_set` / `rgb_off`** | ✅ 整条变色 + 单灯寻址 |
| 光敏 P32（ADC1） | **`analog_avg` / `ldr_read`** | ✅ 读数随光照 164↔2802 变化 |
| 按键 P4 | **`button_debounced`** | ✅ 去抖准确，无连跳 |
| —（纯串口） | **`print_labeled`** | ✅ 「标签 值」格式正确 |
| —（纯计算） | **`map` / `constrain`** | ✅ 由 `npm test` 覆盖 |

**说明**
- 光敏须用 **ADC1 引脚（GPIO32-36, 39）**；GPIO25 等 ADC2 与 WiFi 冲突，块下拉已故意不列。
- 继电器 / 电机为同一套 `Pin.value(0/1)` 数字输出机制（与 LED 同），逻辑由 `npm test`（含继电器高/低触发极性矩阵）覆盖，未单独接实物。
- 舵机占空比范围 `26~128`（50Hz）经真机确认可达 SG90 两极。
