# 课程例程区

**状态**：已扩展（2026-07-05）  
**入口**：顶栏 **「例程」** → 左侧侧栏

## 用途

Mixly 式例程库：按“合集 → 篇 → 章”管理课堂示例。学生点击后可以载入完整 Blockly 积木工程，也可以载入 MicroPython 代码例程。

后续各课时的标准程序都在 `server/public/js/examples.js` 的 `CATALOG` 里追加。优先用通用积木组合例程，**不要**为每节课做专用积木块；第二、三篇里更适合文本编程的内容可以作为 `kind: 'code'` 例程导入。

## 当前例程

新增独立合集：**从积木到智能体**。

- 第一篇第 1-7 章：以 Blockly workspace 例程为主，覆盖点灯、呼吸灯、RGB/灯条、按键、旋钮、编码器、蜂鸣器、数码管、OLED、光敏、DHT、超声波、槽型光电、声音、红外、HX711、温控风扇和综合项目菜单。
- 第二、三篇：采用“半积木课”。保留核心代码例程，同时为关键概念提供可迁移的 Blockly 例程，例如积木到代码对照、温度预警、智能台灯骨架、电子秤校准起点、HTTP/JSON、MQTT 主题与发布。
- 第四、五篇：不强行 Blockly 化，保留为教材任务和拓展阅读。

## 新增例程

编辑 `server/public/js/examples.js`，在 `CATALOG` 追加积木例程：

```javascript
{
  id: 'unique-id',
  collectionId: 'from-blocks-to-agent',
  collectionTitle: '从积木到智能体',
  part: '第一篇 启蒙积木编程',
  chapter: '第 5 章',
  order: 501,
  kind: 'blocks',
  category: '传感器',
  title: '例程标题',
  desc: '一两句说明',
  tags: ['可选标签'],
  workspace: { /* Blockly.serialization.workspaces.save 的 JSON */ },
}
```

新增代码例程时使用：

```javascript
{
  id: 'unique-code-id',
  collectionId: 'from-blocks-to-agent',
  collectionTitle: '从积木到智能体',
  part: '第二篇 MicroPython 文本编程',
  chapter: '第 9 章',
  order: 901,
  kind: 'code',
  category: '代码',
  title: '例程标题',
  desc: '一两句说明',
  code: 'import time\n\nwhile True:\n    print("hello")\n    time.sleep(1)\n',
}
```

获取 `workspace` JSON：在学生端拼好积木 → **保存** → 导出 `.esp32` → 取文件里的 `workspace` 字段粘贴进 catalog。

代码例程载入后会自动切到 **混合** 视图，左侧保留学生原有积木草稿，右侧写入 CodeEditor，并作为可上传的 MicroPython 代码使用。界面会显示“当前是代码例程”的提示，说明左侧积木不是该代码的等价积木版本。不要放 Arduino/C++ 的 `setup()`、`loop()`、`#include`。

半积木例程仍使用 `kind: 'blocks'`。设计原则是“保留结构，不封死项目”：把容易绊住学生的硬件和协议动作做成通用块，但变量、函数、状态机、异常处理等第二篇要学习的核心语法仍通过右侧代码视图讲清楚。

当前半积木推荐范围：

- 第 8 章：积木到代码对照。
- 第 9 章：温度预警器，帮助理解变量、判断和循环。
- 第 13 章：多档智能台灯骨架，后续用代码重构档位表。
- 第 15 章：电子秤校准起点，积木跑通后在代码里调校准系数。
- 第 18 章：HTTP GET 与 JSON 取字段，不开放 WiFi 连接/断开。
- 第 20 章：MQTT 主题命名与发布一次，不封装完整云端项目。

改完后升级 `sw.js` 的 `CACHE` 版本号。

## 教材截图

教材插图版截图使用真实 Blockly 渲染，不手工模拟积木样式。脚本会启动本机 Chrome 的 headless 模式，从 `Examples.CATALOG` 读取 workspace，载入自定义块定义后裁切原生 SVG 积木区域。

生成截图：

```bash
node tools/generate-textbook-block-assets.js \
  --textbook '/Users/yaril/个人文档/2 智能硬件选修课/校本教材《从积木到智能体——ESP32 智能硬件创意编程》'
```

输出位置：

- 教材仓库：`assets/积木截图/*.png`
- 索引文件：`assets/积木截图/manifest.json`

生成插图版 Markdown：

```bash
node tools/generate-textbook-illustrated-edition.js \
  --textbook '/Users/yaril/个人文档/2 智能硬件选修课/校本教材《从积木到智能体——ESP32 智能硬件创意编程》'
```

输出位置：

- 平行版本：`插图版/`
- 插图索引：`插图版/README-插图索引.md`

原纯文字版不会被覆盖。若要回滚教材侧生成物，可以删除 `插图版/` 与 `assets/积木截图/`。

## 与工具箱的关系

- **工具箱**：通用积木块（参数化）
- **例程区**：完整示例工程（组合好的 workspace）
- 控制类工具箱**不再**放预拼好的 forever 栈，避免与例程重复

## 相关文件

- `server/public/js/examples.js` — 目录与渲染
- `server/public/js/app.js` — `loadExample()`、侧栏开关
- `server/public/index.html` — 侧栏 DOM
- `server/public/css/styles.css` — `.examples-panel`
- `tools/generate-textbook-block-assets.js` — 原生 Blockly 截图
- `tools/generate-textbook-illustrated-edition.js` — 教材插图版生成
