# 三问选题卡

> 用法：拿不准做哪个网页时，用这三问筛一遍。三问都"是"，就是好选题。

## 一问：哪个知识点学生最容易错、或最难想象？
- 候选课题：____________
- 学生最容易出错 / 最难想象之处：____________

## 二问：现有资源为什么解决不了？
- 现有课件 / 平台 / 挂图的局限：____________
- 为什么"非做交互网页不可"：____________

## 三问：做成网页后学生怎么用？
- 使用时机：课堂演示 / 课后自学 / 两者
- 使用方式：单人练习 / 同伴协作 / 教师演示
- 课后延伸场景：____________

## 判定
- [ ] 三问皆"是"——立项，按 PRD 模板细化需求
- [ ] 有一问答不上——换题，或先把问题想清楚
