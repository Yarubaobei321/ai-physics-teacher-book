# 论高中物理可视化教学的学术原则与实施

朱亚军（江苏省苏州中学 ，江苏 苏州 215007）

摘 要 ： 本文结合高中物理可视化教学的实践和现代教育技术理论 针对目前高中物理可视化教学中存在的问题 提出了高中物理可视化教学必须遵循科学性 生本性 创新性 整体性 层次性和反馈性等原则 以期引发广大同行的思考 提升高中物理可视化教学的质量 促进教学效果的最优化

关键词 ： 高中物理 ；可视化教学 ；学术原则

随着现代教育技术的迅猛发展 高中物理可视化教学的优点日益凸显 将隐性知识显性化 显性知识生动化 复杂知识简单化 系统知识结构化．高中物理可视化教学能将文本形象化 图文并茂 声色俱佳 增大课堂容量 时空延展化 延长课堂“时间” 拓展课堂 “空间” ； 情境可视化 实现“动”“静”互变“ 微观”“宏观”互换 动静皆宜 按需变换．可视化教学具有很强的视 听冲击力和感染力 能诱发学生的好奇心 激发学习兴趣 调动学习积极性 提高物理教学的效益和质量．然而如果可视化教学运用不当 则会违背教育和科学原理 误导学生 弄巧成拙．基于此 笔者根据自己多年的教学实践， 结合新课程标准的理念谈谈高中物理可视化教学应遵循的学术原则与实施问题 并以典型的教学案例加以说明 以便跟同行们进行交流

## 1 科学性原则

高中物理的教学任务是引导学生认识物质世界的客观规律，掌握学习现代科学技术和从事国家建设必备的物理基础知识 并帮助学生逐渐形成正确的自然观 世界观 价值观 荣辱观和人生观 培养学生认识世界和改造世界的能力 为学生终身发展应对现代社会和未来发展的挑战奠定基础．这是一个求真务实 追求真理 提高素养 培养能力的过程不仅要注意教学内容的科学性 而且要重视教学方法 手段和技术的科学性．因此 科学性理所当然地成为物理可视化教学的首要原则

$$
v _ { 2 } = { \sqrt { \frac { 2 q \times 3 U } { m } } } , \ r _ { 2 } = { \frac { 1 } { B } } { \sqrt { \frac { 2 m \times 3 U } { q } } } .
$$

离子第 $n$ 次进入金属盒 $D _ { 2 }$ 时，已经过电场加速 $( 2 n { - } 1 )$ 次．同理可得，离子的速率 $v _ { n }$ 和轨道半径 $\boldsymbol { r } _ { n }$ 分别为

$$
\begin{array} { l } { { \displaystyle v _ { n } = \sqrt { \frac { 2 q \times ( 2 n - 1 ) U } { m } } , } } \\ { { \displaystyle r _ { n } = \frac { 1 } { B } \sqrt { \frac { 2 m \times ( 2 n - 1 ) U } { q } } . } } \end{array}
$$

当离子第 $( n + 1 )$ 次进入金属盒 $D _ { 2 }$ 时，已经过电场加速 $( 2 n + 1 )$ 次．同理可得 离子的速率 $\textstyle \mathcal { V } _ { n ^ { + } }$ 和轨道半径 $r _ { n + 1 }$ 分别为

$$
\begin{array} { l } { { v _ { n + 1 } } = \sqrt { \frac { 2 q \times ( 2 n + 1 ) U } { m } } , } \\ { { \displaystyle r _ { n + 1 } = \frac { 1 } { B } \sqrt { \frac { 2 m \times ( 2 n + 1 ) U } { q } } . } } \end{array}
$$

显然，带电粒子在回旋加速器金属盒 $D _ { 2 }$ 内任意两 个 相 邻 的 圆 形 轨 道 半 径 之 比 为 $\frac { r _ { n } } { r _ { n + 1 } } =$ $\frac { \sqrt { 2 n - 1 } } { \sqrt { 2 n + 1 } }$ 这意味着带电粒子在金属盒内运动的轨道间距不相等，越靠近金属盒的边缘，相邻两轨道的间距越小

从上述教学案例可见 在进行高中物理可视化教学的时候，呈现的图片、图像要精准、细致， 千万不能凭空臆想 杜撰物理现象或过程

需要特别强调的是 物理学是一门实验科学物理教学一定要尽可能多的做实验———教师的演示实验 学生的分组实验以及边学边实验（过去常称为边教边实验） 和课外小实验等．因为 在物理教学中有时候是千言万语说不清 一看实验就分明．不以实验为基础的物理教学 很难称之为真正的物理教学， 也就无法发挥物理教学的独特教育功能．物理实验在培养学生的观察能力 操作能力 思维能力等方面具有独特的作用 尤其是在培养学生的创新能力 创新精神和思维独立性等方面是其他学科难以替代的

## 2 生本性原则

学生是教育工作的最主要的对象 他们不仅是教学活动的主体 更是学习的主人．教学上的以生为本主要是以尊重学生的生命存在为本 以观照学生的全面持续发展为本 以呵护学生的创造天赋和灵性为本．对学生而言 无论是新知识的获得或者是对现成知识的理解 掌握，都离不开他们自主的积极参与 教师一定要尽力保护并发挥学生的能动性 积极性

事实上 学生掌握知识的过程是一种探究的过程 选择的过程 创造的过程 也是科学精神 创新精神 乃至正确的世界观 人生观逐步形成的过程．对于学生来说 最重要的不再是接受和存储知识，而是学会探究，以便为他们的终身继续学习奠定基础．因此 高中物理可视化教学要以学生的身心全面和谐发展为最高目标， 践行“为了一切学生 为了学生的一切 一切为了学生”的教育理念紧紧围绕“知识与技能” “过程与方法”和“情感态度与价值观”的三维目标 备教材 备方法 备实验 备媒体 备环境 备文化 备学生 杜绝一份教案一成不变多班 多年地重复使用 应该与时俱进 渗透新素材 变换新情景 使用新方法 从为学生不断发展而奠基的高度进行物理可视化教学反之，“目中无生” “照屏宣讲” “不做实验”的所谓物理可视化教学一定不会成功

高中物理可视化教学的过程应该努力追求“处处是创造之地 天天是创造之时 人人是创造之才”的境界 运用创新思维和方法不断培养学生勇于创新的意识 敢于创新的气魄和善于创新的能力

## 4 整体性原则

整体性原则是系统论原理在高中物理可视化教学中的体现， 经典物理学是一幢由力学 电学热学 光学 原子和原子核理论等知识构成的宏伟大厦 因此 高中物理中的每一章 每一节的教学都不是孤立的 而是整个教材知识体系不可分割的有机组成部分， 与其他部分知识之间必然存在千丝万缕的联系

显然 高中物理可视化设计和教学应从教材的整体出发， 结合学生的身心特点和认知发展水平的实际 明确每一章 每一节的教学内容在整个教材知识体系中的地位和作用 在以学生为本的基础上 紧紧围绕新课程标准 起承转合 承上启下 整体把握 整体优化 整体设计 整体推进 利用直观 具象 可视化的方法和物理实验抓住关键 突出重点 化解难点 确保教师 学生 教学媒体 教学内容和物理实验五者协调 和谐运作 最后达到整体迈进

## 5 层次性原则

层次性原 则 是 教 学 内 容 的 层 次 性、 教 学 对 象的层次性 教学要求的层次性 教学目标的层次性和教学方法的层次性对高中物理可视化教学的客观要求．高中物理教材的编撰一般遵循由简单到复杂 由形象到抽象 由定性到定量的规律．学生无论是对物理概念的建立和理解 还是对物理规律的认识和掌握也是经历由表及里 由浅入深 由特殊到一般循序渐进的过程

层次性原则更是因材施教 尊重个性的教育思想在高中物理可视化教学中的体现 不同学生的认知结构 智力因素 接受能力和学习愿望不可能完全相同； 同一学生的认知发展水平也具有阶段性 差异性．因此 高中物理可视化教学应具有鲜明的层次性 即“低起点面向全体 分类要求 个性化指导 多角度评价 多层次发展” 切实做到低起点 多台阶 多维度 多目标， 让学生们拾级而上 使不同层次的学生都能有所收获 实现协同发展

## 6 反馈性原则

反馈性原则是控制论原理在高中物理可视化教学中的体现 任何系统只有通过及时的信息反馈和自检 才可能实现有效的控制 从而达到既定目的．或者说 没有信息反馈和自检功能的系统 ，要实现有效控制 ， 进而到预设目的是不可能的

高中物理可视化教学过程是一个复杂的特殊系统 这个系统由教师 学生 教材 仪器 课件等和教学方法 手段等基本要素构成．因此为了实现教学目的 在高中物理可视化教学的过程中一定要确保反馈渠道的畅通 ， 对学生来说 反馈信息可以使学生强化正确 改正错误找出差距 促进努力 ； 对教师来说 反馈信息可以使教师掌握教学情况 调整 改进教学方法及时纠正教学活动中出现的偏差或失误 实现教与学的高度同步 和谐统一 刻意提高高中物理可视化教学的针对性和有效性 从而圆满完成教育教学任务
