# ESP32 烧录板台账（按 MAC）

> 由 `tools/batch_health.py` / `tools/diag_one.py` 测试后**自动维护**。
> MAC=芯片出厂不可变身份；别名=内部编号(好板才分配)；最近测试=最近一次烧录/诊断时间。
> 编号产生和改变会写入“编号变更记录”，避免同一编号被重复使用。
> **⚠️曾好转坏** = 该板历史出现过 PASS、但最近一次不是 PASS（好板变坏的信号）。

## 别名与二维码规则

- `Nxx`：WiFi + BLE 均正常，适合 Blockly WiFi 课堂系统。
- `Sxx`：ESP32-S3 好板，单独用于 AI / TFT / 创客项目。
- `Bxx`：BLE 可用但 WiFi 不可用，可留作纯 BLE 项目。
- `Cxx`：BLE 不可用；若 MCU/Flash/GPIO 仍正常，可留作非无线基础实验。
- `Fxx`：下载/烧录/启动层失败或无法稳定运行，按完全不可用处理。
- 二维码文件在 `tools/out/qr/<别名>.png`；贴纸外观保持 `别名 + MAC`，扫码内容为单行 ASCII 文本：`别名 MAC=<mac> HEALTH=<OK/WIFI_BAD/BLE_BAD/DEAD>`。
