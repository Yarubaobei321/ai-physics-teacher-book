# 《从用到造》项目说明

## PROJECT_SUMMARY

### 项目目标与当前状态

本项目是《从用到造：高中物理可视化教学的自研之路》V1作者反馈独立修订目录。它以V1为只读基线，专门吸收作者人工审阅意见；不覆盖原V1，也不并入“V2-理论增强”的第7、12章试点。全书仍以四篇十二章讨论高中物理可视化、教师自研工具、课堂应用、评价与持续发展。

十二章V1正文、书内图片、审稿文件、合订稿和内部审读PDF已复制为修订基线。第1—4章既有作者反馈及第5、6、8、9、10章新增口述反馈已经在独立修订稿中落实；第7、11、12章保留V1基线，未混入“V2-理论增强”试点。当前修订稿为12章、107,828字符、150幅正文图、A4共164页；自动验证和重点页面抽检通过，仍需作者人工复核和出版社版权裁决，不能视为出版定稿。

### 主要目录

- `00_CONTEXT/`：本书定位、章节地图、写作与视觉标准、工作流和技能路由。
- `01_SOURCE/`：资料入口、资源索引、分章事实档案、资料矩阵、视觉策划和作者问题。
- `02_MANUSCRIPT/`：十二章正文源文件、书内资产和自动生成的全书合订稿。
- `03_REVIEW/`：事实、物理、版权、可读性审查以及作者确认记录。
- `review/`：供非技术审阅者人工查看的阶段审阅页。
- `tools/`：合订、索引、PDF构建和全书验证脚本。
- `output/`：排版输入、统计和内部审读PDF等生成产物。

### 关键入口与工作流程

1. 先读`00_CONTEXT/README.md`，按任务类型选择最小读取路径。
2. 写作和修订遵循`00_CONTEXT/WORKFLOW.md`的G0—G6流程：章节任务书、素材考古、事实档案、内容与视觉策划、图文写作、四类审查、作者确认。
3. 写正文前读`00_CONTEXT/STYLE_REFERENCE.md`；处理图片前读`00_CONTEXT/VISUAL_STRATEGY.md`。
4. 作者聊天反馈写入`03_REVIEW/第XX章/作者确认.md`，并同步章节审稿结论和全书规则，不能只留在对话中。
5. 十二章独立Markdown是正文唯一源文件；不要直接长期修改`02_MANUSCRIPT/全书合订稿.md`或`output/`中的生成文件。
6. 本目录的修订范围与状态以`03_REVIEW/全书/作者口述反馈修订清单-2026-08-17.md`为唯一入口；原V1目录保持只读。

### 常用构建与验证命令

在本项目根目录执行：

```bash
python3 tools/build_book.py --check
python3 tools/build_book.py --no-pdf
python3 tools/build_book.py
python3 tools/validate_book.py
```

- `build_book.py --check`：检查十二章、图片路径和图号，并刷新索引与统计。
- `build_book.py --no-pdf`：重建合订稿、图像索引和统计，不导出PDF。
- `build_book.py`：在前述基础上使用Pandoc和Typst导出内部审读PDF。
- `validate_book.py`：检查正文、SVG、审阅页、资料台账和当前PDF，并写入`03_REVIEW/全书/最终验证记录.json`。

### 重要输出

- 正文源：`02_MANUSCRIPT/第1章…md`至`第12章…md`
- 合订稿：`02_MANUSCRIPT/全书合订稿.md`
- 图片索引：`01_SOURCE/全书正文图像索引.csv`
- 统计：`output/全书统计.json`
- 内部审读PDF：`output/从用到造：高中物理可视化教学的自研之路.pdf`
- 最终验证记录：`03_REVIEW/全书/最终验证记录.json`

### 范围边界与已知风险

- 当前作者审阅以保护V1为前提；原V1正文和图片保持只读，本次修改只进入本独立“作者反馈修订稿”并重新送审。
- 本目录即独立作者反馈修订稿；不得把“V2-理论增强”的理论插入卡、示范扩写稿或第7、12章试点混入本稿。
- 课堂设计、装置存在、网页运行和学习效果必须分层表述；缺少课堂作品、观察或评价数据时，不把设想写成已证实效果。
- 第三方论文、题干、图片和软件材料进入正文前要核对出处、上下文、引用方式和出版版权。
- V1图注体例存在分裂：第3—11章大量使用括号式来源或性质说明，第1、2、12章没有。V2按`00_CONTEXT/STYLE_REFERENCE.md`逐幅区分读图说明、公开图源和后台记录，禁止机械删括号。
- 第4章已按作者意见改为六个动量仿真的案例族；开发验收与薄膜冲击只作后台检查或短例，不再决定章节骨架。当前版本仍待作者复核。
- 学生材料必须脱敏并确认授权。
- 当前验证结果为12章、150图、72条资料和164页PDF；页数不是永久阈值，正文图片对象数必须与正文图片引用数一致。
