# 第1章作者审阅反馈（V1）

审阅日期：2026-08-14  
审阅对象：`02_MANUSCRIPT/第1章 从知识传授到思维培养：当学生需要现场建模.md`  
状态：独立作者反馈修订稿已落实，待作者复核  

本文件记录作者针对V1的原始审阅判断。2026年8月17日，修改已进入独立作者反馈修订稿；原V1正文和图片保持只读。

## 1. 图1-1图注使用了编务与证据审查口吻

正文位置：图1-1图注。

V1原文：

> 图中行动来自2024年11月至2025年6月的工作记录；解释性重绘不代表某一名学生的完整学习过程。

作者判断：这不是面向读者的表达。

V2修改要求：

- 图注只保留读者理解图片所需的“对象＋读图重点”；
- 工作记录的日期、解释性重绘的来源和证据边界移入资料台账、视觉策划单或审读记录；
- 全章排查“来源核验、版本说明、证据免责”直接进入读者正文的类似表达。

## 2. 提到高考题后，应及时呈现题干和装置图

正文位置：2023年广东高考“药品自动传送系统”题和2024年广东高考“电磁俘能器”题首次出现处。

作者判断：读者看到题名后会立即追问系统长什么样。V1只给出“四阶段地图”和“五层变量链”，没有先让读者看见题目中的实际装置，阅读链条中断。

V2修改要求：

- 第一次提到一道承担分析任务的高考题时，紧接着提供足以独立理解后文的题干；篇幅较长时可以节录，但关键条件不能缺失；
- 装置图是理解题意的必要信息时，放在首次分析附近，不能只用过程图、变量链或结论图代替；
- 2023年药品自动传送系统题补题干与装置图，再进入四阶段分析；
- 2024年电磁俘能器题补题干与装置图，再进入空间分区、磁通量和变量链分析；
- 使用原题图、节录题干或重新绘图前，核对来源、引用方式、图意准确性和出版版权要求。

这条要求提升为全书写作注意事项，不只用于第1章。

## 3. 证据边界写成了少见的教师口吻

正文位置：第四节末。

V1原文：

> 没有匿名学生作品和课堂观察之前，我们不能声称这种改造已经提高成绩。它提供的是一条可实施、可收集证据的路径。未来可以比较同一学生修改前后的过程图、模型说明和迁移题作答，观察困难是否真正从某个断点移开。

作者判断：“没有匿名学生作品和课堂观察之前，我们不能声称……”这类表达是教师写作中很少使用的表达，带有明显的AI审查口吻，不像教师面向教师读者的自然表达。

V2修改要求：

- 保留“不把设想写成已证实效果”的事实边界；
- 不把“没有某证据，所以不能声称某效果”这类内部审查句式原样写入正文；
- 从教师能够实施和观察的动作切入，例如学生怎样划分过程、说明模型、修改作答，以及教师怎样据此判断学习变化；
- 全章排查同类免责声明、程序说明和过度自证句式，改成教师常用的叙述方式。

## 4. 高考题研究需要进入专业教师的术语与表达语境

作者判断：第1章研究高考题的方向值得保留，但V2不能只靠一般化的“现场建模、变量链、接口”等自建表达。

V2修改要求：

- 修改前参考专业高中物理教师、教研员对高考物理题的研究文章或著作；
- 重点学习他们怎样描述情境、设问层次、物理过程、模型建构、关键条件、学生障碍和解题策略；
- 整理可复用的规范术语与表达习惯，再校准第1章两道高考题的分析；
- 参考资料只用于校准术语、分析维度和教师口吻，不照搬他人的分析结论。

## 5. 图1-10不能体现“全书四篇路线”

涉及资产：`02_MANUSCRIPT/assets/ch01/ch01-10-book-route.png`。

作者判断：现图画得奇怪，不能体现“图1-10　全书四篇路线”。经文件核对，成图存在明显裁切和布局故障：四篇内容没有完整出现，只剩左侧一块被截断的卡片，主体区域大面积空白。

V2修改要求：重做图1-10，不在现图上做局部修补。

验收标准：

- “为什么—怎么造—怎么用—怎样评价与维护”四篇全部完整出现；
- 四篇的先后关系或共同主线一眼可辨；
- 图题、正文所说的“四篇路线”和图内结构一致；
- 按纸质书常用阅读尺寸查看时，文字清楚、元素不越界、没有异常空白或裁切；
- 若图不能比相邻四段正文更清楚地呈现全书结构，则删除该图，不为凑图保留。
