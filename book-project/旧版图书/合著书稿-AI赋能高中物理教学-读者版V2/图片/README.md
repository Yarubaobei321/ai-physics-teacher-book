# 第二版图片资产说明

本目录保存第二版正文实际引用的图片副本。正文统一使用相对路径，避免VS Code预览、跨电脑协作、全书合并和DOCX导出时因中文绝对路径失效。

本轮以全书 Markdown 审阅为主，不重建 Word。网页模型截图先进入本目录并回填 Markdown；上一版 DOCX 不随本轮图片更新。

## 目录规则

- `真题/`：广东高考真题及实验题图。文件名使用“年份-情境”命名，便于章节审阅。
- `项目/`：ESP32Blockly、数智育才网站、装置与脱敏作品截图。
- `实验/`：书中分析的真实实验装置、测量过程与失败记录图片。
- `网页模拟/`：数智育才网站高考真题模拟通过测试后的真实页面截图；文件名包含年份与情境。
- 后续新增图片必须先复制到本目录，再写入正文；不从 `分章稿/` 直接引用项目资源库绝对路径。
- 原始来源、题号、授权状态和正文用途必须登记。复制文件只为书稿管理，不改变原图版权与署名要求。
