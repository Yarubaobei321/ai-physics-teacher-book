# 高考题网页模拟台账

> 本表登记第二版使用的20道高考题、书中位置、本地页面和交付边界。20个模型已于2026-08-02在本地实现；尚未部署生产站，也尚未经过四位作者审核。

## 统一模型底座

页面共享原题边界、参数控制、动画与数据图、模型说明、回归测试、极端条件测试和 `?view=book` 截图模式。薄膜冲击是先行开发的独立页面；其余19个模型使用统一模型页和力学、传感器、电磁、波动场景模块。

验证口径分开记录：

- 薄膜冲击：10项独立自检。
- 其余19个模型：77项共享回归测试，覆盖公式、单位、原题锚点、参数边界、非有限状态和场景语义。
- 站点：页面生成一致性、结构测试、Astro 严格构建和20条正式路由检查。

## 截图与回填

- 书稿采用一题一图，共20张真实页面截图，统一保存到 `图片/网页模拟/`。
- 20张截图已由主代理按图书视图生成并回填；图片目录实际文件、全书 Markdown 引用和图片校验报告三者一致。
- 最新全书组装为18/18章、48张图片、缺失0、90,726个非空白字符，结果 `PASS`。
- 截图只能来自通过测试的本地模型。目录页、台账页、规划图和视觉占位图不算完成截图。
- 截图应保留足以理解题境、关键状态、主要参数和结果的区域，同时避免把内部验收提示带进读者正文。

## 证据边界

- “本地完成”只说明代码、模型测试、页面生成和本地构建通过，不表示已经部署到数智育才生产站。
- 网页模拟是理想化模型。参数、假设、适用范围和无解状态必须公开，不能冒充原题实测过程。
- 当前四位作者审核为0/4；题源表述、作者声音、图片授权和出版口径仍待人工确认。
- 当前没有课堂使用记录、学生反馈或学习成效数据，不从模型与截图推导教学效果。
