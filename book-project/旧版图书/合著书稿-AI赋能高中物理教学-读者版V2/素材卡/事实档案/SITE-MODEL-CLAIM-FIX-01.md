# 事实档案：网站首页模型范围错误与修订

- 来源：`项目资源库/数智育才网站/文档副本/docs-顶层文档/adversarial-site-review-2026-07-02.md`
- 当前等级：E1（审查与修订记录可追溯）；尚未在当前线上版本复测。

## 记录事实

2026-07-02全站对抗性审查记录：首页曾宣称模拟实验室包含“平抛、振动、电路”，但当时站点实际只有动量章节的六个模型。审查将该项判为事实性文案错误，并记录首页文案已改为“动量守恒、机械能转化、共速与离轨”。报告同时写明本批代码已落地并通过build/test。

## 可以进入正文的判断

- 网站的物理正确性不只在方程内部，也包括导航、首页和说明是否准确描述真实存在的模型。
- 生成式AI很容易根据“高中物理模拟实验室”的类别期待补出平抛、振动、电路等常见栏目；这些栏目听起来合理，却不能代替真实路由和可运行模型。
- 页面清单可以从构建产物或路由表自动生成，再与首页声明比对，形成“声明—实现”回归测试。

## 边界

- 本档案只证明2026-07-02审查记录载明发现并修订该问题，不证明当前线上站点仍与记录完全一致。
- 本案例不评价六个动量模型各自的物理正确性；模型内部验收仍需原题回归、极端条件和状态一致性测试。
- 学生姓名脱敏和评分改判属于第17章评价证据主线，不在第11章展开。
