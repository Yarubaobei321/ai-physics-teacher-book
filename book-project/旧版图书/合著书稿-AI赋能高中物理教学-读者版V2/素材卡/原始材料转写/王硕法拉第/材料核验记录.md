# 王硕法拉第实验材料核验记录

## 最重要的发现

当前第6章写过“后续方案加入齿轮传动和更稳定支架”，但两份docx和三份配套PPT都没有这条证据。源材料真正记录的迭代更具体：玻璃管内磁铁会翻转，指针变化太快，手机慢动作反复拍仍难抓最大值；Arduino能显示电压和磁场，却卡在转速测量；最后改用约30元的直流调速器、减速马达、微电压传感器和非接触转速仪。

这条真实失败史比“齿轮改进”更有生命力，也必须替换AI补出的版本。

## 单位冲突

曲线截图的纵轴写“微电压探头<mV>”，三张数据表的表头却写`E(V)`。这不是排版小事：如果曲线读数是毫伏，表中数值就不能直接当伏使用，相差1000倍。

当前目录没有原始Excel、CSV或传感器导出文件，不能靠猜测替它统一。正文应保留数值并明确“源文稿单位待核”，直到找到传感器型号、软件设置或原始导出。

## 磁铁个数不是磁通量

源文稿把磁铁个数增加当作磁通量变化增加的办法，这作为操作变量是合理的；但“磁铁数量成倍”不能推出线圈磁通量严格成倍。磁铁个体差异、排列、间距、磁路和线圈位置都会改变结果。原文误差分析也承认这一点。

因此该组数据可支持：在当前结构和范围内，感应电压代表值随磁铁个数近似线性增加。它不能单独证明$E\propto\Delta\Phi$，除非另测线圈位置的磁场分布或直接得到磁通量变化。

## 曲线代表值仍缺定义

曲线是正负交替的周期信号，而表中每个条件只留下一个正数。源稿说“截取稳定区域”“记录感应电动势大小”，没有最终确定这是正峰值、负峰绝对值、峰峰值还是周期平均。不同规则会得到不同斜率，也会影响各组可比性。

后续若取得原始曲线，应先固定时间窗和代表值算法，再重新计算。AI可以批量找峰，但不得替作者默默选择最线性的那一种。

## 正文生长方向

第6章应沿“实验为何一次次换工具”展开：

`玻璃管翻转 → 指针来不及读 → 慢动作仍漏峰 → Arduino转速测量受阻 → 光盘与调速器形成重复运动 → 微电压传感器留下曲线 → 数值表又暴露单位和代理变量问题`

读者最终拿走的不是“实验验证成功”，而是一套判断：装置解决了哪个旧问题，又引入了哪个新问题；控制输入、直接测量和理论量是否被混为一谈。
