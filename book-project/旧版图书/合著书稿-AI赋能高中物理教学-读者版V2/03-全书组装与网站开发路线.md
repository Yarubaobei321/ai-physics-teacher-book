# 全书 Markdown 组装与高考真题模拟开发路线

本文件记录内部流程、验证证据与阶段边界。读者正文只保留物理问题、实验与模型带来的认识，不写入版本、构建、审核和部署说明。

## 阶段一：完成十八章叙事骨架

1. 按总纲完成序言、五篇和18章，使全书能够连续阅读。
2. 每章确立一个核心矛盾和一条母案例叙事，不用空洞理论、重复量规或完整题解补字数。
3. 真题登记稳定 ID；实验设计、真实实施、网页模型和课堂效果分别记录。
4. 每章同步建立作者审核卡，事实、声音、贡献、来源和授权留给四位作者确认。

完成状态：18章、18张作者审核卡和20道主案例题源已经齐套；跨章物理、事实与阅读重复审读已经完成。四位作者尚未审核。

## 阶段二：用真实材料增厚

1. 从实验数据、失败记录、硬件制作、网页测试、作者经验和课堂证据中选择真正改变判断的材料。
2. 所有新增事实进入正文前必须有来源或事实档案；只能支持设计的材料继续写成设计。
3. 缺少实测、课堂或作者证据的章节保留缺口，不用推测性文字补量。

完成状态：已有材料已完成一轮吸收；运行、课堂、授权、作者签认和部分数据身份缺口继续保留。

## 阶段三：生成干净的全书 Markdown

主文件：`《智启格物：从高考题到实验、模型与智能创造》-全书.md`

组装规则：

- 按序言、第一篇至第五篇、第1—18章的顺序组装。
- 把分章稿中的 `../图片/...` 改写为全书文件可用的 `图片/...`。
- 保留标准 Markdown 表格和 TeX 数学语法。
- 检查标题层级、章节顺序、图片存在性、公式定界符和占位标记。
- 删除读者正文里的导出说明、版本演变、审核流程、证据 ID 和待授权清单。
- 直接改写模板化对比句和工作汇报式小标题。

当前主交付是根目录全书 Markdown 与 `导出/《智启格物》Markdown审阅指南.md`。本轮不重建 Word；上一版 DOCX 路径保留在 `导出/README.md`。

## 阶段四：建设20个高考真题模拟

目标项目：`/Users/yaril/个人文档/数智育才网站`

统一要求：

1. 范围以本书登记的20道高考题为准，不对题库530道题平均铺开。
2. 页面共享原题边界、参数控制、动画与数据图、模型说明、回归测试、极端条件测试和 `?view=book` 截图模式。
3. 每道题接入自己的物理状态、方程、事件、单位和边界条件。
4. 原题参数、极端参数与反例均需测试；页面还要经过浏览器、桌面和移动端检查。
5. 通过验收的真实页面才能生成书稿截图，规划页或占位图不能进入正文。

## 阶段五：Markdown 审阅与人工确认

1. 以全书 Markdown 和 Markdown 审阅指南作为本轮交付，不等待 Word 重建。
2. 先检查阅读感与读者正文边界，再检查物理链、实验可执行性、网页假设和图片清晰度。
3. 四位作者逐章确认亲历细节、事实、声音、贡献归属、图片来源与出版授权。
4. 作者意见合并后，再决定是否重建 Word 和进入出版排版。
5. 生产部署必须另获授权；部署完成后补真实网址、版本和回滚说明。

## 阶段门槛

- 全书 Markdown 未通过章节与图片校验，不作为完整审阅稿交付。
- 网页模型未通过物理测试和浏览器检查，不生成书稿截图。
- 本地模型完成不等于生产部署，也不等于课堂验证。
- 没有作者签认，不把当前稿件称为出版定稿。
- 没有真实课堂证据，不写“学生已经掌握”“课堂效果显著”等结论。
- 任何阶段均不以 AI 生成的理想数据冒充真实实验、学生作品或作者经历。
