## 物理模型复核

- [x] 同一介质、张力等条件近似不变时，频率增加由$v=\lambda f$对应波长减小，不把手抖频率直接写成波速决定因素。
- [x] 区分$y-x$波形图与$y-t$振动图，提出固定质点“一点同值”测试。
- [x] 简谐运动$a=-\omega^2x$的相位关系和$T/4$经过平衡位置的判断一致。
- [x] 受迫振动频率由驱动力频率决定；共振条件不由驱动力大小单独决定。
- [ ] 作者复核手机加速度传感器“表观加速度”措辞，按实际应用的软件接口区分是否已扣除重力分量。
- [ ] 作者复核主动降噪关于相位、幅度、延迟和空间位置的表述是否适合高中读者。
