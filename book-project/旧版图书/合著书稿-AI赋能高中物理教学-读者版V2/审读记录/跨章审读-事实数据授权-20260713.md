# 《智启格物》读者版V2跨章审读：事实、数据、实施状态与授权

> 审读日期：2026-07-13  
> 审读性质：第三位独立审阅者，只读核验  
> 覆盖范围：序言、18章正文、18张作者审核卡、`素材卡/主案例真题原件切片台账.md`、`素材卡/实验事实源/`、图片资产台账  
> 本报告只判断“现有材料能支持什么表述”，不判断课程方案本身是否值得实施。

## 一、总判断

读者版V2已经明显改善了第一版最危险的问题：绝大多数章节在章末主动区分了真题事实、项目文档、设计方案、待实施实验和学习效果；20道主案例有稳定ID和本地切片；18章均有审核卡；第7、14章开始使用结构化实验事实档案。这个方向是正确的。

但当前仍不能进入“真实材料增厚后即可出版”的状态，原因不是一般性的“还要补材料”，而是有五类硬阻断：

1. **至少第4、10、15、16章仍有设计方案或综合情境被写成已经发生的课堂。** 章末边界说明不能自动消除正文给读者造成的事实印象。
2. **作者身份存在明确冲突。** 全书作者名单为“丁龙、黄灿斌、严力耕、王硕”，但4张审核卡把黄灿斌写成“黄伟”，并把第15章主笔暂归黄伟。
3. **22幅当前正文图片的出版授权全部未清零。** 16幅真题图均为“待出版核权”，5幅ESP32Blockly截图为“待作者确认”，1幅学生作品复核页为“待学校与作者确认”。
4. **第17章涉及未成年人作品与过程材料。** 30/10/20/13等核心数字虽有项目内证据线索，但V2内没有逐项JSON路径、版本、校验日期、授权编号和受控保存责任人，暂不足以作为出版级可追溯证据。
5. **现有两份实验事实源顶层状态均为`inferred`。** 它们能证明“本地文档中有此描述”，还不能等同于“当前硬件、固件、网页或课堂已经现场复验”。

量化情况：18张审核卡中可直接检出的未完成复选项为143项、已勾选项52项；第5、14—18章还有大量未使用复选框的待办，因此143只是下限。当前真正清楚的不是“补证很少”，而是补证入口已经存在、但尚未完成作者签认和权利清零。

## 二、P0：不解决就不能升级为确定事实或进入出版稿

### P0-1｜第15章把尚未确认的课程配置写成“真实课堂”

**证据冲突：**

- 正文标题直接使用“36名学生、8个小组、16块板”，开头以实际教室语气叙述多组同时运行、设备绑定、传感器接反和教师逐组维修：`分章稿/第15章-36名学生8个小组16块板.md:1-7`。
- 正文称“课程配置为8组、每组两块ESP32”，并用稳定板/试验板叙述已经形成的课堂策略：同文件`:59-67`。
- 正文按“课前—15分钟—20分钟—30分钟—15分钟—10分钟”写出完整90分钟课堂，并在结尾称“项目就达到了本阶段目标”：同文件`:159-173`。
- 第14章预告“下一章将进入一间真实课堂”：`分章稿/第14章-从一束光到一条数据链.md:81-83`。
- 但第15章审核卡明确要求确认“36名学生、8组、每组2块板是已实施事实、计划配置还是混合状态”，并建议若未完整实施先做教师小样和两组试教：`审读记录/第15章-作者审核卡.md:14-18,35-42`。

**判定：** 当前正文已越过审核卡边界。标题、开场和时间流程会使读者理解为完整班级实录，章末“还不能证明学习效果”只能限制效果结论，不能解决“课堂是否发生”的事实问题。

**补证闸门：**

1. 先由责任作者书面选择：已完整实施 / 部分试教 / 课程配置方案。
2. 若为已实施，必须提供日期、年级、班级人数、分组、设备数、课时、教师、任务单、设备上线或健康检查记录、至少一组脱敏学生产物。
3. 若只有部分试教，正文标题和所有现场叙述统一降级，不得继续使用“真实课堂”和完成式时间线。

### P0-2｜第10章以“同一节课三个小组”开场，但没有课堂记录

- 正文断言“同一节实验课，三个小组得到三种结果”，并分别描述纸带组、曲面组和气垫导轨组的结论：`分章稿/第10章-机械能守恒三种实验与一个在线模型.md:3-9`。
- 后文继续以“三组学生”“全班比较”“证据会议”组织叙事：同文件`:89-103`。
- 审核卡却明确写“当前正文没有虚构具体数据和学生结论”，同时要求补三套实验原始数据、全班证据会议或公开课真实记录：`审读记录/第10章-作者审核卡.md:28-34`。
- 正文章末也承认公开课原始数据、学生纸带、全班比较记录和具体网页版本仍待补：`分章稿/第10章-机械能守恒三种实验与一个在线模型.md:107-111`。

**判定：** “三个小组得到三种结果”至少是未标明的综合情境，审核卡对正文状态的描述不准确。第二轮不能在此叙事上直接加数据，必须先确认它是一次真实课、三次不同实验的合成，还是纯教学构造。

**补证闸门：** 真实课需给班级、日期、组别、原始记录；合成情境需在正文明确标注，不得继续让读者误认同一课堂实录。

### P0-3｜第4章把设计目标写成学习已经发生

- 正文称“40分钟的基础课……学生能够区分速度与加速度……核心学习已经发生”：`分章稿/第04章-超重失重-体重秤安全带与智能电梯.md:142-150`。

**判定：** 这是从课程目标直接跳到学习结果。必须改成“目标是/可要求/拟观察”，除非补入学生前后作答、课堂记录或迁移任务证据。

### P0-5｜当前正文图片授权为0/22清零

- 图片规则要求每幅图登记原始来源、题号、授权状态和用途：`图片/README.md:1-10`。

## 三、P1：第二轮增厚前应完成，否则真实材料会继续混线

- 序言写“当学生真的搭起装置”，随后列举小车跑偏、电子秤延迟、铜管磁铁晃动等一组混合经验：`分章稿/序言-一道题为什么要重新变回真实世界.md:19-29`。这些可能来自多种经验，但目前没有逐项来源。

**建议：** 将“能够”改成“本章希望学生能够/可以要求学生说明”，或补真实作答。序言中的混合经验可保留文学表达，但作者需确认每个现象来自真实经验而非AI概括。

### P1-6｜黄正玉著作与全书方法命名缺正式引用和原创性核验

- 序言称“黄正玉教授把这种往返称为‘习题实验化’”，并评价其著作形成于多年检验：`分章稿/序言-一道题为什么要重新变回真实世界.md:23-29`。

### P1-7｜18张审核卡尚未形成统一的可清零台账

- 写作规则要求每张卡覆盖事实时间、题图来源、模型复核、装置数据、课堂声音、授权、贡献等：`02-写作与人工审核规则.md:71-84`。

- 目前可检出的143个未完成框只是下限，也没有责任人、证据路径、截止状态、签认日期。

**建议：** 第二轮建立唯一补证总表，审核卡继续保留分章视图，但不得各自维护相互冲突的状态。

### P1-8｜只有第7、14章有结构化实验事实源，关键实践章仍靠散文和审核卡

第4、6、10、15、17章分别涉及智能超失重仪、电磁装置、三套机械能实验、ESP32Blockly、学生评价数据，风险和证据密度均高，却没有独立事实源。应先建档再扩写，避免第二轮把照片、作者回忆、项目文档、课堂数据混在同一段中。

## 四、P2：不阻断第二轮，但建议在出版终审前补齐

1. **切片与数据文件版本化。** 为20个真题切片、2个事实源、项目截图记录文件哈希、生成脚本版本和最后核验日期。
2. **图片元数据最小化。** 出版复制前检查并清除不需要的EXIF、浏览器地址、设备密钥、网络信息和本地路径；管理台截图当前未见学生身份，但仍需作者确认软件与学校标识使用边界。
3. **统计口径固定。** 第3章的530题、124真题、406模拟题与12道实验真题应绑定索引版本；更新题库时不得静默改变正文数字。证据见`审读记录/第03章-作者审核卡.md:12-18`。
4. **作者回忆单独标记。** 后补课堂故事区分“当时记录”“作者回忆”“后续复核”，不得把回忆改写成同期逐字实录。第17章已给出这一原则：`分章稿/第17章-三十份AI网页作品的两轮审查.md:116-124`。
5. **第三方平台与商标。** DeepSeek、Blockly、ESP32、浏览器界面和学校/实验室标识在正式版中统一核对名称、商标和截图许可口径。
6. **效果主张单列。** 若第二轮加入成绩、完成率、故障率或能力变化，须另列样本、任务、评价工具、时间范围和替代解释，不得从项目功能或一次公开课推断。

## 六、建议采用的统一证据状态

第二轮建议所有事实统一使用以下状态，避免继续用一个“已核验”覆盖不同证据强度：

| 状态 | 含义 | 可写入正文的语气 |
|---|---|---|
| `source_verified` | 题目、文档、图片或代码原件存在且定位准确 | “原件/文档记载……” |
| `runtime_verified` | 当前指定版本在指定环境实际运行并留下测试证据 | “在版本X、设备Y上已验证……” |
| `implemented` | 装置或课程实际实施，时间、对象和记录齐全 | “在某次实施中……” |
| `observed` | 有课堂观察或学生产物，但不能推出普遍效果 | “本次观察到……” |
| `effect_supported` | 有明确样本、任务、比较和评价方法支持效果判断 | 按研究范围下结论 |
| `author_recollection` | 作者后续回忆，非同期原始记录 | “据作者回忆……” |
| `designed` | 由真实材料推导出的方案，尚未实施 | “可设计为/本书建议……” |
| `pending` | 证据不足或存在冲突 | 不进入确定事实；保留待补或删除 |

## 七、退出条件

完成第二轮补证不等于把所有设计都做一遍。可以保留未实施的好方案，但必须满足三条：

1. 正文语气与证据状态一致；
2. 每项确定事实能回到题源、装置、数据、代码、作品或作者签认；
3. 图片、学生材料和贡献归属在出版前完成授权、脱敏与责任人确认。

在P0-1至P0-6未清零前，不建议把读者版V2称为“事实与授权已核验稿”；较准确的状态仍是“第一轮叙事骨架＋第二轮补证入口已建立”。
