# 第二版写作与人工审核规则

## 一、读者前提

默认读者是一线高中物理教师、教研员、师范生和有实验兴趣的高中生。读者熟悉高中物理基本概念和常规实验，但不默认掌握Python、Web Serial、ESP32、传感器协议、AI提示设计或教育研究术语。

技术概念必须在第一次改变教学决策时解释。若一项技术只需要会用，不需要理解底层，不在正文展开工程细节。

## 二、章节写法

每章不套固定六段式，但必须完成以下认识过程：

1. 让一个具体问题发生；
2. 说明原办法为什么不够；
3. 展开一次真实尝试或基于真实材料的设计；
4. 保留异常、失败、误判或模型冲突；
5. 用物理解释把材料组织起来；
6. 说明AI具体参与了哪一段；
7. 回到原题、变式或新的创造。

这些功能可以融入连续叙述，不作为七个固定小标题。

### 两轮写作边界

- **第一轮**：补齐十八章可连续阅读的叙事骨架。保留足以支撑理解的题境、关键关系和案例转折，不嵌入真题原件与答案完整版，不以重复解释追求目标字数。
- **第二轮**：结构稳定后，再按审核卡补真实题目原件、实验数据、失败记录、硬件制作、网页测试与截图、作者经验和课堂证据。
- 第一轮的“完整”指全书叙事完整，不指每章材料已经出版定稿。

## 三、语言约束

- 开头500字内出现具体对象、动作、数据或问题，不从宏观时代背景开始。
- 原则性结论尽量延迟，让材料先出现。
- 读者正文默认不用“不是A，而是B”“并非A，而是B”“不在于A，而在于B”“不在A，而在B”等对称裁判句，直接写结论、原因、条件和证据。全书组装时把这类句式作为语体阻断项检查。
- “教师可以、学生需要、应当、必须”只用于真正的操作和安全要求。
- 三个以上完全平行的项目才使用列表；需要因果和转折时写成段落。
- 同一形状的数据需要比较时才使用表格。
- 不为了显得有方法而不断命名“三层、四步、五问”。
- 作者第一人称只用于可核验经历；AI不能代作者发明回忆。
- 小标题应让读者立即看见现象、矛盾或收获，避免“AI怎样帮助……”“本轮完成了……”这类工作汇报式表达。

## 四、读者正文与内部文档分层

- 面向审稿人交付的全书 Markdown 必须能够直接作为书籍连续阅读。
- 导出日期、版本号、组装路径、审核进度、证据 ID、待授权事项和作者分工只进入 `README.md`、`审读记录/`、`素材卡/` 与 `docs/WORK_HANDOFF.md`。
- `分章稿/` 章末来源与证据边界供内部核验；全书读者版自动排除这些编务段落，题源另以“本章真题与解析”呈现。
- 读者版验收同时检查：内部提示语为零、模板化对比句为零、图片引用全部存在、章节18/18、公式和占位标记无误。

## 五、题目使用

- 必须登记年份、地区、题型和专题ID。
- 第一轮只概述推动叙事所需的题境与关键条件，登记稳定ID，不嵌入题库「解析版」原件切片和答案完整版。
- 第二轮再决定哪些主案例需要嵌入原件、解析或局部题图；避免同一题在多章重复展开。
- 非主案例的提及题可概述题境，并交叉引用其主要叙事章节。
- 原题图注明来源，出版前核对使用边界。
- 同一真题跨专题重复收录时只计一次。
- 题目不是章节终点。至少向实验、模拟、硬件或模型审查中的一项推进，再回到变式。
- 精校稿符号缺失时，优先依据题图标注与原文 DOCX 回填；仍无法核验处标注「待原卷核验」，禁止猜测公式。

## 六、实验与硬件

实验必须说清研究对象、直接测量量、间接计算量、变量控制、操作步骤、误差和安全。硬件必须区分：设计设想、功能已实现、真实测量已完成、课堂已经使用、学习效果已经证实。

AI可以完成：器材方案比较、仿真代码、数据清洗建议、拟合与绘图、故障假设、变式生成、模型反例。AI不能替代：真实装置验收、传感器校准、数据真实性确认和课堂效果判断。

## 七、配图

图片按论证功能分为五类：

1. 题境图：帮助还原题目中的物理世界；
2. 装置图：说明结构、接线、测量链或运动关系；
3. 数据图：呈现原始数据、处理结果、误差或模型差异；
4. 版本图：比较修改前后、错误与修正；
5. 示意图：解释抽象关系，必须标明“示意”。

真实题图和项目图不进行风格化改绘以冒充原证据。AI生成图不出现虚构学生、虚构课堂、虚构仪器读数或虚构数据曲线。

所有正文图片必须复制到本书 `图片/` 目录并登记原始来源，分章稿统一使用 `../图片/...` 相对路径。禁止在读者正文中直接引用项目资源库绝对路径；全书组装时再按最终Markdown位置自动改写路径。

## 八、每章作者审核卡

正文完成后，在 `审读记录/` 建立同名审核卡，至少包括：

- 事实与时间；
- 题目与图像来源；
- 物理模型与计算复核；
- 装置、代码和数据状态；
- 真实课堂声音补充；
- 图片、学生作品和第三方材料授权；
- 作者贡献与署名；
- 可删除的AI腔、模板句和重复解释。

审核卡不进入读者正文。
