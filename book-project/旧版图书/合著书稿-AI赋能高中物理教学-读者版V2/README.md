## 全书方法

> **从题到物，虚实互证，由物返题。**
>
> 把纸面题境还原成可观察、可操作的物理世界；用实验、传感器、仿真与 AI 形成可检验的证据和模型；再回到变式、高考题与新创造中检验理解。

## 读者正文边界

- 正文直接进入对象、行动、现象或问题，不解释初稿、版本、导出、材料整理和审核流程。
- 证据等级、开发状态、图片授权、作者分工和待核事项放入本目录的内部文档。
- 尽量不用“不是A，而是B”“不在于A，而在于B”等对称裁判句，直接写明结论、条件、差异和证据。
- 小标题呈现读者真正关心的现象、冲突或结果，不使用“AI怎样帮助……”一类工作汇报式标题。

这些要求已写入工作区 `AGENTS.md`，后续改写应持续遵循。
