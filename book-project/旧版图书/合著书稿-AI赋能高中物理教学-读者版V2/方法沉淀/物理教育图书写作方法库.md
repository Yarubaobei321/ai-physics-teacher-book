# 物理教育图书写作方法库

> 这份文档沉淀《智启格物》第二版写作与三路独立审读中可迁移的方法。它服务后续章节修订和最终`physics-education-book-writer`技能，不替代本书的具体问题台账。

## 一、三份独立审读怎样分工

原始审读报告全部保存在`审读记录/`：

1. `跨章审读-物理公式真题-20260713.md`：查受力、系统边界、守恒条件、公式符号、单位、真题ID和答案回归。
2. `跨章审读-阅读重复主落点-20260713.md`：查真实母案例、连续阅读、标题密度、重复案例、唯一主章和工作台语言。
3. `跨章审读-事实数据授权-20260713.md`：查设计与实施、数据追溯、作者身份、学生隐私、图片权利和证据强度。

三路必须独立先读，再由主代理裁决。物理正确不能替代事实真实，事实真实不能替代可读，叙事漂亮也不能替代授权与隐私边界。

## 二、两轮写法

### 第一轮：建立可连续阅读的叙事骨架

每章先满足六件事：

- 一个真实问题，不用抽象主题开场；
- 一个可追溯母案例，能承担本章主要转折；
- 一条连续事件线，公式和方法在解决困难时出现；
- 一个明确的物理判断变化；
- 一个通向下一章的问题；
- 一张独立审核卡，工作台信息不混入读者正文。

第一轮不追逐总字数，不用更多标题、表格、清单和“AI可以/不能”句式填充篇幅。

### 第二轮：只增加真实价值

一次扩写至少新增一种可核验价值：题源、原图、实验步骤、器材参数、标定、原始数据、失败记录、硬件制作、网页模型、测试、作者判断变化或可迁移任务。

若新段落只增加解释、同义归纳或管理型清单，应删去或留在作者工作台。

### 第二轮使用“材料生长法”

把原始材料视为根，全书统领问题视为主干。物理推导、实验、误差、模拟、硬件、失败排查、教学任务和迁移是枝条；必要背景是叶片；读者能带走的实验、网页、原型、任务单、判断方法和新问题是果实；跨章审读负责修剪。

30万字不拆成18个章节字数指标。字数不足时，返回素材库寻找新的题源、数据、标定、失败、装置、代码、测试、判断变化和变式，不扩写已有观点。

每段新增内容先过四问：

1. 从哪份原始材料长出来？
2. 增加了什么新的观察、计算、装置、冲突或判断？
3. 最终怎样回到本章中心问题？
4. 是否只能放在本章，而不能原样搬进任何AI教育文章？

材料生长图是工作台，不是统一目录。先允许案例向多个方向充分生长，再按唯一主落点、叙事节奏和证据强度剪裁。

## 三、真实母案例的最低门槛

母案例至少要回答：

- 来源在哪里；
- 版本或日期是什么；
- 哪些事实已核对；
- 哪些原因仍是推断；
- 正文是否可能反查个人；
- 它为什么只能在本章完整展开。

构造反例可以解释方法，但不能冒充真实母案例。第11章原“初速度为零仍斜飞”的平抛页和第13章原“1.20/0.73”异常数据，都是好反例，却因没有来源而不能承担第一轮退出条件。替换方式是：真实材料负责发动，构造反例负责拆解。

## 四、证据状态决定叙述语气

| 状态 | 含义 | 正文语气 |
|---|---|---|
| `source_verified` | 题目、文档、图片、代码或表格原件存在且定位准确 | “原件/文档记录……” |
| `runtime_verified` | 指定版本在指定环境运行并留下测试 | “在版本X、环境Y中验证……” |
| `implemented` | 装置或课程实际实施，时间、对象和记录齐全 | “在某次实施中……” |
| `observed` | 有课堂观察或学生产物，不能推出普遍效果 | “本次观察到……” |
| `effect_supported` | 有样本、任务、比较和评价方法支持效果 | 在研究范围内下结论 |
| `author_recollection` | 作者事后回忆，不是同期记录 | “据作者回忆……” |
| `designed` | 基于真实材料形成的方案，尚未实施 | “可设计为/本书建议……” |
| `pending` | 证据不足或冲突未解 | 不写成确定事实 |

一句“章末待补”不能抵消正文的完成式叙述。标题、开场、时间流程和结果句都要与证据状态一致。

## 五、物理与公式清零方法

### 先查对象，再查公式

每个公式必须同时登记：研究对象、过程、正方向、直接测量量、忽略条件、单位和适用事件。只复算数值不够。

典型错误包括：

- 受力漏项：安全带敏感球若漏掉重力，会把接触力合力误写成水平；
- 对象不清：蹲起方程中的加速度应是人体质心加速度；
- 符号口径混用：势能的有符号变化量与“势能减少量”不能共用`ΔEp`；
- 测量模型越界：同高两次速度差只有在忽略非碰撞耗散、明确只计平动动能时，才能估计碰撞损失；
- 数值链缺参：答案正确也要在首次代入前列全参数；
- 题问未回收：章首提出的真题小问必须在事件线中闭合。

### 真题至少通过三点核对

`本地题源切片（解析版） → 官方原卷或权威排印 → 正文模型与数值`

解析版切片用于追溯，不等同官方原卷。切片脚本要能稳定处理终点污染、术语漂移、公式和图片保留，并把校勘写进索引。

## 六、重复案例的唯一主落点

同一案例可以跨章出现，但只能有一个完整主章。其他章节只保留一种功能：交叉引用、方法抽取、迁移测试或评价调用。

判断唯一主落点的四问：

1. 哪一章拥有完整题境、装置、数据和认识转折？
2. 删除其他章节的重复解释后，其独立任务是否仍成立？
3. 同一公式或数值是否被重新推导超过一次？
4. 读者想回查案例时，能否只去一个主章？

建立“案例—唯一主章—其他章允许功能”矩阵后，先删重复，再扩写真实材料。

## 七、减少AI拼装感

高频风险信号：

- 每两三百字一个标题；
- 连续出现“三步、四层、五问”；
- 反复使用“不是……而是……”；
- 每节都写“AI可以……但不能……”；
- 用“最小闭环、证据包、台账、契约”替代人物、器材和事件；
- 在读者正文暴露“第一轮、第二轮、待回填、截图模式、稳定ID”等生产语言。

修订动作：合并标题，让一次事件连续发展；用真实失败替代抽象禁令；让作者先犯判断、再被证据改变；管理信息移入事实档案、审核卡和修订台账。

## 八、实验数据不整齐时的写法

先保留原始表，再调查：定义、单位、录入、空值、设备状态、原始波形、视频和重复性。统计离群不等于物理错误。

尤其警惕两类“漂亮化”：

- 空值被公式变成0并进入拟合；
- 软件自动删除偏离点，却不留下动作、理由和前后数量。

实验事实档案必须把“表内可见事实”和“原因解释”分成不同状态。原因没有同期记录时，宁可保持`pending`。

过程性命题不能由单帧图片独自证明。图片可以证明器材形态、某一时刻的位置和画面中可见对象，却不能自动证明“停止出流”“完成碰撞”“保持匀速”或“滤波有效”。审查时应先确定真正要追踪的事件，再寻找视频帧序列、时间戳、原始数据或重复记录。

第4章漏水瓶给出了一个可迁移的例子：画面中仍有水滴，不等于释放后仍有新水穿过孔口。早先离孔的水滴、手的挤压和释放过渡都可能留在单帧里。正确的观察对象是孔口附近的新增出流，而不是整个画面是否“还有水”。

单位冲突不能由AI“顺手规范”。第6章法拉第实验的曲线纵轴标mV，数据表却标V；若没有传感器原始导出、型号或软件设置，必须保留冲突和源数值，不能凭数值大小猜一个更像真的单位。1000倍差异足以改变装置量程、信噪比和可行性判断。

操作变量也不能自动升级为理论量。磁铁个数、PWM值、档位、砝码个数都容易控制，却未必分别等于磁通量、实际转速、真实加速度或标准力。正文应先写“E随磁铁个数的经验关系”，取得标定后才写“E与$\Delta\Phi$的关系”。

## 九、网页模型的验收顺序

网页统一底座与逐题模型分开。逐题模型至少检查：原题回归、单位、零值、极端参数、守恒条件、事件切换、动画/公式/图表共享状态、桌面和移动端、截图可读性。

“页面能运行”和“物理正确”是两个闸门。截图只能来自通过测试的页面。

## 十、AI独立完成与作者后审的边界

本次任务由AI独立完成正文、事实档案、内部审读、网站模型、截图和插图版，不等待作者逐项确认。

最终另交付面向作者的全书大纲、书稿介绍和终审清单。作者事实核实、作者声音与贡献签认、图片和学生材料最终授权属于交付后的人工阶段，不作为本次任务阻塞条件。

## 十一、进入技能的内容

最终技能应包含：

- 两轮写作流程；
- 章节母案例检查；
- 证据状态与语气映射；
- 物理公式和真题清零；
- 实验事实档案；
- 跨章唯一主落点；
- AI腔与工作台语言扫描；
- 网页模拟测试闸门；
- 面向作者的交付模板。
- 材料生长图、四问剪枝和全书内容健康度统计。

本书具体学生身份、受限链接、未确认作者回忆和未授权图片不得固化进通用技能。
