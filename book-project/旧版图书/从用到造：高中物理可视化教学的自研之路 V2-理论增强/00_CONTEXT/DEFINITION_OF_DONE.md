# 完成标准

## 理论研究专家

- 技能采用项目级可发现名称 `physics-visualization-ai-researcher`。
- `SKILL.md` 不超过 500 行，详细理论与模板采用渐进加载。
- 只有一个带版本号的权威模型清单，不保留互相竞争的旧模型。
- 默认输出围绕高中物理可视化、AI 协作自研和教师“从用到造”；通用学习科学不得占据主体。
- 输入、来源状态、理论主张、证据边界、输出格式与失败路由均可执行。
- 引用候选必须给出 LIT-ID 或原始来源、锚点、核验状态和可说上限。
- 技能不模仿《聪明教物理》作者声音，不复制其案例、量表、流程图或标志性措辞。

## 蒸馏研究

- 六个研究维度均有独立落盘文件和实际阅读清单。
- 六维必须分别覆盖：可视化理论谱系、物理可视化形态、AI 辅助创造、验真与治理、从用到造方法论、十二章扩展地图。
- 明确区分原始来源、二手转述和研究者推断。
- 至少保留两组理论张力或失效边界，不生成万能理论清单。
- 受版权保护的全文不复制进技能包，技能只保存派生研究、来源索引和路径。
- 十二章扩展地图为每章标明独有理论问题、精确插入位置、引用类型、跨章去重方式和建议新增字符区间，并给出全书总增量区间。
- 字数增长来自新增定义、机制、方法、技术链、项目证据或适用边界；同义改写和跨章重复不计为有效增量。
