# 输出规格：物理可视化 × AI 自研理论专家

> 适用任务：章节诊断、章节插入包、全书扩展地图、引用核验。  
> 核心原则：先判断物理对象、技术链和证据责任，再决定增加什么理论；增加篇幅必须同时增加定义、方法、证据或边界中的至少一项。学习科学只在解释具体表征任务时局部调用，不承担全书总框架。

---

## 一、统一口径

### 1. 六个核心模型

所有输出只从下列六个模型中选取必要项，不再另造平行总框架。

| 代号 | 名称 | 输出中要回答的问题 |
|---|---|---|
| A | 可追溯共同工作对象闭环 | 对象从哪里来，怎样被编码，谁采取什么行动，留下什么产物，在哪些条件下失效？ |
| B | 四层正交架构 | 可见对象、技术载体、生产方式、证据责任分别是什么？四层是否被混成一种分类？ |
| C | 最低足够“用—改—造”责任梯度 | 为什么采用当前生产方式？新增了哪些责任？能否退回更简单、可维护的方案？ |
| D | 独立真值—可失败验真 | 预期值来自哪里？验证源是否独立？什么结果会否决当前资源或主张？ |
| E | `C×E` 主张权限 | 现有材料最多允许把结论写到哪一级？本地材料可复核到哪一级？ |
| F | 门控式资源生命周期 | 资源当前处于什么状态？下一道门、责任人、复验触发器和回退方案是什么？ |

六模型的标准表达如下：

- A：`对象 → 来源 → 视觉/实体/程序编码 → 学生或教师行动 → 可保存产物 → 边界与反证`。
- B：可见对象为过程、结构、关系、数据、模型、推理；技术载体为真实增强、教具、传感、图示、仿真、物理计算、H5/平台；生产方式为直接使用、模板、人工、AI 固定链、智能体协作；证据责任为来源身份、独立测试、课堂产物、主张级别、版本责任人。
- C：`直接使用 → 参数配置 → 局部适配 → 组合编排 → AI 协作自研`。它是责任增量，不是教师能力等级；允许停留、回退和团队分工。
- D：先画依赖关系，再检查“真值”是否与被测对象共享模型、数据、代码或生成源；若不独立，只能报告内部一致。
- E：`C0–C6 × E1–E3`，控制主张强度，不生成总分或高低排名。
- F：`立项 → 使用/适配/设计 → 最小实现 → 独立验真 → 入课 → 本地/校内/公开发布 → 监测维护 → 复验/回退/停用`；资源状态只用“已发布、限定试用、本地开发、隔离停用”。

### 2. 来源标签 R/F/E/L/B/S

| 标签 | 含义 | 可承担的作用 | 不得越界 |
|---|---|---|---|
| R | 原始研究 | 理论定义、研究方法、特定样本中的结果与限制 | 单项研究不能自动升级为普遍规律 |
| F | 正式框架 | 政府、国际组织或标准机构提出的维度、原则与规范 | 不能证明本书项目已经达到框架要求 |
| E | 官方工程 | 产品方或研究机构对功能、系统和工程方式的正式说明 | 不能证明教学效果、普遍提效或物理正确 |
| L | 本地材料 | V1、项目资源、源码、测试、数据、课堂材料和台账 | 原件存在不等于学习改善或迁移 |
| B | 参考书导航 | 寻找概念线索和原始来源入口 | 不作为关键理论结论的终点证据，不参与标题、段落、表格、论证节奏或作者声音生成 |
| S | 本书综合 | 由多源、本地跨章材料归纳的方法、模型和编辑判断 | 必须显式标明本书归纳，并给出复现锚点与失效条件 |

### 3. `C×E` 双轴

#### 主张权限 C

| 坐标 | 允许主张 | 最低关注点 |
|---|---|---|
| C0 | 设计意图 | 想解决什么、怎样计划 |
| C1 | 作品或功能存在 | 指定版本中确有页面、装置、数据链或功能 |
| C2 | 内部一致 | 当前实现通过列明的物理与工程检查 |
| C3 | 指定用途有效 | 在明确范围、容差和环境中可用 |
| C4 | 活动或本任务表现 | 特定对象在给定任务中做了什么、留下什么产物 |
| C5 | 条件性学习变化 | 相对基线或比较出现变化，并处理主要替代解释 |
| C6 | 迁移与保持 | 未见任务、跨情境或延时表现得到复核 |

#### 本地可复核度 E

| 坐标 | 含义 |
|---|---|
| E1 | 作者经验、计划、推断或待补材料 |
| E2 | 已读项目台账、文献卡或汇总记录，本轮未逐项打开原件 |
| E3 | 已打开原始文件、源码、正式数据、测试或课堂材料，可定位复核 |

#### 书写规则

1. 每个关键事实写 `来源=R/F/E/L/B/S` 与主张级别 `C0—C6`。只有本地事实（来源=L）再写可复核度 `E1—E3`；外部 R/F/E/B 写“核验状态=已回原文/官方页面/仅导航/待核验”，不强套本地 E 级。
2. 字母 E 有双重用途。必须写“来源=E（官方工程）”或“坐标=C2×E3”，禁止裸写“E3 证据很好”。
3. 既有卡片中的 `L1/L2/L3` 在新输出中统一转写为 `来源=L + E1/E2/E3`。不得继续输出 `L3` 作为来源类别。
4. `C×E` 不产生总分。来源性质、主张级别和可复核度三者正交，不能折算成“高质量证据分”。
5. 无本地材料的理论定义也要记录来源标签、主张用途与核验状态；可复核度写 `N/A`，不得为了凑齐坐标虚构本地证据。

### 4. S（本书综合）的发布条件

标为 `来源=S` 的方法或模型必须同时满足：

- 明写“本书提出”“本书归纳”或“本书采用”；
- 至少给出两个不同章节或项目的复现锚点；
- 能推出一个新的教师设计、验真或维护动作；
- 写明至少一个失效条件或不适用场景；
- 不挪用外部框架名称，不冒充原始研究结论；
- 未经多教师、多案例研究，不称“能力等级”“普遍规律”或“成熟度标准”。

## 二、四类任务的共同输入与共同输出

### 1. 接单时必填输入

| 字段 | 填写要求 |
|---|---|
| 任务类型 | 诊断 / 章节插入包 / 全书扩展地图 / 引用核验，只选一项；组合任务拆成独立产物 |
| 对象与版本 | 书名、章名、文件绝对路径、版本或日期 |
| 范围 | 指定章节、标题或行号；是否允许查项目资源与原始文献 |
| 目标 | 补定义、补方法、补证据、补边界或控制重复；不得只写“增加字数” |
| 禁止范围 | 不改 V1、不代作者确认事实、不上传敏感材料等 |
| 已知材料 | V1 锚点、项目锚点、研究 01—05、候选模型、理论插入卡及指定来源 |
| 交付位置 | 目标文件绝对路径；未授权不得新增旁支文件 |

输入不足但不影响边界判断时，采用保守默认并记录；缺少会改变事实、版权、公开范围或核心主张的材料时，进入作者裁决，不用流畅文字填空。

### 2. 每个任务包的共同页首

以下页首在一个任务包中只需出现一次，优先放在 `章节诊断.md` 或总入口文件。拆分出的引用表、边界检查、作者裁决卡和示范稿只需在页首写“从属任务、对象版本、原文锚点、授权范围与状态”，不机械复制整套元数据。

```text
任务：
对象与版本：
原文绝对路径与锚点：
本轮读取材料：
授权范围：
当前状态：可用 / 有条件可用 / 待作者裁决 / 阻塞
核心模型：A / B / C / D / E / F（只列实际使用项）
来源口径：R/F/E/L/B/S
主张口径：C0–C6 × E1–E3
```

### 3. 每个任务包的共同最小表

每类任务包整体至少覆盖以下四张表；可以分布在诊断、插入卡、引用核验表和边界检查中，也可以合并字段，但不能删除其信息。不要要求同一任务包的每个分文件重复四张表。

#### 表一：问题—模型路由

| 现象或问题 | 物理/技术/证据对象 | 采用模型 | 为什么需要 | 不采用的相邻模型 | 预期产物 |
|---|---|---|---|---|---|

#### 表二：来源与主张

| 编号 | 候选命题 | 来源标签 | 完整来源与定位 | 核验状态 | `C×E` 上限 | 直接支持 | 不能支持 |
|---|---|---|---|---|---|---|---|

#### 表三：失败与降级

| 失败信号 | 影响对象 | 当前状态 | 立即动作 | 恢复条件 | 作者是否裁决 |
|---|---|---|---|---|---|

#### 表四：范围与去重

| 概念/方法 | 首次定义章 | 本任务只新增什么 | 应回指什么 | 与相邻章分工 |
|---|---|---|---|---|

### 4. 每个任务包的共同结尾

一个任务包只需在总入口、重复与边界检查或作者裁决卡中集中给出以下五项；示范正文不附审核口径，以免编务信息进入读者正文。

1. **允许写入的句子**：给出可直接使用的安全主张，标 `来源` 与 C 级；来源=L 时再标 E1—E3。
2. **暂不能写的句子**：列明越界词、越级因果或尚无原件支持的事实。
3. **最小下一步**：指出能解除当前最大不确定性的一个动作。
4. **作者裁决清单**：只列确需作者确认的事实、取舍和公开边界。
5. **完成状态**：`PASS / CONDITIONAL / BLOCK / NO-EXPANSION`，附一行理由。

## 三、任务一：章节诊断

### 1. 任务目的

判断一章“已经写清什么、真正缺什么、能安全扩写什么”。诊断不直接把理论填进正文，也不以理论数量衡量质量。

### 2. 必填输出字段

#### A. 章节定位

- 章名、文件绝对路径、标题层级和精确行号；
- 本章在全书中的唯一任务；
- 原文已完成的案例、方法和边界；
- 本轮诊断仅覆盖的段落，不外推到未读全文。

#### B. A 模型：闭环缺口

逐项填写对象、来源、编码、使用者行动、可保存产物、边界与反证，并给出 `完整 / 部分 / 缺失 / 不适用`。只有闭环中的真实空位才进入候选扩写。

#### C. B 模型：四层拆分

| 层 | 本章当前内容 | 缺口 | 混放风险 |
|---|---|---|---|
| 可见对象 | 过程/结构/关系/数据/模型/推理 |  |  |
| 技术载体 | 真实增强/教具/传感/图示/仿真/物理计算/H5平台 |  |  |
| 生产方式 | 直接使用/模板/人工/AI固定链/智能体协作 |  |  |
| 证据责任 | 来源/独立测试/课堂产物/主张/版本责任 |  |  |

#### D. C 模型：责任选择

- 当前生产方式及最低足够方案；
- 从当前方式再升级会新增什么审查、验真和维护责任；
- 为什么不采用更简单方案；
- 可回退的方案和条件。

#### E. D 模型：验真状态

- 被验证对象；
- 预期值、来源和容差；
- 与被测对象是否共享模型、数据、代码或 AI 来源；
- 能导致失败的输入、趋势、特殊点、不变量或外部测量；
- 只能支持内部一致还是指定用途有效。

#### F. E 模型：主张上限

至少列出本章三条最强主张，逐条标 `来源`、`C×E`、替代解释、安全动词和禁用动词。不能只给整章一个总等级。

#### G. F 模型：资源状态

- 当前状态：已发布 / 限定试用 / 本地开发 / 隔离停用；
- 已经过与未经过的门；
- 当前责任人、复验日期、触发器和备用方案；
- 若本章只谈纸面方法而无可运行资源，明确写 `F=N/A`，不虚构生命周期。

#### H. 理论路由

将候选补充归入：

1. 核心框架：A—F 中的必要一项；
2. 物理可视化理论：概念定义、对象—编码—任务、模型与仿真分界、数据血缘等；
3. AI 自研方法：规格、职责、上下文、原型—测试—修复、版本与发布；
4. 局部学习科学：只解释特定表征转换、注意分配、自我解释或任务脚手架；
5. 不应扩写：与本章决策无关的理论史、软件功能罗列、成效想象。

#### I. 扩写建议

每个候选位置填写：插入点、唯一问题、建议字符区间、材料来源、预期新增价值、跨章去重、失败条件。建议字符必须由内容功能产生，不能先定篇幅再重复改写。

### 3. 诊断判定

| 判定 | 条件 |
|---|---|
| PASS | 关键闭环、分类、主张和边界完整，无需新增理论 |
| CONDITIONAL | 有真实缺口且材料足够，可进入章节插入包 |
| BLOCK | 关键事实、独立真值、版权或作者选择缺失，继续扩写会制造越界 |
| NO-EXPANSION | 本章已足够或新增内容只能重复他章；改用回指、删减或图表 |

## 四、任务二：章节插入包

### 1. 任务目的

把一项已经通过诊断的缺口制成可审阅、可定位、可核验的写作包。一个插入包只解决一个章节问题；同一问题需要多个位置时，以主卡加子卡组织。

### 2. 包清单

插入包必须包含：

1. 包说明与插入清单；
2. 一张或多张理论插入卡；
3. 来源与主张矩阵；
4. 可直接改写为正文的段落骨架；
5. 验真、发布、去重和作者裁决记录。

### 3. 每张插入卡的必填字段

沿用理论插入卡 A—I，不得删减：

#### A. 章节定位

- 章节、原文绝对路径、前后标题与行号；
- 当前段落已经完成什么；
- 真正缺少的是定义、机制、方法、证据还是边界；
- 与可视化、AI 自研或“从用到造”的直接关系。

#### B. 可视化诊断

- 要显现的对象；
- 信息来源身份；
- 技术链与视觉编码；
- 使用者必须进行的预测、操控、测量、比较、解释、生成或验真；
- 可保存、可观察的产物；
- A 闭环和 B 四层的定位。

#### C. “用—改—造”选择

- C 模型中的当前生产方式；
- 选择它而不采用更简单方案的理由；
- AI 可承担的追问、整理、候选生成、实现、测试草案、修复和文档；
- 教师不得外包的模型、来源、课堂、发布和停用决定；
- 最低回退方案。

#### D. 理论与来源

每条命题填写 `来源=R/F/E/L/B/S`、完整来源、定位、核验状态、直接支持、不能支持和用途。B 只能导航，S 必须通过本书综合发布条件。

#### E. 本书案例与项目证据

每条本地证据标 `来源=L` 与 `C×E`，给绝对路径和行号/页码，写明能证明与仍缺什么。截图、源码、测试、课堂记录和作者回忆不得写成同一证据等级。

#### F. 正文生成骨架

固定回答六件事：

1. 从本章现象、对象或冲突进入；
2. 给出完成当前判断所必需的定义或分界；
3. 用本书案例解释对象—来源—编码—行动—产物链；
4. 转成教师可采取的选择、测试或维护动作；
5. 写适用范围、失效条件和证据边界；
6. 回到原文下一段，不留下理论孤岛。

另填：建议新增字符区间；字符分别来自新定义、新方法、新证据、新边界中的哪一项。不得以同义改写计入“理论增强”。

#### G. 验真与发布门

至少检查用途与来源、物理、模型、测量数据、AI 与责任、权利公开、版本维护七道门。每道门填 `PASS / FAIL / N/A`、证据和失败处理。未通过硬门不得生成可直接发布的肯定句。

#### H. 跨章去重

- 首次定义章；
- 本章唯一新增内容；
- 应回指而不重写的内容；
- 与相邻章节的职责分工；
- 若同一理论已出现三次以上，指定唯一主讲章，其余仅保留一至两句回指。

#### I. 作者裁决

- 必须由作者确认的事实；
- 必须由作者选择的篇幅、语气、案例公开范围和原创定位；
- 作者暂不确认时的安全处理：删去、降级、标待核或使用区间；
- 是否阻塞正文生成。

### 4. 包级验收

章节插入包通过时应满足：

- 每张卡只解决一个问题；
- 至少调用 A—F 中一个模型，并说明未调用其他模型的理由；
- 每个强主张有来源、定位、`C×E` 和“不能支持”；
- 新段落至少产生一个教师可执行动作；
- 学习科学概念只解释局部表征任务，且有 R 来源或明确标为推演；
- 没有把参考书内容、段落节奏或措辞改头换面写入；
- 有字符区间，也有停止扩写条件。

## 五、任务三：全书扩展地图

### 1. 任务目的

把十二章的理论功能、案例责任和证据边界分开，确定“哪里首次定义、哪里实际使用、哪里验证、哪里维护”。扩展地图服务全书结构，不直接替作者决定最终篇幅。

### 2. 全书总表必填字段

| 字段 | 说明 |
|---|---|
| 章节与路径 | 章名、绝对路径、主要标题锚点 |
| 本章唯一问题 | 读者在本章必须解决的物理可视化或自研判断 |
| 现有资产 | 已有案例、图表、项目、测试和课堂材料 |
| 主要可见对象 | 过程/结构/关系/数据/模型/推理，可多选但标主次 |
| 主要技术载体 | B 模型第二层；不与对象和生产方式混写 |
| 主要生产方式 | B 模型第三层与 C 模型责任位置 |
| 证据责任 | 来源、独立测试、课堂产物、主张和版本负责人 |
| 核心模型职责 | A—F 中“首次定义 / 主讲 / 应用 / 回指 / N/A” |
| 理论插入点 | 精确标题或行号、要补的内容功能 |
| 来源计划 | R/F/E/L/B/S，原件状态和缺口 |
| 主张上限 | 本章关键主张的最高 `C×E`，不得按章给平均分 |
| 建议新增字符 | 区间及其定义/方法/证据/边界构成 |
| 重复控制 | 从哪章回指、禁止重写什么 |
| 风险与失败门 | 最可能的分类、物理、AI、合规或维护失败 |
| 作者裁决 | 事实、案例、篇幅、公开层级或原创定位 |

### 3. 六模型跨章分工表

地图必须为 A—F 各指定：

- 一个“首次完整定义章”；
- 至少一个“用案例展开章”；
- 至少一个“验真或反例章”；
- 其余章节采用一至两句回指；
- 若没有足够材料，允许暂不进入正文。

不得让每章都重新定义六模型，也不得把六模型机械平均分给十二章。

### 4. 扩展量预算

全书扩展量由四种可核内容相加：

```text
新增字符 = 新定义 + 新方法 + 新证据 + 新边界
```

地图需分别统计四项的区间，并列出：

- 纯过渡、标题、图注和引用列表不作为理论增量；
- 同义改写、案例复述和参考书结构模仿不计入；
- 未通过引用核验的段落只计候选量，不计可发布量；
- 一旦后续新增只能重复或抬高主张，触发 `NO-EXPANSION`。

### 5. 全书一致性检查

扩展地图交付前逐项回答：

1. “可见对象、技术载体、生产方式、证据责任”是否始终分层？
2. 真实现象、测量数据、模型、仿真输出和生成内容是否标明身份？
3. “从用到造”是否被写成责任选择，而非教师等级？
4. AI 是否保留教师的来源、物理、课堂、发布和维护裁决？
5. 每项 S 是否有跨章复现、新动作和失效条件？
6. 每章的最强主张是否有 `C×E` 上限？
7. 学习科学是否只在具体表征任务处出现？
8. 参考书是否只作结构导航，并已回到原始或可核来源？

## 六、任务四：引用核验

### 1. 任务目的

确认一个具体句子由什么来源直接支持、允许写到什么强度、哪些部分必须删除或降级。核验对象是“主张—来源关系”，不是文献名录的完整程度。

### 2. 单条引用核验卡

```text
主张编号：
拟写句子：
主张对象、时间、条件和范围：
来源标签：R / F / E / L / B / S
完整来源：作者、年份、题名、出版物或机构
精确定位：DOI/URL/本地绝对路径 + 页码或行号
本轮核验：回原文 / 官方页面 / 原始项目文件 / 汇总卡 / 未核
原文实际研究或说明了什么：
直接支持的最小命题：
不能支持：
替代解释或冲突材料：
坐标：C0–C6 × E1–E3
安全动词：
禁止动词：
处置：保留 / 缩小 / 降级 / 换源 / 删除 / 待作者裁决
```

### 3. 来源分流

| 当前来源 | 核验动作 | 可接受终点 |
|---|---|---|
| R | 打开摘要、方法、结果和限制；定义尽量核对原始出处 | 原始论文或正式报告的精确位置 |
| F | 打开发布机构原件，核对版本、适用对象和规范语气 | 机构正式框架、指南或标准 |
| E | 打开官方工程文档，核对功能范围、版本和限制 | 产品方或研究机构正式资料 |
| L | 从台账/卡片回到项目原件；不能回原件则停在 E1/E2 | 绝对路径、版本、行号/页码及可复核原件 |
| B | 只提取关键词、结构线索和引文入口，再回查 R/F/E | 不作为核心结论终点 |
| S | 核对至少两个跨章锚点、新动作、失效条件和原创措辞 | 明示“本书归纳”的操作模型 |

### 4. 强词专项门

出现下列词语必须单独核验：首次、首创、普遍、必然、显著、有效、提升、精准、可靠、安全、降低负荷、促进迁移、提高能力、节省时间、降低门槛、可复现。

最低处置原则：

- 只有 C0—C2 时，优先使用“设计、存在、运行、通过列出的检查”；
- C3 要同时说明用途、范围、容差和外部依据；
- C4 只报告给定任务中的行为或产物；
- “改善、提升”至少进入 C5，并处理基线、比较和替代解释；
- “迁移、保持”进入 C6，需要未见或延时任务；
- 来源无法定位时删除，不用“有研究表明”占位。

### 5. 核验结论

| 状态 | 定义 |
|---|---|
| VERIFIED | 来源、定位、语义和范围直接支持拟写句，`C×E` 匹配 |
| DOWNGRADE | 有相邻证据，但需缩小对象、条件或因果语气 |
| REPLACE | 当前来源不能直接支持，已有可核的替代来源 |
| DELETE | 无直接证据或与原文相反，应删除 |
| BLOCK | 关键原件、作者事实或权利状态缺失，暂不能裁决 |

## 七、统一失败路由

| 编号 | 触发信号 | 立即状态 | 处理路由 | 恢复条件 |
|---|---|---|---|---|
| FR-01 | 关键命题只有 B 参考书或文献卡，没有原始/正式来源 | DOWNGRADE | B 只留导航；回查 R/F/E；找不到则删去理论归因或标待核 | 原件定位与语义核对完成 |
| FR-02 | 本地事实只有作者回忆或计划 | CONDITIONAL | 标 `来源=L，C0/C4×E1`；禁止写成已完成、已验证 | 打开原件，升级到 E2/E3 |
| FR-03 | 源码、截图或成品被用来证明学习改善 | BLOCK | 把主张降到 C1/C2/C4；另行寻找学习证据 | 有符合 C5/C6 的设计与数据 |
| FR-04 | 同一模型、代码、数据或 AI 生成源互相验证 | CONDITIONAL | 明示“内部一致”；增加手算、实测、解析解、其他算法或原始权威源 | 至少一个独立真值和可失败判据 |
| FR-05 | 真实现象、测量、模型、仿真输出、生成内容身份混写 | BLOCK | 回到 B 四层和来源身份；重写图题、数据血缘和模型卡 | 每项内容身份与边界明确 |
| FR-06 | 可见对象、技术载体、生产方式被放进同一分类 | REVISE | 拆成 B 四层；原“九类”只作为资产检索标签 | 每层能独立填写且不互相替代 |
| FR-07 | 物理硬错、单位/方向/阶段错误或失败输入仍正常输出 | 隔离停用 | 停止发布，修正模型或代码，重跑相关回归 | G1/G2 重新通过并有责任人签核 |
| FR-08 | 学生身份、作品映射或敏感数据可能暴露 | 隔离停用 | 最小化、脱敏、撤下公开入口，记录影响 | 权利与公开门通过，作者批准范围 |
| FR-09 | 素材、代码、数据或 AI 生成内容权利不清 | 限定试用/本地开发 | 查许可、署名和生成标识；无法确认则替换或不公开 | 权利链与公开条件明确 |
| FR-10 | 无版本、维护人、回退点或复验触发器 | 本地开发/限定试用 | 补 F 生命周期记录；限定使用范围 | 责任人、版本、回退与复验条件齐全 |
| FR-11 | 同一概念跨章重复定义 | NO-EXPANSION | 指定唯一主讲章；其他章改为应用或回指 | 章际分工与回指明确 |
| FR-12 | 学习科学术语成为整章主轴但无具体表征任务 | REVISE | 删除通用综述；先写对象—编码—行动—产物，再按需补局部机制 | 机制能解释一个可观察任务且有来源 |
| FR-13 | AI 生成、自评、自测并决定发布 | BLOCK | 拆开生成与裁决；教师或独立人员复核来源、物理、课堂与发布 | 有人工签核、独立真值和叫停权 |
| FR-14 | 强主张的对象、时间、条件或范围不明 | DOWNGRADE | 缩小句子，补 `C×E`、替代解释和禁用动词 | 主张与证据范围一致 |
| FR-15 | 需要作者确认的事实被写成确定陈述 | 待作者裁决 | 保留问题与安全版本，不代作者选择 | 作者给出可记录的确认或选择 |
| FR-16 | 新增内容只增加同义改写、案例复述或引用数量 | NO-EXPANSION | 删除重复；改为新定义、方法、证据或边界，否则停止 | 至少新增一个可核内容功能 |

### 失败优先级

1. **P0 立即隔离**：物理硬错、隐私暴露、权利人要求下线、数据身份错置。
2. **P1 限定使用**：核心功能失效、校准漂移、兼容问题、课堂路径中断。
3. **P2 降级说明**：来源不足、外部验证不足、主张越级、分类不清。
4. **P3 计划维护**：外观、低频说明、非核心归档问题。

P0/P1 问题不能靠加免责声明放行；修复后必须重过受影响的门。

## 八、作者裁决点

### 1. 必须交给作者的决定

| 类别 | 典型问题 | 未裁决时安全处理 |
|---|---|---|
| 事实身份 | 某案例是否真实入课、数据是否来自学生、功能是否已公开 | 标待核；降到 C0/C1；不写“已经” |
| 经验边界 | 单人经验是否只作为案例，能否代表团队或其他教师 | 限定为“作者案例/本地项目” |
| 原创定位 | 某模型是否采用“本书归纳”名称，是否有足够跨章复现 | 保持描述性表述，不宣称模型或首创 |
| 篇幅取舍 | 哪一章主讲、哪些章回指、是否接受新增字符区间 | 提供两个有边界选项，不擅自铺开全文 |
| 项目公开 | 源码、学生作品、失败记录、测试数据可公开到什么程度 | 脱敏、摘要或不公开 |
| 风险接受 | 限定试用是否可入课、缺少哪类验证时可接受 | 采用更简单资源或回退方案 |
| 主张语气 | 是否保留“有效、提升、迁移、首次”等强词 | 使用较低 C 级安全动词 |
| 维护责任 | 谁负责版本、域名、依赖、设备、撤回与复验 | 保持本地开发或限定试用 |

### 2. 不需要交给作者的常规判断

以下事项由专家按本规格直接处理并记录：

- 把混合分类拆成 B 四层；
- 把 B 参考书线索路由到原始或正式来源；
- 把超出证据的句子降到现有 `C×E`；
- 把重复定义改为回指建议；
- 把学习科学从总框架降为局部机制；
- 在无独立真值时把“验证”改为“内部一致性检查”；
- 为 AI 生成物增加人工复核、版本和回退要求。

### 3. 裁决请求格式

每次只提交真正改变结果的选择：

```text
裁决编号：AD-章节-序号
需要作者决定：
已知事实与锚点：
选项 A：影响、可支持的 C×E、风险
选项 B：影响、可支持的 C×E、风险
专家建议：
若暂不决定：采用的安全版本
是否阻塞：是 / 否
```

## 九、交付前自检

### 结构

- [ ] 任务类型唯一，范围、路径和锚点明确。
- [ ] 实际调用的 A—F 模型已说明，未机械凑齐。
- [ ] 诊断、插入包、扩展地图或引用核验的必填字段完整。
- [ ] 失败路由、恢复条件和作者裁决点可执行。

### 证据

- [ ] 关键命题均有 `来源=R/F/E/L/B/S`。
- [ ] 关键主张均有 `坐标=Cn×Em`，没有总分。
- [ ] “来源=E”与“坐标=E1/E2/E3”没有混写。
- [ ] B 只作导航；L 已区分 E1/E2/E3；S 满足发布条件。
- [ ] 每条来源同时写“直接支持”和“不能支持”。

### 内容边界

- [ ] 可见对象、技术载体、生产方式、证据责任分层。
- [ ] 真实、测量、模型、仿真和生成内容身份清楚。
- [ ] AI 没有代替教师作来源、物理、课堂、公开和维护裁决。
- [ ] 学习科学只解释具体表征任务，没有成为通用总论。
- [ ] 参考书只提供概念与来源导航，没有参与标题、段落、表格、论证节奏或作者声音生成。
- [ ] 新增字符来自新定义、方法、证据或边界，而非重复增字。
