# 技能目录说明

## 当前权威技能

`physics-visualization-ai-researcher/`

该技能围绕三条主轴工作：

1. 高中物理可视化：现象、结构、关系、数据、模型与推理如何变成可观察、可操控、可检验的对象。
2. AI 协作自研：教师怎样把教学判断写成需求、规则、技能、测试和版本，使 AI 能参与网页、仿真、代码与平台开发。
3. 从用到造：教师从选择资源、修改资源走向创造、验真、交付与维护。

## 历史研究目录

`physics-visualization-theory-researcher/` 是主题校正前形成的研究副本，学习科学比重过高。它仅保留作背景和过程追溯，不作为本项目最终技能，也不参与权威综合与试点验收。

## 禁止混用

- 最终研究文件只从 `physics-visualization-ai-researcher/references/research/` 读取。
- 最终综合模型只从 `physics-visualization-ai-researcher/references/synthesis/` 读取。
- 旧研究中若有可用观点，必须重新接受“与可视化/AI 主轴直接相关、来源可核验、能转成教师动作”的三项检查后，才能局部吸收。
