# 两章试点说明

试点只在 V2 目录中展示理论研究专家怎样工作，不修改 V1 正文。

## 第 7 章：可视化理论试点

重点回答：电容概念课中的实物、结构示意、变量链、物理模型和符号关系分别让什么变得可见；这些表征怎样连接；哪些图像只能说明结构，哪些证据才能支持物理结论。

## 第 12 章：AI 自研方法试点

重点回答：教师怎样把教学问题转成 AI 可执行的规格；规则、技能、模板、验收和版本怎样组成稳定工装；需求、原型、验真、入课、交付和维护之间怎样闭环。

## 每章交付物

| 文件 | 作用 |
|---|---|
| `章节诊断.md` | 标出现有强项、理论空白、重复风险和优先级 |
| `理论插入卡.md` | 给出来源、解释机制、项目锚点、教师动作、插入位置与目标字数 |
| `引用核验表.md` | 逐条限制每个来源能支持的命题 |
| `重复与边界检查.md` | 检查跨章重复、模型/现实混淆、AI 功能/效果混淆和证据外推 |
| `作者裁决卡.md` | 只保留真正需要作者决定的内容取舍与事实确认 |
| `示范扩写稿.md` | 展示理论怎样进入原有案例和表达，不作为 V1 的自动替换稿 |

## 验收标准

- 第 7 章以可视化理论和物理表征链为主，不写成通用学习科学综述。
- 第 12 章以教师 AI 协作自研、验真和维护为主，不写成 AI 工具教程或供应商宣传。
- 每项外部理论至少有原始或官方来源；每项本书事实都有项目入口与证据等级。
- 新增字数来自新概念、新机制、新方法、新边界或新证据，不靠同义改写重复原文。
- 所有建议均标明精确插入位置；所有示范稿均保留可删、可改、可回退的独立状态。
