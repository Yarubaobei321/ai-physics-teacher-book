## 3. 术语与例证重复检测规则

### 3.1 术语

- `表征`：指实物、语言、图、表、方程等表达系统；不要与“媒介”互换。
- `可视化`：指把对象、关系或证据外显并组织为可观察、可操作任务；不要把所有实物展示都命名为可视化。
- `结构`：本章指两个导体、绝缘介质、重叠区域和连接关系；不要只写外形。
- `模型`：必须写保留、忽略和用途；“结构图”不自动等于模型。
- `变量`：必须区分改变量、保持量、干扰量和系统状态。
- `证据`：至少注明是实物观察、仪表响应、学生作答还是学习研究证据。
- `符号`：指 `C=Q/U`、`C=εS/d`、同轴近似和 `U=Q/C` 等关系；每个关系附适用语境。
- `迁移`：若只有一个新外形任务，写“新情境作答”或“迁移任务表现”，不写“实现迁移”。
- `理解／形成`：无过程、基线、比较和延时证据时，用“给出解释”“完成标注”“修订条件链”。

### 3.2 例证

- 莱顿瓶是第7章唯一主案例；平行板装置只作模型参照。
- 触摸按键、液位传感器、可变电容器和同轴电缆最多选一个作新外形任务，不能四例逐项铺开。
- 起电机仍连接、漏电明显、导线移动三种失败情境各承担不同断点；不要在四个新增模块重复列同一组风险。
- 第3章活版电路、第5章积木—代码、第8章光电门、第9章磁通量链只进入编务去重表，不进入第7章读者正文。

## 4. 物理边界

| 容易越界的表述 | 安全表述 | 原因 |
|---|---|---|
| “莱顿瓶就是同轴圆柱电容器” | “本章把样机近似为同轴圆柱结构，以讨论有效重叠长度；真实形状和边缘场仍在模型外” | 实物不规则，模型有用途和范围 |
| “面积决定电容” | “在介质、距离／等效半径和基本几何条件保持时，有效重叠面积或长度的变化对应电容的定性变化” | 需写保持条件和模型差异 |
| “静电计显示电容” | “静电计对连接端电势差作出响应；由张角推断电容方向还需 `Q` 近似不变等条件” | 仪表直接响应对象不同 |
| “断开电源后电荷量不变” | “在所定义连接系统内、观察时间足够短且漏电影响可忽略时，把 `Q` 近似看作不变” | 真实装置有漏电、附加电容和电荷转移 |
| “张角增大证明电容减小” | “在列明条件下，张角变化与预测方向相符；若条件破坏，现象不能单独裁决电容变化” | 定性现象存在替代解释 |
| “平行板与莱顿瓶遵守同一个公式” | “两种模型在本任务中共享‘有效面积／长度增大，电容增大’的定性趋势，几何公式不同” | 防止模型混同 |
| “现象不一致说明操作失败” | “先定位模型、系统状态、漏电、接线或仪表响应中的断点” | 失败也是边界证据 |
