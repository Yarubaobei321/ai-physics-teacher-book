# V2 语料说明

## 当前权威入口

- `CORPUS_PLAN.md`：六维调研计划与语料边界。
- `viz-ai-source-register.md`：可视化、AI 协作开发、验证治理和教师能力的原始/官方来源。
- `project-evidence-register.md`：网站、ESP32Blockly、继续教育课程和学生作品的证据等级与写作上限。
- `corpus-index.json` / `corpus-index.md`：本地语料索引，用于定位原件，不代表每张卡都适合本书主题。

## 背景材料

`seed-corpus.md` 与 `source-theory-supplement.md` 形成于主题校正之前，学习科学比重偏高。二者仅作背景导航，不进入最终综合的默认读取集。

## 默认读取顺序

1. 读取 V1 当前章节与 `PROJECT_BOUNDARY.md`。
2. 读取 `viz-ai-source-register.md`，选择与章节问题直接相关的理论或方法。
3. 读取 `project-evidence-register.md`，确定案例事实及证据上限。
4. 按 `corpus-index` 回到本地原件；涉及外部理论时回到原始论文或官方文档。
5. 生成理论插入卡，并检查跨章重复、外推风险和新增字数是否来自新解释而非改写堆叠。
