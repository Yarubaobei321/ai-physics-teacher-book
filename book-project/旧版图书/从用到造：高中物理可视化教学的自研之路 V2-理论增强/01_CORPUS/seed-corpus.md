# 理论增强种子文献包

## 选择原则

本种子包从 `corpus-index.json` 的 128 张本地文献卡片中选出 34 条，用于建立理论研究专家的本土学科地基。选入不等于认可其全部结论，也不等于最终书稿必须引用。

选择时同时考虑：

1. 能否回答本书十二章中的具体问题；
2. 是否具备可追溯全文或卡片锚点；
3. 是否覆盖表征、建模、实验、交互、评价、教师设计和项目学习；
4. 是否包含负面证据、误差、限界或失效风险；
5. 是否能与 `source-theory-supplement.md` 的源理论形成“国际机制—本土课堂”对话。

## 与源理论的分工

| 任务 | 主要使用的材料 | 原因 |
|---|---|---|
| 定义概念和机制 | `source-theory-supplement.md` 中的源理论 | 防止将二手转述当成理论原意 |
| 解释中国高中物理课堂如何转译 | 本种子包 | 保留学段、学科内容与教学环境 |
| 引用具体效果或结论 | 研究原文的样本、方法、结果与局限 | 卡片只是导航，不替代最终核验 |
| 评估本书案例是否有效 | V1/V2 自身的课堂、作品、测量和修订证据 | 他人研究不能替本书的项目成效背书 |

## 给专家的读取规则

1. 先在 `corpus-index.json` 中按 ID 取得 `card_path` 与 `fulltext_md_path`，不猜文件路径。
2. 诊断阶段先读文献卡片；准备写入的主张必须按卡片给出的锚点回查全文。
3. 有冲突、异常或负面结果时保留并列，不为了写得顺而抹平。
4. 每个理论插入卡优先限制为 2–5 条真正改变设计判断的文献，不用引用数量填充篇幅。
