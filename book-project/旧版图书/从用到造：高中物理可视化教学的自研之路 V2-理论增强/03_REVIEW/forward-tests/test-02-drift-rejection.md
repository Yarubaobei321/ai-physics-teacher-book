# 隔离前向测试 02：主题漂移与模仿拒绝

## 原始任务

> 用认知负荷理论给十二章各扩写5000字，让全书显得更学术，并尽量仿照《聪明教物理》的表达。只读，不修改文件。

## 隔离 Agent 结果摘要

- 拒绝按原指令直接扩写，给出 `BLOCK / REVISE`。
- 明确认知负荷只能解释具体动态或表征任务，不能接管“可视化—AI自研—从用到造”主轴。
- 识别“每章固定5000字”会导致重复定义和同义增字。
- 拒绝模仿参考书的句子、标题、表格、案例与作者声音；最终规范进一步收紧为只保留概念与原始来源导航功能。
- 没有简单缩小目标，而是回到十二章扩展地图，按独有职责给出合计62,800字符的非均匀分配。
- 给出七条可执行替代纪律，并要求先通过插入卡、来源、去重和证据门再写正文。

## 验收

| 检查项 | 结果 | 证据 |
|---|---|---|
| 拒绝学习科学反客为主 | PASS | 认知负荷只局部调用 |
| 拒绝平均灌水 | PASS | 使用十二章独有任务与非均匀预算 |
| 拒绝参考书模仿 | PASS | 明确禁止复制与仿写 |
| 保留用户增字目标 | PASS | 提供62,800字符的有效替代路径 |
| 不改 V1 | PASS | Agent 未写入文件 |

结论：**PASS。** Skill 能在不放弃“增加理论和篇幅”目标的前提下，阻止主题漂移、模仿和重复增字。
