# Phase 1 维度 01—03 主题预审

> 审阅对象：01《可视化理论谱系》、02《高中物理可视化形态与技术谱系》、03《AI辅助教师自研可视化工具的方法论》  
> 审阅结论：**PASS，可进入主综合阶段；三份研究不能原样拼接。**  
> PASS 的含义：主题、证据边界和方法生成力已达到综合输入要求，不表示其中的本书归纳已经成为经实证验证的通用理论。

## 一、总判断

三份研究已经共同守住本书的主线：以高中物理中“原本难以观察、比较、操控或审查的对象”为起点，选择可视化技术，把教师经验转成可运行、可测试、可维护的工具，再用课堂产物限定结论。学习科学没有被用作使用 AI 或自研工具的总论证，主要停留在动态呈现、表征转换、学生任务和学习证据的辅助位置。

当前不存在需要退回重做的事实冲突。主要风险来自**分类维度混放和方法重复**：01 的六类回答“什么对象要被显出”，02 的九类混合了“用什么技术实现、怎样生产、怎样留证”，03 的六种生成物回答“AI 协作交付什么”。主综合若把三套名称平行罗列，读者会误以为出现了三种互相竞争的分类标准。

建议采用一条总链收束三份研究：

```text
教学问题与现成工具评估
→ 要显出的对象（01）
→ 最低足够的技术链（02）
→ 是否需要 AI 协作自研（03）
→ 独立验真、发布与维护（02＋03）
→ 学生任务、产物与有限结论（01＋02）
```

## 二、逐项 PASS

### 01《可视化理论谱系》：PASS

- **主题中心正确。** 文件以数据可视化、科学可视化、信息可视化、物理表征、动态与交互、模型仿真和可视分析为理论源头，最终落到过程、结构、关系、数据、模型、推理六类“被显现对象”。AI 只在模型生成、验真和第12章规格中出现，没有抢走可视化主轴。
- **“从用到造”已经埋入决策逻辑。** 可视化价值模型、最低足够表征、学生生成、模型卡和九步生成协议能够把“调用现成图”推进到“根据任务设计表征”。主综合还需把“先判断现成工具是否足够”写成显式入口。
- **学习科学未越位。** 动画研究只用来约束节奏、任务和外部记忆；文件明确禁止把“降低认知负荷”“促进理解”当作无证据的通用解释。
- **证据分层基本清楚。** A、L、N、I、G 能区分权威源、本地材料、参考书导航、本书推演和缺口；《聪明教物理》只承担组织方式导航，没有成为理论原典。
- **来源与命题匹配。** 原始或正式来源主要支撑概念定义和设计边界；本地 C 级课例只支撑技术链与案例形态；六类编辑分类已明确标为本书综合。
- **能生成教师动作。** 每个概念都有对象、教师动作、学生产物、边界和章节入口，结尾九步协议可以直接驱动理论段落和案例修订。

### 02《高中物理可视化形态与技术谱系》：PASS（需重排层级）

- **可视化与“从用到造”最强。** 九类均从不可见对象、转换链、教师决策、验证门和失效模式展开，V1 的教具、传感器、仿真、编程、H5、AI 与作品证据都能找到实际锚点。
- **AI 没有被写成万能技术。** 文件明确说“生成式 AI”是生产与责任类型，AI 生成的仿真、H5、图示仍要回到相应内容类型验收。
- **学习科学没有主导技术分类。** 学习变化与迁移被放在 G5，且要求基线、未见任务、比较或延时证据；单个资源存在不能推出学习效果。
- **事实、文献、推演分得开。** V1／项目事实支持作者做过什么，本地文献支持某条技术链怎样实现，本书谱系和操作卡均标为推演；结尾也明确九类尚未完成编码一致性和跨案例验证。
- **教师动作非常充分。** 每类都有“技术链—教师决策—学生动作—可观察证据—验证门—失效模式”，能够直接生成案例补写和验收清单。
- **关键保留条件。** 九类可以作为“项目资产检索标签”，不能原样称为九个同层级的可视化类型。类型1—6主要是对象／技术链，类型7是交付容器，类型8是生产与责任层，类型9是证据层；文件自身已经承认后三者的跨层性质。

### 03《AI辅助教师自研可视化工具的方法论》：PASS

- **主题中心准确。** 内容始终围绕教师把物理教学需求转成图像、网页、仿真、代码、平台和测试，未滑向通用 AI 教学法或学生使用 AI 的泛论。
- **“从用到造”已成为完整生产链。** 自然语言规格、责任契约、五类工装、上下文工程、工作流／智能体选择、共同设计、原型—测试—修复、版本发布和教师专业判断构成可执行路径，并单列“不该用智能体自研”的条件。
- **学习科学严格居于辅助位置。** 学生误区只帮助定义需求，学生产物只帮助设计入课证据；文件没有用学习科学为 AI 的必要性、效率或成效背书。
- **证据层级是三份中最清楚的一份。** 外部实证、权威框架、官方工程、本地事实和本书归纳分别回答不同问题；供应商指南只支撑工程模式，不承担教育效果命题。
- **来源总体支持相应命题。** 自然语言编程研究支持歧义、复述和测试问题；人机交互与教师研究支持纠错和学科终审风险；NIST／UNESCO 支持责任和治理原则；官方资料支持工作流、上下文、技能和评测做法。所有跨到高中物理教师情境的部分均已标出外推限制。
- **方法可以落到教师动作。** 九个方法均给出来源、生成内容、操作链、可保存证据、限制与失效；“既有做法—本书差异—证据边界”也避免了把本地方法写成首创。

## 三、主综合阶段必须处理的问题

### P1｜把三套分类改成四层矩阵

建议固定为：①可见对象：01 的过程、结构、关系、数据、模型、推理；②技术／载体：02 的真实增强、教具、测量传感、图示、仿真、物理计算、平台；③生产方式：人工、模板、AI 工作流或智能体；④证据责任：来源身份、测试、课堂产物、主张等级。03 的图像、网页、仿真、代码、平台、测试只是 AI 生产的交付物，不新增一套“可视化分类”。

### P2｜显出“用—改—造”的选择门

三份研究都擅长说明怎样造，但主综合应先问：现成工具能否满足目标、差距是否值得开发、教师是否承担得起测试和维护。可把路径写为“直接使用—参数配置—局部改造—组合编排—AI 协作自研”，每向右一步都增加来源、测试、版本和维护责任。自研应是解决明确缺口的选择，不是技术进阶终点。

### P3｜统一证据标签

01 的 A/L/N/I/G、02 的事实／文献／推演加 P/A/L/N/I 与 E1—E3、03 的五类标签不能同时进入正文。主综合建议只保留两条正交标记：**来源性质**（原始研究／正式框架／官方工程／本地材料／本书归纳）和**本地事实强度**（原件可复核／台账汇总／经验待证）。文献研究等级、项目证据等级和课堂主张等级不得合并成一个“高低分”。

### P4｜合并验证体系，说明各门用途

01 的来源—模型—表征—交互—分析五层、02 的 G0—G5、03 的物理测试矩阵与五道发布门用途不同。正文应形成一套主流程：来源身份 → 物理／测量 → 功能／设备 → 课堂任务 → 证据解释 → 合规发布 → 维护复验。模型的五类特殊点测试作为“物理／功能”子卡，发布五门作为生命周期末端检查，避免读者记忆多套相似数字清单。

### P5｜给“学生产物”增加适用条件

01 的“每类都要有学生产物”适合声称课堂使用、学习表现或思维外化时使用；03 的教师开发和入课前验证可以只留下需求、模型卡、代码、测试和教师裁决。综合稿应改成：**资源开发阶段必须有可复核的工程产物；进入课堂并提出教学主张时，必须增加学生行动与产物。**

### P6｜压缩跨文件重复

- 概念定义与六类可见对象只在第2章集中出现，由 01 负责；
- 技术链、来源身份和各类失效由 02 负责，后章只调取对应方法卡；
- AI 需求、职责、工装、上下文、智能体、测试和版本由 03 负责；02 的 AI 类型仅保留一段跨层导航；
- 十二章映射只保留一张总表；模型卡、特殊点测试、证据边界和发布门只定义一次，案例章负责展示其具体用法。

### P7｜继续限定外推与时效

01 中 PhET 的平均效应不能迁移到本书自研网页；02 的本地 B/C 级课例不能支持普遍成效；03 的编程研究、数学／艺术教师小样本不能变成高中物理教师结论。供应商工程资料只保留稳定的功能结构，出版前复核日期、产品名称和功能，不引用宣传性的效率数字。

### P8｜统一术语与作者声音

“visual analytics”建议统一译为“可视分析”，首次出现附英文；“H5／平台”“生成式 AI”“学生作品”分别说明是载体、生产层和证据层。理论段落采用“对象—判断—动作—产物—边界”的作者语言，不复制参考书的句式、教案结构或案例叙述；参考书只保留二手导航身份。

## 四、不可吸收进正文的表述

| 不可直接吸收的表述 | 原因与处理原则 |
|---|---|
| “九类构成高中物理可视化的统一／完整分类。” | 九类尚未做编码一致性和跨案例验证，且混有载体、生产和证据层。只称“基于本书项目归纳的技术谱系／检索标签”。 |
| “AI把门槛从写语法移到了说清、验真与维护。” | 作为标题过于确定，容易暗示语法和工程门槛已经消失。改为“在本书项目中，AI降低了部分实现负担，同时提高了需求澄清、验真和维护的重要性”。 |
| “自然语言使普通教师能够无障碍／零代码开发平台。” | 现有研究不是高中物理教师的普遍性证据，复杂程序仍有抽象层级和调试障碍。 |
| “五类工装、九项决定或 L0—L4 是行业标准／成熟度等级。” | 它们是本书归纳的操作结构，只能作为待检方法；L0—L4 是任务选择梯度，不是能力高低。 |
| “每一种可视化都必须留下学生作品。” | 入课前开发不一定有学生对象。只有提出课堂或学习主张时，学生行动与产物才是硬条件。 |
| “页面能运行、自动测试通过或真机成功，说明物理正确／课堂有效。” | 工程、物理、课堂与学习证据回答不同问题，不能越级互证。 |
| “生成图像、模型输出或仿真曲线就是实验事实。” | 三者来源身份不同，必须标注生成、模型或实测，并保留独立验证链。 |
| “AI在环／教师在环即可保证可靠。” | Gurl 等的小样本研究已显示教师可能漏掉学科错误；必须说明独立判据、检查动作和停止条件。 |
| “NIST／UNESCO证明某产品安全、合法或教学有效。” | 正式框架提供治理原则，不代替当地制度、法律意见、产品验证或课堂研究。 |
| “提交次数、作品数量、访问量或问卷满意度证明 AI 提效、教师能力或学习提升。” | 这些只证明活动或产物存在；效率、能力和学习变化需要相应对照、过程与迁移证据。 |
| “学生作品直接呈现了学生的思维。” | 作品只显现特定任务、工具和支持条件下的可观察痕迹；还需过程、解释与新任务交叉判断。 |
| “供应商的智能体工作流就是教育研究结论。” | 官方资料只能支撑产品与工程做法；转译到教师自研的方法必须标为本书归纳并继续验证。 |

## 六、主综合的通过条件

主综合阶段满足以下四项，即可吸收 01—03：用一条“用—改—造”总链组织；用四层矩阵消解分类混放；每一条理论主张保留来源性质与证据上限；每个方法最终落到教师决定、学生或工程产物、验证动作和不适用条件。除此之外，不再另造平行分类、能力等级或效果结论。
