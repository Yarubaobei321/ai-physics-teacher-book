# 培训材料能为 S3 提供什么

## 一、可以借鉴的价值

### 1. 把“改什么”拆成候选维度

培训材料提出从知识记忆转向素养能力、从单一学科转向跨学科、从单问转向问题链、从难度系数转向认知层次。这四项适合作为**候选生成维度**，提醒教师不要把改题等同于换背景、加字数或调数字。

本试点不把四项当成每道题必须同时满足的指标。跨学科和问题链只有在服务真实物理问题时才采用，不能机械叠加。

### 2. 把“科学性校验”变成不可跳过的门

培训中的六步工作流——需求分析、方案设计、AI 辅助制作、科学性校验、教学适配、部署分享——原本用于数字资源，本试点将其迁移为：

```text
原题解剖 → 候选改编 → 七门审核 → 退回修订 → 教师定稿 → 课堂试测／发布
```

迁移的关键不是复制六个名称，而是保留“AI 生成之后必须经过教师科学审查和教学适配”的责任结构。

### 3. 把真实问题、教师审核、持续迭代作为共同标准

讲座整理中多处强调资源要解决真实教学问题、经过教师专业审核并在使用中迭代。S3 因而把“为什么改”“退回原因”“修订后解决了什么”设为强制字段，而不是只存最终题面。

### 4. 把题目设计证据与学生思维证据分层

汇报 PPT 第 18—27 页把题目、标准解析、学生解题叙述、思维表征和评价报告分开。对 S3 最有用的不是复制其具体思维诊断项目，而是确认两类证据不能混用：

- 设计阶段只能审查题目**要求学生做什么**、评分点**能观察什么**；
- 试测后才能根据真实学生表达判断**学生实际上怎样思考**。

因此，本试点用“目标动作标签—题面动作标签—评分点”检查设计闭合，不生成虚构学生思维树，也不根据题目结构直接判定 SOLO 层级。

### 5. 把“可用、可信、可迭代”迁移成发布门

汇报 PPT 第 28 页将资源价值概括为可用、可信、可迭代。S3 将其具体化为：课堂时间与评分可执行；物理、条件、答案和来源可信；退回版、修订版和使用反馈可追溯。

## 二、需要修正或补足的地方

### 1. “情境不要说太清楚”不能理解为省略物理条件

开放情境可以让学生选择方案、提出假设或作出决策；决定物理结论所必需的系统边界、数据含义、测量精度和评分规则不能缺失。开放性来自明确的选择空间，不来自条件不充分。

### 2. 认知层次不能由题目篇幅或标签直接决定

题面写了“评价”“探究”不代表学生真的需要分析证据。审核时要看学生实际必须完成的动作，以及评分点是否能观察到这些动作。

### 3. 大题库与账号登录只作为负面边界

培训录音提到大规模题库导出和让智能体登录题库网站。当前没有可核验的个人自动访问授权、再分发权限或第三方模型处理许可，本试点不采用这些做法，也不把它们写成推荐路径。
