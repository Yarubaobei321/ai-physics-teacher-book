# S3 任务书：素养导向题目改编流水线

> 状态：独立并行研发试点  
> 样本：1 道自编题，4 个版本（原题＋3 个候选／修订）  
> 停止点：形成可运行原型、审核记录和可选择回流的方法，不回写新书 B1

## 一、要做的事

1. 从一道自编高中物理题出发，记录考查对象、学生动作、条件、答案和来源边界；
2. 形成情境、设问、数据／图像和开放任务的候选改编；
3. 逐关审核学段边界、物理真值、条件充分性、答案唯一性／开放性、认知要求、版权和可教性；
4. 保留原题、候选、退回、修订和试点定稿之间的差异与理由；
5. 做出不联网、零外部依赖的可运行原型，并留下失败样例；
6. 提炼一线教师可以不用代码执行的方法和可入书的新认识。

## 二、不做的事

- 不接入、抓取、批量导入或模拟登录学科网及其他未授权题库；
- 不使用培训专家导出的 5 万道题或其详细项目数据；
- 不复写培训中的烘焙店案例、提示词或产品实现；
- 不复制教材题干、图表或答案；教材只确认学段、概念和表征边界；
- 不使用真实学生答题、成绩或对话数据；
- 不自动宣布题目通过，不把结构检查升级为质量、难度或核心素养测量结论；
- 不修改新书 B1 总入口、书的宪法、S1 文件或主项目台账。

## 三、完成标准

| 完成标准 | 验证方式 |
| --- | --- |
| 有一套教师能按步骤执行的最小工作流 | `01_METHOD/教师工作流.md` 可独立阅读 |
| 七道审核门都有明确输入、退回条件和人工责任 | `01_METHOD/七道审核门.md` |
| 至少保留一次否决、一次退回和一次修订链 | 原型报告中的 Q001-C01、C02、C03 |
| 原型能检查版本血缘、数值一致性和关键字段 | 运行 `pipeline.py audit` |
| 原型能生成报告、CSV、版本图和教师参考图 | `03_RECORDS/generated/` |
| 有自动测试覆盖主要失败路径 | 运行 unittest，全部通过 |
| 形成失败样例和不适用边界 | `03_RECORDS/失败样例.md` |
| 形成可选择性回流的新书方法与交接说明 | `04_BOOK/` 与 `05_HANDOFF/` |

## 四、最小技术路径

- **输入**：一个 JSON 文件，保存题源、每个版本、父子关系、差异、审核证据和教师处置；
- **处理**：一个 Python 标准库脚本，做字段、血缘、公式、条件、答案模式和认知动作的一致性检查；
- **输出**：一份 Markdown 审核报告、一份 CSV 门禁台账、两张 SVG 图；
- **人工责任**：物理模型、学段适切性、课堂时间、评分可用性和出版授权仍由教师／作者签字确认。

选择这条路径，是因为它能在不接题库、不依赖模型服务的情况下先验证流程价值；数据规模仅 1 题，运行预计少于 1 秒，内存占用可忽略。

## 五、风险与回滚

| 风险 | 控制办法 |
| --- | --- |
| 自动结果被误当作命题质量证明 | 报告固定显示“结构审核，不替代命题审读和试测” |
| 开放任务因缺条件变成随意作答 | 区分“允许选择”与“遗漏必要条件”，分别检查答案空间和条件充分性 |
| 只换情境却宣称提高认知要求 | 认知门同时比较目标动作和题目实际要求学生完成的动作 |
| 数值自洽但物理模型错误 | 自动公式检查只作辅助，物理真值门必须保留人工理由 |
| 外部材料越界 | 样题完全自编；外部材料只登记方法启发和负面边界 |

所有新增文件都在本独立目录。若主线不采用，保持该目录不合并即可；无需修改或恢复 B1、宪法和 S1。
