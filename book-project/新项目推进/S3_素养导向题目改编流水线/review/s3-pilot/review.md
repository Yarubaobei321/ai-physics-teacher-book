# S3 试点审阅

## 1. 摘要

S3 已从培训中的“题目改编值得形成最小系统”推进为一套可运行、可复核的单题版本流水线。

以前只有 B1 候选问题和风险边界；现在已有 1 道自编题、4 个版本、七道审核门、两类失败、自动报告、人工审读单和可入书方法。作者可先阅读 `03_RECORDS/generated/audit_report.md`，再用 `03_RECORDS/人工命题审读单.md` 独立复核 Q001-C03。

## 2. 前后对比

| 项目 | 以前 | 现在 | 改善 |
| --- | --- | --- | --- |
| S3 状态 | 培训触发的问题与最小系统设想 | 1 道题的完整版本链和可运行检查器 | 从概念候选变成可检查对象 |
| 改编记录 | 只说明可能改情境、问题链和认知层次 | 每版保存父版本、变化、理由、风险与处置 | 能复盘为何否决、退回和修订 |
| 科学审核 | 原则性要求复核物理、条件和答案 | 七道门分别给出通过或退回证据 | 硬错误不能被亮点抵消 |
| 自动化 | 没有 S3 原型 | 零依赖 Python 生成 Markdown、CSV 和 SVG | 可重复运行，教师仍保留最终责任 |
| 证据边界 | 不能提前声称质量和效果 | 报告固定区分结构通过、人工审读和课堂试测 | 降低把原型冒充效果证据的风险 |

## 4. 关键决策

- 只做 1 道题的深版本链，不为凑满 10 题扩样本；
- 培训材料只提供问题、关系和审核启发，不复制专家项目；
- 教材只确认学段与概念，题干和数据完全自编；
- 正式工作目录放在 `图书出版/新项目推进/S3_素养导向题目改编流水线`；旧工作树副本仅作回滚快照。

## 5. 下一步

1. 作者先独立审读 Q001-C03，再看自动报告；
2. 邀请另一位高中物理教师填写同一审读单；
3. 若两人均认为可教，安排一次小范围试测，记录真实用时、非预期理解和评分分歧；
4. 主会话当前优先只回流方法，不回流效果结论。
