# S3：素养导向题目改编流水线（独立试点）

这不是“让 AI 一键出题”的工具，而是一套把改题意图、版本差异、退回理由和教师裁决保留下来的最小工作流。

本轮只处理 **1 道自编题**：先保留原题，再形成“只换情境”的失败候选、条件不足的退回候选和一个修订后的试点定稿。自动工具逐关检查学段边界、物理真值、条件充分性、答案设计、认知要求、版权与可教性；最终是否进入课堂仍由教师决定。

## 先看这里

1. [任务书](./00_TASK/任务书.md)：目标、范围、完成标准和回滚方式；
2. [培训材料能提供什么](./00_TASK/培训材料取用说明.md)：可借鉴的方法与不可复写的边界；
3. [来源与取用台账](./00_TASK/来源与取用台账.md)：本轮读取位置、哈希和不取用内容；
4. [教师工作流](./01_METHOD/教师工作流.md)：不用读代码也能执行；
5. [七道审核门](./01_METHOD/七道审核门.md)：每道门查什么、怎样退回；
6. [原型使用说明](./02_PROTOTYPE/README.md)：运行命令和数据结构；
7. `03_RECORDS/generated/audit_report.md`：运行后生成的逐版本审核报告；
8. [可入书方法提炼](./04_BOOK/可入书方法提炼.md)；
9. [主会话交接说明](./05_HANDOFF/主会话交接说明.md)；
10. [过程记录](./06_LOG/过程记录.md)：保留影响方法的选择、失败和修订依据。

## 一条最短路径

```bash
python3 02_PROTOTYPE/pipeline.py audit
python3 -m unittest discover -s 02_PROTOTYPE/tests -v
```

原型只使用 Python 标准库，不需要联网或安装依赖。

正式工作目录为 `/Users/yaril/个人文档/3 写作/图书出版/新项目推进/S3_素养导向题目改编流水线`。Codex 工作树中的同名目录只保留为迁入前快照。

## 已明确不声称

- 不声称修订题“质量更高”或“难度更合适”；
- 不声称一道题能够测量物理核心素养；
- 不声称自动检查等于物理教师审题；
- 不声称培训中的题库、数据和效果已经获得授权或复核；
- 不把试点定稿当作已经课堂试测的正式试题。
