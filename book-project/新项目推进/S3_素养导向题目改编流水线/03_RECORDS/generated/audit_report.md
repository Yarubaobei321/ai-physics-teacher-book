### Q001-C02 · 退回

**题面**：某校车制动时记录到 0、1、2、3、4 s 的速度依次为 12.0、9.1、6.0、3.2、0.1 m/s。请画出 v-t 图像，判断校车是否做匀减速运动，并求加速度和制动距离。

**版本变化**：

- `data_image`：直接给出恒定加速度 → 给出离散速度数据并要求作图判断；理由：让学生从数据和图像获得模型证据。；风险：测量精度、停止判据和计算方法若不说明，答案会漂移。
- `question_chain`：直接计算时间和位移 → 作图—判断—计算；理由：尝试建立证据链。；风险：前后问的证据关系尚未写清。

| 审核门 | 状态 | 证据或退回理由 |
| --- | --- | --- |
| G1 学段边界 | 通过 | 数据作图和匀变速判断在必修范围。 |
| G2 物理真值 | 通过 | 数据呈近似线性，但需要明确它是测量数据；自动复算：endpoint_slope=-2.975 m/s²。 |
| G3 条件充分 | 退回 | 题面缺少：位移估算方法、停止判据、读数分辨率。 |
| G4 答案设计 | 退回 | 允许多种估算方法却标为唯一答案，且未固定方法或误差。 |
| G5 认知要求 | 退回 | 目标为“分析与评价”，但题面没有要求：evidence_reasoning。 |
| G6 版权 | 通过 | 自编数据；来源类型：self_authored_internal。 |
| G7 可教性 | 通过 | 预计 15 分钟；纸笔或电子表格均可完成。 |

**教师处置记录**：`returned`。缺读数分辨率、停止判据和位移估算方法；同时把多方法任务误标为唯一答案。

### Q001-C03 · 内部试点定稿

**题面**：某校车在平直封闭测试路段进行制动测试。记录仪每隔 1.0 s 给出一次瞬时速度，读数分辨率为 0.1 m/s；沿行驶方向为正，4.0 s 时显示 0.0 m/s，视为车辆已停止。数据为：t/s＝0、1、2、3、4；v/(m/s)＝12.0、9.1、6.0、3.0、0.0。（1）描点作出 v-t 图像，判断 0—4 s 内能否近似看作匀减速运动，并写出至少一项定量证据；（2）用首末数据估算平均加速度；（3）用相邻数据点间的梯形面积之和估算制动距离；（4）测试人员据此声称‘全过程严格做匀减速运动’，评价这一说法并指出一项现有数据不能排除的因素。

**版本变化**：

- `condition_repair`：未说明分辨率、停止判据和位移方法 → 补充分辨率、瞬时速度含义、正方向、停止判据和梯形估算方法；理由：把开放性放在证据评价，不把必要条件留空。；风险：数据量仍不足以证明全过程严格线性。
- `answer_reframe`：误标为唯一答案 → 数值小问有约定方法，评价小问采用有界开放评分；理由：让不同结论必须受共同证据和评分标准约束。；风险：评分者需要审读论证而非只对数值。

| 审核门 | 状态 | 证据或退回理由 |
| --- | --- | --- |
| G1 学段边界 | 通过 | 数据描点、斜率、面积和模型近似均属于必修学习范围。 |
| G2 物理真值 | 通过 | 明确瞬时速度、正方向和近似模型；数值与图像可重算；自动复算：average_acceleration=-3 m/s²；trapezoid_distance=24.1 m。 |
| G3 条件充分 | 通过 | 7 项必要条件均已在题面或约定中出现。 |
| G4 答案设计 | 通过 | 混合题含 2 个唯一答案小问和 2 个有界开放小问。 |
| G5 认知要求 | 通过 | 题面动作覆盖目标动作：data_representation、evidence_reasoning、model_evaluation。 |
| G6 版权 | 通过 | 由自编题与自编数据修订；内部试点可用，外发前由作者确认署名；来源类型：self_authored_internal。 |
| G7 可教性 | 通过 | 预计 15 分钟，可用坐标纸完成；评分标准已列出。 |

**教师处置记录**：`provisional_final`。七门结构审核通过，作为内部试点定稿；仍待作者与另一位高中物理教师命题审读，未做课堂试测。
