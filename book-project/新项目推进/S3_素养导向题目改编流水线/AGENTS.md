# S3 题目改编流水线 Agent 规则

## PROJECT_SUMMARY

- **项目目标**：用一道自编高中物理题验证“原题—候选—退回—修订—试点定稿”的可追溯改编流程，形成一线教师能复核、复用的最小工具。
- **当前状态**：独立并行研发试点，不代表新书 B1 已裁决 S3，也不是书稿正文。样本数固定为 1 道原题、3 个后续版本。
- **正式工作目录**：`/Users/yaril/个人文档/3 写作/图书出版/新项目推进/S3_素养导向题目改编流水线`。2026-08-29 从 Codex 独立工作树迁入；旧工作树副本只作回滚快照，不再继续编辑。
- **主要入口**：`README.md` → `00_TASK/任务书.md` → `01_METHOD/教师工作流.md` → `02_PROTOTYPE/README.md`。
- **运行与验证**：在本目录运行 `python3 02_PROTOTYPE/pipeline.py audit`；测试运行 `python3 -m unittest discover -s 02_PROTOTYPE/tests -v`。
- **输出位置**：自动审核结果写入 `03_RECORDS/generated/`；方法提炼在 `04_BOOK/`；主会话交接在 `05_HANDOFF/`。
- **过程记录**：有分析价值的选择、失败和边界追加到 `06_LOG/过程记录.md`；不记录无助于复核的命令流水账。
- **范围边界**：不访问外部题库，不抓取或模拟登录学科网，不复制培训专家的详细项目，不收集学生数据，不修改新书 B1 总入口、书的宪法或 S1 文件。
- **已知风险**：自动检查只能发现结构、数值和记录缺口，不能证明题目质量更高、难度合适或能测量核心素养；外发和入书仍需作者及高中物理教师人工审读。

## 修改规则

- 每个版本必须有唯一 ID、父版本、变化、理由和最终处置。
- 被退回或否决的版本不得删除；后续修订必须新建子版本。
- 题目来源必须是自编、公共领域或有明确授权；教材只用于确认学段和概念边界，不复制题干。
- 自动报告属于辅助证据，不代替命题审读、课堂试测和版权裁决。
