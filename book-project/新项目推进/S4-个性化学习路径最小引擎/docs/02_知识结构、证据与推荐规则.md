# 知识结构、证据与推荐规则

## 目标与节点

目标能力不是“会做某一题”，而是能在一个给定力学过程中：选定系统，判断机械能是否守恒，正确写出初末能量；若条件不满足，知道换用动能定理或更一般的能量关系，并检查结果边界。

| 节点 | 含义 | 主要前置 |
| --- | --- | --- |
| K1 研究对象与系统 | 说清机械能属于哪个物体/物体系统 | 无 |
| K2 能量项与表达 | 识别动能、重力势能、弹性势能及归属 | K1 |
| K3 外力做功与守恒条件 | 区分“受力”与“做功”，判断是否只有重力/系统内弹力做功 | K1 |
| K4 初末状态表征 | 用状态表记录速度、高度、形变量和零势能面 | K2、K3 |
| K5 守恒列式与替代规律 | 条件成立时列机械能守恒；否则选择动能定理等 | K4 |
| K6 结果与边界复核 | 检查单位、符号、特殊值、能量去向和适用条件 | K5 |

## 证据事件

每次检查只记录一个“事件”，包含任务、时间顺序、结果和它直接观察的节点。v0.1只有三种结果：

- `pass`：本次任务提供了较充分的正向证据，记1；
- `partial`：本次证据混合或只完成一部分，记0.5；
- `not-yet`：本次尚未形成支持，记0；

这些数值只用于演示排序，不是掌握度、概率或分数。系统不从资源“已阅读”推断节点达成，只从检查任务结果更新。

## 状态词

| 状态 | 条件 | 页面措辞 |
| --- | --- | --- |
| 无直接证据 | 节点没有任何事件 | “证据待补，先安排低成本检查” |
| 当前证据待加强 | 加权均值低于0.6 | “这条线索值得复核” |
| 当前证据混合 | 同一节点同时出现pass与not-yet | “证据出现矛盾，不据此下结论” |
| 当前证据支持 | 加权均值不低于0.6且无明显矛盾 | “本轮可暂不优先” |

阈值0.6是原型排序参数，不是经验研究结论。教师可以否决任何由阈值产生的优先级。

## 排序规则

1. 先识别目标K6的前置链；
2. “证据出现矛盾”优先推荐复核任务，不推荐进阶资源；
3. “无直接证据”推荐最小检查任务，不能写成薄弱；
4. “当前证据待加强”按前置顺序排序，避免只根据同标签错题重复推送；
5. 每个候选由“1—2项微资源＋1个检查任务”组成；
6. 已被教师否决的候选从本轮列表移除，但否决记录保留；
7. 采用一个候选后不自动发送，只进入“待教师实施/模拟完成”区；
8. 新证据进入后重新计算，展示变化原因。

## 推荐理由模板

每项候选必须同时包含：

1. **依据**：哪一次合成检查提供了什么结果；
2. **可能卡点**：只写可复核假设，不写真实原因；
3. **不确定性**：哪些节点没有直接证据或证据冲突；
4. **行动**：为什么先看这些资源、再做哪项检查；
5. **教师控制**：教师可改写、换序或否决。

示例：“C01中系统边界部分尚未形成支持，而K2已有本轮正向证据。系统边界可能是更靠前的复核点；也可能只是任务表述影响。建议先读R01，再用C01的另一情境复核。教师可改写或否决。”

## 已知限制

- 任务与节点的映射由本项目作者人工设定，可能漏项或带有教学偏好；
- 三档结果压缩了学生表达的丰富性；
- 合成画像只能检验流程和文案，不能验证诊断效度；
- 资源顺序基于本微单元的教学推理，不代表所有教材版本和课堂；
- 没有长期遗忘、迁移、动机、时间成本和情感因素模型。
