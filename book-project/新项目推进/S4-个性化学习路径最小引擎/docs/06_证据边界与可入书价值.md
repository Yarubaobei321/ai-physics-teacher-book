# 证据边界与可入书价值

## 当前能证明什么

- 一个单元、少量资源和有限规则可以不用大模型、图数据库或题库，形成可运行的透明候选路径；
- 未知、证据待加强和证据矛盾可以在界面上分开处理；
- 推荐理由可以忠实回到检查事件和规则ID；
- 教师可以改写、采用或否决，并在检查后看到路径更新；
- 10项资源、4项任务、3个合成画像的静态结构可由自动测试复核。

## 当前不能证明什么

- 不能证明任何真实学生的认知原因、知识状态或学习需要；
- 不能证明推荐比教师原有安排更有效、更省时或更适合；
- 不能证明任务具有诊断效度、学习增益或跨课堂可迁移性；
- 不能证明机械能知识结构完整、顺序唯一或阈值合理；
- 不能把合成演示、测试通过、页面运行写成课堂使用或教学效果；
- 不能把培训讲者的设想、数据和实现写成作者自己的成果。

## 本轮新增的真实认识

1. **个性化路径的最小单位可以是“下一项可否决任务”**，不必从一开始就生成整套个性化作业。这样更符合教师可审查的现实工作量。
2. **知识结构不是技术名词，而是一组必须由教师负责的前置关系**。在6个节点的范围内，普通关系表已经足够；图数据库不会自动让关系正确。
3. **缺证据与负向证据必须分开**。把未观察节点记为0，会制造一个看似量化、实则越界的结论。
4. **完成资源与形成学习证据必须分开**。阅读记录只能说明任务状态，新的检查表现才允许更新路径。
5. **证据矛盾应成为教师介入点**。系统的价值不只是继续推荐，也包括知道何时暂停自动排序。
6. **推荐解释需要忠实于决策过程**。流畅的大模型说明可能只是事后故事；模板化理由虽然朴素，却能回到事件和规则。
7. **作者既有资源建设门禁可以迁移到路径推荐**：系统边界、物理条件、数据不被自动修正、教师最终裁决和失败保留，都是跨项目可复用的方法。

## 进入书中实践案例前的门槛

1. 物理教师逐项审过节点、资源、任务和理由；
2. 至少一次非开发者教师试用，保存其改写、否决和困惑；
3. 若使用真实课堂，另立知情同意、脱敏、数据最小化和研究方案；
4. 不把试用体验升级成效果结论；
5. 作者决定是否将S4作为D5材料生长案例回流；
6. 出版前重新核对教材表述、图片、许可、动态技术和链接。
