# 微资源与检查任务台账

## 资源原则

10项微资源和4个检查任务全部为S4原型自编。教材只用于确认概念范围、前置关系和常见教学难点；培训材料只用于发现“路径规划、前序补全、教师复核、完成后更新”等问题。没有复制教材题目、图片、段落、专家界面或题库内容。

## 4个检查任务

| ID | 标题 | 直接观察 | 任务边界 |
| --- | --- | --- | --- |
| C01 | 研究对象与守恒条件分拣 | K1、K3 | 自编三个无数值情境；不从一次选择推断认知原因 |
| C02 | 初末状态能量表 | K2、K4 | 检查能量项与参考面一致；不评价综合计算能力 |
| C03 | 守恒列式与替代规律选择 | K3、K5 | 检查规律选择是否与条件一致；不要求固定格式 |
| C04 | 换条件后的边界复核 | K5、K6 | 检查改变阻力、参考面、系统边界后的判断；允许写信息不足 |
