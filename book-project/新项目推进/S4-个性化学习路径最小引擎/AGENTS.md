# S4 项目工作规则

## PROJECT_SUMMARY

- **目标**：用一个高中物理微单元、10项自编微资源、4个自编检查任务和3个合成学习者画像，演示“初始证据→可能卡点→候选下一任务→教师裁决→完成后更新路径”。
- **当前状态**：v0.1.0 独立实验原型；不代表新书B1已完成裁决，不是课堂实证成果。
- **物理范围**：人教版高中物理必修第二册“机械能守恒的条件判断与解题路径选择”，不扩展到整章、实验数据处理或真实题库。
- **技术入口**：`app/index.html`；规则与数据分别在`app/engine.js`、`app/data.js`。
- **验证入口**：`node tests/test_engine.js`与`node tools/validate.js`，均不需要安装依赖。
- **材料入口**：`docs/04_来源、失败与版本记录.md`；教材和培训材料只读，微资源与检查任务全部自编。
- **教师审核门**：推荐理由、依据和不确定性必须可见；教师可以改写理由、采用或否决；没有教师采用，不形成“已布置任务”。
- **证据边界**：只使用合成画像；状态词只写“当前证据支持/待补/出现矛盾”，不写“准确诊断、真实掌握、最优路径”。
- **禁止事项**：不连接外部题库或模型API；不复制教材题目、培训专家实现或S1文件；不修改B1总入口、书的宪法及主项目台账。
- **回滚**：本项目只存在于独立工作树的本目录，删除整个S4目录即可完整回滚，不影响主项目。

## 修改规则

1. 新规则必须同时补充可读说明和自动测试。
2. 新资源必须写明来源身份、可复用范围和对应知识节点。
3. 任何自动推荐都先经过教师审核门；不得新增自动推送按钮。
4. 真实学生数据、姓名、作业、录音、账号与成绩不得放入本项目。
5. 若未来选择性回流，只回流本目录；上游B1状态仍由作者单独裁决。
