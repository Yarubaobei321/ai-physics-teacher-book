# S4 个性化学习路径最小引擎

版本：v0.1.0（2026-08-29）  
状态：可运行的独立实验原型，待物理教师人工审读

## 一句话说明

它不替学生下结论，只把有限学习证据整理成2—3个候选下一任务，并把理由、不确定性和最终决定权交给教师。

## 直接查看

打开[`app/index.html`](./app/index.html)。无需安装依赖、无需联网、无需账号；页面数据只存在当前浏览器内存，刷新即可复位。

建议依次体验三个合成画像：

1. 条件判断证据待加强；
2. 能量表达证据待加强；
3. 证据不足，先补检查。

在候选任务中可以改写推荐理由、采用或否决；采用后选择“未形成证据／部分完成／完成”，页面会重新计算路径并保留一条本次会话内的教师裁决记录。

## 已做到

- 单一微单元：机械能守恒的条件判断与解题路径选择；
- 10项自编微资源、4个自编检查任务；
- 3个合成学习者画像，不含真实学生数据；
- 显式知识关系、证据聚合和确定性规则；
- 2—3项候选下一任务及可见理由；
- 教师改写、采用、否决和完成后路径更新；
- 对未知证据、矛盾证据和失败结果分别处理；
- 无外部题库、无模型API、无第三方依赖。

## 没有做到

- 没有验证真实学生的学习原因、掌握状态或学习效果；
- 没有证明推荐任务更优，也没有寻找所谓“最短/最适合路径”；
- 没有接入教材全文、题库、学生成绩、课堂录音或真实账号；
- 没有形成B1作者裁决、书稿正文或可直接发布的教学产品。
