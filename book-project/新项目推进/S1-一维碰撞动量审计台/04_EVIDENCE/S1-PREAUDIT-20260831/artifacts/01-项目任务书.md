# S1 项目任务书：一维碰撞动量审计台

> 版本：v0.2-workspace  
> 状态：已授权建立独立工作区；物理真值与教学任务仍待逐门审核  
> 第一读者：一线高中物理教师

## 1. 真实教学问题

一维碰撞课堂中，学生能看见物体碰后怎样运动，却不容易在同一对象上同时判断：

- 正方向和速度正负怎样对应；
- 单个物体的动量变化与系统总动量守恒有什么区别；
- 总动量守恒与总动能守恒为什么不是同一件事；
- 页面给出的结论是否能用原始数独立复算。

S1 先把这些关系变成一个可操作、可定格、可复算的共同对象，再研究它能否迁移到已有的弹簧、小球—小环等复杂模拟。

## 2. 最小作品

### 物理对象

- 两个物体在同一直线上运动，质量为 `m1、m2`，碰前速度为 `u1、u2`；
- 明确取向右为正，负速度同时进入计算与箭头显示；
- 首版只含弹性碰撞和完全非弹性碰撞；
- 碰撞动画只表示短时事件，不生成未经建模的真实力—时间曲线。

### 页面必须看得见

1. 系统边界与正方向；
2. 碰前、碰撞事件、碰后三个可跳转状态；
3. 两个物体速度箭头，方向与数值符号一致；
4. `p1、p2、P总` 的有正负条形图，碰前后并排；
5. 碰前后总动能并排；
6. 质量、速度、动量和动能均带单位，关键数据可抄写；
7. 页面结论由当前参数的真实比较驱动，不设置永远点亮的“守恒”徽章。

### 页面必须让学生做事

- 播放前预测碰后方向；
- 改变质量比，寻找等质量弹性碰撞的速度交换；
- 把一个初速度改成负值，检查正方向与矢量性；
- 比较两类碰撞，说明什么守恒、什么不一定守恒；
- 使用页面原始数独立计算一次总动量和总动能。

## 3. 当前不做

- 把程序计算值标成测量值或实验数据；
- 学生账号、成绩、个性化推荐和自动能力诊断；
- 改写或覆盖数智育才网站现有动量页面；
- 在线部署。

## 4. 独立真值与测试

解析关系是首版唯一物理状态源，动画引擎不决定末速度。

完全非弹性碰撞共同速度：

`v = (m1*u1 + m2*u2) / (m1 + m2)`

一维弹性碰撞通式已经登记在事实源，但在实现前仍需物理教师独立推导和复核。

| 编号 | 输入或情形 | 必须出现的结果 |
| --- | --- | --- |
| T1 | 弹性，`m1=m2，u2=0` | `v1=0，v2=u1` |
| T2 | 完全非弹性，`m1=m2，u2=0` | 共同速度 `u1/2`，动能减少一半 |
| T3 | 弹性，`m1=m2，u1=-u2` | 交换速度，总动量仍为 0 |
| T4 | 碰前总动量为 0 | 碰后总动量仍为 0，不能只看方向判断 |
| T5 | 同向且后车速度不大于前车 | 提示当前初态不会发生追碰 |
| T6 | 质量取允许范围两端 | 无 NaN、无异常状态，符号、单位和残差正确 |
| T7 | 审核副本故意注入错误末速度 | 守恒检查必须不过 |

## 5. 最低充分技术

- 独立静态 HTML，使用 SVG 或 Canvas，首版不使用 3D；
- 解析模型、可视状态和渲染分离；
- 播放倍率只改变观看速度，不改变计算结果；
- 教师调试区可折叠显示残差与测试；
- 不需要外部 API、数据库和登录。
