# 一维弹性碰撞通式独立推导与复算

> 状态：AI独立推导与自动复算材料；物理教师终审批注待完成。  
> 日期：2026-08-31  
> 对象：质量均大于0的两个物体，在同一直线上发生弹性碰撞；碰撞过程中系统外力冲量可忽略；向右为正。

## 1. 从两条独立关系求末速度

动量守恒：

```text
m1·u1 + m2·u2 = m1·v1 + m2·v2          (1)
```

弹性碰撞还满足相对接近速度等于相对分离速度：

```text
u1 - u2 = v2 - v1                       (2)
```

由式（2）得`v2 = v1 + u1 - u2`，代入式（1）：

```text
m1·u1 + m2·u2
= m1·v1 + m2·(v1 + u1 - u2)
= (m1+m2)·v1 + m2·u1 - m2·u2
```

整理得：

```text
v1 = [(m1-m2)·u1 + 2m2·u2] / (m1+m2)
```

再代回式（2）：

```text
v2 = [2m1·u1 + (m2-m1)·u2] / (m1+m2)
```

## 2. 第二条计算链：质心速度反射

质心速度：

```text
Vcm = (m1·u1 + m2·u2) / (m1+m2)
```

在质心系中，弹性正碰后两物体速度反向；变回实验室参考系：

```text
v1 = 2Vcm - u1
v2 = 2Vcm - u2
```

这条链与通式代数等价，但实现路径不同，可用作程序的第二求解器。页面主模型采用通式；自动测试同时调用质心求解器，二者不一致即失败。

## 3. 三个守恒／一致性残差

```text
动量残差 ΔP = (m1·v1+m2·v2) - (m1·u1+m2·u2)
动能残差 ΔK = 1/2·m1·v1² + 1/2·m2·v2²
            - (1/2·m1·u1² + 1/2·m2·u2²)
相对速度残差 Δvr = (v2-v1) - (u1-u2)
```

浮点计算用相对／绝对混合容差判断，不把显示四舍五入后的数再次用于物理计算。

## 4. 特殊值人工复算

| 情形 | 通式结果 | 物理检查 |
| --- | --- | --- |
| `m1=m2=m，u2=0` | `v1=0，v2=u1` | 等质量速度交换 |
| `m1=m2=m，u1=-u2=u` | `v1=-u，v2=u` | 总动量为0，交换速度 |
| `u1=u2=u` | `v1=v2=u` | 相对速度为0，没有追碰事件 |
| `m2≫m1，u2=0` | `v1≈-u1，v2≈0` | 小物体撞近似固定大物体后反弹 |
| `m1≫m2，u2=0` | `v1≈u1，v2≈2u1` | 重物速度变化很小，轻物体获得近两倍速度 |

## 5. 是否会发生碰撞

首版只表示两物体位于同一直线上、物体1在左、物体2在右的追碰情形。初始间距为正时，只有：

```text
u1 > u2
```

才会在未来发生碰撞。`u1≤u2`时仍可计算“假设发生碰撞的末速度”，但页面不得播放成未来真实事件；应显示“当前初态不会追碰”，让学生修改初态。
