# S1 失败与修正记录

## 记录格式

| 字段 | 内容 |
| --- | --- |
| 失败 ID | `S1-FAIL-YYYYMMDD-序号` |
| 对象与版本 | 文件、模型、页面或任务 |
| 触发条件 | 输入、操作和环境 |
| 实际现象 | 可观察事实，不先解释原因 |
| 影响 | 物理、教学、视觉、工程或证据 |
| 初步假设 | 可有多项，标明未证实 |
| 定位证据 | 测试、复算、截图、代码位置或教师观察 |
| 修正 | 实际采取的动作 |
| 复验 | 方法、版本和结果 |
| 可复用认识 | 是否转为测试、检查表、课堂提醒或书中方法 |

## 当前状态

本次工作区初始化未记录原型开发失败。后续不得为了充实材料虚构失败；被测试或教师审核发现的真实问题按上述格式追加。
