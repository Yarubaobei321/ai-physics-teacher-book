# S1 一维碰撞动量审计台

这是 S1 的独立研发工作区。它既用于制作最小教学网页，也用于保存具有分析价值的推导、试错、反馈、审核和入书提炼。

> 当前状态：工作区已初始化，网页尚未开发。  
> 初始化日期：2026-08-29  
> 当前主张上限：已经完成项目立项与记录架构，不能据此声称网页可用、物理终审通过或产生课堂效果。

## 从哪里开始

1. 阅读 `00_TASK/项目任务书.md`，确认最小作品和不做项；
2. 阅读 `00_TASK/事实源.yaml`，检查已核验事实与待核公式；
3. 按 `00_TASK/人机共同审核方案.md` 推进阶段门；
4. 每次工作同步写入 `03_RECORDS/`；
5. 阶段完成后在 `04_EVIDENCE/` 生成证据包；
6. 只有成熟且经作者裁决的认识进入 `05_BOOK/`。
