# 过程记录入口

过程材料只要能帮助解释一次判断、失败、修正或可复用方法，就应及时落盘。

## 文件分工

- `项目日志.md`：每轮做了什么、验证到哪里、下一停止点；
- `决策记录.md`：重要取舍、替代方案和理由；
- `失败与修正记录.md`：错误、退回、定位、修正和复验；
- `反馈与版本记录.md`：保留反馈原话并追踪到版本；
- `价值生长台账.md`：提炼对教学、AI应用、工程和本书的新增价值。

## 记录门槛

以下内容值得记录：

- 改变物理模型或适用边界；
- 改变学生任务、教师操作或视觉表达；
- 形成新的测试、检查表、模板或排错路径；
- 暴露一个常见误解或 AI 容易犯的错误；
- 证明某种设计没有教学增量，需要缩小或放弃。

机械命令流水、无判断价值的临时输出和重复状态不进入长期记录。
