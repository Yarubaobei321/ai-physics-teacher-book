# 证据包入口

每个阶段证据包至少包含：

- `manifest.json`：文件来源、包内路径、大小、SHA-256、隐私状态和 Git 状态；
- `evidence-summary.md`：需求、范围、完成、失败与修正、验证边界、教学价值和回滚；
- `artifacts/`：最小充分证据，不复制整个工作区。

验证结论只使用：`verified`、`partially_verified`、`pending`、`not_tested`。

软件测试不等于实体课堂验证。含学生信息、令牌、局域网地址或未经授权图片的材料必须脱敏或标为 `pending`，不得进入可公开证据包。
