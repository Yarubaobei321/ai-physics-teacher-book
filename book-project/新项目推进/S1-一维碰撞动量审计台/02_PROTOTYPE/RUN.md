# S1 v0.3运行与验证

## 直接打开

双击[一维碰撞动量审计台](./index.html)。页面使用已经生成的本地单文件脚本，无需联网、账号、API、数据库或本地服务器。

如果修改了`src/model.js`或`src/app.js`，先在本目录运行：

```bash
npm run build
```

不要直接编辑`dist/app.bundle.js`。它由两份源码机械生成，作用是避开部分浏览器对`file://`本地模块导入的限制。

建议按以下顺序体验：

1. 选择“等质量速度交换”，先预测两个物体碰后方向；
2. 揭示结果，切换碰前／碰撞事件／碰后三个状态；
3. 查看带正负零轴的个体动量与总动量条；
4. 将一个初速度改为负值；
5. 切换完全非弹性碰撞，比较动量与总动能；
6. 抄下表格原始数，独立复算四项总量；
7. 选择“当前不会追碰”，检查页面是否拒绝播放成未来事件。

## 自动验证

在本目录运行：

```bash
npm test
node --check src/model.js
node --check src/app.js
```

当前结果：离线浏览器包重建成功；T1—T7、500组确定性随机双求解器对照、非法输入边界共9组检查通过；生成文件语法检查通过。

## 已实现的第二真值回路

- 主求解器：一维弹性碰撞通式；
- 第二求解器：质心速度反射法；
- 审计：总动量残差、总动能变化、两个求解器速度差；
- 故障注入：测试将一个末速度人为增加0.25 m/s，审计必须判为不过。
