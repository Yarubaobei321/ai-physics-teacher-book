# 原型开发区

v0.3预审原型已经建立，可直接双击`index.html`打开。页面不联网、不保存输入，不含真实学生数据。

## 当前结构

- `index.html`：预测、三状态、动量／动能比较、独立复算和边界；
- `styles.css`：响应式视觉与正负冗余编码；
- `src/model.js`：输入校验、两类碰撞求解、第二求解器和独立审计，是唯一模型源码；
- `src/app.js`：界面状态与渲染源码；
- `tools/build-browser.mjs`：从模型和界面源码生成离线浏览器包；
- `dist/app.bundle.js`：供双击本地页面加载的生成文件，不单独维护公式；
- `tests/verify.mjs`：T1—T7、500组双求解器对照和输入边界；
- `RUN.md`：打开方式、验证命令、已完成与待审核。

## 当前验证

`npm test`会先重建离线浏览器包，再执行模型测试和生成文件语法检查；当前输出9/9检查通过。验证覆盖解析关系、边界和错误注入，不替代浏览器人工操作、物理教师终审或课堂试用。
