## 来源登记原则

- 教材、论文、已有网页和作者决定使用稳定 `source_id`；
- 精确结论回到原件位置，不能只引用文件名或摘要；
- 外部讲座只用于发现问题，未经授权不复制方案、页面或原始素材；
- 每项来源写清能证明什么、不能证明什么；
- 动态工具信息在实际使用时重新核验。
