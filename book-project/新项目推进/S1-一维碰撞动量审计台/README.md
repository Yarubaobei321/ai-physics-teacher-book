# S1 一维碰撞动量审计台

这是 S1 的独立研发工作区。它既用于制作最小教学网页，也用于保存具有分析价值的推导、试错、反馈、审核和入书提炼。

> 当前状态：v0.3预审原型已实现，G3自动测试通过；物理教师终审、真实课堂操作与作者入书裁决待完成。  
> 初始化日期：2026-08-29；原型日期：2026-08-31  
> 当前主张上限：本地解析模型、页面结构与约定自动测试已通过；不能据此声称物理教师终审、课堂可用或产生学习效果。

## 从哪里开始

1. 双击打开 `02_PROTOTYPE/index.html`体验预审原型；
2. 阅读 `02_PROTOTYPE/RUN.md`了解验证命令和边界；
3. 阅读 `00_TASK/事实源.yaml`，检查已核验事实、自动预审与待教师终审公式；
4. 按 `00_TASK/人机共同审核方案.md`继续G4—G6；
5. 只有成熟且经作者裁决的认识进入 `05_BOOK/`。
