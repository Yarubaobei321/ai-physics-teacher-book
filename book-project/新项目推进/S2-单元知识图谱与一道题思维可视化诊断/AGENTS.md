# S2 独立研发规则

## PROJECT_SUMMARY

- **目标**：围绕高中物理“机械能及其守恒”单元，研发一个离线可运行的最小系统，把教材知识关系、一道自编题的标准推理链和学生文字表述连接起来，为教师提供可复核的概念断点提示。
- **状态**：独立候选原型，不是 B1 总入口、书稿正文、课堂研究结论或自动诊断产品。
- **入口**：`README.md`；运行界面为 `app/index.html`；主会话交接为 `HANDOFF.md`。
- **主要目录**：`app/` 为离线界面，`data/` 为图谱与提示规则，`docs/` 为材料、物理、教学、版权和失败记录，`tests/` 为静态与样例验证，`release/` 为教育发布闸门，`review/` 为非技术审阅页。
- **运行与验证**：浏览器直接打开 `app/index.html`；运行 `node tests/verify_mvp.mjs`；运行教育发布闸门脚本检查 `release/s2-release-gate.yaml`。
- **输出边界**：不采集真实学生数据；不访问外部题库；不上传文本；不输出成绩、能力画像或自动诊断结论；语音只保留接口说明。
- **回流原则**：主会话逐文件选择性复制。不得用本目录覆盖现有 B1、书的宪法、S1 或其他研发项目。

## 修改要求

1. 新关系必须有教材、作者材料或明确的教师判断来源。
2. 诊断规则只能生成“可见证据、可能断点、教师复核问题”，不得改成确定性认知归因。
3. 题目、图形和示例保持自研，不复制培训专家的文本、界面、数据或流程图。
4. 新增个人数据入口前必须停止并重新做隐私与伦理审查。
5. 改动 `data/` 或 `app/` 后必须重跑 `node tests/verify_mvp.mjs`。
