## 题目

质量 `m=0.50 kg` 的小滑块从光滑轨道上距水平面 `h=1.80 m` 的 A 点由静止释放。B、C 之间是长 `L=2.0 m` 的粗糙水平面，滑块与该段的动摩擦因数 `μ=0.20`；其余轨道光滑。滑块越过 C 后沿右侧轨道上滑到最高点 D。取 `g=10 m/s²`，B、C 所在水平面为零势能面。

求 `vB`、`vC` 和最高点 D 的高度 `H`，并评价“全过程能量没有消失，所以滑块机械能始终守恒”这句话。请逐段说明研究系统、适用规律和理由。

## 选择这道题的理由

同一个情境中，AB和CD满足滑块—地球系统机械能守恒，BC因摩擦而不满足。学生必须区分：

1. 总能量守恒与机械能守恒；
2. 一个连续轨道与三个不同条件的过程；
3. 正确结果与可解释的规律选择；
4. 滑块—地球系统与扩展到含轨道的系统；
5. 摩擦力做功、机械能减少和内能增加。

## 标准推理树

```text
读题
├─ 分段：AB光滑 / BC粗糙 / CD光滑
├─ AB：滑块—地球系统
│  ├─ 支持力不做功，只有重力做功
│  ├─ 机械能守恒
│  └─ mgh = 1/2 mvB² → vB = 6.0 m/s
├─ BC：先以滑块为研究对象用动能定理
│  ├─ 重力、支持力不做功
│  ├─ 摩擦力 f=μmg，Wf=-μmgL=-2.0 J
│  └─ EkC=EkB+Wf=9.0-2.0=7.0 J
│     └─ vC=√(2EkC/m)=√28 m/s≈5.29 m/s
├─ CD：滑块—地球系统
│  ├─ 支持力不做功，只有重力做功
│  ├─ 机械能守恒
│  └─ EkC=mgH → H=1.40 m
└─ 评价原说法
   ├─ BC段滑块—地球系统机械能不守恒
   ├─ 机械能减少2.0 J，滑块与轨道内能增加
   └─ 把滑块、地球、轨道纳入更大系统时，总能量守恒
```

## 数值复核

### AB段

初始重力势能：

`EpA=mgh=0.50×10×1.80 J=9.0 J`

由机械能守恒：

`1/2 mvB²=9.0 J`

`vB=√(2×9.0/0.50) m/s=6.0 m/s`

### BC段

`f=μmg=0.20×0.50×10 N=1.0 N`

`Wf=-fL=-1.0×2.0 J=-2.0 J`

`EkC=EkB+Wf=9.0 J-2.0 J=7.0 J`

`vC=√(2×7.0/0.50) m/s=√28 m/s≈5.29 m/s`

### CD段

`mgH=EkC=7.0 J`

`H=7.0/(0.50×10) m=1.40 m`

## 物理表述边界

- “只有重力做功”针对本题选定的滑块—地球系统和光滑轨道理想化；支持力存在，只是本题中不做功。
- BC段若只取滑块为研究对象，可直接用动能定理；若取滑块—地球系统，摩擦力对该系统造成机械能减少；若再把轨道纳入，则需讨论系统内能增加。
- 不能笼统写“摩擦消耗能量”。应写清减少的是机械能，增加的是内能，总能量没有消失。
- D点是沿固定轨道上滑的最高点，瞬时速度为零。这个条件不能机械迁移到所有二维抛体的最高点。
