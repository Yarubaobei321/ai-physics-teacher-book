# 失败与否决记录

## F01 工作树上下文路径不存在

- **现象**：线程上下文把工作目录写成 `…/worktrees/013f/3 写作/图书出版`，实际 Git 工作树根是 `…/worktrees/013f/3 写作`，其中尚无“图书出版”目录，最初命令无法启动。
- **原因**：上下文路径把尚未检出的子目录当成了当前目录。
- **处理**：先在 `/tmp` 做只读核对，确认真实 Git 工作树，再建立独立 S2 目录；没有向主新书目录写文件。
- **价值**：并行项目交接不能只相信显示的 cwd，应核对 Git worktree 与实际目录同时存在。

## F02 直接搜索大 CSV 产生大量教材图片噪声

- **现象**：在 6.6 MB 文件级索引中搜索“机械能”时，大量教材图片行淹没了可读底本。
- **原因**：机械索引按文件登记，图片路径和材料说明重复出现，不能替代材料入口。
- **处理**：回到 `本书资料台账.md` 与教材主题导航卡，定位三份权威 Markdown，再按章节行号定向读取。
- **价值**：材料存在性索引适合发现，物理主张必须回到可读底本；索引越全，越需要二次收束。

## F03 曾考虑沿用“学生树—标准树—结构评分”

- **现象**：培训项目已经给出完整的知识图谱、思维树、SOLO评价与报告路径，表面上可以快速复刻。
- **风险**：边数、分支数和树形复杂度不能直接证明物理正确、思维灵活或高阶；复制还会侵犯用户要求的自研与版权边界。
- **处理**：只保留“学生表述与标准关系对照”这一抽象问题；删除结构评分、SOLO定级、灵活性／高阶性评价和自动处方。
- **价值**：S2的核心不是把推理画成树，而是让每条提示回到原句、物理关系、条件和不确定性。

## F04 关键词缺失一度被设计成“概念断点”

- **现象**：早期规则草案把未命中关键词直接标为断点。
- **风险**：学生可能省略、使用同义表达，规则也可能漏识别；这会把书写表现误当认知事实。
- **处理**：输出改为“未见显式证据”，同时列出三种解释；只有与本题条件直接冲突的句子才进入“需优先核对”。
- **价值**：诊断边界需要进入产品语言，而不能只藏在说明文档中。

## F05 详细培训图片有一张本地预览显示为纯黑

- **现象**：`P21-四选项思维树对比图.png` 在本地原始预览中显示为黑底，无法可靠辨认具体图形。
- **处理**：不转换、不修图、不猜测图形内容；只使用同份 Markdown 中可核对的页面文字，并查看其他可正常显示的图谱与报告截图。
- **价值**：视觉材料无法可靠读取时，应降低证据等级，不能用演讲备注替代图中事实。

## F06 主工作目录在研发中途调整

- **现象**：项目先在013f并行工作树中建立，用户随后指定 `/图书出版/新项目推进/` 下新建S2文件夹作为工作目录。
- **处理**：把本地 `新项目推进/S2-单元知识图谱与一道题思维可视化诊断` 设为主副本；013f工作树保留选择性回流镜像，后续交付明确主副本，避免误把两个版本同时编辑。
- **价值**：并行研发需要同时满足过程隔离与用户可见落盘；交接必须写清当前权威副本。

## F07 第一轮自动验证未通过

- **现象一**：完整解释样例只命中6/8，漏掉CH04“守恒条件与规律选择”和CH08“总能量／机械能边界”。
- **原因一**：规则只允许关键词相距18个字符；自然表述在“BC段”与“机械能不守恒”之间插入了摩擦功和系统说明，超过窗口。
- **修正一**：只针对同一短段的窗口放宽到48—64个字符，并保留物理关键词组合约束，避免改成任意全文共现。
- **现象二**：教育发布闸门把证据隐私状态判为非法。
- **原因二**：档案使用了`not_applicable`／`synthetic_only`，闸门只接受`cleared`、`redacted`、`pending`。
- **修正二**：确认全部证据不含真实学生数据后统一改为`cleared`。
- **价值**：测试样例需要模拟自然解释的句长；发布档案必须以机器实际schema为准，不能自行发明更细枚举。

## F08 `xmllint` 不适合作为本项目的HTML5检查器

- **现象**：`xmllint --html`把`header`、`main`、`section`和内联SVG全部报告为无效标签。
- **原因**：本机libxml HTML解析器按旧HTML4标签集工作，不理解HTML5语义元素与SVG；本机HTML Tidy也是2006版，同样不足以作为稳定门禁。
- **处理**：不把这些工具警告冒充页面缺陷；改用项目测试检查本地链接、必需边界文本、无网络／存储接口和JavaScript语法。遵守项目规则，不自动启动浏览器截图或视觉验收。
- **价值**：验证工具必须匹配文档标准。当前保留“浏览器视觉效果待人工查看”，不以旧解析器的噪声掩盖真正检查项。
