# S2 范围与完成标准

## 要做的事

1. 从本地已登记教材、作者阶段材料和培训材料中选择一个物理单元；
2. 建立 30—50 个可追溯、可人工审读的概念关系节点；
3. 自编一道能暴露多类推理关系的题，给出标准推理树；
4. 允许输入学生文字说明，映射到可见证据与可能断点；
5. 形成可离线运行页面、测试、审核、失败记录和入书价值提炼。

## 不做的事

- 不修改新书 B1 总入口、书的宪法、S1 文件和现有正文；
- 不调用、抓取或模拟登录任何未授权题库；
- 不复制培训专家的方案、文本、界面、数据或诊断模型；
- 不收集真实学生姓名、学号、录音、作业照片或历史画像；
- 不开发语音转写、自动推题、班级分析、评分和学习路径推荐；
- 不宣称学习效果、诊断准确率或可普遍推广。

## 完成标准

| ID | 标准 | 验证 |
| --- | --- | --- |
| AC-01 | 独立目录，现有 B1／宪法／S1 无修改 | Git 范围检查 |
| AC-02 | 单元选择有教材、作者材料和培训问题三类依据 | `01_材料回查与对象选择.md` |
| AC-03 | 图谱 30—50 个节点，边端点和来源完整 | `node tests/verify_mvp.mjs` |
| AC-04 | 题目自编，答案、单位、守恒条件正确 | `02_自编题与标准推理树.md`＋发布闸门 |
| AC-05 | 自由文字可生成可解释提示并联动图谱 | 离线页面＋4个样例测试 |
| AC-06 | 页面明确“教学提示，不是自动诊断结论” | 页面结构测试＋人工审阅 |
| AC-07 | 无真实学生数据、无网络请求、无外部题库接入 | 静态扫描＋隐私说明 |
| AC-08 | 物理、教学、版权、交付四层审核有明确结论 | 发布闸门档案 |
| AC-09 | 有真实失败记录和可入书新增价值 | `06_失败记录.md`、`07_可入书价值提炼.md` |

## 风险与回滚

- **物理风险**：图谱关系或题解条件可能被简化。回滚为删除有争议边或把它标成“教师待审”，不保留错误关系求完整。
- **教学风险**：关键词缺失被误读为概念缺失。回滚为只展示“未见显式证据”和复核问题，停用断点名称。
- **版权风险**：第三方材料被误作题目或界面素材。回滚为只保留来源台账，题干、图形、样例全部重写。
- **数据风险**：当前不持久化。若未来增加存储或语音，必须另立任务并重新获得授权。
- **文件回滚**：本项目全部新增在 S2 独立目录，移除该目录即可撤回，不影响主项目现有文件。
