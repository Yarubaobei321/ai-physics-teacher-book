## 有意否决的关系

| 候选错误边 | 否决理由 |
| --- | --- |
| “题目做错 → 某知识点不会” | 一次表述不足以推出稳定认知状态 |
| “思维树边数更多 → 思维更高阶” | 结构复杂不等于物理正确或理解深入 |
| “分支更多 → 灵活性更高” | 错误试探也会增加分支，需看物理内容与条件 |
| “没有出现关键词 → 概念断点” | 学生可能省略、用同义表达或规则漏识别 |
| “摩擦存在 → 能量不守恒” | 机械能可能减少，总能量仍守恒 |
| “网页能映射 → 自动诊断成立” | 只能作为教师追问提示，未经效度研究 |
