# 文字映射与隐私边界

## 当前实现是什么

MVP使用教师编写的透明规则，识别文字中显式出现的分段、系统、做功、守恒条件、规律选择、关键数值和边界表述。每个检查点公开：

1. 它在找什么；
2. 命中了哪段原文；
3. 关联哪些图谱节点；
4. 教师下一句可以追问什么。

这是一条安全基线，不是大语言模型，也不假装理解学生内心。它为未来本地模型接口保留清晰的输入输出契约：任何模型输出都必须落回相同的证据字段和教师复核边界。

## 八个检查点

| ID | 可见证据 | 未见时的教师行动 |
| --- | --- | --- |
| CH01 | AB／BC／CD分段 | 让学生指出何处条件发生变化 |
| CH02 | 滑块—地球或含轨道系统 | 追问“重力势能属于谁，内能算在哪里” |
| CH03 | 支持力不做功、摩擦力做负功 | 追问力与位移夹角 |
| CH04 | 光滑段守恒、粗糙段换律 | 让学生先判断条件再选公式 |
| CH05 | AB关系或 `vB=6.0 m/s` | 追问数值对应哪一段和哪条规律 |
| CH06 | 摩擦功、C点动能／速度 | 检查是否把摩擦计入 BC 段 |
| CH07 | C点动能到最高点高度 | 检查是否误用 A 点初始势能 |
| CH08 | 机械能边界与总能量／内能 | 分别说清“哪个系统的哪种能量” |

## 输出等级

系统只有三种状态：

- **文字中可见**：规则找到了足够的显式表达；
- **未见显式证据**：建议教师追问，不能写成“学生不会”；
- **需优先核对**：原文出现与本题物理条件直接冲突的表述。

不输出分数、正确率、SOLO层级、能力等级、灵活性、高阶性、学生画像或个性化推荐。

## 规则局限

- 同义表达、隐含推理、口语省略和公式格式可能漏识别；
- 学生可能复制标准表述但并不理解；
- 数值正确可能来自猜测或记忆，数值错误也可能只是计算失误；
- 一次回答不能代表稳定认知状态；
- 标准推理树是一条可审读路径，不是唯一合法解法。

## 隐私与数据

- 当前页面没有账号、数据库、网络请求、日志和持久化存储；
- 输入只在浏览器当前内存中处理，刷新即清空；
- 四个示例全部由本项目自构，不代表真实学生；
- 页面提示用户不要输入姓名、学号或其他个人信息；
- 未接入摄像头、麦克风、照片、录音或手写识别。

## 语音后续接口（未实现）

若未来增加语音，只允许形成如下中间对象：

```json
{
  "utterance_id": "匿名本地编号",
  "transcript": "转写文本",
  "uncertain_spans": ["模型不确定的词段"],
  "consent_record": "单独保存的知情同意状态",
  "retention": "本地、短期、可删除"
}
```

语音转写不确定必须与物理关系断点分开呈现。没有知情同意、脱敏、删除机制和教师复核流程时，不进入真实学生试用。
