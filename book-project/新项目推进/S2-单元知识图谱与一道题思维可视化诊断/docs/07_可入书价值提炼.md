# 可入书价值提炼

## 当前新增的真实认识

### 1. 知识图谱的最小单位应是“有条件的关系”

机械能单元最容易被整理成“功—动能—势能—机械能—守恒”的名词树。真正影响学生解题的关系还包括：先选系统、再判做功；条件改变时必须分段；机械能减少和总能量守恒可以同时成立；计算结果要能回到条件和证据。

可入书形态：一张“名词树为什么不够”的对照图，以及教师构图的六类关系模板。

### 2. 标准推理树不能直接充当学生认知真相

学生文字与标准路径不同，可能意味着概念关系缺失，也可能只是省略、同义表达、合法替代方法或规则漏识别。系统需要把“文字证据”“关系未见”“物理冲突”“教师判断”分开。

可入书形态：三状态提示语言、教师追问卡和误判清单。

### 3. 更复杂的树不必然代表更高阶的思维

边更多、分支更多可以来自有效试探，也可以来自概念混乱。思维结构指标若脱离物理正确性、条件与证据，只能描述表达形态，不能直接评价思维质量。

可入书形态：一个被否决的自动评价方案，以及“先做物理真值审查，再谈结构特征”的门禁。

### 4. 透明规则可以成为AI系统的安全基线

当前MVP没有调用大模型，但它定义了未来AI必须遵守的输出契约：引用原句、关联节点、说明不确定、提出复核问题、不输出认知结论。以后接入本地模型时，可以用同一批自构样例比较模型是否超出边界。

可入书形态：从规则基线到模型增强的渐进路线、可替换接口和回归测试模板。

### 5. 一道题可以同时检查“会算”和“会选”

自编题让AB、BC、CD三个阶段在同一情境中改变条件。正确数值只回答“算到了什么”；文字说明还暴露“为什么分段、选哪个系统、为什么换规律、能量去了哪里”。

可入书形态：一道题的题目谱系、标准推理树、四种自构表述和对应教师追问。

## 可复用的读者工具

1. **单元图谱六类关系表**：定义、组成、前置、条件、证据、边界；
2. **一道题选择表**：一道题至少能暴露两个合法方法或两个条件变化；
3. **文字映射三状态**：可见／未见／冲突；
4. **教师复核四问**：原句是什么、关系是什么、还有何解释、下一句追问什么；
5. **隐私最小化单**：先用自构样例，语音和真实学生数据另立门禁；
6. **AI输出契约**：不评分、不画像、不自动处方，所有提示可追溯。

## 目前还不能入书的内容

- 本系统提高了学生成绩、思维水平或教师效率；
- 规则覆盖了学生自然语言的主要表达；
- 图谱是机械能单元的最优结构；
- 一次回答可以定位稳定认知断点；
- 培训项目的成效数字已被复核或可以迁移。

## 下一轮最有价值的材料生长

不扩功能，先请2—3位物理教师各用一条自构学生表述审读：

1. 哪条提示会让教师产生错误判断；
2. 哪个图谱节点命名不符合一线课堂语言；
3. 哪个追问最能区分“没写”与“没懂”；
4. 是否存在另一条完全合法但当前规则漏掉的解法。

这轮反馈完成前，不接真实学生、不做语音、不做自动推题。
