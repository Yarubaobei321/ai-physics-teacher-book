# S2：单元知识图谱＋一道题思维可视化提示

这是一个完全自研、无第三方依赖、可离线运行的候选最小系统。它用“机械能及其守恒”单元的一张人工审读图谱和一道自编题，检查学生文字中**可见的推理证据**，把可能遗漏或冲突的关系指回图谱节点，供教师复核。

## 立即查看

双击打开 [`app/index.html`](app/index.html)。页面不联网，输入只在当前浏览器内存中处理，刷新即清空。

也可以运行验证：

```bash
node tests/verify_mvp.mjs
```

## 已实现

- 40 个节点的人工审读知识图谱，覆盖概念、规律、条件、过程、证据与边界；
- 一道自编的“光滑—粗糙—光滑”分段能量题及标准推理链；
- 自由文字输入和 4 个匿名自构样例；
- 8 个可解释检查点、显式冲突检测、图谱联动高亮；
- 每条提示显示命中文字、缺少的可见证据、复核问题和局限；
- 本地运行、无账号、无数据库、无外部题库、无真实学生数据；
- 语音输入只保留后续接口设计，当前未实现。

## 不能据此声称

- 不能声称系统识别了学生真实认知原因；
- 不能把没写出某个词等同于不会；
- 不能用于评分、分层、学生画像、自动推题或课堂效果结论；
- 不能把培训材料中的项目成效、数据或方案写成本项目成果。
