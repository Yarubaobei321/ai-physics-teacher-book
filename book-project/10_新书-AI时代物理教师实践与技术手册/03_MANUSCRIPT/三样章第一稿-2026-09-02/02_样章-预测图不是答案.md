# 预测图不是答案

## 用AI和Python另建一条静电场数值对照路线

五张旧图还在：单个中心电极与外环、有限平行板、点电极与板、同种双点、异种双点。实物装置也在。可更换电极放进浅水槽，探针逐点寻找相同电势，再把这些点连成等势线。过去我曾用COMSOL Multiphysics做过数值图，今天却找不到可以直接打开和复算的`.mph`工程文件。

丢失的并非一张彩图。真正丢失的是几何、材料、边界、接线、求解设置与输出之间的完整关系。旧操作笔记还能证明当时建立过二维静电模型，使用过表面电荷密度和无限元边界，也记录过一次不收敛后的调整；它不能证明旧图严格模拟了真实水槽的定电势边界。

我决定不再“照着旧图画一张相似图”，而是把问题重新交给AI和Python：从实物测量的对象出发，另起一个可阅读、可运行、可测试的新版本。旧图保留为历史证据，新代码不冒充旧工程复原。

下面先用有限平行板建立一个最小可检验的边值问题。源码、配置、测试、图件和验收记录保存在一起；实物尺寸、接线电压和原始测点尚未取得，所以不进入当前预测结论。

读完后，你应该能够判断三件事：为什么参考论文中的点电荷彩图不能直接预测水槽；怎样让生成式AI先说明方程和边界，再生成代码；怎样用解析解、残差、对称性、网格收敛和错误注入审查AI结果，而不是被一张漂亮图说服。

## 探针在水里测到的是什么

装置利用的是两种场在一定条件下共享的数学结构。浅水层中有稳恒电流时，电流密度可写为

\[
\mathbf J=-\sigma\nabla V,
\]

其中`σ`是介质电导率，`V`是电势。水域内部没有电流源或汇时，电荷不持续积累，因此

\[
\nabla\cdot\mathbf J=0,
\]

得到

\[
\nabla\cdot(\sigma\nabla V)=0.
\]

若水层厚度与电导率近似均匀，方程化为

\[
\nabla^2V=0.
\]

无自由电荷的静电区域也满足Laplace方程。只要边界形状与电势对应，水中稳恒电流场的等势线就可以帮助我们研究相应静电问题的空间结构。

“对应”不等于两者是同一种物理场。水中流动的是电荷载流子，真实静电场由静止电荷与导体边界建立；介质不均匀、水深变化、电极极化、探针扰动和槽壁边界都会破坏简单映射。若水层厚度`t(x,y)`变化明显，更合适的二维近似应把厚度也写进通量：

\[
\nabla\cdot[\sigma t(x,y)\nabla V]=0.
\]

因此，仿真前不能只问“网格多密”。先要问水深是否可近似均匀，电极接在哪个电势，槽壁是否绝缘，外环是接电、接地还是悬空，以及探针相对哪个参考端测量。

## 参考论文给出的不只是一个提示词

叶张胜、杨树林在《生成式人工智能在物理教学中的应用研究：以Python编程实现静电场仿真为例》中，使用DeepSeek辅助生成和修改Python程序。该文正式刊载于《物理与工程》2025年第35卷第5期169—173页；本地剪藏页的2026日期是转载时间。程序用NumPy建立二维网格，按库仑定律叠加自由空间点电荷的场，再由Matplotlib绘制箭头、流线和颜色。

连续迭代中的两次退步比“AI会写Python”更值得带走。第一次美化以后，正电荷周围的场箭头反向指向电荷；后续提示修正方向，却又丢失了原先的颜色映射功能。最终版本增加鼠标左右键添加正负电荷的交互。

这段过程说明：AI能帮助教师形成原型候选，也可能带来物理错误、需求漂移和功能回退。每轮新增交互后，都要重新检查前一轮已经通过的物理与功能。“AI已经修改”只是过程记录，测试结果才能回答问题是否解决。

论文模拟的是自由空间点电荷。它适合解释库仑场和AI协作编码，却不能直接充当本装置的水槽预测。真实装置多了四类决定性信息：

1. 电极有有限尺寸，并非数学点；
2. 水槽有限，亚克力壁阻止电流穿出；
3. 电流必须有回路，回流电极和接线不能省略；
4. 探针测量的是相对某一参考端的电势。

如果我只给AI一句“参考论文，用Python画静电场”，它很可能返回一张熟悉的点电荷图。图可能完全正确地回答了另一个问题，却没有回答这只水槽。

这次开发把提示词拆成三步。第一步只澄清模型：

实物是有限浅水槽，电极有实际尺寸，槽壁绝缘。我将测量水中的稳恒电势，再与数值预测比较。请先输出：

2. 每类边界对应的真实部件；
3. 仍缺少、必须由我测量或确认的几何、接线和材料参数；
4. 自由空间点电荷公式为什么不能直接作为水槽预测；
5. 至少五项独立于彩图的验收测试。

这一步的作用是让AI暴露假设。若它把槽壁设成`V=0`，教师要追问槽壁为什么接地；若它把外圆环当绝缘墙，要追问外环究竟是否连接电源；若它自行补出电极尺寸，这些数值必须退回“待确认”。

第二步才要求代码，并限定最小对象：有限平行板、定电势电极、绝缘外壁。第三步要求AI每次修改后重跑全部测试，说明修改触及方程、边界、单位、求解器还是绘图。

三组完整提示词保存在配套的[AI协作记录](</Users/yaril/个人文档/3 写作/图书出版/10_新书-AI时代物理教师实践与技术手册/01_SOURCE/三样章写作包-2026-09-02/03_静电场AI协作与提示词记录.md>)中。它们是根据真实开发整理的复做工具，不冒充逐字聊天记录。

## 把实物翻译成一份可审查的模型规格

第一版只做两片有限电极。实物照片中的平行板横向放置，当前坐标中把同一拓扑旋转90°，在矩形水槽内放置左右两片竖直电极。示例配置为：

```text
水槽：30 cm × 20 cm
高电势电极：x=9 cm，y=6～14 cm，V=+5 V
低电势电极：x=21 cm，y=6～14 cm，V=-5 V
外壁：绝缘，法向电流为0
介质：二维、均匀、无内源
```

这些尺寸是方法演示值，只在结构拓扑上对应实物平行板；它们不是对水槽与电极的现场测绘。把这句限制写进配置、README和验收JSON，可以防止示例值在传播中悄悄变成“装置参数”。

| 实物对象 | 数学表示 | 当前身份 | 下一步要补什么 |
| --- | --- | --- | --- |
| 水域 | 矩形计算域 | 示例 | 实测内尺寸、水深与有效水域 |
| 两片电极 | 内部定电势、零厚度线段 | 拓扑对应 | 轮廓、厚度、位置、浸入深度 |
| 电源 | `+5 V/-5 V` | 示例边界 | 实际端电压、参考端、稳定性 |
| 亚克力壁 | `∂V/∂n=0` | 物理推断 | 检查是否有其他导电或接地结构 |
| 水层 | 常`σ`二维介质 | 简化模型 | 水深、电导率、温度与均匀性 |
| 探针 | 当前模型未纳入 | 待补 | 探针位置、深度、参考端与重复测量 |

常电导率模型中，`σ`的绝对数值不改变归一化电势的空间形状；它在空间上是否均匀、在测量期间是否稳定更值得现场检查。

如果未来改做“中心电极—外圆环”，必须先确认外环接线。外环接电时可作为定电势边界；外环若悬空，就不能随意改成接地或绝缘墙。五类电极不能只靠换一张掩膜批量生成。

## 在画图之前，先让一个有答案的问题来考求解器

有限电极没有简单解析解，不能用它自己的彩图证明自己。代码因此另建了一个校准题：左右边界分别固定为`+5 V`和`-5 V`，上下绝缘。理想平行板间的电势沿`x`线性变化，解析式已知。

161×121的主示例在本机迭代3815次，末次最大更新量约为`9.98×10⁻⁹ V`。16个单元测试中，11类主要数值与边界指标汇总如下；场方向和错误注入在下一节展开。

| 检查 | 结果 | 通过门槛 | 它保护什么 |
| --- | --- | --- | --- |
| 电极定电势 | 最大误差`0 V` | `≤10⁻¹² V` | 迭代没有改写电极 |
| 绝缘外壁 | 离散法向梯度最大值`0 V/m` | `≤10⁻¹⁰ V/m` | 外壁没有虚构的法向通量 |
| 五点差分残差 | 最大约`5.37×10⁻⁹ V` | `≤10⁻⁷ V` | 自由网格点满足离散方程 |
| 左右反对称 | 减去两极电势中值后为`0 V` | `≤10⁻⁶ V` | 对称几何没有产生不应有的偏斜 |
| 上下对称 | `0 V` | `≤10⁻⁶ V` | 上下结构保持一致 |
| 最大值原理 | 无越界 | 不超出`-5∼+5 V` | 自由水域没有无来由的极值 |
| 电极通量平衡 | 相对不平衡`0` | `≤0.005` | 绝缘槽内的流入与流出相符 |
| 粗、中、细三档网格 | 相邻网格最大差从`0.0146 V`降至`0.00731 V` | `最大≤0.05 V` | 采样点随加密趋于稳定 |
| 线性解析解 | 最大误差约`5.99×10⁻⁷ V` | `≤2×10⁻⁵ V` | 求解器能复现已知问题 |
| 二维调和解，`dx≠dy` | 最大误差约`1.99×10⁻⁷ V` | `≤2×10⁻⁵ V` | 横纵网格不等时权重仍正确 |
| 电势零点整体平移 | 电场最大差约`3.79×10⁻¹² V/m` | `≤2×10⁻³ V/m` | 代码没有把电势正负号当作物理零点 |

对称性不是所有配置都必须满足。程序先检查固定边界是否真的具备左右或上下镜像关系：具备才核对相应对称误差；几何不对称时标为“不适用”，不把正确的不对称解判成失败。

通过这些门，只能说明程序按声明的数学模型工作。若槽壁边界本来就设错，残差仍可能很小；若实物尺寸与示例不同，对称性仍可能完美。数值验收与实物建模是两道不同的门。

## 故意写错一个负号，比再画一张彩图更有用

参考论文曾出现正电荷周围场箭头反向的问题。这里把类似错误写成一个必须失败的测试：同一电势数组分别用`E=-∇V`和错误的`E=+∇V`计算箭头。

在槽中央，正确实现得到`Ex≈+78.27 V/m`，方向由左侧高电势电极指向右侧低电势电极；故意写错后得到`Ex≈-78.27 V/m`，检查立即失败。

**图4　同一电势图上的方向错误。** 左图通过，右图是故意注入的错误版本。若只看等势线，两幅图完全相同；方向检查必须独立存在。

代码还故意把声明为高、低电势端的两片电极都设成`+5 V`。求解前先检查“高电势数值大于低电势数值、电势差非零、两片电极位置不重合且均在水槽内”，发现等电势边界后直接拒绝。检查不要求电势必须一正一负：电势零点可以任意平移，`5 V/2 V`仍是合法的高低电势设置。端到端回归测试会用这组边界完成求解、绘图和全部验收；另一项测试同时给两极加`7 V`，检查电势整体平移而电场保持不变。

这项端到端测试还抓到过测试自身的错误：早期对称性门直接计算`V(x,y)+V(W-x,y)`，暗中把`0 V`当作固定中点，因而会错误拒绝`5 V/2 V`。修正后先减去两极电势中值；若电极位置本来就不镜像，对应的对称性项标为“不适用”。测试代码同样需要接受物理审查。

错误注入把验收从口号变成可执行问题：我们能否造出一个明确错误，并看见检查真的失败？如果所有测试永远是绿色，很可能只是没有触碰它们的盲区。

## 预测图怎样回到实物测量

下一步先取得一组可以比较的平行板测点；另外四种彩图留到边界与数据齐备以后。每个数据点至少记录：

| 字段 | 为什么必须有 |
| --- | --- |
| 电极配置与版本 | 确认比较的是哪一组结构 |
| `x、y`坐标 | 把测点放进同一坐标系 |
| 供电电压与参考端 | 明确电势零点与边界 |
| 水深、温度或介质说明 | 判断均匀模型是否合理 |
| 测得电势 | 保留原始读数，不只留下最终曲线 |
| 重复次数与时间 | 区分随机波动和系统偏差 |
| 操作者与备注 | 追溯探针、扰动和异常 |

实物复做还必须使用隔离的低压电源和明确的限流方式，把电源与接头放在溅水范围之外，上电前由教师检查接线。测量过程同时观察电极极化、电解气泡和水温变化；这些现象持续或加剧时应停止取数，而非继续增大电压。Python报告不是电气安全验收。

配套的[预测—实测对照表模板](</Users/yaril/个人文档/3 写作/图书出版/10_新书-AI时代物理教师实践与技术手册/01_SOURCE/三样章写作包-2026-09-02/静电场_预测实测对照表模板.csv>)已经预留预测值、差值与归一化电势字段，目前没有填入任何虚构数据。

有了测点后，先用水槽角点或电极中心做坐标配准，再在每个实测坐标插值Python电势。绝对电势零点若不同，可以在明确规则下归一化；原始数据仍须保留。比较至少分四个区域：

1. 两电极之间的中心区；
2. 电极端部，边缘效应最明显；
3. 槽壁附近，边界假设最敏感；
4. 对称轴，用于检查装置与测量偏斜。

偏差出现后，不急着说“实验误差大”或“仿真更准确”。逐项检查：水深是否一致，电源是否漂移，电极位置是否偏移，探针是否改变局部场，介质是否均匀，坐标是否配准，二维近似是否足够，以及边界是否按真实接线设置。

预测与实测真正的教学价值正在这些偏差里。完全重合只能告诉学生结果符合预期；有结构的偏差会迫使他们区分模型假设、数值误差、装置条件和测量操作。

## 课堂任务先按“设计”保存

当前材料可以提出一条课堂任务，但尚不能写成已经实施：

1. 学生先根据电极与接线预测等势线的对称性和大致弯曲；
2. 读取Python预测图，选择最能区分模型的测点，而非均匀撒点；
3. 在水槽中完成重复测量，保留坐标与原始读数；
4. 将测点叠加到预测图，标出偏差集中的区域；
5. 每组只修改一项可解释因素，再重新预测或测量；
6. 汇报“哪一条证据支持哪一项修改”，不以“更像标准图”为唯一结论。

这条任务能否在高中课堂时间、设备数量和学生数学基础下走通，还需要真实试用。首次实施时应保存任务单、测点表、修改痕迹、课堂时间与学生解释，之后才能讨论学习价值。

## AI留下代码，教师留下裁决

Python本身不是AI。本案例之所以属于AI应用，是因为生成式AI参与了需求拆解、模型质疑、代码生成、测试草案、排错与文档整理，而且这些过程被保存在提示词、源码、失败测试和验收报告里。

AI可以迅速生成网格、迭代、绘图和报告，也可以把自由空间点电荷误当成水槽，把`-∇V`写成`+∇V`，或者在增加交互时弄丢已有功能。教师的工作由此更加具体：

| AI可以加速 | 教师不能外包 |
| --- | --- |
| 把自然语言拆成代码任务 | 确认研究对象与物理量 |
| 给出方程与边界候选 | 把边界逐一对应到真实部件 |
| 生成求解器与图件 | 判断简化条件和单位是否成立 |
| 草拟解析解、残差与回归测试 | 决定测试是否覆盖真实风险、阈值是否合理 |
| 根据失败信息修代码 | 判断应修实现、改模型还是补实验 |
| 整理复做说明 | 决定何时能进入课堂、出版或继续扩展 |

旧COMSOL图没有被这一版Python取代为“真值”。它被更准确地放回历史位置：证明作者曾经探索数值可视化，也提醒我们没有工程文件就无法复算。新原型则留下了下一位教师可以审查的方程、边界、配置、代码和失败门。

真正的完成还要等实物测绘与测点进入同一坐标系。到那时，预测图依然不是答案。它是一个可以被水槽、探针和学生质疑的假设。
