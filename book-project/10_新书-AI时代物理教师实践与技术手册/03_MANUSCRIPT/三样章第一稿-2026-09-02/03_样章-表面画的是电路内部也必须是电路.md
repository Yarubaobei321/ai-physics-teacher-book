# 表面画的是电路，内部也必须是电路

## 活版电路拼图怎样把连接关系变成可移动对象

黑板上的电路图只有几条线。到了实验桌，电源、开关、电阻、电容、仪表和一束导线同时出现，原理图里清清楚楚的节点与支路忽然藏进空间接线。固定演示板可以减少接线失败，却又常把真实连接封在板后；学生看见现象，未必看见电流路径怎样成立。

活版电路拼图在图和散装器材之间增加了一层实体表征。每一块模块正面画电路符号，内部安装相应元件与导线，侧面触点被设计用于建立模块间连接，外壳和磁吸结构让它可以在黑板上移动、组合和拆换。拼出的版式是一张电路图；端点是否确实按图导通，仍要逐块验收。

![活版电路拼图组合](</Users/yaril/个人文档/3 写作/图书出版/10_新书-AI时代物理教师实践与技术手册/03_MANUSCRIPT/三样章第一稿-2026-09-02/assets/active_circuit/active-overview.jpg>)

**图1　活版电路拼图组合实物。** 它证明模块与组合结构存在；实际摄影者、图件权利人和出版授权主体仍待分别确认。

这个案例的核心链基本没有使用AI。原因很简单：要解决的问题是移动、拼接、导通、追踪和排错，实体模块就是最低充分媒介。硬给它增加图像识别或智能评价，只会让读者离触点、电路和课堂任务更远。

作品已经制成并参加自制教具评选。现有市级与区级证书列作品共同作者为严力耕、汪小明、黄灿斌；专利受理文件所列发明人为严力耕，申请人为深圳市蛇口育才教育集团。三人在原理、CAD、打印、接线、改进与教学设计中的具体分工仍需逐项确认；实际摄影者、图件权利人和授权主体另行确认。当前原件能够共同支持的是结构与制作事实；它们不支持把全部过程归到单一作者，也不支持把“作品共同作者”与“专利发明人”混成一个身份。

读完这一章，你应当能完成两件事：判断一项实体教具究竟封装了什么、又把什么判断留给学生；用“模块定义—断电核对—低压试通—任务试用”工作单，检查自己的可视化教具是否表里一致。现有材料足以支持过程级复做，还不足以让第三方按尺寸和参数一比一复刻。

## 真正需要显现的是节点、支路和状态

电路图的优势是抽象。它忽略元件外形、导线长度和空间摆放，只保留连接关系。实验桌的优势是真实。学生必须识别端口、选择仪表接法、处理极性、接触与故障。两种表征都重要，困难发生在它们之间的翻译。

活版拼图没有把全部操作变简单，它选择性地封装了“重复接一堆跨越黑板的导线”，把这些线藏进模块内部；同时把更值得观察的连接关系放大到表面。

| 被封装的动作 | 仍留给学习者的判断 |
| --- | --- |
| 模块内部的重复走线 | 需要哪些元件和模块 |
| 模块间触点的快速连接 | 节点与支路怎样组织 |
| 模块在黑板上的固定 | 不同开关状态下哪条路径闭合 |
| 已完成模块的元件安装 | 极性、仪表位置和错误结构怎样诊断 |

这项取舍决定了它适合什么，也决定了什么时候应停止使用。如果本课目标正是训练学生识别接线柱、使用散装仪表、整理导线和处理真实接触故障，拼图不能替代实验桌。若课堂要做精确定量测量，触点电阻、重复性和仪表接法没有独立验收以前，也不应把它当作精密平台。

## 一块模块同时承担四层对应

![独立模块](</Users/yaril/个人文档/3 写作/图书出版/10_新书-AI时代物理教师实践与技术手册/03_MANUSCRIPT/三样章第一稿-2026-09-02/assets/active_circuit/active-modules.png>)

**图2　独立模块。** 图中可见直线、转角、节点与电容等不同模块。模块种类已被照片证明，完整清单与数量仍待整理。

一块合格模块要同时回答四个问题。

### 第一层：表面告诉读者什么

表面图形应使用教学中熟悉的电路符号，导线要一直画到真实端口所在的边。元件有极性时，正负、阳阴极或仪表端子必须在操作距离上可辨认。表面不能为了好看省略决定接法的信息。

### 第二层：内部究竟连了什么

表面每一段线都必须能在内部追踪到相应端点。元件模块内部安装真实元件，转角和直线模块内部也要有与图形一致的导线；节点模块则把指定端口连接到同一电气节点。

![模块内部](</Users/yaril/个人文档/3 写作/图书出版/10_新书-AI时代物理教师实践与技术手册/03_MANUSCRIPT/三样章第一稿-2026-09-02/assets/active_circuit/active-inside.jpg>)

**图3　模块内部实拍。** 图片能证明电池盒、导线与端口真实存在，不能替代逐模块接线图与通断记录。

### 第三层：相邻模块怎样导通

侧面触点被设计为在两个模块靠近后形成电气连接，磁吸与外壳结构同时帮助定位。触点也是需要优先检查的风险位置：偏移可能造成间歇断路，表面贴合不能证明接触电阻足够小；相邻端口若定义不一致，还可能形成短路。现有材料没有保存这些故障的实测记录，本章把它们列为待验收风险。

![模块触点](</Users/yaril/个人文档/3 写作/图书出版/10_新书-AI时代物理教师实践与技术手册/03_MANUSCRIPT/三样章第一稿-2026-09-02/assets/active_circuit/active-contact.jpg>)

**图4　模块侧面的触点。** 照片证明结构存在，尚无型号、额定电流、接触电阻和寿命测试。

### 第四层：组合后发生什么

模块拼成电路，通电现象应当与表面原理图一致。这里的“现象”是最后一层，不是第一层证据。灯亮或曲线出现，仍可能来自绕过、误接或隐藏短路；先证明表面—内部—触点三层一致，再用通电现象复核。

四层关系可以写成一句验收原则：

> 表面画到哪一个端口，内部就必须通到哪一个端口；表面没有连接的端口，断电检查时也不得意外导通。

## 先定义模块，再打开SolidWorks

原始材料保存了SolidWorks建模、3D打印、装配、内部接线和表面贴纸的过程。容易被忽略的一步发生在建模之前：先定义模块的电气身份。

以一个低压电容充放电电路为候选任务，先画目标原理图和节点表，再列模块。基础库可能需要直线、转角、三端节点、电源、开关、电阻、电容、二极管、电流表和电压表。每一块先填下面六项：

| 模块定义 | 示例要回答的问题 |
| --- | --- |
| 名称与功能 | 这是直线、节点、电阻还是有极性元件 |
| 表面符号 | 学生看到什么，端口画到哪条边 |
| 端口身份 | 左、右、上、下哪些端口有效 |
| 内部连接 | 哪些端口互通，中间经过哪个元件 |
| 方向与极性 | 能否旋转使用，反接会发生什么 |
| 允许／禁止组合 | 与哪些模块相邻，什么组合会短路或误导 |

只有这张定义表稳定以后，才进入外壳设计。否则模型打印得很精致，仍可能出现表面引脚与内部端口错位。

## 现有材料支持的制作顺序

### 1. 按端口与元件设计外壳

外壳需要预留磁铁、触点、元件安装件和内部走线空间。不同模块的有效端口数不同，内部元件高度也不同；“一个盒子适配全部模块”可能让端口定义和结构强度同时失控。

### 2. 3D打印框架

原件写明使用PLA打印。当前没有保留下来的材料牌号、喷嘴、层高、填充率、打印方向、单件时间和公差记录，所以这一步只能复做流程，不能照抄参数。

### 3. 安装磁铁、触点和元件固定件

先检查每条边的端口位置与方向，再固定磁铁和触点。有极性或一公一母的结构意图，应同时在机械图、表面标识和接线表中出现，不能只靠装配者记忆。

### 4. 完成内部接线

依照模块定义表连接真实元件与端口。每完成一块便贴临时编号，记录内部接线图；不要等所有外壳封闭后再寻找一条错线。

### 5. 制作表面标识

贴纸上的线、端口和元件符号与内部接线逐项对照。表面标识既是给学生看的图，也是制造验收图，版本变化必须同步修改。

### 6. 断电验收后再组装

制作记录在这里出现明显缺口：现有文稿没有触点电阻、极性防错、短路、过流和重复拼接测试数据。因此，只能说明“应该逐块检查”，不能声称“已经全部通过”。下一版实物可以按以下协议留下验证记录。

## 通电之前，先证明表面没有说谎

下面七道门是根据结构风险新制定的验收协议，不是历史项目已经完成的测试记录。

### 表里一致门

检查前先断开全部外部电源；带电池的模块须拆除电池或与测试端隔离，电容须按器件要求安全放电并确认无残余电压。严禁在带电模块上使用通断档或电阻档。

测试方法按模块身份选择。直线、转角、节点和无源触点可用通断／低阻检查；电阻模块测量电阻值；二极管模块使用二极管档并检查两个方向；电容模块按电容与充放电特性另行测试，不能用一次“通／断”作结论；电源和仪表模块按各自说明单独验收。每条表面线路都要追踪到内部端点，表面未连接的端口也要检查意外通路。任一结果与模块定义不符，就退回该模块。

### 意外短路门

在电源已拆除或隔离、储能元件已安全放电的前提下，检查任意两个本不应相连的端口。尤其关注节点模块、转角模块和外壳内裸露导线。未解释的低阻通路不得进入通电评估；电源模块不得直接用通断／电阻档跨接其输出端。

### 极性门

电源、电容、二极管与仪表的极性同时出现在表面、内部接线图和使用说明中。结构防错与视觉标识都要测试；“设计成一公一母”不能自动证明绝不会反接。

### 触点门

模块对齐后轻触、移动和重复拼接，记录是否出现间歇断路，并实测接触电阻。合格阈值和循环次数必须根据目标电流与元件确定，当前材料不能替读者填一个虚假数字。

### 低压与限流门

冻结最大供电电压、最大电流、限流或保险方式、元件额定值和教师断电权限。这些参数目前没有完整证据，补齐并经教师安全评估前只做断电结构检查，不进行通电演示，也不宣称装置已经通过安全验收。

### 整机功能门

前五门通过且供电上限、限流和元件额定值已经冻结以后，先组装一个经审核的低压电路，逐节点复查，再使用批准的限流电源上电。预期现象、实际现象和异常处分别记录。通电成功只能作为最后确认，不能跳过前五门。

### 定量停止门

触点电阻、重复性、仪表接法和传感器标定未通过独立测试时，停止把装置用于精密定量实验。低压与限流门也未通过时，只能在断电状态下用它辨认连接关系、路径与开关状态；各项通电门通过后，才讨论低压通电演示。

## 拼接的任务不是“照图摆得一样”

原始文稿列出电容充放电、闭合电路欧姆定律、伏安法测电阻、通电与断电自感等候选内容。截至2026年8月12日，作者确认装置尚未进入真实课堂。这些只能写成待验证的教学设计。

若把完整电路图直接给学生，让他们按形状拼好，任务容易退化为配对。更有物理含量的任务可以分四级：

### 由目标倒推结构

只给“使电容充电，再切换为通过电阻放电”这样的目标和可用模块，学生先画电路、标节点，再选择模块。完成后说明每一块承担什么作用。

### 追踪状态变化

保持模块位置不变，只改变开关状态。学生用可擦箭头或逐段指认闭合路径，解释充电与放电时哪些支路成立、哪些被断开。这里可见的是拓扑变化，不需要先上AI动画。

### 诊断一处结构错误

教师预置一块方向错误、缺少节点或极性错误的模块。学生先断电判断，再用万用表验证，最后修改并说明“现象—假设—证据—修正”。由于历史材料没有保存真实失败—修改—复验链，这项任务应明确标为新设计的故障注入，不伪装成研发故事。

### 与散装器材互译

学生先在拼图上稳定识别节点与支路，再把同一电路接到散装器材；或从真实接线反画模块图。拼图是中间脚手架，最终仍要回到真实端口、导线与仪表。

首次课堂试用应保存的不只是“完成了几组”，还包括学生原理图、模块选择、路径说明、错误修改痕迹、实际用时和教师观察。没有这些材料，本章不报告学生参与度、理解、成绩或创新能力的变化。

![大小模块对比](</Users/yaril/个人文档/3 写作/图书出版/10_新书-AI时代物理教师实践与技术手册/03_MANUSCRIPT/三样章第一稿-2026-09-02/assets/active_circuit/active-size-comparison.jpg>)

**图6　两种尺度实物。** 大模块适合黑板展示的设计意图，小模块更接近小组操作；现有材料尚无教室可视距离、组数和收纳测试。

尺度不是把CAD整体缩小。大模块要让后排辨认符号、端口和开关状态，小模块要兼顾手指操作、触点对齐、桌面面积和收纳。缩小以后，磁力、触点间距、字体、极性标记和元件安装都会重新成为问题。

因此每种尺度需要单独验收：多远还能辨认符号，连续拼接是否掉落，小组桌面能否完整铺开，一套需要多少备件，课前清点与课后收纳需要多久。这些数据目前尚未取得，不能把“已有大小两套”直接写成“已适合班级推广”。

## 为什么本章没有把AI补上去

原始材料确实提到ESP32、Phyphox、浏览器数据页面和“AI编程”扩展，也保存了界面图片。现有证据缺少传感器型号、接线、协议、采样率、单位、原始数据和运行复验。现在写入这些扩展，只会分散对模块结构、连接关系和安全门的解释，还无法交付可复做的技术路径。

本章选择停在实体可视化：表面符号怎样对应内部电路，触点怎样把模块连接起来，学生怎样组织节点与支路，教师怎样在通电前证明表面没有说谎。数据采集以后可以成为另一个完整案例，前提是硬件、协议、标定、原始CSV和课堂任务都能被核验。

不使用AI并非技术缺口。技术选择已经由教学问题决定：

| 教学困难 | 最低充分媒介 |
| --- | --- |
| 看不见节点与支路怎样连接 | 可移动实体模块 |
| 需要改变拓扑并观察状态 | 拼接、拆换和开关 |
| 要核对表面与内部是否一致 | 万用表与逐块记录 |
| 要训练真实接线与仪表使用 | 回到散装器材 |
| 需要采集与分析时间序列 | 待另建经过验收的数据系统 |

每做一种模块复制一行；同一模块有新版本时保留旧编号，不覆盖历史记录。

| 字段 | 填写内容 |

这张表不能替代缺失的CAD、STL、BOM和接线图。它能让第三方复做时知道哪些文件和参数必须出现，也直接暴露现有材料停留在“过程级复做”的哪个位置。

若要让第三方按图制作，还必须冻结一个代表电路与模块清单，补齐源文件、尺寸、BOM、逐块接线、元件和触点参数、安全限制，并请一位没有参与研发的教师在工作台上完成断电核对。复做者遇到的卡点、故障、修改与复验记录，才能说明这套说明真的可以用；在此之前，不对“提高兴趣”之类学习效果作无证据判断。

活版电路拼图的价值也不只在“接线更快”。它把电路图中的连接关系做成了可以移动、拆换、测通和质疑的对象。表面与内部经验证保持一致以后，这套装置便提供了要求学生在真实通电前判断节点、支路和状态的条件；该任务能否在课堂中产生预期学习价值，仍待首次实施验证。这里没有AI，教学设计依然成立。
