## 一、建议先这样审阅

1. 打开`overview.html`，先看十二章阅读地图、两幅核心图和待核事项。
2. 连续阅读`正文-第一批.md`，优先判断声音、技术密度和章间推进，不在第一遍逐句核来源。
3. 需要核事实时打开`进度与停笔位置.md`，按章查看原件入口、主张上限与待核句。
4. 需要判断图片时回到本文件，区分“已经制作”“可从真实原件选取”“需要重绘”“当前不应使用”。
5. 最后在`review/第一批/review.md`按优先级给出作者裁决。

## 二、已经制作的两幅核心图

### 图1　三种机械能装置的证据路径

- **文件**：`diagram/图1-三种机械能装置的证据路径.svg`；`diagram/图1-三种机械能装置的证据路径@2x.png`。
- **建议章位**：第5章“三种装置给规律三双眼睛”之后、“网页是第四件器物”之前。
- **解决的问题**：纸带、圆柱体摆动和气垫导轨为什么不能只用“都在验证机械能守恒”概括；三条关系式各自依赖什么对象、直接记录、派生量和模型边界。
- **图中事实**：6组、3方案、每方案2组；同方案内分析或提问已经发生；跨方案比较没有自然发生；公开课为手动录入与投屏。
- **不能证明**：三种方案完成了效果比较；自动采集已使用；学生因比较而产生学习变化。
- **出版前复核**：三种装置名称、公式排版、圆柱体自转项的措辞，以及公开课图片和共同完成者署名。

### 图2　器械铸造链与退回点

- **文件**：`diagram/图2-器械铸造链与退回点.svg`；`diagram/图2-器械铸造链与退回点@2x.png`。
- **建议章位**：第一部第4章结束、第二部标题之前；也可作为全书前折页或目录后的读法图。
- **解决的问题**：原始现象怎样经过测量身份、页面／装置、课堂动作，最后变成一句可公开主张；每次身份变化在哪里可以退回。
- **事实锚点**：单摆空白原点、法拉第单位与代理量、动量页面同源自洽、机械能跨方案比较未自然发生。
- **不能证明**：图中链条已经作为正式量表在教师群体中验证；四件工具具有诊断效度或学习效果。
- **出版前复核**：若进入纸书，建议另出浅底印刷版并检查灰度可辨性；当前深色版适合屏幕审阅和数字资源。

## 四、图片证据身份统一写法

每幅图进入正文前登记六项：

| 字段 | 要写什么 |
| --- | --- |
| 图的身份 | 实物照片、结构图、原始截图、模型预测、原始测量图、人工重绘或概念图 |
| 原始来源 | 绝对路径、作者／摄影者、形成日期或版本 |
| 它能证明 | 只写这幅图直接支持的对象、结构、状态或动作 |
| 它不能证明 | 精度、稳定、课堂使用、学习效果、权利状态等容易越层的主张 |
| 处理动作 | 裁切、脱敏、重绘、标色、合成与文字补注 |
| 授权状态 | 作者、共同完成者、学生、摄影者与出版授权是否完成 |

AI生成或概念重绘只能解释关系，不能冒充真实装置、课堂、学生作品、实验数据和法律文件。装置首次出现时优先用真实外观，随后再用机制图拆结构。

## 六、导出与版式提示

- 两幅SVG均为自包含矢量图，未设置固定宽高；@2x PNG为3200×2000，适合当前审阅和数字资源。
- 当前图采用深色底。纸书正式排版前需另做浅底版、灰度打印测试和最小字号检查，不能直接假定屏幕版适合印刷。
- 图中公式使用Unicode字符以保证跨工具显示；出版排版时建议由公式系统重排，并与正文符号、斜体和上下标统一。
- HTML入口只用于本地人工审阅；没有生成浏览器截图，也没有把本地页面状态写成线上发布状态。
