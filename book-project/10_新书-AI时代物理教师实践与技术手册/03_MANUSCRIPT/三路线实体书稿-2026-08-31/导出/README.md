# 三路线Word审阅版

本目录交付三份可连续阅读和批注的Word文档：

1. [`Fable-连续正文审阅版.docx`](./Fable-连续正文审阅版.docx)：71页；
2. [`GLM-连续正文审阅版.docx`](./GLM-连续正文审阅版.docx)：67页；
3. [`Grok-连续正文审阅版.docx`](./Grok-连续正文审阅版.docx)：46页。

三份文档均嵌入各路线的两幅核心图，使用真实Word标题、列表、表格和页码结构。已经完成解包、Courier残留、表格几何、图片、章节层级、可访问性、字体嵌入和逐页视觉检查。它们是作者审阅稿，不等于事实终审或出版定稿。

`build_review_docx.py`为可重复生成脚本。重新生成前应保留正文、图件和本脚本的对应版本；生成后仍需再次渲染并逐页检查。
