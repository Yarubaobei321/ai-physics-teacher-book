# 最小写书工作流：从材料生长到约20万字成书

> 目标：保留论文最小工作流中“材料、主张、作者裁决、充分展开、出版对齐”的优点，同时适应长书稿、技术手册和持续吸收新AI方法的需要。

## 一、迁移时保留什么，改变什么

| 论文流程中的有效机制 | 写书中的迁移方式 | 为什么 |
| --- | --- | --- |
| 原始材料先于立意 | B0先做材料地图和证据边界 | 书更长，错误材料会被放大到多个章节 |
| 开放方向池与作者裁决 | B1比较多种读者价值方向 | 避免旧目录或AI候选过早锁死全书 |
| 最小大纲 | B2先冻结“书的宪法”和结构关系，不急着排满章节 | 长书需要主线、读者承诺和章节职责，目录仍可随材料调整 |
| 章前内容裁决 | B2形成结构后，逐章确认核心问题、价值层级、展开路径和细节处置 | 防止后台材料、微小失败和工具数量替代读者价值排序 |
| M4充分展开 | B3先做一个纵向样章，B4再分批展开 | 先验证叙事、案例、技术手册、图表和证据能否真正融合 |
| M5保守表达审校 | B3样章、B4分章和B5合订稿均设置表达直用步骤 | 只直接合并A类安全修改，不生成审核包，不等待逐项裁决，也不把论文压缩带进书稿 |
| M5对齐期刊 | B6对齐出版社、版权、体例、图文和技术时效 | 当前没有期刊式字数收缩；出版对齐不反过来压扁前期认识 |

写书新增五项论文里不够突出的机制：

1. **跨章综合**：同一概念、案例和技术不能在不同章节重复生长；整书要形成关系和进阶。
2. **持续更新入口**：AI工具变化快，外部资源长期进入候选池，但只有完成来源、概念、学科和实践四次转译后才能进入正文。
3. **彩图解释链**：每章先判断什么对象、过程、关系、数据或推理需要变得可见，再用彩图、表格、公式或文字形成“图前问题—读图动作—图后判断”；不按图数配额补图。
4. **可见的成长路线**：章节优先从具体对象、任务或冲突进入；需要呈现创造过程时，写清“能运行或看见—可信或可复核—能判断或用于教学—记录、复用或扩展”的真实进阶，并为操作配验收、为失败配排错动作。
5. **风险分级制图与页面验收**：复杂案例按需形成“认出对象—看懂机制—能够检查或行动”的图组。物理、工程和数据类高风险图先核事实再制图；所有正式彩图都要回到实际页面检查可读性、色彩、留白和前后文关系。

## 二、七个最小阶段

### B0 材料地图

回答“我们真正拥有什么”。登记作者实践、研究总结、培训讲座、外部AI资源和教材，区分材料身份、证据上限、时效与版权。

交付：范围说明、机械清单、A/B/C材料判断、少量核心材料卡和B1候选关系。此阶段不写目录和正文；全库可被发现即可，不追求全库摘要、复杂路由或长期知识系统。

### B1 读者价值方向池

回答“这本书最值得给读者什么”。从材料中开放生成多个方向，每个方向同时说明核心读者、真实问题、独特认识、可带走的方法、现有证据和关键缺口。

交付：若干独立方向和比较表。由作者裁决，不按AI投票或材料数量自动决定。

### B2 书的宪法与结构关系

冻结读者承诺、核心主张、作者声音、证据边界、技术手册形态和禁说项。随后只画章节之间的关系与职责，暂不把20万字平均分配。

交付：书的宪法、结构关系图、章节职责草案、首个样章任务书。

### B2→B3 章前价值共识门

这是一道写作门禁，不另增独立阶段。全书以`../04_REVIEW/全书章节价值地图与作者裁决.md`作为集中讨论入口。每章开始素材深挖和正文写作前，作者与主Agent先确认：

1. 一个核心读者问题；
2. 一个核心价值和必要的支撑价值；
3. 每个价值依靠什么案例、关系、解释或读者工具展开；
4. 每个价值对应哪个本地项目、哪份材料和什么证据状态；
5. 哪些细节进入主线，哪些压缩、移入侧栏／附录／其他章节或只留证据后台；
6. 读者读完后新增什么认识、判断或行动；
7. 与其他章节的边界及重复处理；
8. 当前哪些高价值项目材料尚未利用，为什么暂不进入；
9. 作者对采用、修改、补证、并章、移章、暂缓或撤回的裁决。

通过条件是核心问题、价值层级、展开顺序和内容处置均获得作者确认。未通过时保持讨论、补材料、并章或撤回，不用失败数量、工具数量和字数推动正文。

#### 三项永久检查

1. **跨章重复检查**：同一材料进入不同章节时，必须说明分析对象、核心问题和读者所得有什么不同；说不清就并章、移章或只保留一次。章节名称不同、段落角度不同，不足以证明两章具有独立价值。
2. **未发生现象的价值检查**：“没有比较、没有追问、没有达到预期”可以成为高价值材料，但必须能够说明原定目标、实际组织条件、教师引导停在哪里，以及它带来的可迁移改进。缺少这些要素时，只作为过程记录，不进入正文主线。
3. **价值—材料对应检查**：每个价值点都要写明怎样展开、根据哪个本地项目材料展开、证据到什么程度；同时列出尚未利用的高价值材料，交给作者裁决。

这三项是所有章节和后续图书项目都适用的工作检查。某一本书中具体哪几章怎样分工，单独记录在该书的价值地图和跨章边界中，不写成通用规则。

交付：全书价值总览、十六章价值展开、项目材料覆盖与缺口审计、当前章节价值裁决卡、作者批注与结论。确认后的结果同步到全书大纲和分章任务书，讨论过程不进入读者正文。

#### 多章结构审阅的双页面要求

任务涉及全书、多章、跨章边界或项目材料覆盖时，在Markdown裁决稿之外提供两个互相链接的本地HTML入口：

1. `overview.html`是图解总览页，用真实图件、关系图和少量文字帮助作者先看懂全书主线、关键冲突、章节分工与材料覆盖；它不承担逐条证据核验。
2. `index.html`是自由跳转审阅页，至少支持按篇章或章节锚点跳转，并在每章集中呈现核心问题、价值点、展开方式、本地项目材料、证据边界、跨章关系、材料缺口和作者裁决位置；同时链接Markdown原稿和材料审计。

审阅页中的重要本地材料代号不能只是不可解释的徽标。每个代号都要链接到一张可独立打开的Markdown材料卡；卡片至少写明原件入口、真实问题、可展开价值、可支持主张、不能支持主张、作者或共同完成者、图件候选和待核事项。A级表示对本书的挖掘价值高，不自动表示教学效果、测量精度、法律状态或长期稳定已经得到A级证明。

两页优先复用已经核验、来源明确且不涉及未授权身份的本地图件，不用AI概念图冒充真实装置、课堂或研究证据。Agent检查文件、链接和HTML基本结构，页面视觉由作者人工审阅；除非作者另行要求，不自动生成浏览器截图或移动端验收结果。

### B3 纵向样章

选择一个材料最完整、又能代表全书难度的真实问题。该章先通过章前价值共识门，再从确认的核心价值出发配置原始材料，形成可阅读、可操作、可核验的完整样章。样章至少包含：对象与冲突、真实案例、关键解释、操作路径、物理判断、必要的失败排错、彩图和适用边界。陌生术语先建立直觉再给准确解释；真实创造过程按需呈现版本或层级；操作步骤写明验收，排错优先写成“现象—可能原因—检查或修正动作”。

每幅核心图完成“图前问题—读图动作—图后判断”，正式图件均有彩图出版方案。复杂案例判断是否需要“认出对象—看懂机制—能够检查或行动”的递进图组；中高风险图保留可编辑源，高风险图先建立事实表或等价核查依据。彩图接入样章后必须在实际页面中检查尺寸、文字、色彩、留白和前后文比例。

事实、物理和首轮图文关系稳定后，直接调用`academic-paper-conservative-editing`处理歧义、搭配、真实冗余、含糊指代和逻辑关系。只合并A类安全修改，B/C类保持原文；不生成独立审核包或作者逐项裁决页。完成后再进入作者、合著者和目标读者首读。

交付：一个纵向样章及事实、物理、版权、技术复现和教师首读记录。样章不过关，不批量写全书。

### B4 分批生长与回查

每批只推进2—3章。每章先在集中裁决入口完成章前价值共识，再按确认结果建立材料卡和视觉任务表；用“具体入口—关键解释—真实进阶—验收与排错—可带走工具”检查章节组织，不把它机械变成固定栏目。视觉任务同时标出图组层次和错误风险；关键事实和彩图落位、页面呈现可读后执行表达直用步骤，再进入批次整合。每批结束后执行三项永久检查，回查跨章关系、重复、术语、图表、代码或网页状态，并更新“本批实际使用项目／跨章差异／未利用高价值材料／只留后台的过程细节”。材料不足时转为实验、访谈、复测、补图或原文核对。

交付：已确认的章节价值卡、分章稿、每章价值增量记录、材料回查记录、批次整合说明。

### B5 全书综合与20万字体量校准

全书初步成形后再看18万—22万字目标。先补关系、案例、证据、失败和读者工具，再处理过长、重复和节奏；不能用同义扩写填足字数。合订稿形成后，对跨章术语、指代、重复和作者声音再执行一次表达直用步骤，并统一检查彩图的配色语义、层次分工、跨章重复和整页阅读节奏。

交付：全书合订稿、跨章冲突表、缺口补证表、术语与工具索引、目标读者试读记录。

### B6 出版版对齐

在出版社或编辑要求明确后，统一体例、篇幅、彩图规格、色彩空间、引用、版权、二维码／网址、技术时效和交付格式。这里对应论文M5的“正式发表版”，但没有先验的期刊式字数压缩任务。出版社修改形成新句或新段时，只对受影响范围补跑表达直用步骤。

交付：出版候选稿、图件与授权台账、动态内容复核日期、编辑问题单。未知出版要求继续标待核。

## 三、对最终成果贡献较大的工作

按优先级判断：

1. 作者自己的新认识、真实案例、失败、数据和选择；
2. 把多个材料连接成新解释、新边界或可迁移方法；
3. 把抽象AI思想转成物理教师可执行并可验收的动作；
4. 回到原始项目、课堂材料、代码、图片和文献核对关键主张；
5. 用纵向样章尽早暴露叙事、技术、图文和读者理解问题；
6. 真实读者试用步骤、模板或排错路线后的反馈；
7. 跨章整合，删掉重复，补上因果、比较、边界和进阶关系；
8. 对动态AI工具和外部观点做成稿时复核。

## 四、贡献较小或容易制造虚假进度的工作

- 先把20万字平均拆到每章，再按配额补段落；
- 在B0就生成完整目录、十八章标题或大量样章；
- 让多个AI围绕同一旧框架反复改写，候选数量代替认识增长；
- 汇总模型、产品、插件和博主名单，却不说明解决什么真实问题；
- 过早润色标题、金句、过渡句和出版格式；
- 把M5期刊压缩稿当成书稿的最高事实源；
- 全量摘要所有培训材料和教材，却没有当前写作问题；
- 用泛化的清单、附录和提示词堆积“手册感”；
- 只统计字数、文件数、图表数和引用数，不检查读者获得了什么。

## 五、每次新增内容的最小记录

一项新材料、一节或一章进入下一阶段前，至少记录：

1. 原来只知道什么；
2. 现在新增了什么真实认识；
3. 证据或材料来自哪里；
4. 读者因此能够理解、判断或完成什么；
5. 可以沉淀为什么案例、步骤、模板、检查表或排错路径；
6. 适用条件、失败方式和仍待验证之处；
7. 它与全书已有内容形成什么新关系。

记录入口见`../01_SOURCE/价值生长台账.md`。
