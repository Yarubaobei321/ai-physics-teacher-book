# B3任务书：纵向样章

> 状态：进行中  
> 启动：2026-08-29  
> 启动依据：作者明确要求“开始B3阶段写作”  
> 当前样章：第8章“从一个页面到一个资源网站”第一版保持对照；第二版候选章名为“一节公开课为什么需要自己的实验网站”  
> 具体对象：三种验证机械能守恒方案的共同课堂任务、三个数据页面与网站入口；气垫导轨页面作为代表性单页

## 一、本阶段回答什么

B3用一个材料较完整、又能暴露全书真实难度的样章，检验实践叙事、物理解释、AI协作、操作方法、失败排错、图文和证据边界能否进入同一条阅读链。

本阶段不以“写出一章”作为唯一目标。样章还要回答：物理教师读得进去吗，能否照着完成一个动作，能否辨认哪些结论已经有证据、哪些仍须停止，以及这套写法是否值得推广到B4。

## 二、本轮要做的事

- 在重写样章前，由作者先裁决第6、13、11、8章的本书跨章边界，再确认第8章核心问题、价值层级、展开路径、材料使用和内容处置；
- 从三种验证机械能守恒方案的共同课堂任务进入，回查课堂组织、三页面、网站入口、开发会话、Git版本、学案和课后汇报；
- 只选择一类最能支撑教师判断的真实失败，紧凑写清发现、判断、退回、修改和复验；其余失败移入第6章、侧栏或证据后台；
- 从两篇相关M4内容稿继续生长，形成“课堂任务提出资源需求，资源升格同时增加审核与维护责任”的认识；
- 把气垫导轨系统的对象、变量、公式、过程区间和模型条件写成教师可检查的映射；
- 把单页、专题资源、在线实验室和网站入口的升格／停止条件写清；
- 正文候选只保留三重验收表和单页／专题／在线实验室／网站升格与停止判断表；选题卡、任务书、退回单和详细维护清单移到相应章节或配套资源；
- 为每幅正式图件确定彩图出版方案，补齐读图动作和图后判断；灰度旧图只可作来源或临时占位；
- 事实、物理和首轮图文关系稳定后，直接应用`academic-paper-conservative-editing`的A类安全修改，再进入作者、合著者和目标读者首读；
- 建立事实、物理、图文、版权、技术复现和教师首读门禁记录。

## 三、本轮不做的事

- 不把四篇十六章冻结为最终出版目录；
- 不同时启动其他章节或按20万字分配篇幅；
- 不修改数智育才网站源码，不部署网站，不修复冻结页面遗留问题；
- 不把M4或M5改写一遍充当样章；
- 不把页面存在、测试通过或课堂使用写成学习效果；
- 不虚构合著作者独立审读、目标读者试读、图件出版授权或长期维护机制；
- 不打开与本样章无关的学生原件、旧书全稿或网站全库。

## 四、完成标准

| 完成标准 | 判断方式 |
| --- | --- |
| 章前价值共识 | 作者已经确认核心读者问题、核心与支撑价值、展开路径、细节处置和跨章边界；未确认前不写第二版 |
| 清楚的案例链 | 正文从三种方案的共同课堂任务进入，以气垫导轨页面说明单页学习链，再解释三个页面为何形成在线实验室和网站入口 |
| 新增认识 | 至少形成一项超出M4的关系、边界或方法，并进入价值生长台账 |
| 物理可核 | 研究对象、变量、公式、过程区间、简化条件与输入字段能够逐项对应 |
| 一个高价值失败 | 失败有开发记录或Git锚点，直接支撑教师专业判断；其余细节不抢占正文主线 |
| 课堂主张不过界 | 只写学生手动录入和平板投屏等有材料支持的事实，不写学习增益 |
| 可操作 | 读者能使用三重验收表和升格／停止判断表完成一次判断，工具数量不替代章节价值 |
| 图文进入解释链 | 每幅拟用图均写明解释任务、读图动作、读后判断、来源、能说明与不能说明什么 |
| 彩图达到书稿要求 | 每幅正式图件都有彩色出版底稿或明确的彩图重制任务；灰度图不作为成品 |
| 表达直接净化 | 已直接合并A类安全表达修改，B/C类保持原文；未生成独立审核包或逐项裁决页 |
| 审读状态透明 | 已完成自动核验与待作者／合著者／目标读者确认分开记录 |

## 五、风险与回滚

- **旧论文遮住新书写法**：正文从页面异常和教师选择进入；M4只作导航，证据回到M2、Git和课堂原件。
- **主线再次膨胀成开发史**：三种方案只保留产生共同数字入口所需信息，气垫导轨页面只解释单页学习链，网站只解释升格价值与责任。
- **技术细节压过读者问题**：公式和页面字段只服务教师判断；代码差异放证据矩阵，不进入正文流水账。
- **未完成外部审读被误写成通过**：合著作者审读、2—3位目标读者首读、图件出版授权均保留为待完成硬门。
- **回滚方式**：本轮新增内容集中在`01_SOURCE/B3/`、`03_MANUSCRIPT/B3-第8章-从一个页面到一个资源网站/`、`04_REVIEW/B3-门禁记录.md`和独立审阅目录。若作者改选样章，可保留证据包，撤回入口更新，不影响B0—B2和原始材料。
