# 三路线正文检验任务书

> 启动日期：2026-08-31  
> 状态：执行中  
> 作者决定：同时推进 Fable、GLM、Grok 三个独立版本，用真实正文判断路线，不先融合或淘汰。

## 一、本轮要得到什么

1. Fable、GLM、Grok 各形成一份具有连续阅读感的实体书稿第一批；
2. 三版复用同一批已核材料，但保持章序、叙述声音、案例进入方式和工具组织方式独立；
3. 建立一套共享事实与证据边界，避免重复回查原件；
4. 每版明确已经写到哪里、依据什么材料、下一处自然续写点在哪里；
5. 用独立目录和 Git 白名单形成可回滚检查点。

本轮没有三小时硬截止，也没有字数配额。优先把一段或数章写厚、写连续；材料不足时在证据边界处停笔，不用摘要、提纲或同义扩写制造进度。

## 二、三版分工

| 路线 | 主要阅读动力 | 优先检验 |
| --- | --- | --- |
| Fable | 器物、教师判断与物理对象的双声部 | 真实对象能否带出AI进入、失败与教师成长，又不虚构经历 |
| GLM | 从教学想法到可验收、可退回、可交付的项目 | 连续行动能否兼具书稿可读性与技术手册可操作性 |
| Grok | 课堂现场、数据、作品与证据之间的冲突 | 新认识能否从真实矛盾中生长，工具能否在现场之后自然出现 |

三版互不改稿。共享事实可以相同，具体句子、结构与叙述不得互相拼接。

## 三、共同写作边界

- 正文直接进入对象、行动、现象或问题，不出现B0、B1、B2、路线候选、材料生长、版本评选等编务话语；
- 不把页面存在、构建通过或复算通过写成物理正确、课堂有效或可以公开；
- 不虚构学生反应、课堂对话、跨教师共同实施、学习增益、广泛采用或长期维护；
- 合著材料保留原作者和共同完成者，不因主笔身份转成另一位作者亲历；
- A01只覆盖同一特优生AI技能测试项目中已分析的25份物理模拟网页；271只是相关目录文件数；
- 机械能守恒公开课只写已核的手动录入、投屏汇报和课堂组织，不补写自动采集当堂使用；
- W01两个实验版本分开叙述；W03人工原点和异常点只能支持数据审查，不能补写学生复测；
- H04目前是“发现并独立复算问题”，尚未完成修改、浏览器复验和教师终审；
- 对称裁判句、抽象宣言、工具名单和无事实支撑的文学化场景均应删减。

## 四、完成标准

| 完成标准 | 验收方式 |
| --- | --- |
| 三版各有连续正文 | 每版至少有一个可从头连续阅读的正文文件，不以大纲代替 |
| 三版保持独立 | 结构、开篇、叙述声音和工具进入方式可辨认，没有互相改稿 |
| 共享成果可追溯 | 每项关键事实标明证据包、原件入口、可写范围和禁止外推 |
| 停笔位置可继续 | 每版有进度文件，说明下一处自然续写点和阻塞证据 |
| 文件可用 | Markdown结构、内部链接、禁说项和引用路径完成检查 |
| 可回滚 | 只暂存本轮白名单文件并形成单独Git检查点；若仓库状态不允许安全提交，保留白名单与差异清单 |

## 五、回滚与范围

三版正文写入`03_MANUSCRIPT/三路线实体书稿-2026-08-31/`的三个独立子目录；共享成果写入`01_SOURCE/三路线共享写作-2026-08-31/`。不覆盖旧样章、旧大纲、既有候选或外部原件。撤回本轮时只需移除本任务新增目录和本任务书，不影响此前材料。
