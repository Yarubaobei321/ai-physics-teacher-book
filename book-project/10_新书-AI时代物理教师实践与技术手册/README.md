## 一句话定位

面向物理教师，把真实教学实践、可核验案例和不断发展的AI思想与方法组织成一本既可连续阅读、又可按问题查用的实践专著与技术手册，为读者提供进入AI时代并保持专业判断力的路径。

## 当前样章阶段要完成什么

- 用网站、静电场与活版电路三个真实案例，检验不同章型能否达到“看得懂、学得会、能迁移”；
- 分别核对AI Coding、AI协作数值建模和基本不依赖AI的教学可视化，避免把AI使用量当作章节价值；
- 让作者裁决三章的叙事深度、复做颗粒度、个人声音与证据边界；
- 把待确认的物理口径、工程参数、课堂证据和出版授权继续留在审阅层，不用推测填平。

## 已保留的历史产物

2026-08-29前已形成B1方向池、B2四篇十六章阶段性地图、教师Agent开放价值池、教材AI应用开发地图，以及第8章纵向样章第一版。它们没有被删除，也不再具有当前结构约束力；新B2只复用其中经得起B1主线、AI增量与材料边界检验的部分。

## 当前不做什么

- 不按旧四篇十六章补空位；
- 不把20万字拆成逐章配额；
- 不把八章候选或三篇样章直接冻结为出版目录，不做字数填充；
- 不因为已有旧B2/B3文件较完整就默认继续该结构；
- 不同时补齐全部缺口，只处理会改变结构或样章选择的少量问题；
- 不把自媒体、讲座、工具介绍或旧AI书稿直接写成权威结论；
- 不覆盖或改写现有书稿。
