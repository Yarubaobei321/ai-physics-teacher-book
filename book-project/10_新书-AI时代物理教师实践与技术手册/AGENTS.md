# 新书项目 Agent 指南

## PROJECT_SUMMARY

- **项目目标**：为物理教师写一本约20万字的实践专著与技术手册，让读者既能理解AI时代物理教育中的关键变化，也能按真实问题查到可执行的方法、案例、判断标准和技术路径。
- **当前状态**：2026-09-03作者确认优先重写网站部分，并确认现有网站样章偏开发流水账，后续改用“指导为主、案例为证”的技术手册写法。现有网站样章、落体法MVP和开发记录冻结为项目史与案例材料，不覆盖；静电场和活版电路第二稿继续保留为作者内部审阅稿，尚非出版定稿。
- **权威入口**：网站部分先读`00_CONTEXT/网站部分写作任务书-2026-09-03.md`与`04_REVIEW/网站部分重启判断与作者裁决-2026-09-03.md`；三样章历史与配套材料仍从`03_MANUSCRIPT/三样章第二稿-2026-09-02/00_三样章阅读入口.md`进入。第一稿与B2历史文件保留为比较和追溯材料，不再作为现役答案。
- **按问题读取**：处理网站部分时只读网站任务书、重启判断、现有网站样章、MVP开发记录和当前操作需要的原件；不要默认加载四版全稿、全部历史会话、整个论文项目或网站文件树。核对静电场或活版电路时仍按三样章阅读入口定向进入。
- **现阶段流程**：网站部分按章前价值共识、定向材料与事实包、内容结构与视觉策划、一个纵向操作单元、事实/物理/技术/图文/表达/目标读者审查推进。第一个操作单元不过关，不批量写网站部分；其他样章暂不扩写。旧`B0_PREPROCESS/`、十六章候选、旧B2裁决单、S1选择和第一稿只作资源池，不自动回流。
- **作者想法入口**：`00_CONTEXT/作者想法持续记录.md`保存作者关于本书、AI实践与内容生产方式的新认识。2026-09-04新增“真实实践 -> 独立文章 -> 同行反馈 -> 图书结构”的重大转折；以后收到作者新的相关想法，先重读该文件并追加记录。该文件保存思考，不自动替代现役网站任务书或触发书稿重构，流程切换仍需作者明确裁决。
- **目标体量**：正文约18万—22万字。字数是整书结果指标，不是逐章填充任务。
- **范围边界**：现有书稿和论文原件保持只读；外部培训、自媒体和教材资料先登记身份、来源、时效、版权和可验证性，再判断是否进入后续章节。

## 核心生长规则

新增内容至少带来一项：

1. 新的真实对象、案例、数据或失败；
2. 新的解释、关系、比较或边界；
3. 新的教师判断或学生可执行动作；
4. 新的AI思想经过物理教育情境转译后的方法；
5. 新的读者工具，如操作步骤、检查表、模板或排错路径。

同义改写、概念堆叠、工具名单和为补字数生成的段落不算生长。

每章开写前和作者内审前，执行`../../docs/agents/AI-Agent文本写作表达门禁.md`。优先说清读者、核心问题和读者所得；核心案例展开到读者能看懂、学会和迁移。材料很多却只浅层并列、用偶发小问题代替主要路径、或让审核与版本语言压过读者价值时，退回结构或材料阶段。

## 材料身份

| 身份 | 用途 | 进入正文前要求 |
| --- | --- | --- |
| 作者已核验实践 | 核心案例和方法来源 | 回到项目原件、运行记录、课堂材料或作者确认 |
| 合著作者实践 | 核心案例、跨作者比较和共同方法来源 | 保留具体作者、共同完成者、授权与隐私；不改写成另一位作者亲历 |
| M4/M5阶段总结 | 发现已形成的案例、解释和方法 | 回到共享事实、M2证据和原始材料，不把论文压缩稿当唯一事实源 |
| 培训与同行讲座 | 发现同行问题、AI思想和实践方向 | 核对原作者、原始出处、时间和事实；不能写成作者亲历 |
| AI自媒体与教程 | 发现工具用法、学习路径和新方法 | 保存原链接与日期，区分演示、经验和可复核事实；动态信息重新验证 |
| 教材、专著和研究文献 | 建立概念、方法和历史脉络 | 核对原文、页码、版权和适用条件 |

2. 静电场或活版电路的续改从`03_MANUSCRIPT/三样章第二稿-2026-09-02/00_三样章阅读入口.md`进入，读取对应正文和作者审读。
3. 新想法记录读取`00_CONTEXT/作者想法持续记录.md`；独立实践文章进入`../真实实践文章池/README.md`，不自动改写本书任务书。
4. 涉及全书定位或阶段变更时再读`00_CONTEXT/README.md`、`书的宪法-工作版.md`与`最小写书工作流.md`。其中文件名以`00_CONTEXT/`为基准。
5. 只有比较历史候选时才读旧B0/B1/B2/B3与整稿；不把旧大索引、整本教材或四版全文作为默认输入。可靠Markdown与事实档案可复用，具体主张仍回原件。

## 阶段门禁

- B0只登记材料、身份、潜在价值、证据边界和缺口，不写目录或正文。
- B1可以开放产生图书方向，候选数量由材料决定，不以旧书框架收口。
- B2只冻结作者理解并确认的读者承诺、主线、作者声音和禁说项。
- B2形成结构后，每章先通过章前价值共识门：作者确认核心读者问题、核心与支撑价值、展开路径、本地项目材料与证据边界、细节处置、跨章边界和未利用高价值材料。未通过时不深挖材料、不扩写工具、不写正文。
- 章前和每批结束执行三项通用检查：同一材料跨章时核对分析对象、核心问题和读者所得；“没有比较、没有追问、没有达到预期”只有在能说明原定目标、实际条件、教师引导停点和可迁移改进时才进入主线；每个价值点都要对应展开方法、本地材料和证据程度，并列出尚未利用的高价值材料交作者裁决。
- B3至少完成一个纵向样章，经过事实、物理、版权、图文和教师首读后，才规划全书批次。
- B4每批只推进2—3章；每章开写前重复章前价值共识门。材料不足或价值不清时暂停写作，转为讨论、并章、实验、访谈、复测、补图或原文核对任务。
- B5形成全书综合后再按18万—22万字校准，补认识、关系、案例和读者工具，不做同义扩写。
- B6只在出版社或编辑要求明确后对齐体例、篇幅、版权、图件、技术时效和交付格式。

## 文件职责

- `00_CONTEXT/`：定位、作者原则、阶段任务书和工作流。
- `01_SOURCE/`：各阶段材料入口、证据矩阵、台账和候选资源。旧`B0_PREPROCESS/`只作历史机械底表。
- `02_PILOT/`：作者批准的研发项目任务书、事实源、审核设计和后续试点；不等于纵向样章或已完成案例。
- `03_MANUSCRIPT/`：保存旧B3纵向样章及通过章前门禁的正文；当前三篇第二稿属于作者内部审阅稿。
- `04_REVIEW/`：保存历史阶段作者裁决、证据边界和跨阶段问题；旧`全书章节价值地图与作者裁决.md`当前不是结构约束。
- `review/`：面向作者的阶段性交付说明。

## 章级彩图与表达直用

- 每章必须建立视觉任务表，逐项写明读者问题、解释对象、视觉媒介、读图动作、新增判断或行动、来源、边界、彩图方案和正文落点；不设置固定图数。
- 本书正式图件必须是彩图。真实照片保留真实色彩，结构图、流程图、数据图和信息图制作彩色出版底稿；灰度旧图只可作来源或临时占位，不能作为正式成品。
- 正文中的核心图必须形成“图前问题—图中信息—读图动作—图后判断”闭环。图表用于降低理解成本、保存过程或帮助行动，不能只作装饰。
- 图文与关键事实稳定后调用`academic-paper-conservative-editing`。书稿不生成独立审核包或逐项裁决页，只直接合并A类安全修改；B/C类保持原文。执行前保留Git差异、阶段版本或独立副本作为回滚入口。
- 具体规则以`00_CONTEXT/章节彩图与表达直用规则.md`为准。

## 验证与交付

- 移动、重命名或新增来源后，检查资料台账路径真实存在。
- 精确引用前记录原件、内部位置和支持范围。
- 动态AI工具、模型能力、产品名称、价格和政策在成稿时重新核验。
- 复杂任务使用`review-protocol`；没有视觉成果时只交付一份`review.md`，不为形式生成HTML。
- 全书、多章或材料覆盖审阅需要自由跳转和视觉对照时，提供一个综合HTML；已有总览与证据页可复用，只有信息量确实需要时分成两页并互链。保留来源、证据与作者裁决入口，不因章节数量机械增加页面。
- HTML只做文件、链接和基本结构检查，视觉由作者人工查看；作者没有另行要求时，不自动生成浏览器截图或移动端适配结论。
