# 三样章重启：材料考古、新章承诺与网站 MVP 路线

## 摘要

这次深挖后可以明确判断：三篇旧样章都不宜在原稿上继续修补。问题在章节主线，不在个别段落。网站稿把一段完整的教师开发史压缩成了一个偶发 bug；静电场稿让新做的 Python 原型覆盖了两年多的装置生长史；活版电路稿只使用了旧文稿，遗漏了新版 Word、三份 PPT 和关键实物图。

现在三章已经各自找到一条可持续展开的真实主线：

1. **网站**：公开课的教学需求与早期门户、蓝牙、串口、图表等技术能力如何汇合，先长出三个机械能实验页，再长成在线实验室和多功能网站。
2. **静电场**：从 47 元水槽原型，到五类电场、COMSOL 预测叠图、45°镜面展示和动态电容器实测，再到今天用 AI 辅助 Python 重建可复算模型。
3. **活版电路**：如何把电路图拆成可拼的实体语法，让表面符号、内部元件、侧面导电触点与电气现象一一对应，再根据测量任务决定是否加入 ESP32 和数据曲线。

上一版三章将保留为“已否决基线”，本轮没有改动旧正文，也没有修改或部署现有网站。

### 2. 新章承诺

读完本章，读者应当真正带走六件事：

1. 把一节课的教学困难写成可开发的功能任务；

建议正文次序：

### 3. 读者可跟做的 MVP

先复刻“落体法数据工作台”，不在第一步加蓝牙。

| 版本 | 读者动作 | Codex 任务 | 教师验收 |
| --- | --- | --- | --- |
| V0 教学规格 | 写清学生输入、程序输出、计算关系与课堂动作 | 只读学案与表格，列原始量、计算量、单位、公式和待确认问题 | 参考点、速度算法、误差口径均已确定 |
| V1 单页骨架 | 建立器材、步骤、原始数据表 | 生成无计算的界面骨架 | 顺序符合学生实验动作，平板可操作 |
| V2 计算版 | 加入速度、动能、重力势能变化与误差计算 | 依照冻结后的物理规格实现 | 至少一组结果与手算或原 Excel 一致 |
| V3 图表版 | 让表格与能量图同步 | 加动态图、演示数据、清空和导出 | 修改任意输入时图表同步；演示数据不冒充实测 |
| V4 课堂版 | 在平板、投屏与断网条件下走完流程 | 修正触摸区、异常输入、重置和离线访问 | 学生不看代码也能完成录入与汇报 |
| V5 复用版 | 把落体法改造为曲面方案 | 复用表格、图表与验收规则，只更换物理模型和数据接口 | 分清真正复用的能力和需重新裁决的物理含义 |
| V6 硬件扩展 | 再选择串口或 BLE 接入 | 对接真实程序和数据协议 | 手工录入始终保留为回退方案 |

首轮提示词应当先阻止 AI 急着写代码：

> 先不要写代码。读取我提供的课堂学案和数据表，列出学生手动输入的原始量、程序自动计算的量、公式、单位、参考点、一个可手算的验收样例和仍需我确认的问题。不得自动调整原始数据顺序，不得生成实验结论；不确定的物理含义先提问。

### 4. 证据边界

- 现有材料首先支持学生手工录入、平板投屏与小组汇报，不能改写成六组均用蓝牙自动采集。
- 同一方案内是一组分析、一组提问，没有证据说三种方案当堂完成了系统比较。
- 代码历史能证明功能发展，不能单独证明学习效果、采用人数或成绩变化。
- 公开课确切日期、合作者分工、蓝牙当堂使用情况仍需作者确认。

### 3. 两级复刻，而不是一步造出省赛整机

**一级：一下午水槽 MVP**

只做平行板水槽，使用低压电源、共参考电表和探针；固定 P 点与刻度，分别执行“固定正板、移动负板”和“固定负板、移动正板”。每个位置至少重复测量三次，同时保留输入电压、水深和原始读数。现有资料能给出操作思路和历史样例，还需作者补齐最终尺寸、接线和电源口径，才能对外称为可直接复刻。

**二级：课堂展示版**

建立五个独立电极槽、透明预测板、集成大表和镜面/摄像。课堂任务写成“先预测、再测量、最后说偏差”，不把 COMSOL 图当作需要实物盖章的标准答案。

**AI/Python 扩展**

先测量真实槽、极板和 P 点坐标，冻结真实供电，把海报五张照片的实验条件转成带来源的数据表，然后再建两种移动板配置。输出必须同时包含配置、方程、边界、测试和实测对照。用 `E=-∇V` 的正负号错误注入做短侧栏即可，不再占据主叙事。

### 4. 证据边界

- 早期“47 元”只是当时文稿自报，且不含电源和电表，不能移植成熟整机的总价。
- 不同文稿对电源有 3 V、6 V、12 V 和 24 V 等不同口径，成熟 BOM 未冻结前不应自行选择一个数值。
- 海报的五张读数图能证明做过这次演示并观察到趋势，不能证明重复性、精度或学习效果。
- 旧 COMSOL 笔记中的自由空间/表面电荷模型与浅水槽稳恒导电模型不完全同一，不应说成边界严格等同。
- 发明或实用新型申请受理只证明申请被接收，后续驳回不等于装置无效；两者都不能改写成“已授权”。
- 当前还缺成熟版逐件 BOM、几何坐标、水深/水质/稳定时间、重复测量原表、课堂任务单和学生证据。

## 四、活版电路：一张电路图怎样变成可以拼、可以换、可以测的实体系统

### 1. 新材料补回了哪些关键信息

此前转写主要来自旧版介绍文稿。本轮重新检查了 [新版《创新实验(1).docx》](</Users/yaril/个人文档/3 写作/项目资源库/9 其他老师资源库/严力耕/活版电路拼图/创新实验(1).docx>)、[高分辨率演示稿](</Users/yaril/个人文档/3 写作/项目资源库/9 其他老师资源库/严力耕/活版电路拼图/活版电路拼图-创新实验PPT1.pptx>)和其他两份 PPT，得到了以下实质性增量：

| 新发现 | 对章节的意义 |
| --- | --- |
| 散线接法耗时、凌乱；固定板整洁但不能改变拓扑、不能让学生组装 | 可以从两种现有解法的真实矛盾开场 |
| 每个连接面采用“一公一母”导电触点 | 可讲接口标准如何支持模块换序，但极性与旋转规则仍待确认 |
| 先设计表面图案，再用支持多色的 3D 打印机制作 | 表面电路符号进入了结构设计，不只是最后粘贴说明 |
| 教师大板与学生小型模块两个尺度 | “后排看得清”与“小组能操作”是两个不同的设计任务 |
| 双向发光二极管与可视化单刀双掷开关 | 装置在继续解决“电流方向”和“开关状态”的可视问题 |
| ESP32 采集模块、Phyphox、浏览器曲线和 AI 编程界面有实物图件 | 项目不是“完全不用 AI”；它是在定量测量需求出现时才选择数字模块 |

一个必须改正的结构认识：装置上其实有两套不同的磁性机构。

- 模块四角的扁圆磁铁负责把模块吸附到黑板上；
- 模块侧面的导电触点负责相邻模块的定位和电气连通。

上一章把它们混成了一个“磁吸触点”，恰好丢掉了最值得读者学习的机械—电气分工。

另一处版本冲突是：新文稿既写“多色 3D 打印”，又保留“模块表面贴有元件标识和电路图”；旧文稿明确是打印后贴纸。最终工艺需严老师确认，不能在书中自行合并。

### 2. 新章承诺

**建议章名：《一张电路图怎样变成可以拼、可以换、可以测的实体系统》**

全章用“电容器充放电”走完一次真正的组合：

```text
搭出电路
→ 用单刀双掷开关改变充、放电路径
→ 用双向发光二极管呈现电流方向
→ 让学生先解释两种状态中的闭合路径
→ 必要时换入电流传感模块
→ 用 Phyphox 或网页查看瞬态曲线
```

建议正文次序：

1. 散线太乱，固定板又不能动；
2. 把电路图拆成路径、节点、元件和测量模块；
3. 黑板磁铁与导电触点如何各司其职；
4. 用电容器充放电走完一次拼接；
5. 双向 LED 和单刀双掷开关怎样让路径与方向可见；
6. 从教师大板到学生小型套件，为什么缩小不只是改尺寸；
7. 定性现象不够时，再加入 ESP32 与数据曲线；
8. 读者复做：完成最小模块库并逐块验收；
9. 作品有丰富的公开展示记录，真实课堂证据仍从零开始。

闭合电路欧姆定律、伏安法测电阻和自感可以放入“模块库还能支持什么”短栏，不再并列写成四个浅案例。

### 3. 可复制的制作链与当前上限

现有材料已经能还原过程级制作：

1. 先选一个代表电路，确定路径、节点、元件和观察模块；
2. 为每块模块定义表面符号、有效端口、内部连接、方向与极性；
3. 在 SolidWorks 中为黑板磁铁、侧面导电触点、元件和走线预留孔位；
4. 同步设计表面图案；
5. 打印外壳，安装一公一母触点、黑板磁铁和元件固定件；
6. 按表面符号完成内部接线；
7. 先逐块核对，再组合代表电路；
8. 只有当定量问题出现时，才加入 ESP32 数据模块。

但目前没有 CAD/STL、尺寸、公差、BOM、逐块接线图、触点型号与电气参数，因此只能承诺“读者理解并试做最小模块系统”，不能承诺按书一比一复制成品。

## 五、三章不应写成同一种样子

这三章恰好可以用不同写法，回应全书“有些用 AI，有些不用，都服务教学”的定位。

| 章节 | 最适合的章型 | AI 的位置 | 读者主要带走什么 |
| --- | --- | --- | --- |
| 网站 | 教师开发过程教程 | 深度参与需求整理、编码、修改、复用和发布 | 把自己的一个课堂问题做成可用网页的整套方法 |
| 静电场 | 装置生长史＋实验操作章 | 后期用于重建可复算的预测模型 | 从教学难点出发造一个水槽 MVP，会测、会看偏差、会继续改 |
| 活版电路 | 共创作品解剖＋读者制作挑战 | 核心物理链不需 AI；定量测量分支可用 AI 与 ESP32 | 把电路图转成模块系统的设计原则和最小复做路径 |

这种差异不仅是文风不同，也会让全书的“为什么、怎么造、怎么用、那又怎样”真正分工。

## 八、关键决策

1. **三章全部重启，不在旧稿上打补丁。**
2. **网站章先做一个隔离的落体法 MVP，再用它讲从需求到复用的过程。**现网站工作区有未提交改动，MVP 不在原仓库中直接制作。
3. **静电场章先写实物项目，Python 只接续“如今如何重建”。**现有 Python 测试成果可保留为配套工具，不丢弃。
4. **活版电路章以严力耕老师的作品发生史和实体设计为主，ESP32/AI 只是定量测量分支。**
5. **每章承诺的复制深度由证据决定。**网站可以做到功能级复刻；静电场目前可做一级 MVP；活版电路目前只能做过程级复刻。

## 九、下一步

建议不再同时粗写三章，而是以下面顺序做出第一篇真正达标的样章：

1. **冻结网站章承诺。**用本文的章名、八节结构和 V0—V6 作为写作任务书。
2. **在新的隔离目录中重做落体法 MVP。**每一版保留输入素材、提示词、生成结果、教师批注、验收样例和版本差异，为正文直接提供截图和步骤。
3. **MVP 验收后只重写网站一章。**请作者首先判断这一章是否达到“看得懂、学得会、能迁移”，再把同一深度标准用到后两章。
4. **同时做两份最小补料，不等于停笔。**静电场只补平行板槽、极板、P 点、供电与三次重复测量；向严老师只索取一套代表电路的 CAD/STL、BOM、触点规格、逐块接线图、ESP32 原始文件与三人分工。

在这三步完成前，不应再用“材料够多”代替“读者可以完整学会一件事”。
