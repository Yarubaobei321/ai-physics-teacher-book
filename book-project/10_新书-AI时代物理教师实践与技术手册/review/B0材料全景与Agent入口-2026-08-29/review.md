## 验收标准

1. 13份教材默认Markdown路径存在，SHA与资料台账一致。
2. 文件级索引记录数与集合统计一致，没有重复的`collection_id＋absolute_path`。
3. 高敏感学生材料不出现在HTML的文件名与姓名列表中，只显示合计和禁读边界。
4. HTML为自包含静态页面，无外部网络依赖；搜索、类型/作者/证据筛选和展开卡片由本地JavaScript完成。
5. 所有项目内Markdown链接存在；外部原材料保持只读。
6. B0阶段边界仍有效：不生成目录、正文和教学效果结论。

## 使用方法

作者人工判断时先打开`index.html`，按“作者项目、教材、其他教师、参考与旧书”筛选。准备让Fable 5做B1时，只提供`B0-AGENT轻量入口.md`和作者选中的1—3份材料卡；不要附完整CSV或整本教材。

更新外部材料后，在项目根目录运行：

```bash
python3 tools/build_b0_preprocess.py
```

脚本只重建机械索引。新增材料的价值、证据等级、授权和优先级仍需人工更新卡片。
