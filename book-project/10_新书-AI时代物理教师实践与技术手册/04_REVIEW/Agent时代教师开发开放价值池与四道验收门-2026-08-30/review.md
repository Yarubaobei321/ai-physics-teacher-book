# Agent时代教师开发：开放价值池与四道验收门审阅

## 一、摘要

本轮已经把“教教师使用Agent完成开发”从一个候选章节想法，推进为一组暂不受章数限制、能够继续组合和试用的方法材料。

以前，AI橙皮书和WorkBuddy蓝皮书主要承担参考来源，Agent主题仍围绕“是否放进第7章”讨论；四道验收门只有名称和基本判断，还不足以直接带教师做项目。现在，AI橙皮书八册均已完成全书级目录与关键词覆盖，并对关键段落进行深读，形成八张材料卡、32个开放价值单元、四道门操作手册、可复制模板和一个第一方真实退回案例。

建议按下面顺序审阅：

1. [八册深挖与教师转译](../../01_SOURCE/B2/12_AI橙皮书八册深挖与教师转译.md)：先看材料是否真正被转成教师问题；
2. [32个开放价值单元](../../01_SOURCE/B2/13_教师Agent开发开放价值单元池.md)：再看哪些属于本书主干、哪些适合数字资源；
3. [四道验收门操作手册](../../01_SOURCE/B2/14_四道验收门操作手册.md)：重点审查每一道是否能照着执行；
4. [模板与真实案例演练](../../01_SOURCE/B2/15_四道验收门模板与真实案例演练.md)：最后判断模板和培训活动是否可用。

## 四、关键决策

1. **先保存价值，再安排章节。** 当前32个单元允许合并、分散、降级或删除，不按八本书分章，也不按工具品牌分章。
2. **外部书承担方法互证，第一方项目承担事实。** 橙皮书均按B级结构参考使用；数智育才网站、课程、Git版本和课堂记录承担本书案例。
3. **四道门是四种专业否决权。** 构建通过不能替代物理核验，物理正确不能替代教学判断，课堂使用也不能自动获得公开发布资格。
4. **四门只有通过、退回、暂停待确认、停止四种结论。** 结论必须限定对象、版本、环境、样例和当前用途。
5. **稳定方法进入纸书，动态教程后置。** 产品按钮、价格、模型、额度和短期生态数据不进入稳定主张。

## 五、下一步

本轮最适合先做作者价值筛选，不急着改全书目录。建议审阅时直接标出：

1. 32个单元中，哪些是物理教师进入Agent时代必须掌握的8—12个主干单元；
2. 四道门的步骤是否太重、太轻，哪些步骤在真实开发中一定会使用；
3. `v₁/v₂`案例是否适合作为第一次演练，是否还有更典型的失败案例；
4. 下一轮选择哪两类真实项目试门：建议一类为数据／计算页面，一类为公开网站、硬件控制或含学生数据的高风险项目；
5. 主干价值确认后，再判断它们应形成独立章节、跨章方法线，还是纸书＋配套资源的组合。
