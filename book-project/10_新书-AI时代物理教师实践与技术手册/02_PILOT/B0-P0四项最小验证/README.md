# B0—P0 四项最小验证

> 作者裁决：这不是四套待开发系统。原型只负责把教学思想和教师方法变得可观察、可反驳；代码、数据表和审阅页均为附属证据，不成为本书叙事中心。

## 这轮只验证什么

这四项工作服务 B0 材料判断：用最小演示检验“有没有值得本书长期写给教师的思想和方法”，暂不生成目录、章节正文或教学效果结论。

| P0 | 要验证的核心问题 | 当前输入边界 | 最低完成标准 |
| --- | --- | --- | --- |
| P0-1 SOLO 思维评价 | 过程线索能否帮助教师提出更好的追问，而不把层级标签当成学生思维真相 | 自编物理任务、合成作答与人工构造候选树；不使用龙华原团队数据、量表、提示词或工作流 | 有理论原文证据、一个可复查对照、教师追问方法和边界说明 |
| P0-2 知识图谱 | 从知识关系到诊断、推荐之间能否保留可追溯的层级 | 自建动量/碰撞小图谱、自编题、合成学习轨迹；不使用外部团队私有图谱或学生数据 | 图谱、题目映射、简单诊断、推荐依据、反例和人工复核点均可回查 |
| P0-3 选择性自动化 | 低风险自动处理、高风险转人工，是否比“全部自动批改”更可靠 | 自编或合成学生回答；无真实学生身份信息 | 分层基准、重复运行记录、风险升级规则、申诉入口和保守结论 |
| P0-4 教师不可外包判断 | 已有真实项目中，教师究竟在哪些节点必须定义、退回、停止或签字 | 只使用本书已核验的一手项目材料和当前审计记录 | 15—20 个可追溯事件，区分历史行动与本轮审计裁决，并能归纳成可复用判断框架 |

## 共同规则

1. **授权边界**：龙华方向与知识图谱方向都采用独立自建 MVP。当前没有龙华原团队授权，不能复用其数据、量规、提示词、代码、运行结果或组织流程。
2. **证据身份**：真实历史行动、当前材料审计、合成测试和未来计划分别标记，不互相冒充。
3. **教师权利**：每条自动输出都要能查看依据、改写、否决或转人工；高风险判断默认不自动发布。
4. **教学主张**：离线程序跑通只证明流程可运行，不证明诊断正确、教学有效或能够规模化。
5. **材料归属**：产物放在独立试点目录；原始资料保持原位，不覆盖既有书稿。

## 本轮最终要回答的三个 B0 问题

- 哪些认识能形成教师反复使用的判断工具？
- 哪些方向只有技术演示价值，暂时不值得进入本书主线？
- 下一步最小补证应找真实教师审读或经授权的真实学生材料，还是应当停止继续开发？
