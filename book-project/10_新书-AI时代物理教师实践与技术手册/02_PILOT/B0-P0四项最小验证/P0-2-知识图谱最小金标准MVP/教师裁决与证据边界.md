# 教师裁决与证据边界

## 一、事实身份

- 物理单元：高中物理“动量与碰撞”。
- 题目：本项目为结构验证而自编，没有复制教材、培训课件或平台题库。
- 学生：`SYN-A`、`SYN-B`、`SYN-C`均为人为设计的合成画像，不对应任何真实学生。
- 算法：使用最简单的二状态 BKT 式更新作为演示；参数由项目显式指定，不是从学生样本拟合。
- 图谱：由一位编制者建立，当前只是“待第二位物理教师审定的候选图谱”。

## 二、四层分别能说什么

| 层 | 可以支持 | 不能支持 |
| --- | --- | --- |
| 章节标签 | 这个任务属于哪个单元、单元总正确数 | 学生在哪个概念上遇到困难 |
| 内容图谱 | 概念之间的候选前置关系、回查路径 | 学生已经掌握或未掌握某个概念 |
| Q-matrix | 每道题的预期测量对象、按组件汇总证据 | 一次错误的唯一原因；矩阵本身也可能标错 |
| 动态状态 | 在给定参数和作答序列下，假设怎样更新 | 学生脑中的真实状态、稳定能力或教学效果 |

## 三、状态更新为何只能叫“诊断假设”

对一个知识组件，脚本保存一个`P(掌握)`。每次看到答对或答错，先按猜测率与失误率进行贝叶斯更新，再加入一个固定学习转移率。这个过程透明，但至少有四个限制：

1. 同一道多组件题被简化为对每个组件提供同方向证据；真实错误可能只来自其中一个组件；
2. 题目之间被当成条件独立，实际存在题型熟悉度、计算负担与上下文迁移；
3. 所有组件共用一组演示参数；
4. 合成轨迹没有噪声、缺失与真实学习过程，不能检验模型拟合优度。

因此，概率只能触发“回看哪几道原始作答、追问什么、用哪道区分性复测”的建议，不可自动生成成绩、标签或永久画像。

## 四、已经否决的三类边

`rejected_edges.csv`保留了三条被否决候选：

- 把“一维弹性碰撞”设为“动量守恒”的前置：因果方向倒置；
- 把“完全非弹性碰撞”设为“弹性碰撞”的前置：两者是基于共同基础形成的不同分支；
- 把“会算冲量”直接设为“会定义系统”的前置：计算技能与系统边界判断不是同一依赖。

保留被否决边的目的，是让图谱形成过程可追溯。未来第二位教师可以恢复、改写或新增边，但必须写明物理依赖与教学顺序的区别。

## 五、下一轮人工审定清单

1. 两名教师独立审查10个组件的粒度与定义；
2. 对每条边标注“物理必要”“常用教学顺序”“无依赖”之一，并报告分歧；
3. 对20道题独立填写Q-matrix，再比较一致率，不先看当前答案；
4. 为多组件题补“主组件／支撑组件”或区分性追问题；
5. 只在完成脱敏和知情边界后，用小样本真实作答检查题意与归因；
6. 参数拟合和稳定复测前，不设置“80%即掌握”等固定阈值。

## 六、关于 LLM

本项目不调用 LLM。若以后加入，允许它在受约束模板中解释：

> “根据哪些题、哪个Q-matrix映射和哪次更新，系统暂时建议回查什么。”

LLM不得自行修改图谱、Q-matrix、答案、状态或路径规则；任何修改先生成候选差异，再由教师审核进入事实源。
