# P0-3 物理作业选择性自动化基准 MVP

> 状态：离线管线已跑通，尚未进入真实模型、双教师或真实作答验证。
>
> 数据身份：24份自编合成作答。
>
> 参考身份：单作者暂定参考。
>
> 关键限制：输出数字不是任何AI模型准确率。

## 核心教师方法：错误代价决定是否自动化

教师先判断“这类错误一旦漏过，会造成什么后果”，再决定AI可以处理到哪一步。识别一处普通格式可能只需抽查；漏掉受力、弄反电表连接、把实验结论建立在缺失数据上，都会改变物理判断或教学行动，必须升级给教师。

因此，自动化范围不由一个总准确率决定。即使两类作答的平均正确率相同，只要错误后果不同，自动处理规则就应不同。最稳妥的次序是：

1. 分清识别、评分、物理判断和教学解释分别会错在哪里；
2. 预先约定哪些错误必须人工复核；
3. 在硬边界内逐步放宽自动处理范围；
4. 同时观察不一致、错误代价和教师复核量，而不只看处理比例。

## 这个MVP怎样把方法跑一遍

物理作业不宜只问“AI能批多少”。更实际的问题是：哪些样本可以进入自动预审，哪些信号必须触发教师复核；放宽自动处理范围时，教师复核量减少多少，同时增加了多少不一致和错误代价。

本MVP先验证记录与比较方法，不验证某个模型。它把一次“批改”拆成五层：

```text
原始作答
  ↓
识别：系统读到了什么？
  ↓
评分：按量规给多少分？
  ↓
物理判断：关系、条件和因果是否成立？
  ↓
教学解释：下一次追问应针对什么？
  ↓
最终决定：自动接受、教师复核或仅人工处理
```

这样可以定位“读错了”“分数不同”“物理结论错了”“教学解释过度了”分别发生在哪一层，避免把它们压成一个总准确率。

## 立即运行

在本目录执行：

```bash
python3 scripts/run_benchmark.py
python3 -m unittest discover -s tests -v
```

脚本只使用Python标准库，不联网、不调用外部模型，也不需要安装依赖。每次运行都会重新生成`outputs/`中的四份CSV和一份摘要。

## 当前演示结果怎样读

本次运行的管线推荐为：自动接受4份、教师复核12份、仅人工处理8份。这是预设规则对合成样本的分流结果，不代表真实节省了多少教师时间。

阈值对照显示：

- 风险阈值0.15时，只自动处理2/24份，合成参考下没有不一致，教师仍需复核22份；
- 风险阈值0.45时，自动处理7/24份，自动样本中有14.3%至少一层与暂定参考不一致，加权错误代价为1，教师复核17份；
- 风险阈值0.85时，仍只自动处理8/24份，自动样本不一致率为12.5%，加权错误代价为1，教师复核量保留16份。

最高阈值仍保留16份人工复核，是因为硬升级规则不允许阈值绕过物理冲突、识别异常和高风险复杂作答。这个“复核下限”比追求100%自动覆盖更接近本MVP要验证的选择性自动化。以上数字的价值在于展示取舍方法；它们不支持“0.15是最佳阈值”或“系统可自动批改8.3%的作业”。正式阈值必须由真实样本、双教师基准和真实模型重复调用共同决定。

## 三条硬升级规则

管线先执行硬规则，再看数值阈值：

1. 检出明确物理冲突时，不能自动接受；
2. 机器读入与合成原始作答明显不一致时，必须回看原作答；
3. 高风险图像描述和实验报告只进入人工处理。

这三条规则已进入自动测试，并在曲线的每个阈值中强制执行。曲线逐步放宽的只是硬边界以内的数值风险阈值，不能把硬升级样本纳入自动处理；它不是当前推荐政策。

## “不一致”和“错误代价”是什么

只要识别、分数、物理判断、教学解释或最终决定中至少一层与单作者暂定参考不同，该自动样本就计为一项不一致。

演示权重为：分差每1分计2；一般物理状态不一致计3；涉及明确物理冲突计5；教学解释不同计1；识别降级计2；机器决定比人工参考更激进时，每跨一级计4。权重只用于证明管线能计算代价，正式研究前必须由教师预先裁决并冻结。

教师复核量目前只按“未自动处理的份数”计算，没有测量分钟数。后续真实小试才记录实际复核时间、改判动作和放弃原因。

## 重复评分为何仍是确定性的

每份样本运行5个固定的压力测试变体。变体依据样本编号和运行序号生成可复现的±1分扰动，只对识别降级、证据不完整或中高风险样本生效。这用于验证“重复记录—波动检测—人工升级”的软件链条。

它不模拟任何特定大语言模型，因此`score_spread`只能理解为测试夹具制造的压力，不是模型稳定性结论。

## 申诉与改判怎样保留

`outputs/appeals_results.csv`同时保留机器初始分数、初始物理状态、初始教学代码、申诉理由、人工复核动作、修订结果和依据。人工改判不会覆盖原结果。

当前4项申诉分别演练：识别遗漏、缺单位的扣分边界、图像描述遗漏和实验报告无原始数据。正式使用时还需增加复核人、时间、原图锚点和量规版本。

## 下一步真实验证门槛

进入真实模型评估前，至少补齐：

1. 20—30份经授权、脱敏的真实小样本及原图；
2. 两名物理教师独立评分和协商前后记录；
3. 同一模型、同一参数、同一提示词重复3—5次；
4. 识别、评分、物理判断和教学解释分别计算，不公布单一总准确率；
5. 先冻结错误代价与升级条件，再运行模型；
6. 量规无法稳定解释时停止扩样。
