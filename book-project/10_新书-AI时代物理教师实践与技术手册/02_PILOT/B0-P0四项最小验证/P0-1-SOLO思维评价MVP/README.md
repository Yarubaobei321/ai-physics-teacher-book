# P0-1：SOLO思维评价最小验证

## 做成了什么

本目录只保留两个核心成果：

1. [SOLO理论一手证据调研](./SOLO理论一手证据调研.md)：说明SOLO能描述什么、不能替教师断定什么；
2. [自编物理作答最小对照](./自编物理作答最小对照.md)：用一个人工合成回答演示“原话→候选结构→误差审核→教师追问→新任务复测”。

没有开发平台、自动定级器或复杂数据系统。这里验证的是一套教师可执行的方法，不是一个产品。

## 教师可以直接带走的方法

拿到AI生成的“思维树”时，先不要看树是否漂亮，也不要急着定SOLO等级。依次做四步：

1. **逐句找来源**：每个树节点必须能回指学生原话；
2. **圈出四类变化**：遗漏、无原话依据的增补、意义失真、原话没有表达的错连；
3. **回到原话提假设**：SOLO只描述这一次任务中可观察到的结构，允许写两个相邻候选等级；
4. **用追问和新任务推翻自己**：先问一条能区分“不会”与“省略”的问题，再换一个表面情境复测关系是否保持。

还要把两个判断分开：候选结构是否忠实，回答中的物理是否正确。忠实保留的观点可能是错的；机器补上的话也可能物理正确，却不能冒充学生已经表达的证据。
