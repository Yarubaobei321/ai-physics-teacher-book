# 一次作答怎样变成可复查的诊断假设

> 数据身份：本页题目、回答、候选结构、追问和复测任务均为人工自编，不对应真实学生，也未调用ASR或LLM。它只演示方法能否说清楚，不能提供任何效果或准确率证据。

## 第一步：只看原话

### 自编任务

在近似水平的气垫导轨上，质量均为\(m\)的小车A以速度\(v\)向右运动，小车B静止。两车碰撞后粘在一起。请解释共同速度为什么是\(v/2\)，并说明这个结论成立的条件。

### 合成回答

> 两车粘在一起以后总质量变成了\(2m\)，所以速度就是原来的一半。它们碰撞时动量守恒。

教师先把原话切成三个可回指的命题：

| 锚点 | 原话命题 | 物理审核 |
| --- | --- | --- |
| P1 | 粘在一起后总质量为\(2m\) | 在本题中正确 |
| P2 | 因为总质量变成两倍，所以速度变成一半 | 结论碰巧正确，推理缺少初末动量与外冲量条件 |
| P3 | 碰撞时动量守恒 | 缺少系统边界和“碰撞期间外力冲量可忽略”的条件 |

这里已经出现一个重要区别：回答有相关要点，也有因果链，但这条链不完整。教师不能只数关键词，也不能因为最终答案正确就判定解释完整。

## 第二步：审核候选结构是否忠实

假设某种结构化工具给出下面的候选树：

```text
A、B组成系统
├─ 碰撞期间外力冲量可忽略
├─ 系统动量守恒
│  ├─ 初动量 mv
│  └─ 末动量 2mu
└─ 所以 u=v/2
```

这棵树在物理上比原回答完整，却不能当作学生已经表达的思维证据。

| 候选内容 | 原话锚点 | 审核结果 | 为什么重要 |
| --- | --- | --- | --- |
| A、B组成系统 | 无 | **增补** | 系统替学生补出了分析对象 |
| 外力冲量可忽略 | 无 | **增补** | 这是守恒成立的关键条件，原话未说 |
| 系统动量守恒 | P3 | **失真风险**／条件缺失 | 原话没有界定哪个系统，候选结构把对象收紧成了A、B系统 |
| 初动量\(mv\) | 无 | **增补** | 原话没有建立初态量 |
| 末动量\(2mu\) | 无 | **增补** | 原话没有建立末态量 |
| 由\(mv=2mu\)推出\(u=v/2\) | 无 | **错连／增补** | 工具把正确推导补成了学生自己的关系链 |
| “质量翻倍直接导致速度减半” | P1→P2 | **遗漏** | 原话中最值得诊断的错误因果反而消失了 |

因此，这棵树适合做“教师反馈候选”，不适合直接做“学生思维画像”。如果按树定级，机器补全会把原回答从不完整解释抬高为关系整合。

## 第三步：把SOLO写成待推翻的假设

基于原话，而不是基于美化后的树，可以写：

> **当前假设：多点结构／关联结构待辨。** 学生提到了总质量和动量守恒多个相关方面，也表达了质量—速度因果；但这条因果在物理上不成立，系统边界、外冲量条件和初末动量关系也没有出现。是否把“结构完整但关系错误”计入关联结构，必须由本地量规预先说明，不能临场迁就答案。

这里保留两个相邻候选，不强行终评。SOLO描述的是这一次任务中的可观察表现，不是学生永久的“思维等级”。

## 第四步：用一条追问区分“不会”与“省略”

教师追问：

> 如果小车B碰撞前也向左运动，只知道两车粘后的总质量，还能判断共同速度吗？你还需要哪些量，依据是什么？

这条追问没有直接给出“外力冲量”或完整方程，但会让两种解释出现分叉：

- 若学生能主动说出两车的初速度、质量、系统边界与初末总动量关系，原回答更可能是表达省略；
- 若学生仍坚持“总质量翻倍，所以速度减半”，错误比例规则的解释得到更强支持。

追问后的回答是**支架后新证据**，不能倒写成初次回答已经达到关系结构。

## 第五步：换表面情境复测关系能否迁移

复测任务：

> 质量为\(2m\)的小车A以速度\(v\)向右运动，质量为\(m\)的小车B以速度\(v\)向左运动。两车碰撞后粘在一起。忽略碰撞期间的外力冲量，判断共同速度的方向并求大小。

教师观察的不是学生有没有记住\(v/2\)，而是能否在新表面条件下继续完成：

```text
选系统
→ 判断外冲量条件
→ 写有方向的初总动量
→ 写末总动量
→ 建立关系并检查方向
```

若关系保持，可以把原假设修订为“已出现关系整合证据”；若只会套等质量结论，应保留或下调原假设。一次复测仍不足以形成稳定能力结论。

教师验算锚点：取向右为正，初总动量为\(2mv-mv=mv\)，末态总质量为\(3m\)，所以共同速度应为向右\(v/3\)。这个结果刻意不同于原题的\(v/2\)，避免只背结论也能碰巧答对。

## 教师可复制的五行记录

```text
原话中明确说了什么：
候选结构遗漏／增补／失真／错连了什么：
当前SOLO候选及证据：
能区分竞争解释的一条追问：
换情境后，哪条关系保持或消失：
```

## 这个演示增加的认识

1. **一棵物理上正确的树，也可能是失真的测量结果。** 它可能把系统知识补成学生知识；
2. **生成忠实度与物理正确性是两条审核线。** 两者任一不合格，都不能直接进入学生诊断；
3. **SOLO最有教学价值的地方是帮助设计下一问。** 它把“感觉学生没想清楚”改成可以追问、复测和修订的假设；
4. **复测必须改变表面情境。** 只换数字或让学生复述刚才的提示，不能证明关系迁移；
5. **教师最终判断仍不可外包。** 教师决定任务要求、证据是否忠实、物理是否成立、追问是否泄露答案，以及何时停止推断。
