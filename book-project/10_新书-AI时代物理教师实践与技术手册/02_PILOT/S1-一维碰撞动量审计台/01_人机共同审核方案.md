# S1人机共同审核方案

> 原则：可复算的交AI预审，可感知和需要专业裁决的留给人；AI报告也必须被抽查。

## 一、七道门

| 门 | 责任者 | 核心动作 | 最低证据 | 不通过时 |
| --- | --- | --- | --- | --- |
| G0 任务冻结 | 作者／物理教师 | 确认对象、学生困难、范围和不做项 | 已签任务书 | 缩小或重写任务 |
| G1 真值建档 | AI整理＋教师核对 | 登记公式、条件、单位、特殊值和待核项 | 事实源通过结构校验，教师核公式 | 公式保持pending，不开发 |
| G2 AI静态预审 | AI | 查数据来源、单位、公式、同一量多处取值、声称功能是否实现 | 逐条结论、位置和计算过程 | 形成退回单 |
| G3 自动测试 | 开发者／AI | 执行T1—T7及输入边界测试 | 输入、期望、实际、残差 | 修正后只复验相关条目并跑全套回归 |
| G4 人工运行验收 | 至少1名教师 | 真打开、逐个点击、定格、检查初始状态和可读性 | 操作记录与问题清单 | 退回交互或呈现问题 |
| G5 物理与教学终审 | 物理教师＋合著作者 | 独立复算，判断模型边界、课堂任务和易错提示 | 签字或明确批注 | 不进入课堂／书稿候选 |
| G6 作者裁决 | 作者组 | 判断继续、缩小、暂停、试用或入书 | 决定、理由、允许主张 | 保留为失败材料或待开发项目 |

## 二、AI预审固定检查

1. 每个显示数的数据身份：解析计算、随机模拟、人工输入或真实测量；
2. 任取两组参数复算碰前后总动量，列原始数、公式和残差；
3. 弹性碰撞复算总动能，完全非弹性碰撞比较动能变化；
4. 同一速度／动量在文字、箭头、表格、条形图中的符号和值是否一致；
5. 页面写出的模型条件和代码实际限制是否一致；
6. 播放倍率、复位、参数修改是否改变了可信状态；
7. 找不到实现位置时明确写“未找到”，不以页面文字代替代码证据。

AI预审结论只能写“通过／可疑／不过”。每条“通过”也要附依据；不接受“整体没有问题”。

## 三、人类不能外包的检查

- 教材学段和术语是否合适；
- 系统边界与正方向是否让学生一眼可见；
- 初始状态、碰撞状态和碰后状态是否真的能被操作到；
- 箭头、正负条、颜色和动画是否造成新的误解；
- 预测—操作—复算任务是否能在课堂时间内完成；
- 这个页面是否比板书、真实实验或现有资源增加了教学价值；
- 哪些结论允许进入书中，哪些仍只能写为项目设想或本地测试。

## 四、审核报告最小格式

| 字段 | 要求 |
| --- | --- |
| 对象与版本 | 文件、版本、哈希或提交号 |
| 检查条目 | 对应G门和测试编号 |
| 结论 | 通过／可疑／不过 |
| 证据 | 页面位置、代码位置、输入输出、截图或原始数 |
| 复算 | 公式、代入、结果和残差；不适用时说明 |
| 人工操作 | 点击或定格步骤、实际看到什么 |
| 修改要求 | 可执行，不写“有问题请优化” |
| 复验 | 复验人、日期、版本和结果 |

## 五、当前主张上限

完成G0—G5，可以说“这个版本通过了约定的模型、特殊值、运行和教师审读”。只有真实课堂试用并留下相应证据，才可以描述教师和学生怎样使用；任何门通过都不能单独证明提升了理解、成绩或AI素养。
