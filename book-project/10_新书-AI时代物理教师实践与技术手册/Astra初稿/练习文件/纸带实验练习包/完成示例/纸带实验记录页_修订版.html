一装置与选点

实验器材

打点计时器、纸带、重物、刻度尺。（电源与导线按设备说明配置。）

操作提醒

  1. 先接通电源，待打点稳定后再释放重物。
  2. 打点计时器的供电方式与电压按设备铭牌或说明书执行。
  3. 重物应靠近打点计时器由静止释放，纸带保持竖直，减少与限位孔的摩擦。
  4. 从打出的纸带中挑出点迹清晰的一段，再选定计数点。

选点与坐标

  • A、B 是同一条清晰纸带上选定的两个状态，B 晚于 A。
  • A 不默认是静止释放点，本页不使用“从静止开始下落”的任何推论。
  • A、B 可以是相邻的计数点，各自用于测速的前后相邻点允许共用。
  • 沿重物下落方向建立位置坐标 s，六个位置均从同一参考点量起。 s 是位置坐标，不是“距地高度”；允许出现负值。
  • 检查条件：同一组三个位置须严格递增——sA前 < sA < sA后， sB前 < sB < sB后；且 B 在 A 之后（sB > sA）。

相邻计数点的时间间隔 T = n / f。f 与 n 由设备与选点确定，请按实际情况填写。

三计算比较

先将位置由厘米换算为米，再按下式计算。A 前与 A 后、B 前与 B 后分别关于所求时刻等时间间隔； 在近似匀变速运动条件下，一段位移内的平均速度可代表该段中间时刻的瞬时速度。

T = n / f　　vA = ( sA后 − sA前 ) / ( 2T )　　vB = ( sB后 − sB前 ) / ( 2T )　　Δh = sB − sA
重力势能减少量 ÷ 质量：gΔh　（单位 m²/s²）
动能变化量 ÷ 质量：( vB² − vA² ) / 2　（单位 m²/s²，带符号，可能为负）
带符号差值：D = gΔh − ( vB² − vA² ) / 2　（单位 m²/s²，带符号）

以上两项均已约去质量 m，单位为 m²/s²，不是焦耳；本页不输入质量，也不显示以焦耳为单位的能量值。

      请结合差值 D 的大小、测量精度与实验过程写出你的分析。若数据不足以支撑判断，可以填写“数据不足，暂不能判断”。

      教师提示（点击展开，打印时不输出）
      • 重物与纸带受到空气阻力、打点计时器限位孔的摩擦等作用，阻力做负功， 通常使动能变化量 ( vB² − vA² ) / 2 略小于重力势能减少量对应的 gΔh， 此时 D 为正值。
      • 读数估读、点迹对准、刻度尺精度、f 与 n 的取值等误差，也可能使差值向其他方向偏（D 为负或接近零）。
      • 动能变化量除以质量是带符号的量：vB < vA 时它为负，表示动能减少。
      • 本页不替你判定是否守恒，也不设置“误差在百分之几以内就算守恒”的阈值。
      • 若发现原始读数不合理，应重新测量并在结论中说明，不要直接修改已记录的读数。
