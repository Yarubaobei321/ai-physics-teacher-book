# 教材AI开发雷达

这是111项教材主题的本地筛选入口，单一工作是帮助物理教师缩小开发候选：按领域、优先级、首选载体、包含载体和AI能力筛选，并同时查看学习对象、最小AI增量和真实／虚实要求。

## 载体角色

- “首选载体”是源表“主载体”组合中的第一个代码；
- “支持载体”是后续代码，顺序原样保留；
- “包含载体”筛选同时检索首选与支持角色。

这三项都由schema 1.1按源顺序机械生成，不根据主题语义重排或补标。页面卡片用文字标签和不同样式区分首选／支持，不只依赖颜色。

## 使用

直接双击`index.html`。页面不联网、不保存筛选、不读取学生数据，也不需要本地服务器。

修改上游`02A／02B／02C`后，先在教材地图根目录运行目录生成器，再在本目录运行：

```bash
npm test
```

测试会从`../data/topics.jsonl`重新生成`topics.bundle.js`，验证111个唯一主题、schema 1.1、首选／支持顺序、三领域计数、两种载体筛选的区分、搜索与脚本语法。

## 视觉判断

页面把每个主题的六类载体画成一条“证据轨”：K关系、S模型、D/H现实、V视频、P工程。实色与“首选”文字标记第一个代码，浅色虚线与“支持”文字保留其余代码的顺序。它同时提醒使用者，真实测量与模型输出必须保持不同身份。

## 边界

- 上游三份Markdown矩阵仍是内容权威，页面是机械检索副本；
- A7是合法标签，但当前源表没有显式使用，页面不会自行补写；
- 页面不生成项目、不决定优先级、不替代教材原PDF或物理教师审核；
- 筛选结果不证明原型、课堂、学习效果或长期维护已经完成。
