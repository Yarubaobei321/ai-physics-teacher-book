## 先记住五条规则

1. 新书的最高事实源是作者真实项目原件和作者确认，不是旧书、论文压缩稿或外部工具书。
2. 每次最多选3个材料块，每块最多打开1—5份原件。
3. 教材、专著和AI工具书先看大纲或导航；只读与当前问题相关的章、节或案例。
4. 其他教师材料保留原作者。含学生姓名、作品或对话的271个文件不得默认打开。
5. 索引、摘要、卡片和文件名负责导航；写入具体事实时回到原件或已经核验的事实档案。

## B1优先材料池

以下顺序只表示B0材料成熟度，不是全书目录：

1. `PRJ-TEACHER-AI`：教师怎样表达学科约束、判断错误并验收AI产物。
2. `PRJ-MECH-ENERGY`：一个公开课怎样连接装置、实验、数据、网页和多证据任务。
3. `PRJ-SHUZHI`：分散资源怎样长成可维护的教学网站。
4. `PRJ-ESP32`：积木、代码、设备、协议和物理响应怎样形成工程链。
5. `PRJ-STUDENT-AI`：学生与AI共制作品怎样做过程—成品双轨评价。
6. `PRJ-CONTINUING-ED`：教师如何从真实问题走到需求、实现、验收和发布。
7. `PRJ-EFIELD-DEVICE`、`PRJ-MOMENTUM`：装置迭代、模型边界和人工物理审阅。

这些项目还没有被作者裁决为主线。B1应比较它们能为读者增加什么新认识，而不是按材料体量排章节。

## 精确检索方法

在`01_SOURCE/B0_PREPROCESS/`下执行：

```bash
rg '机械能守恒' generated/B0-文件级索引.csv
rg '法拉第|电磁感应' generated/B0-文件级索引.csv
rg 'default_read,入口|default_read,按需' generated/B0-文件级索引.csv
```

CSV包含绝对路径、所有者、材料身份、敏感级别、默认读取级别、文件角色、大小、标题和部分Markdown指纹。路径命中后仍需回材料卡判断能否使用。

## 停止条件

出现以下任一情况就停止扩读，转为问题单：

- 所有权、授权或学生隐私不清楚；
- 只有课题目标、宣传稿、网站功能或软件测试，却要推导课堂效果；
- 旧书、论文和项目原件之间事实冲突；
- 教材Markdown中的公式、数据、题目或人名需要直接引用；
- 动态AI工具的功能、价格、模型能力或政策可能已经变化；
- 现有材料不能给出真实对象、证据、失败、判断或可迁移方法。
