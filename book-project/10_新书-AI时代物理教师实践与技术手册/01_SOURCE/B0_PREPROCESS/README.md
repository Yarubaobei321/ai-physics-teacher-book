> 状态：停止维护。本目录保留2026-08-29重做前的10,491条机械索引、人工卡和HTML生成数据，只用于查漏与追溯。当前B0入口为`../B0/00_scope.md`、`../B0/02_material_review.md`和`../B0/03_b1_handoff.md`。不要再运行旧构建脚本扩大索引，也不要把本目录卡片当成当前B1输入。

> 状态：2026-08-29已建立第一版。用途：让B1及后续Agent先看地图、卡片和大纲，再按问题读取少量原件。

## 这一层解决什么问题

新书可用材料分散在作者项目、旧书、教材、参考专著、AI工具书和其他教师资料中。直接扫描这些目录会同时造成三类问题：重复版本占用上下文、导航材料被误当事实、学生与他人材料越过授权边界。

本目录把材料组织成四层：

```text
L0 轻量入口：知道有哪些材料块、哪一块值得读
  ↓
L1 人工卡片：知道能支持什么、不能支持什么、先读哪份
  ↓
L2 大纲与文件检索：定位到一本书、一项项目或一个文件包
  ↓
L3 原件复核：只打开当前主张需要的1—5份原件
```

## 默认入口

1. [B0-AGENT轻量入口.md](./B0-AGENT轻量入口.md)：Agent第一读物，控制上下文预算。
2. [B0-全景材料分类索引.md](./B0-全景材料分类索引.md)：查看材料块、数量、所有权和加工状态。
3. `cards/`：作者项目、教材、其他教师、旧书和参考书的人工判断卡。
4. `generated/B0-教材大纲卡片索引.md`：按册别定位教材章目。
5. `generated/B0-文件级索引.csv`：最后才用的机械检索底表，不整表读取。

## 当前预加工结果

- 作者项目：13项真实项目已形成统一卡片，可从问题路由到权威入口。
- 教材：确定12册学生教材＋1册教师用书的默认Markdown；精校版优先，其余使用官网Hybrid优化版。

- AI工具书：AI橙皮书按总索引→逐书导航→全文路由；WorkBuddy按总目录→篇章→具体案例路由。
- 完整性：九个登记集合共10,491条文件记录、约1.2GB；原材料均保持原位只读。

## 自动更新

当教材、其他教师资料、旧书或参考书新增文件后，在新书项目根目录运行：

```bash
python3 tools/build_b0_preprocess.py
```

脚本只重建`generated/`机械索引，不修改人工卡片，不读取PDF正文，不做OCR，也不移动原文件。新增材料是否真正可用，仍需人工更新卡片和证据边界。

## 已知边界

- 文件级完整不等于内容级逐份审阅完成。
- 教材优化版不是逐页逐字人工审定版；关键公式、数据和引文回查PDF。
- 其他教师原始Office文件尚未批量转Markdown；只有被B1选中的项目包才转写。
- 工作区中的旧论文和历史AI稿默认不进入上下文，只在比较、诊断或追溯时打开。
- B0预加工不产生书名、目录、章节正文或字数任务。
