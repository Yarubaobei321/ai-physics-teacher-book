# 三路线共享写作入口

> 用途：为Fable、GLM、Grok三版提供共同事实、原件入口和证据上限。  
> 原则：共享核验结果，保持叙述独立；先复用可靠证据包，具体主张需要时再回原件。

## 文件

1. [`01_共享事实与证据边界.md`](./01_共享事实与证据边界.md)：三版可共同调用的稳定事实、可写范围和禁说项；
2. [`02_案例复用与路线接口.md`](./02_案例复用与路线接口.md)：同一案例怎样给三条路线提供不同读者价值；
3. [`03_原件存在性与指纹核验.md`](./03_原件存在性与指纹核验.md)：本轮重新核对的关键原件路径、大小和SHA-256；
4. [`04_协调记录与待核问题.md`](./04_协调记录与待核问题.md)：共享发现、跨版冲突、待作者确认和后续补证；
5. [`05_三版声音与趋同审计.md`](./05_三版声音与趋同审计.md)：三条路线的阅读发动机、后半部趋同位置和融合时应保留的差异；
6. [`06_完成情况与未完成位置.md`](./06_完成情况与未完成位置.md)：最终规模、成品入口、Word验收、自然停笔点和作者待决事项。

## 本轮处理口径

- 2026-08-30已经形成原件级证据包的材料直接复用，不生成第二套摘要；
- 本轮重新检查关键原件是否仍存在并记录指纹；
- 受限学生材料、商业题库正文和未授权课堂图片不重新打开；
- 共享层只规定事实边界，不规定三版的章序、声音或表达。
