# B2首个纵向样章任务书

> 版本：v0.1  
> 更新：2026-08-29  
> 状态：首选方案待作者裁决，尚未进入B3  
> 首选主题：改进版大纲第8章“从一个页面到一个资源网站”

## 一、为什么推荐这个样章

首个样章需要同时检验实践专著与技术手册两种形态，也要把AI、物理教师判断、真实失败、操作路径和维护边界放进同一条阅读链。A03“从一节公开课到教学资源网站”的材料目前最接近这一要求：它保存需求、实现、教师否决、版本变化、页面与课堂边界，也能承接D1全过程判断、D4行动入口和U7维护复用。

本样章不承担“平台产生教学效果”的主张。它检验的核心问题是：一线教师怎样把一个真实教学问题说清、做小、验真、退回、修改，并判断何时发布或停止扩建。

样章通过后，建议用第9章“超重与失重”完成第二个短试写，检验丁龙的独立作者声音能否完整保留，以及严力耕超失重仪能否在不稀释课例的前提下形成相邻关系。

## 二、首选样章的读者承诺

读完后，一线高中物理教师应当能够：

1. 从自己的课堂中选出一个小而真实的问题；
2. 写出对象、使用者、学习动作、物理约束和当前不做事项；
3. 用最低充分技术形成一个可检查的原型；
4. 分别检查物理模型、真实对象／数据和教学任务；
5. 用退回理由、版本记录和维护责任处理AI生成结果；
6. 判断资源应继续开发、保持单页、并入系统、暂缓或撤回。

## 三、范围与材料入口

### 默认只读入口

- A03对应的M4内容稿，作为完整过程叙事与材料导航；
- B1 `D1`、`D4`方向卡和AI物理教学应用工程架构；
- 数智育才网站的项目入口、与样章选定页面直接相关的源码和Git记录；
- 对应公开课的任务、页面使用说明、教师否决或修改记录；
- 已登记的图片、截图、数据和授权状态。

### 不默认读取

- M5投稿压缩稿作为唯一事实源；
- 整个数智育才网站、全部Git历史或所有旧页面；
- 与样章对象无关的书稿、课程、教材和外部AI资源；
- 没有授权的学生、课堂人物或第三方图片。

具体主张进入正文前，必须回到它所依赖的源码、页面、记录、图片或作者确认；M4只提供入口和已经形成的解释。

## 四、样章应完成的解释链

1. **对象与冲突**：课堂中出现了什么具体问题，现有资源为什么不足；
2. **需求形成**：教师怎样把对象、变量、任务和成功标准交给AI或开发工具；
3. **最小实现**：首版为什么只做这些，哪些功能明确不做；
4. **失败与退回**：至少保留两类不同失败，呈现教师怎样识别并说明退回理由；
5. **三重验收**：物理模型、真实对象／数据、教学任务怎样分别检查；
6. **真实使用边界**：页面在哪里使用过、谁使用过、有哪些记录，缺少什么就不作什么主张；
7. **发布与维护**：单页怎样进入网站，何时值得复用，谁负责后续变化；
8. **读者工具**：选题卡、轻量PRD、三重验收表、退回单和维护责任表。

## 五、图文与技术手册要求

样章G3视觉策划至少判断以下材料是否必要：

- 一张“教学问题—需求—原型—失败—验收—发布”的过程图；
- 一组真实页面或装置的前后版本对照；
- 一张物理对象、变量、数据来源和页面元素的映射表；
- 一处失败的局部截图、错误说明、退回理由和修正后证据；
- 可直接复用的选题卡或三重验收表。

真实截图只证明对应版本存在和呈现状态。运行、物理正确、课堂使用和学习价值分别需要独立证据。图件涉及人物、学生作品或第三方素材时先脱敏和核授权。

## 六、进入B3前的补证任务

1. 在A03中选定一个具体教学页面或资源对象，避免把整个网站写成一个案例；
2. 为该对象定位2—3类真实失败及其版本或记录锚点；
3. 回查一份课堂任务或使用说明，确认页面要支持的学习动作；
4. 找到一位合著作者进行物理与教学独立审读；
5. 找到2—3位目标读者试读任务书或工具表，记录他们看不懂、做不到或会误用的地方；
6. 确认拟用图件、页面截图和代码片段的作者与出版边界。

## 七、样章验收标准

| 维度 | 通过条件 |
| --- | --- |
| 真实对象 | 样章围绕一个明确页面或资源，不用整个平台代替具体问题 |
| 新增认识 | 至少形成一项超出M4总结的新关系、边界或方法，不能只扩写旧文 |
| 物理与教学 | 对象、变量、数据身份、任务和系统边界可核对 |
| 操作性 | 一线教师能按步骤完成选题、需求、验收和退回中的至少一条完整路径 |
| 失败与排错 | 至少两类真实失败进入解释链，写明发现、判断、修改和复验 |
| 图文 | 每幅图回答明确问题，来源与能证明／不能证明的内容清楚 |
| 证据 | 课堂、使用、访问、效果、推广等主张均不超过现有证据 |
| 作者声音 | 个人实践、共同方法和外部观点的声音可区分 |
| 首读 | 目标读者能复述本章帮助他解决什么，并指出可立即使用的工具 |

任一硬门未通过，样章留在B3补证，不批量启动B4。

| 备选 | 优点 | 当前阻塞 |
