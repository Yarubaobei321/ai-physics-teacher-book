## 二、八张材料卡

### O-01　Claude Code完整指南：从一次要求到可维护产品

**来源锚点**：`Claude-Code-Complete-Guide-zh-v260411.md` 611—824、1341—1521、2350—2383、2620—2693、2719—2817、3027—3061行。  
**证据等级**：B结构参考。

材料把第一个项目拆成描述需求、审查方案、执行、验证和迭代，并进一步提出：项目规则文件只记录AI猜不到的命令、约束、陷阱和完成定义；复杂产品先形成规格，再拆成最小可验证步骤；重要规则写入项目，不能只留在会被压缩的对话中。对教师最有价值的转译，是把注意力从“代码怎样写”移到“教学问题是什么、首版做到哪里、什么证据才算做对”。它能支撑项目式Agent协作和教师职责迁移，不能证明不懂代码即可忽略实现、也不能支撑任何培训效果。

### O-02　Claude Code源码分析：Harness不只是提示词

**来源锚点**：`Claude-Code-Source-Analysis-zh-v260411.md` 120—261、732—881、1976—1986、2328—2369、2381—2499行。  
**证据等级**：B结构参考；部分内容来自特定时点源码与内部实验描述。

材料把Agent行动写成Think—Act—Observe—Repeat循环，并指出所有行动经工具发生，工具层因此能够承载权限、日志和安全审查。它还区分“执行者自检”与“独立验证”：完成声明要由没参与实现的检查者对照可观察结果作出。对本书最有用的不是工具数量，而是六层Harness视角——提示、工具、权限、记忆、上下文和协作共同决定结果。教师转译后，应把物理模型、数据身份、学生任务和发布边界放进系统，而不是寄希望于一句更长的提示词。

### O-03　Codex完整指南：给Agent一张项目地图

**来源锚点**：`Codex-Complete-Guide-zh-v2.0.1.md` 374—509、690—758、951—1049、1635—1985、2217—2349行。  
**证据等级**：B结构参考。

材料提供了Prompt—Plan—Execute—Verify的初始闭环，并把AGENTS.md解释为项目契约：写清构建、测试、架构决策、特殊环境、禁止事项和“什么叫完成”，AI自己能够从文件推断出的内容则不重复塞入。Skills、连接器、自动化和长期目标分别处理方法复用、外部行动、重复调度和状态延续。对教师的稳定价值是：受控工作区、明确完成定义、最小权限、人工升级和“先手动跑稳再自动化”。当前App、CLI、审批和模型细节变化快，只适合配套数字资源。

### O-04　DeepSeek Harness橙皮书：从“相信总结”到“核对轨迹”

**来源锚点**：`DeepSeek-Harness-Orange-Book-zh-v260814.md` 697—887、2169—2308、2334—2443行。  
**证据等级**：B结构参考；书中实跑、源码和作者推断需保持原标记。

这册最重要的价值来自事故，而非功能。日志把模型看到什么、工具做过什么、权限与沙盒是什么状态分开记录；四篇复盘又证明“测试全绿”可能验的是旧代码、错误快照或替身服务器。材料提出一个对教师极有用的问题：验的是不是学生实际会打开的那个页面、那组原始数据和那台真实装置？它还把事故经验固化为机器门禁，并要求不确定的副作用操作先查外部状态再决定是否重试。可支撑运行门和证据留痕，不能把其具体实现当作所有Agent共有能力。

### O-05　Hermes Agent橙皮书2.0：会积累，也要会克制

**来源锚点**：`Hermes-Agent橙皮书2.0-v260607.md` 315—439、443—658、670—786、918—1040、1125—1211、2151—2418行。  
**证据等级**：B结构参考。

材料把长期Agent拆成“造、修、续”：从经历中沉淀方法、定期整理方法库、在明确目标下续跑。真正有价值的是刹车：不自动删除，只归档；修改前快照；支持dry-run；用来源标记限制AI只能整理自己生成的内容；明确禁止把临时环境故障学成永久规则。记忆还被区分为会话、稳定事实和程序性方法，第三方Skill则同时带来生态红利和供应链风险。教师转译后，应把失败先分成普遍规律与临时状态，再决定是否写入项目规则或Skill。

### O-06　Loop Engineering橙皮书：把教师放在循环上方

**来源锚点**：`Loop-Engineering橙皮书-v260615.md` 92—171、173—266、270—472、559—646、648—721、808—823行。  
**证据等级**：B结构参考。

材料区分Prompt、Context、Harness与Loop四个层次，并把一个持续循环拆成发现、交付、验证、持久化和调度。其核心警告是：无人看守的循环也会无人看守地犯错；生成速度越快，越可能累积验证债、理解腐烂、判断外包和成本失控。对本书的关键转译是：教师可把实现交给Agent，却要亲自设计能说“不”的检查、硬预算、最大重试、人工停点和长期维护责任。它能解释为什么四道验收门必须进入循环，不能证明自动化天然提升教学质量。

### O-07　Obsidian + AI橙皮书：让材料成为可追溯的项目知识

**来源锚点**：`Obsidian-AI-v1.0.0.md` 637—767、835—967、1152—1293、1354—1403行。  
**证据等级**：B结构参考。

材料从文件夹、项目规则、路由文件和索引出发，提出“编译器而非一次性检索器”的知识观：原始材料只增不改，AI把它们编译为带来源的结构化知识，再生成具体产物；Schema约束命名、字段、来源、链接和更新规则。对本书的价值，是为教师开发建立`原件—事实卡/模型卡—网页/课程产物`三层，而不是每次重新把一堆PDF、图片和旧对话塞给Agent。书中关于容量和规模的阈值高度依赖版本，不进入稳定主张。

### O-08　OpenClaw完整指南：常驻Agent扩大了权限，也扩大了风险

**来源锚点**：`OpenClaw-Complete-Guide-zh-v1.4.0.md` 195—388、390—463、1784—1838、2135—2231、2848—2947、3078—3152行。  
**证据等级**：B结构参考；安全事件数字和平台现状需外部复核。

材料展示常驻Agent怎样把身份、工具、用户记忆、会话、日志和定时任务写入工作区，同时按私聊、群组和工具权限隔离上下文。更重要的是它把第三方Skill视为受信代码：安装意味着把Agent已有权限交给外来内容，描述文件和安全扫描都不能替代来源审查。对教师开发的稳定转译是：涉及学生数据、账号、邮箱、网盘和公开网站时，必须收窄可读范围、分离私密与公开材料、检查凭证与外发路径，并给自动任务设置预算和停用方法。

## 三、八册材料相互印证出的十条稳定认识

| 稳定认识 | 对教师开发的直接含义 | 主要互证来源 |
| --- | --- | --- |
| 1. Prompt、Context、Harness、Loop是层级，不是互相替代的流行词 | 提示词只解决一次表达；项目还要有材料选择、工具、权限、状态和停止条件 | Loop、Claude源码、Codex |
| 2. 第一个项目要小，但要走完整闭环 | 首次练习选一个小时级小网页，仍要包含任务、实现、验证和保存版本 | Claude完整、Codex |
| 3. 项目规则是协作契约，不是百科全书 | 只写AI猜不到且必须遵守的对象、禁区、命令、陷阱和完成定义 | Claude完整、Codex、Obsidian |
| 4. 上下文要精选，材料不是越多越好 | 用路由、索引和来源卡按需读取；过时材料和长文不默认灌入 | Claude完整、Hermes、Obsidian |
| 5. 工具和权限决定Agent真正能做什么 | 能读写、联网、部署或访问账号时，风险已经超出“回答可能出错” | Claude源码、Codex、OpenClaw、Hermes |
| 6. 生成者不能独占“完成”的判定权 | Agent自检只能是证据之一；物理教师和独立检查者必须能退回 | Loop、Claude源码、DeepSeek |
| 7. 测试数字不等于真实交付可用 | 必须验证确切页面、确切版本、真实流程和外部可观察行为 | DeepSeek、Claude完整、数智育才网站 |
| 8. 长期记忆只应保存慢变量和可迁移方法 | 当前文件位置、临时故障和版本功能要现场重查；偏好、边界和成熟流程才进入规则/Skill | Claude源码、Hermes、OpenClaw |
| 9. 自动化必须配状态、预算、重试上限和人工停点 | 先手动跑稳；无人值守任务到顶即停，失败不能无限循环 | Loop、Codex、Hermes、OpenClaw |
| 10. 失败要进入制度，不只进入复盘文章 | 可机械检查的写成脚本或Hook；需专业判断的保留教师签字 | DeepSeek、Hermes、Claude完整 |

## 四、对本书最重要的教师转译

八册书共同讨论的是通用Agent系统。本书真正的新价值，不是复述“Agent会调用工具”，而是增加一层物理教育责任链：

```text
通用Agent系统
任务 + 上下文 + 工具 + 权限 + 循环 + 状态 + 评判
                        ↓ 教师专业转译
物理教学项目
对象与模型 + 原始数据身份 + 学生动作 + 课堂约束 + 发布责任
                        ↓ 四道验收门
运行门 + 物理门 + 教学门 + 发布门
```

这条转译产生三个可以进入本书的原创候选：

1. **教师Agent项目的完成定义必须是四层完成，不是“页面做出来了”。**
2. **教师的专业判断要尽可能变成可核对的模型卡、样例、清单、日志和退回理由。**
3. **Skill不是把教师移出流程，而是把已经验证过的方法交给Agent重复执行，把教师时间留给不能外包的判断。**

## 五、动态内容隔离区

- 各产品当前模型、价格、免费额度、活跃度、下载量、技能数量和市场排名；

- “某格式已在所有Agent完全兼容”的绝对结论；
- 企业每周PR数量、代码生成比例、效率倍数等二手或时间敏感数据；
- 漏洞数量、恶意Skill比例和已经修复到哪个版本；
- 任何由外部图书案例推导出的教师培训效果或课堂学习效果。
