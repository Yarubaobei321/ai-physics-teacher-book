## 这条路线怎样改了

GLM原稿抓住了一种很真实的教师愿望。AI让许多过去要找团队才能完成的页面、数据工具和资源入口，第一次进入个人可尝试的范围。本轮继续让“造物与交付”承担主线，同时修正原稿的四个问题。

1. 开篇不再使用v₁。第1章先让四位作者的真实问题进入视野，读者当场判断自己最值得做的第一件东西。
2. “黄金标准”改成更朴素的完整证据链。王硕、丁龙和严力耕的实践凭自身物理与教学价值进入，不需要补做AI对照实验才能取得章位。
3. AI橙皮书和WorkBuddy方法分散到开工、项目管理、Skill、多Agent和自动化各章，不再只在一个长章中集中罗列。
4. 黄灿斌的造物线保留主轴，合著者分别承担实验标准、概念测量和项目组织中的关键章节，避免全书变成个人开发史。

## 读者承诺

这本书带一线高中物理教师从一个真实教学问题出发，选出值得做的第一件东西，把它做小、做实，随后逐步加入物理验收、课堂使用、版本管理、Skill、多Agent、自动化、发布和维护。读者最终获得一套能完成项目的操作方法，也知道每一次升格会增加什么责任。

读完后，读者应当能够交付一个自己的最小项目包。

```text
问题起点卡
+ 项目Brief
+ 受控工作区
+ 物理模型卡
+ 一个最小产物
+ 验收样例
+ 版本与退回记录
+ 发布或停止决定
```

四位教师的真实问题进入候选清单

## 第一篇　先看清要造什么

### 第1章　想做的东西很多，先选哪一个

**开篇安排**

第1章先摆出四项已经存在于材料中的问题。电磁感应现象怎样走向定量探究，学生怎样理解超重和失重，支持力变化怎样被真实测量，分散的物理资源怎样围绕课堂任务重新组织。四项问题来自不同作者，也对应实验、概念、教具和数字资源四种造物方向。

读者随后写下自己手里最想解决的3个问题，比较教学价值、现有材料、AI新增能力、低技术替代、错误代价和维护成本，最后只选一个首项目。

**读者新增认识**

AI降低了一部分实现成本。问题是否值得做，仍取决于课堂需要、可验收程度和后续责任。第一个项目应当小到能够完成，也要完整到能够留下证据。

**展开内容**

1. 四位作者各自面对的真实对象和教学困难；
2. 页面、数据工具、教具和网站的成本差异；
3. AI实际能增加生成、分析、修改或编排中的哪一种能力；
4. 低技术方案何时已经足够；
5. 读者选出一项本书陪跑项目。

**读者工具**

- 我的三个问题清单；
- AI进入判断卡；
- 首项目选择器；
- 当前不做清单。

**材料与边界**

四位作者的片段按已核材料表述，不增加心理、对白和多年经历。教材开发地图只帮助发现候选对象，不证明项目已经完成。

### 第2章　一条曲线怎样才有资格支持规律

**本章作用**

读者动手前先见一条完整实验链。王硕的法拉第定量探究把装置、变量、测量、图表和论证放在一起。W03单摆数据短审计提醒读者，空白、异常和图表设置会改变结论强度。

**读者新增认识**

AI可以生成方案、图表和解释，教师仍要追问测到了什么、怎样处理、依据哪些条件作出结论。完整链给后面的造物章提供验收标准。

**读者工具**

- 数据来路表；
- 变量与测量身份表；
- 预测、测量与偏差检查；
- 图表口径检查。

**材料与边界**

W01和W03不补写AI参与，不安排对照实验作为入书条件。若以后真实开展AI方案审查，可作为新增材料进入章末。

### 第3章　页面会动，物理是否跟得上

**本章作用**

读者在开工前学会检查数字成品。H04选一项动量模型，依次确认系统边界、正方向、解析关系、特殊值、页面输出和显示范围。

**读者新增认识**

页面内部一致与物理正确需要两条检查路径。生成者自检、自动测试和漂亮误差数字都可以留下证据，独立解析真值仍需另建。

**读者工具**

- 一页物理模型卡；
- 外部真值双回路；
- 三组普通、边界和极端验收样例；
- 对象身份五查。

**材料与边界**

H04只选一项能够形成独立检查的模型。剩余模型、浏览器显示和对象识别短例按实际证据上限进入。

## 第二篇　把第一个东西做出来

### 第4章　把想法写成AI能做、教师能验的任务

**读者新增认识**

任务说明承担协作契约。它要限定工作区，写清目标、输入、动作、约束、输出、验收和当前不做。读者给AI的材料也需要说明来源和可修改范围。

**展开内容**

1. 从第1章选定的问题提取对象、学生动作和教师判断；
2. 创建独立工作区，写出可读、可写、禁止和需批准；
3. 列出原始材料、参考材料和预期产物；
4. 把功能、物理、教学和发布写进完成定义；
5. 决定第一轮只交付什么。

**读者工具**

- 教师项目Brief；
- 工作区边界卡；
- 材料清单和来源栏；
- 四层完成定义。

**方法来源**

Claude Code与Codex橙皮书提供项目地图、规格、最小权限和完成定义。WorkBuddy第3、4章提供工作区与第一项任务的易懂结构。H07和H03提供教师自己的任务工装和项目事实。样章阶段可用本机 WorkBuddy 实际建立同题工作区，保存任务页、权限边界、运行过程和脱敏截图。

### 第5章　第一个页面只做一件事

**本章定位**

这是全书最直接的入门操作章。读者不需要先建设网站，只完成一个能够输入、计算、显示并接受三组物理样例检查的最小页面。具体工具界面进入数字资源，纸书保留跨工具稳定的操作次序。

**展开内容**

1. 选一个对象和一个学生动作；
2. 用模型卡写清变量、单位、条件和预期关系；
3. 规定输入、输出和页面不替学生完成的判断；
4. 先准备普通值、边界值和极端值；
5. 让AI生成首版，记录产物位置和版本；
6. 逐项验收，写下采用或退回；
7. 保存能够重新开始的最小项目包。

**读者工具**

- 最小页面任务单；
- 字段与物理过程对应表；
- 三组验收样例；
- 首版验收记录。

**材料与边界**

H03和H04提供作者开发链中的稳定方法。作者已授权把本章候选任务交给本机 WorkBuddy 受控复现；第一次实测要完整保存任务、首版、失败、退回、复验和截图。书稿不承诺某个模型一次生成成功，也不把能打开的页面写成课堂可用。

### 第6章　一堂课怎样长出在线实验室

**读者新增认识**

一个页面的价值来自它与课堂任务的关系。机械能守恒公开课把自由落体、圆柱摆和气垫导轨三种方案放入共同任务，网页承担录入、计算和投屏。课堂中的使用与不足随后推动页面继续修改或升格。

**展开内容**

1. 公开课为什么需要三种实验路径；
2. 页面字段怎样对应三种测量过程；
3. v₁自动排序在这里出现，说明功能会改变数据身份；
4. 教师怎样退回、删减和复验；
5. 6个小组实际怎样使用网页；
6. 跨方案比较没有发生，下一版任务怎样调整；
7. 单页何时有理由长成专题实验室。

**读者工具**

- 页面字段与物理过程对应表；
- 退回单和版本差异表；
- 课堂使用观察表；
- 单页到专题升格初判。

**材料与边界**

A02、H02和W02承担事实。v₁在造物过程中出现，不承担开篇。课堂事实、作者贡献和未发生的比较按原件核对，不写学习效果。

### 第7章　概念课、传感器和显示怎样接成一条链

**读者新增认识**

造教具时，教师要同时回答教什么、测什么、怎样处理、显示什么、学生仍要判断什么。概念任务和测量链缺一项，器材都会偏离课堂问题。

**展开内容**

1. 丁龙超重失重教学设计中的现象、预测、受力、加速度和示数；
2. 严力耕超失重仪中的应变梁、HX711、ESP32、校准和显示；
3. H08、H09提供了哪些可复用技术模块；
4. 页面控制与真实采集怎样分开验收；
5. 读者为自己的传感器项目画出完整链。

**读者工具**

- 对象、物理量、信号、算法、显示五身份表；
- 概念任务链；
- 校准与接口检查；
- 学生必须保留的判断动作清单。

**材料与边界**

DL-01和YL-02分别保留作者声音。完整采集、曲线、滤波源码和课堂事实按当前状态写，不把数字控制扩写为AI实质增量。

### 第8章　页面多了以后，什么时候做成网站

**读者新增认识**

页面数量增加不会自动形成系统。升格需要共同任务、可复用结构、稳定入口、明确维护者和停止条件。系统越大，权限、设备、测试、发布与接手责任越多。

**展开内容**

1. H03从分散页面到资源网站的真实需求；
2. 网站目录、统一入口、版本和发布记录怎样形成；
3. H06浏览器数据通道怎样连接真实设备；
4. H05与H10展示自研平台的能力上限和维护代价；
5. 读者比较单页、专题、网站和平台四种交付形态；
6. 决定继续扩建或及时停止。

**读者工具**

- 系统升格五问；
- 网站发布前检查；
- 设备与页面责任表；
- 是否值得自研判断卡。

**材料与边界**

网站和源码可以证明项目存在与部分运行事实。页面数量、自动测试和公开访问不能代替物理终审、课堂采用或长期效果。

## 第三篇　把一次做法变成工作系统

### 第9章　材料、规则、版本和Skill怎样留下来

**读者新增认识**

项目经验要分层保存。原件保持原貌，事实卡和模型卡写清来源，具体页面、课件和模板保留版本。项目规则只记录AI无法自行推断又必须遵守的约束。Skill只保存已经重复成功并能测试的方法。

**展开内容**

1. 建立原件、知识和产物三层资料结构；
2. 用资料入口和任务路由控制每次读取范围；
3. 区分会话事实、稳定规则和程序性方法；
4. 写一份短项目规则，包含禁区、完成定义和常见陷阱；
5. 判断一张检查表是否成熟到可以变成Skill；
6. 给Skill写触发、步骤、输出、边界和测试；
7. 用诱饵场景和真实任务做压力检查。

**读者工具**

- 原件、知识、产物三层图；
- 教师版项目规则模板；
- 该记与不该记判断表；
- Skill成熟度和五要素卡。

**方法来源与边界**

Obsidian、Hermes、Codex和Claude材料解释资料、记忆、规则与Skill。WorkBuddy第5、22章提供从SOP或知识到Skill的操作结构。H03和C05承担第一方项目材料。外部流程的固定阶段和数量只作参考。

### 第10章　什么时候需要多个Agent，什么时候可以自动运行

**读者新增认识**

单Agent、多Agent、自动化和网站解决不同规模的问题。多人分工需要独立子任务、不同资料或工具、清楚的交接格式和总负责人。自动运行要求手动流程已经稳定，并且具备状态、重复执行处理、重试、告警、降级、预算和停用。

**展开内容**

1. 用一张选择矩阵判断继续单Agent还是拆分；
2. 为物理建模、课堂设计、实现和独立复核写角色契约；
3. 规定共享产物和串并行汇合点；
4. 设置必须由教师确认的节点；
5. 判断任务是否已经稳定到可以定时运行；
6. 设计状态、输入就绪、重复执行处理和失败出口；
7. 写重试、告警、降级、日志、预算和停用办法；
8. 演练数据源缺失、权限失效和重复触发。

**读者工具**

- 单Agent、多Agent、自动化与网站选择矩阵；
- 角色契约和共享产物表；
- 自动化上线清单；
- 状态、重试、告警和降级模板。

**方法来源与边界**

Loop、Claude源码、OpenClaw与Hermes提供分工、权限和停止原则。WorkBuddy第24、25章提供角色契约、共享产物、状态、重复执行、断点和降级结构。物理同题跨工具实测尚未执行，作者已授权在后续阶段补测；结论只对应当次任务和环境，不写脱离条件的平台排名。

## 第四篇　交付给学生和后来的人

### 第11章　学生和AI共同完成的作品怎样评

**读者新增认识**

教师评价学生AI作品时，要先分开过程与成品，再核对任务要求、学生表达、AI实现和页面表现。退回意见应落到可复核现象，不能从产品错误直接推断学生能力。

**展开内容**

1. 同一特优生测试项目的任务与组织背景；
2. 从25份已分析网页选择2到4个脱敏代表案例；
3. 并排呈现任务、过程、成品、浏览器表现和数值复核；
4. 角色证据怎样支持或限制归因；
5. 教师怎样给出下一轮可执行的修改要求。

**读者工具**

- 过程与成品对照表；
- 角色归属检查；
- 浏览器与数值复核；
- 退回理由卡。

**材料与边界**

只使用两篇论文已分析的25份物理模拟网页。严力耕负责项目组织背景，黄灿斌负责论文分析。当前材料不支持学生真实思维、诊断准确、干预和复测效果结论。

### 第12章　做成以后，证据、发布和接手怎样安排

**读者新增认识**

项目存在、技术运行、物理正确、课堂使用、学习过程和学习效果需要不同证据。交付还要包含来源、授权、版本、链接、维护者、停用方法和下一位接手者能看懂的入口。

**展开内容**

1. H11静电场描绘仪的实物、竞赛、技术交底、专利和课堂材料怎样分层；
2. 前11章的项目怎样分别通过运行、物理、教学和发布检查；
3. 主张怎样停在证据上限；
4. 反馈怎样进入澄清、取舍、修改和复验；
5. 交接包需要哪些文件、图件、授权和状态说明；
6. 什么情况下继续、暂停、撤回或保留问题。

**读者工具**

- 四道验收门记录；

- 发布和授权检查；
- 接手包清单；

**材料与边界**

本章不新增效果主张。H11法律状态出版前复核，H03维护记录只支持已发生的版本事实。跨教师采用、长期维护和普遍复做继续标为待补证。

## 阅读节奏要求

工具多不等于每章都写成表格堆叠。每章先回答一个读者真的会遇到的问题，再让一个完整案例把问题撑住。概念解释应帮助读者处理变化，步骤写到能看到结果，章末工具负责复用。读者每读完一章，都在自己的最小项目包中新增一项产物。

## 这条路线的主要风险

1. 工具信息密度高，写作时容易变成培训讲义。真实项目、失败和作者判断必须承担正文主体。
2. 第5章需要选择一个足够简单又物理完整的首项目。B3前应由作者确认对象，不能临时虚构课堂案例。
3. 第9、10章大量借用外部方法。正文要写清转译与边界，产品操作进入数字资源。
4. 造物线容易让黄灿斌成为唯一叙述者。第2、7、11章需要保留王硕、丁龙和严力耕的完整声音，跨章引用不改变成果归属。

## 样章建议

首个样章选择第5章。它直接检验这条路线能否真正指导一位教师完成最小项目，同时保持物理严谨和自然阅读。

第二个样章选择第7章。它检验合著双声音、概念任务、真实测量和工具书表达能否接在同一章里。
