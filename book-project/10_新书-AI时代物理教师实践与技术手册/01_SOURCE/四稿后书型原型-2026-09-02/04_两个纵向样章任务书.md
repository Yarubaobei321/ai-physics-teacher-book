# 样章A　一节机械能实验课，怎样长成一个可回退的教学网站

## 1. 章节身份

- **主要文体**：开发实录＋工具手册。
- **主要回答**：一位不会专业前端编程的高中物理教师，怎样把一节实验课中的真实数据处理问题交给AI Coding，得到一个可运行、物理可信、课堂可用、可以撤回的页面，并判断何时值得把单页扩展成网站。
- **读者完成任务**：复做一个冻结的气垫导轨数据页；重现旧版故障；修改规则；用手算样例验收；决定保留、退回或发布。
- **主案例边界**：全章只把“气垫导轨页的`v₁/v₂`保序问题”写透。三方案在线实验室和整个网站承担来路与延伸，不平铺网站全部功能。

## 3. 正文展开链

### 第一步　只选一个课堂卡点

说明三种机械能实验为何需要不同页面，再把样章收窄到气垫导轨页：学生输入两次速度后，页面怎样保留真实测量次序并计算动能变化。

本步必须交代：

- 教材实验任务和本课的三种装置；
- 原来用Excel或单台电脑录入时卡在哪里；
- 页面替学生承担哪些重复计算；
- 数据处理后释放出的课堂时间准备用于什么物理活动。

### 第二步　把装置翻译成字段和关系

用一张“实物—测量量—页面字段—公式—单位”图说明`m、M、h、v₁、v₂`分别来自哪里。每个输入项都要绑定真实对象，避免读者只看到表单。

交付：一份可复制的“物理模型卡”，包含研究对象、系统边界、理想化条件、直接量、派生量、公式、单位和故意保留的异常值。

### 第三步　第一次交给AI Coding

用真实界面截图呈现：

- 在什么工具中打开了哪个项目文件夹；
- 左侧或工作区能看到哪些文件；
- 教师第一轮原话；
- AI计划修改哪些文件；
- 教师怎样确认修改范围。

正文保留足以复做的真实提示词，不把提示词改写成后来总结的“完美版本”。整理后的推荐提示词另放边栏，与历史原话分开。

### 第四步　读懂最小项目包

只解释本案例真正涉及的页面、组件、数据、图片和测试文件。用文件树和箭头说明“改一个字段会影响哪里”。读者无需学习完整Astro框架，但要知道哪里是内容、哪里是计算、哪里是显示、哪里负责测试。

### 第五步　让旧版真实失败一次

冻结并提供修改前版本。读者按原操作逐字符输入，让页面重现“输入过程中自动比较并交换`v₁/v₂`”的故障。

本步同时呈现：

- 实际输入顺序；
- 页面发生的变化；
- 对应源码位置；
- AI如何解释触发原因；
- 这次故障为什么不仅是界面不顺手，还改变了原始实验记录的身份。

### 第六步　比较两个修法

把AI提出的“延后排序”与教师最终选择的“取消排序、保留原序”并排比较。让读者看到一次专业裁决怎样发生：AI能够定位代码，物理教师决定软件是否有权改写测量记录。

交付：退回单，至少写清现象、复现步骤、被破坏的规则、接受条件和复验样例。

### 第七步　看文件和版本究竟改了什么

展示旧版、差异和新版的关键片段，同时给出确切commit和冻结包。版本记录必须回答：

- 哪个文件改了；
- 为什么改；
- 哪些表述随代码一起改；
- 哪些问题本轮故意没有解决；
- 怎样回到上一版。

### 第八步　完成外部物理验真

至少用三组不依赖页面内部逻辑的手算样例：

1. 普通值；
2. 零变化或临界值；
3. `v₁>v₂`的反预期值。

逐项比对输入、动能变化、势能变化、符号和误差表达。测试通过只说明指定样例与程序行为一致，物理教师终审另列结论。

### 第九步　把页面放回课堂

按上课时间顺序写：谁打开、谁录入、谁检查、谁投屏、另一组怎样提问、断网或设备不足时怎样退回纸笔或本地文件。教师的个人反思围绕真实取舍展开，例如哪些自动功能最后删除、哪些提示必须留在页面上。

### 第十步　判断单页何时值得长成网站

只有当稳定入口、移动端访问、跨课复用、统一导航和持续维护产生新增教学价值时，才升格为网站。页面数量、代码量和栏目齐全不作为升格理由。

### 第十一步　发布、维护与回滚

纸书说明从构建、测试、生成release到切换软链和撤回的完整责任链。服务器地址、密钥和易变命令不进入公开正文；读者练习包采用本地或安全演示部署。

### 第十二步　读者迁移

读者选择自己的一项教学问题，依次填写：问题卡、模型卡、最小任务书、原始提示词、验收样例、退回单、课堂适配表、发布或停止单。

## 4. 必须出现的图与工具

## 5. 当前缺口

- 原始会话尚需整理为可出版的“教师原话—AI回应—教师判决—文件变化”短链。
- 缺真实AI Coding界面、文件差异和页面预览同屏的操作截图。
- 缺面向新读者的环境准备、首次运行说明和无敏感信息练习包。
- 课堂照片、装置图和学生操作材料仍需核对摄影、肖像与出版授权。
- 出版前须复核线上版本、二维码、维护人和撤回入口。
- 没有独立学习效果证据；正文只能写已核课堂动作和设计意图。

# 样章B　把等势线从书上的图变成可测量、可质疑的对象

## 1. 章节身份

- **主要文体**：装置制作实录＋实验探究案例。
- **主要回答**：高中教材中的等势线怎样从一张理想图，变成教师和学生能够亲自改变边界、逐点测量、与预测比较并解释偏差的对象。
- **读者完成任务**：搭建一个简化装置，完成一组电极的逐点测量，生成等势线，将实测与预测放在同一坐标中比较，并说清偏差来自哪里。
- **技术选择**：这是一个可以不使用AI的教学可视化案例。装置、测量和数值预测已经足以形成完整价值链；AI帮助配准测点或生成交互页面只属于可选的后续研发，不是样章入选条件。

## 2. 当前材料已经支持什么

现有材料已经支持：

- 2019人教版必修第三册《电势差》相关的教学起点；
- 用浅水稳恒电流场模拟静电场的原理与边界；
- 点、线、圆三类不锈钢电极和五组典型边界；
- 透明亚克力水槽、电源、电压表、探针、镜面和摄像位置；
- “从测量生成图”与“沿预测图验证”两种操作路径；
- 水体波动、电源波动和有限边界不一致等失败认识；
- 整机、五组电极、测点标记和立体结构图等真实图件。

集中入口见[H11静电场描绘仪首轮深挖](../价值增量挖掘/H11-静电场描绘仪首轮深挖-2026-08-30.md)。

## 3. 正文展开链

### 第一步　从教材中的理想图进入

先还原学生真正要理解的关系：电势、等势线、电场线和边界条件。再指出当前缺口：学生常常只会识别已经画好的图，较少经历“逐点取证—形成图—检查图”的过程。

### 第二步　为什么选模拟法

通过方程、物理量对应和边界条件说明：两种场在什么条件下可以建立空间分布的对应。有限水槽、回流电极、水深和电导率均进入模型卡；“形状相似”不自动等于真实静电场被直接测量。

### 第三步　认识真实整机

用一张剖解图标注：水槽、电极、探针、参考端、电压表、电源、镜面、摄像头和观察者位置。每个部件同时说明物理职责、制作规格、可替代材料和常见失效。

### 第四步　给出真正可复做的制作包

出版级制作包至少包括：

- 带版本号的BOM；
- 水槽和电极尺寸图；
- 加工文件与装配顺序；
- 接线图和参考端说明；
- 供电、安全、防水和清洁要求；
- 一组低成本替代方案；
- 制作后首次检查清单。

### 第五步　五组电极各回答一个比较问题

五种电极不作为成果陈列。每组须绑定一个学生可回答的问题，例如：平行板间为何近似等间距；点电极附近为什么更密；同种与异种电荷的对称性和零场区有什么不同。

### 第六步　完成第一次逐点测量

写清接线、水深、参考端、目标电势、取点间隔、稳定等候、重复读数和原始记录格式。纸书展示一组完整原始点，不能只放平滑后的漂亮曲线。

### 第七步　比较两种知识路径

1. **测量到图**：先取点，再连成等势线，最后依据正交关系讨论电场线。
2. **预测图到测量**：先由模型给出预测，再让探针沿预测线移动，寻找一致区和偏差区。

两种路径各有不同的认知任务，不能混成“验证正确答案”。

### 第八步　把COMSOL写成可复做工具

若核到源模型，正文需要展示真实界面中的几何、电极边界电势、介质、网格和等势线导出，而非只展示最终彩图。每个参数与实物逐项对应，模型文件进入配套下载。

### 第九步　对预测和实测共同验真

至少检查：拉普拉斯方程适用区、有限边界、参考电势、单位、对称性、特殊区域和故意错误边界。预测图和实测点放进同一坐标，原始点与插值图分层显示。

### 第十步　把装置放回三种课堂任务

- 教师演示：学生先预测，再观察几个关键位置。
- 分组探究：学生自己确定目标电势、取点并比较不同电极。
- 习题实证：以平行板电容器动态问题为对象，测量某点电势随极板位置或端电压变化。

现有材料只能支持这些教学设计。没有真实课堂记录前，不写学生反应和学习效果。

### 第十一步　写清失败、版本与发布身份

分别处理供电、水体、电极、探针、模型边界和课堂组织失败，并补齐三类可执行记录：

1. **版本记录**：每个真实版本只写原件能确认的材料、结构、测量现象、修改理由和保留/放弃决定；旧记录不足时登记缺口，不反推版本史。
2. **退回与停止**：当读数漂移超过预设门、实物边界与模型不对应、原始点无法复核，或安全条件不满足时，停止课堂发布，退回最近一个已验收的装配与测量方案；阈值须由补入的原始数据确定。
3. **发布身份**：分别标记“装置存在”“可完成测量”“已通过独立物理审查”“已进入课堂”“具有学习效果证据”，只发布已经过门的身份。竞赛材料、技术披露和专利状态不能代替课堂证据。

作者个人反思至少回答：当时为什么选择水槽与镜面摄像；哪些失败真正改变了结构或课堂任务；今天重做时会保留、删去或停止什么；哪些判断仍没有证据。没有当时记录支撑的感受不补写成历史事实。

### 第十二步　读者迁移

读者把本案例方法迁移到另一项“不可直接测量但可建立模拟或代理测量”的物理问题，并填写对象对应、边界条件、测量身份、误差来源和停止条件。

### 研发侧栏　以后什么情况下才另立数字项目

本样章的复做主线到“装置—测量—COMSOL预测—偏差解释”已经闭合，当前不开发、也不验收额外的AI功能。只有在真实课堂进一步提出“批量配准测点、分层显示原始点与预测、跨组比较”等明确需求，并且现有工具确实无法低成本完成时，才另立数字研发任务书。届时可选择常规数值软件或AI Coding，并按数字项目的证据门单独验收；这项未来研发不回写成静电场装置的既有事实，也不占用本章主线篇幅。

## 4. 必须出现的图与工具

| 图或工具 | 解决的读者问题 |
| --- | --- |
| 教材理想图—实物边界—实测点三联图 | 三种图各自是什么证据 |
| 整机爆炸或剖解图 | 每个部件为什么存在 |
| BOM、尺寸图与接线图 | 怎样真正复做 |
| 五组电极问题卡 | 每组电极要比较什么 |
| 逐点测量连拍与原始记录表 | 等势线怎样从数据生成 |
| COMSOL真实界面与参数—实物对应表 | 预测图从哪里来 |
| 实测—预测—偏差叠加图 | 哪里一致、哪里不同、能说到什么程度 |
| 故意错误边界对照 | 验收方法能否发现漂亮但错误的图 |
| 三种课堂任务时序 | 演示、探究和习题实证怎样分开 |

## 5. 当前缺口

- COMSOL源文件与五组实物边界、参数尚未逐一对应。
- 缺一组可引用的原始测点、重复读数和环境条件。
- 缺出版级BOM、加工尺寸、装配版本和安全说明。
- 五组电极是否属于同一最终版本待作者确认。
- 缺真实高中课堂实施、学生操作和学习结果证据。
- 图件作者、摄影者、共同完成者和出版授权待核。
- 专利申请的最新法律状态须在出版前另行核查。

说明：没有AI对话、AI Coding界面或提示词不属于本案例的材料缺口。

## 6. 样章最低验收标准

- [ ] 一份带版本号的完整BOM、尺寸图、接线图和安全说明。
- [ ] 五组电极与最终水槽版本关系已经确认。
- [ ] 至少一组原始测点、重复读数与环境条件。
- [ ] COMSOL源文件、几何和边界参数与该组实物对应。
- [ ] 预测图与测点在同一坐标中比较，原始点未被平滑图替代。
- [ ] 至少放入一个错误边界条件，验收方法能发现不一致。
- [ ] 至少一位独立物理教师审查模型、边界与测量方法。
- [ ] 2—3位目标教师依样章完成简化复做并记录卡点。
- [ ] 本样章按非AI资源完成，正文说清现有媒介为什么已经足够；未来若另立数字研发项目，单独走数字项目证据门，不并入本样章最低验收。
- [ ] 未有真实课堂记录前，不写学生理解或学习效果。
- [ ] 图件、共同完成者和最新权利状态完成出版核验。

## 两个样章共同要检验什么

| 压力测试 | 网站样章 | 静电场样章 |
| --- | --- | --- |
| 读者能否复做 | 复现旧版故障并跑通新版 | 搭建简化装置并完成一组测量 |
| 教师专业判断是否可见 | 数据身份、公式、课堂动作、发布责任 | 模拟条件、边界、测量身份、误差解释 |
| 技术选择是否有理由 | 有原始会话、提示词、文件和版本链，能说明AI改变了什么 | 不需要AI；装置、测量和数值预测已经服务核心教学问题 |
| 失败是否进入下一版 | 有真实排序故障和退回链 | 有波动与边界问题，尚缺版本化处理 |
| 证据上限是否清楚 | 可写开发与课堂动作，不写学习效果 | 可写装置与设计，不写课堂效果 |
| 方法能否迁移 | 一页到项目、网站和维护 | 模拟法、代理测量和预测—实测比较 |

## 建议顺序

1. 先完成网站样章，因为证据链已经足以支撑“真实问题—AI Coding—版本退回—物理验真—课堂使用—发布维护”。
2. 静电场样章同步补原始测点、COMSOL源文件和出版级制作包，按非AI的教学可视化厚案例推进。
3. AI只在真实问题确有需要时进入。静电场描绘仪和活版电路拼图无需为呼应书名而追加AI功能。
