# 四稿后书型原型阶段任务书

> 日期：2026-09-02  
> 状态：本轮原型交付完成，待作者裁决两个样章是否进入正文  
> 触发：作者确认以“资源选择与开发能力主线”作为全书首要读者变化，并明确案例不必都使用AI。

## 本轮要做的事

1. 把培训需要、教材任务、专家书章法和第一方项目交叉为8—12个全书关键问题。
2. 明确不同资源在书中承担的职责，防止再次形成“材料很多、读者所得不清”的货架式结构。
3. 建立一份可供作者判断的全书形态原型，说明这本书服务谁、承诺什么、四类阅读动作如何分工，以及纸书和配套网站怎样互补。
4. 为“数智育才网站”和“静电场描绘仪”各建立一份纵向样章任务书，用一数字、一实体两个案例压力测试新的章节基本单位。
5. 回写决策地图，清楚区分作者已经裁决、研究已回答、仍待裁决和仍待补证的事项。

## 本轮不做的事

- 不修改、拼接或覆盖现有四版书稿。
- 不写第五套全稿，不按章数或字数补齐正文。
- 不把书型原型称为正式目录，不冻结篇章数量和章名。
- 不把培训转录、项目导航、旧稿表述或外部参考书当作课堂效果证据。
- 不承诺两个样章已经具备复做条件；缺少尺寸、步骤、提示词、版本记录、课堂记录或原始数据时，明确登记缺口。
- 不因现有工作区较脏而整理、暂存或修改本轮白名单以外的文件。

## 完成标准

1. 每个关键问题都写明：教师为什么会遇到、读者最终能做什么、主要材料、当前证据边界和在书中的位置。
2. 资源职责矩阵同时写“可承担”和“不能承担”，至少覆盖教材与教参、步步高、专家书、AI工具书、继续教育课程、培训材料、第一方项目、SOLO理论和初步研发项目。
3. 全书形态原型的开篇定位、序言第一页与“读者所得”部分，能让目标读者回答：这本书解决什么问题、我能带走什么、它与编程教材和普通课例集有什么不同；实际清楚程度仍须目标读者试读。
4. 两个样章任务书至少覆盖：教材起点、旧方法限制、开发或制作、工具与界面、文件与版本、物理验真、课堂适配、退回条件、发布判断、个人反思、视觉证据和待补材料；不适用项写明原因。
5. 所有结论区分“作者已确认”“原件支持”“结构推断”“待核验”。
6. 新增文件链接可达，Markdown无明显格式错误；现有四稿保持未修改。

## 主要风险与控制

| 风险 | 控制方式 |
| --- | --- |
| 为呼应书名给每个案例硬加AI | 先判断教学问题需要什么媒介；静电场描绘仪、活版电路拼图等可视化教具可以完整保留为非AI案例 |
| 又回到列项目、排目录 | 先完成关键问题和读者所得，再谈候选内容块 |
| 用统一模板抹平四篇风格 | 只统一全书验收底线，四类阅读动作采用不同文体与节奏 |
| 把网站开发写成通用编程教程 | 每一步都回到具体高中物理教学问题、物理判断和课堂任务 |
| 把装置存在写成教学有效 | 分开登记装置存在、功能运行、课堂实施和学习成效四级证据 |
| 把所有细节推给配套网站 | 纸书必须保留可复做的关键闭环；网站只承载大体量、动态和可下载内容 |
| 覆盖用户既有改动 | 仅新增本日期目录，并只更新本轮新建的决策地图与审阅页 |

## 回滚方式

本轮成果全部集中在日期目录与对应审阅目录；现有书稿不动。若作者否定本轮书型，只需停用这些新增候选文件即可，不影响四版书稿和既有B0—B3材料。
