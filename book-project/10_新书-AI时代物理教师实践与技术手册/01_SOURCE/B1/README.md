### 历史暂定的关系组合

```text
现有真实教学问题／培训触发的新问题
→ 教师表达需求与物理约束
→ 限定最小系统，明确当前不做什么
→ AI或其他技术形成原型
→ 模型、真实对象／数据、教学任务三重验收
→ 进入多证据课堂或学生共创任务
→ 同时检查过程与成品
→ 记录失败、修正、发布与维护边界
```

这只是用于比较五个方向能否形成一条读者行动链，不是B2结构，也不等于章节顺序。
