## 目前最值得投入的三件事

### 1. 把物理审核变成公共底座

以已经运行的S1碰撞审计台和S3题目改编为两个不同样本，统一模型卡、失败样例、独立真值、退回理由和回归测试。价值不在增加页面数量，而在任何AI生成对象都能被教师拒绝、修正和复验。

### 2. 只选一个项目冲R2

三类候选各代表不同价值：

- 机械能三方案：真实实验和数据证据最强，但必须先解决原始数据与日期冲突；
- S1动量审计台：数字成品与物理审核链最清楚，下一门是另一位教师真实操作与签字；
- S2图谱提示：推理外显和教师判断最集中，下一门是节点／关系／提示的独立审读。

首轮只选一个进入R2，避免三个项目同时卡在“还差一次人工审读”。

### 3. 用机械能或动量长出第一套真实数据格式

建立直接量、派生量、单位、时间戳、校准、原始哈希、人工删点理由和结论上限。先让一套数据完整追溯，再讨论DIS设备扩展或自动诊断。

## 必须保留的边界

- 当前B2八章结构仍待作者裁决；本项目池只提供研发与证据输入，不自动生成目录或正文。
- 机械能公开课存在“课件首页2025年4月30日／项目卡2026年4月”的来源冲突，作者裁决前不选边。
- 不把模型输出、插值、拟合、AI候选或合成画像写成真实测量／学生认知。
- 不把S1—S4的内部测试通过写成物理教师终审、课堂可用或学习有效。
- 不宣称自研H5、微信入口、Web DIS优于GeoGebra、PhET或其他成熟工具；只比较任务、证据、条件、成本和边界。
