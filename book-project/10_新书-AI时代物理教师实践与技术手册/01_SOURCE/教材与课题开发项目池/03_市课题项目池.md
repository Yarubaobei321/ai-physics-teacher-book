## 一、先给结论：市课题最该增加的不是更多孤立H5，而是一套可选择、可验真、可迭代的开发体系

市课题已经提出H5交互、AI辅助开发、自制教具、DIS、智能硬件、微信传播和教学评价，覆盖面很大。专家意见指出了两个必须收缩的方向：

1. 先按高中物理知识体系梳理每学期真正值得开发的重点、难点，不能同时开发“所有资源”。
2. 将泛化的“课前—课中—课后”改造成概念新授、实验探究、习题讲评、学生开发四类不同任务链。

因此，市课题与本书教材地图结合后的核心产品应是：

```text
教材重点难点与真实教学摩擦
→ 选择最低足够载体 K／S／D／H／V／P
→ 教师写物理规格与学生动作
→ AI辅助生成、分析、诊断或编排
→ 独立物理验真与真实数据复核
→ 课型化使用
→ 收集学生产物和失败记录
→ 教师裁决、修订、保留或停用
```

本项目池共列出18项候选，其中8项与现有教材P0项目直接对接，6项补齐市课题的研发、课型和研究基础设施，4项拓展习题、学生开发和资源治理。建议任何一个学期只选2个学科项目＋1个基础设施项目做深。

## 三、优先级与近期推进标记

| 标记 | 含义 |
| --- | --- |
| P0 | 本地已有教材锚点、案例／代码／设备基础或独立真值，适合首批试点 |
| P1 | 教学价值高，但需补原型、器材、任务或一轮学生材料 |
| P2 | 需要较复杂硬件、安全条件、长期数据或外部合作 |
| R0 | 仅用现有电脑材料即可先完成规格、测试集、任务单或证据模板 |
| R1 | 需要做可运行原型或小样实测 |
| R2 | 必须进入课堂、访谈或正式研究才能回答 |

优先级是开发顺序，不是知识点重要性排序。“两小时可推进”只指R0文档和规格，不代表产品、实验或研究已经完成。

### 9.3 形成研究问题

1. 显式写出物理规格后，AI生成H5中的单位、方向、守恒、边界和状态同步错误如何变化？
2. 同一主题在概念课、实验课和习题课中，学生留下的关系图、数据解释和推理修订有何差异？
3. DIS异常提示会促进学生复测，还是让学生直接依赖系统解释？
4. 静电场实测点、数值模型与学生手绘等势线之间的差异，如何支持模型边界讨论？
5. 学生参与开发时，物理规格、测试和版本修订中出现哪些可观察的模型建构行为？
6. 手机／视频、低成本自制装置与专用DIS能否保留相同的核心学生动作？哪些证据质量不可等效？

这些都只是可研究问题。必须在研究问题、样本、伦理、数据、分析方法和失败报告明确后，才能形成结论。

## 十、停止门与禁说项

### 10.1 项目继续的最低条件

一个项目只有同时满足以下条件才从R0进入R1或R2：

1. 对应一个明确教材难点和真实教学摩擦。
2. 学生至少要预测、操作、采集、解释、复测、改模或开发中的一种，不能只观看。
3. AI增加可定位的生成、识别、分析、诊断、审核或编排能力，普通自动作图不单列为AI。
4. 有不依赖生成链的物理真值或实测校准。
5. 教师能修改、否决、回退和停用。
6. 安全、隐私、版权、设备和维护成本可接受。

### 10.2 当前不能说

- 不能说微信／H5／AI方案优于GeoGebra、PhET或其他成熟平台；只能比较技术路线、使用条件和适用场景。
- 不能说市课题已经形成课前—课中—课后闭环、系列资源、学生作品、评价数据或推广效果。
- 不能把网站存在、测试通过、访问量、比赛参与、课程开设线索写成学习效果。
- 不能把仿真输出写成实验数据，把AI诊断写成学生稳定认知，把平滑曲线写成原始测量。
- 不能把课题组成员、专家或他人作品改写为黄灿斌个人亲历；引用S3时保留朱春莺副教授署名。
- 未回查原PDF和原始教材前，不直接引用教材图、公式数据或长段文字；公开产品还需处理版权与学生隐私。
