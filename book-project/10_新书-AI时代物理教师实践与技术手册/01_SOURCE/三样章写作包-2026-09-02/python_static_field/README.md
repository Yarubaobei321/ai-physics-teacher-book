# 静电场 Python 独立原型

## 这个程序算什么

程序求解一个有限矩形浅水槽中的二维稳恒电势：两片内部电极分别固定为 `+5 V` 与 `-5 V`，水槽外壁按绝缘边界处理。当前 `30 cm × 20 cm` 及电极尺寸是用于验证方法的**示例值**，只在拓扑上对应实物的有限平行板组合；尚未按实物测绘定标。均匀介质、无内源区域满足

\[
\nabla\cdot(\sigma\nabla V)=0,
\]

当电导率 `σ` 为常数时化为 `∇²V=0`。图中的电场按 `E=-∇V` 计算。

这是 2026-09-02 新建的 Python 路线。它与旧 COMSOL 探索有历史关联，但研究对象、边界表达和证据链都重新建立；没有恢复旧参数，也没有生成或冒充实测数据。

## 先改哪里

优先复制并修改案例JSON中的水槽长宽、电极位置、长度与电势。程序会拒绝它尚未实现的方程或外壁边界。若真实装置使用不同边界、非均匀水深或非均匀电导率，不能只改彩图；应先改方程和边界假设，再重新设置验收标准。

## 这组检查能证明什么

- 定电势节点没有在迭代中被改写；
- 绝缘外壁的离散法向导数为零，高低电极的净通量近似守恒；
- 只有固定边界具备相应镜像关系时，才启用该方向的对称性检查；左右项先减去两极电势中值，不对称几何会标为“不适用”，不会被误判为数值失败；
- 自由节点的电势没有超出高低电极的边界值；
- 离散方程残差达到阈值；
- 三档网格在选定采样点上的差异逐步减小；
- 求解器能复现有解析解的平行板问题；
- 电场方向在全域与电势梯度反向；方向符号写反时，检查会失败；
- 声明为高低电势的一对电极却被误设成等电势时，边界检查会失败。电势零点可以任意平移，例如`5 V/2 V`仍是合法边界；
- 两电极电势同时加上同一常数时，电势整体平移、电场保持不变；
- 二维调和函数`V=x²-y²`在`dx≠dy`的网格上仍须被正确复现，用来保护横纵差分权重。

自由节点以固定边界电势的平均值作为迭代初值。这样整体平移所有定电势边界时，求解过程也随之平移，不会因为默认从`0 V`起算而给某个电势零点特殊地位。

主图中的电场线在电极节点及一格邻域停止，不把节点差分值画成“导体内电场”；流线线宽统一，疏密仍受绘图播种参数影响，不用于定量判定场强。

这些检查只能说明本次数值原型按声明的数学模型工作，不能说明它已经对应某一次真实水槽测量，更不能说明课堂效果。
