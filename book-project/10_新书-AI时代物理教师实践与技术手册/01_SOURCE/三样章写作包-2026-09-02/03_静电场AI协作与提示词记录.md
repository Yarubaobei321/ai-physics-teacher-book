# 静电场样章：AI协作与提示词记录

> 日期：2026-09-02  
> 性质：本轮真实开发过程的整理记录。下列“复做提示词”是为读者重新组织的工具，不冒充逐字聊天记录。

## 作者提出的任务

作者确认旧数值模型当前找不到，希望参考叶张胜、杨树林的研究，用Python建立新的静电场仿真路线。作者同时要求把这一方案写成AI应用案例。本书据此作出的工作界定是：AI应用体现在生成式AI参与需求澄清、建模质疑、代码生成和回归检查；Python是本案例的数值计算载体。

## AI第一轮判断被退回的地方

参考论文使用二维网格上的自由空间点电荷库仑场叠加。若直接照搬，它能画出点电荷的电势和场线，却不能回答作者实物水槽的问题：有限电极有尺寸，亚克力槽壁阻止电流穿出，回流电极与接线决定边界。把两种对象合在一起，会得到一张熟悉而无法对照测点的图。

因此本轮先退回“照论文生成点电荷彩图”的快捷方案，改成有限水槽边值问题。旧资料也被重新核对：原软件名称是COMSOL Multiphysics；旧图和操作笔记仍在，但没有找到可复算的`.mph`工程，笔记中的表面电荷密度和无限元边界也不能自动变成水槽的定电势边界。

## 本轮实际形成的需求清单

1. 只先做一个拓扑清楚的有限平行板组合，不一次生成五种彩图。
2. 水域近似均匀、无内源，求解`∇²V=0`。
3. 电极使用定电势边界；水槽外壁使用绝缘边界。
4. 电场按`E=-∇V`计算。
5. 图件之前先验收定电势、绝缘外壁、残差、最大值原理、通量平衡、适用条件明确的对称性、解析解、电势零点平移和三档网格收敛。
6. 故意加入两个错误：把电场写成`+∇V`，把声明为高低电势的一对电极误设为等电势；检查必须抓住它们，同时不得错误拒绝`5 V/2 V`这类整体平移后的合法边界。
7. 当前尺寸只作方法演示，不宣称复原实物，不生成虚构测点。

## 复做提示词一：先逼AI说明模型

```text
我要为高中物理“静电场描绘”装置建立二维Python数值模型。请先不要写代码。

实物是有限浅水槽，电极有实际尺寸，槽壁绝缘。我将测量水中的稳恒电势，再与数值预测比较。请先输出：
1. 你认为应求解的物理量和控制方程；
2. 每类边界对应的真实部件；
3. 仍缺少、必须由我测量或确认的几何、接线和材料参数；
4. 自由空间点电荷公式为什么不能直接作为水槽预测；
5. 至少五项独立于彩图的验收测试。

所有未给出的参数标为“待确认”，不要自行补成实物事实。
```

## 复做提示词二：再让AI交付最小代码包

```text
依据已经确认的模型，先实现一个“有限平行板+绝缘外壁”的最小原型。

交付必须包括：
- 单独的配置对象，明确标记当前尺寸是示例值；
- Laplace方程求解器；
- 电势、等势线和E=-grad(V)的图；
- 有解析解的理想平行板校准题；
- 定电势保持、绝缘壁、差分残差、最大值原理、通量平衡、对称性和三档网格收敛测试；
- 线性平行板和`dx≠dy`的二维调和解析题；
- 两电极电势整体平移后电场不变的回归测试；
- 故意使用E=+grad(V)和两电极等电势的错误注入；
- JSON验收报告与CSV网格比较；
- README，说明能证明什么、不能证明什么。

任何测试未通过时，程序以非零状态退出，不要只给我一张图。
```

## 复做提示词三：把AI修改变成回归检查

```text
请审查刚才的代码修改。逐项回答：
1. 修改触及了方程、边界、单位、求解器、绘图还是文案？
2. 哪些既有测试会保护这些行为，哪些行为目前没有测试？
3. 如果改进图形、交互或中文字体，是否可能改变数值数组？
4. 用同一命令重新运行全部测试与验收，并列出前后关键指标。
5. 未通过前不要声称模型正确，也不要扩展到其他四组电极。
```

## AI做了什么，教师仍要做什么

| 环节 | AI可以承担 | 教师必须裁决 |
| --- | --- | --- |
| 需求 | 把自然语言拆成方程、配置、输出和测试 | 研究对象是否真是这套水槽；哪些参数来自实物 |
| 编码 | 生成求解、可视化、报告和测试草案 | 方程、边界、正负号、单位是否符合物理 |
| 排错 | 根据失败信息定位实现问题 | 错误是程序问题、模型问题还是实验条件问题 |
| 验收 | 自动重复残差、解析解、对称性等检查 | 阈值是否有物理意义；验收是否覆盖真实任务 |
| 发布 | 整理复做说明和版本记录 | 能否进入课堂或出版；限制写到什么程度 |

## 本轮已经运行的检查

2026-09-02本机运行结果保存在`python_static_field/output/静电场_验收报告.json`。16项单元测试通过，主程序验收整体通过。新增的完整流程测试确认`5 V/2 V`不会因电势零点而被拒绝；左右不对称的电极配置会把左右反对称项标为“不适用”，同时继续检查仍然适用的上下对称。报告记录了运行环境、源码与配置哈希、求解参数及电极吸附到网格后的实际坐标。当前原型通过定电势、绝缘壁、五点差分残差、最大值原理、通量平衡、适用的对称性、三档网格、两类解析解、电势零点平移和全域场方向检查；故意反向的电场与等电势错误边界均被拒绝。

这些结果验证的是声明的示例模型和代码。实物尺寸、实际电势、水深、电导率、探针与测点仍待下一轮取得，因此“仿真与实物相符”仍没有证据。
