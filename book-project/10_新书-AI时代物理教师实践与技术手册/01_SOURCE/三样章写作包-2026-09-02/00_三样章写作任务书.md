# 三样章写作任务书

> 日期：2026-09-02  
> 状态：第一轮三样章与内部验收已完成，待作者裁决书型  
> 目标：用三个技术介入程度不同的案例，验证“教学问题决定技术选择”的全书立意。

## 三个样章的分工

| 样章 | 核心对象 | 技术身份 | 要验证的全书能力 |
| --- | --- | --- | --- |
| 数智育才网站 | 气垫导轨机械能实验页面 | AI Coding深度参与资源开发 | 教师怎样把课堂问题变成需求、版本、物理验收和发布责任 |
| 静电场描绘仪 | 实物逐点测量与Python数值预测 | 生成式AI辅助Python仿真开发 | 教师怎样审查AI生成的模型、边界、代码和图像，并让仿真与实测相互质疑 |
| 活版电路拼图 | 可移动元件与可见电路结构 | 基本不使用AI | 一项实体可视化资源怎样靠结构、操作和课堂问题本身形成完整价值 |

三个样章共同回答“怎样选择、开发、使用和验收教学资源”，但不追求统一技术路线。AI参与程度从深到浅，不能据此排出案例高低。

## 要做的事

1. 为三个样章分别建立来源与主张矩阵，回到第一方原件或明确署名的外部参考，不从旧稿复制事实。
2. 完成三篇连续可读的样章第一稿；正文直接进入对象、行动和冲突，同时保留可复做的操作、验收、排错和边界。
3. 为静电场建立新的实验事实档案和Python仿真原型。原始材料已核定软件名称为COMSOL Multiphysics；旧工程作为当前无法复算的历史路线，Python按实物水槽边界新建独立路线，两者不建立替代或复原关系。
4. Python原型至少覆盖一个可与实物电极边界对应的二维拉普拉斯方程问题，输出电势、等势线与电场，并设置独立检查、错误注入和数值收敛记录。
5. 建立三章的视觉任务表，优先复用授权待核的真实图件和本轮可复算的数据图；正文没有可靠图片时不放装饰性占位。
6. 更新书型与决策记录，说明静电场属于“AI辅助物理建模”，活版电路拼图承担非AI实体可视化基线。

## 不做的事

- 不覆盖现有四版书稿、旧B3样章或原始项目材料。
- 不把叶张胜、杨树林的研究写成本书作者亲历；只吸收其“生成代码也会出现物理错误，需要人工校正”的方法启发并明确署名。
- 不把本轮Python仿真写成已经进入课堂、已经改善学习或已经替代真实实验。
- 不为活版电路拼图追加没有发生过的AI设计、图像识别或智能评价。
- 不因COMSOL源文件当前无法找到而反推旧参数、旧版本和旧仿真结果。
- 不把页面构建通过、代码测试通过或装置存在写成教学效果。
- 不在本轮部署网站、修改线上资源、公开学生材料或处理未授权图片。

## 完成标准

### 共同标准

- [x] 每章开头能让物理教师迅速知道“这是什么、解决什么、读完能做什么”。
- [x] 每章至少形成一条“对象与问题—选择—制作/开发—验真—课堂任务—失败/退回—迁移”的连续链。
- [x] 每个确定事实有原件或本轮可重复运行结果；设计、推断和待核内容明确降级。
- [x] 每章交付一项读者可以实际使用的工具，而不只是项目介绍。
- [x] 三章写法保持对象差异：网站重版本，静电场重预测—测量—偏差，电路拼图重结构—操作—表达。

### 网站样章

- [x] 围绕气垫导轨页面，不以整个网站代替具体案例。
- [x] 写清原始输入顺序被自动排序破坏、教师退回与版本修正的真实链。
- [x] 写清页面运行、物理正确、课堂使用和发布状态是四个不同判断。

### 静电场样章

- [x] 明确实物模拟法、点电荷理论场和有限边界数值场不是同一个对象。
- [x] Python源代码、配置、测试、示例输出和复现说明可以在本地重新运行。
- [x] 至少检查边界电势、对称性、有限差分残差、网格收敛和故意错误边界。
- [x] 新仿真没有原始测点时，只展示预测方法和未来对照表，不虚构测量数据。
- [x] 生成式AI的贡献和教师的物理裁决分别可见。

### 活版电路拼图样章

- [x] 写清元件怎样移动、连接关系怎样变得可见，以及学生要完成什么任务。
- [x] 制作材料、结构、操作、故障与安全信息达到现有证据允许的最大深度。
- [x] 没有AI不是缺口；本章价值由物理对象与课堂任务承担。

## 风险与回滚

| 风险 | 控制与回滚 |
| --- | --- |
| 三章同时写导致再次铺陈材料 | 每章只保留一条主冲突；次要项目只作比较或迁移，不扩成第四条主线 |
| Python图像漂亮但物理错误 | 建立事实档案、解析/对称性检查、残差、收敛和错误注入；验收未过不进入确定表述 |
| 把他人论文改写成作者成果 | 外部文章保持作者、题名、刊期和引用身份；本轮代码与结果单独登记为新原型 |
| 源文件缺失造成虚假复原 | 旧COMSOL口径标为历史且工程文件当前无法找到；Python方案作为独立路线另起事实记录 |
| 原件不足仍强写课堂故事 | 写成制作事实、课堂设计或待补证问题；不补造学生反应与效果 |
| 现有工作区较脏 | 所有新增内容集中在本日期写作包、三样章稿和对应审阅目录；不整理无关改动 |

删除或停用本轮三个新增目录即可回滚；现有四稿、旧B3稿和项目原件均不受影响。
