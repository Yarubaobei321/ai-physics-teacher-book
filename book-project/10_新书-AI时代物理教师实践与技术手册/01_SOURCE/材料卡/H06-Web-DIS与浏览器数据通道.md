# H06｜Web DIS与浏览器数据通道

- **等级**：A/C。
- **入口**：[网页DIS组件](</Users/yaril/个人文档/数智育才网站/src/components/DisPanel.astro>)、[设备协议](</Users/yaril/个人文档/数智育才网站/docs/dis-ble-devices.md>)。
- **真实问题**：真实传感器数据怎样带着设备身份、单位和时间进入浏览器，并能绘图、记录和导出？
- **可展开**：力、距离、单/双头光电门的模式、BLE协议、图表和CSV。
- **重要版本边界**：当前网站力传感器程序使用ADS1220差分采集；它不是H09的HX711程序版本。
- **可支持**：网站数据通道、协议与页面功能。
- **不能支持**：全部硬件已台架复测、精度与长期稳定性已证实。
