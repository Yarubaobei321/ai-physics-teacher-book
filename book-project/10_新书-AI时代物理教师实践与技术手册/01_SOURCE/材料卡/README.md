> 用途：把全书价值地图中的材料代号变成可打开、可追溯、可裁决的本地入口。网页中的材料标签应链接到这里的对应卡片。

## 使用规则

1. 页面标签打开材料卡，材料卡再进入权威原件。
2. 卡片中的“A级”指对本书具有核心挖掘价值，不表示所有效果主张都已得到A级证据。
3. 同一材料进入不同章节时，必须说明分析对象、核心问题和读者所得的差异。
4. 课程设计、申报、代码存在、网站运行、获奖或专利受理都不自动证明课堂效果。
