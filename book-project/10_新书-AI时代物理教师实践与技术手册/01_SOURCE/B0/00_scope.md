# B0范围、边界与停止规则

> 状态：2026-08-29历史基线；当前B0入口见[`README.md`](./README.md)  
> 更新：2026-08-30  
> 定位：一次性材料清点与价值提炼工作流，不建设长期材料操作系统。

## 一、B0只解决三个问题

1. 目前有哪些可能与新书有关的材料；
2. 哪些材料值得在B1前优先理解，哪些只需备用或排除；
3. 现有材料之间已经出现哪些值得由作者继续判断的读者价值关系。

本轮采用以下原则：

> 材料存在性要全面，材料理解要选择性，具体主张核验要精确。

B0不确定书名、目录、章节数量和篇幅分配，不写样章或正文，不预测B1以后可能需要的全部材料。

## 二、稳定来源材料包与动态问题视图

### 来源材料包

来源材料包按真实实践、项目或来源单元组织，结构相对稳定。例如：

- 学生与AI共制物理作品及评价；
- 机械能守恒公开课与在线实验室；
- 数智育才教学网站与教师—AI协作开发；
- 合著作者共同实践，包括王硕的物理教学与实验创新、严力耕的科创教具与AI教育、丁龙的超重与失重课例；
- 继续教育课程设计；
- ESP32Blockly及设备治理。

它回答“这批材料是什么、形成于哪项实践、含有哪些证据”。来源材料包不按尚未确定的书稿问题反复重组。

### 问题视图

问题视图由B1或后续任务临时形成。例如“AI生成的物理资源怎样验收”“多种实验路径怎样形成比较”。一个问题可调用多个来源材料包，一个材料包也可服务多个问题。

### 候选价值关系

B0把来源材料包之间已经显现的关系写成候选关系卡，交给B1和作者判断。关系卡属于编辑假设，不等于书的中心命题。

```text
稳定来源材料包
→ 按任务形成问题视图
→ 提出候选价值关系
→ B1比较并由作者裁决
```

## 三、材料范围

### 已纳入机械盘点

1. 作者项目资源库入口层与已登记项目卡；
2. 新书首批M4/M5、继续教育课程及同行培训材料；
3. 高中物理教材与教师用书；
4. 旧书作者反馈修订稿及其材料系统；
5. 三本物理教育精校专著、AI橙皮书和WorkBuddy蓝皮书；
6. 合著作者材料的项目卡、目录级存在性、作者归属与敏感边界；
7. 作者点名保留的《专著框架蓝图 v1》及其四人合著修订版。

`01_inventory.csv`以重做前已完成的10,491条机械索引为底表，删除SHA、默认阅读层级、Token等治理字段，再补入本轮直接核过的核心原件。它用于查漏，不直接交给B1阅读。

### 本轮只精读的A类来源材料包

1. `A01` 学生与AI共制物理作品及评价；
2. `A02` 机械能守恒公开课与在线实验室；
3. `A03` 数智育才教学网站与教师—AI协作开发；
4. `A04` 合著作者共同实践（王硕、严力耕、丁龙）。

前三个来源包以已核验项目材料为核心；A04复用三位教师已有素材卡和15个项目包索引，不批量打开346份原件。继续教育、智能硬件、教材、旧书、参考书和外部同行材料先保留为B类，不为字段完整而继续摘要。

### 合著材料的进入原则

- 合著作者的真实成果与黄灿斌的实践同属A类候选核心，不再按“他人参照”整体降级；
- A类表示“必须进入B1价值判断”，不表示所有原件都已核验、可默认读取或可直接出版；
- 每项成果保留具体作者、共同完成者和原始项目归属，不合并成单一作者经历；
- B1应检查四位作者的成熟成果能否共同支撑全书，而不是只从材料数量最多的一位作者生成方向；
- 学生作品、照片、姓名、代码和未公开项目仍分别执行隐私、版权与授权门禁。

### 明确排除或受限

- 初高中衔接课程：本书本轮明确排除；不进入B1关系生成。
- 20个粗糙且未经人工物理审阅的高考交互模型：不作为质量案例或书稿证据。
- 学生身份映射、未脱敏对话、含姓名的作品与网页附件：禁止进入默认上下文。
- 合著作者材料中的学生原件、现场照片和未授权图件：来源包进入A类，但这些具体原件仍禁止进入默认上下文，出版前逐项脱敏与授权。
- 商业教辅正文、批量题库与题图：不公开、不批量注入写作上下文。
- 部署密钥、WiFi信息、设备MAC和服务器敏感配置：不进入书稿材料。
- 作者与来源不明的理论篇：只作检索线索，不能承担理论主张。
- 旧书正文、旧AI候选和重复转换稿：只作历史参照，不作为事实源。作者点名的《专著框架蓝图 v1》例外保留为B1结构假设：允许继承其中有效的“为什么—怎么造—怎么用—评价与推广”、分章合著和风险清单，但不在B0冻结12章目录。

排除项只有在作者明确改变决定，或授权、隐私、来源、物理核验等条件被补齐时，才允许重新讨论。

## 四、判断依据

B0对“核心、备用、排除”的判断受《书的宪法（B0工作版）》约束：

- 面向希望使用AI但仍承担物理学科判断和教师责任的读者；
- 从真实教学问题进入AI；
- 优先保留各位合著作者的真实实践、失败、选择、证据和可迁移动作；
- AI、物理、可视化和教师价值应形成关系，工具名称本身不构成价值；
- 外部内容先完成来源、概念、学科和实践转译；
- 学习效果、普遍迁移、原创性和技术领先等主张必须有相应证据。

智能硬件可以进入B0，但默认承担支撑案例或技术附属角色。抽象测试是：删去ESP32、传感器型号和代码名称后，案例能否仍形成教师可迁移的方法。不能通过该测试的内容不进入B1主方向。

## 五、证据与判断分层

每张核心卡分四层记录：

1. **来源事实**：材料是什么、谁形成、何时形成、包含什么对象；
2. **证据判断**：能支持什么、不能支持什么、可回到哪个原件位置；
3. **编辑假设**：可能形成什么读者价值或跨材料关系；
4. **作者决定**：认可、否决、暂缓或要求补证。

B0生成的关系一律标为“Agent提出／作者未审”，不得自动升级成全书主线。

证据不压缩成单一总分。核心卡至少分别写清：来源身份、原件核验、证据作用、充分程度、时间状态、权利与隐私边界。

## 六、默认阅读顺序

本文件形成时的默认顺序如下；2026-08-30重启B0后，当前顺序以[`README.md`](./README.md)为准：

1. `README.md`；
2. 本文件；
3. `02_material_review.md`中的历史A/B/C分类和核心卡；
4. `03_b1_handoff.md`中的历史候选关系；
5. 围绕当前B0问题选择1—3个材料包；
6. 卡片不足、版本冲突或需要核验具体主张时，再打开卡片指向的原件或片段。

这是默认顺序，不是禁止升级读取的硬层级。需要完整上下文时可以读完整原件，但必须说明为何需要扩大范围。

## 七、B0完成与停止规则

以下是2026-08-29旧一轮B0的停止规则；新一轮退出条件见[`05_B0继续深挖任务池-2026-08-30.md`](./05_B0继续深挖任务池-2026-08-30.md)：

1. 候选材料范围已有机械清单，已知排除项不会回流；
2. 材料包已完成A/B/C处理决定；
3. 四个A类核心包已有一屏卡、证据边界和原件锚点；
4. 已形成一张统一关系矩阵；
5. 已提出5—10个可供B1比较的候选价值关系；
6. B1无需扫描全库即可开始判断。

停止后不继续为长尾材料补摘要、建关系图、维护六类索引、制作任务路由或完善HTML功能。B1如发现关键缺口，只做一至两轮定向补查。
