## 本轮只做什么

B0只登记材料身份、来源、潜在价值、证据边界、材料之间已经出现的关系和下一步补证任务。本轮不生成目录、不分配章节、不修改样章正文，也不把研究建议写成已经发生的课堂结果。

当前工作的基本判断是：

> 生成式AI降低了生成和处理候选内容的成本，低成本传感器增加了可获得的真实数据，教师自建资源增加了修改和组织能力。三者都没有自动提高结论的效度。教师仍要决定问题、测量、证据、干预和停止条件。

## 当前已经形成的五条候选价值关系

这些关系已进入新B1比较，但仍不预设章数和章位。白话解释和作者裁决问题见[五条价值关系白话裁决版](./06_五条价值关系白话裁决版-2026-08-30.md)。

1. **新条件扩大候选，教师判断决定效度。** AI、传感器和自建资源分别增加生成、测量和修改能力；问题界定、测量模型、证据解释、教学干预和停止仍不可外包。
2. **过程痕迹只能支持诊断假设。** 口述、作答、AI对话、修改日志和成品互相补充；任何单一通道都不是学生思维的录像。
3. **内容地图、测量模型、学生状态和教学策略必须分层。** 知识图谱描述知识世界，Q-matrix描述题目测什么，认知诊断或知识追踪估计学生可能在哪里，路径规则决定下一步，LLM负责受约束的自然语言交互。
4. **个性化学习首先是课堂编排问题。** 更值得验证的是“个体证据怎样被压缩为教师可行动的共性与长尾信号”，而不是宣称系统已经找到最优路径。
5. **自动化应按错误代价选择。** AI可承担预审、聚类、重复评分和风险分流；识别、评分、物理判断、教学解释与最终裁决需要分层，并保留人工升级和申诉路径。
