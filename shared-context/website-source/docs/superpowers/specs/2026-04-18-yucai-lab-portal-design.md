# 育才一中物理创新实验室门户设计说明

## 目标

建设一个面向“育才一中物理创新实验室”的门户网站，第一版包含首页、在线编程、网页版 DIS 三个页面。首页突出校园身份、育才蓝和实验室简介；在线编程先提供四个 MicroPython 模板；网页版 DIS 先用模拟数据展示采集、绘图和导出流程。

## 技术选择

使用 Astro 管理静态页面，Tailwind CSS 管理样式。硬件交互界面先使用原生 TypeScript 脚本实现，后续再接入 Web Serial 和 Web Bluetooth 的真实数据流。这样可以先完成可部署、可演示、结构清楚的版本，再逐步增加 ESP32 写入和蓝牙采集。

## 页面范围

首页使用校园照片作为首屏主视觉，搭配 LOGO、实验室简介和两个工具入口。在线编程页面包含模板选择、代码编辑区、串口状态、模拟写入和串口输出。网页版 DIS 页面包含实验模式、实时数值、曲线画布、暂停、清空和导出 CSV。

## 第一版限制

第一版不真正写入 ESP32，也不订阅真实 BLE 数据。页面会检测浏览器是否支持 Web Serial / Web Bluetooth，并保留下一阶段接入点。在线编程模板只包含力传感器、距离传感器、单光电门测速度、双头光电门测速度。
