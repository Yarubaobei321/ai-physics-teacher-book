# 学生 AI 素养评价

## 页面定位

该专题把 77 份匿名学生材料整理为可用于教学观察和论文复核的证据链。公开页面统一使用“学生 AI 素养评价”口径，不展示姓名、班级、分享凭据、内部目录或代号映射。

页面入口为 `/simulations/student-ai-lab/`，单份案例继续使用稳定代号路由 `/simulations/student-ai-lab/<alias>/`。

## 现场任务

- 时间：50 分钟。
- 工具：DeepSeek 网页版。
- 任务：独立完成一个单文件、可交互的知识科普 HTML 网页。
- 过程：通过对话生成初版，继续修正和优化，最后提交 HTML 与对话记录。

现场原始五维标准总分 100 分：

| 维度 | 分值 |
| --- | ---: |
| 主题与知识准确性 | 30 |
| AI 工具使用能力 | 25 |
| 交互设计合理性 | 25 |
| 页面呈现与可读性 | 15 |
| 创意与亮点 | 5 |

原规则采用 5 位评委独立评分、去掉最高分和最低分后取平均值。当前材料库没有这组正式评委成绩，页面只介绍规则，不展示或推算正式结果。

## AI 研究性评分 v4

专题主展示口径为作者开发的双轨评分，总分 100 分：

- A 轨 60 分：只根据可确认由学生提出的对话证据，评价问题定义、迭代诊断、学科建模、验收校验和版本取舍。
- B 轨 40 分：只评价学生提交最终版的学科正确性、教学可用性、交互完整性和呈现可访问性。

DeepSeek 回复、AI 生成代码和页面复杂度不能反推学生的 A 轨能力。页面不建立排行榜、不设置“优秀/合格”等级，也不把 AI 研究性评分称为正式成绩。

A4“验收与数据校验”在展示层统一按分数派生档位：

| 分数 | 展示档位 |
| ---: | --- |
| 10–12 | 判据核验 |
| 6–9 | 功能自查 |
| 3–5 | 被动修正 |
| 0–2 | 未进行验收 |

物理作品另有 B1 学科正确性深度复评，只作为方法附录中的敏感性分析，不回写主 v4 总分。

## 单份案例的证据顺序

1. 关键对话：按统一规则抽取初始需求、首次完整代码、学生迭代、回退或验收轮次。
2. 完整可见对话：保留所有自然语言消息；大段代码正文不重复渲染，由作品预览承载。
3. DeepSeek 第一版与学生提交最终版：并排、隔离、可交互预览。
4. AI 研究性评分 v4：展示 A/B 轨、九个维度、证据与教学观察。
5. 评审重构的最优提示词：由全过程需求、评分暴露问题和验收判据整理而成，不是学生现场原话。
6. DeepSeek 优化对照：由 `deepseek-v4-flash-0731` 根据最优提示词生成，用于观察规格前置后的结果差异。

优化对照使用了后续模型且没有现场时限，因此页面只展示对照结果，不把差异单独归因于提示词，也不把研究生成页称为学生作品。

## 特殊状态

- 只有一个完整阶段的作品标记为“单阶段提交”，不描述为多轮优化。
- 第一版与学生提交版相同的作品明确标记“首版与提交版一致”。
- 学生提交版与对话末版不同的作品明确标记“提交版与对话末版不同”；提交文件始终是最终版权威来源。

## 发布数据边界

网站只消费脱敏后的公开数据契约，不直接读取原始评分文件或身份映射。每个代号只发布：

- 关键对话与完整可见对话；
- DeepSeek 第一版；
- 学生提交最终版；
- v4 安全字段；
- 最优提示词；
- DeepSeek 优化对照。

不发布历史教师增强页、真实姓名、班级、联系方式、DeepSeek 分享链接、本地路径、内部作品 ID 或原始评分 JSON。页面不提供匿名数据文件下载。

学生 HTML 通过不含 `allow-same-origin` 的 iframe 沙箱运行，并使用 `referrerpolicy="no-referrer"`。普通教学资源和 CDN 依赖可以保留；本地文件路径、保存来源注释和分享链接必须清除。
