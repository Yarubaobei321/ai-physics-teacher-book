# 网页版 DIS 蓝牙设备命名约定

本文档记录网页版 DIS 页面连接 ESP32 BLE 设备时使用的蓝牙名称前缀。后续修改网站或 ESP32 程序时，应保持这里的命名一致，避免距离传感器和光电门设备互相混淆。

## 默认蓝牙名称前缀

| 实验模式 | 默认蓝牙名称前缀 | 示例设备名 | 说明 |
| --- | --- | --- | --- |
| 力传感器 | `ESP32-force` | `ESP32-force01` | 用于力传感器模式，网页会优先搜索此前缀。 |
| 距离传感器 | `ESP32-dis` | `ESP32-dis01` | 用于距离传感器模式，网页会优先搜索此前缀。 |
| 单头光电门 | `ESP32-sgate` | `ESP32-sgate01` | 用于单头光电门模式，网页会优先搜索此前缀。 |
| 双头光电门 | `ESP32-gate` | `ESP32-gate01` | 用于双头光电门模式，网页会优先搜索此前缀。 |
| 两单头光电门 | `ESP32-2sgate` | `ESP32-2sgate01` | 用于两单头光电门模式，网页会优先搜索此前缀。 |
| 两双头光电门 | `ESP32-2gate` | `ESP32-2gate01` | 用于两双头光电门模式，网页会优先搜索此前缀。 |

## 使用规则

1. 力传感器设备名称必须以 `ESP32-force` 开头。
2. 距离传感器设备名称必须以 `ESP32-dis` 开头。
3. 单头光电门设备名称必须以 `ESP32-sgate` 开头。
4. 双头光电门设备名称必须以 `ESP32-gate` 开头。
5. 两单头光电门设备名称必须以 `ESP32-2sgate` 开头。
6. 两双头光电门设备名称必须以 `ESP32-2gate` 开头。
7. 不要把光电门前缀写成其他 ESP 编号；单头正确前缀固定为 `ESP32-sgate`，双头正确前缀固定为 `ESP32-gate`，两单头正确前缀固定为 `ESP32-2sgate`，两双头正确前缀固定为 `ESP32-2gate`。
8. 如果教室里有多台设备，建议用编号区分，例如 `ESP32-force01`、`ESP32-dis01`、`ESP32-sgate01`、`ESP32-gate01`、`ESP32-2sgate01`、`ESP32-2gate01`。
9. 网页端保留“蓝牙名称前缀”输入框，可以临时修改前缀；但默认值应遵守本文件约定。

## BLE 数据格式

六个实验模式都使用 phyphox BLE 数据特征值。力、距离、单头、双头四个基础模式每次通知发送两个 32 位小端浮点数；两单头和两双头模式每次通知发送四个 32 位小端浮点数：

| 实验模式 | 第 1 个 float | 第 2 个 float | 网页端处理 |
| --- | --- | --- | --- |
| 力传感器 | 受力 / N | 设备时间 / s | 直接绘制力-时间曲线。 |
| 距离传感器 | 位移 / cm | 设备时间 / s | 直接绘制位移-时间曲线。 |
| 单头光电门 | 挡光时间 / s | 设备时间 / s | 根据遮光物宽度计算速度：`速度 = 遮光物宽度 / 挡光时间`。网页输入的遮光物宽度单位是 cm，计算速度时会换算成 m。 |
| 双头光电门 | 速度 / m/s | 设备时间 / s | 直接记录速度事件，显示柱形图和数据表。 |
| 两单头光电门 | 光电门编号 | 速度 / m/s | 第 3 个 float 是遮光时间 / s，第 4 个 float 是设备时间 / s。网页用光电门编号显示 G1/G2，并直接使用 ESP32 算出的速度。 |
| 两双头光电门 | 光电门编号 | 速度 / m/s | 第 3 个 float 是两探头时间差 / s，第 4 个 float 是设备时间 / s。网页用光电门编号显示 G1/G2。 |

## 网页连接策略

网页版 DIS 页面提供两种蓝牙搜索方式：

1. **按名称连接**：优先使用当前实验模式的默认前缀搜索设备。力传感器默认搜索 `ESP32-force`，距离传感器默认搜索 `ESP32-dis`，单头光电门默认搜索 `ESP32-sgate`，双头光电门默认搜索 `ESP32-gate`，两单头光电门默认搜索 `ESP32-2sgate`，两双头光电门默认搜索 `ESP32-2gate`。
2. **搜索所有蓝牙**：显示当前浏览器可见的所有 BLE 设备，适合浏览器缓存异常、设备名称未按约定设置或需要临时排查时使用。

切换实验模式时，页面会保存新模式、断开当前 BLE 连接并刷新页面，避免继续使用上一个模式的蓝牙设备。
