## 题型分布

- 选择题：实验原理、操作细节、装置作用（含多选）
- 填空题：公式应用、关键参数计算
- 计算 / 数据处理：能量计算、相对误差、表格读数
- 误差分析与改进：定量讨论误差来源、提出改进方案

## 教学使用建议

1. **课前预习**：让学生先打开网页实验工具，跑一次 AI 模拟数据，再做选择题。
2. **课中合作**：用页面"导出 CSV / 截图"功能，让小组数据进入计算题分析。
3. **课后拓展**：误差分析与改进部分作为开放性作业，鼓励学生在网页上调整参数复现现象。
4. **学考衔接**：每份习题最后一道题难度对接高考全国卷实验题。

## 题目共同设计原则

- 每道题都能在网页工具上"动手验证"，避免空对空推导。
- 涉及具体数据的计算题，给出的数值与网页上"AI 模拟"或常见教学数据一致。
- 误差分析强调本实验**特有**的误差源（例如气垫导轨的滑轮摩擦、曲面下滑的转动动能），
而不是泛泛地说"读数误差"。
