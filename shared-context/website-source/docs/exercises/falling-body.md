# 落体法验证机械能守恒定律 · 习题

> 配套页面：[https://shuzhiyucai.cn/online-lab/falling-body/](https://shuzhiyucai.cn/online-lab/falling-body/)
> 适用对象：中国大陆高中物理（人教版必修第二册第八章 §5）
> 题量：10 道（含解析）

## 实验回顾

**装置**：铁架台、电磁打点计时器、低压交流电源（50 Hz）、重物（约 100 g）、纸带。

**原理**：重物自由下落带动纸带，打点计时器在纸带上每 0.02 s 打一个点。
取纸带上若干清晰、间距适当的点为 0、1、2、…、n 号计数点；测量各点到 0 号点的距离 $x_n$。
对从 0 号点下落到 n 号点的过程，比较

$$
\Delta E_p = m g h_n,\quad \Delta E_k = \tfrac{1}{2}m v_n^2
$$

其中：

- 下落距离 $h_n = x_n - x_0$
- 中间点 n 的瞬时速度 $v_n = \dfrac{x_{n+1} - x_{n-1}}{2T}$（**中间点定理**：匀变速直线运动中，某段时间内的平均速度等于该段时间中点的瞬时速度）

**关键参数**（页面默认）：


| 参数  | 值           | 说明              |
| --- | ----------- | --------------- |
| $m$ | 0.1000 kg   | 重物质量            |
| $g$ | 9.8000 m/s² | 当地重力加速度         |
| $T$ | 0.0200 s    | 相邻计数点时间间隔（不抽点时） |


> **注意**：实际教学中常每隔几个打点取 1 个计数点，此时 $T$ 要相应改为 0.04 s 或 0.10 s，
> 网页上 "相邻计数点时间 T" 必须按你实际选取的间隔填写。

## 参考答案与解析

**1. B** —— 先释放再通电，纸带最开始几格内可能无打点或打点不清晰，导致 0 号点附近数据丢失或不准。
A 错，顺序与数据可靠性相关；C 错，先通电主要是为了让计时器进入稳定打点状态；
D 错，电磁、电火花计时器都遵循"先通电再释放"的原则。

**2. C** —— 起点不必是纸带最开始那一点，关键是清晰、间距适当、且其前面还有点（这样才能用中间点公式 $v_n = \dfrac{x_{n+1}-x_{n-1}}{2T}$ 算出 0 号点附近的速度，对照参考）。A 错，开始点常常打点重叠；B 错，最密的点说明速度小、间隔分辨率不够；D 错，间距越小相对读数误差越大。

**3. AC**

- A 正确：这是匀变速直线运动的"中间时刻定理"。
- B 错：双头光电门也使用"距离/时间差"的等价思想，并不是只能用于打点计时器。
- C 正确：用 n−1 与 n+1 两点参与计算，而不是直接相邻点之差，可减小单点位置误差的影响。
- D 错：该公式仅在匀变速运动下才精确成立；非匀变速运动中它只是近似的"中间时刻平均速度"。

**4. B** —— 自由落体模型忽略阻力，但实验中纸带与限位孔的摩擦、空气阻力、电磁阻尼都做负功，
使重物实际加速度 $a < g$，因此实测 $\tfrac{1}{2}mv^2 < mgh$ 是系统性的偏差。
A、D 是数值偏差，会随机出现；C 实际上 50 Hz 频率非常稳定。

**5.** $T = 0.10$ s；网页上"相邻计数点时间 T"应填 **0.1000** 。

> 提示：相邻两计数点中间夹了 5 个间隔（4 个打点 + 1 个计数点连接），所以
> $T = 5 \times 0.02\ \mathrm{s} = 0.10\ \mathrm{s}$。

**6.（计算题）**

数据先化为 m：$x_2 = 0.0304$ m，$x_3 = 0.0684$ m，$x_4 = 0.1216$ m。

(1) 中间点定理：

$$
v_3 = \dfrac{x_4 - x_2}{2T} = \dfrac{0.1216 - 0.0304}{2 \times 0.04} = \dfrac{0.0912}{0.08} \approx \mathbf{1.14\ \text{m/s}}
$$

(2)

- 下落距离 $h_3 = x_3 - x_0 = 0.0684$ m
- 势能减少 $\Delta E_p = mgh_3 = 0.100 \times 9.80 \times 0.0684 \approx \mathbf{0.0670\ J}$
- 动能增加 $\Delta E_k = \tfrac{1}{2}mv_3^2 = 0.5 \times 0.100 \times 1.14^2 \approx \mathbf{0.0650\ J}$

(3) 相对误差

$$
\delta = \dfrac{|0.0670 - 0.0650|}{0.0670} \times 100 \approx \mathbf{3.0}
$$

(4) 同理可算得（保留 3 位有效数字）：


| n   | $v_n$ /(m·s⁻¹) | $mgh_n$ / J | $\tfrac{1}{2}mv_n^2$ / J | 相对误差  |
| --- | -------------- | ----------- | ------------------------ | ----- |
| 1   | 0.380          | 0.00745     | 0.00722                  | ≈3.1% |
| 2   | 0.760          | 0.0298      | 0.0289                   | ≈3.0% |
| 3   | 1.140          | 0.0670      | 0.0650                   | ≈3.0% |
| 4   | 1.520          | 0.119       | 0.116                    | ≈2.7% |
| 5   | 1.900          | 0.186       | 0.180                    | ≈3.0% |


各点相对误差大致稳定，说明系统性能量损失（阻力做负功）的比例近似恒定，
也佐证了"自由落体加速度被打折扣"的图像（实测 $a \approx 9.5$ m/s² 而非 9.8 m/s²）。

**7.（图像处理）**

(1) 由 $v^2 = 2ah$，理想下 $a = g$，所以 ${v_n}^2 - h_n$ 图为过原点直线，**方程 $v^2 = 2gh$，斜率 $k = 2g$**。
(2) 实测斜率 19.2 < 2g = 19.6，因为存在阻力使**有效加速度** $a$ 略小于 $g$，
　　这个有效 $a$ 就是 $k/2 \approx 9.6\ \mathrm{m/s^2}$。
(3) 优点：① 用所有数据点共同确定斜率，比单点比较受偶然误差影响小；
② 直接给出"实际重力加速度修正值"$a$，可以量化阻力的影响；
③ 直线是否过原点也是检验数据可靠性的一种判据。

**8.（误差分类）**


| 类型  | 误差来源                                             | 偏向                          |
| --- | ------------------------------------------------ | --------------------------- |
| 系统性 | 空气阻力、纸带与限位孔摩擦、电磁阻尼，使有效 $a < g$                   | 始终 $mgh > \tfrac{1}{2}mv^2$ |
| 系统性 | 用 $g = 9.8$ 默认值，但本地实际 $g$ 可能偏大或偏小（如 9.79 或 9.83） | 单向偏移                        |
| 随机性 | 纸带读数误差（毫米尺最小分度 1 mm，估读±0.5 mm）                   | 双向                          |
| 随机性 | 打点本身略有抖动                                         | 双向                          |
| 随机性 | 选取 0 号点不一致                                       | 双向                          |


> 重点："$mgh > \tfrac{1}{2}mv^2$ 几乎是必然的"——这反映了实验系统性误差，
> 是机械能"略微不守恒"的能量去向问题，而不是定律本身有误。

**9.（改进辨析）**

- A **可减小**：重物越重，重力相对阻力的占比越大，有效加速度更接近 $g$；
- B **可减小**：锥形头降低空气阻力，对自由落体段尤其重要；
- C **可减小**：避免纸带刮擦，能减小摩擦阻力；
- D **可减小**：电火花计时器的纸带摩擦更小，且不必使用低压交流电；
- E **不一定能减小，反而要谨慎**：这只是把多个打点合并为一个计数点，
　 间距变大相对读数误差变小，但**前提是 T 必须改为 0.10 s**，
　 否则速度算出来会差 5 倍——这正是网页工具上常见的输入错误。

**10.（科学方法论）**

实验目的是**验证**机械能守恒，前提是不能预设结论里的物理量。
若直接用 $g = 9.8$ 计算 $\tfrac{1}{2}mv^2$（其实是用 $h$ 反推 $v$），就退化为"用守恒律算守恒律"，逻辑循环。

正确方法：从纸带读出**独立测量量** $x_n$，由运动学（中间点定理）得到 $v_n$，
再用 $g$、$m$ 算 $mgh$ 与 $\tfrac{1}{2}mv^2$ 进行**独立比较**。
这样 $v_n$ 就和 $h_n$ 在原始数据上分离开，二者的接近才能作为守恒律成立的证据，
也才能体现"自由落体模型 vs 实际下落"的差距——这是物理实验"独立测量、独立验证"的基本要求。
