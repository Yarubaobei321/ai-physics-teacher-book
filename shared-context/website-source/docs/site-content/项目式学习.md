## 2. 新高一 /project-learning/new-grade-one/

- **页面标题**：新高一项目式学习 | 育才物理创新实验室
- **Meta 描述**：新高一暑假项目式学习：用五种方案测量深圳本地重力加速度 g，支持填写数据表、自动计算、绘制图表并导出 CSV 与结果图片。

### H1：新高一：测量深圳本地重力加速度 g（eyebrow：PART 01 · NEW GRADE ONE）

导语：利用身边简易器材实测深圳地区真实 g 值，对比 9.8 m/s² 分析误差。至少完成一种方案，有余力者可完成两种方案并比较结果差异。

项目目标：① 建立自由落体或周期运动模型，写出核心公式；② 记录原始数据，不只写最终答案；③ 用网页表格自动计算 g、平均值和误差；④ 导出 CSV 和结果图片，放入探究报告。

### H2：五种实验方案（eyebrow：EXPERIMENT METHODS）

引导语：推荐先做手机慢动作摄像法，因为器材最容易准备、运动过程最直观。想要提高报告质量，可以再做单摆法或弹簧测力计图像法作为对照。页面交互形式：五个方案以标签页（tab）切换，每个方案面板内嵌该方案专属的数据分析工作台。

#### 方案一：手机慢动作摄像法测自由落体（推荐方案 · 难度★☆☆）

- **配图**：/images/project-learning/experiments/新高一方案一.webp（alt：手机慢动作摄像法测自由落体实验示意图）
- **公式**：g = 2h / t²（由自由落体位移公式 h = ½gt² 变形得到）
- **原理**：物体由静止开始自由下落，忽略空气阻力时满足自由落体位移公式，变形即可解出重力加速度。用 240fps 慢动作录下重物下落全程，逐帧计数得到下落总时间 t，配合卷尺测得下落高度 h，便能算出本地 g 值。
- **符号**：h＝物体下落竖直高度（m）；t＝完整下落总时间（s，t = 总帧数 n ÷ 帧率）；g＝本地重力加速度（m/s²）
- **器材**：智能手机（支持 120/240fps 慢动作）、金属钥匙串（小重物）、卷尺、书本（固定手机支架）、白纸、马克笔（墙面高度标记）
- **步骤**：① 选取平整垂直墙面，标记上下两点，卷尺多次测量竖直距离记录 h；② 手机倚书本固定，镜头正对标记区域，开启高帧率慢动作；③ 手紧贴上方标记处静止释放钥匙，完整录制下落全程；④ 回放逐帧计数总帧数 n，t = n ÷ 帧率；⑤ 重复 3 次分别算 g 后取平均。
- **注意事项**：释放必须初速度为 0；画面完整包含高度标记；优先 240fps；卷尺读数视线与刻度平齐。
- **误差来源**：系统误差（空气阻力）；人为偶然误差（释放带初速度、帧数计数出错、卷尺读数偏差）；装置误差（手机倾斜导致高度非纯竖直距离）。
- **核心优势 / 适合场景**：器材最易得、过程直观，是暑假作业的首选方案 / 人人可做的首选方案。

#### 方案二：单摆法（经典严谨 · 难度★★☆）

- **配图**：/images/project-learning/experiments/新高一方案二.webp（alt：单摆法测量重力加速度实验示意图）
- **公式**：g = 4π²L / T²（由单摆周期公式 T = 2π√(L/g) 变形得到）
- **原理**：单摆在摆角很小（θ<5°）时近似做简谐运动，周期与摆长满足周期公式，变形即可解出 g。L 为摆长（悬挂点到摆球质心的距离），T 为一次全振动周期。
- **器材**：细缝纫线或钓鱼线（约 1–1.5 m）、金属螺母或小钢球、卷尺、智能手机秒表、铅笔或筷子（悬挂支点）、量角器 / 手机量角 App
- **步骤**：① 细线系螺母、铅笔水平架于门框或桌沿；② 测悬挂点到螺母中心距离为摆长 L（3 次取平均）；③ 拉至偏离竖直约 3°–5° 静止释放；④ 稳定后计时 30 个全振动总时间 t，T = t/30；⑤ 重复 3 次分别算 g 取平均。
- **注意事项**：摆角控制在 5° 以内；同一竖直平面内摆动，画圈须重放；从最低点开始计时；细而轻的线配小而重的球。
- **误差来源**：系统误差（摆角偏大周期偏长使 g 偏小；摆线质量与弹性使等效摆长不准）；人为偶然误差（秒表启停延迟、计数出错、摆长量不到球心）；装置误差（悬挂点不牢、圆锥摆动）。
- **核心优势 / 适合场景**：原理清晰、过程完整，适合追求严谨探究的同学 / 追求完整探究过程。

#### 方案三：手机加速度传感器法（操作极简 · 难度★☆☆）

- **配图**：/images/project-learning/experiments/新高一方案三.webp（alt：手机加速度传感器法测量重力加速度实验示意图）
- **公式**：g = a_z（手机水平静置时 z 轴加速度读数即为 g）
- **原理**：智能手机内置三轴 MEMS 加速度计。手机水平静置时传感器测得的合加速度即为 g。进阶法：让手机自由下落到软垫上，下落阶段处于失重状态，分析加速度–时间图像可读取自由落体阶段加速度。
- **器材**：智能手机、物理传感器 App（推荐 phyphox）、厚海绵垫或枕头、卷尺
- **步骤**：方法 A 静态测量（选“加速度（含 g）”模块，平放桌面记录 10 秒取 z 轴平均）；方法 B 自由落体进阶（铺 ≥20cm 软垫，最高采样率，约 1 m 高度松手，找加速度接近 0 的平台段，重复 3 次取平均）。
- **注意事项**：区分“含 g / 不含 g”模式；手机必须水平；自由落体务必缓冲保护；不同手机传感器精度不同。
- **误差来源**：传感器零点漂移与出厂校准偏差；未水平放置导致重力分量分配到多轴；释放时施加额外力、图像区间选取不准。
- **核心优势 / 适合场景**：操作极简，几分钟即可拿到数据 / 快速获取数据。

#### 方案四：滴水法（创意趣味 · 难度★★★）

- **配图**：/images/project-learning/experiments/新高一方案四.webp（alt：滴水法测量重力加速度实验示意图）
- **公式**：g = 2h / t²（相邻两滴间隔 t 即一滴自由下落时间）
- **原理**：调节滴速使上一滴恰好落盘的同时下一滴刚好脱落，此时相邻两滴时间间隔 t 恰等于一滴水自由下落到盘面所用时间。测量滴口到水面竖直高度 h 即可解出 g。
- **器材**：可调流速水龙头或一次性输液器、金属盘（落水声清脆）、卷尺、手机秒表、椅子或梯子
- **步骤**：① 测滴口到盘面高度 h（3 次平均）；② 调滴速至“滴落声”与“新滴脱落”严格同步；③ 计连续 50 滴总时间 t₀，t = t₀/50；④ 重复 3 次（每次重新调速）分别算 g 取平均。
- **注意事项**：调滴速最关键最耗时，需安静环境；输液器比水龙头易调；高度建议 1.0–1.5 m；金属盘声音清脆。
- **误差来源**：空气阻力使测量值偏小；“同步”判断主观性强；滴速漂移（水压变化）、高度起止点不精确。
- **核心优势 / 适合场景**：创意独特、趣味性强 / 喜欢动手调试。

#### 方案五：弹簧测力计 + 已知质量法（原理最直接 · 难度★☆☆）

- **配图**：/images/project-learning/experiments/新高一方案五.webp（alt：弹簧测力计加已知质量法测量重力加速度实验示意图）
- **公式**：g = F / m（静止时测力计示数 F = G = mg；进阶取 F–m 图像斜率）
- **原理**：竖直悬挂已知质量 m 的物体，静止时弹簧测力计示数 F 即等于重力 G，可解出 g。进阶：以 m 为横轴、F 为纵轴作图，过原点直线的斜率 k 即为 g；图像法比逐组取平均更能减小随机误差。
- **器材**：弹簧测力计（5N 或 10N）、厨房电子秤（0.1g 或 1g）、不同质量重物 3–5 个、细线
- **步骤**：① 电子秤称量各重物质量（每个 3 次平均）；② 测力计竖直悬挂并校零；③ 挂重物待静止后读数；④ 依次更换重物记录 F 与 m；⑤ 逐组算 g 取平均，进阶用 F–m 拟合斜率。
- **注意事项**：使用前校零、不超量程；读数需竖直静止；电子秤水平去皮；质量梯度分布均匀。
- **误差来源**：刻度标定不准、弹簧老化；读数视差、晃动时急于读数；电子秤精度有限、分度值较大。
- **核心优势 / 适合场景**：原理最直接，可作为其他方案的对照验证实验 / 验证其他方案结果。

#### B1 水平抛体运动：测量初速度与验证独立性原理

- **配图**：/images/project-learning/experiments/新高二B1.webp
- **公式**：v₀ = x√(g/2h)，x² = (2v₀²/g)h
- **目标**：固定小球离开桌面的初速度，改变桌面高度，检验水平匀速与竖直自由落体是否相互独立。
- **原理**：竖直方向 h = ½gt²，水平方向 x = v₀t；消去 t 后可由落点距离与桌面高度求初速度；固定 v₀ 改变 h，x²-h 图像应接近过原点直线。
- **器材**：光滑斜面或硬纸板轨道、小钢球或玻璃弹珠、碳纸与白纸、卷尺、不同高度桌面或台阶。
- **步骤**：搭斜面使小球同一高度释放后水平飞出；地面铺白纸+碳纸记录落点；固定高度重复 5 次测 h 与 x；改变高度重复，比较 x² 与 h 关系。
- **数据处理要点**：固定高度求平均水平距离与标准差；画 x²-h 散点图拟合斜率 k = 2v₀²/g；图线不过原点时检查释放高度一致性、桌边水平度、落点测量基准。

#### B2 验证机械能守恒定律

- **配图**：/images/project-learning/experiments/新高二B2.webp
- **公式**：mgh = ½mv²，v² = 2gh
- **目标**：改变释放高度，测量底端速度，用 v²-h 图像判断重力势能减少量是否主要转化为动能。
- **原理**：摩擦、空气阻力与转动动能影响较小时，v² 与 h 近似成正比，斜率理论值 2g。
- **器材**：光滑斜面轨道、小车或小球、手机慢动作摄像、卷尺、量角器或高度标尺。
- **数据处理要点**：斜率小于 2g 时讨论摩擦、转动动能和测速误差。**页面提示优先进入在线实验室（/online-lab/mechanical-energy/）完成更完整的数据处理。**

#### B3 碰撞中的动量守恒

- **配图**：/images/project-learning/experiments/新高二B3.webp
- **公式**：m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′
- **目标**：用两球碰撞前后的水平飞行距离间接表示速度，比较碰前碰后总动量是否近似相等。
- **原理**：碰撞前后都从同一高度水平飞出，飞行时间相同，水平距离与水平速度成正比，可用 m·x 之和比较动量。
- **步骤**：称量 m₁、m₂；先测 m₁ 不碰撞时的 x₀；再放靶球碰撞，记录碰后 x₁′、x₂′，多次取平均。
- **数据处理要点**：比较 m₁x₀ 与 m₁x₁′ + m₂x₂′ 的相对偏差；规定正方向，反弹记负；偏差大时检查正碰、水平度与桌缘。

#### B4 弹簧振子：探究周期与质量的关系

- **配图**：/images/project-learning/experiments/新高二B4.webp
- **公式**：T = 2π√(m/k)，T² = (4π²/k)m
- **目标**：改变悬挂质量测周期，用 T²-m 图像求弹簧劲度系数并分析截距含义。
- **数据处理要点**：用斜率求 k；截距不为 0 时讨论弹簧自身质量、计时反应和振幅过大；每组质量至少重复 2 次。

#### B5 单摆探究：周期与摆长、摆角、质量的关系

- **配图**：/images/project-learning/experiments/新高二B5.webp
- **公式**：T = 2π√(L/g)
- **目标**：三组控制变量实验，判断单摆周期主要由摆长决定，观察小角度条件适用范围。
- **步骤**：实验 a 固定质量摆角改摆长（验证 T²-L 线性）；实验 b 固定摆长摆角改质量（周期应基本不变）；实验 c 固定摆长质量改摆角（大角度周期变化）；每组至少计时 20–30 次全振动。
- **数据处理要点**：实验 a 的 T²-L 斜率可反算 g；实验 b 重点写“是否在误差范围内相同”；实验 c 小角度通常取 10° 以内。

### H2：新高二图像法与守恒分析工作台（#grade-two-workbench）

五个数据处理模型（选择后填写原始数据，自动生成斜率、拟合图像、守恒偏差）：

1. **h-t² 图像法测 g**：h = ½gt²，拟合斜率 k 后 g = 2k。
2. **T²-L 图像法测 g**：T² = (4π²/g)L，g = 4π²/k。
3. **F-m 图像法测 g**：F = mg，拟合斜率即 g。
4. **弹簧振子 T²-m 图像**：T² = (4π²/k)m，斜率反推劲度系数 k。
5. **碰撞动量守恒对比表**：输入两物体碰撞前后速度，自动比较碰前/碰后总动量与平均相对偏差（动量条形图）。

### H1：DIS传感器实验：超声波追踪小车运动（eyebrow：PART 03 · DIS SENSOR LAB）

导语：本项目使用 ESP32 和 HC-SR04P 超声波传感器搭建数字化物理实验装置。它不要求先学复杂编程，而是从接线、烧录、采集数据开始，理解传感器如何把真实运动转换成可分析的图表。页首按钮直达 /project-learning/ultrasonic-lab/。

### 实验目标与原理

- **配图**：/images/project-learning/experiments/esp32-hc-sr04p-overview.webp（alt：ESP32 超声波传感器追踪小车运动实验示意图）
- **公式**：d = v声·Δt / 2（v声 ≈ 340 m/s，Δt 为超声波往返时间）
- **目标**：实时追踪运动小车位置，自动采集位移–时间数据，验证匀速与匀变速直线运动规律，绘制 x-t、v-t 图。
- **原理**：HC-SR04P 发射 40kHz 超声波脉冲并接收回波，测往返时间算距离；ESP32 每 50ms 测一次得位移–时间序列。x-t 为直线→匀速（斜率为 v）；x-t 为抛物线→匀变速，差分得 v-t 图，其斜率即加速度 a。

## 5. 超声波小车网页实验室 /project-learning/ultrasonic-lab/（工具页）

- **页面标题**：超声波小车网页实验室 | 育才物理创新实验室
- **Meta 描述**：通过浏览器 Web Serial 连接 ESP32 超声波装置，一键烧录采集程序，实时接收位移数据，自动绘制 x-t、v-t 图并拟合速度与加速度，支持导出 CSV 与截图。

### H1：超声波小车网页实验室（eyebrow：ULTRASONIC ONLINE LAB）

功能说明：数据线连接 ESP32 → 点「连接串口」→ 一键「烧录采集程序」（写入 MicroPython，无需 Arduino）→「开始记录」→ 推动或释放小车 → 网页实时接收 time_ms,distance_cm 并绘制 x-t、v-t 图，自动拟合速度或加速度。没有设备也可粘贴/载入示例数据。

### 页面功能结构

- **图表区**：位移–时间图（x-t）、速度–时间图（v-t，中心差分）两块 Canvas；可编辑数据表（修改时间/位移后图表与拟合即时更新，可增删行）。
- **控制区**：运动类型选择（匀速求 v / 匀变速求 a）；数据点计数与最新距离读数；拟合结果（含拟合方程与 R²）；按钮组：连接串口 / 烧录采集程序 / 开始记录 / 清空数据 / 导出 CSV / 导出结果图片。
- **无设备模式**：粘贴已采集 CSV，或载入内置「匀速示例」「匀变速示例」数据。
- **兼容性提示**：页面顶部含 BrowserSupportNotice（浏览器不支持 Web Serial 时显示琥珀色横幅，建议电脑端 Chrome/Edge）。
- **数据处理细节**：以首个数据点为时间与位移零点；线性拟合用最小二乘法并输出 R²；v-t 由中心差分生成；导出 CSV 含表头注释（记录时间、拟合结果）。
