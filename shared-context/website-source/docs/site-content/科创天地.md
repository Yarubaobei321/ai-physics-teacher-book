## 2. 智能小车作品说明 /maker/smart-car/

- **页面标题**：三红外三循迹智能小车 · 作品介绍 | 科创天地
- **Meta 描述**：ESP32 + DRV8833 三红外三循迹智能小车作品介绍：从四大部分、信号流与供电、接线表、模式状态机、避障与循迹决策，到调试顺序和常见问题排查，让学生一页看懂整车工作原理。
- **OG 图**：/maker/smart-hardware/images/smart-car-build-02.webp
- **文档形态**：编号章节长文档（01–09），页首 hero + 快速参数 + 返回科创天地链接。

### Hero

标题：三红外三循迹智能小车（创新实验作品 · SMART CAR · ESP32 · DRV8833）。核心表述：“这台小车不是‘电机自己会跑’，而是 ESP32 一直在重复做四件事：读取传感器和按键 → 判断当前模式 → 算出左右轮速度 → 输出 PWM 控制电机。看懂这条链路，就看懂了整台车。”标签：源码 v3.2 / 环境 esp32dev / 串口 9600 / 低速平滑控制。快速参数：主控 ESP32 DevKit；驱动 DRV8833；传感器 3 避障 + 3 循迹；交互 3 按键 + 1 LED。

### 01 · 整体认识：小车由四个部分组成

大脑：ESP32（读 6 路传感器和 3 个按键，运行状态机，输出 PWM）；眼睛：避障与循迹（三路红外看前方障碍，三路 TCRT5000 看地面黑线）；腿：DRV8833 + TT 电机（PWM 驱动，差速转向）；提示：按键 + LED（三按键切模式，LED 闪烁次数表示模式）。

### 02 · 信号流与供电（#wiring，内嵌 SVG 信号流示意图）

SVG 图内容：三路红外避障（左36·中39·右34，有障碍=低电平）、三路 TCRT5000 循迹（左35·中32·右33，黑线=高电平）、三个模式按键（21 避障·22 循迹·23 手动）→ ESP32 大脑 → DRV8833（GPIO25/26 控左轮、GPIO27/14 控右轮）→ 左右电机；红线为电机电源（5V~6V→VM），灰线为公共地。

供电三条铁律：① VM 是电机电源，建议 5V~6V，不要把没稳压的高电压接到 ESP32；② ESP32 GND、DRV8833 GND、电机电源负极、所有传感器 GND 必须共地；③ STBY/SLEEP/EN 必须接高电平，否则程序再对电机也不转。

### 03 · 接线总表

DRV8833 与电机：GPIO25→AIN1（左轮 PWM1）、GPIO26→AIN2、GPIO27→BIN1（右轮 PWM1）、GPIO14→BIN2；AO1/AO2→左电机、BO1/BO2→右电机（方向反了交换两线）；VM→电机电源正极。传感器与按键：避障 36/39/34（有障碍=低）；循迹 35/32/33（黑线=高）；按键 21/22/23（按下接 GND）；状态 LED GPIO2。电源分两套：控制电路 3.3V/稳定 5V，电机电路 5V~6V，正极可分开、GND 必须连在一起。

### 04 · 状态机：三个按键切换三个“大脑模式”

四状态：停车/待机（LED 不闪）；避障模式（GPIO21，LED 每周期 1 闪）；循迹模式（GPIO22，2 闪）；手动模式（GPIO23，3 闪）。按键处理链：读取电平（松开=高，按下=低）→ 软件消抖（约 40ms）→ 生成事件（按下瞬间触发一次）→ 切换模式（先停车再进新状态）。要点：切换模式先停车，避免车轮继承旧速度。

### 05 · 决策逻辑

避障真值表（左/中/右 → 动作）：无无无→低速前进；有无无→向右偏；无无有→向左偏；无有无→原地转向找路；有有无→右转；无有有→左转；有有有→后退再转向。记忆口诀：前面没挡就走，左挡往右，右挡往左，三边都挡先后退。

循迹真值表（左/中/右 → 动作）：白黑白→沿线直行；黑黑白→小幅左转；黑白白→大幅左转；白黑黑→小幅右转；白白黑→大幅右转；黑黑黑→慢速直行（宽线或交叉口）；白白白→按最近方向搜索。原则：看到线在哪，就往哪修正。

### 06 · 平滑控制

决策层与电机层分离：决策层给目标速度，电机层每 30ms 把当前速度向目标靠近 8（MOTOR_RAMP_INTERVAL_MS=30，MOTOR_RAMP_STEP=8），如 0→8→16→…→160，减少猛冲和抖动。

### 07 · 调试：串口监视器与课堂测试顺序

串口 9600，每秒输出一行中文状态（模式/避障电平/循迹电平/动作/当前与目标速度）。排查顺序：模式对不对 → 传感器对不对 → 动作对不对 → 速度对不对。课堂测试四步：架空车轮 → 测试避障（手挡左中右）→ 测试循迹（黑线放左中右模块下）→ 低速落地。

### 08 · 排查：常见问题速查表

电机完全不转→查 VM 供电、共地、STBY/SLEEP/EN；低速只响不转→TT 电机启动扭矩不足，保留起步冲量；串口状态与实际相反→查 OBSTACLE_ACTIVE_LOW / LINE_ACTIVE_LOW；循迹左右反了→查传感器或电机接反；一动就重启→电源电流不足或电机噪声，供电要稳且必须共地。

### 09 · 自检（6 个 Q&A 折叠卡）

为什么按键按下读到低电平（上拉输入）；为什么避障低电平触发而循迹高电平触发（模块比较器设计不同，用串口实测确认有效电平）；为什么切模式前先停车；为什么左循迹见黑线要左转（车身偏右，黑线在左侧）；为什么电机不转不能只怀疑程序（VM/共地/使能/接线）；为什么调车先架空车轮（首次上电方向速度逻辑都可能反）。

一句话总结：这台车的核心不是某一行代码，而是一条完整的控制链——传感器电平 → 程序判断状态 → 状态机选择动作 → 左右轮 PWM → 小车运动。

## 3. 火星车作品说明 /maker/mars-rover/

- **页面标题**：尘光一号火星车 · 作品介绍 | 科创天地
- **Meta 描述**：尘光一号火星车作品介绍：基于双 ESP32 的火星基地新能源智能巡检车，讲清运动安全 A 板与能源环境 B 板的分工、Web Bluetooth 网页地面站协议、电池+太阳能追光除尘能源闭环、搭建阶段路线图与比赛演示流程。
- **OG 图**：/maker/smart-hardware/images/mars-rover-01.webp
- **文档形态**：编号章节长文档（01–09）。

### Hero 与整车展示

标题：尘光一号火星车（创新实验作品 · MARS ROVER · 双 ESP32 · Web Bluetooth）。定位語：一台模拟未来火星基地的新能源智能巡检车，把网页、蓝牙通信、双控制板、电机驱动、姿态安全和太阳能能源管理放进同一条任务链——最适合用来讲“系统集成”。标签：文档 v0.1.0 / 双 ESP32 架构 / 六轮编码底盘 / 网页蓝牙地面站。快速参数：主控 双 ESP32；底盘 六轮编码电机；通信 Web Bluetooth；能源 太阳能 + 追光除尘。

- **整车图**：/maker/smart-hardware/images/mars-rover-01.webp（图注：尘光一号 · AI 智能火星探索车（概念渲染图，仅供参考））

### 01 · 项目定位：不是“纯太阳能开车”，而是一套能源闭环

四步能源闭环：电池稳定供电（7.4V 2S 主电池）→ 太阳能持续补能（12V 板经 CN3791 MPPT）→ 追光提高效率（4 路光敏 + 2 舵机对准光源）→ 除尘恢复效率（积尘功率下降，风扇除尘后回升，形成闭环）。

### 02 · 总体架构：双 ESP32，一个管“跑得稳”，一个管“看得清”

- **ESP32-A 运动与安全主控**：控制 6 个 TT 编码电机、3 块 TB6612FNG；读左右代表轮编码器做轮速检测与直线修正；读五路循迹、前方避障、坑洞检测、MPU6050 姿态；接收 2.4G 八通道遥控（手动/自动/急停）；所有运动与安全的最终裁决都在 A 板。
- **ESP32-B 能源环境与展示主控**：读 PMS5003T 粉尘温湿度、BMP280 气压、BH1750 光照；读 INA219 太阳能电压电流功率与电池电压；读 TCRT5000 积尘、4 路光敏；控制 2 舵机二维追光、5V 风扇除尘、TFT 显示；建立 BLE 网页地面站，UART 与 A 板通信。
- 内嵌 SVG 架构图：网页地面站 ←BLE→ ESP32-B ←UART→ ESP32-A →（3×TB6612 六轮差速电机 / 安全传感器 VL53L0X·MPU6050）。图注：网页命令不直接控制电机，最后由 A 板按安全规则决定是否执行。

### 03 · 实现状态（工程诚信表：已实现 / 骨架占位 / 规划中）

已实现：双 ESP32 心跳 + UART 双向通信；BLE 网关（广播/遥测通知/命令转发）；网页地面站（遥测/控制/CSV/演示/日志）；命令急停 / SAFE 默认态 / 超时失联停车；风扇+追光器状态回传（仅状态）。骨架占位：电机驱动（虚拟 PWM 日志，不驱动真电机）；电池/太阳能/PM2.5 数据（固件现报 0，演示数据由网页提供）；避障/坑洞/姿态安全字段（协议在，未接入裁决）；风扇除尘/追光执行（只改状态位）。规划中：物理急停/低电量保护/编码器测速；2.4G 接管/自动循迹/防侧翻；太阳能追光执行/TFT 显示/Wi-Fi 服务。页面强调：对外展示与答辩只宣称“已实现”项。

### 04 · 硬件清单

底盘运动：六轮越野底盘×1；TT 霍尔编码减速电机×6（1:90）；TB6612FNG×3；五路数字循迹×1；2.4G 八通道串口遥控×1。安全与地形：MPU6050×1（坡度/侧倾/防侧翻）；VL53L0X×2（前方避障+坑洞）；蜂鸣器/报警 LED×1。环境与能源：PMS5003T×1；BMP280/BH1750 各 1；INA219×1；TCRT5000/光敏 LDR 1-2/4；12V3W 太阳能板+CN3791；SG90/MG90S 舵机×2 + 5015 风扇×1。电源安全警示：7.4V 2S 主电池+两路 5V 降压；电机舵机风扇不从 ESP32 取电；所有 GND 共地；机械大电流总开关；不要同时用平衡充电器和 CN3791 充同一电池。

### 05 · 安全保护

地形风险识别（五路循迹模拟巡检路线；两个 VL53L0X 分别朝正前方与前下方识别岩石与坑洞）。姿态阈值（MPU6050 Roll）：正常 <15°；警告 15°–25°；危险 25°–35°；急停 >35°。裁决原则：安全逻辑最终裁决在 A 板，优先级高于循迹。

### 06 · 网页地面站协议

BLE 名称前缀 ESP32-rover。遥测包（B 板→网页）：ROVER,seq,ms,mode,estop,left_pwm,right_pwm,battery_v,solar_w,pm25,pitch,roll,obstacle,pit,fan,tracker。控制命令（网页→B 板）：CMD,seq,MODE,<MANUAL|AUTO|SAFE>；CMD,seq,DRIVE,forward,turn；CMD,seq,ESTOP,1；CMD,seq,CLEAR_ESTOP,1；CMD,seq,FAN,0|1；CMD,seq,TRACKER,0|1。命令链路：网页→B 板→A 板→电机驱动，A 板把关。

### 07 · 搭建路线（8 阶段）

阶段 1 主电源 → 2 双心跳通信 → 3 电机裸测 → 4 编码器 → 5 遥控急停 → 6 自动循迹 → 7 地形安全 → 8-9 能源闭环。原则：先让车能安全跑，再让车能自动跑，最后做能源环境与展示系统。

### 08 · 演示流程（火星基地新能源巡检任务，9 步）

开机连接 → 自检显示 → 自动巡检 → 遇障减速停止 → 坑洞停止报警 → 倾角防侧翻 → 模拟沙尘（PM2.5/积尘升高、功率下降）→ 风扇除尘+追光恢复功率 → 评委网页端看完整状态并演示急停与人工接管。

### 09 · 自检（6 个 Q&A）

为什么用双 ESP32；网页地面站为什么不能直接控制电机；为什么不是“纯太阳能开车”而是能源闭环；为什么安全裁决必须在 A 板；六轮底盘为什么需要编码器反馈；答辩为什么要如实区分“已实现、骨架占位、规划中”。

一句话总结：尘光一号的核心不是“网页能遥控”，而是一条完整的系统集成链——网页地面站 → B 板通信与能源环境 → A 板运动安全 → 电机与传感器执行。
