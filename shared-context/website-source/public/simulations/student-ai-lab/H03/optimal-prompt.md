一、主题与受众：面向高中历史的"中国历代制度变革"科普网页（夏至清）。学习目标：学生通过看上端时间轴总览、中部六时代板块的核心制度、下端朝代更迭总览，掌握主要制度的朝代归属及其对政治结构的影响。

二、史实模型规格（朝代-制度匹配须与统编教材逐条可考，不得错挂）：
- 朝代年代（教材级 ballpark）：夏约前 2070—前 1600、商约前 1600—前 1046、周前 1046—前 256、秦前 221—前 207、汉前 202—220、三国 220—280、晋 266—420、南北朝 420—589、隋 581—618、唐 618—907、五代十国 907—960、宋 960—1279、元 1271—1368、明 1368—1644、清 1636—1912。

- 改革人物不错配（页面若涉改革人物，商鞅=秦、王安石=北宋，不得张冠李戴）。
- 术语规范：皇帝制、三公九卿、郡县制、三省六部、科举制、二府三司、行省制、内阁、军机处、密折制；察举/科举/九品中正选官体系分代清晰。
