# C08 · 简单有机物球棍模型 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中化学（必修二）课堂的"简单有机物球棍模型"3D 交互搭建器。学习目标：学生通过一键生成预设分子球棍模型、自由加原子拖动成键，理解碳四价、单/双/三键键级、sp³ 正四面体构型（甲烷键角 109.5°）。

二、化学模型规格：
- 原子：C（深灰，最大）、H（白，最小）、O（红，中等）；共价半径比例 C:H:O ≈ 0.77:0.37:0.66 Å（球径按此比例）。
- 价键限制 maxBonds：C=4、H=1、O=2；C–C 最多 3 键、C–O 最多 2 键、O–H 1 键。**单键画一根圆柱、双键画两根平行圆柱、三键画三根平行圆柱**——双键/三键不得画成单圆柱。
- 五个预设分子的精确构型（必须严格按以下坐标/键数实现）：
  · 甲烷 CH₄（1C+4H）：4 个 H 必须放在正四面体顶点，可用方向向量 (±1,±1,±1) 归一化后乘键长，保证任意两个 H-C-H 键角均 ≈ 109.5°（**不得是平面十字或近乎共面，键角不得为 73°/131°**）；
  · 乙烷 C₂H₆（2C+6H）：C–C 单键，每个 C 的 3H + 1C 按 sp³ 四面体方向；
  · 丙烷 C₃H₈（3C+8H）：C–C–C 链，端 C 各 3H、中 C 2H；
  · 乙醇 C₂H₅OH（2C+6H+1O）：C–C–O + O–H，O 二价；
  · 乙醛 CH₃CHO（2C+4H+1O）：CH₃–CHO，醛基 C=O **必须画两根平行圆柱**（双键），O 连 1 C(双键)=2 价。
- 每个预设分子切换后，页面必须显著列出其分子式，方便学生数 C/H/O 原子核对碳四价。

三、交互与教学功能：左侧 C/H/O 三个原子按钮（点击在画面中央生成原子）；中键（滚轮）成键、点击两原子手动成键（支持双键/三键，按 maxBonds 与 C–C≤3/C–O≤2 限制）；右键原子/键删除；右侧预设分子按钮（甲烷/乙烷/乙醇/乙醛/丙烷）一键生成；"清除全部"按钮；OrbitControls 旋转缩放、DragControls 拖动原子；原子图例放侧边不遮挡中央视图；状态栏显示当前选中原子数/键数。

四、工程与呈现约束：深色毛玻璃 + 圆角胶囊按钮课堂版；1440×900 分辨率下无遮挡、无溢出；全部使用真实 <button>（≥0.8rem）；3D WebGL canvas 加 aria-label；OrbitControls 构造器传入 renderer.domElement 不得抛 TypeError；@media 700px 响应式断点。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. **甲烷正四面体（核心 B1 warning 规避）**：点击预设"甲烷"，4 个 H 必须放在正四面体顶点（方向 (±1,±1,±1) 归一化×键长），任意两个 H-C-H 键角均应 ≈ 109.5°（允许 ±2°），**不得出现 73° 或 131° 或近乎共面的键角**；
2. **乙醛 C=O 双键（B1 规避）**：点击预设"乙醛"，醛基 C=O 必须画两根平行圆柱（双键），碳视觉仍满四价（CH₃ 碳 3H+1C=4 价；醛基碳 1H+1C+1O(双键)=4 价）；
3. **分子式原子计数核对（核心验收）**：切换每个预设后数 C/H/O——甲烷 1C+4H、乙烷 2C+6H、丙烷 3C+8H、乙醇 2C+6H+1O、乙醛 2C+4H+1O，与页面分子式一致；每个原子均满足价键限制（C=4、H=1、O=2）；
4. **双键/三键画法**：自由搭建时手动成双键必须画两根平行圆柱；乙烷/丙烷的 C–C 单键只画一根；
5. **搭建交互**：点 C/H/O 按钮各加 1 个原子；中键/滚轮成键（或点击两原子）能在两原子间生成共价键；右键能删除原子/键；清除全部后场景为空且原子所带标签同步删除（不得残留图标）；
6. **价键限制**：尝试给 H 加第二键、给 O 加第三键、给 C 加第五键应被拒绝（不得超价）；
7. 交互完整性：3 原子按钮 + 5 预设分子按钮 + 清除全部共 9 控件各操作一次，OrbitControls 旋转缩放与 DragControls 拖动均可用，无 console 报错（仅有 WebGL ReadPixels 性能 warning 可接受）；3D canvas 有 aria-label。
