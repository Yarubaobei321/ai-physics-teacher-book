# P20 · 抛体运动模型 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"抛体运动"交互仿真，支持无阻力与线性空气阻力两种模式对照。学习目标：学生通过对照两种模式的轨迹与速度读数，理解空气阻力对抛体运动的影响。

二、物理模型规格：以抛出点为原点，x 轴水平向右为正、y 轴竖直向上为正；无阻力模式：x=v₀cosθ·t、y=v₀sinθ·t−½gt²；阻力模式：阻力 F=−kv（方向与速度相反，分量 Fx=−kvₓ、Fy=−kv_y），用数值积分求解，时间步长足够小保证平滑；g=9.8 m/s²；页面显式声明坐标正方向与模型假设；SI 单位。

三、交互与教学功能：v₀（5–30 m/s）、θ（15°–75°）、k（0–0.5 kg/s，k=0 即无阻力）滑块；发射/暂停/重置；轨迹绘制，且无阻力理论轨迹以虚线叠加对照；飞行全程实时显示 t、x、y、vₓ、v_y、合速度 v（带单位，读数必须随动画每帧更新）；落地后显示射程与飞行时间；数据记录表；页面设"观察与结论"区。

四、工程与呈现约束：布局分"画布区／控制区／数据区"；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. k=0、θ=45°、v₀=15 m/s：手算最大高度 H=(v₀sinθ)²/(2g)≈5.74 m、射程 R=v₀²sin2θ/g≈22.96 m，与页面读数对比；
2. k=0 时飞行全程 vₓ 读数恒等于 v₀cosθ≈10.6 m/s；
3. k=0.2 时飞行全程盯住 v_y 读数：必须逐帧连续变化（不得冻结在某一值），且射程明显小于 22.96 m；
4. k=0 时数值轨迹与理论虚线重合；
5. 极端参数（θ=15°/75°、v₀=5/30）画面不溢出，所有控件各操作一次无报错。
