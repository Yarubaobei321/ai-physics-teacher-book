观察与结论

观察：调节 k 从 0 增大到非零值，轨迹变得不对称——上升段更陡、下降段更缓，射程和最大高度均减小。

结论：空气阻力始终与速度方向相反，持续做负功，使抛体动能不断耗散。k 越大，射程缩短越显著，飞行时间也越短。对比两条轨迹可直观理解理想模型与实际运动的差异。
