# B04 · DNA的复制 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中必修二课堂的"DNA 的复制"交互演示。学习目标：学生通过分步推进复制过程、读 5'/3' 方向与碱基配对、数子代分子，能说出 DNA 半保留复制的方式（解旋→碱基互补配对→合成子链）、方向（新链 5'→3'）与结果（1 个 DNA→2 个子代 DNA，各含一条母链一条新链）。

二、生物模型规格：以一段双链 DNA 为对象（双螺旋形态）；复制叉处解旋酶打开双链、DNA 聚合酶按碱基互补配对 A-T、G-C（DNA 层面，不得出现 A-U）合成新链；明确标注新链方向 5'→3'、模板链方向 3'→5'（在链端标 5'/3'）；区分前导链（连续合成）与后随链（以冈崎片段不连续合成），两者方向相反但合成方向均为 5'→3'；保留人教版高中所需的 RNA 引物、DNA 连接酶等命名（命名规范即可，不必展开超纲机制）；终局展示两个子代 DNA 双螺旋，每个子代 DNA 各含一条亲代链（母链）+ 一条新合成链，体现半保留复制；氢键数标注 A=T 两键、G≡C 三键；不得做成 RNA 复制。

三、交互与教学功能：分步按钮流程——重置→解旋酶（解旋）→DNA 聚合酶（合成），每步切换阶段状态并在状态讲解区说明当前事件；侧栏核心知识库（解旋酶、DNA 聚合酶、碱基配对 A-T/G-C、半保留、前导/后随链、冈崎片段、RNA 引物、连接酶）；底部概念卡；碱基配对表（A-T、T-A、G-C、C-G）；配子/新链合成过程中明显标注掺入位点的互补碱基。

四、工程与呈现约束：双栏布局清晰，碱基彩色区分；1440×900 分辨率下无遮挡、无溢出；控件为真实 <button>、带可见文字标签且不小于 0.8rem；canvas 加 aria-label 描述复制叉、前导/后随链、冈崎片段等场景；侧栏文字层级分明。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 任取一段亲代序列（如上链 5'-ATGC-3'），逐位核对新链碱基与模板互补：模板 A→新 T、T→A、G→C、C→G，不得出现 A-U（DNA 层面）；
2. 点击"解旋酶"后再点"DNA 聚合酶"，页面应进入"合成前导链与后随链冈崎片段"阶段，并显示前导链连续、后随链分段；
3. 完成一次复制后，页面应显示 2 个子代 DNA 双螺旋，每个都保留一条母链＋一条新链（半保留，不得全旧或全新）；
4. 链端可见 5'/3' 方向标注，新链合成方向标为 5'→3'、模板链为 3'→5'；
5. 氢键数：A=T 标 2 键、G≡C 标 3 键；
6. 重置/解旋酶/DNA 聚合酶三按钮各点击一次，无报错、无失效；阶段切换时讲解区文字同步更新；页面无"RNA 的复制"模块（仅可有 RNA 引物说明）。
