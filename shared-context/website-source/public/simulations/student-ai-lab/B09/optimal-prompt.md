# B09 · 呼吸作用 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中生物课堂的"细胞呼吸"交互讲学。学习目标：通过生活现象导入、有氧呼吸三阶段递进展示、有氧/无氧对比、限制因素变量实验与练习，掌握有氧呼吸各阶段场所与产物、无氧呼吸两类产物的区别。

二、生物模型规格：有氧呼吸三阶段场所与产物必须严格如下（按高中教材口径，使用"三羧酸循环"而非"克雷伯氏循环"等别称）：
- 第一阶段糖酵解：场所细胞质基质，1 葡萄糖 → 2 丙酮酸 + [H] + 少量 ATP（净 2 ATP）；
- 第二阶段三羧酸循环：场所线粒体基质，丙酮酸 → CO₂ + [H] + 少量 ATP；
- 第三阶段氧化磷酸化：场所线粒体内膜，[H] + O₂ → H₂O + 大量 ATP。
总反应式 C₆H₁₂O₆ + 6O₂ + 6H₂O → 6CO₂ + 12H₂O + 能量（需配平）。无氧呼吸分两类：动物肌肉细胞缺氧 → 乳酸（不产 CO₂）；酵母菌无氧呼吸 → 酒精 + CO₂。场所：糖酵解在细胞质基质，无氧呼吸全过程均在细胞质基质。

三、交互与教学功能：①生活现象导入（如长跑后肌肉酸痛、发面、酿酒）；②有氧呼吸递进分步按钮（不一次性堆砌全部流程，由简到难），每步显示当前阶段场所、反应物与产物，可暂停/重置；③有氧/无氧对比模块，区分乳酸发酵与酒精+CO₂ 发酵的对象；④限制因素变量实验：学生可选择自变量（温度/氧气浓度/CO₂ 浓度之一）、设置对照，图表显示因变量（呼吸速率相对值）随自变量的定性变化趋势；⑤图表必须含标题、坐标轴名、图例与结论文字；切换每个限制因素后标题、坐标、结论同步更新；⑥5 题闯关练习，答对≥3 题显示鼓励，错题给解析与正确答案。

四、工程与呈现约束：布局分"导入/三阶段流程区／实验与图表区／练习区"多层卡片；1440×900 分辨率下无遮挡、无溢出；所有控件为真实 button、有可见文字标签；canvas 图表与状态变化除颜色外还要有文字标签（不只用颜色传递状态）；canvas 提供 aria-label。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 逐个点击有氧三阶段按钮，对应文字必须分别显示"糖酵解—细胞质基质""三羧酸循环—线粒体基质""氧化磷酸化—线粒体内膜"，不得出现场所张冠李戴；
2. 术语统一：页面全程使用"三羧酸循环"，不得出现"克雷伯氏循环"或别称作为主术语；
3. 无氧呼吸题：若问"人体剧烈运动缺氧时产物"，标答为乳酸（无 CO₂）；若问"酵母菌无氧呼吸产物"，标答为酒精和 CO₂——两类对象产物不可混淆；
4. 总反应式核对：C₆H₁₂O₆ + 6O₂ + 6H₂O → 6CO₂ + 12H₂O + 能量，反应物侧与产物侧 C/H/O 原子守恒；
5. 切换每个限制因素（温度、O₂、CO₂）图表后，标题、坐标轴名、图例与结论文字全部同步更换（不残留上一变量的内容）；
