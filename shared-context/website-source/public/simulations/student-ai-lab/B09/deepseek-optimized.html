🏃 生活现象导入

😮‍💨 长跑后肌肉酸痛

剧烈运动时供氧不足，肌肉细胞进行无氧呼吸产生乳酸。

🍞 发面

酵母菌无氧呼吸产生酒精和 CO₂，CO₂ 使面团膨松。

🍺 酿酒

酵母菌在缺氧条件下把葡萄糖转化为酒精和 CO₂。

🧮 有氧呼吸总反应式

C₆H₁₂O₆ + 6O₂ + 6H₂O → 6CO₂ + 12H₂O + 能量

配平检查：C：左侧 6 = 右侧 6；H：左侧 12+12=24 = 右侧 12×2=24；O：左侧 6+12+6=24 = 右侧 6×2+12=24。反应物侧与产物侧 C/H/O 原子守恒。

⚖️ 有氧 / 无氧对比

类型场所产物
有氧呼吸细胞质基质 → 线粒体基质 → 线粒体内膜CO₂ + H₂O + 大量能量
无氧呼吸（动物肌肉细胞）全程细胞质基质乳酸（不产 CO₂）
无氧呼吸（酵母菌）全程细胞质基质酒精 + CO₂

⚠️ 区分记忆：动物肌肉无氧→乳酸，酵母菌无氧→酒精+CO₂，二者不可混淆。
