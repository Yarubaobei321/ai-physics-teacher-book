# P10 · 导数表示动能、动量关系 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中（选学导数）或高三复习课的"动能与动量关系"可视化页。学习目标：学生通过拖动 Ek–p 曲线上的切点，发现切线斜率恰好等于速度 v，理解 Ek=p²/(2m) 与 dEk/dp=p/m=v。

二、物理模型规格：Ek=p²/(2m)，dEk/dp=p/m=v；改变 m 时曲线整体更新；碰撞实例采用一维弹性碰撞（公式同标准弹性碰撞）；SI 单位。

三、交互与教学功能：三个联动区——① Ek–p 抛物线图像，切点可拖动，实时画出切线并显示斜率数值；② 读数面板：当前 m、p、v、Ek（带单位），四个量必须同源互洽；③ 碰撞实例区：两球一维弹性碰撞，碰前碰后各球的 (p, Ek) 点标注在曲线上，动画演示碰撞过程；质量滑块 m（0.5–5 kg）；页面设"观察与结论"区（引导写出斜率的物理意义）。

四、工程与呈现约束：三区布局清晰；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. m=2 kg、拖切点至 p=6 kg·m/s：手算 Ek=9 J、切线斜率=3 m/s，且读数面板 v=3 m/s，与显示对比；
2. 读数面板四量互洽：用 p²/(2m) 与 ½mv² 两条路手算 Ek 应相同；
3. m 改为 1 kg：同 p=6 下 Ek 变为 18 J（曲线变陡）；
4. 碰撞实例：碰前碰后 Σp 相等，且四个标注点都落在对应质量的曲线上；
5. 所有控件各操作一次，无报错、无失效。
