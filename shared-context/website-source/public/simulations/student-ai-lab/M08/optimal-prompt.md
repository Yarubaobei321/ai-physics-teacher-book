# M08 · 立体模型 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中数学课堂的「立体模型」交互学习页。学习目标：学生通过输入棱长、切换立体类型、观察 3D 多角度视图、应用内切球/外接球、用坐标平面切割，掌握正方体/长方体/正四面体等常见立体的体积 V、表面积 S 与体对角线公式。

二、数学模型规格：核心公式——正方体（棱长 a）：V=a³、S=6a²、体对角线 d=√3·a、外接球半径 R_外=√3·a/2、内切球半径 r_内=a/2；长方体（a×b×c）：V=abc、S=2(ab+bc+ca)、体对角线 d=√(a²+b²+c²)、外接球半径 R_外=√(a²+b²+c²)/2；棱长输入范围 a,b,c∈[0.5, 10]，单位统一标注（如「单位长度」）；空间坐标系 O-xyz，切割平面用坐标参数（如 x=k、y=k、z=k，k∈[−10,10]）表示并显隐控制；术语必须严格使用「内切球」「外接球」，不得用平面几何的「内接圆/外接圆」称呼立体。所有量纲一致并标注。

三、交互与教学功能：左栏讲解各类立体的 V/S/体对角线公式与推导；右栏 3D 视图支持鼠标拖拽旋转多角度观察；控制区含棱长输入框（实时更新体积、表面积、体对角线读数）、立体类型切换（正方体/长方体）、内切球/外接球显隐切换、坐标平面切割（输入坐标参数 x=k/y=k/z=k 后显示截面）；每次改尺寸或切换类型，体积/表面积/体对角线/球半径读数实时同步；底部设「观察与结论」区引导归纳体对角线与棱长的关系。

四、工程与呈现约束：布局分「讲解区／3D 画布区／控制与读数区」三栏，1440×900 分辨率下无遮挡、无溢出；3D 渲染用纯 CSS 3D transform 或内联 Canvas/Three.js（须打包进单文件，不得外链 CDN）；所有输入框、按钮、滑块有可见中文标签；3D 画布加 aria-label 描述当前立体类型与棱长；切割平面与嵌套显隐用真实 <button>，不得用 div 当按钮。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 取正方体棱长 a=2：手算 V=2³=8、S=6×2²=24、体对角线 d=√3×2≈3.46、外接球半径 R_外=√3×2/2≈1.73、内切球半径 r_内=2/2=1，与页面读数逐项对比；
2. 取长方体 a=3,b=4,c=5：手算 V=3×4×5=60、S=2(3×4+4×5+3×5)=2(12+20+15)=94、体对角线 d=√(9+16+25)=√50≈7.07，与页面读数对比；
3. 切换立体类型并改棱长，体积/表面积/体对角线/球半径读数须实时同步联动，无延迟或残留旧值；
4. 页面术语必须为「内切球」「外接球」，全文检索不得出现「内接圆」「外接圆」（验证 B1 warning 已规避）；
5. 坐标平面切割输入 x=k（如 x=1）后，截面在 3D 视图中显隐正确，且切割参数在坐标系内可读；
6. 棱长输入框、立体切换、内切球/外接球切换、切割输入、3D 拖拽旋转各操作一次，无 console 报错、无失效。
