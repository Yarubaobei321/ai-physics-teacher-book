守恒说明

为什么"拉起 1 球，摆出 2 球（各以半速）"不会发生？
假设：1 球以速度 v 撞入 → 2 球各以 v/2 摆出
动量：入 = m·v；出 = 2m·(v/2) = m·v → ✓ 守恒
动能：入 = ½mv²；出 = 2·½m(v/2)² = ¼mv² → ✗ 损失 50%，违反守恒！
正确：1 球以速度 v 撞入 → 1 球以速度 v 摆出
动量：入 = m·v；出 = m·v → ✓ 守恒
动能：入 = ½mv²；出 = ½mv² → ✓ 守恒
结论：动量与动能必须同时守恒。唯一解是"拉 n 出 n，速度不变"。
