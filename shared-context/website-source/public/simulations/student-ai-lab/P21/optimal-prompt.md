# P21 · 牛顿摆 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"牛顿摆"交互仿真。学习目标：学生通过改变拉起球数并观察摆出结果，理解"动量与动能同时守恒决定了拉起 n 个必然摆出 n 个"。

二、物理模型规格：5 个等质量钢球（每球 m=0.1 kg）悬挂成列；理想模式：碰撞为完全弹性、忽略空气阻力与摆线损耗（页面显式声明）；拉起球从高度 h 释放，到达底部速度 v=√(2gh)；碰撞通过球列传递，另一侧摆出球数与速度满足动量、动能同时守恒；g=9.8 m/s²；SI 单位。

三、交互与教学功能：拉起球数选择（1–4）；释放高度 h（0.02–0.10 m）滑块；播放/暂停/重置；实时显示底部碰撞前后系统水平动量与动能读数；"守恒说明"面板：解释为何"拉 1 出 2（各半速）"满足动量守恒却违反动能守恒，所以不会发生；页面设"观察与结论"区。

四、工程与呈现约束：布局分"画布区／控制区／说明区"；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 拉起 1 球、h=0.05 m：手算底部 v=√(2×9.8×0.05)≈0.99 m/s，与碰撞前读数对比；另一侧应且仅应摆出 1 球，上升高度接近 0.05 m（理想模式偏差 <2%）；
2. 拉起 2 球：另一侧摆出 2 球，等高；
3. 碰撞前后水平动量读数一致（同一手算值 0.1×0.99≈0.099 kg·m/s，1 球情形）；
4. 连续摆动 5 个周期，理想模式下摆幅不衰减；
5. 所有控件各操作一次，无报错、无失效。
