📝 观察与结论

  • 动量守恒的普适性：无论碰撞类型如何，只要系统不受外力，系统总动量 Σp 全程守恒（过程曲线中为水平直线）。
  • 弹性碰撞：动量和动能同时守恒；碰撞后两球分离，末态 ΣEk = 初态 ΣEk。
  • 完全非弹性碰撞：动量守恒但动能不守恒；碰撞后两球共速运动，部分动能转化为内能。
  • 弹簧缓冲模型（核心）：压缩最大时刻，两球共速 v共 = (m₁v₁+m₂v₂)/(m₁+m₂)；此时动能暂时减少的部分全部转化为弹性势能 Ep；弹簧恢复后等效于弹性碰撞，Ep 归零，两球分离。
  • 能量转化视角：弹簧模型清晰展示了 "动能 → 弹性势能 → 动能" 的连续转化过程，说明弹性碰撞并非"瞬间"完成，而是经历了一个有限时间的相互作用过程。
  • 关键公式：Σp = m₁v₁ + m₂v₂ = 常量；Ek = ½mv²；Ep = ½k·(Δx)²；v共 = Σp / (m₁+m₂)。
