📖 动量守恒定律 · 详细解析

定律表述：对于一个不受外力（或合外力为零）的系统，系统总动量保持不变。

∑mᵢvᵢ = 常矢量   →   m₁v₁ + m₂v₂ + m₃v₃ = m₁v₁' + m₂v₂' + m₃v₃'

碰撞过程：两球之间发生完全弹性碰撞（e=1）或非弹性碰撞（0≤e<1）。恢复系数 e = |分离速度| / |接近速度|。

一维碰撞速度公式：对于两个小球 i 和 j，碰撞后的速度由下式给出（基于动量守恒和恢复系数定义）：

vᵢ' = [mᵢvᵢ + mⱼvⱼ + mⱼ·e·(vⱼ - vᵢ)] / (mᵢ+mⱼ)
vⱼ' = [mᵢvᵢ + mⱼvⱼ + mᵢ·e·(vᵢ - vⱼ)] / (mᵢ+mⱼ)

实验原理：本实验模拟三个小球在光滑水平轨道上的一维运动。系统水平方向不受外力，总动量守恒。通过调整质量、初速度和恢复系数，观察碰撞前后总动量的数值不变性，验证动量守恒定律。采用刚性分离算法确保小球在任何情况下绝不重叠，完全符合真实物理接触法则。
