📖 动量守恒定律

系统不受外力或合外力为零时，总动量保持不变。

m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'   (常量)

🧪 碰撞速度公式 (弹性/非弹性)

v₁' = [m₁v₁ + m₂v₂ + m₂·e·(v₂ - v₁)] / (m₁+m₂)
v₂' = [m₁v₁ + m₂v₂ + m₁·e·(v₁ - v₂)] / (m₁+m₂)
