# E01 · 语法 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中英语课堂的"英语语法专项练"互动网页。学习目标：学生通过卡牌讲解、点击弹窗（规则明细/易错考点/高考真题/解析）、专项练习（交后批改+错题解析）、综合诊断（含约 50% 高考原题的柱状图薄弱分析与定向强化建议），掌握时态、语态、固定搭配、句子结构四大语法模块。

二、语法规则与例句规格（例句本身语法错=fail；时态卡高考真题必须测该卡时态，不得测相邻时态；讲法取舍属"不判错区"不判错）：
- 时态构成陈述须正确：一般现在时（三单加 s/es）、一般过去时（动词过去式）、一般将来时（will+动原 / be going to+动原）、现在进行时（am/is/are+doing）、过去进行时（was/were+doing）、现在完成时（have/has+过去分词）。
- 被动语态构成须正确：be+过去分词；am/is/are done、was/were done、will be done、have/has been done；含特殊被动：need/want/require doing = need to be done、be worth doing（主动表被动）。
- 固定搭配：to 为介词的 doing 类（look forward to doing、be/get used to doing）、形容词+介词搭配；句子结构：简单句/并列句（连词）/状语从句/定语从句/名词性从句；主将从现。
- 时态知识卡的高考真题**必须体现该卡所授时态**（核心 B1 规避）：一般现在时卡的真题答案须为一般现在时（不得是 will check 这类一般将来时）；现在完成时卡的真题答案须为现在完成时（不得是 have been cleaning 这类现在完成进行时）。如该真题答不能体现该卡时态，须替换为可体现的真题或改挂到对应时态卡。
- 术语规范：时态/语态/非谓语（不定式/过去分词/动名词）、句子结构成分（主/谓/宾/表/定/状/补）、主将从现、部分倒装——不混淆。

三、交互与教学功能：①时态模块（5 张卡：用法+标志词+例句，点击弹窗展开规则明细/易错考点/高考真题+解析）；②语态模块（主动/被动+need doing、be worth doing 等主动表被动）；③固定搭配模块（to 为介词的 doing 类、形容词+介词）；④句子结构模块（简单句/并列句/状语从句/定语从句/名词性从句）；⑤每模块附专项练习（≥3 题/模块，提交后自动批改并展示错题解析）；⑥综合诊断（10 题约 50% 高考原题，提交后生成薄弱点柱状图+定向练习推荐）；⑦错题本（自动收录、可重做）。

四、工程与呈现约束：布局分"标签切换（5 大模块）／卡牌网格+弹窗／专项练习+综合诊断图表"多层；1440×900 分辨率下无遮挡、无溢出；卡片化布局+语态色彩区分；含移动端 viewport meta 与 @media 适配；所有 tab、卡牌、radio、提交/重置按钮为真实 button/input，radio 不得靠隐藏取消键盘可达性，须有显式键盘路径；图表（柱状图）须提供文本替代（aria-label 或下方文字版数据）以降级，无外链字体/外链 JS 库（如须用图表，自写 canvas 或纯 div 柱图）。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 时态卡真题归属核对（核心 B1 fail→warning→规避）：逐张时态卡核对其挂载的高考真题答案是否真为该卡所授时态——一般现在时卡真题须为一般现在时（不得是"will check"）、现在完成时卡真题须为现在完成时（不得是"have been cleaning"）；若不符须替换或改挂；逐条报告每张卡真题答案与其时态的一致性；
2. 时态构成核对（B1 grammar-rule 规避）：抽 6 个时态（一般现在/一般过去/一般将来/现在进行/过去进行/现在完成）核对构成陈述——一般现在=动原/三单 s、现在进行=be+doing、现在完成=have/has+过去分词、将来=will/be going to+动原——无错；
3. 例句语法核对（核心 B1 规避）：通读全部英文例句（如 "She reads every morning."、"The window was broken by the boy."、"The book is worth reading."、"What he said is true."），语法、拼写均无误，且能说明对应规则；不得出现例句本身语法错误；
4. 答案-解析同源核对（核心 A4 补全 + B1 exercise-consistency）：对全部练习题（≥27 题）逐题核对正确选项确实正确、解析与答案一致——语态 Q2 take place 无被动、Q3 need doing=need to be watered；结构 Q2 together with 就近一致、Q3 Only+状语倒装、Q5 Seen 表被动；综合 Q3 混合虚拟、Q6 Not until 倒装、Q10 look forward to being given；同一规则在跨模块题中判定一致（如 reason why / reason for which 在综合 Q8 与结构 Q4 应判定一致）；
5. 批改得分核对（A4 补全）：实测"全部错答"应得 0/5（专项）或 3/10（综合），判分逻辑与所选答案挂钩正确；
6. 工程核对（B4 规避）：5 个 tab、18 张卡牌弹窗、5 组练习提交/批改/重置、综合诊断图表生成、模态关闭（按钮+点遮罩）各操作一次，0 console errors；图表含文本替代；radio 有键盘可达路径；无外链字体/外链 JS 库请求。
