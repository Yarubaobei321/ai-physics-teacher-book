# C06 · pH值与氢离子物质的量的计算 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中化学（必修一/必修二）的"pH 值与氢离子物质的量的相互计算"交互工具。学习目标：学生通过拖动 pH 标尺、双向联动输入 [H⁺] 与体积、看代入式公式演算过程，掌握 pH=−lg[H⁺]、[H⁺]=10^(−pH) mol/L、n(H⁺)=[H⁺]×V 三公式并能手算典型值。

二、化学模型规格（知识范围严格限必修一/必修二，**不含离子积、pOH、弱酸电离常数等超纲内容**）：
- pH 定义：pH = −lg[H⁺]，[H⁺] 单位 mol/L；
- 反算：[H⁺] = 10^(−pH) mol/L；
- 物质的量：n(H⁺) = [H⁺] × V，V 单位 L（mL 须先 ÷1000 换算成 L），n 单位 mol；
- pH 范围 0–14：pH<7 酸性（[H⁺]>10⁻⁷）、pH=7 中性（[H⁺]=10⁻⁷）、pH>7 碱性（[H⁺]<10⁻⁷）。
- 数值验收锚点（撰写者手算，AI 必须显示一致）：
  · pH=0 → [H⁺]=1 mol/L；pH=1 → [H⁺]=0.1 mol/L；pH=2 → [H⁺]=0.01 mol/L；pH=3 → [H⁺]=10⁻³ mol/L；pH=7 → [H⁺]=10⁻⁷ mol/L；pH=13 → [H⁺]=10⁻¹³ mol/L；
  · 反向：[H⁺]=0.01 mol/L → pH=2；[H⁺]=1×10⁻³ → pH=3；
  · 物质的量：[H⁺]=0.1 mol/L、V=50 mL=0.05 L → n(H⁺)=0.1×0.05=5×10⁻³ mol；
  · 强酸稀释规律：强酸稀释 10 倍，[H⁺] ÷10，pH +1（如 pH=2 稀释 10 倍 → pH=3）。

三、交互与教学功能：左侧 pH 色觉标尺（0–14，红→紫，可拖拽、可点击定位、方向键微调）；右侧 [H⁺] 输入框（支持 1e-7 / 0.001 / 1×10⁻³ 等科学计数法）与体积输入框（mL/L 单位切换），三量双向联动——改 pH 自动算 [H⁺]、改 [H⁺] 自动算 pH、改体积自动算 n(H⁺)；底部实时显示代入式公式演算过程（含数值代入，如 n(H⁺)=0.1 mol/L × 0.05 L = 5×10⁻³ mol）；7 个常用预设示例（如胃酸 pH≈1.5、纯水 pH=7、强酸示例等），点击预设后**仍可手动改 pH 重新计算**（不得锁定）；"互换/重置"按钮；3 张知识卡片显示三公式。

四、工程与呈现约束：排版整洁、术语规范（pH / [H⁺] / n(H⁺) / mol·L⁻¹ / mol）；720/500px 响应式断点；1440×900 分辨率下无遮挡、无溢出；使用真实 <button>、<input>；pH 标尺作为独立控件须有 aria 角色（slider）与 aria-label；移动端刻度字号 ≥0.7rem（≈11px）；0 输入应自动恢复（避免 lg0 无定义报错）。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. **pH→[H⁺] 公式核对（核心验收）**：输入 pH=1 应显示 [H⁺]=0.1 mol/L；pH=0 → [H⁺]=1 mol/L；pH=13 → [H⁺]=10⁻¹³ mol/L；pH=7 → [H⁺]=10⁻⁷ mol/L；
2. **[H⁺]→pH 反算（核心验收）**：输入 [H⁺]=0.01 mol/L 应显示 pH=2；[H⁺]=1×10⁻³ → pH=3；
3. **物质的量 n=cV 算例（核心验收）**：[H⁺]=0.1 mol/L、V=50 mL（自动换算 0.05 L）→ n(H⁺)=5×10⁻³ mol，底部代入式必须显示完整演算；
4. **强酸稀释规律**：pH=2 的强酸稀释 10 倍后 [H⁺] 应变为 0.001 mol/L、pH 应 +1 变为 3（隐含规律正确）；
5. **预设后可重填**：点击任一预设示例后，必须仍能手动修改 pH 输入并正常重新计算（不得锁定输入或无法清空）；
6. **0 输入容错**：输入 pH=0 或 [H⁺]=0 不得导致计算崩溃或 NaN，应自动恢复到合理值或提示；
7. 中性定义（B1 warning 规避）：pH=7 时标签必须为"中性"，pH=6.5 与 pH=7.5 不应宽松归为中性（容忍带不超过 ±0.05）；
8. 交互完整性：pH 输入、[H⁺] 输入（含科学计数法）、体积输入、mL/L 切换、互换/重置、7 个预设、标尺拖拽点击、方向键微调各操作一次，单位规范（mol/L 与 mol），无 console 报错。
