# L01 · 文言文特殊句式讲解 · 评审重构的最优提示词

一、主题与受众：面向高中语文的"文言文特殊句式"互动讲解网页。学习目标：学生通过看标准句式基准、读五大句式卡片、研习倒装句细分、做句式挑战 quiz，掌握判断句、被动句、省略句、固定句式与四大倒装句式的判定规则、标志词与翻译方法。

二、学科模型规格（句式判定规则、标志词、例句归类须正确；引文与课文原文须逐字一致；不得张冠李戴）：
- 标准句式基准：现代汉语"主—谓—宾"基本语序，作为对照基准。
- 五大特殊句式判定规则与标志词（标志词讲对，判定条件正确）：
  · 判断句：常见标志"……者……也""乃""则""非""即""皆"；翻译补"是"。例句须归类为判断句；
  · 被动句：主语是动作接受者；标志词"于""见""为""被"及"见……于……""为……所……"结构；
  · 省略句：主语/宾语/介词等成分省略；
  · 固定句式：如"何以……为""得无……乎""不亦……乎"等；
  · 倒装句四类（细分边界清楚，宾语前置≠状语后置≠定语后置≠主谓倒装）：
    - 宾语前置：疑问句中疑问代词作宾语前置，或否定句中代词作宾语前置，或用"之""是"提宾；
    - 状语后置：介宾短语"于/以……"放谓语后作补语，翻译时提前；
    - 定语后置：中心词＋"之"＋定语＋"者"，或"……者"结构；
    - 主谓倒装：主谓顺序对调，多用于感叹。
- 例句引文（与教材原文逐字一致，出处归篇正确，不混入错字）：陈胜者，阳城人也（《陈涉世家》）；臣诚恐见欺于王（《廉颇蔺相如列传》）；沛公安在 / 未之有也 / 何陋之有（宾语前置）；马之千里者（定语后置）；贤哉，回也 / 不亦说乎（主谓倒装）；战于长勺（状语后置，《曹刿论战》）；甚矣，汝之不惠（主谓倒装，《愚公移山》）。
- 不可混淆：宾语前置与状语后置判定条件不同，标志词不同，例句归类须正确；不得把状语后置句归为宾语前置，反之亦然。
- 不判错区声明：情感色彩与艺术效果评价差异不判错；本页只考句式判定规则与引文准确性。

三、交互与教学功能：①"标准句式基准"区（主谓宾对照）；②五大句式卡片（判断/被动/省略/固定），每卡含定义＋标志词＋带出处例句＋速记口诀＋"随机例句"按钮（点击切换本类其他例句）；③倒装句大板块，宾语前置/状语后置/定语后置/主谓倒装各自含判定条件＋例句＋**完整现代汉语翻译**（每条例句，包括随机池中的，都须给出完整翻译，不得只标句式名与标志）；④句式挑战 quiz：≥14 题，倒装细分四选项，作答后逐题正误反馈，**每题给出答案键与解析，解析须含"判定依据（命中哪条规则/标志词）＋句意翻译"**；⑤速记口诀可点击以 toast 浮现并停留足够时间（≥3 秒，字体≥1rem）；⑥每条例句旁设"对照原文"可点开入口，注明该句出自教材哪篇课文，便于核对。

四、工程与呈现约束：布局分"标准句式基准／五大句式卡片／倒装细分精讲／句式挑战"四区；1440×900 分辨率下无遮挡、无溢出、文字不拥挤；冷色调统一、卡片留白充足；含响应式断点（max-width:750px）；正文字号≥0.9rem，速记口诀≥1rem；用系统字体栈，不外链远程字体；所有按钮（卡片切换、随机例句、倒装细分、quiz 选项、速记口诀、随机抽题、对照原文）为真实 button 含 aria-label，可 Tab 到达、回车触发；toast 浮现有 role="status" 供读屏读取。
