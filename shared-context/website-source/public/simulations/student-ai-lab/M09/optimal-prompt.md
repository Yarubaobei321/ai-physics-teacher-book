# M09 · 统计与概率 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中数学课堂的「统计与概率」交互学习页。学习目标：学生通过抽样演示、统计图表例题、概率分布列交互，掌握分层/简单随机抽样、常见统计图表（饼图/柱状图/折线图/直方图）、离散型随机变量的分布列与期望/方差。

二、数学模型规格：统计部分——分层抽样（按层比例 n_i=n×N_i/N）、简单随机抽样；常见统计量均值 x̄=Σx_i/n、方差 s²=Σ(x_i−x̄)²/n、中位数（n 奇取中、偶取中间两数均值）。概率部分——离散型分布列 P(X=x_i)=p_i 必须满足① p_i≥0 ② Σp_i=1（概率和恒为 1）；期望 E(X)=Σx_i·p_i，方差 D(X)=Σ(x_i−E(X))²·p_i；统计与概率分卡片，方差/中位数概念分开陈列不得混置；术语用「相关关系」不得表述为「因果」。

三、交互与教学功能：统计卡片含抽样演示（输入总体与样本量，显示分层/简单随机结果）与饼/柱/折/直方四类统计图表例题；概率卡片含分布列编辑（可改 x_i、p_i，实时校验概率和并显示期望/方差）与随机刷新例题；随机刷新数据联动题面时必须先确认目标 DOM 已存在再写入，刷新前题面与解法须同步更新；底部设「观察与结论」区引导归纳「概率和=1」与「期望是加权平均」。

四、工程与呈现约束：布局分「统计卡片／概率卡片／控制与读数区」三栏，1440×900 分辨率下无遮挡、无溢出；所有滑块、按钮、输入框有可见中文标签；所有写入 innerHTML/textContent 的语句必须先判空（if (el) {...}）或用可选链，杜绝「Cannot set properties of null」类运行时 TypeError；canvas 加 aria-label 描述当前图表；分布列编辑用真实 <input> 与 <button>，不得用 div 当按钮。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 概率和=1：任一分布列所有 p_i 之和必须显示为 1（允许浮点 0.9999...圆整）；把某行 p_i 改到使总和≠1 时，页面须提示「概率和不等于 1」而非静默；
2. 期望/方差手算：取分布列 X～{1:0.2, 2:0.3, 3:0.5}，手算 E(X)=1×0.2+2×0.3+3×0.5=0.2+0.6+1.5=2.3、D(X)=(1−2.3)²×0.2+(2−2.3)²×0.3+(3−2.3)²×0.5=1.69×0.2+0.09×0.3+0.49×0.5=0.338+0.027+0.245=0.61，与页面读数对比；
3. 统计量手算：取样本 {2,4,6,8,10}，均值 x̄=6、中位数=6、方差 s²=[(2−6)²+(4−6)²+(6−6)²+(8−6)²+(10−6)²]/5=(16+4+0+4+16)/5=8，与页面读数对比；
4. 核心交互无运行时报错：随机刷新例题、切换图表、编辑分布列各操作多次，打开浏览器 console 不得出现任何 TypeError 或 error 级日志（规避该生 innerHTML null 报错）；
5. 统计与概率必须分卡片，方差/中位数概念分开陈列，全文不得混置；
6. 分布列编辑、抽样演示、图表切换各操作一次，无报错、无失效；canvas 有 aria-label。
