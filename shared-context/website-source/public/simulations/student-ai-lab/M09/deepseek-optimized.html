三、概念对照与结论

方差 vs 中位数（分开展列）

中位数（集中趋势）

排序后：奇数个取中间值，偶数个取中间两数均值。反映数据的「中间位置」，对极端值不敏感。

方差（离散程度）

s² = Σ(xi−x̄)² / n，反映数据围绕均值的「波动大小」，对极端值敏感。

⚠️ 概念要点
  • 分布列要求：pi ≥ 0 且 Σpi = 1（概率和恒为 1）。
  • 期望 E(X) 是取值的加权平均，权重即概率。
  • 统计研究中观察到的联系是相关关系，不直接表述为「因果」。

🧭 观察与结论

拖动 pi 观察：只要 Σp=1，期望总等于加权平均；若把 0.5 从 x=3 移到 x=1，期望会明显下移。验证「概率和=1」是分布列成立的前提，也是检查分布列是否「合法」的第一道关。
