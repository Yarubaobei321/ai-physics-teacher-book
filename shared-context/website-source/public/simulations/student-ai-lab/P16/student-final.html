🎯 弹性碰撞核心结论 (大字体公式)

📐 动量守恒: m₁·v₁ + m₂·v₂ = m₁·v₁' + m₂·v₂'
⚡ 动能守恒: ½ m₁ v₁² + ½ m₂ v₂² = ½ m₁ v₁'² + ½ m₂ v₂'²
🔄 相对速度反向: v₂' - v₁' = -(v₂ - v₁)   (e=1)
  • 质量相等 → 速度交换
  • 动碰静: v₁' = (m₁-m₂)/(m₁+m₂)·v₁ , v₂' = 2m₁/(m₁+m₂)·v₁
  • 重碰轻 → 大球几乎匀速，轻球高速反弹；轻碰重 → 轻球原速反弹，重球几乎不动。
