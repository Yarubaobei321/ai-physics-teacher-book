🔬 观察与结论

特例 1：等质量碰撞

当 m₁ = m₂ 时，碰后两球交换速度：v₁′ = v₂，v₂′ = v₁。

特例 2：重球撞轻球

当 m₁ > m₂ 且球2静止时，碰后两球均沿正方向运动，重球减速但不停。

特例 3：轻球撞重球

当 m₁ < m₂ 且球2静止时，轻球反弹（v₁′ < 0），重球缓慢前进。

核心规律：完全弹性碰撞中，系统总动量守恒（Σp = const）且总动能守恒（ΣEk = const）。 公式：v₁′ = [(m₁−m₂)v₁ + 2m₂v₂] / (m₁+m₂)，v₂′ = [(m₂−m₁)v₂ + 2m₁v₁] / (m₁+m₂)。 养成习惯：先手算预测 → 再仿真验证 → 差值应趋近于零，培养数据验收意识。
