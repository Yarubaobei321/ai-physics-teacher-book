# B01 · DNA复制 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中生生物课堂的"DNA 半保留复制"交互演示。学习目标：学生通过观看解旋→配对→合成全过程、编辑碱基、逐位核对，能说出 DNA 复制为半保留复制、子链按碱基互补配对（A-T、G-C）合成。

二、生物模型规格：以一段双链 DNA（约 10–20 个碱基对）为对象，正弦双螺旋形态呈现；复制叉处解旋酶（环形六聚体）位于复制叉前方、DNA 聚合酶位于两侧子链合成位点，体现"解旋→碱基互补配对→子链合成"的顺序；碱基互补配对严格为 A-T、G-C（DNA 层面，不得出现 A-U）；两条母链各作模板，每个子代 DNA 含一条旧链（母链）和一条新链（子链），旧链与新链用不同颜色区分，体现半保留复制；新链合成方向标为 5'→3'、模板链方向标为 3'→5'（在链端标注 5'/3'）；一次复制由 1 个 DNA 分子得到 2 个子代 DNA 分子；飞入的游离核苷酸粒子所显示的字母必须等于其将要掺入位点的互补碱基（由模板碱基决定，不得随机）。

三、交互与教学功能：进度滑块与速度滑块可调；开始/暂停合并键、重置键、完成复制键、延长链长/重置链长键；动画按解旋→配对→连接推进，可循环；可点击画布上任一碱基进行编辑（输入 A/T/G/C），编辑后该位点及互补链对应位点自动更新为正确互补碱基；讲解区用文字说明解旋酶、DNA 聚合酶、模板链、游离核苷酸的作用，并引导"看图—逐位读碱基—归纳半保留"。

四、工程与呈现约束：布局分"画布区／控制区／讲解区"三栏；1440×900 分辨率下无遮挡、无溢出；所有控件有可见文字标签且不小于 0.8rem；canvas 加 aria-label 描述复制场景；碱基编辑用页面内输入或下拉，不依赖浏览器原生 prompt() 对话框；点击右链碱基时编辑的就是被点的那一位（不要把右链点击改写到左链）。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 复制完成后任取 3 个位点，逐位核对新链碱基与模板碱基互补：模板 A↔新链 T、模板 T↔新链 A、模板 G↔新链 C、模板 C↔新链 G，不得出现 A-U；
2. 一次复制结束后页面应显示 2 个子代 DNA 双螺旋，且每个子代 DNA 均为"一条母链色＋一条新链色"，体现半保留（不得两个子代都是全旧或全新）；
3. 观察飞入的游离核苷酸粒子：每个粒子显示的字母必须等于其掺入位点的互补碱基（如模板为 A 的位点，飞入粒子应显示 T），随机抽样 5 个粒子核对一致；
4. 链端可见 5'/3' 方向标注，新链方向标为 5'→3'；
5. 点击任一碱基编辑为指定字母后，该位点及互补链对应位点均更新为正确互补对，再随机抽 2 个位点复核；
6. 所有滑块与按钮各操作一次，无报错、无失效；进度从 0 推进到 100% 过程中画面不溢出。
