💡 常考点 / 易错点

易错 1：光合作用释放的 O₂ 全部来自 H₂O（水），不是来自 CO₂——记住"水的光解放氧"。
易错 2：¹⁸O 是稳定同位素（非放射性），用 H₂¹⁸O 标记后，释放的 O₂ 带 ¹⁸O 标记、可被质谱检测，但不能说 ¹⁸O"有放射性"。
易错 3：光反应场所是类囊体薄膜/类囊体膜，暗反应（卡尔文循环）场所是叶绿体基质，不要张冠李戴。
易错 4：能量流动方向为 光能 → ATP/NADPH 中活跃化学能 → 糖类等有机物中稳定化学能，方向不可反。

🔬 光反应 / 暗反应 / 总反应式

过程场所主要变化
光反应类囊体薄膜（类囊体膜）水光解：2H₂O → O₂ + 4H⁺ + 4e⁻（O₂ 全部来自水）；同时合成 ATP 与 NADPH（[H]）。
暗反应（卡尔文循环）叶绿体基质CO₂ 固定：CO₂ + C₅ → 2C₃；C₃ 还原（消耗 ATP 与 NADPH）→ 糖类等有机物。

总反应式：6CO₂ + 12H₂O —光/叶绿体→ C₆H₁₂O₆ + 6O₂ + 6H₂O

配平检查：C 6=6；H 24=12+12；O 24=6+6+12。能量来自光能、储存在有机物中，方向不可反。

🔗 与呼吸作用的关联

光合作用把光能固定为有机物中的化学能，并释放 O₂；呼吸作用分解有机物释放能量，供生命活动利用，并释放 CO₂。二者物质与能量上相互联系：光合作用产生的 O₂ 可供呼吸作用利用，呼吸作用产生的 CO₂ 又可作为光合作用的原料。
