# B13 · 光合作用预习讲学 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中生物的"光合作用"预习讲学网页。学习目标：通过叶绿体五阶段动画、即时题与课后练习，掌握光反应/暗反应的场所与物质变化、总反应式、O₂ 来源、与呼吸作用的关联，以及同位素标记实验的结论。

二、生物模型规格：
- 光反应场所：叶绿体类囊体薄膜（类囊体膜）；暗反应（卡尔文循环）场所：叶绿体基质。
- 光反应：水光解 2H₂O → O₂ + 4H⁺ + 4e⁻（O₂ 全部来自水），同时合成 ATP 与 NADPH（[H]）。
- 暗反应：CO₂ 固定（CO₂ + C₅ → 2C₃）、C₃ 还原（消耗 ATP 与 NADPH）→ 糖类（C₃ 还原首先接受 ¹⁴C 标记的是 C₃）。
- 总反应式：6CO₂ + 12H₂O —光/叶绿体→ C₆H₁₂O₆ + 6O₂ + 6H₂O（需配平，方向不可反，能量来自光能、储存在有机物中）。
- 同位素标记（关键修正）：¹⁸O 是**稳定同位素**（非放射性），用 H₂¹⁸O 标记后释放的 O₂ 带 ¹⁸O 标记、可被质谱检测——文字必须写"带 ¹⁸O 标记、可检测"，**不得写"¹⁸O 有放射性"或"具有放射性"**；¹⁴C 标记 CO₂ 最先出现在 C₃。
- 能量流动：光能 → ATP/NADPH 中的活跃化学能 → 糖类等有机物中的稳定化学能，方向不可反。

三、交互与教学功能：①五阶段依次推进（阶段0 类囊体受光 → 阶段1 水光解放氧 → 阶段2 ATP/NADPH 形成 → 阶段3 基质中 CO₂ 固定 → 阶段4 糖合成），每阶段显示物质流向（O₂、ATP/NADPH、CO₂、糖按阶段依次出现）；②阶段1–4 各插一道即时选择题并给即时正误反馈；③3 道课后练习题（含 O₂ 来源、暗反应消耗物、¹⁴C 最先出现的物质），提交后逐题计分并显示解析；④常考点/易错点总结卡 + 光反应/暗反应/总反应式 + 与呼吸作用的关联说明。

四、工程与呈现约束：布局分"叶绿体动画区／阶段控制条／即时题与练习区／总结区"多层卡片；1440×900 分辨率下无遮挡、无溢出；所有控件为真实 button、有可见文字标签；动画画布（含 WebGL/3D）提供文本替代与 aria-label，描述当前阶段与可见物质；不得使用外链外部模块（保证离线单文件可运行）；正文字号≥0.9rem。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 同位素术语修正（核心 warning 规避）：页面凡涉及 ¹⁸O 的文字必须表述为"稳定同位素""带 ¹⁸O 标记、可检测"，全文不得出现"¹⁸O 有放射性""具有放射性"等表述；
2. 阶段物质顺序核对：依次点击阶段 0–4，O₂ 必须只在阶段 1（水光解）后才出现，ATP/NADPH 在阶段 2 后供应给暗反应，CO₂ 在阶段 3 进入基质被固定，糖在阶段 4 出现——顺序不得错位；
3. 场所标注核对：光反应标注"类囊体薄膜/类囊体膜"，暗反应标注"叶绿体基质"，O₂ 来源题标答为"H₂O（水）"，三者均不得写错；
4. 总反应式核对：6CO₂ + 12H₂O → C₆H₁₂O₆ + 6O₂ + 6H₂O，反应物与产物两侧 C/H/O 原子守恒、方向不可反；
