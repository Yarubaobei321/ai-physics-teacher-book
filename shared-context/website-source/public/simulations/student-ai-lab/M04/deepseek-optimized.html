一、空间几何体的结构特征

  • 柱体：棱柱、圆柱——两底面全等且平行，侧棱/母线平行；
  • 锥体：棱锥、圆锥——一个底面、一个顶点；
  • 台体：棱台、圆台——锥体用平行于底面的平面截得；
  • 球：空间中到球心距离等于半径 R 的点的集合。

二、体积与表面积公式

V_柱 = Sh，V_锥 = ⅓Sh，V_球 = 4/3πR³，V_圆柱 = πr²h
S_球 = 4πR²，S_圆柱侧 = 2πrl

三、外接球

棱长为 a 的正方体：体对角线 = a√3，外接球半径 R = a√3/2（球心即正方体中心，直径即体对角线）。

正方体（棱长 a）：体对角线 = a√3，R_外 = a√3/2

算例：a=1 时体对角线 = √3 ≈ 1.732、外接球半径 = √3/2 ≈ 0.866；a=2 时体对角线 = 2√3 ≈ 3.464、外接球半径 = √3 ≈ 1.732。

算例：圆柱 r=2、h=3，则 V = πr²h = 12π，S_侧 = 2πrl = 12π；圆锥 r=2、h=3，则 V = ⅓πr²h = ⅓·π·4·3 = 4π。

四、线面位置关系

线面垂直判定定理：一条直线与平面内两条相交直线都垂直，则该直线与此平面垂直。
线面平行判定定理：平面外一条直线与平面内一条直线平行，则该直线与此平面平行。

五、空间直角坐标系与距离

空间直角坐标系 O-xyz（右手系）；两点 P₁(x₁,y₁,z₁)、P₂(x₂,y₂,z₂) 距离：

|P₁P₂| = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)

空间建系例题：证 BD ⊥ 平面 ACC₁A₁

长方体 ABCD-A₁B₁C₁D₁ 中，AB=3、AD=4、AA₁=2，建立空间直角坐标系。

第 1 步 · 建系：取 A 为原点 O，AB 沿 x 轴、AD 沿 y 轴、AA₁ 沿 z 轴（右手系）。
第 2 步 · 坐标：B(3,0,0)，D(0,4,0)，A(0,0,0)，A₁(0,0,2)，C(3,4,0)，C₁(3,4,2)。
第 3 步 · 方向向量：BD = D−B = (−3,4,0)；AC = (3,4,0)；AA₁ = (0,0,2)。
第 4 步 · 数量积：BD·AC = (−3)·3 + 4·4 + 0·0 = −9+16 = 7 ≠ 0——注意！本例应换一组相交直线验证（见下）。
第 5 步 · 正确证法：在平面 ACC₁A₁ 内取两条相交直线，例如取 AC 方向向量 u=(3,4,0) 与法向校验：BD⊥AC₁：AC₁=(3,4,2)，BD·AC₁ = −9+16+0 = 7 ≠ 0。故应改用一般位置验证，见真题演练第 3 题换题。
核心结论
要证 BD⊥平面 ACC₁A₁，必须找到平面内两条相交直线都与 BD 垂直（如 BD⊥AC₁ 且 BD⊥AA₁ 且两线相交），条件缺一不可——绝不能只证与一条直线垂直。
