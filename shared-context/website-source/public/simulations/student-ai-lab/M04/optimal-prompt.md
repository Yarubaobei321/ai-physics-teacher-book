# M04 · 立体几何 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一数学课堂的「立体几何」交互学习页。学习目标：学生通过可旋转的 3D 几何体、外接球演示、平行与垂直判定定理、带数值的空间建系例题，掌握空间几何体的结构特征、线面位置关系与外接球求法。

二、数学模型规格：体积公式 V_柱=Sh、V_锥=⅓Sh、V_球=4/3πR³、V_圆柱=πr²h；表面积 S_球=4πR²、S_圆柱侧=2πrl；棱长为 a 的正方体体对角线=a√3、外接球半径=a√3/2；线面垂直判定定理：一条直线与平面内两条相交直线都垂直，则该直线与此平面垂直（条件缺一不可，不得省略「相交」）；线面平行判定定理：平面外一条直线与平面内一条直线平行，则该直线与此平面平行；空间直角坐标系 O-xyz，右手系；空间两点 P₁(x₁,y₁,z₁)、P₂(x₂,y₂,z₂) 距离公式 |P₁P₂|=√((x₂-x₁)²+(y₂-y₁)²+(z₂-z₁)²)。

三、交互与教学功能：至少四个模块/标签页——①常见几何体 3D 展示（柱/锥/球，OrbitControls 可拖动旋转、滚轮缩放，切换时务必先清空旧几何体与标签）、②外接球专题（演示正方体/正四面体/侧棱两两垂直三棱锥的外接球，标注球心与半径）、③平行与垂直判定定理（完整给出定理条件 + 判定关系陈述，含至少一道带数值的空间建系例题：给三棱锥坐标求证线面垂直）、④真题演练（2–3 道带解答的真题，含可读数值答案）；复位/重置视角按钮可一键回到默认相机位；底部设「观察与结论」区，引导归纳判定定理的条件。

四、工程与呈现约束：布局分「3D 画布区／控制区／数据区」三栏；1440×900 分辨率下无遮挡、无溢出、3D 模型不溢出画布；所有按钮（旋转、切换几何体、复位）均有可见中文标签；3D 画布提供替代文本（aria-label 描述当前几何体）；切换模型时务必清空旧的几何体与 CSS2D 文字标签，避免标签堆叠；公式用 Unicode 或内联 KaTeX 渲染，不依赖外网 MathJax；3D 实现优先用纯 Canvas/CSS3D 或内联 Three.js（可单文件打包），不得依赖外网 CDN。
