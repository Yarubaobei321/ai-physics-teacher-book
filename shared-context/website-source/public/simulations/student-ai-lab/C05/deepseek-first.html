📐 分子结构

分子式 C₂H₄  |  结构简式 CH₂=CH₂  |  最简式 CH₂  |  电子式 (C原子间双键，每个C与两个H共用电子对)

  • 空间构型：平面型分子，所有原子共平面，键角∠H-C-H ≈ 117°~121°，C=C键长0.134 nm (比C-C单键短)。
  • 杂化方式：碳原子为sp²杂化，未参与杂化的p轨道形成π键，C=C由1个σ键和1个π键组成 → 不能自由旋转。
  • 结构特点：碳碳双键具有不饱和性，π键易断裂，决定乙烯化学性质活泼。
电子式示意： H : C :: C : H (每个碳与氢形成一对共用电子，碳碳间两对电子)

⚡ 物理性质

🧊 状态：无色、稍有甜味的气体
💧 溶解性：难溶于水，易溶于有机溶剂(如CCl₄、苯)
⚖️ 密度：比空气略小 (相对分子质量28，空气29)
🌡️ 熔沸点：熔点 -169℃ / 沸点 -103.7℃

🧨 化学性质 · 双键的盛宴

🔥 1. 氧化反应

● 燃烧： 火焰明亮并伴有黑烟 (含碳量较高，不完全燃烧)

C₂H₄ + 3O₂ → 2CO₂ + 2H₂O (剧烈放热)

● 被酸性KMnO₄氧化： 乙烯使酸性高锰酸钾溶液褪色，本身被氧化为CO₂，可用于鉴别烷烃和烯烃。

5CH₂=CH₂ + 12KMnO₄ + 18H₂SO₄ → 10CO₂ + 12MnSO₄ + 6K₂SO₄ + 28H₂O (总反应，高中定性)

➕ 2. 加成反应 (核心特征)

π键断裂，两个原子或基团分别加在双键两端碳上。

  • 🔹 与溴(Br₂)加成：使溴水或溴的CCl₄溶液褪色 (用于检验碳碳双键)
    CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br (1,2-二溴乙烷，无色液体)
  • 🔹 与H₂加成(催化加氢)：Ni作催化剂，加热 → 乙烷
    CH₂=CH₂ + H₂ → CH₃–CH₃
  • 🔹 与卤化氢加成：如HCl → 氯乙烷
    CH₂=CH₂ + HCl → CH₃CH₂Cl
  • 🔹 与水加成(工业制乙醇)： 加热、加压、酸催化 → 乙醇
    CH₂=CH₂ + H₂O → CH₃CH₂OH

🔗 3. 加聚反应

乙烯在催化剂下打开双键，相互连接成长链 → 聚乙烯(高分子材料)。

n CH₂=CH₂ → [–CH₂–CH₂–]ₙ (聚乙烯，链节 –CH₂–CH₂–)

聚乙烯无毒，可做食品包装、塑料制品；高压法得低密度聚乙烯(LDPE)，低压法得高密度聚乙烯(HDPE)。

注意：乙烯不与强碱、强酸等反应，但双键易亲电加成。

🧪 实验室制法 (乙醇脱水)

原理： 乙醇在浓硫酸催化下，170℃发生消去反应生成乙烯和水。

CH₃CH₂OH → CH₂=CH₂↑ + H₂O (浓H₂SO₄, 170℃)
  • 装置： 液液加热型，温度计插入反应液面下，控制温度迅速升至170℃ (避免140℃生成乙醚)。
  • 注意事项： 浓硫酸作脱水剂+催化剂，加碎瓷片防止暴沸；NaOH溶液洗气除去SO₂、CO₂等杂质；排水集气法收集乙烯。
  • 现象： 有气泡，高锰酸钾/溴水褪色检验。
除杂试剂常用NaOH溶液 (吸收挥发酸) → 再用澄清石灰水验证CO₂已除尽。

⚠️ 重要考点： 温度计位置、浓硫酸与乙醇体积比(约3:1)、迅速升温防副反应、不能用酸性KMnO₄除杂(会氧化乙烯)。

🏭 工业制法 · 石油裂解

石油化工核心：石油裂解 (深度裂化) 在高温(约800~900℃)下将长链烃断裂成短链烯烃，获得乙烯、丙烯等。乙烯产量是衡量一个国家石油化工水平的标志。

CₙH₂ₙ₊₂ (石脑油等) → C₂H₄ + 其他烯烃/烷烃

此外也可通过乙烷裂解、煤化工等获得乙烯。

💎 主要用途

🌾 植物催熟剂：调节果实成熟，用于香蕉、番茄等催熟。
🧴 合成聚乙烯：塑料薄膜、容器、管道等。
🍷 合成乙醇：乙烯水化法制备工业乙醇。
🧪 制备环氧乙烷、乙苯、氯乙烯等有机化工原料。
⚗️ 有机合成基石：制造聚苯乙烯、乙二醇等多种重要产品。

📊 对比 · 乙烯 vs 乙烷

对比项目乙烯 (C₂H₄)乙烷 (C₂H₆)
碳碳键型双键(一个σ+一个π)，键长0.134nm单键σ，键长0.154nm
空间构型平面分子，键角~120°立体结构(可旋转)
燃烧现象火焰明亮并带黑烟淡蓝色火焰，无黑烟
酸性KMnO₄褪色 (氧化反应)不褪色
溴水(CCl₄)褪色 (加成反应)不褪色 (取代需光照)
主要反应类型加成、加聚、氧化取代(卤代)、裂解
主要工业来源石油裂解天然气/石油裂化

结论： 乙烯因碳碳双键表现出显著不饱和性，化学性质活泼，与乙烷形成鲜明对比。

  4. 写出乙烯与氢气加成、与氯化氢加成、加聚反应的化学方程式。
  5. 鉴别乙烯和乙烷的两种化学方法是什么？
🔍 点击查看参考答案（解析）

1. 通过溴水 (或溴的四氯化碳溶液)，乙烯与Br₂加成生成液态1,2-二溴乙烷而除去，甲烷不反应。不可用酸性KMnO₄，否则会引入CO₂新杂质。
2. 原理不同：溴水褪色是加成反应，酸性KMnO₄褪色是氧化还原反应。
3. 防止在140℃发生分子间脱水生成乙醚，温度需迅速跨越，并控制在170℃以得到更多乙烯。
4. C₂H₄+H₂→C₂H₆；C₂H₄+HCl→C₂H₅Cl；nC₂H₄ → [C₂H₄]ₙ。
5. 方法一：通入酸性KMnO₄溶液，褪色为乙烯；方法二：通入溴水(或溴的CCl₄溶液)，褪色为乙烯。

📌 拓展视野 · 乙烯与生活

✧ 催熟原理：乙烯作为植物激素，与受体结合促进果实成熟。但运输香蕉等时需用高锰酸钾吸收乙烯，延迟成熟。
✧ “聚乙烯塑料”可回收编号为02/04，安全无毒。
✧ 2020年全球化乙烯产能超2亿吨，是合成纤维、橡胶等的重要基石。
✧ 双键的π电子云易受亲电试剂进攻，牢固掌握“马氏规则”的基础（对乙烯无差异，但为后续丙烯打基础）。
