# C05 · 乙烯化学物理性质 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖（不引 Three.js / OrbitControls 等 WebGL 库，分子演示用内联 SVG 或图片序列），双击即可在浏览器打开。

一、主题与受众：面向高中化学（依据必修二 + 选必三）的"乙烯化学物理性质"系统讲解页。学习目标：学生通过读结构、物理性质、化学性质、制法、对比表、自测题，掌握乙烯的结构特征（sp²、σ+π、平面型、键角 120°）与典型反应（加成/加聚/氧化/消去制法），并理解 Br₂ 加成机理。

二、化学模型规格：
- 分子结构：sp² 杂化、σ+π 键、键角约 120°、平面型，C=C 键长 0.134 nm；每个 C 连 2H+1C(双键)=4 价。
- 物理性质：无色气体、难溶于水、密度略小于空气（M=28）、熔点 −169℃、沸点 −103.7℃。
- 化学性质方程式（必须配平、标注条件与状态符号 (g)/(aq)/↑）：
  · 加成 Br₂：CH₂=CH₂ + Br₂ →(常温) CH₂Br–CH₂Br（1,2-二溴乙烷，非 1,1-）；
  · 加成 H₂：CH₂=CH₂ + H₂ →(催化剂，加热) CH₃CH₃；
  · 加成 H₂O：CH₂=CH₂ + H₂O →(催化剂，加热加压) CH₃CH₂OH；
  · 加成 HCl：CH₂=CH₂ + HCl →(加热) CH₃CH₂Cl；
  · 加聚：n CH₂=CH₂ →(催化剂，加热) [–CH₂–CH₂–]ₙ；
  · 消去（实验室制法）：CH₃CH₂OH →(浓 H₂SO₄，170℃) CH₂=CH₂↑ + H₂O；
  · 氧化：使酸性 KMnO₄ 褪色；燃烧产物 CO₂ + H₂O。
- 与乙烷对比表：结构（C=C 双键 vs C–C 单键）、键角（120° vs 109.5°）、典型反应（加成 vs 取代）、燃烧现象。

三、交互与教学功能：8 大板块（结构/物理性质/化学性质/制法/工业/用途/对比表/思维自测）；**核心交互"Br₂ 加成分步演示"使用图片序列或内联 SVG 实现（不得依赖 Three.js/WebGL）**：4 个步骤按钮（①乙烯初始 / ②Br₂ 靠近极化 / ③π 键断裂 / ④新键形成→1,2-二溴乙烷）点击切换对应图片/SVG 并更新步骤说明文字，高亮当前步骤；返回顶部按钮点击后页面 scrollTop 平滑回到 0；侧边栏锚点定位到各板块；思维自测 3 题带可折叠答案。
