①蒸发

方向：海洋/陆地 → 云层（向上）
成因：太阳短波辐射加热水体，水分子获得能量逸出水面成为水汽（含植物蒸腾）。

②水汽输送

方向：海 → 陆（横向）
成因：大气环流（信风、盛行西风、季风等）将海洋上空的水汽输送到陆地上空。

③降水

方向：云层 → 地面（向下）
成因：水汽绝热冷却达饱和 + 凝结核成云滴，云滴碰并增长，重力下落形成雨雪。

④径流

方向：陆 → 海（含地表径流与地下径流 / 下渗）
成因：降水超过下渗能力时沿地表汇流成河，入海；部分下渗形成地下径流。

四环节首尾衔接：蒸发 → 水汽输送 → 降水 → 径流 → 蒸发，循环闭合。

② 三类水循环区分

类型过程环节特点
海陆间循环海洋 → 陆地 → 海洋蒸发、水汽输送、降水、径流（最全）陆地淡水资源更新的主要来源，最重要
陆地内循环陆地 → 陆地陆地蒸发/蒸腾、降水、下渗水量小，只在内陆局部
海上内循环海洋 → 海洋海洋蒸发、海上降水参与水量最大、环节最少

日常问答举例

Q1：为什么"陆风吹海风"的地区温差小？
水的比热容大，蒸发吸热与凝结放热共同调节，使海洋性气候温差小；缺水的沙漠无此缓冲。
Q2：人类活动主要影响水循环的哪个环节？
主要影响地表径流：修水库、跨流域调水、植树造林增大下渗等，对蒸发与输送影响相对较小。
Q3：为何海陆间循环对人类最重要？
环节最全，持续更新陆地淡水，是陆地生态系统与人类用水最根本的来源。
