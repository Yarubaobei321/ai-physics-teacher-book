# G02 · 水循环流程演示 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中地理课堂的"水循环流程演示"互动网页。学习目标：学生通过看海陆间循环示意图、点击四环节、读统计图，掌握水循环的主要环节（蒸发→水汽输送→降水→径流）及其方向、三类水循环的区分。

二、地理模型规格：
- 四环节与方向：蒸发（海洋/陆地向上的箭头）→水汽输送（海→陆横向箭头）→降水（云层向下的箭头）→径流（陆→海，含地表径流与地下径流/下渗）；四环节齐备且首尾衔接，箭头方向不得反向（不得把"降水→蒸发"画反）。
- 三类循环区分：海陆间循环（海洋→陆地→海洋，环节最全）、陆地内循环（陆地→陆地）、海上内循环（海洋→海洋）；不得混淆。
- 成因：蒸发=太阳短波辐射加热水体；凝结=绝热冷却达饱和+凝结核；降水=云滴碰并增长；径流=降水超下渗能力沿地表汇流。
- 水量数据（数值须统一）：全球年蒸发量约 505 千km³（其中海洋蒸发约 434、陆地约 71）、年降水量约 505 千km³（海洋降水约 386、陆地约 119）；海洋蒸发约占全球蒸发的 86%。**全页所有"降水总量""年蒸发量"数值须统一为同一套口径**，不得一处写 505 千km³、另一处写 577,000 km³。

三、交互与教学功能：①一张海陆间循环示意图（海洋左下、陆地右下、太阳右上、云层在上、河流在陆地汇入海洋），用箭头标明蒸发/水汽输送/降水/径流方向；②点击图中海洋/云层/降雨区/河流分别高亮对应环节说明（**四区命中矩形不得互相重叠、不得先判大矩形后判小矩形**，确保点河流高亮"径流"而非"蒸发"）；③右侧每环节成因详解卡；④下方 3 张统计图（海洋/陆地蒸发占比饼图、年蒸发/降水/径流量条形图、水分停留时间折线图）；⑤左下角"观察与填空"引导归纳四环节；⑥"日常问答举例"卡片。

四、工程与呈现约束：布局分"示意图区／环节详解区／统计图区／填空问答区"多层；1440×900 分辨率下无遮挡、无溢出；所有控件为真实 button、有可见中文文字标签；canvas 提供 aria-label（描述当前高亮环节）；不得使用外链外部模块，保证离线单文件可运行；正文字号≥0.9rem；点击命中检测若用矩形分区，矩形之间不得重叠或嵌套导致先判误命中。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 四环节方向核对：蒸发箭头向上（海洋/陆地→云层）、水汽输送箭头海→陆、降水箭头向下（云层→地面）、径流箭头陆→海；任一反向即不合格；
2. 环节完整性核对：四环节齐备且首尾衔接（蒸发→水汽输送→降水→径流循环闭合），不得缺环节或断链；
3. 点击命中区核对（核心 B3 规避）：依次点击图中海洋、云层、降雨区、河流四个区域，每次高亮的说明卡片必须与点击区域对应——点河流高亮"径流"而非"蒸发"；命中矩形之间不得重叠；
4. 数据自洽核对（核心 B1 warning 规避）：全页所有"降水总量"数值须统一为同一口径（如统一写"约 505 千km³"），条形图标注与文字描述读数一致，不得一处 505、一处 577,000；
5. 三类循环区分核对：海陆间循环（海→陆→海，环节最全）须与陆地内循环、海上内循环明确区分，标注不可混淆；
6. 统计图绘制核对：饼图/条形图/折线图三张均能正常绘制（canvas 像素非默认空白），坐标轴与读数文字清晰可见；
7. 逐个点击四区域、查看三张统计图、提交填空各一次，无报错、无失效。
