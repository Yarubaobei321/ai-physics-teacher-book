# M01 · 三角函数 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一数学课堂的「三角函数」交互学习页。学习目标：学生通过单位圆动画、参数滑块、特殊角测验，掌握 sin/cos 的定义、y=A sin(ωx+φ) 的振幅/周期/相位含义、以及特殊角的精确值。

二、数学模型规格：核心解析式 y=A sin(ωx+φ)，参数取值范围 A∈[0.1, 3]、ω∈[0.5, 3]、φ∈[-π, π]，弧度制；单位圆定义式 sinθ=y₀/r（r=1）、cosθ=x₀/r（r=1）；周期 T=2π/|ω|，振幅=|A|；特殊角 30°/45°/60°/90°/120° 必须给出 sin、cos 精确值（如 sin30°=1/2、cos60°=1/2、sin90°=1、cos120°=-1/2）；含 tan 模块时必须标注其无定义点 θ=π/2+kπ（k∈Z）并给渐近线提示，不得画成连续函数；坐标横轴统一弧度制并标注单位 rad。

三、交互与教学功能：至少五个分区/标签页——①学习指南、②单位圆投影动画（播放/暂停，动点绕单位圆运动，实时显示 sinθ/cosθ 投影线并同步绘制右侧 sin/cos 波形）、③基础函数演示、④自定义函数输入框（输入解析式后绘制并显示解析式，输入框旁注明「不支持 tan 在 π/2+kπ 附近取值」的教学提示）、⑤特殊角互动测验（随机出 30°/45°/60°/90°/120°，学生填 sin/cos 精确值，答对给出反馈）；y=A sin(ωx+φ) 的 A/ω/φ 三个滑块改参数时，波形与页面读数必须同步联动；底部设「观察与结论」区，引导归纳 A 控制振幅、ω 控制周期、φ 控制相位。

四、工程与呈现约束：布局分「画布区／控制区／数据区」三栏；1440×900 分辨率下无遮挡、无溢出；所有滑块、按钮、输入框均有可见中文标签；canvas 提供替代文本（aria-label 描述当前解析式）；所有公式用 Unicode 或内联 KaTeX 渲染，不依赖外网 MathJax；自定义函数输入用安全的 JS 表达式并捕获异常，无定义点不得报错崩溃。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 取 A=2、ω=1、φ=0：波形峰值读数必须为 2、谷值为 -2（振幅=|A|）；
2. 取 A=1、ω=2、φ=0：周期 T=2π/|ω|=π，一个完整波形的横向间距应等于 π；
3. 特殊角测验：sin90°=1、cos90°=0、sin30°=1/2、cos60°=1/2、sin120°=√3/2、cos120°=-1/2，逐题答对应反馈正确；
4. 单位圆动画播放时，动点 θ 走到 π/2，sinθ 投影读数=1、cosθ 投影读数=0；
5. 含 tan 的模块在 θ=π/2 附近必须显示「无定义」或渐近线提示，不得画成连续曲线；
6. 自定义函数输入「tan(x)」或非法表达式时不报错、给出友好提示；
7. 五个标签页与播放/暂停、三滑块各操作一次，无报错、无失效。
