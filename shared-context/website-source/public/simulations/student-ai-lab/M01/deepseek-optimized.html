一、sin 与 cos 的定义（单位圆）

在单位圆（半径 r=1）上取动点 P，其坐标为 (x₀, y₀)，设 OP 与 x 轴正方向的夹角为 θ（弧度），则：

sinθ = y₀ / r = y₀（r=1），  cosθ = x₀ / r = x₀（r=1）

因此单位圆上一点的 纵坐标就是 sinθ，横坐标就是 cosθ。

二、一般函数 y = A·sin(ωx + φ)

  • 振幅：|A| —— 波形偏离平衡位置的最大距离；
  • 周期：T = 2π/|ω| —— 波形重复一次所需的横向距离；
  • 初相：φ —— 决定波形在 x=0 处的起始位置（相位）。
y = A·sin(ωx + φ)，A∈[0.1, 3]，ω∈[0.5, 3]，φ∈[-π, π]（弧度制）

观察与结论：① 改变 A，波形只在竖直方向被拉长/压缩，A 控制振幅（峰值=|A|、谷值=-|A|）；② 改变 ω，波形横向被压缩/拉伸，ω 控制周期（T=2π/|ω|，ω 越大周期越短）；③ 改变 φ，整个波形沿 x 轴整体平移，φ 控制相位（初相），不改变振幅与周期。
