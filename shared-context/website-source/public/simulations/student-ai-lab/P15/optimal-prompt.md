# P15 · 动量守恒思维导图 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理复习课的"动量守恒定律"思维导图页。学习目标：学生通过展开导图各分支并完成一道交互验算题，能系统梳理定律内容、适用条件与典型应用。

二、物理模型规格：导图知识必须物理正确——定律表述（系统不受外力或所受外力矢量和为零时，系统总动量保持不变）；守恒条件的三种常见判定（不受外力／外力矢量和为零／内力远大于外力且作用时间极短）；公式 m₁v₁+m₂v₂=m₁v₁′+m₂v₂′（注明矢量性与正方向约定）；典型应用分支：弹性碰撞、完全非弹性碰撞、爆炸、反冲（注明爆炸与反冲中动量守恒但动能增加的来源）；SI 单位。

三、交互与教学功能：中心主题向外辐射的可展开/收起导图（点击节点展开子节点）；每个分支配一句要点说明；"交互验算"叶节点：给出例题——m₁=3 kg、v₁=2 m/s 的小车与静止的 m₂=1 kg 小车碰后连在一起，求共同速度；用户输入答案，页面判定对错并给出解析步骤；页面设"自我检查清单"区（列出易错点：忘记规定正方向、把动能守恒当成普适条件）。

四、工程与呈现约束：导图布局清晰不重叠；1440×900 下无遮挡、无溢出；节点可键盘聚焦；文字对比度充足。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 验算题手算：v′=(3×2+1×0)/(3+1)=1.5 m/s；输入 1.5 判定为正确，输入其他值判定为错误且解析步骤数值正确；
2. 导图中定律表述、守恒条件、公式符号逐条核对无知识性错误；
3. 爆炸/反冲分支正确说明"动量守恒、动能增加（来自化学能等）"；
4. 所有节点展开/收起正常，无遮挡重叠；
5. 页面交互遍历一次，无报错、无失效。
