📖 动量定理核心概念

1. 动量（Momentum）

动量是描述物体运动状态的物理量，定义为质量与速度的乘积：

p = m · v

📌 动量是矢量，方向与速度方向相同。单位：kg·m/s（千克·米/秒）。

💡 物理意义：动量越大，物体的运动状态越难改变。一辆大卡车即使速度很慢，动量也可能很大，因此很难停下来。

2. 冲量（Impulse）

冲量是力在时间上累积的效果：

I = F · Δt

📌 冲量也是矢量，方向与力的方向相同。单位：N·s（牛·秒），与动量单位等价（1 N·s = 1 kg·m/s）。

🔍 关键洞察：同样的动量变化，可以通过大力短时间（如撞击），也可以通过小力长时间（如慢慢刹车）来实现。这就是为什么安全气囊能救命——它延长了碰撞时间，减小了作用力。

3. 动量定理（Impulse-Momentum Theorem）

F合 · Δt = Δp = mv' − mv

合外力的冲量等于物体动量的变化量。这是牛顿第二定律的积分形式。

📐 推导：由 F=ma 和 a=Δv/Δt，得 F=m·Δv/Δt，即 F·Δt = m·Δv = Δp。动量定理将力、时间、质量、速度变化统一在一起。

🧮 互动计算：冲量-动量转换

拖动滑块，观察冲量与动量变化的关系：

Δp = m·Δv = 6.00 kg·m/s = 需要冲量 I = 6.00 N·s

若作用时间 Δt = 0.5s，则平均力 F = I/Δt = 12.00 N

⚖️ 动量定理 vs 动能定理 —— 深度对比

这是高中物理最容易混淆的两个定理。它们从不同维度描述力的作用效果，相互补充。

对比维度 🔵 动量定理 🟠 动能定理
核心公式 F·Δt = Δp = mv'−mv W = F·s = ΔEk = ½mv'²−½mv²
累积维度 力在时间上的累积 力在空间上的累积
物理量类型 矢量（有方向） 标量（无方向）
适用范围 恒力、变力均适用 恒力、变力均适用
守恒条件 系统合外力=0 只有保守力做功
典型应用 碰撞、爆炸、打击 自由落体、弹簧、斜面
🎯 核心区别：动量定理关注时间积累（F·Δt），用于分析碰撞等短时过程；动能定理关注空间积累（F·s），用于分析物体在位移中的能量变化。两者联立可求解复杂问题。

📐 典型场景分析：子弹打木块

一颗子弹射入木块并嵌入其中（完全非弹性碰撞）。动量守恒可求共同速度，动能定理可求产生的热量。

mv₀ = (M+m)v共 → v共 = mv₀/(M+m)
Q = ½mv₀² − ½(M+m)v共² （动能定理求热量）

📌 这个经典模型在深圳模考和高考中频繁出现，需要熟练掌握动量守恒与能量守恒的联立求解。
