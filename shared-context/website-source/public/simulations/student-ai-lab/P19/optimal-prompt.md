# P19 · 动量定理 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"动量定理"路径式学习页：概念讲解 → 冲量模拟 → 题库自测三步。学习目标：学生通过模拟读数验证 I=Ft=Δp，并能用动量定理解释缓冲现象。

二、物理模型规格：动量定理 Ft=Δp=mv₂−mv₁（恒力情形）；模拟采用水平面上恒力推静止物块：v=Ft/m；忽略摩擦（页面声明）；向右为正方向；SI 单位。

三、交互与教学功能：三步路径导航（同一文件内切换，完成上一步可进下一步或自由切换）；模拟区：F（1–20 N）、作用时间 t（0.5–5 s）、m（0.5–5 kg）滑块，播放后实时显示已作用时间、v、当前动量 p，结束后并排显示冲量 I=Ft 与动量变化 Δp 两个读数；题库区：至少 4 题（含缓冲情境概念题与计算题），提交出对错与解析；页面设"生活中的动量定理"小结区（安全气囊、跳远垫等）。

四、工程与呈现约束：单文件内多视图；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 模拟取 F=10 N、t=2 s、m=2 kg：手算 I=20 N·s、Δp=20 kg·m/s、末速 v=10 m/s，与页面读数对比，且 I 与 Δp 两读数相等（同源）；
2. 改 F=5 N、t=4 s：I 仍为 20 N·s、末速仍 10 m/s（体现"相同冲量不同过程"）；
3. 题库每题：按解析手算正确答案，确认该答案在选项中且判定正确；
4. 三步路径切换正常、状态不串扰；
5. 所有控件各操作一次，无报错、无失效。
