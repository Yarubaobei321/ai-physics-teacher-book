# P01 · 平抛运动 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一物理课堂的"平抛运动"交互仿真。学习目标：学生通过改参数、看轨迹与分运动投影、读数据，能归纳出"水平方向匀速直线运动、竖直方向自由落体运动"的规律。

二、物理模型规格：以抛出点为原点，x 轴水平向右为正，y 轴竖直向下为正；x=v₀t，y=½gt²，vₓ=v₀，v_y=gt；g 默认 10 m/s²（可调 9.8/10）；忽略空气阻力，并在页面显著位置注明"理想模型：忽略空气阻力"；所有物理量使用 SI 单位并标注。

三、交互与教学功能：初速度 v₀（2–20 m/s）与下落高度 h（1–45 m）滑块；发射/暂停合并键与重置键；轨迹动画同时显示水平、竖直两个方向的分运动投影点（同步运动）；鼠标悬停轨迹上任意点，显示该时刻的 t、x、y、vₓ、v_y（带单位）；绘制 X-t 与 Y-t 图像，X-t 应为过原点直线；每次落地自动把（v₀、h、飞行时间、水平射程）追加进数据记录表；页面底部设"观察与结论"填空区，引导归纳两个分运动的规律。

四、工程与呈现约束：布局分"画布区／控制区／数据区"三栏；1440×900 分辨率下无遮挡、无溢出；所有控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 取 v₀=10 m/s、h=8 m、g=10 m/s²：手算飞行时间 T=√(2h/g)≈1.26 s、落地水平距离 x=v₀T≈12.6 m，与页面落地读数对比；
2. 悬停 t=0.5 s 附近轨迹点：x=5.0 m、y=1.25 m、v_y=5.0 m/s，与悬停读数对比；
3. X-t 图直线斜率应等于 v₀；把 v₀ 改为 15 m/s 复测一次；
4. 所有滑块与按钮各操作一次，无报错、无失效；
5. 极端参数（v₀=2 与 20，h=1 与 45）下轨迹与读数不违背规律、画面不溢出。
