# L04 · 重点实词释义和古诗文赏析 · 评审重构的最优提示词

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中语文课堂的"重点文言实词释义＋课内古诗文赏析＋高考真题"互动网页。学习目标：学生通过查高频实词的本义与引申义、看本义→引申推演图解、读课内例句、刷古诗文真题，掌握文言实词词义推演脉络与古诗文赏析方法。

二、语文规则与文本规格（引文错字=fail、例句须真实含目标字、称谓体例严谨；赏析情感评价属"不判错区"不判错）：
- 实词释义须与古汉语词典一致：收录≥11 个高考高频实词（安/被/本/道/度/见/间/举/胜/致/所以），每词列本义单独一行＋引申义用①②③编号；词义推演脉络方向须正确（示例："安：本义安稳→安逸→安抚→虚化反问哪里"）。
- 每个义项配的课内例句**必须真实含该目标字**且出处可核（核心 B1 规避）：如"安"义项配"安能摧眉折腰事权贵"（含"安"）、"被"通假配"被八创"、"举"配"函谷举"、"胜"配"何可胜道也哉"、"致"配"其致一也"；**禁止配不含目标字的例句**（如不得给"间·间隔"配"因得观所谓石钟者"——该句不含"间"，须改配如"于乱石间"之类含"间"的课内语句）。
- 诗人小传须称谓体例严谨（核心 B1 规避）：按"名/字/号/朝代/代表作"分列；荀子名况、时人尊称荀卿、汉代避汉宣帝讳（讳询）改称孙卿——**不得把"荀况"标为字，不得把"孙卿"标为号**；其余苏轼/辛弃疾/韩愈/杜甫/白居易等字、号、朝代、代表作须与教材一致。
- 古诗文赏析引用诗句须与课文逐字一致：如《琵琶行》"大珠小珠落玉盘"（比喻）、《登高》"萧萧/滚滚"（拟声摹状）、《念奴娇·赤壁怀古》《永遇乐·京口北固亭怀古》《师说》《劝学》篇目归属正确。
- 修辞判定术语规范不混淆：比喻 vs 拟人、被动 vs 使动、通假（通"披""导"）等；"樯橹"用人教版主流写法。

三、交互与教学功能：①实词释义模块（搜索栏＋≥11 个高频实词按钮，输出本义单独一行＋引申义①②编号，每义项配课内例句与篇名出处，附本义→引申义推演图解，目标字在例句中高亮）；②课内古诗文赏析模块（搜索栏＋部编版名篇按钮，输出"翻译""赏析"两大标题＋诗人小传，结果页可滚动完整展示不截断）；③高考真题模块（≥5 题交互答题，覆盖念奴娇/永遇乐/登高颔联/师说/琵琶行，提交后显示对错＋每选项错因解析）。

四、工程与呈现约束：布局分"主页三栏卡片（实词/古诗文/真题）＋跳转下一页＋返回键"多层；1440×900 分辨率下无遮挡、无溢出；**不得使用 picsum.photos 等图片外链（成品有此问题，须改为纯 CSS/SVG 装饰或 emoji 配 alt），htmlAudit.externalReferences 必须为空**；所有按钮、搜索栏、卡片为真实 button/input 含 aria-label；emoji 图标须配 alt 文本；正文字号≥0.9rem。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 例句含目标字逐条核对（核心 A4 补全 + B1 text-basis 规避）：对≥11 个实词的每个义项逐一核对例句是否真实含目标字——"安能摧眉"含"安"、"被八创"含"被"、"函谷举"含"举"、"何可胜道也哉"含"胜"、"其致一也"含"致"、"间"义项须配含"间"的课内句（不得配"因得观所谓石钟者"）。出现任一不含目标字的例句即不合格，须改正；
2. 词义推演脉络核对（B1 rule-accuracy 规避）：抽 3 个实词（如"安/间/举"），词义推演图解方向须正确（"安"本义安稳→安逸→安抚→虚化反问哪里；不得反向或跳层）；
3. 称谓体例核对（核心 B1 attribution 规避）：诗人小传中"名/字/号"分列——荀子须为"名况、尊称荀卿、避汉讳称孙卿"，**不得标"荀况"为字、"孙卿"为号**；苏轼/辛弃疾/韩愈/杜甫/白居易等字、号、朝代须与教材一致；
4. 引文与课文对照（核心 A4 补全 + B1 text-basis）：把赏析所引诗句（《登高》"无边落木萧萧下"、琵琶行"大珠小珠落玉盘"、《念奴娇》《永遇乐》《师说》《劝学》等）与部编版教材原文逐字核对，无错字、无漏字、无出处错配；
5. 真题答案-解析同源核对（A4 补全 + B1 exercise-consistency）：5 题正确答案（Q1 D 人生如梦=旷达非消极、Q2 A 孙权讽刺偏安、Q4 B 闻道有先后/术业有专攻、Q5 C 比喻形象化）须与解析一致；逐选项错因分析正确；
6. 工程核对（B4 规避）：打开页面控制台无错误；无 picsum.photos 等图片外链请求；按钮/卡片含 aria-label；emoji 图标均有 alt；正文字号≥0.9rem；6 个部编名篇按钮、11 个实词按钮、5 组真题 radio、提交核对与返回主页按钮各操作一次，无报错、无失效。
