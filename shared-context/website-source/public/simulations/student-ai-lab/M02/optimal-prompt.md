# M02 · 复数的几何意义及相关运算 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一数学课堂的「复数的几何意义及相关运算」互动实验室。学习目标：学生通过复平面点位、四则运算、模与辐角、模长最值轨迹，掌握 z=a+bi 与复平面点 (a,b) 的一一对应、|z|=√(a²+b²) 的几何含义（点到原点距离）、复数乘法的几何意义（模相乘、辐角相加）。

二、数学模型规格：复数 z=a+bi（a∈[-6,6]、b∈[-6,6]，a,b∈R），对应复平面点 (a,b)；模长 |z|=√(a²+b²)，辐角 arg(z)=atan2(b,a)（范围 (-π,π]）；i²=-1；四则运算：加减按向量分量、乘法 (a+bi)(c+di)=(ac-bd)+(ad+bc)i、除法分母实数化（乘以共轭）；复数乘法的几何意义：|z₁·z₂|=|z₁|·|z₂|、arg(z₁·z₂)=arg(z₁)+arg(z₂)；模长最值轨迹：|z-z₀|=r 表示以 z₀ 为圆心、r 为半径的圆；坐标轴用直角坐标，横轴实部、纵轴虚部，刻度统一。

三、交互与教学功能：至少三个模块/标签页——①复平面展示（输入 a、b 或拖动点位，实时显示 z=a+bi 的位置与模、辐角读数）、②四则运算（输入 z₁、z₂，显示加减乘除结果及结果向量）、③模长最值轨迹（输入圆心 z₀、半径 r，画出 |z-z₀|=r 并显示 |z| 的最大/最小值）；「随机 z1」按钮每次点击必须在 [-6,6]×[-6,6] 范围内重新生成坐标，连续 10 次不得重复同一坐标；底部设「观察与结论」区，引导归纳模的几何含义与乘法辐角相加规律。

四、工程与呈现约束：布局分「画布区／控制区／数据区」三栏；1440×900 分辨率下无遮挡、无溢出；所有输入框、按钮均有可见中文标签；canvas 提供替代文本（aria-label 描述当前 z 或当前运算）；所有公式用 Unicode 或内联 KaTeX 渲染（如 √(a²+b²)），不依赖外网 MathJax；模块切换时画布须先清空旧矢量与标注，再绘制新模块内容。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 输入 z=3+4i：模长读数必须为 |z|=√(9+16)=5，辐角读数约为 arg(z)=atan2(4,3)≈0.927 rad（53.13°）；
2. 输入 z=1+i 与 w=1-i：乘积 z·w=(1·1-1·(-1))+(1·(-1)+1·1)i=2+0i，结果点落在 (2,0)；
3. 随机 z1 按钮连续点击 10 次：每次坐标必须变化、均在 [-6,6]×[-6,6] 范围内，不得出现坐标不变或越界；
4. 模长最值轨迹取 z₀=0、r=3：画出以原点为圆心、半径 3 的圆，|z| 最大值=最小值=3（轨迹上点模长恒为 3）；
5. 模长最值轨迹取 z₀=4+0i、r=1：|z| 最大=5、最小=3；
6. 三个模块按钮切换：画布只显示当前模块的矢量/轨迹/标注，旧模块内容不残留；
7. 模块切换、随机按钮、运算按钮、参数输入各操作一次，无报错、无失效。
