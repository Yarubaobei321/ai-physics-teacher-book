一、复数与复平面的一一对应

每个复数 z = a + bi（a、b 为实数）都唯一对应复平面上的一个点 (a, b)：横轴为实轴，纵轴为虚轴。

z = a + bi ↔ 点 (a, b)，且 i² = −1

二、模长与辐角

复数的模 |z| 等于对应点到原点的距离，辐角 arg(z) 等于 OP 与实轴正方向的夹角：

|z| = √(a² + b²)，  arg(z) = atan2(b, a)，范围 (−π, π]

例如 z = 3 + 4i：|z| = √(9+16) = 5，arg(z) ≈ 0.927 rad（≈53.13°）。

三、复数乘法的几何意义

  • 模相乘：|z₁·z₂| = |z₁|·|z₂|
  • 辐角相加：arg(z₁·z₂) = arg(z₁) + arg(z₂)
  • 乘法计算：(a+bi)(c+di) = (ac−bd) + (ad+bc)i

算例：z=1+i 与 w=1−i，则 z·w = (1·1−1·(−1)) + (1·(−1)+1·1)i = 2+0i，结果点落在 (2,0)。

四、模长最值轨迹

|z − z₀| = r ⇔ 以 z₀ 为圆心、r 为半径的圆

轨迹上任意一点到原点的距离（|z|）最大值为 |z₀| + r，最小值为 ||z₀| − r|。

五、除法（分母实数化）

(a+bi) / (c+di) = (a+bi)(c−di) / (c²+d²)

观察与结论：① 复数 z=a+bi 的模 |z| 就是点到原点的距离 √(a²+b²)，模的几何含义是「长度」；② 复数乘法对应「模相乘、辐角相加」——两个复数的乘积模长等于各自模长之积，辐角等于各自辐角之和；③ 方程 |z−z₀|=r 的轨迹是圆：圆心为 z₀、半径为 r，圆上每一点到原点的距离都在 [|z₀|−r, |z₀|+r] 之间。
