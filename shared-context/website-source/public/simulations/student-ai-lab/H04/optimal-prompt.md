一、主题与受众：面向高中历史课堂的"经济基础决定上层建筑"综合互动演示。学习目标：学生通过调四组生产力滑块、看右侧上层建筑联动、读工人第一人称自述，体会"新生产力催生新生产关系→震荡法律/政治/文化"这一唯物史观因果方向。

二、史实模型规格（年代/事件须与统编教材逐条可考；因果方向不可反）：
- 切入场景锚点：1908 年福特 T 型车投产、1913 年福特高地公园工厂移动装配线投产、1914 年五美元日薪。
- 生产力四组滑块（每组状态按时间正序递进）：
  · 蒸汽机：早期实验 → 瓦特改良蒸汽机（分离冷凝器）→ 蒸汽机车与轮船 → 逐渐被内燃机取代；
  · 电力：富兰克林风筝实验 → 法拉第电磁感应 → 电灯/电话普及 → 信息时代；
  · 内燃机：勒努瓦煤气机 → 奥托四冲程/戴姆勒/本茨首辆汽车 → 福特 T 型车 → 电喷时代；
  · 福特流水线：背景（手工作坊产能瓶颈）→ 促进（移动装配线 1913）→ 推广（流水线普及）。
- 上层建筑五条（随综合生产力指数自动演变）：资产阶级政治权力 / 两大阶级对立 / 劳动法 / 社会保障 / 进取与功利主义思想。
- 综合阶段分期（时序不得倒置）：前工业 → 第一次工业革命 → 第二次工业革命 → 工业成熟期 → 后工业/信息革命；拉满四滑块须进入"后工业/信息革命"，蒸汽状态须切为"逐渐被内燃机取代"。
- 因果链（方向不可反，本课锚点重点）：经济基础决定上层建筑、社会存在决定社会意识、生产力→生产关系→上层建筑；不得出现"上层建筑决定经济基础""社会意识决定社会存在"式颠倒。
- 理论锚：引用马克思《政治经济学批判》序言原话作为唯物史观依据。
- 边界声明：若页面提及社会主义流派，须区分"空想社会主义"（圣西门/傅立叶/欧文）与"科学社会主义"，二者不得混淆；马克思主义诞生标志为 1848 年《共产党宣言》，不得误作他年他文。
