# P08 · 验证动量守恒定律·完全弹性碰撞实验 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"验证动量守恒定律"数字实验，采用一维完全弹性碰撞方案。学习目标：验证的对象是动量守恒；同时展示弹性碰撞中总动能也守恒，作为对照认识两个守恒量的区别。

二、物理模型规格：一维对心完全弹性碰撞；光滑水平面、系统不受外力（页面显式声明）；向右为正方向；碰后速度 v₁′=((m₁−m₂)v₁+2m₂v₂)/(m₁+m₂)、v₂′=((m₂−m₁)v₂+2m₁v₁)/(m₁+m₂)；SI 单位。

三、交互与教学功能：两球质量（0.5–5 kg）与初速度（−5–+5 m/s）可调；播放/暂停/重置；碰前碰后数据表：各球 v、p，系统 Σp、ΣEk 分列；"守恒检验"行显示 |Σp碰前−Σp碰后| 与 |ΣEk碰前−ΣEk碰后|——必须来自实时数值计算的真实残差，不得硬编码为零或伪造随机小数；页面设"观察与结论"区。

四、工程与呈现约束：布局分"画布区／控制区／数据区"；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. m₁=2 kg、v₁=3 m/s 撞静止 m₂=1 kg：手算 v₁′=1 m/s、v₂′=4 m/s，Σp 恒为 6 kg·m/s、ΣEk 恒为 9 J，与数据表对比；
2. 等质量对撞（m₁=m₂=1 kg，v₁=4 m/s，v₂=0）：两球交换速度；
3. 改任意质量后表格数字随之变化（检验非硬编码）；
4. 守恒检验行的残差应为数值计算真实结果（接近 0 的机器精度量级）；
5. 所有控件各操作一次，无报错、无失效。
