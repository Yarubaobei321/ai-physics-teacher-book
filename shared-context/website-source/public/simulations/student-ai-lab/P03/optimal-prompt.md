# P03 · 万有引力定律 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"万有引力定律"交互演示页。学习目标：学生通过改 M、m、r 并读 F，能归纳出 F 与两质量成正比、与距离平方成反比。

二、物理模型规格：F=GMm/r²，G=6.67×10⁻¹¹ N·m²/kg²；质点模型（球体视为质量集中于球心，页面显式声明）；引力沿两质点连线方向，两力互为作用力与反作用力（等大、反向、分别作用在两个物体上）；SI 单位，力用科学计数法显示。

三、交互与教学功能："宇宙视图"（两天体相互吸引）与"地表视图"（地面物体受地球引力）双视图切换；M、m、r 三个滑块（范围要宽，可用对数刻度）；实时 F 读数；两物体上各画一个力矢量箭头，长度随 F 变化、方向始终指向对方；"代入式"面板实时显示当前参数代入 F=GMm/r² 的完整算式；页面设"观察与结论"区。

四、工程与呈现约束：布局分"画布区／控制区／数据区"；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 取 M=6.0×10²⁴ kg、m=1 kg、r=6.4×10⁶ m：手算 F≈9.8 N，与页面读数对比；
2. r 加倍（1.28×10⁷ m）：F 应变为约 2.44 N（1/4）；
3. m 加倍：F 加倍；
4. 任意参数下两个箭头始终等长、反向、分别指向对方；
5. 双视图切换后读数连续、无 NaN；所有控件各操作一次无报错。
