# M12 · 三角函数 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中数学（必修一）课堂的「三角函数」交互学习页。学习目标：学生通过单位圆定义、三角形几何证明和差角公式、诱导公式（k·π/2 形式）、sin/cos/tan 动态演示与恒等变换，掌握三角函数的定义、特殊角精确值、和差角与诱导公式及其证明路径。

二、数学模型规格：单位圆定义 sinθ=y₀/r、cosθ=x₀/r（r=1）；周期 sin/cos=2π、tan=π，tan 无定义点 θ=π/2+kπ（k∈Z）须标注渐近线。特殊角精确值——sin(π/6)=1/2、cos(π/6)=√3/2、sin(π/4)=√2/2、cos(π/4)=√2/2、sin(π/3)=√3/2、cos(π/3)=1/2、sin(π/2)=1、cos(π/2)=0。诱导公式统一用 k·π/2±α 形式（如 sin(π/2−α)=cosα、sin(π+α)=−sinα、cos(π−α)=−cosα、sin(2π−α)=−sinα）。和差角公式 sin(α±β)=sinα cosβ ± cosα sinβ、cos(α±β)=cosα cosβ ∓ sinα sinβ；二倍角 sin2α=2sinα cosα、cos2α=cos²α−sin²α。弧度制，坐标轴标 rad。

三、交互与教学功能：多标签页/分区——①单位圆动态演示（动点绕单位圆运动，实时显示 sinθ/cosθ 投影线）、②三角形几何证明和差角（用单位圆内三角形或几何构造展示 sin(α+β) 的推导路径）、③诱导公式区（k·π/2 形式列表，附一般角证明而非仅特殊角代入）、④sin/cos/tan 动态演示（可切换）、⑤恒等变换区（和差角/二倍角/诱导公式应用）；公式按钮可在 sin/cos/tan/和差角/诱导间切换；底部设「观察与结论」区引导归纳诱导公式「奇变偶不变，符号看象限」。

四、工程与呈现约束：布局分「演示画布区／公式切换区／证明与读数区」三栏，1440×900 分辨率下无遮挡、无溢出；所有按钮、滑块有可见中文标签；sin/cos/tan/公式切换按钮用真实 <button>（不得用 div 当按钮）；canvas 加 aria-label 描述当前公式与角度读数；所有公式用 Unicode 或内联 KaTeX 渲染，不依赖外网 MathJax；点字母与坐标轴标注齐全。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 特殊角读数验收：单位圆动点 θ 走到 π/2 时，sinθ 投影读数=1、cosθ 投影读数=0；θ=π/6 时 sin=1/2、cos=√3/2；θ=π/3 时 sin=√3/2、cos=1/2；
2. 周期标注：sin/cos 周期须标注为 2π、tan 周期须标注为 π；tan 在 θ=π/2 附近须显示渐近线或「无定义」提示，不得画成连续曲线；
3. 诱导公式手算验收：取 α=π/6，sin(π/2−π/6)=sin(π/3)=√3/2 应等于 cos(π/6)=√3/2（公式 sin(π/2−α)=cosα 成立）；取 α=π/4，sin(π+π/4)=sin(5π/4)=−√2/2 应等于 −sin(π/4)=−√2/2（公式 sin(π+α)=−sinα 成立），页面诱导公式区举例须与手算一致；
4. 和差角验收：取 α=π/6, β=π/6，sin(π/6+π/6)=sin(π/3)=√3/2，按公式 sin(π/6)cos(π/6)+cos(π/6)sin(π/6)=1/2×√3/2+√3/2×1/2=√3/2，两者一致；页面和差角演示须与此手算吻合；
5. 二倍角验收：取 α=π/4，sin(2·π/4)=sin(π/2)=1，按公式 2sin(π/4)cos(π/4)=2×√2/2×√2/2=1，一致；
6. 诱导公式必须用 k·π/2 形式（不得用 k·90° 或仅特殊角列表）；证明区须含一般角 α 的证明路径，不得仅靠特殊角代入；
7. sin/cos/tan/和差角/诱导公式切换按钮各操作一次、单位圆动画播放一次，无 console 报错、无失效；canvas 有 aria-label。
