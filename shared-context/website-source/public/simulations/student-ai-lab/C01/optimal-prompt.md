# C01 · 烃类有机物及其反应的演示 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一化学课堂的"烃类有机物及其反应"3D 交互演示。学习目标：学生通过看可旋转立体结构、看化学键断裂与形成的分步动画、用碳数滑杆探索同系物，归纳出烷烃 CₙH₂ₙ₊₂ 通式与取代/加成/加聚三类典型反应的机理差异。

二、化学模型规格：烷烃通式 CₙH₂ₙ₊₂，碳骨架按 sp³ 正四面体键角 109.5°（端基 C 连 3H+1C=4 价、中间 C 连 2H+2C=4 价，全碳四价自洽，不得画成平面十字）；烯烃以乙烯 C₂H₄ 为代表，平面型 sp² 键角≈120°，C=C 一根 σ + 一根 π（π 键易断裂决定反应性），每 C 连 2H+1C(双键)=4 价。三类反应的方程式与机理口径严格如下：
- 取代反应：CH₄ + Cl₂ →(光照) CH₃Cl + HCl，分步时序为「Cl–Cl 键断 → C–H 键断、H 脱离碳 → Cl 连到碳上 → H 与另一半 Cl 结合成 HCl」；属自由基取代而非加成。
- 加成反应：C₂H₄ + Br₂ →(常温，CCl₄ 溶剂) BrCH₂CH₂Br（1,2-二溴乙烷），C=C π 键断开、Br–Br 断开、两个 Br 分别加到两个不同碳上（1,2-加成，不得写成 1,1-二溴乙烷 CH₃CHBr₂）；不得误写成取代。
- 加聚反应：n CH₂=CH₂ →(催化剂、加热) [–CH₂–CH₂–]ₙ，单体 C=C 双键断开、单体之间形成新的 C–C 单键成长链。
所有方程式必须配平并标注反应条件（光照 / 常温 CCl₄ / 催化剂加热）与状态符号（气体 g、液体 l、水溶液 aq）；不得省略。

三、交互与教学功能：模块一"结构展示"——烷烃/烯烃按钮切换可旋转缩放的 3D 球棍模型，碳数滑杆（范围 2–8）调出乙烷 C₂H₆ / 丙烷 C₃H₈ / 戊烷 C₅H₁₂ … 同系物，分子式与状态信息条随滑杆实时按通式更新；模块二"三类反应分步动画"——取代/加成/加聚三按钮，按上述时序分步播放（步骤提示文字与符号表征同源），完成后明确显示产物分子式与名称；模块三"观察与结论"区——引导学生归纳"烷烃饱和（只 C–C 单键）→ 取代；烯烃含 C=C π 键 → 加成/加聚"。

四、工程与呈现约束：布局分"画布区／控制区／状态信息区"三栏，深色星空 + 毛玻璃面板课堂版；1440×900 分辨率下无遮挡、无溢出；所有控件用真实 <button> 并带可见文字标签（≥0.8rem）；3D WebGL canvas 加 aria-label；OrbitControls 构造器必须传入 renderer.domElement（canvas DOM）而非 renderer，不得抛 TypeError；步骤按钮点击必有可观察响应（.active 类出现、stepMessage 更新）。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 通式核对：把碳数滑杆分别拉到 2/3/5，页面分子式应分别显示乙烷 C₂H₆（2C+6H）、丙烷 C₃H₈（3C+8H）、戊烷 C₅H₁₂（5C+12H）——逐个数 C/H 原子，H 个数必须 = 2n+2；
2. 取代反应守恒：CH₄+Cl₂→CH₃Cl+HCl 两边各 1C、4H、2Cl，原子守恒；动画必须按"Cl–Cl 断→C–H 断 H 脱离→Cl 连 C→H 与另 Cl 成 HCl"时序播放，不得把取代演成加成；
3. 加成反应 1,2- 位置核对（核心）：C₂H₄+Br₂→BrCH₂CH₂Br，产物必须是 1,2-二溴乙烷（每个碳各连 1 个 Br），不得写成 1,1-二溴乙烷 CH₃CHBr₂；动画必须呈现"π 键断开、两个 Br 分别加到两个碳上"；
4. 加聚反应机理：n CH₂=CH₂→[–CH₂–CH₂–]ₙ 动画必须呈现"C=C 双键断开 + 单体间形成新 C–C 单键成链"，不得停留在双键未断开的状态；
5. 状态符号与条件：三条方程式必须标注反应条件（光照 / 常温 CCl₄ / 催化剂加热）与状态符号 (g)/(l)/(aq)，缺一即不合格；
6. 立体结构保真：烷烃 C–H–C 键角应接近 109.5°（可用 (±1,±1,±1) 归一化方向构造），不得画成平面十字；所有碳保持四价；
7. 交互完整性：烷烃/烯烃/取代/加成/加聚 5 按钮与碳数滑杆(2–8) 各操作一次，无 console 报错、无失效、无 pageerror；OrbitControls 拖拽缩放正常。
