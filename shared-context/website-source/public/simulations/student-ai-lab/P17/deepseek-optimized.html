📝 观察与结论

🔍 观察要点

调节角速度 ω 滑块，观察物块从随盘转动到相对滑动的临界转变。当 ω 超过 ωc 时，物块沿径向向外滑离转盘。

⚠ 关键发现

改变物块质量 m（保持 r、μ 不变），临界角速度 ωc 不变。这说明临界条件与质量无关：ωc = √(μg/r)，m 被约去。

📐 公式推导

向心力由静摩擦力提供：mω²r ≤ μmg。化简得 ω ≤ √(μg/r)。故临界角速度 ωc = √(μg/r)（g = 9.8 m/s²）。
