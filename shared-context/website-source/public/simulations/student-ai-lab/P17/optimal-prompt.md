# P17 · 圆周运动转盘模型 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"水平转盘上物块的临界转速"交互仿真。学习目标：学生通过调节角速度观察物块从随盘转动到相对滑动的转变，能推导并验证临界角速度 ω_c=√(μg/r)。

二、物理模型规格：物块随转盘做匀速圆周运动时，向心力由静摩擦力提供，需 mω²r≤μmg；临界角速度 ω_c=√(μg/r)（与 m 无关）；ω>ω_c 时物块相对转盘向外滑动；g=9.8 m/s²；SI 单位（ω 用 rad/s）。

三、交互与教学功能：m（0.2–2 kg）、r（0.1–0.5 m）、μ（0.1–0.8）、ω（0–10 rad/s）滑块；转盘俯视动画，物块清晰可见；播放/暂停/重置；实时显示所需向心力 mω²r、最大静摩擦力 μmg、当前 ω_c 与运动状态（"随盘转动"/"相对滑动"）；页面加载后所有读数即为默认参数下的有限数字；页面设"观察与结论"区。

四、工程与呈现约束：布局分"画布区／控制区／数据区"；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 双击打开页面后不做任何操作：所有读数均为有限数字（无 NaN、无空白），转盘上物块可见；
2. μ=0.5、r=0.2 m：手算 ω_c=√(0.5×9.8/0.2)≈4.95 rad/s，与页面显示的临界值对比；
3. 同参数下把 ω 从 4.5 升到 5.5 rad/s：状态应从"随盘转动"切换为"相对滑动"，动画表现一致；
4. 只改 m（其他不动）：ω_c 读数不变（公式与 m 无关）；
5. 所有控件各操作一次，无报错、无失效。
