# P09 · 力学 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"力学核心模型"导航学习页，含牛顿第一定律、牛顿第二定律两个可运行子模型。学习目标：学生通过操作各模型并读数据，能区分"不受力（合力为零）时保持匀速"与"受恒力时匀加速"。

二、物理模型规格：子模型一（第一定律）：物块在光滑水平面运动，可随时撤去水平推力，撤力后 a=0、v 保持不变；子模型二（第二定律）：a=F/m，v=at（初速为零）；均忽略摩擦并页面声明；向右为正方向；SI 单位。

三、交互与教学功能：首页为导图式入口（卡片或节点图），点击进入对应子模型（同一文件内切换，非跳转外部页面）；每个子模型有播放/暂停/重置，暂停时读数冻结；子模型一：推力开关按钮、实时 v 与 a 读数；子模型二：F（1–20 N）与 m（0.5–5 kg）滑块、实时 a、v、t 读数与 v-t 图；每个子模型底部设一句"观察与结论"填空。

四、工程与呈现约束：单文件内多视图切换；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 子模型二：F=10 N、m=2 kg，手算 a=5 m/s²、2 s 末 v=10 m/s，与读数对比，v-t 图为过原点直线；
2. 子模型一：运动中撤去推力后，v 读数保持不变（连续观察 3 s，Δv≈0）；
3. 每个子模型暂停时动画与读数同时冻结，恢复后连续；
4. 两个子模型来回切换各两次，状态不串扰、无残影；
5. 所有控件各操作一次，无报错、无失效。
