# B06 · 基因分离定律及自由组合定律的模拟 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中生的"基因分离定律与自由组合定律"交互模拟。学习目标：学生通过展示模式看分步遗传图解、用自定义模式选亲本杂交，能归纳出单对相对性状 F2 性状分离比为 3:1（基因型 1:2:1）、两对相对性状 F2 比为 9:3:3:1。

二、生物模型规格：以豌豆为模型，两对相对性状——子叶颜色黄色/绿色、种子形状圆粒/皱粒。展示模式：默认亲本 P 为 YYRR（黄圆）× yyrr（绿皱），按 P→F1→F2 顺序分步画出遗传图解；F1=YyRr（黄圆）。分离定律（单对性状 Yy×Yy 自交）：F2 基因型 1 YY : 2 Yy : 1 yy，表现型 3 黄 : 1 绿。自由组合定律（两对性状 YyRr×YyRr 自交）：F2 性状分离比 9 黄圆 : 3 黄皱 : 3 绿圆 : 1 绿皱。自定义模式：用户选择双亲基因型后杂交得 F1，可再选择自交或自由交配得到子代，输出子代基因型与比例。**符号体系统一**：全站统一用 Y/y（黄/绿）、R/r（圆/皱）表示豌豆这两对性状，展示模式与自定义模式不得改用 A/a、B/b 等不同符号体系（避免初学者误以为是不同规律）；等位基因大小写排序一致（Y 前 y 后，R 前 r 后）。

三、交互与教学功能：展示模式（默认亲本）按 P→F1→F2 分步展开遗传图解，单性状 F2 显示基因型 1:2:1 和表型 3:1，双性状 F2 显示 9:3:3:1；自定义模式用按钮（Y/y/R/r）选双亲基因型，输出 F1 及分别自交、自由交配的子代基因型和比例，并保留全过程遗传图解；含开始展示、模式切换、亲本选择、杂交、自交、自由交配、停止、重置等控件；图解为文字＋简图（不必画个体图片），尺寸统一。

四、工程与呈现约束：展示/自定义模式分区清楚，黄/绿配色对应性状，遗传图解层级明确；1440×900 分辨率下无遮挡、无溢出；所有按钮为真实 <button>、带可见文字标签且不小于 0.8rem；提供 aria 标注与键盘操作说明；文字不小于 0.8rem。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 展示模式运行 YY×yy（单对）：F2 应显示基因型 1 YY : 2 Yy : 1 yy、表型 3 黄 : 1 绿；
2. 展示模式运行 YYRR×yyrr（两对）：F1=YyRr（黄圆）；F1 自交 F2 应显示 9 黄圆 : 3 黄皱 : 3 绿圆 : 1 绿皱；
3. 自定义模式选 Yy×Yy 和 YyRr×YyRr 分别运行，页面比例必须与 3:1、9:3:3:1 一致；
4. **符号一致性**：展示模式与自定义模式全站统一用 Y/y/R/r，不得出现 A/a、B/b 等不同符号体系；
5. 自定义模式选亲本杂交后，子代基因型与比例应正确显示（不被覆盖、不为空），自交与自由交配两条路径都能产出子代；
6. 所有主按钮（开始展示/模式切换/亲本选择/杂交/自交/自由交配/停止/重置）各点击一次，无报错、无失效，画面不溢出。
