# G03 · 河流地貌 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中地理必修一的"河流地貌"交互式 3D 网页。学习目标：学生通过看四个典型地貌的形成过程动画、读形成逻辑链、对照真实案例，掌握 V型谷、河漫滩、冲积平原、三角洲的成因机制、河段位置与堆积/侵蚀方向。

二、地理模型规格：
- 四个典型地貌与河段位置：V型谷=河流上游（落差大、下蚀为主，河谷加深成 V 形）；河漫滩=河流中游（侧蚀+堆积，凹岸侵蚀凸岸堆积）；冲积平原=河流下游（以堆积为主，如长江中下游平原）；三角洲=河口（流速骤减、泥沙快速沉积、从河口向海呈扇形推进）。
- 侵蚀/堆积方向（核心判据）：凹岸侵蚀、凸岸堆积，不得判反；河漫滩动画须标注"侵蚀岸"与"沉积岸"，河流向侵蚀岸偏移、对侧沉积。
- 形成逻辑链：V型谷"落差大→下蚀强烈→河谷加深→V形"；三角洲"河流入海→流速骤减→泥沙快速沉积→扇形堆积→三角洲向海推进"；溯源侵蚀方向指向上游。
- 真实案例（空间定位）：V型谷=雅鲁藏布江大峡谷（上游下蚀）；河漫滩=长江中游（凹岸侵蚀凸岸堆积）；冲积平原=长江中下游平原（下游堆积）；三角洲=黄河三角洲（河口堆积）。

三、交互与教学功能：①上端目录导航 + 详情卡，切换四个地貌；②每个地貌含形成过程动画（可播放/暂停/重置）、形成逻辑链、真实案例；③可拖动说明面板；④"观察与结论"区，引导归纳"凹岸侵蚀凸岸堆积、上游侵蚀下游堆积、三角洲从河口向外生长"。

四、工程与呈现约束：布局分"3D 场景区／地貌目录与详情区／逻辑链与结论区"多层；1440×900 分辨率下无遮挡、无溢出、3D 模型不溢出画布；所有按钮（播放/暂停/重置、地貌切换）为真实 button、有可见中文文字标签；3D 画布提供 aria-label（描述当前地貌与侵蚀/堆积方向）；**不得外链远程图片**（Wikipedia 等图片离线会加载失败），地貌示意一律用内联 SVG 或本地绘制；3D 实现用纯 Canvas 或内联 Three.js 单文件打包，不得依赖外网 CDN，且光源对象须正确加入场景（不得 `Object3D.add` 误用非 Object3D 实例）。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 凹凸岸判别核对（核心 B1 规避）：切换到河漫滩地貌，核对侵蚀岸=凹岸、堆积岸=凸岸，方向不得判反；河流向侵蚀岸偏移、对侧沉积；
2. 河段位置核对：V型谷=上游、河漫滩=中游、冲积平原=下游、三角洲=河口，四者河段对应全部正确，不得把冲积平原归上游或三角洲归中游；
3. 三角洲堆积方向核对：三角洲动画中堆积体必须从河口向海方向生长推进（扇形展开），不得反向（不得从海向河口堆积）；
4. 控制台与渲染自检（核心 B3 规避）：打开页面后控制台无任何红色错误；4 个地貌切换、播放/暂停/重置、面板拖动均生效；3D 场景无 `Object3D.add` 类异常；所有内联图示渲染正常、无 naturalWidth=0 的外链失败图；
5. 形成逻辑链核对：V型谷逻辑链"落差大→下蚀→V形"、三角洲"入海→流速骤减→沉积→扇形推进"，方向不可反；
6. 案例地名核对：V型谷=雅鲁藏布江大峡谷、河漫滩=长江中游、冲积平原=长江中下游平原、三角洲=黄河三角洲，案例与地貌河段一致；
7. 逐个操作地貌切换、播放/暂停/重置、面板拖动各一次，无报错、无 3D 崩溃、无远程图片加载失败。
