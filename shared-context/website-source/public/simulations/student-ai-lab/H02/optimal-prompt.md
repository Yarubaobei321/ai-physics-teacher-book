# H02 · 康乾盛世背后隐患及原因 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中历史的"康乾盛世背后的隐患及原因"互动网页。学习目标：学生通过看盛世全景数据、点开四大隐患卡片、读多维度根源剖析、对照时间线，理解盛世表象下的隐患及其对后世的因果影响。

二、史实模型规格（年代/事件须与统编教材逐条可考）：
- 时代与帝王：康乾盛世指康熙—雍正—乾隆三朝（康熙 1662—1722、雍正 1723—1735、乾隆 1736—1795），盛清国力顶峰。
- 盛世数据（教材级 ballpark）：乾隆五十五年（1790）人口突破 3 亿；户部存银约 7894 万两；《四库全书》收书 3503 种；疆域达 1300 多万平方公里；马戛尔尼使团 1793 年来华，乾隆"天朝物产丰盈无所不有"。
- 四大隐患：人口爆炸（人地矛盾）、税制僵化（永不加赋—摊丁入亩后财政固化）、闭关锁国（一口通商）、白银依赖（白银流入未转化为资本、鸦片输入致外流）。
- 关键时间线节点（时序不得错置）：1712 永不加赋→1724 摊丁入亩→1757 一口通商（闭关锁国强化）→1793 马戛尔尼使团→1840 鸦片战争。
- 因果方向（核心判据，方向不可反）：闭关锁国为因非果——"闭关锁国→拒绝外交→错失工业革命→差距拉大→鸦片战争惨败"，不得颠倒为"列强入侵→被迫闭关"；白银链"白银流入→未转化资本→鸦片输入致白银外流→银贵钱贱→鸦片战争"，方向不可反。
- 术语规范：永不加赋、摊丁入亩、耗羡归公、一口通商、银贵钱贱、天朝上国、奇技淫巧、朝贡体系。

三、交互与教学功能：①盛世全景（疆域/人口/国库/粮食/外贸/文化等维度数据卡，每项配一句"暗流提示"）；②四大隐患卡片（人口爆炸/税制僵化/闭关锁国/白银依赖），点击展开"盛世表现 vs 同期隐患"对比双栏；③每张卡片附"制度/经济/社会/观念"多维度根源剖析；④后世影响链（箭头因果图）；⑤底部时间线（1712/1724/1757/1793/1840）。

四、工程与呈现约束：布局分"盛世全景区／隐患卡片对比区／根源剖析区／影响链与时间线区"多层；1440×900 分辨率下无遮挡、无溢出；明亮暖白底高对比，古铜金/暗红主题契合历史叙事；**隐患卡片为真实 button（含 role/tabindex/aria-label）**，不仅靠 1-4 数字键可达；正文字号≥0.9rem；不得使用外链外部模块。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 年代对照教材核对（核心 A4 补全 + B1 规避）：逐条把时间线年代与统编教材对一遍——1712 永不加赋、1724 摊丁入亩、1757 一口通商、1793 马戛尔尼使团、1840 鸦片战争，五个年代与事件均须对应正确、时序先后不得错置；
2. 因果方向核对（核心 B1 规避）：闭关锁国链须为"闭关锁国→拒绝外交→错失工业革命→差距拉大→鸦片战争惨败"——闭关锁国为因非果，不得颠倒为"列强入侵→被迫闭关"；白银链方向"白银流入→未转化资本→鸦片输入致外流→银贵钱贱→鸦片战争"不可反；
3. 朝代年号核对：康熙（1662—1722）、雍正（1723—1735）、乾隆（1736—1795）三代不得错挂；乾隆五十五年（1790）人口突破 3 亿、马戛尔尼 1793 来华、户部存银约 7894 万两、《四库全书》3503 种，关键数据须与教材一致；
4. 盛世表现 vs 同期隐患对比核对：每张隐患卡片的"盛世表现"与"同期隐患"双栏内容须指向同一时间窗（康乾时期），不得把后世事件（如鸦片战争）作为盛世表现；
5. 根源剖析维度核对：每张卡片附"制度/经济/社会/观念"四维度剖析，层次分明，不得遗漏维度或与卡片主题不符；
6. 工程核对（B4 规避）：四张隐患卡片为真实 button 含 aria-label（不仅靠数字键）；点击切换、默认激活首卡、键盘 1-4 切换均生效；控制台无错误；逐个操作各卡片、时间线节点各一次，无报错、无失效。
