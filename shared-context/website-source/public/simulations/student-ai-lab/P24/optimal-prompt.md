# P24 · 机械能守恒定律 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"机械能守恒定律"闯关式学习页，四个关卡依次解锁：情境引入 → 单摆实验 → 规律总结 → 例题闯关。学习目标：学生按关卡完成观察、归纳与应用，掌握机械能守恒的条件与使用。

二、物理模型规格：单摆实验关：摆长 L、摆角 θ，以最低点为零势能面（页面声明），h=L(1−cosθ)、Ep=mgh、Ek=½mv²、E 恒定；忽略阻力（页面声明）；数值实现必须保证能量不漂移（用解析角度解或对数值积分做能量校正）；g=9.8 m/s²；例题关：每题的正确答案必须先经解析计算得出，再放入选项——正确数值必须出现在选项中且判定逻辑与解析一致；SI 单位。

三、交互与教学功能：关卡导航条显示解锁状态，完成当前关才解锁下一关；引入关：生活情境（过山车/秋千）配简短动画与提问；实验关：L（0.5–2 m）、θ₀（5°–60°）滑块，播放/暂停，实时 Ek/Ep/E 读数与能量条形图；总结关：结论填空（守恒条件与表达式），判定后展示规范表述；例题关：至少 3 道选择题，提交出对错与解析步骤；全部通关显示完成页；页面设"闯关记录"区。

四、工程与呈现约束：单文件内多关卡视图；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 实验关连续运行 60 s：E 相对偏差始终 <1%（能量不得单调漂移）；
2. L=1 m、θ₀=30°：手算最低点 v≈1.62 m/s，与读数对比；
3. 例题关逐题验证：按解析步骤手算正确答案，确认该数值出现在选项中且选择后判定为正确；
4. 解锁逻辑：未完成实验关时总结关与例题关不可进入；完成后依次解锁；
5. 所有控件各操作一次，无报错、无失效。
