⚠ 概念提醒：苯环（—C₆H₅）与碳氢键（C–H）不是官能团。官能团是决定有机物化学特性的原子或原子团：碳碳双键 C=C、羟基 –OH、醛基 –CHO、羧基 –COOH 等。苯环只是不饱和的碳环骨架，其 "稳定" 来自大 π 键的共轭，与官能团的反应活性来源不同。
⚠ 苯环不是官能团：苯环（C₆H₅–）与 C–H 碳氢键都不属于官能团。学习时注意区分：能发生特征反应、决定有机物主要化学性质的是 C=C、–OH、–CHO、–COOH 等官能团。

有机转化规律与反应条件

① 醇 → 醛 → 羧酸（氧化 / 还原）

2C₂H₅OH (l) + O₂ (g) →（催化剂 Cu，加热）2CH₃CHO (l) + 2H₂O (l)
2CH₃CHO (l) + O₂ (g) →（催化剂，加热）2CH₃COOH (l)
醇催化氧化断 α-C–H 与 O–H 键生成醛；醛进一步氧化生成羧酸。反向还原（加氢）可逆推。

② 烯烃加成 / 水合（常温或催化）

CH₂=CH₂ (g) + Br₂ (l) →（常温，溴水/CCl₄）CH₂Br–CH₂Br (l)
CH₂=CH₂ (g) + H₂O (g) →（催化剂，加热，水合）C₂H₅OH (l)
CH₂=CH₂ (g) + H₂ (g) →（Ni，加热）CH₃CH₃ (g)
C=C 断裂 π 键、形成新 σ 键为加成反应（非取代）。烯烃 + Br₂ 为常温加成；烷烃 + Cl₂ 须光照才取代，两类条件不得混用。

③ 酯化反应（可逆）

CH₃COOH (l) + C₂H₅OH (l) ⇌（浓硫酸，加热）CH₃COOC₂H₅ (l) + H₂O (l)
酸脱 –OH、醇脱 –O–H 上的 H——即酸脱羟基醇脱氢。浓硫酸作催化剂与吸水剂，反应可逆，用 ⇌。

④ 反应类型判定速查

C=C + Br₂ / H₂ / H₂O / HCl → 加成（常温或催化）
CH₄ + Cl₂ → 取代（光照）
判定口诀：不饱和键（C=C/C≡C）倾向加成；饱和烃（C–H 单键）在光照下取代。加成不换原子、取代有原子被替换。
