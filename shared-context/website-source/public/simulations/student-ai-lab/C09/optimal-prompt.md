# C09 · 有机智学堂 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一化学的"有机智学堂"综合互动教学。学习目标：学生通过三模块（核心官能团 + 有机转化规律 + 高考真题练习），掌握 C=C、–OH、–CHO、–COOH 四大官能团的特征反应、醇→醛→羧酸的转化链、并能判断加成位置（1,2- vs 1,1-）与反应条件（加成 vs 取代）。

二、化学模型规格：
- 四大核心官能团：碳碳双键 C=C、羟基 –OH、醛基 –CHO、羧基 –COOH；**附"苯环与碳氢键不是官能团"的概念提醒**。
- 典型反应方程式（必须配平、标注反应条件、状态符号 (g)/(l)/(aq)、有机反应用箭头 → 而非等号 =）：
  · 烯烃加成：CH₂=CH₂ + Br₂ →(常温，溴水/CCl₄) CH₂Br–CH₂Br（1,2-二溴乙烷，**非 1,1-**；**条件是常温而非光照**——光照属烷烃取代条件，不得混用）；
  · 醇催化氧化：2C₂H₅OH + O₂ →(催化剂 Cu，加热) 2CH₃CHO + 2H₂O（断 α-C–H 与 O–H 键）；
  · 醛银镜氧化：CH₃CHO + 2[Ag(NH₃)₂]OH → CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O（N=6、Ag=2 守恒）；
  · 酯化（可逆）：CH₃COOH + C₂H₅OH ⇌(浓硫酸，加热) CH₃COOC₂H₅ + H₂O（酸脱 –OH、醇脱 –O–H 上的 H）。
- 反应机理：醇催化氧化断 α-C–H 与 O–H；酯化"酸脱羟基醇脱氢"；烯烃加成 π 键断 + 新 σ 键成。
- 转化链总图：醇 ⇄ 醛 ⇄ 羧酸（氧化/还原方向），烯烃加成/水合，酯化可逆；箭头方向标注条件。
- 反应类型判定：加成（C=C+Br₂/H₂/H₂O/HCl）非取代；烯烃+Br₂ 常温加成；烷烃+Cl₂ 光照才取代——两类条件不得混。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. **加成 1,2- 位置核对（核心验收）**：点击烯烃加成反应，产物必须是 1,2-二溴乙烷 BrCH₂CH₂Br（两个 Br 加在不同碳上），不得写成 1,1-二溴乙烷 CH₃CHBr₂；
2. **反应条件核对（B1 规避学生条件错误）**：CH₂=CH₂+Br₂ 的反应条件必须标注为"常温（溴水/CCl₄）"，**不得标"光照"**——光照是烷烃取代（CH₄+Cl₂）的条件，两类条件不得混；
3. **守恒核对**：CH₃CHO+2[Ag(NH₃)₂]OH→CH₃COONH₄+2Ag↓+3NH₃+H₂O 两边 N=6、Ag=2、C=2、H 与 O 守恒；2C₂H₅OH+O₂→2CH₃CHO+2H₂O 两边 C=4、H=12、O=4；

6. **官能团概念边界**：苯环与碳氢键必须标注"不是官能团"，四大官能团 C=C / –OH / –CHO / –COOH 命名准确；
