# M10 · 五点作图法 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中数学课堂的「五点作图法」交互学习页。学习目标：学生通过 y=A sin(ωx+φ)+b 的参数滑块、五点坐标实时列表、波形绘制，掌握正弦型函数的振幅 A、角频率 ω、初相 φ、竖直位移 b 的几何含义与五点作图法（θ=0, π/2, π, 3π/2, 2π 五个关键相位）。

二、数学模型规格：通式 y=A sin(ωx+φ)+b；参数范围 A∈[0.1,3]、ω∈[0.5,3]、φ∈[−π,π]、b∈[−3,3]，弧度制；周期 T=2π/|ω|；振幅=|A|，最值范围 [b−|A|, b+|A|]；重置目标 A=1, ω=1, φ=0, b=0（基础函数 y=sin x）；五点相位固定取 x_相=0, π/2, π, 3π/2, 2π，对应函数值 y=A sin(ω·x_相+φ)+b；显示初相 φ 时必须对极小浮点残留（如 |φ|<1e-6）做硬归零处理，不得出现 0.01、−0.00 等残留显示。

三、交互与教学功能：左栏讲解五点作图法原理、y=A sin(ωx+φ)+b 通式、A/ω/φ/b 各参数对图像的影响（A 控制振幅最值、ω 控制周期、φ 控制左右平移、b 控制上下平移）；右栏画布绘制波形并标注五点坐标；控制区含 A/ω/φ/b 四个滑块与「重置」按钮；每次滑块变动，五点坐标列表、解析式、周期 T、最值读数实时同步联动；五点坐标以表格形式列出（相位 | 函数值），便于学生手算核对；底部设「观察与结论」区引导归纳四参数的几何意义。

四、工程与呈现约束：布局分「讲解区／画布区／控制与读数区」三栏，1440×900 分辨率下无遮挡、无溢出；所有滑块、按钮有可见中文标签；滑块用真实 <input type="range"> 与 <button>，不得用 div 当按钮；canvas 加 aria-label 描述当前解析式与五点坐标；所有公式用 Unicode 或内联 KaTeX 渲染，不依赖外网 MathJax；初相显示前必须对浮点残留做硬归零。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 取 A=2, ω=1, φ=0, b=0：五点相位 x_相=0,π/2,π,3π/2,2π 对应函数值手算为 0, 2, 0, −2, 0，峰值点应为 (π/2, 2)，与页面五点坐标列表逐项对比；
2. 重置后 φ 必须精确显示为 0（不得出现 0.01、−0.00、≈−0.0016 等浮点残留），A=1,ω=1,φ=0,b=0 时解析式应为 y=sin x；
3. 周期验收：取 A=1, ω=2, φ=0, b=0，周期 T=2π/|ω|=2π/2=π，波形一个完整周期的横向间距应等于 π；
4. 取 A=2, ω=1, φ=0, b=0：最值范围应为 [b−|A|, b+|A|]=[−2, 2]，波形峰值读数=2、谷值=−2（振幅=|A|）；
5. 滑动 ω 至 3 时周期 T 应为 2π/3，波形变密；滑动 φ 时波形左右平移而形状不变——验证参数独立性；
6. A/ω/φ/b 四滑块各操作一次、重置按钮操作一次，无 console 报错、无失效；canvas 有 aria-label。
