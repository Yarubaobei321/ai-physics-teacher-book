反应类型：取代反应
典型反应：CH₄(g) + Cl₂(g) →(光照) CH₃Cl(g) + HCl(g)
CH₄(g) + Cl₂(g) →(光照) CH₃Cl(g) + HCl(g)
光照使 Cl₂ 离解为 Cl 自由基；Cl 自由基夺取 CH₄ 中的一个 H。旧键断裂：Cl–Cl 与 C–H；新键形成：C–Cl 与 H–Cl。属自由基取代反应（不属于加成）。
结构简式：CH₄ + Cl₂ → CH₃Cl + HCl
实验现象：黄绿色气体颜色变浅；试管内壁出现油状液滴（CH₃Cl）；容器口出现白雾（HCl 遇水蒸气）。

观察与结论

官能团决定反应性：含 C=C 的烯烃倾向加成 / 加聚；含 —OH 的醇可酯化或消去；含 —CHO 的醛可被氧化为羧酸；含苯环的芳香烃可硝化、卤代。
结构决定性质：饱和烷烃只发生取代；不饱和烯烃 π 键打开而加成；羧酸与醇相遇即酯化；醛基的氧可被银氨溶液识别为"银镜反应"。
新旧键断裂与形成：每个反应都对应"旧键断裂 + 新键形成"；红色高亮活跃键（M01 标记）能在 3D 模型中直观看到化学键层面的变化。
