# C02 · 有机物的结构和反应 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中化学课堂的"有机物结构与反应"3D 交互教学。学习目标：学生通过切换 6 类代表物球棍模型、读典型反应机理、对比反应类型表，归纳出官能团决定反应性的规律。

二、化学模型规格：覆盖 6 类有机物代表物，每个分子用球棍模型精确呈现，相同元素原子同色（碳深灰、氢白、氧红），**单键画一根圆柱、双键画两根平行圆柱、三键画三根平行圆柱**——双键/三键不得画成单圆柱以免碳视觉似三价：
- 烷烃：甲烷 CH₄（4 C–H，正四面体 H-C-H 键角 109.5°，4 个 H 取 (±1,±1,±1) 归一化顶点）、乙烷 C₂H₆、丙烷 C₃H₈；
- 烯烃：乙烯 C₂H₄（C=C 平行双键 + 4 C–H，平面型 sp²，每 C 连 2H+1C(双键)=4 价）；
- 醇：乙醇 C₂H₅OH（C–C–O + O–H，O 二价）；
- 羧酸：乙酸 CH₃COOH（甲基碳 4 单键；羰基碳连 =O、–OH、–CH₃，C=O 双键画两根圆柱）；
- 芳香烃：苯 C₆H₆（6 C–C + 6 C–H，苯环大 π 键）；
- 醛：甲醛 HCHO（C=O 双键 + 2H，C=O 画两根圆柱）。
每类配一条典型反应及已配平方程式，标注反应条件与状态符号 (g)/(l)/(aq)：取代（CH₄+Cl₂→(光照)CH₃Cl+HCl）、加成（C₂H₄+Br₂→(常温,CCl₄)BrCH₂CH₂Br，1,2-二溴乙烷非 1,1-）、消去（C₂H₅OH→(浓硫酸,170℃)CH₂=CH₂↑+H₂O）、酯化（CH₃COOH+C₂H₅OH⇌(浓硫酸,△)CH₃COOC₂H₅+H₂O，可逆号）、硝化（C₆H₆+HNO₃→(浓H₂SO₄,△)C₆H₅NO₂+H₂O）、氧化银镜（HCHO+2[Ag(NH₃)₂]OH→HCOONH₄+2Ag↓+3NH₃+H₂O，N=6、H 守恒）。反应类型判定准确：加成非取代、1,2- 非 1,1-、酯化用可逆号。

三、交互与教学功能：左侧 8 个分子按钮（甲烷/乙烷/丙烷/乙烯/乙醇/乙酸/苯/甲醛）点击切换 3D 球棍模型，OrbitControls 可拖拽缩放；右侧反应面板显示当前分子所属反应类型、方程式、反应描述、新旧键断裂/形成（活跃键红色高亮）、结构简式与实验现象行；右上反应类型对比表（反应类型/条件/反应物·生成物特点）可折叠展开。每个分子切换时在面板显著位置列出分子式，方便学生数 C/H/O 原子核对碳四价。

四、工程与呈现约束：布局分"分子按钮列／3D 画布区／反应面板+对比表"三栏，深色毛玻璃 + 星空背景课堂版；1440×900 分辨率下无遮挡、无溢出；所有按钮为真实 <button>；**对比表表头凡带 cursor:pointer、🔽 图标或 hover 变色的元素必须绑定点击事件——若不绑定事件则必须去除可点击外观**（避免"看起来可点却无响应"的交互语义 bug）；表格正文与脚注字号 ≥12px（约 0.8rem），适配课堂大屏；3D canvas 加 aria-label。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 双键球棍可视化（核心，B1 warning 规避）：逐个点击乙烯/乙酸/苯/甲醛，C=C 或 C=O 必须画成两根平行圆柱（而非单根），每个碳视觉上仍满四价；甲烷必须为正四面体构型（任意两个 H-C-H 键角≈109.5°，不得为平面十字）；
2. 分子式原子计数核对：切换每个分子后数 C/H/O——甲烷 1C+4H、乙烷 2C+6H、丙烷 3C+8H、乙烯 2C+4H、乙醇 2C+6H+1O、乙酸 2C+4H+2O、苯 6C+6H、甲醛 1C+2H+1O，与页面分子式一致；
3. 反应类型与位置核对：乙烯按钮显示"加成反应"且产物为 1,2-二溴乙烷（BrCH₂CH₂Br，两 Br 加在不同碳上），不得误写取代或 1,1-二溴乙烷；甲烷+Cl₂ 标"取代反应"；酯化用可逆号⇌；
4. 方程式状态符号与条件：每条方程式必须标注反应条件（光照/常温 CCl₄/浓硫酸 170℃ 等）与状态符号 (g)/(l)/(aq) 与沉淀/气体 ↓/↑；
5. 守恒核对：HCHO+2[Ag(NH₃)₂]OH→HCOONH₄+2Ag↓+3NH₃+H₂O 两边 N=6、Ag=2，原子守恒；
6. 交互语义一致性：对比表表头凡可点外观的元素均必须绑定事件，点击有可观察响应；不可点的元素不得有 cursor:pointer/🔽/hover 变色等误导外观；
7. 排版可读：表格正文与脚注字号 ≥12px（≥0.8rem），无 console 报错；8 个分子按钮 + 折叠/显示隐藏各操作一次，无失效。
