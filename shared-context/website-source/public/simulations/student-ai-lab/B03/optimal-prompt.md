# B03 · 孟德尔自由组合定律 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中必修二课堂的"孟德尔自由组合定律"交互模拟。学习目标：学生通过随机组合亲本、抽选配子、统计 F2 与测交后代，能归纳出 F2 性状分离比为 9:3:3:1、测交后代比为 1:1:1:1，并理解重组型是相对当前亲本而言的。

二、生物模型规格：以豌豆两对相对性状为模型——黄色（Y）/绿色（y）、圆粒（R）/皱粒（r），Y/y、R/r 为等位基因，完全显性；亲本 P 基因型可在九种中随机组合：YYRR、YYRr、YYrr、YyRR、YyRr、Yyrr、yyRR、yyRr、yyrr，各显示对应表现型（黄/绿、圆/皱）；F1 由双亲配子随机受精产生，配子按"等位基因分离 + 非等位基因自由组合"生成，配子种类数 = 2ⁿ（n 为亲本杂合基因对数，如 YYRR→1 种、YyRr→4 种）；F1 自交（YyRr×YyRr）给出 F2 理论性状分离比 9:3:3:1（黄圆:黄皱:绿圆:绿皱），并列出各表现型包含的基因型；测交模块 F1×隐性纯合 yyrr，理论后代比为 1:1:1:1。
**关键修正——重组/亲本型标签必须根据当前实际亲本动态判定**：某一子代基因型是否为"重组型"应相对于当前两个亲本的基因型组合判定（凡与亲本表现型不同的即为重组型），不得写死为"黄皱/绿圆是重组型"。例如亲本为 YYrr×yyRR 时，亲本型应为黄皱/绿圆，重组型应为黄圆/绿皱；亲本为经典 YYRR×yyrr 时，亲本型为黄圆/绿皱，重组型为黄皱/绿圆。判定逻辑必须读当前亲本状态，不得固定文案。

三、交互与教学功能：模块一"亲本与 F1"：随机组合双亲（从九种基因型随机）、重置为经典亲本（YYRR×yyrr）、随机抽选雌/雄配子并模拟受精，显示合子基因型与表现型；模块二"F2 理论比例"：根据当前 F1 计算 F2 理论 9:3:3:1 及各表现型基因型，标注哪些是亲本型、哪些是重组型（动态）；模块三"测交"：可重复执行 F1×yyrr 并累计统计各表现型计数与百分比，显示"测交后代统计（共 N 次）"，与理论 1:1:1:1 对照；模块四"配子随机结合"：可多次随机抽选配子看合子结果；事件日志带可回溯时间戳。

四、工程与呈现约束：四模块分区清晰，黄/绿配色与性状语义一致；1440×900 分辨率下无遮挡、无溢出；所有按钮为真实 <button>、带可见文字标签且不小于 0.8rem；配子 chip 若可点击则用 <button> 而非 div，保证键盘可达；加 aria-label；亲本型/重组型徽章对照条颜色醒目。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. **重组标签动态判定（核心）**：点击"随机组合双亲"多次，当随机到 YYrr×yyRR 时，页面应将黄圆/绿皱标为"重组型"、黄皱/绿圆标为"亲本型"；切回经典 YYRR×yyrr（重置经典）后，应将黄皱/绿圆标为"重组型"、黄圆/绿皱标为"亲本型"——两次状态下的标签必须相反，不得固定；
2. 经典亲本 YYRR×yyrr：F1 应为 YyRr（黄圆）；F1 自交 F2 理论比应为 9:3:3:1（黄圆:黄皱:绿圆:绿皱），各占比 56.25%/18.75%/18.75%/6.25%；
3. 测交模块累计执行约 100 次（或较多次数）后，四种表现型（黄圆/黄皱/绿圆/绿皱）计数应各约占 25%，与理论 1:1:1:1 自洽（小样本允许波动）；
4. 配子种类数随亲本杂合度变化：YYRR→1 种、YyRr→4 种，页面显示的配子种类数应与此一致；
5. 页面脚注/文案中关于"重组基因型包括哪几种"的描述，必须随当前亲本动态更新，不得固定写"黄皱和绿圆"；
6. 所有主按钮（随机组合双亲/重置经典/随机结合/执行测交/随机母本/随机父本/雌配子/雄配子/重置配子/重置测交）各点击一次，无报错、无失效，亲本变更时测交记录自动重置。
