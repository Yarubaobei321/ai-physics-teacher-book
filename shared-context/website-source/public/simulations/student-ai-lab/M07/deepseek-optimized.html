📈 线性回归 · 最小二乘法（OLS）

拖拽/点击加点 → 观察拟合直线、样本中心 (x̄,ȳ) 与决定系数 R² —— 高中数学互动课堂

一、原理讲解

最小二乘法：寻找一条直线 y=a·x+b，使所有样本点到该直线竖直距离的平方和（残差平方和 SSE）最小。它是描述两个变量之间相关关系的经典方法——注意是「相关关系」，不是「因果关系」。

解析式

y = a·x + b
  • 斜率：a = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²
  • 截距：b = ȳ − a·x̄
  • 样本中心：(x̄, ȳ) —— 回归线必过此点
  • 残差平方和：SSE = Σ(y − ŷ)²
  • 总平方和：SST = Σ(y − ȳ)²
  • 决定系数：R² = 1 − SSE/SST ∈ [0,1]

R² 的含义

R² 衡量回归线对数据的解释程度：R²=1 表示所有点恰好落在直线上（完全拟合）；R²=0 表示直线毫无解释力（等价于直接用 ȳ 预测）。数值越接近 1，拟合越好。

AI 原理卡片

🤖 符号主义 × 连接主义 联想

符号主义：最小二乘给出封闭解析式 y=a·x+b，如同符号推理给出「规则」。

连接主义：从数据中逐步调整参数使误差最小，类似神经网络靠数据「学习权重」。

——以上仅作联想启发，不替代本页的回归数学本身。

⚠️ 使用边界（重要） 回归线仅在样本 X 区间内有效，不应外推到样本区间之外。样本外的数据可能完全偏离该直线关系。

三、学习助手

五步操作闭环：讲解 → 解析式 → 实时读数 → 归纳。建议尝试顺序：

  1. 点击「加载示例」观察接近直线的数据；
  2. 对照左侧解析式手算 OLS 值；
  3. 确认回归线穿过样本中心 (x̄,ȳ)；
  4. 把所有点拖成一条完美直线，观察 R² → 1；
  5. 把所有点拖到同一竖直线，观察优雅提示。
  • 斜率 a > 0：x 增大时 y 总体增大（正相关）；a < 0：负相关；a≈0：接近无关。
  • 回归线必过样本中心 (x̄,ȳ)，这是由 b=ȳ−a·x̄ 保证的几何性质。
  • R² 越接近 1，说明自变量对因变量的解释能力越强；但强相关 ≠ 因果。
  • 样本中有一个点离群时，最小二乘对离群点敏感，可对比拖动前后的 a 变化。
  • 至少需要 2 个点，且不能全部位于同一条竖直线上（否则 Σ(x−x̄)²=0，斜率无定义）。
  • 注意外推风险：回归线只在样本 X 区间内有统计学意义。
