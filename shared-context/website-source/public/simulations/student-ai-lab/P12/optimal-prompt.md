# P12 · 单摆-机械能守恒单摆 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"单摆机械能守恒"交互仿真。学习目标：学生通过观察摆动中 Ek、Ep 的此消彼长与 E 的恒定，能表述机械能守恒的条件与内容。

二、物理模型规格：单摆摆长 L、摆角 θ；以最低点为零势能参考平面（页面显式声明）；h=L(1−cosθ)，Ep=mgh，Ek=½mv²，E=Ep+Ek 恒定；g=9.8 m/s²；忽略空气阻力与摩擦（页面声明）；数值实现必须保证长时间运行能量不漂移（用解析角度解，或对数值积分做能量校正）；SI 单位。

三、交互与教学功能：L（0.5–2 m）、初始摆角 θ₀（5°–60°）、m（0.5–2 kg）滑块；播放/暂停/重置；实时显示 θ、v、Ek、Ep、E（带单位）与三色能量条形图；E 的相对偏差百分比显示；E 随时间折线（应为水平线）；页面设"观察与结论"区。

四、工程与呈现约束：布局分"画布区／控制区／数据区"；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. L=1 m、θ₀=30°：手算 h₀=L(1−cos30°)≈0.134 m、最低点 v=√(2gh₀)≈1.62 m/s，与最低点读数对比；
2. θ₀ 改 60°：手算最低点 v=√(2gL(1−cos60°))≈3.13 m/s，复测一次；
3. 连续运行 60 s，E 相对偏差始终 <1%；
4. 暂停时读数冻结且 Ep+Ek=E 自洽；
5. 所有控件各操作一次，无报错、无失效。
