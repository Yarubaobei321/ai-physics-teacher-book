# C04 · 乙烯的加成反应 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中化学课堂的"乙烯的加成反应"3D 交互演示。学习目标：学生通过看乙烯结构与性质说明、看六个加成反应的分步动画（π 键断裂→过渡态→σ 键形成），理解 C=C 双键中 π 键易断裂是加成反应活性的根源，并能判断 1,2-加成产物。

二、化学模型规格：乙烯 C₂H₄ 为平面型 sp² 杂化，键角约 120°，C=C 一根 σ + 一根 π（π 键暴露、键能较低、易断裂决定反应性），每 C 连 2H+1C(双键)=4 价；球棍模型 C=C 画两根平行圆柱。化学键长度按真实键长比例：C=C 0.134 nm、C–C 0.154 nm、C–H 0.109 nm。六种加成反应方程式与条件（必须配平、标注催化剂/温度/CCl₄ 等条件与状态符号 (g)/(l)/(aq)）：
- C₂H₄ + H₂ →(催化剂 Ni，加热) C₂H₆（乙烷）；
- C₂H₄ + Cl₂ →(常温) ClCH₂CH₂Cl（1,2-二氯乙烷）；
- C₂H₄ + HCl →(加热) CH₃CH₂Cl（氯乙烷）；
- C₂H₄ + H₂O →(催化剂，加热加压) C₂H₅OH（乙醇）；
- C₂H₄ + Br₂ →(常温，CCl₄) BrCH₂CH₂Br（1,2-二溴乙烷）；
- C₂H₄ + HCN →(催化剂) CH₃CH₂CN（丙腈，C≡N 三键）。
所有反应均为加成（π 键断→σ 键成），不得误写为取代；Br₂/Cl₂ 产物必须是 1,2-二卤乙烷（两个卤素加在不同碳上），不得写成 1,1-（CH₃CHX₂）。

三、交互与教学功能：3D 画布显示乙烯可旋转缩放球棍模型；底部反应按钮组（H₂/Cl₂/HCl/H₂O/Br₂/HCN/重置）点击触发对应加成反应分步动画（π 键断裂 → 过渡态 → σ 键形成），步骤提示文字与符号表征同源，完成后显示产物分子式与名称；侧边/底部"乙烯性质与结构说明"区讲解 C=C、π 键暴露、易断裂原因；原子图例放侧边不遮挡中央视图。

四、工程与呈现约束：布局分"3D 画布区／反应按钮组／性质说明区"三栏，深色毛玻璃 + 大字体课堂版；1440×900 分辨率下无遮挡、无溢出；**底部提示条(.instruction)与反应按钮组(.reaction-dock)不得同高重叠**——提示条应放置在反应按钮组上方或下方独立一行，z-index 与定位不得冲突；所有按钮为真实 <button>、带可见文字标签（≥0.8rem）；3D canvas 加 aria-label；原子图示标注使用 CSS3D（跟随 3D 转动）而非静态 CSS2D（不跟随）；OrbitControls 构造器传入 renderer.domElement 不得抛错。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. **加成位置 1,2- 核对（核心）**：点击 Br₂ 反应按钮，产物必须是 1,2-二溴乙烷 BrCH₂CH₂Br（两个 Br 分别加到两个不同碳上），不得写成 1,1-二溴乙烷 CH₃CHBr₂；Cl₂ 反应同样为 1,2-二氯乙烷；
2. 守恒核对：逐反应数两边 C/H/卤素原子——C₂H₄+Br₂→BrCH₂CH₂Br 两边各 2C、4H、2Br；C₂H₄+H₂O→C₂H₅OH 两边各 2C、6H、1O；C₂H₄+HCN→CH₃CH₂CN 两边各 3C、5H、1N；
3. 反应类型判定：六个反应全部为加成（π 键断→σ 键成），不得误写取代；动画时序必须呈现"π 键先断开 → 过渡态 → σ 键形成"；
4. 碳四价与键级：所有产物每个碳均满四价（如 1,2-二溴乙烷每 C 连 2H+1C+1Br=4 价），丙腈 CH₃CH₂CN 中 C≡N 三键三根圆柱；
5. 状态符号与条件：六条方程式均标注反应条件（催化剂/加热/常温 CCl₄ 等）与状态符号 (g)/(l)/(aq)，不得省略；
6. 布局无重叠（B3 规避）：底部提示条与反应按钮组在 1440×900 下不得同高重叠，操作反应按钮不被提示条遮挡；
7. 键长比例：3D 球棍模型 C=C 键长 ≈ C–C 键长 × 0.87（0.134/0.154），不得明显失真；
8. 交互完整性：H₂/Cl₂/HCl/H₂O/Br₂/HCN/重置 7 按钮各操作一次，OrbitControls 拖拽缩放可用，无 console 报错。
