🔺 正弦定理 (Sine Rule)

a/sinA = b/sinB = c/sinC = 2R
📐 证明（外接圆法）
作△ABC的外接圆，半径为R。连接直径BD，则∠BCD=90°，∠D=∠A。
在Rt△BCD中，BC = BD·sin∠BDC → a = 2R·sinA → a/sinA = 2R。
同理 b/sinB = 2R, c/sinC = 2R，得证。
✍️ 适用题目类型：
① 已知两角一边，求其它边角；② 已知两边及其中一边对角，判断三角形解的个数。
例: △ABC中，A=30°, B=45°, a=10，求b。
解: b = a·sinB/sinA = 10·(√2/2)/(1/2) = 10√2 ≈14.14。

📐 余弦定理 (Cosine Rule)

c² = a² + b² - 2ab·cosC
🧭 向量法证明（粗体a, b, c 表示向量）
设△ABC中，AB = c，BC = a，CA = b，满足 a + b + c = 0。
考虑 c = -(a+b)，则 |c|² = (a+b)·(a+b) = |a|² + |b|² + 2a·b。
而 a·b = |a||b|·cos(π-C) = -ab·cosC (夹角为π-C)。
代入得 c² = a² + b² - 2ab·cosC，得证。
✍️ 适用题目类型：
① 已知两边及其夹角求第三边；② 已知三边求角；③ 判断三角形形状。
例: △ABC中，a=7, b=5, C=60°，求c。
解: c² = 49+25-2·7·5·cos60° = 74-35 =39 → c = √39 ≈6.245。
