# M03 · 三角函数的性质与运用 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一数学课堂的「三角函数的性质与运用」综合学习页。学习目标：学生通过单位圆、sin/cos/tan 分图、诱导公式、正余弦定理，掌握三角函数的周期性、奇偶性、单调性及在解三角形中的应用。

二、数学模型规格：弧度制统一，角度 θ 与单位圆动点 (cosθ, sinθ) 一一对应；sin/cos 周期 T=2π、tan 周期 T=π（周期性条件 θ→θ+2kπ 与 θ→θ+kπ，k∈Z）；诱导公式 sin(π-θ)=sinθ、cos(π-θ)=-cosθ、sin(π+θ)=-sinθ、tan(θ+π)=tanθ；正弦定理 a/sinA=b/sinB=c/sinC=2R，余弦定理 c²=a²+b²-2ab·cosC；tan 在 θ=π/2+kπ（k∈Z）无定义，渐近线须标出；向量统一用粗斜体字母（如 **a**、**b**）排版，不得用代码字体；坐标横轴弧度制并标注 rad。

三、交互与教学功能：至少四个分区——①单位圆动画（动点绕单位圆运动，复位按钮复位到 60°=π/3，显示 sin/cos/tan 投影）、②sin/cos/tan 三个分图（同横轴对照，tan 图须标渐近线）、③诱导公式区（列举 5 组以上诱导公式，并配一个可交互示例：输入 θ 显示 sin(π-θ) 与 sinθ 的数值，验证两者相等）、④正余弦定理证明区（向量法或坐标法框架，含一个可输入三边/三角的算例）；复位按钮可一键将动点与读数归位 60°；底部设「观察与结论」区，引导归纳周期、奇偶、单调性。

四、工程与呈现约束：布局分「画布区／控制区／数据区」三栏；1440×900 分辨率下无遮挡、无溢出；所有按钮、输入框均有可见中文标签；canvas 提供替代文本（aria-label 描述当前角度与函数值）；向量与公式排版统一用数学字体（粗斜体向量、Unicode 或内联 KaTeX），不出现代码等宽字体；tan 无定义点不得画成连续曲线。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 单位圆动点 θ=π/2 时：sinθ=1、cosθ=0、tanθ 必须显示「无定义」或趋近渐近线，不得给出有限值；
2. 诱导公式交互示例：输入 θ=π/6，sin(π-θ)=sin(5π/6)=1/2 与 sinθ=sin(π/6)=1/2，两者数值必须相等；
3. 诱导公式：输入 θ=π/3，cos(π-θ)=cos(2π/3)=-1/2 与 -cosθ=-cos(π/3)=-1/2，两者必须相等；
4. 复位按钮：每次点击后动点与读数归位 θ=60°=π/3，sinθ=√3/2≈0.866、cosθ=1/2；
5. sin/cos/tan 三分图：sin/cos 周期 = 2π、tan 周期 = π，tan 在 π/2 与 3π/2 处出现渐近线（不连续）；
6. 正弦定理算例：a=6、A=30°、B=45°，按 a/sinA=2R 得 2R=12、R=6，b=2R·sinB=12·sin45°=6√2≈8.49；
7. 四个分区与复位按钮、诱导公式输入各操作一次，向量排版为粗斜体而非代码字体，无报错、无失效。
