✍️ 动词作非谓语

不定式 to do / 动名词 doing / 现在分词 doing / 过去分词 done —— 四种形式，一个核心：非谓语动词不随主语变位，但须与逻辑主语保持语态一致。选错 1 次可再试，连错 2 次才揭示答案。

📘 总述 · 四种形式

不定式

to do

表目的 / 将来 / 具体某次动作。如 to catch、to become、to be held。

动名词

doing

具名词性质，表习惯 / 抽象概念。如 Seeing is believing.、enjoy doing。

现在分词

doing

表主动 / 进行。如 Walking in the park、a boring movie（令人无聊的）。

过去分词

done

表被动 / 完成。如 Seen from the hill、a bored audience（感到无聊的）。

🧪 经典对比例句：forget to do vs forget doing

I forgot to lock the door.
忘记要锁门（门还没锁）→ 不定式表未做之事
I forgot locking the door.
忘记锁过门（门已锁）→ 动名词表已做过之事

🧠 逻辑主语一致（核心规则）

分词作状语时，其逻辑主语必须与主句主语一致，否则为垂悬分词错误。

❌ 错例：Walking down the street, the trees were beautiful.（分词逻辑主语是 trees，但树不能 walk，逻辑错误）
✅ 改为：Walking down the street, I saw the beautiful trees.
✅ 独立成分例外（不受主句主语限制）：generally speaking（一般来说）、judging from（根据……判断）、to tell the truth（说实话）。

🔗 固定搭配速查表

✅ 接 doing：enjoy / finish / mind / practice doing
✅ 接 to do：decide / hope / refuse / promise to do
✅ forget to do（忘记要做）vs forget doing（忘记做过）
✅ regret to do（遗憾要做）vs regret doing（后悔做过）
✅ need / want / require doing = need to be done（需要被做）
✅ be worth doing（值得被做）
✅ It is no use doing（做……没用）
✅ It takes sb... to do（花某人时间做）

⚠️ 易错警示

-ing 修饰物 / -ed 修饰人：a boring movie（令人无聊的电影，修饰物）／ a bored audience（感到无聊的观众，修饰人）。
be used to doing（习惯于）≠ used to do（过去常常）≠ be used to do（被用来做）。

① 作状语 本板块得分 0 / 5

非谓语作状语可表时间 / 原因 / 结果 / 条件 / 让步 / 伴随；主动进行用现在分词，被动完成用过去分词，表目的 / 结果用不定式。

核心讲解

不定式 to do → 目的 / 结果（He got up early to catch the bus.）；现在分词 doing → 主动 / 进行（Walking in the dark, she was afraid.）；过去分词 done → 被动 / 完成（Seen from the hill, the town is beautiful.）；完成式 having done → 主动且先于谓语（Having finished his homework, he went out.）。

② 作定语 本板块得分 0 / 5

单个分词作定语前置（a smiling girl），分词短语作定语后置（the girl standing by the window）；表将来 / 被动用不定式（the meeting to be held），序数词后用不定式（the first student to answer）。

核心讲解

现在分词 → 主动 / 进行（The girl standing by the window is my sister.）；过去分词 → 被动 / 完成（The bridge built last year is modern.）；不定式 → 将来（the meeting to be held next week，将来且被动用 to be done）；序数词 / 最高级 + 名词 + to do（the first student to answer）。

③ 作主语 / 宾语 / 表语 本板块得分 0 / 5

动名词表习惯 / 抽象（Seeing is believing.、It is no use crying.）；不定式表具体 / 目的 / 将来（To become a doctor is her dream.）；enjoy / mind / finish / practice 接 doing，decide / hope / refuse / promise 接 to do。

核心讲解

作主语：Seeing is believing.（动名词，抽象）；作宾语：enjoy listening to music、decide to accept the offer；作表语：Her dream is to become a doctor.（不定式表将来）；固定：It is no use crying over spilt milk.、be worth reading。

④ 作补语 本板块得分 0 / 5

make / let / have + sb + do（被动加 to：be made to do）；hear / see / watch + sb + do（全过程）/ doing（进行中）；get / have + sth + done。

核心讲解

make sb do（The boss made the workers clean the office.）→ 被动 be made to do；hear sb doing（I heard her singing. 正在唱）；get sth done（get my car repaired. 使车被修）；ask sb to do（ask him to answer）。
