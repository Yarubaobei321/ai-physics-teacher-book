# M05 · 导数与积分原理 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高一数学课堂的「导数与积分原理」交互学习页。学习目标：学生通过切线演示、积分面积演示、求导法则实例，理解导数的几何意义（切线斜率）与积分的几何意义（曲线下方面积），并掌握幂、积、商、链式求导法则。

二、数学模型规格：核心解析式 y=f(x)；导数 f′(x) 几何意义为曲线在 x 处的切线斜率；常见求导法则：幂 (xⁿ)′=n·xⁿ⁻¹、积 (u·v)′=u′v+uv′、商 (u/v)′=(u′v-uv′)/v²、链式 (f(g(x)))′=f′(g(x))·g′(x)；定积分 ∫ₐᵇ f(x) dx 的几何意义为曲线 y=f(x) 与 x 轴在 [a,b] 之间围成的面积（x 轴上方为正、下方为负）；对常见初等函数（多项式、sin、cos、eˣ）必须用**解析求导**，对用户自定义输入可降级为数值差分并**显式标注方法口径**（如「解析求导」或「数值差分近似」）；观测点 x₀、积分下限 a、上限 b 均为实数，输入须有范围限制（如 x₀∈[-10,10]）。

三、交互与教学功能：至少四个分区——①概念讲解（导数/积分定义 + 几何意义图示）、②求导法则实例（幂/积/商/链式各一例，配公式与解析结果）、③自由函数输入框（输入 f(x) 如 x^2、sin(x)、x^3，应用后绘制曲线 + x₀ 处切线 + 显示切线斜率读数）、④积分演示（滑块/输入框设 a 与 x₀，对 [a,x₀] 区间画阴影面积并显示积分值读数）；切线随 x₀ 滑块实时移动，阴影面积随 a、x₀ 实时更新；底部设「观察与结论」区，引导归纳切线斜率=导数、积分=面积。

四、工程与呈现约束：布局分「画布区／控制区／数据区」三栏；1440×900 分辨率下无遮挡、无溢出、阴影区域不溢出坐标轴；所有滑块、输入框、按钮均有可见中文标签；canvas 提供替代文本（aria-label 描述当前 f(x) 与读数）；切线斜率读数旁必须标注「解析」或「数值差分」方法口径；所有公式用 Unicode 或内联 KaTeX 渲染（如 f′(x)、∫ₐᵇ、xⁿ），不依赖外网 MathJax；输入框用安全 JS 表达式并捕获异常，非法输入给友好提示而非崩溃。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 输入 f(x)=x²、x₀=1：切线斜率读数必须显示为 2（f′(x)=2x，x₀=1→2），并标注方法为解析或数值；
2. 输入 f(x)=x²、x₀=3：切线斜率读数必须为 6；
3. 输入 f(x)=x²、积分区间 [0,1]：积分读数必须约为 1/3≈0.333（∫₀¹ x² dx = x³/3 |₀¹ = 1/3）；
4. 输入 f(x)=x³、积分区间 [0,2]：积分读数必须约为 4（∫₀² x³ dx = x⁴/4 |₀² = 16/4 = 4）；
5. 输入 f(x)=sin(x)、x₀=0：切线斜率读数必须为 1（f′(x)=cos(x)，f′(0)=cos0=1）；切线方程 y=x；
6. 切线斜率读数必须标注当前所用方法（解析/数值差分），不得误导用户为符号求导；
7. 四个分区、函数应用按钮、x₀/a 滑块各操作一次，无报错、无失效。
