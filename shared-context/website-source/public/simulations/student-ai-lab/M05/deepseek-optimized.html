一、导数的定义与几何意义

函数 y = f(x) 在 x₀ 处的导数 f′(x₀) 是曲线在该点处切线的斜率：

f′(x₀) = lim (Δx→0) [f(x₀+Δx) − f(x₀)] / Δx

几何上，切线就是割线在 Δx→0 时的极限位置；切线的倾斜程度由斜率（导数）刻画。

二、积分（定积分）的定义与几何意义

∫ₐᵇ f(x) dx = 曲线 y=f(x)、x 轴与直线 x=a、x=b 围成区域的有向面积
  • x 轴上方面积记为正，下方面积记为负；
  • 积分值 = 上方净面积 − 下方净面积。

三、求导法则

幂：(xⁿ)′ = n·xⁿ⁻¹　（如 (x²)′ = 2x）
积：(u·v)′ = u′v + uv′　（如 (x·sinx)′ = sinx + x·cosx）
商：(u/v)′ = (u′v − uv′)/v²
链式：(f(g(x)))′ = f′(g(x))·g′(x)　（如 ((2x+1)³)′ = 3(2x+1)²·2）

四、常见函数的导数

(xⁿ)′ = n·xⁿ⁻¹　(sinx)′ = cosx　(cosx)′ = −sinx　(eˣ)′ = eˣ

算例：f(x)=x²、x₀=1 时切线斜率 = f′(1) = 2x|x=1 = 2；x₀=3 时斜率 = 6；f(x)=sinx、x₀=0 时斜率 = cos0 = 1，切线方程 y=x。

积分算例：∫₀¹ x² dx = x³/3 |₀¹ = 1/3 ≈ 0.333；∫₀² x³ dx = x⁴/4 |₀² = 16/4 = 4。

五、方法口径说明

本页对多项式、sin、cos、eˣ使用解析求导/解析积分；对自定义的其它函数使用数值差分 / 梯形法近似，所有读数旁均标注当前方法，绝不冒充符号运算。

四种求导法则 · 解析实例

① 幂法则
f(x) = x³　⇒　f′(x) = 3x²
代入 x=2：f′(2) = 3·4 = 12；解析求导
② 积法则
f(x) = x·sinx　⇒　f′(x) = sinx + x·cosx
u=x、v=sinx，u′=1、v′=cosx；代入 x=0：f′(0) = 0 + 0·1 = 0；解析求导
③ 商法则
f(x) = x/(x²+1)　⇒　f′(x) = (1·(x²+1) − x·2x)/(x²+1)² = (1−x²)/(x²+1)²
代入 x=0：f′(0) = 1/1 = 1；解析求导
④ 链式法则
f(x) = (2x+1)³　⇒　f′(x) = 3(2x+1)²·2 = 6(2x+1)²
g(x)=2x+1、g′(x)=2；代入 x=0：f′(0) = 6·1 = 6；解析求导
以上实例均为解析求导（非数值差分），可对照第 ③ 分区在 x₀ 处用切线验证。
