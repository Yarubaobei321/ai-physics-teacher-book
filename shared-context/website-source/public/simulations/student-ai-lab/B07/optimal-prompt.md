# B07 · 细胞分裂与分化 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中必修一课堂的"细胞分裂与分化"学习页。学习目标：学生通过看流程图概览、交互演示有丝分裂各时期、读各时期染色体/DNA/染色单体数目表，能说出有丝分裂各时期特征与数目变化、细胞分化是基因选择性表达（遗传物质不变）。

二、生物模型规格：有丝分裂时期顺序为 间期→前期→中期→后期→末期，不得颠倒；各时期特征：间期（DNA 复制、中心体复制，染色体数目不变）、前期（染色质螺旋化为染色体、核膜核仁解体）、中期（染色体着丝粒排列在赤道板）、后期（着丝粒分裂、姐妹染色单体分离分别移向两极）、末期（核膜核仁重建、胞质分裂）；子细胞与母细胞遗传组成一致、染色体数目不变（2n→2n）。
**各时期染色体/DNA/染色单体数目表（设体细胞为 2n，必修一核心量化内容）**：间期 染色体=2n、DNA=2n→4n（复制后）、染色单体=0→4n；前期 染色体=2n、DNA=4n、染色单体=4n；中期 染色体=2n、DNA=4n、染色单体=4n；后期（着丝粒分裂后）染色体=4n、DNA=4n、染色单体=0；末期 染色体=2n、DNA=2n、染色单体=0。变化主线 2n→4n→2n、染色单体 0→4n→0。
**用词修正**：图中若画的是动物细胞中心体，则发出的是"星射线"形成纺锤体，不得与植物细胞两极发出的"纺锤丝"混用；请在图中统一并正确标注（动物细胞用"中心体/星射线"，植物细胞用"纺锤丝"）。
细胞分化：实质为基因的选择性表达，所有体细胞含相同遗传信息（遗传物质不变，不得说成遗传物质改变）；子细胞与母细胞遗传组成一致。

三、交互与教学功能：三页架构——（1）流程图页：有丝分裂 间期→前期→中期→后期→末期 各时期卡片＋关键点条；（2）思维导图页：讲细胞分化=基因选择性表达（遗传物质不变），配红细胞（双凹圆盘状、无核、运输氧气）、神经细胞（轴突树突、传递电信号）、肌肉细胞（肌原纤维、收缩）、淋巴细胞（免疫防御）四种分化产物的简图与特点；（3）交互演示：canvas 动画可播放/暂停/上一步/下一步/点击时期圆点跳转/调速，图中标出染色体、姐妹染色单体、着丝粒、赤道板、纺锤丝（或星射线）、核膜核仁等结构名称；每个时期同步显示该时期染色体/DNA/染色单体数目表与文字描述；分化图例悬停显示对应细胞特点。

四、工程与呈现约束：紫色主题统一、卡片层次清晰、tab 为真实 <button>；1440×900 分辨率下无遮挡、无溢出；canvas 加 aria-label 描述各时期分裂场景；阶段圆点与图例若可交互则用 <button> 保证键盘可达；文字与背景对比度清晰（不得用白字配浅背景）、文字不小于 0.8rem。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 逐步点完五个时期，顺序必须为 间期→前期→中期→后期→末期，不得颠倒或跳期；
2. **数目表核对（核心）**：各时期染色体/DNA/染色单体数目必须与教材一致——间期 2n/(2n→4n)/(0→4n)、前期 2n/4n/4n、中期 2n/4n/4n、后期 4n/4n/0、末期 2n/2n/0，主线 2n→4n→2n、染色单体 0→4n→0；
3. 后期描述：着丝粒分裂、姐妹染色单体分离分别移向两极（不得说成同源染色体分离——那是减数分裂）；
4. **用词修正**：图中结构命名统一——动物细胞用"中心体/星射线"，植物细胞用"纺锤丝"，不得同一图混用；
5. 细胞分化实质表述为"基因选择性表达、遗传物质不变"，明确排除"分化改变遗传物质"；思维导图四种细胞特点与教材一致（红细胞双凹圆盘状无核运输氧气等）；
6. 三个顶层 tab、播放/上一步/下一步/时期圆点跳转/调速/分化图例悬停各操作一次，无报错、无失效；画面文字对比度清晰（无白字配浅背景）。
