# B12 · 有丝分裂原理 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中生物初学者的"减数分裂"交互讲学（注意：全程统一为减数分裂，标题、过程描述、对比表、习题术语都不得出现"有丝分裂"作为本页主题，仅在与减Ⅱ对比时作为对照概念出现）。学习目标：通过逐期推进的减Ⅰ/减Ⅱ动画或图示、染色体/DNA/染色单体数目变化与即时反馈题，理解减数分裂如何将 2n 体细胞产生 n 单倍体配子。

二、生物模型规格：减数分裂含两次连续分裂；以 2n=4（2 对同源染色体）为例：
- 减数第一次分裂（减Ⅰ）：前期I 同源染色体联会形成四分体、可发生交叉互换；中期I 同源染色体成对排列于赤道板；后期I **同源染色体分离、着丝粒不分裂**，非同源染色体自由组合；末期I 形成两个子细胞，每个染色体数 n=2、每条仍含两条姐妹染色单体；这一步实现 2n→n 的染色体数减半。
- 减数第二次分裂（减Ⅱ）：前期II/中期II 染色体仍为 n、每条含两条姐妹染色单体；后期II **着丝粒分裂、姐妹染色单体分离**；末期II 形成 4 个单倍体子细胞（n），每个核 DNA=n。
关键事件区分：减Ⅰ后期是同源分离（着丝粒不分裂）；减Ⅱ后期是姐妹染色单体分离（着丝粒分裂，过程类似有丝分裂但起始细胞已是 n）。配子种类数：不考虑交叉互换时 1 对同源 → 2 种配子，2 对 → 2²=4 种；考虑交叉互换则种类更多。

三、交互与教学功能：①逐步推进的减Ⅰ/减Ⅱ动画或图示（前期/中期/后期/末期），每步显示当前时期、染色体排列与同源/姐妹染色单体的状态变化（不只是一段文字）；②每一步同步显示该时期的染色体数、DNA 分子数、染色单体数；③"有丝分裂 vs 减Ⅱ"对比表，列出二者起始倍性、是否同源、着丝粒分裂时机、子细胞数与倍性差异；④5 道即时反馈情境题（含交叉互换辨析、减Ⅱ vs 有丝分裂、染色体不分离后果等），点击"查看答案"显示正误与解析；⑤幽默语气可保留但要服务于入门阅读，emoji 不密集。

四、工程与呈现约束：布局分"阶段动画/图示区／数目读数区／对比表与习题区"多层卡片；1440×900 分辨率下无遮挡、无溢出；所有控件为真实 button（含查看答案按钮）、有可见文字标签；图像/canvas 加 aria-label 描述时期与染色体状态；页面有 lang="zh-CN" 与 viewport meta；正文字号≥0.9rem。
