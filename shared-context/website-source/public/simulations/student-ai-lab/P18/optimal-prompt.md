# P18 · 天体运动学习网页 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"天体运动"学习网页：知识讲解＋交互自测。学习目标：学生通过阅读分节内容并完成自测题，掌握万有引力提供向心力的分析方法与三个宇宙速度。

二、物理模型规格：知识内容必须物理正确——万有引力提供向心力 GMm/r²=mv²/r；近地卫星 v=√(gR)；第一宇宙速度 7.9 km/s（最大环绕速度、最小发射速度）；同步卫星周期 24 h、轨道在赤道平面上方约 3.6×10⁴ km 处；卫星越高线速度越小、周期越大；SI 单位。

三、交互与教学功能：知识区按"引力与向心力—卫星运动规律—宇宙速度—同步卫星"分节，可折叠展开；自测区至少 5 题（含概念判断与计算题），其中必须有一道计算题：已知 g=9.8 m/s²、地球半径 R=6.4×10⁶ m，求近地卫星环绕速度；每题提交后立即显示对错与完整解析（解析给出代入步骤与数值）；答完显示得分汇总；页面设"易错点提醒"区。

四、工程与呈现约束：单文件；1440×900 下无遮挡、无溢出；控件有可见标签；文字对比度充足。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 计算题手算 v=√(9.8×6.4×10⁶)≈7.9×10³ m/s：正确答案必须出现在选项中，选择后判定为正确，解析代入数值与手算一致；
2. 每道题提交后均出现对错标记与解析，无一题缺失；
3. 知识区逐条核对：第一宇宙速度、同步卫星周期与轨道位置、"越高越慢"规律，均无知识性错误；
4. 故意答错一题：判定为错误且解析仍正确显示；
5. 全部交互遍历一次，无报错、无失效。
