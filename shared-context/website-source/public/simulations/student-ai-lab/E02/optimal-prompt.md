一、主题与受众：面向高中英语课堂的"定语从句概念及用法"互动教学网页。学习目标：学生通过判断互动引入、概念先行、限定/非限定两大分类讲解、关系代词vs关系副词对比+口诀、总结表格、5 道高考真题带详细解析，掌握定语从句关系词选择规则。

二、语法规则与例句规格（例句本身语法错=fail；讲法取舍属"不判错区"不判错）：
- 定语从句结构：先行词＋关系词＋从句；关系词选择须给条件：先行词指人/指物、从句缺主语/宾语/定语→用关系代词（who/whom/whose 指人，which 指物，that 兼指）；从句结构完整缺状语（时间/地点/原因）→用关系副词（when/where/why）。口诀："缺主宾用代，完整缺状用副"。
- 限定 vs 非限定区别（核心 A3 补全）：限定性从句无逗号、可用 that、关系词作宾语可省；非限定性从句有逗号、**绝不能用 that**、关系词不可省。
- that/which 使用限制（核心 A3 补全）：先行词为物时 that/which 通常可互换；**但非限定从句只能用 which 不能用 that**；先行词被序数词/最高级/the only/the very/不定代词修饰时倾向用 that。
- 例句本身须语法正确、拼写无误，且能说明对应规则；高考真题题干须规范。
- 术语规范：先行词、关系代词（who/whom/which/that/whose）、关系副词（when/where/why）、限定性/非限定性定语从句、Attributive Clause；从句成分（主/宾/表/定/状）描述准确，不与名词性从句、状语从句混淆。
