# C07 · 无机物性质与转化 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖（**严禁外链 Google Fonts、Font Awesome 等任何 CDN**，字体用系统默认、图标用 emoji 或内联 SVG），双击即可在浏览器打开。

一、主题与受众：面向高一化学课堂的"无机物性质与转化"互动教学。学习目标：学生通过 7 大元素家族转化链对比、读典型反应方程式、看实验模型，归纳"单质 → 氧化物 → 酸/碱/盐"的转化关系并理解变价、两性、歧化等特性。

二、化学模型规格：覆盖 7 大元素家族（Na / Mg / Cl₂ / S / N / Al / Fe），每家族按"单质 → 氧化物 → 酸/碱/盐"转化链组织。所有方程式必须配平、**用等号连接、标注反应条件、用 ↑/↓ 标注气体与沉淀**；转化链方向必须是"单质 → 氧化物 → 酸碱盐"，不得反向。核心方程式（守恒口径）：
- 钠：4Na+O₂=2Na₂O；2Na+2H₂O=2NaOH+H₂↑；2Na₂O₂+2H₂O=4NaOH+O₂↑；2Na₂O₂+2CO₂=2Na₂CO₃+O₂；
- 氯：Cl₂+H₂O⇌HCl+HClO（歧化）；2Fe+3Cl₂=2FeCl₃；氯碱工业 2NaCl+2H₂O=2NaOH+H₂↑+Cl₂↑；
- 铁：3Fe+2O₂=Fe₃O₄；2FeCl₂+Cl₂=2FeCl₃；4Fe(OH)₂+O₂+2H₂O=4Fe(OH)₃（Fe²⁺→Fe³⁺ 变价）；
- 铝：2Al+6HCl=2AlCl₃+3H₂↑；2Al+2NaOH+6H₂O=2Na[Al(OH)₄]+3H₂↑（两性，与酸/碱均产生 H₂）；2Al+Fe₂O₃=Al₂O₃+2Fe（铝热）；
- 硫/氮：S+O₂=SO₂；2SO₂+O₂⇌(催化剂,△)2SO₃；N₂+3H₂⇌(催化剂,△)2NH₃；4NH₃+5O₂=4NO+6H₂O（接触法制硫酸、氨催化氧化制硝酸）；
- 离子检验：Cl⁻+Ag⁺→AgCl↓、SO₄²⁻+Ba²⁺→BaSO₄↓、Fe³⁺+SCN⁻→血红色、Fe²⁺ 先加 SCN 无明显现象再加氯水变血红色、NH₄⁺+OH⁻ →(△) NH₃↑。
反应类型标签准确（强还原性/强氧化性/歧化/两性/催化氧化）；金属与酸产物为盐 + H₂↑（不得误写）；电子转移方向（如 Zn+Cu²⁺：Zn 失 2e⁻、Cu²⁺ 得 2e⁻）正确。

三、交互与教学功能：(1) 首部"7 大元素家族转化链对比表"——单质→氧化物→酸/碱/盐链对照；(2) 每家族一张卡片，先写性质标签（还原性/氧化性/两性/歧化）再写已配平、标注条件、用等号连接的方程式；(3) 除杂/离子检验/工业流程（氯碱/接触法制硫酸/侯氏制碱/制硝酸）专项；(4) 每个方程式旁加"观看实验模型"按钮，模态框 canvas **按方程式系数比例绘制粒子**（如 2Na+2H₂O 至少画 2 个 Na、2 个 H₂O → 2NaOH + H₂↑）；(5) 物质图像按钮 7 个（Na/Mg/Cl₂/S/NH₃/Al/Fe）弹出对应物质图片/示意。

四、工程与呈现约束：卡片式分区 + 统一蓝绿渐变主题；1440×900 分辨率下无遮挡、无溢出；**单文件零外链**：字体系统默认、图标用 emoji 或内联 SVG，不得有 Google Fonts/Font Awesome 的 <link> 或 ./css2、./all.min.css 等外链请求；模态框关闭按钮用真实 <button>（不得用 × span）；canvas 实验示意加 aria-label/role；方程式等宽字体、反应类型/条件用彩色小标签区分；含 @media 720px 响应式断点。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. **零外链核对（B4 工程约束规避，核心）**：打开开发者工具 Network 面板，刷新页面不得有任何对 Google Fonts（fonts.googleapis.com/css2）、Font Awesome（./all.min.css）等外部 CDN 的请求；所有字体/图标均内联或系统默认；
2. **方程式守恒核对（核心验收）**：逐条核对核心方程式两边原子守恒——2Na₂O₂+2CO₂=2Na₂CO₃+O₂ 两边 Na=4、O=6、C=2；2Na+2H₂O=2NaOH+H₂↑ 两边 Na=2、O=2、H=4；4NH₃+5O₂=4NO+6H₂O 两边 N=4、H=12、O=10；
3. **转化链方向（B1 规避）**：每个家族的转化链必须是"单质 → 氧化物 → 酸/碱/盐"方向，不得反向；Na→Na₂O/Na₂O₂→NaOH→Na₂CO₃/NaCl，Fe→Fe₃O₄/Fe₂O₃→FeCl₂/FeCl₃→Fe(OH)₂/Fe(OH)₃ 价态递进；
4. **产物方向核对**：Na 与水产物 NaOH+H₂↑；Al 与酸产物 AlCl₃+H₂↑、Al 与碱产物 Na[Al(OH)₄]+H₂↑；金属与酸产物为盐 + H₂↑（不得误写）；
5. **canvas 粒子比例（B1 warning 规避）**：实验模型 canvas 必须按方程式系数比例绘制粒子（如钠水反应至少 2 Na + 2 H₂O → 2 NaOH + 1 H₂），不得只画 1 个气泡或忽略系数比例；SO₂ 漂白性可保留文字方程（品红为有机物）但应注明"有机品红被还原为无色物质"；
6. **Fe²⁺/Fe³⁺ 变价 + Al 两性 + Cl₂ 歧化**：价态标注正确（2FeCl₂+Cl₂=2FeCl₃ 中 Fe +2→+3；Cl₂+H₂O⇌HCl+HClO 中 Cl 一部分 −1、一部分 +1 歧化）；
7. 离子检验试剂与现象：Cl⁻+Ag⁺→白色 AgCl↓；SO₄²⁻+Ba²⁺→白色 BaSO₄↓；Fe³⁺+SCN⁻→血红色；NH₄⁺+OH⁻ 加热产生使湿润红色石蕊试纸变蓝的 NH₃；
8. 交互完整性：12 个实验模型按钮 + 7 个物质图像按钮 + 关闭按钮 + 点遮罩关闭各操作一次，弹出对应标题与 canvas，无 console 报错（不得有 ERR_FILE_NOT_FOUND）；模态框关闭按钮为真实 <button>。
