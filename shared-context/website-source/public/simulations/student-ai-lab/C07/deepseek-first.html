碱土金属镁(Mg)银白金属，较活泼与CO₂反应，与酸快速反应燃烧耀眼白光，与酸冒气泡

典型物质深度解析

钠 (Na) · 活泼金属

密度0.97 g/cm³熔点97.8℃强还原性
银白色金属光泽
🔬 钠的切割面 (示意: 银白质软)
2Na + 2H₂O → 2NaOH + H₂↑
实验现象 → 浮、熔、游、响、红 (生成H₂，酚酞变红)
模型: 金属晶体自由电子模型

氯气 (Cl₂) · 强氧化剂

黄绿色气体密度＞空气有毒
⚗️ 氯气黄绿色 & 与铁反应实验示意
H₂ + Cl₂ → 2HCl (苍白色火焰)
2Fe + 3Cl₂ → 2FeCl₃ (棕褐色烟)
现象: 湿润红纸褪色(漂白性来自HClO)，钠在氯气中燃烧白烟

铁 (Fe) · 变价金属

银白磁性熔点1538℃钝化
🧲 铁粉呈黑色，与氯气反应产棕烟
Fe + S → FeS (黑色固体)
2Fe + 3Cl₂ → 2FeCl₃
铁在纯氧中剧烈燃烧火星四射，生成Fe₃O₄

铝 (Al) · 两性典范

银白轻金属致密氧化膜两性
🧪 铝与NaOH溶液反应生成氢气
2Al + 6HCl → 2AlCl₃ + 3H₂↑
2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
与碱反应剧烈冒泡，体现两性特征

过氧化钠 Na₂O₂

淡黄色固体强氧化剂
✨ 与水、CO₂反应产生O₂
2Na₂O₂ + 2H₂O → 4NaOH + O₂↑
2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂
现象: 气泡产生，带火星木条复燃，供氧剂原理

钠盐 · 碳酸钠 vs 碳酸氢钠

Na₂CO₃ 苏打NaHCO₃ 小苏打
🧂 溶解度与热稳定性差异
2NaHCO₃ → Na₂CO₃ + H₂O + CO₂↑
加热稳定性: Na₂CO₃不分解, NaHCO₃易分解产生气体使石灰水变浑
与酸反应: NaHCO₃更剧烈

二氧化硫 SO₂

无色刺激性气体易溶于水
🌫️ 品红溶液褪色 (可逆性漂白)
SO₂ + H₂O ⇌ H₂SO₃
使品红溶液褪色 (加热恢复红色) 体现漂白性，是酸性氧化物

氨气 NH₃ · 碱性气体

无色刺激性气味极易溶于水
💧 喷泉实验: 形成红色喷泉 (酚酞)
NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻
遇到湿润红色石蕊试纸变蓝，与HCl产生白烟(NH₄Cl)
微观模型与实验现象集锦
NaCl 离子晶体模型
Cl⁻ (大球) 与 Na⁺ (小球) 交替排布，离子键模型
氧化还原电子转移模型
电子从还原剂(Zn)转移至氧化剂(Cu²⁺)
金属晶体“电子气”模型
金属离子 + 自由电子 → 导电导热延展性
