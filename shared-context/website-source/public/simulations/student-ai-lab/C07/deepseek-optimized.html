元素单质氧化物酸 / 碱 / 盐特性

Mg Mg（银白）MgOMg(OH)₂ / MgCl₂还原性 · 燃烧耀眼白光

🧫 离子检验（试剂与现象）

离子试剂现象
Cl⁻AgNO₃ + 稀硝酸白色沉淀 AgCl↓
SO₄²⁻BaCl₂ + 稀盐酸白色沉淀 BaSO₄↓
Fe³⁺KSCN 溶液血红色
Fe²⁺先加 KSCN 无明显现象，再加氯水变血红色（Fe²⁺被氧化为 Fe³⁺）

🧹 常见除杂

体系方法 / 试剂
CO₂ 中混有 HCl通过饱和 NaHCO₃ 溶液洗气
CO₂ 中混有 SO₂通过饱和 NaHCO₃ 溶液（SO₂ 反应，CO₂ 不反应）
NaCl 中混有 Na₂CO₃加适量稀盐酸，蒸发结晶
FeCl₂ 中混有 FeCl₃加足量铁粉过滤（2FeCl₃+Fe=3FeCl₂）
FeCl₃ 中混有 FeCl₂通入足量 Cl₂（2FeCl₂+Cl₂=2FeCl₃）

🏭 工业流程（四线）

氯碱工业：饱和食盐水 → 电解 → 2NaCl+2H₂O = 2NaOH+H₂↑+Cl₂↑（阳极 Cl₂、阴极 H₂，阴极区得 NaOH）
接触法制硫酸：硫黄/黄铁矿 → 焙烧 → S+O₂ = SO₂ → 催化氧化（V₂O₅，450℃）2SO₂+O₂ ⇌ 2SO₃ → SO₃+H₂O = H₂SO₄
侯氏制碱（联合制碱法）：饱和食盐水 + NH₃ + CO₂ → NaHCO₃↓ 析出（NaCl+NH₃+CO₂+H₂O = NaHCO₃↓+NH₄Cl）→ 2NaHCO₃ =△= Na₂CO₃+H₂O+CO₂↑
工业制硝酸：N₂+3H₂ ⇌ 2NH₃（合成氨）→ 氨催化氧化 4NH₃+5O₂ = 4NO+6H₂O → 2NO+O₂ = 2NO₂ → 3NO₂+H₂O = 2HNO₃+NO

⚡ 电子转移方向示例

Zn + Cu²⁺ = Zn²⁺ + Cu
失电子（氧化）：Zn 0 → +2，失 2e⁻；
得电子（还原）：Cu²⁺ +2 → 0，得 2e⁻；电子由 Zn 经导线流向 Cu。
2FeCl₂ + Cl₂ = 2FeCl₃
Fe +2 → +3 失电子（被氧化）；Cl₂ 得电子（被还原）。
Cl₂ + H₂O ⇌ HCl + HClO
歧化：Cl 0 → −1（HCl）与 0 → +1（HClO），同一元素既失电子又得电子。
