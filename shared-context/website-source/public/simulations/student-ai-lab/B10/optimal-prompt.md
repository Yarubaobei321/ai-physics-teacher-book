# B10 · 动画演示mRNA的合成 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中生物必修二的"DNA 转录为 mRNA"动画演示。学习目标：通过分阶段动画与翻页知识卡，理解转录的模板链/编码链方向、碱基配对规则（RNA 层 A-U）、氢键数与磷酸二酯键。

二、生物模型规格：DNA 双链分编码链（5'→3'）与模板链（3'→5'），RNA 聚合酶沿模板链 3'→5' 移动；转录碱基配对严格为 A-U、T-A、C-G、G-C（RNA 层 U 替代 T，不得写成 A-T）；新生 mRNA 沿 5'→3' 方向延伸；氢键数必须为 A-T=2 个、G-C=3 个（DNA 层）、A-U=2 个（RNA-DNA 杂交层），二者均不得颠倒；过程分起始—延伸—终止三步；模板链与新 mRNA 之间为磷酸二酯键（核糖核苷酸间 3'-5' 磷酸二酯键）；密码子读在 mRNA 上（非模板链读法，但页面以模板链转录为准）。

三、交互与教学功能：①动画分起始/延伸/终止，可播放、暂停、单步、重置、调速；②显著区分编码链、模板链、RNA 聚合酶、新 mRNA（颜色+图例），图例始终保留不丢失；③模板链标签固定在 DNA 左侧不随动画越界移出；mRNA 的 5' 标签独立固定，不随"mRNA"字样复制下移；④hover 任一碱基对显示其配对碱基与氢键数（A-T/A-U=2、G-C=3）；⑤下方设翻页知识卡（≥4 张），分别讲解模板链与编码链、合成方向、氢键、磷酸二酯键；⑥设一道观察题让学生根据动画归纳"模板链方向与 mRNA 方向的关系"。

四、工程与呈现约束：布局分"动画画布区／控制区／知识卡区"三栏；1440×900 分辨率下无遮挡、无溢出、标签不越界；所有控件为真实 button、有可见文字标签；canvas 加 aria-label 描述当前阶段；正文字号≥0.9rem，密集处适当留白。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 氢键数核对：hover A-T 碱基对显示"2 个氢键"，hover G-C 碱基对显示"3 个氢键"——必须正确，不得颠倒（A-T 三根/G-C 两根为错误）；
2. 配对规则核对：转录时模板链 A 配 mRNA 的 U（不是 T）；模板链 T 配 mRNA 的 A；C 配 G、G 配 C——页面不得在 RNA 层出现 A-T 配对；
3. 方向核对：编码链标注 5'→3'，模板链标注 3'→5'，RNA 聚合酶沿模板链 3'→5' 移动，新生 mRNA 5'→3' 延伸；
4. 标签稳定性：播放完整动画后，模板链标签仍在原位不越出左侧、mRNA 的 5' 标签不随"mRNA"字样下移、图例全程可见；
5. 给定模板链 3'-ATGC-5'，手算 mRNA 应为 5'-UACG-3'（A→U、T→A、G→C、C→G），与动画合成结果逐位对比；
6. 逐个操作播放/暂停/单步/重置/调速与知识卡上一页/下一页，无报错、无失效、无 console 错误。
