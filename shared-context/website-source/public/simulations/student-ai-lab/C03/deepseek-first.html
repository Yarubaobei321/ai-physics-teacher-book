⚡ 氧化还原反应 · Redox

电子转移 · 化合价升降 · 生活与工业核心
📖 核心概念

✨ 氧化还原反应 是化学反应中 电子发生转移 的反应，表现为元素化合价的改变。

  • 氧化：失去电子 → 化合价升高 → 被氧化（还原剂）
  • 还原：得到电子 → 化合价降低 → 被还原（氧化剂）
  • 💡 口诀：“升失氧，降得还；剂性相反”。
  • 🧪 氧化剂本身被还原，还原剂本身被氧化。
🌰 经典例子：铜与硝酸银
Cu + 2Ag⁺ → Cu²⁺ + 2Ag
Cu 失电子 (氧化)，Ag⁺ 得电子 (还原)
⚙️ 基本原理

电子守恒 & 化合价升降守恒 —— 反应中得失电子总数相等，化合价升降总数相等。

🔁 半反应法 (离子-电子法):
氧化半反应: Red → Ox + n e⁻
还原半反应: Ox' + n e⁻ → Red'
合并时电子数相等，体现 电子转移的微观本质。
原电池 电解池 氧化剂/还原剂

✅ 氧化还原反应是 能量转化 的基础（电池、金属冶炼、光合作用呼吸等）。

🧪 反应初始

⚡ Zn 尚未失去电子，Cu²⁺ 未得电子

🟢 还原半反应 (Cu²⁺ → Cu)
Cu²⁺ + 2e⁻ → Cu

🔋 拓展：原电池原理与氧化还原

原电池中，负极发生氧化反应（失去电子），正极发生还原反应（得到电子），电子通过外电路定向流动产生电流。

✅ 锌铜原电池：Zn极溶解，Cu极析出铜，盐桥维持电荷平衡。

🌊 电子流向
负极(Zn) → 导线 → 正极(Cu)
→ 电流方向相反
