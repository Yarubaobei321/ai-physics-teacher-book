升失氧 · 降得还 · 剂相反

模块一 · 概念与口诀

氧化反应
失电子，化合价升高，该物质为还原剂
还原反应
得电子，化合价降低，该物质为氧化剂
电子转移方向
失电子者 → 得电子者
物质化合价变化电子得失角色
Zn → Zn²⁺0 → +2失 2e⁻还原剂（被氧化）
Cu²⁺ → Cu+2 → 0得 2e⁻氧化剂（被还原）
MnO₄⁻(Mn)+7 → +2得 5e⁻氧化剂（被还原）
Fe²⁺ → Fe³⁺+2 → +3失 1e⁻还原剂（被氧化）
HNO₃(浓) 中 N+5 → +4得 1e⁻氧化剂（被还原）
半反应：Zn → Zn²⁺ + 2e⁻（氧化半反应）；Cu²⁺ + 2e⁻ → Cu（还原半反应）。口诀含义：升价失电子被氧化（作还原剂），降价得电子被还原（作氧化剂），氧化剂与还原剂相反对应。

模块二 · 氧化性 / 还原性强弱比较

氧化性：氧化剂 > 氧化产物
还原性：还原剂 > 还原产物
示例：Zn + CuSO₄ → ZnSO₄ + Cu 中，氧化性 Cu²⁺ > Zn²⁺；还原性 Zn > Cu。

模块三 · 四大反应类型关系

反应类型是否氧化还原判据
置换反应必为氧化还原一定有单质 → 一定有电子转移
复分解反应必非氧化还原复分解为离子交换，无化合价变化
化合反应看是否有单质参与单质+单质→化合物：是；氧化物+水→碱：否
分解反应看是否有单质生成如 2KClO₃→2KCl+3O₂↑ 是；CaCO₃→CaO+CO₂↑ 否

模块四 · 电子转移可视化（Zn + Cu²⁺ → Zn²⁺ + Cu）

未反应进行中完全反应
Zn → Zn²⁺ + 2e⁻　|　Cu²⁺ + 2e⁻ → Cu
Zn 化合价0
Cu²⁺ 化合价+2
已转移电子数（e⁻）0

模块五 · 配平核心步骤 + 2 组互动练习（提交后打印两边原子数 / 电荷数对照表）

配平四步：① 标化合价 → ② 求化合价升降（电子得失）并取最小公倍数 → ③ 先配电子（得电子总数 = 失电子总数）→ ④ 用观察法配平其他原子，最后核对原子守恒与电荷守恒。
