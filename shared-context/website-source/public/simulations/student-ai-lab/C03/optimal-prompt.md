# C03 · 氧化还原反应 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖（不得外链 Google Fonts 等任何 CDN，字体用系统默认），双击即可在浏览器打开。

一、主题与受众：面向高中化学的"氧化还原反应"互动教学。学习目标：学生通过概念讲解、电子转移可视化、强弱比较规律、四大反应关系分类、配平核心步骤与互动配平练习，掌握"升失氧、降得还、剂相反"的判别规则并能在离子型方程式上手算原子守恒 + 电荷守恒。

二、化学模型规格：
- 核心概念口诀：氧化 = 失电子（化合价↑，该物质为还原剂）；还原 = 得电子（化合价↓，该物质为氧化剂）；电子转移方向为"失电子者 → 得电子者"。
- 化合价标注口径严格如下（不得标反）：Zn 0→+2、Cu²⁺ +2→0、Mn（KMnO₄ 中）+7→+2、Fe²⁺ +2→+3、Cu 0→+2、N（HNO₃ 浓）+5→（NO₂ 中）+4。
- 半反应书写：氧化半反应 Zn → Zn²⁺ + 2e⁻；还原半反应 Cu²⁺ + 2e⁻ → Cu。
- 强弱比较规律：氧化剂 > 氧化产物、还原剂 > 还原产物。
- 与四大反应类型关系：置换反应必为氧化还原；复分解反应必非氧化还原；化合/分解看是否有单质参与。
- 示例方程式（必须配平、用等号连接、必要时标↑/↓）：
  · 离子型（酸性高锰酸钾氧化亚铁）：MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O；
  · 浓硝酸与铜：Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O；
  · 置换示例：Zn + CuSO₄ → ZnSO₄ + Cu。

三、交互与教学功能：模块一"概念与口诀"——化合价变化、电子转移、口诀"升失氧、降得还、剂相反"卡片化呈现；模块二"强弱比较"——氧化性/还原性强弱比较规律 + 示例；模块三"四大反应关系"——置换/复分解/化合/分解与氧化还原关系表；模块四"电子转移可视化"——以 Zn+Cu²⁺→Zn²⁺+Cu 为例，电子滑块（未反应 / 进行中 / 完全反应三态）拖动显示化合价与电子转移读数，复位按钮可重置；模块五"配平核心步骤 + 2 组互动练习"——输入系数即时校验：练习一 MnO₄⁻+?Fe²⁺+?H⁺→Mn²⁺+?Fe³⁺+?H₂O（正确键 1,5,8,1,5,4）；练习二 Cu+?HNO₃(浓)→Cu(NO₃)₂+?NO₂↑+?H₂O（正确键 1,4,1,2,2）。**每次提交配平答案后，页面必须显式打印两边原子数与电荷数对照表**（练习一两边电荷均应为 +17、两边 O 均为 4），让学生看到守恒证明。

四、工程与呈现约束：卡片式分区 + 统一绿色主题；1440×900 分辨率下无遮挡、无溢出；使用真实 <button>/<input>，回车键可触发验证；字体 ≥0.85rem（韦恩图若使用其放大后文字仍需清晰可读）；canvas/示意图加 aria-label。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. **离子方程式守恒手算（核心验收）**：练习一 MnO₄⁻+5Fe²⁺+8H⁺→Mn²⁺+5Fe³⁺+4H₂O 必须同时满足：① 电荷守恒——左边 −1+5×(+2)+8×(+1)=+17，右边 +2+5×(+3)=+17，两边均为 +17；② 原子守恒——两边 O 均为 4、H 均为 8、Mn 均为 1、Fe 均为 5；页面提交正确答案后应打印这两条守恒证明；
2. 浓硝酸练习守恒：Cu+4HNO₃(浓)→Cu(NO₃)₂+2NO₂↑+2H₂O 两边 Cu=1、N=4（注意 2 个进 Cu(NO₃)₂、2 个进 NO₂）、H=8、O=12，原子守恒；
3. 化合价与方向：Zn 0→+2（还原剂、被氧化）、Cu²⁺ +2→0（氧化剂、被还原）、Mn +7→+2（氧化剂）、Fe +2→+3（还原剂）、N +5→+4（氧化剂），均不得标反；电子转移方向必须是"失电子者→得电子者"；
4. 电子守恒自洽：Mn 得 5e⁻×1 = 5e⁻ = Fe 失 1e⁻×5 = 5e⁻；Cu 失 2e⁻ = N 得 1e⁻×2 = 2e⁻；滑块拖到完全反应态时显示的转移电子数与配比一致；
5. 练习正误反馈：练习一输入 1,5,8,1,5,4 应判定正确并打印守恒证明；任意一项错误应给出错误提示（如"两边电荷不等"），不得静默通过；
6. 四大反应分类：置换必氧化、复分解必不氧化、化合分解看单质，分类正确；
7. 交互完整性：电子滑块（未反应/进行中/完全反应三态）、复位按钮、两组练习提交 + 输入框回车各操作一次，无 console 报错、无失效。
