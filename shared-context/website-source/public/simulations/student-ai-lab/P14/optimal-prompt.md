# P14 · 机械能守恒的验证 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"机械能守恒的验证"三实验合集页：自由落体、光滑斜面下滑、单摆。学习目标：学生在三种情境中分别验证"只有重力做功时机械能守恒"，体会守恒规律与情境无关。

二、物理模型规格：统一以最低点/地面为零势能参考平面（页面声明）；自由落体 v=√(2gh)；光滑斜面 v=√(2gh)（h 为竖直下降高度，与倾角无关）；单摆 h=L(1−cosθ)；Ep=mgh、Ek=½mv²、E=Ep+Ek；g=9.8 m/s²；均忽略阻力（页面声明）；SI 单位。

三、交互与教学功能：三个实验分入口（同一文件内切换）；每个实验：参数滑块（高度/倾角/摆长摆角）、播放/暂停/重置、动画与实时读数；数据表按采样自动计算 Ep、Ek、E；"手算核对"功能：任选一行，用户先在输入框填入自己手算的 E 值，点"核对"后并排显示手算值、自动值与差值；页面设"观察与结论"区。

四、工程与呈现约束：单文件内三视图切换；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 自由落体 h=0.8 m：手算落地 v=√(2×9.8×0.8)≈3.96 m/s，与读数对比；
2. 斜面实验取 30° 与 45° 两个倾角、相同竖直高度 h=0.8 m：底端速度应相同（均 ≈3.96 m/s）；
3. 单摆 L=1 m、θ₀=30°：最低点 v≈1.62 m/s；
4. 三个实验的数据表 E 列全程偏差 <1%；"手算核对"功能可用且差值计算正确；
5. 三入口切换无串扰，所有控件各操作一次无报错。
