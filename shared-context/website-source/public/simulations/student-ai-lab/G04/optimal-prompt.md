# G04 · 产业区位因素 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中地理课堂的"产业区位因素"交互网页。学习目标：学生通过看区位因素速览框架、读真实案例、做选择题与综合题，掌握农业/工业/服务业三大产业的区位主导因素与典型指向类型。

二、地理模型规格：
- 三大产业分区：农业区位、工业区位、服务业区位，各自独立成区。
- 典型指向类型（核心判据，不得错配）：制糖厂=原料指向型（原料易腐/运输损耗大）；啤酒厂=市场指向型（保质期短、运输成本高）；炼铝厂=动力指向型（高耗能）；服装厂=劳动力指向型；集成电路=技术指向型。原料指数>1→原料导向（韦伯理论）。
- 典型地区案例（空间定位）：地中海沿岸（农业·地中海农业）、墨累-达令盆地（农业·混合农业）、潘帕斯（农业·大牧场放牧业）、鲁尔区（工业·传统煤铁复合体）、沪宁杭/京津唐/辽中南/珠三角（四大工业基地）、上海陆家嘴/深圳前海/北京中关村（服务业·金融/物流/科技）。
- 案例与指向类型、主导因素须自洽：不得出现"文字说劳动力指向，案例却是集成电路"或"指向类型与综合题答案关键词矛盾"。

三、交互与教学功能：①每产业先表格速览区位因素（含主导导向类型与典型案例），再分步详解"某因素如何影响布局"；②配真实地区案例（SVG 示意图+文字）；③每产业含 3 道选择题 + 1 道综合题，综合题用采分关键词批改并给鼓励/改进建议+答题模板；④地区检索窗口，输入"地中海沿岸""鲁尔区"等返回正确区位文本；⑤折叠案例探究。

四、工程与呈现约束：布局分"三产业标签区／速览与详解区／案例与检索区／练习与批改区"多层；1440×900 分辨率下无遮挡、无溢出；三产业配色区分；所有控件为真实 button、textarea，Enter 键可达检索；术语规范（区位导向型、生产性/生活性服务业）；含响应式断点；正文字号≥0.9rem；数据出处（footer 注明参考人教版教材与高考真题）显式给出。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 指向类型核对（核心 B1 规避）：主导因素表中——制糖厂归原料导向、啤酒厂归市场导向、炼铝厂归动力导向、服装厂归劳动力导向、集成电路归技术导向，五条全部正确，不得颠倒或错配；
2. 主导因素与案例自洽核对：主导因素表、地区案例、综合题答案关键词三处指向同一结论，不得出现"文字说劳动力指向，案例却是集成电路"类自相矛盾；
3. 综合题批改核对：在工业综合题输入全部采分关键词，应得满分（如 4/4）；输入空答案或无关词应得 0 分并给出改进建议；
4. 地区检索核对：分别输入"地中海沿岸""鲁尔区"，应返回对应产业的正确区位文本，不得张冠李戴或空返回；
5. 选择题答案核对：每道选择题正确项须与教材/案例同源（如工业第 1 题正确项为"制糖—原料/啤酒—市场/炼铝—动力"对应选项），干扰项不与正确项矛盾；
6. 逐个操作三标签切换、地区检索、选择题、综合题提交、参考答案显隐、折叠案例、Enter 检索各一次，无报错、无失效；
7. 数据出处核对：footer 或页面显式注明数据/案例来源（参考人教版教材与高考真题），不得无出处。
