# H06 · 马克斯主义的诞生 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中历史的"马克思主义的诞生"互动网页。学习目标：学生通过读时间轴、看三大思想来源继承关系 SVG、答 5 道由易到难的选择题，掌握马克思主义诞生的经济、阶级、思想条件与标志事件，区分空想与科学社会主义。

二、史实模型规格（年代/事件须与统编教材逐条可考；时间轴按年代先后排列，不得倒置；空想与科学社会主义不得混淆）：
- 时代背景与条件：
  · 经济条件：工业革命→生产力飞跃→生产社会化与生产资料私有制之间的矛盾；
  · 阶级条件：1825 英国首次经济危机；1831/1834 法国里昂工人起义；1836—1848 英国宪章运动；1844 德国西里西亚织工起义；
  · 思想条件（三大来源，不得张冠李戴）：德国古典哲学（黑格尔辩证法"合理内核"、费尔巴哈唯物主义"基本内核"）、英国古典政治经济学（亚当·斯密、大卫·李嘉图劳动价值论→马克思剩余价值学说）、空想社会主义（法国圣西门、傅立叶，英国欧文）。
- 诞生标志与组织沿革（年代顺序不得错置）：
  · 1847 正义者同盟改组为共产主义者同盟；
  · 1848 年 2 月《共产党宣言》发表，标志着马克思主义诞生；
  · 1848 欧洲革命、1871 巴黎公社——理论指导实践、实践检验理论；
  · 1864 第一国际（国际工人协会）成立；1876 解散。
- 时间轴节点排列顺序（核心 B1 chronology 规避，须严格按年代先后）：工业革命与阶级矛盾 → 三大工人运动（1831—1848）→ 马恩理论探索/三大思想来源 → 1848 年 2 月《共产党宣言》→ 1848 欧洲革命与巴黎公社（1848—1871）→ 1864 第一国际（1864—1876）→ 历史意义。**1848 欧洲革命与巴黎公社节点须排在 1864 第一国际节点之前**，不得倒置。
- 因果链（方向不可反）：工业革命→生产力飞跃→贫富分化→阶级对立→工人运动→呼唤科学理论→马克思主义诞生；社会主义从空想变为科学；理论→指导→实践检验。不得出现"上层建筑决定经济基础"式颠倒。
- 术语规范：三大思想来源、辩证法、剩余价值学说、空想社会主义、科学社会主义、共产主义者同盟、第一国际、巴黎公社；"将社会主义从空想变为科学"是科学社会主义的标志表述。
- 边界声明：空想社会主义（圣西门/傅立叶/欧文）与科学社会主义（马克思、恩格斯）须区分清晰，不混淆；马克思主义诞生标志明确为 1848 年 2 月《共产党宣言》。

三、交互与教学功能：①左侧时间轴（≥7 节点，按年代先后排列），点击节点切换右侧详情面板（含核心要点）；②难点处配 SVG 图解：三大思想来源继承关系图、理论与实践关系图（1848 革命与巴黎公社实践关系）；③每个节点提供"对照教材"可点开核对入口，注明该年代出自教材哪章；④末尾 5 道由易到难的选择题，答错给解析、答对进入下一题，全部答对显示"已完成"；⑤解析须标注教材出处；⑥至少一处史论结合收束（如"理论在工人运动中诞生，又在 1848 革命与巴黎公社的实践中检验"）。

四、工程与呈现约束：布局分"时间轴区／详情面板区／SVG 图解区／测验区"多层；1440×900 分辨率下无遮挡、无溢出、scroll-margin 锚点不被吸顶遮挡；棕色复古主题排版整洁；用系统字体栈，不外链远程字体；SVG 须含 role="img" 与 <title>/<desc> 或 aria-label；时间轴节点、测验选项按钮、对照教材入口均为真实 button 含 aria-label，可 Tab 到达、回车触发；测验选项有键盘可达的对/错反馈路径；正文字号≥0.9rem；不外链远程图片，图示一律用内联 SVG。
