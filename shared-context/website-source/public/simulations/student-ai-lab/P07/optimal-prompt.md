# P07 · 能量守恒定律 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中物理课堂的"能量守恒定律"学习页：知识讲解与一个可运行的自由落体能量转化实验放在同一页面。学习目标：学生通过拖动高度滑块并观察能量条形图，能表述"能量既不会凭空产生也不会凭空消失，只会从一种形式转化为另一种形式"。

二、物理模型规格：自由落体能量转化，Ep=mgh、Ek=½mv²、E=Ep+Ek 恒定；g=10 m/s²；以地面为参考平面、忽略空气阻力（页面显式声明）；SI 单位。

三、交互与教学功能：上半部为知识点区（定律表述、常见能量形式与转化实例，条理分节）；下半部为实验模块（同一 HTML 文件内实现，不使用 iframe）：高度 h 滑块（1–20 m）、质量 m 滑块（0.5–5 kg）、释放/重置按钮；下落动画旁用条形图实时显示 Ep、Ek、E 及数值读数；页面设"观察与结论"区。

四、工程与呈现约束：整页为单文件、无 iframe、无外链；1440×900 下无遮挡、无溢出；控件有可见标签；canvas 提供替代文本。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. h=5 m、m=2 kg：初始 Ep=100 J；手算落地 v=10 m/s、Ek=100 J，与读数对比；
2. 高度滑块从最小拖到最大，Ep 读数全程满足 Ep=mgh（抽两点手算核对）；
3. 下落过程中任意时刻 Ep+Ek 与 E 读数一致（偏差 <1%）；
4. 查看页面源码确认无 iframe、无外部资源引用；
5. 所有控件各操作一次，无报错、无失效。
