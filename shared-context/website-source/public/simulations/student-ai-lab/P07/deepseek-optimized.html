定律表述

能量既不会凭空产生，也不会凭空消失，它只会从一种形式转化为另一种形式，或者从一个物体转移到另一个物体，而在转化和转移的过程中，能量的总量保持不变。

这是自然界最基本的定律之一，适用于所有物理过程。在力学范围内，常考察机械能守恒：当只有重力做功时，物体的动能和重力势能之和保持不变。

常见能量形式与转化实例

  • 重力势能 Ep = mgh—物体因高度而具有的能量
  • 动能 Ek = ½mv²—物体因运动而具有的能量
  • 弹性势能—弹簧形变储存的能量 ⇌ 动能
  • 内能（热能）—摩擦生热：机械能 → 内能
  • 电能 / 光能 / 化学能—电池：化学能 → 电能 → 光能

实验结论

在忽略空气阻力的条件下，自由落体运动中物体的重力势能不断减小、动能不断增大，但二者的总和（机械能）始终保持不变。

这正是能量守恒定律在力学中的具体体现：
E = Ep + Ek = 常量

能量不会凭空产生或消失，只是从重力势能的形式转化为了动能的形式。
