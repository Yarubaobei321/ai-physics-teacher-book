# H05 · 建国前中国共产党砥砺前行的路程 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中历史课堂的"建国前中国共产党砥砺前行的路程（1921—1949）"互动网页。学习目标：学生通过点击时间线节点、答高考真题、看思维导图，掌握建党到大革命、土地革命、抗日战争、解放战争五期关键年代、事件、地点与因果。

二、史实模型规格（年代/事件/地点须与统编教材《中外历史纲要（上）》逐条可考；不得事件-地点错配，不得时序倒置）：
- 16 个时间节点（年代+事件+地点须一一正确）：
  · 中共一大 1921.7，上海→嘉兴南湖红船；
  · 中共二大 1922.7，反帝反封建民主革命纲领；
  · 中共三大 1923.6，国共合作（党内合作）；
  · 四一二政变 1927.4、七一五政变 1927.7；
  · 南昌起义 1927.8.1（打响武装反抗第一枪）；
  · 八七会议 1927.8.7（"枪杆子里出政权"）；
  · 秋收起义 1927.9；
  · 井冈山革命根据地 1927.10（第一个农村革命根据地）；
  · 中华苏维埃共和国 1931.11，瑞金；
  · 长征开始 1934.10；
  · 遵义会议 1935.1（确立毛泽东在党和红军中的领导地位，生死攸关转折点）；
  · 红军三大主力会宁会师 1936.10（长征胜利结束）；
  · 全面抗战爆发/国共第二次合作 1937.7；
  · 中共七大 1945.4（毛泽东思想确立为党的指导思想）；
  · 抗战胜利/重庆谈判/双十协定 1945.8—10；
  · 三大战役 1948.9—1949.1、开国大典 1949.10.1。
- 五期分期（与时间线同源）：创建时期 / 大革命时期 / 土地革命时期 / 抗日战争时期 / 解放战争时期。
- 关键时序（不得错置）：南昌起义（8.1）→八七会议（8.7）→秋收起义（9）→井冈山（10）；长征（1934.10）在遵义会议（1935.1）之前、会宁会师（1936.10）在遵义之后。
- 因果链（方向不可反）：北伐胜利与工农运动高涨→国民党右派恐慌叛变（四一二/七一五）；大革命失败→武装斗争必要→南昌起义；"左"倾教条主义错误→第五次反"围剿"失败→长征；长征濒危→遵义会议纠正错误→转危为安；日本全面侵华→国共第二次合作→抗日民族统一战线。
- 术语规范：民主革命纲领、反帝反封建、两步走（最低/最高纲领）、党内合作、工农武装割据、农村包围城市武装夺取政权、抗日民族统一战线、三大法宝（党的领导/武装斗争/统一战线）、新民主主义革命、毛泽东思想。
- 不可越界：本页内容截止 1949.10.1 开国大典，不展开 1949 年后党史。

三、交互与教学功能：①一个可点击时间线（≥16 节点），点击节点弹出模态（背景/详情/困难/解决/历史意义+关键词），模态可 × / 遮罩 / Esc 关闭；②另一 tab 为按 5 期组织的思维导图（每期 3—4 子节点，可折叠展开）；③每个知识点后配对应高考真题（选择+简答），真题须覆盖五期中至少四期（不得只考某一期），作答后逐题正误反馈并自动揭示解析，解析须标注教材出处；④"我已掌握"按钮关闭模态返回时间线；⑤顶部 sticky tab 在"时间线/思维导图/真题"之间切换，滚动高亮联动；⑥至少一处显性因果链收束（如"大革命失败→武装斗争→农村包围城市"），从史实罗列升级为史论结合。

四、工程与呈现约束：布局分"hero+sticky tab／时间线模态区／思维导图区／真题区"多层；1440×900 分辨率下无遮挡、无溢出、scroll-margin 锚点不被 sticky 吸顶遮挡；红金主题契合党史题材；用系统字体栈（PingFang/YaHei 等），不外链远程字体；emoji 作图标须配 alt 文本（或改用内联 SVG 含 role="img"+aria-label）；tab-nav、模态、真题按钮、模态 × 与"我已掌握"按钮均为真实 button 含 aria-label；打开模态时焦点进入模态、关闭后焦点回到触发节点；正文字号≥0.9rem。
