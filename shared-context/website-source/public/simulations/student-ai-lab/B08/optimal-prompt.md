# B08 · DNA复制的交互演示 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中生物课堂的"DNA 复制"交互演示。学习目标：通过分步观察一条母链作模板的复制过程、对照碱基配对与计数自测，理解半保留复制、合成方向 5'→3'、酶与原料、复制场所（细胞核/分裂间期）。

二、生物模型规格：只演示转录层 DNA-DNA 配对，碱基互补严格 A-T、G-C（DNA 层面不得出现 A-U）；模板链方向 3'→5'，新合成链方向 5'→3'；分步顺序固定为"解旋酶结合 → 按碱基逐位配对 → 连接酶连接 → 形成两条相同子代 DNA"，体现半保留（每条子 DNA 含一条母链+一条新链）；复制 n 代后 DNA 分子数为 2ⁿ，含母链的分子恒为 2；原料为 4 种脱氧核苷酸（dATP/dTTP/dGTP/dCTP）；氢键数 A-T 之间为 2 个、G-C 之间为 3 个；复制场所标注为细胞核、时期为分裂间期 S 期。

三、交互与教学功能：①分步点击演示，按钮标注当前步骤（解旋→配对→连接→完成）；②逐碱基合成动画显示新链沿模板 5'→3' 延伸，模板与碱基用颜色区分，hover 单个碱基显示其互补碱基与氢键数；③知识卡分块写明：复制方式（半保留）、场所、时期、酶（解旋酶/DNA 聚合酶/连接酶）、原料、方向；④演示结束后进入 5 题闯关测验，每题给即时正误反馈与解析，并累计正确率，可重做；⑤页面底部设"观察与归纳"区，列出看图后应得出的 3 条结论。

四、工程与呈现约束：布局分"画布区／控制区／知识卡与测验区"三栏；1440×900 分辨率下无遮挡、无溢出；所有控件为真实 button 元素、有可见文字标签；canvas 加 aria-label 描述当前步骤；测验选项用真实 button 而非 div.click；正文字号≥0.9rem，避免过暗背景。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 设模板链序列 3'-ATGC-5'：手算新合成子链应为 5'-TACG-3'（与模板逐位互补：A-T、T-A、G-C、C-G），演示完成后页面合成出的子链读数必须逐位等于该序列；
2. 设模板链 5'-AGCT-3'：其互补链按 3'-TCGA-5'（或等价改写为 5'-AGCT-3' 同一条链的反向）计，两种写法指同一条互补链——若测验出现该序列题，两种写法都必须判正确（不得只认一种而把另一种判错）；
3. "A 占 20% 时 G=?"：按双链 DNA 嘌呤=嘧啶（A=T、G=C，A+T+G+C=100%），A=T=20% → G+C=60% → G=30%，页面此题标答须为 30% 且解析含上述推导；
4. 复制 n 代题：若问"1 个 DNA 连续复制 3 代"，结果分子数应为 2³=8 个、含母链的分子恒为 2 个，标答与解析须与此一致；
5. 氢键计数：在 hover A-T 碱基对时显示"2 个氢键"，hover G-C 显示"3 个氢键"，不得颠倒；
6. 逐个操作分步按钮、测验按钮与重置按钮，无报错、无失效；演示完成后测验入口出现、提交反馈生效。
