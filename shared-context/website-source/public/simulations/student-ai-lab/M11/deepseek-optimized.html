一、求导法则讲解

基本初等函数

(c)′ = 0（常数的导数为 0）
(xⁿ)′ = n·xⁿ⁻¹如 (x²)′=2x、(x³)′=3x²、(√x)′=(x^½)′=1/(2√x)
(sin x)′ = cos x
(cos x)′ = −sin x
(eˣ)′ = eˣ
(ln x)′ = 1/x

求导法则

(u ± v)′ = u′ ± v′（和差）
(c·u)′ = c·u′（常数倍）
⚠️ 注意事项
  • 术语：导函数记作 f′(x)，其值即曲线在该点的切线斜率。
  • f′(x₀)=0 不一定取极值，须配合左右导数符号变化检验。
  • 定义域：ln x 要求 x>0，1/x 要求 x≠0。

四、简易问答自测

Q1：f(x)=x² 的导函数是？

🧭 观察与结论

幂函数求导规律：指数 n 降为 n−1，系数 n 乘以前方。即 (xⁿ)′=n·xⁿ⁻¹——每求导一次，次数减一，这就是多项式求导的「降次」本质。
