# M11 · 求导 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中数学课堂的「求导（导数）」交互学习页。学习目标：学生通过求导过程演示、基本初等函数求导法则、参数交互、简易问答自测，掌握常见函数 f(x) 的导函数 f′(x) 求法与基本求导法则（幂函数、和差、常数倍）。

二、数学模型规格：基本初等函数求导公式——常数 (c)′=0；幂函数 (xⁿ)′=n·xⁿ⁻¹（如 (x²)′=2x、(x³)′=3x²、(√x)′=(x^½)′=1/(2√x)）；正弦 (sin x)′=cos x；余弦 (cos x)′=−sin x；指数 (eˣ)′=eˣ；对数 (ln x)′=1/x。求导法则——和差 (u±v)′=u′±v′；常数倍 (c·u)′=c·u′。术语用「导函数 f′(x)」「切线斜率」；不得把「f′(x₀)=0」直接断言为极值（须配合左右导数符号变化检验）。函数定义域须声明（如 ln x 要求 x>0、1/x 要求 x≠0）。

三、交互与教学功能：起始页→进入工坊的多区布局；求导工坊含多函数（x²、x³、sin x、cos x、eˣ、ln x 等）过程演示（逐步显示法则应用与结果）、参数区（可改系数或指数看导数变化）、简易问答模块（单选题，如「f(x)=x² 的导函数是？A. x  B. 2x  C. x²/2  D. 2」，正确答案 B，附解析「幂函数 (xⁿ)′=n·xⁿ⁻¹，n=2 故 2x」）；问答模块每题必须写死标准答案与解析（不得仅靠随机拼字符串生成题目而无固定答案对照）；底部设「观察与结论」区引导归纳幂函数求导规律。

四、工程与呈现约束：布局分四栏（讲解／过程演示／参数／问答），1440×900 分辨率下无遮挡、无溢出；所有按钮、输入框有可见中文标签；函数选项卡、问答选项、进入工坊按钮均用真实 <button>（不得用 div 当按钮）；canvas 加 aria-label 描述当前函数与导函数；所有公式用 Unicode 或内联 KaTeX 渲染，不依赖外网 MathJax；问答题目与答案不得用未判空的模板字面量拼装，杜绝 innerHTML null 风险。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 幂函数求导：选择 f(x)=x²，过程与结果须显示 f′(x)=2x（按 (xⁿ)′=n·xⁿ⁻¹，n=2）；选择 f(x)=x³，结果须为 f′(x)=3x²；
2. 三角函数求导：选择 f(x)=sin x，结果须为 f′(x)=cos x；选择 f(x)=cos x，结果须为 f′(x)=−sin x；
3. 问答验收：题目「f(x)=x² 的导函数是？」正确选项必须为「2x」（B），答对给出解析「幂函数 (xⁿ)′=n·xⁿ⁻¹，n=2 故 2x」；至少再有一题如「f(x)=x³ 的导函数是？」正确答案 3x²；
4. 参数验收：把幂函数指数改为 n=4，导数结果须为 4x³；改系数 c=2（即 f=2x²），导数须为 4x（常数倍法则）；
5. 问答模块所有题目均有写死的标准答案与解析，刷新或重选不依赖随机拼字符串，无 console 报错；
6. 起始页进入工坊按钮、函数选项卡、参数输入、问答选项各操作一次，无报错、无失效；canvas 有 aria-label。
