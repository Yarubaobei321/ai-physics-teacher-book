一、柱、锥、台、球的结构特征

  • 棱柱/圆柱：两底面全等且平行；圆柱底面圆，母线平行且相等；
  • 棱锥/圆锥：一个底面、一个顶点；圆锥母线长 l = √(r²+h²)；
  • 棱台/圆台：用平行于底面的平面截锥体所得，上下底面相似；
  • 球：到球心距离等于半径 R 的点的集合。

二、体积与表面积公式

V_柱 = Sh，V_锥 = ⅓Sh，V_球 = (4/3)πR³
S_球 = 4πR²，S_圆柱侧 = 2πrl

三、长方体与正方体

长方体（a,b,c）：体对角线 = √(a²+b²+c²)，表面积 = 2(ab+bc+ca)
正方体（棱长 a）：体对角线 = a√3，外接球半径 = a√3/2

四、线面平行与垂直判定

线面垂直判定：直线 l ⊥ 平面内两条相交直线 ⇒ l ⊥ 平面（「相交」条件缺一不可）
线面平行判定：平面外直线 l ∥ 平面内一条直线 ⇒ l ∥ 平面

五、空间角与距离

线面角范围：[0°, 90°]（斜线与平面所成角为其与射影的夹角）
两点距离：|P₁P₂| = √((x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²)

六、外接球与内切球

侧棱两两垂直且长度为 a、b、c 的三棱锥，外接球半径：

R = ½√(a²+b²+c²)

七、斜二测画法

原图面积 = 直观图面积 × 2√2
