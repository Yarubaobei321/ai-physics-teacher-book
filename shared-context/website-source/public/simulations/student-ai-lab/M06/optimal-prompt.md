# M06 · 立体几何相关知识点 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖（不得用任何 CDN、importmap 或 unpkg 加载 Three.js/MathJax），双击即可在浏览器离线打开。

一、主题与受众：面向高一学生的「立体几何相关知识点」互动科普网页。学习目标：通过 3D 可旋转模型、带解答的演算例题、知识点讲解，覆盖柱/锥/台/球的结构特征、线面平行与垂直判定、空间角与距离、外接球与内切球等高一立体几何知识点。

二、数学模型规格：体积公式 V_柱=Sh、V_锥=⅓Sh、V_球=(4/3)πR³；表面积 S_球=4πR²、S_圆柱侧=2πrl；长方体（a,b,c）体对角线=√(a²+b²+c²)、表面积=2(ab+bc+ca)；正方体棱长 a 体对角线=a√3、外接球半径=a√3/2；侧棱两两垂直且长度为 a,b,c 的三棱锥，外接球半径 R=½√(a²+b²+c²)；斜二测画法：原图面积是直观图的 2√2 倍；线面角范围 [0°,90°]；线面垂直判定：一条直线与平面内两条相交直线都垂直，则该直线垂直于该平面（「相交」条件缺一不可）；所有公式与下标必须以**可离线渲染**的方式呈现：用 Unicode（√、π、²、³、½）或内联 KaTeX（把 KaTeX 的 CSS/JS 直接内联进单文件），**禁止使用 `\(...\)` 定界符依赖外网 MathJax 渲染**。

三、交互与教学功能：至少四个分区——①知识点讲解（柱/锥/台/球结构特征 + 线面平行垂直判定 + 空间角与距离 + 外接球内切球，公式可读）、②3D 模型演示（4 个按钮：长方体/正四面体/圆柱/球，OrbitControls 拖动旋转、滚轮缩放，**切换按钮时必须先 scene.remove 旧几何体与旧 CSS2D 标签、并从 DOM 移除旧标签 div，再创建新模型与新标签**）、③演算例题（至少 3 道带解答的数值题，含长方体对角线、表面积、外接球表面积）、④视频讲解（B 站等外链，注明「需联网」）；复位视角按钮可一键回到默认相机位；底部设「观察与结论」区。

四、工程与呈现约束：单文件、零外链、零 CDN、零 importmap（Three.js 若用须把库代码内联打包进单文件，或用纯 Canvas/CSS3D 替代实现 3D 效果）；布局分「3D 画布区／控制区／数据区」三栏；1440×900 分辨率下无遮挡、无溢出、3D 模型不溢出画布；4 个模型按钮、复位按钮均有可见中文标签；3D 画布与 CSS2D 标签提供 aria-label；所有公式可读渲染（不得出现字面 `\(...\)` 文本）；切换模型时画布只显示当前模型的几何体与文字标签，旧模型与旧标签必须清空。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 切换 4 个模型按钮（长方体→正四面体→圆柱→球）逐一点击：每次切换后画布上**只显示当前模型**的几何体与文字标签，前一个模型的 CSS2D 标签与几何体必须被清空，不得堆叠、不得残留；
2. 长方体长宽高 a=3、b=4、c=5：体对角线读数必须=√(9+16+25)=√50=5√2≈7.07，表面积读数必须=2(3·4+4·5+5·3)=2(12+20+15)=94；
3. 侧棱两两垂直、长度 a=3、b=4、c=5 的三棱锥：外接球半径 R=½√(9+16+25)=½·5√2=5√2/2，外接球表面积 S=4πR²=4π·(25·2/4)=50π；
4. 正方体棱长 a=2：体对角线=2√3≈3.464，外接球半径=√3≈1.732，外接球表面积=4π·(√3)²=12π；
5. 公式渲染：页面打开后所有公式（如 V_柱=Sh、V_锥=⅓Sh、4πR²）必须可读，不得出现字面 `\(...\)` 或 `\\(...\\)` backslash 文本；
6. 离线可用：断网状态下双击打开页面，3D 模型、公式、例题、按钮全部可用，无外网请求、无 console 报错；
7. 线面角范围标注 [0°,90°]；线面垂直判定定理必须含「两条相交直线」条件，不得省略；
8. 4 个模型按钮、复位视角、视频链接各操作一次，无报错、无 3D 崩溃。
