# G01 · 大气环流讲解 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中地理课堂的"大气环流·三圈环流"互动讲解网页。学习目标：学生通过看南北极剖面地球圆上的气压带/风带/三圈环流粒子动画、切换季节、读归纳表，掌握七个气压带的纬度分布、三圈环流的环向、北半球地转偏向"右偏"。

二、地理模型规格：
- 七个气压带（自北向南）：北极高压（90°）、北副极地低压（60°）、北副热带高压（30°）、赤道低压（0°）、南副热带高压（30°）、南副极地低压（60°）、南极高压（90°）；纬度标注不可错位（赤道低压必须在 0°、副热带高压必须在 30°、副极地低压必须在 60°、极地高压在 90°）。
- 成因：赤道低压=热力（受热上升）、极地高压=热力（冷却下沉）、副热带高压=动力（高空堆积下沉）、副极地低压=动力（冷暖交汇抬升）——不得把赤道低压误标为动力成因。
- 三圈环流环向：哈德莱环流（0–30°，赤道上升→高空向极→30°下沉→地面信风回流）、费雷尔环流（30–60°，60°抬升→高空向赤道→30°下沉，与哈德莱反向）、极地环流（60–90°，极地下沉→地面向赤道→60°抬升）；赤道与 60° 为上升、30° 与极地为下沉。
- 地面风带（北半球）：0–30°东北信风、30–60°盛行西风、60–90°极地东风；地转偏向遵循"北半球右偏、南半球左偏"，盛行西风不可画成东风。
- 季节移动：1月气压带整体南移、7月整体北移，春秋分居中，幅度约 5°。

三、交互与教学功能：①南北极剖面地球圆，用粒子动画展示哈德莱/费雷尔/极地三圈环流的环向（赤道与 60°上升、30°与极地下沉）；②季节切换按钮（1月/春秋分/7月），切换后所有气压带与风带整体南北移动；③鼠标悬停气压带时弹出 ≤30 字说明（含纬度与成因）；④底部"气压带与风带"归纳表（纬度+成因）与各自然带真实图景卡片；⑤"观察与结论"区，引导归纳"北半球地转偏向右偏、气压带纬度分布、三圈环流环向"。

四、工程与呈现约束：布局分"地球剖面动画区／季节控制条／归纳表与图景区／结论区"多层卡片；1440×900 分辨率下无遮挡、无溢出；所有控件为真实 button、有可见中文文字标签；canvas 提供 aria-label（描述当前季节与可见的气压带/环流）；**不得使用外链外部模块或远程图片**（如 unsplash），保证离线单文件可运行；正文字号≥0.9rem。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 主画布渲染自检（核心 B3 规避）：打开页面后浏览器控制台不得有任何红色错误；地球剖面图主画布必须实际画出内容（非空白），三圈环流粒子动画可见、季节切换按钮、图例高亮、悬停说明、暂停按钮全部可操作——杜绝"cy 误用为函数致 render() 抛错、主画布空白"类笔误；
2. 气压带纬度核对：依次核对七个气压带纬度——赤道低压=0°、北副热带高压=30°、北副极地低压=60°、北极高压=90°，南半球对称；不得出现"副热带高压画在赤道"或纬度错位；
3. 三圈环流环向核对：哈德莱环流赤道上升、30°下沉；费雷尔环流 60°抬升、高空向赤道；极地环流极地下沉；上升/下沉位置不得颠倒，环向不可画反；
4. 地转偏向核对：北半球地面风带——东北信风（0–30°）、盛行西风（30–60°，不可画成东风）、极地东风（60–90°）；偏向方向遵循"北半球右偏、南半球左偏"；
5. 季节移动核对：从春秋分切换到 7月，所有气压带整体北移约 5°；切换到 1月整体南移约 5°；移动方向不得反；
6. 成因标注核对：赤道低压=热力、极地高压=热力、副热带高压=动力、副极地低压=动力，不得把赤道低压误标为动力；
7. 逐个操作季节按钮、悬停每个气压带、暂停按钮各一次，无报错、无失效、主画布不空白。
