# B05 · DNA的转录与复制 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。响应式设计。

一、主题与受众：面向高中生的"DNA 的转录与翻译"互动配对网页。学习目标：学生通过在互补配对位置拖动碱基、按正确方式和顺序配对，掌握转录（DNA→mRNA）与翻译（mRNA→多肽）两阶段的碱基互补配对规则与方向。注意：本页主题就是"转录＋翻译"，不要做成 DNA 复制，也不要在标题里写"复制"。

二、生物模型规格：
模块一·转录：给定一条 DNA 模板链 3'→5'（页面默认提供一段示例，如 3'-TACGGATTCACT-5'），学生在 mRNA 合成槽位按正确顺序拖入与模板互补的 RNA 碱基；转录配对规则为 A-U、T-A、G-C、C-G（RNA 用 U 代替 T，不得把 DNA 层面的 A-T 写到转录环节）；模板链方向标 3'→5'，合成出的 mRNA 方向标 5'→3'；区分模板链与非模板链（编码链）。
模块二·翻译：按 mRNA 密码子顺序（从 5' 端 AUG 起，每次一个密码子=3 个核苷酸）拖入带互补反密码子的 tRNA；反密码子与密码子方向互补（如密码子 AUG 对应反密码子 UAC）；肽链随正确配对延伸；区分 mRNA、核糖体、tRNA、反密码子等结构。

三、交互与教学功能：在转录和翻译的每个互补配对位置暂停，等用户拖入正确碱基/tRNA 后才继续，按正确方式及顺序配对；配对成功后该位置锁定为绿色；配对错误时显示错误原因（应显示模板碱基/密码子、用户所选、以及正确答案的理由，例如"模板为 A，转录应配 U 而非 T"）；含阶段切换（转录↔翻译）、下一步按钮、全部重置；移除顺序提示让用户自行判断从哪一端转录/翻译，但错误时给出原因；元素尺寸适中便于操作（配对槽、拖拽元素、虚线框清晰可辨）。

四、工程与呈现约束：浅色响应式卡片布局，转录/翻译标签、图例、按钮、错误信息层级明确；1440×900 分辨率下无遮挡、无溢出；控件为真实 <button>、带可见文字标签；移动端可用；拖拽操作提供键盘可达的替代方式（如点击选择）；canvas/图例加 aria-label 描述配对场景；文字不小于 0.8rem。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 完成转录后，mRNA 应与模板链逐位互补：模板 A→mRNA U、T→A、G→C、C→G，逐位核对全程无错（不得出现 DNA 层面 A-T 被错用到转录）；
2. 翻译必须从 mRNA 5' 端 AUG 起按密码子顺序推进，每个密码子 3 个核苷酸；tRNA 反密码子与密码子互补（抽 2 个密码子核对方向互补）；
3. 故意拖错一个碱基（如模板为 A 处拖入 T）时，页面应提示错误原因并指出正确答案（应配 U），不直接跳过；
4. 配对成功后位置锁定为绿色，不可二次拖动；
5. 阶段切换（转录↔翻译）、下一步、全部重置各操作一次，无报错、无失效；
6. 页面标题、两个模块均统一为"转录＋翻译"，不出现"复制"字样（若登记题目含复制，成品标题与模块必须与实际内容一致，不得挂羊头卖狗肉）。
