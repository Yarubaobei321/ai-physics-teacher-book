# L03 · 语文古诗赏析题指导与实战演练 · 评审重构的最优提示词

> 这是活动结束后依据评审证据重构的研究提示词，不属于学生现场原始提示词。

请生成一个纯 HTML+CSS+JS 单文件网页，零外链、零素材依赖，双击即可在浏览器打开。

一、主题与受众：面向高中语文课堂的"古诗鉴赏答题方法指导与实战演练"互动网页。学习目标：学生通过读方法指导、看精讲例题、查意象锦囊、刷高考真题、订正错题，掌握"手法名称+诗句分析+情感效果"三段式分层采分答题法。

二、语文规则与文本规格（引文/出处错字=fail，赏析情感评价属"不判错区"不判错）：
- 方法指导四步法须自洽不自相矛盾：❶读懂·明语境 → ❷析技·定点突破 → ❸悟情·知人论世 → ❹规范·分层采分；"手法名称+诗句分析+情感效果"三段式须与简答提示"按手法+诗句分析+情感"一致，与炼字提示"字义+画面+情感"三段式变体方向相同（同型三段式，不构成模板矛盾）。
- 精讲课堂 4 例题须与分析方法一一对应：解诗（读懂）、炼字（字义+画面+情感）、用典（析技+悟情）、反衬（析技+悟情）。
- 引文须与课文/原卷逐字一致：杜甫《登高》颔联"无边落木萧萧下，不尽长江滚滚来"（"落木""长江"）；辛弃疾《永遇乐·京口北固亭怀古》"廉颇老矣"用典；刘克庄《宿千岁庵听泉》"变作怒声犹壮伟，滴成细点更清圆"原句。
- 作者-年代对应须正确：王安石(1021–1086) 北宋；宋之问(约 656–712)、陈子昂(661–702) 唐代；刘克庄(1187–1269) 南宋江湖派；杜甫流寓夔州作《登高》。
- 修辞/表现手法术语规范不混淆：反衬、用典、通感、炼字、借景抒情、虚实结合、动静结合、托物言志、比喻、拟人、衬托、对比、借代（注意借代 vs 比喻、被动 vs 判断句不混）。
- 选择题选项须按高考原卷一比一呈现，不得精简。

三、交互与教学功能：①方法指导页（四步法＋炼字/选择/简答三类题型提示）；②精讲课堂（4 例题，"先呈现完整标准答案、点击后再单独呈现采分点"，采分点高亮，答案可展开/收回双向）；③锦囊（意象/情感词/氛围词/手法术语四类词条，点击出对应诗句实例，如 月亮→杜甫《月夜忆舍弟》"月是故乡明"、流水→苏轼"大江东去"、用典→辛弃疾"廉颇老矣"、对比→杜甫"朱门酒肉臭，路有冻死骨"）；④真题刷题（≥3 道近年新高考真题原题，选择题自动核对、简答分层评分、采分点对照、一键订正，计时器从"点击开始"才计时，固定 6 分钟可调）；⑤错题本（自动收录、按关键词与日期搜索、显示掌握程度+错因、可一键跳回答题界面）。

四、工程与呈现约束：布局分"hero＋tab-bar＋content 三段式"四模块（方法/精讲/锦囊/真题/错题本）；1440×900 分辨率下无遮挡、无溢出；字体声明 Noto Serif SC/华文楷书须有 serif 系统字体降级链，**不得走外链字体（如 Google Fonts），htmlAudit.externalReferences 必须为空**；所有 tab、选项、提交按钮为真实 button 且带 aria-label，tab 含 aria-selected/role=tab，emoji 图标须配 alt 文本；正文字号≥0.9rem。

五、验收清单（生成后请逐条自检，并在代码之外用文字报告每条结果）：
1. 答题模板一致性核对（B1 规避）：方法指导四步法与精讲课堂 4 例题一一对应；"手法+诗句分析+情感"三段式与简答/炼字提示同型不矛盾；generalTip 与第❹步一致；
2. 引文逐字核对原文（核心 A4 补全 + B1 规避）：把所有引文与课文/原卷逐字核对——杜甫《登高》"无边落木萧萧下，不尽长江滚滚来"、辛弃疾"廉颇老矣"、刘克庄《宿千岁庵听泉》"变作怒声犹壮伟，滴成细点更清圆"——不得有错字、漏字、出处错配；作者-年代（王安石北宋、刘克庄南宋、杜甫流寓夔州）须正确；
3. 简答评分逻辑核对（核心 B1 fail→warning→规避）：`evaluateEssay()` 拆分采分点的字符必须与采分点数据的连接符严格一致——若数据用中文顿号"、"连接，则 split 用"、"；若用英文逗号","连接，则 split 用","；也可二者并容（`split(/、|,/)`）。验收：取 3 道简答中任一题，输入其完整正确采分点（如"借物喻人"）应得满分（6/6），6 分档可达；输入空串得 0 分；
4. 选择题自动核对一致性（A4 补全）：3 道高考真题正确答案（均设为 D，且 explanation 与选项 D 表述自洽，如"久埋瘴雾看犹湿"=润泽非水渍斑驳、"古壁"=年代久远、"亦把湍流替管弦"=以自然代音乐）须与 officialAnswer、extraPoints 表述同源；选项按原卷一比一呈现不精简；
5. 交互完整性：5 个 tab 切换、4 个折叠答案（展开/收回双向）、38 个 tip-tag（逐一点击出实例）、计时器（开始→计时→重置）、选择题核对、简答评分、诗歌切换、错题本收录与搜索各操作一次，无报错、无失效、0 console 错误；
6. 工程核对（B4 规避）：无 Google Fonts 等外链请求；emoji 图标均有 alt；tab/radio 含 aria-selected/role/aria-label；正文字号≥0.9rem。
