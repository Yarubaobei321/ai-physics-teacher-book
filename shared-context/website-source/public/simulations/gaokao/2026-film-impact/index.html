原题结构与观察任务

本页对应《智启格物》第1章使用的 2026 年广东高考薄膜冲击实验。 页面只展开“由三帧位移估速度、由峰值力与平均力系数估压缩时间”的模型链，不复制整道试题和完整解析。

  1. 比较 s₂−s₁ 与 T²，判断三帧数据是否与自由落体加速度相容。
  2. 把峰值力减小，观察压缩时间和重力冲量占比如何变化。
  3. 保持峰值力不变，切换三种力时程，解释为什么平均力系数会改变时间。

MODEL BOUNDARY

哪些结论不能越界

  • 2.06 ms 是按题目读图精度给出的估测；2.058 ms 只用于程序回归，不是更精确的实验结论。
  • 三角形只是一种实现平均力 F/2 的等效力史，真实薄膜冲击曲线需要传感器数据验证。
  • 反弹只用于分段示意；归一化形变不代表真实压缩位移。
  • 当平均接触力不足以克服重力时，当前模型没有“速度降为零”的解；重力占比偏大时题式近似失效。
