用动画观察：小球从左端滑上光滑小车。初速度小于临界值时从左边滑回；初速度达到或超过临界值时越过最高点并从右边滑下。

模型假设

  • 小球质量为 m，小车质量为 M，均可调节。
  • 水平面与曲面均光滑，只考虑重力和支持力。
  • 水平方向外力为零，系统水平动量守恒。
  • 曲面采用对称方程 h(q)=H[1-|1-2q/L|3/2]2。

关键公式

曲面：h(q)=H[1-|1-2q/L|3/2]2，u=dq/dt
约束：x球 = X + q，小车速度为 V
动量：m(V + u) + MV = mv0
临界：vc = √[2gH(M+m)/M]
能量：u2 = [(M/(M+m))v02 - 2gh(q)] / [M/(M+m) + h'(q)2]
读图：上滑时 u 变小，所以小球速度变小，小车速度变大；下滑时相反。

1. 为什么最高点共速

当 v0 < vc 时，小球到达某个转折点后相对小车反向运动，最后从左边滑下。

当 v0 ≥ vc 时，小球能越过最高点，并从右边滑下。临界时最高点相对速度为零。

2. 课堂观察任务

  • 切换低于临界和高于临界，观察小球分别从哪一侧滑下。
  • 调节小球质量和小车质量，观察临界速度怎样变化。
  • 比较小车动能、小球动能和小球重力势能三项的转化。
  • 低速情形下跳到转折点，观察小球相对小车的速度变为零。
