用动画观察这道多选题中的两个关键点：半圆槽为什么会先向右、再向左做往复运动；小球第一次离开槽时为什么不是斜抛，而是竖直上抛。

为什么会这样运动

1. 建立模型

设半圆槽质量为 M，小球质量为 m，半径为 R。槽只允许在水平面上运动，小球沿光滑半圆面运动；若小球离槽，则在空中只受重力。

2. 水平方向守恒

地面和重力都不给系统水平方向的外力，所以任何时刻都有：

守恒式m vx + M V = 0

这说明小球向左运动时，槽会向右；小球向右运动时，槽会向左。槽不是一直向右，而是往复运动。

3. 离槽瞬间

小球在半圆槽边缘处的切线是竖直的。此时小球相对槽没有水平速度，若离开槽，球和槽的水平速度相同；再由水平总动量为 0，可知二者水平速度都为 0。

结论vx = V = 0，小球只剩竖直速度

题目判断

答案：B、C

  1. A 错：第一次离槽时，小球水平速度为 0，不会向右上方斜抛。
  2. B 对：若从右上方释放，小球第一次到另一侧边缘时仍有竖直向上速度，因此做竖直上抛。
  3. C 对：小球竖直上抛后会落回同一侧边缘，随后反向经过半圆槽，整个过程重复，槽做往复运动。
  4. D 错：槽先向右，后向左，不是一直向右运动。

观察任务

  • 把 h / R 调为 0，观察小球到两侧边缘时速度如何变化。
  • 把 h / R 调大，观察小球第一次离槽时速度箭头是否水平倾斜。
  • 观察质心竖线：系统水平方向质心为什么不动？
  • 比较槽的速度读数：什么时候为正、什么时候为负、什么时候为 0？
