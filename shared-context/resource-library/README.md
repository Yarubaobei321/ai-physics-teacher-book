# 项目资源库

项目资源库是本人真实项目、课程、网站、软件、课题和证据材料的通用索引层。原件继续保留在各自目录；这里负责告诉人和AI“有什么、归谁、当前做到哪一步、按什么顺序读取”。

## 第一入口

处理任何科研、论文或书稿任务时，先读：

1. [知识地图](./00_AGENT入口/KNOWLEDGE_MAP.md)
2. [项目注册表](./00_AGENT入口/PROJECT_INDEX.md)
3. [证据索引](./00_AGENT入口/EVIDENCE_INDEX.md)
4. [观点与研究假设](./00_AGENT入口/CLAIMS.md)
5. [任务路由](./00_AGENT入口/TASK_ROUTER.md)

入口按真实项目和证据组织，不再按旧论文代号组织。旧代号只在[历史代号对照](./00_AGENT入口/历史代号对照.md)中用于读懂历史文件。

## AI读取原则

- 不递归扫描整个资源库；先从项目注册表选最多3个项目。
- 每个项目默认只从证据索引选择最多5份材料。
- 优先读源项目的AGENTS、README、原始数据或正式文书；整理副本只作辅助。
- 区分已核原件、可复核、历史快照、待补和受限材料。
- 旧论文完整稿默认不读；只有比较、诊断或追溯版本时才打开。
- 论文02和其他现有AI成稿都是待作者重构的端到端产物，不以“文件齐全”推断接近投稿。

## 权利和安全边界

- 学生材料先脱敏；姓名映射不进入普通科研上下文。
- 商业教辅原件和批量转换内容只供本地研究，不公开分发或上传到未授权服务。
- WiFi、MAC、部署密钥和服务器配置不进入写作上下文。
- 其他教师材料保留原作者和贡献，不并入本人独立成果。
- 课题文本说明研究承诺，不能代替研究结果。
