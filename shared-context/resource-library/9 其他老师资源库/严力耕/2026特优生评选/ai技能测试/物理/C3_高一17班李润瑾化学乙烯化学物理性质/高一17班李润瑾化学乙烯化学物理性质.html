📐 分子结构

分子式：C₂H₄  |  结构简式：CH₂=CH₂  |  电子式：碳碳双键(两对共用电子)

  • 杂化方式：C原子为sp²杂化，形成平面三角形，键角≈120°
  • 双键组成：1个σ键 + 1个π键，π键电子云分布在平面上下，易断裂 → 化学性质活泼
  • 所有原子共平面，C=C键长0.134nm（比乙烷单键短）
电子式示意： H : C :: C : H (双键代表两个共价键)

⚡ 物理性质

🧊 无色、稍有甜味的气体
💧 难溶于水，易溶于有机溶剂
⚖️ 密度比空气略小 (M=28)
🌡️ 熔点 -169℃ / 沸点 -103.7℃

🧨 化学性质 (双键的盛宴)

➕ 加成反应（核心）

定义：π键断裂，两个原子或基团分别加到双键两端碳上。

① 与Br₂加成：CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br (溴水褪色，检验双键)
② 催化加氢：CH₂=CH₂ + H₂ → CH₃–CH₃ (Ni, 加热)
③ 与水加成：CH₂=CH₂ + H₂O → CH₃CH₂OH (工业乙醇)
④ 与HCl加成：CH₂=CH₂ + HCl → CH₃CH₂Cl

🔥 氧化反应

• 燃烧：火焰明亮带黑烟（含碳量高）
• 使酸性KMnO₄溶液褪色（被氧化为CO₂）

🔗 加聚反应

n CH₂=CH₂ → [–CH₂–CH₂–]ₙ (聚乙烯)

🧪 实验室制法 (乙醇消去)

CH₃CH₂OH → CH₂=CH₂↑ + H₂O (浓H₂SO₄, 170℃)
  • 浓硫酸作催化剂和脱水剂；碎瓷片防暴沸；温度计插入液面，迅速升温至170℃防乙醚生成；NaOH溶液除杂SO₂/CO₂。

🏭 工业制法 · 石油裂解

高温裂解石脑油或乙烷，获得乙烯、丙烯。乙烯产量是衡量国家石油化工水平的标志。

💎 主要用途

🍌 植物催熟剂
🧴 聚乙烯塑料 (薄膜、容器)
🍷 合成乙醇 (水合法)
🏭 制备环氧乙烷、苯乙烯等

📊 乙烯 vs 乙烷

对比项乙烯 (C₂H₄)乙烷 (C₂H₆)
碳碳键型双键 (σ+π)单键 σ
酸性KMnO₄褪色 (氧化)不褪色
溴水/CCl₄褪色 (加成)不褪色 (取代需光照)
主要反应类型加成、加聚取代、裂解

✍️ 思维自测 (考点巩固)

  1. 乙烯使溴水褪色与使酸性高锰酸钾褪色的原理有何不同？
  2. 从化学键角度解释乙烯为何比乙烷活泼？
  3. 实验室制乙烯为何温度必须迅速升到170℃？
🔍 点击查看答案

1. 乙烯与溴水是加成反应；与酸性KMnO₄是氧化还原反应。
2. 乙烯含有π键，易断裂发生加成；乙烷只有σ键，较稳定。
3. 防止在140℃时发生分子间脱水生成乙醚，影响乙烯产率。
