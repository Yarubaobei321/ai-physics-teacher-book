代表性无机物 · 性质方程式全览

钠 Na

强还原性质软密度＜1
  • 还原性/氧化4Na + O₂ (常温) = 2Na₂O
  • 与水反应2Na + 2H₂O = 2NaOH + H₂↑
  • 供氧剂2Na₂O₂ + 2H₂O = 4NaOH + O₂↑
  • 与CO₂2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂
银白色金属，切面光泽

氯气 Cl₂

  • 强氧化性H₂ + Cl₂ (光照或点燃) = 2HCl
  • 歧化反应Cl₂ + H₂O ⇌ HCl + HClO
  • 与碱歧化Cl₂ + 2NaOH = NaCl + NaClO + H₂O
  • 与金属反应2Fe + 3Cl₂ (点燃) = 2FeCl₃
黄绿色气体，强氧化性

铁 Fe · 变价体系

  • 与氧气反应3Fe + 2O₂ (点燃) = Fe₃O₄
  • 与氯气反应2Fe + 3Cl₂ (点燃) = 2FeCl₃
  • Fe²⁺→Fe³⁺2FeCl₂ + Cl₂ = 2FeCl₃
  • Fe(OH)₂氧化4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃
铁与氯气生成棕褐色烟

铝 Al · 两性

  • 与酸反应2Al + 6HCl = 2AlCl₃ + 3H₂↑
  • 与碱反应2Al + 2NaOH + 6H₂O = 2Na[Al(OH)₄] + 3H₂↑
  • 铝热反应2Al + Fe₂O₃ (高温) = Al₂O₃ + 2Fe
铝与碱反应产生氢气

硫 S · 氧化物与硫酸

  • 单质燃烧S + O₂ (点燃) = SO₂
  • 催化氧化2SO₂ + O₂ (催化剂、加热) = 2SO₃
  • 漂白性SO₂ + 品红溶液 → 无色(加热恢复红色)
品红溶液褪色现象

氨气 NH₃

  • 合成氨N₂ + 3H₂ (高温高压、催化剂) = 2NH₃
  • 催化氧化4NH₃ + 5O₂ (催化剂、加热) = 4NO + 6H₂O
  • 氨与酸NH₃ + HCl = NH₄Cl (白烟)

无机物流程题 · 除杂与检验模型 高频考点

物质除杂模型

① NaCl溶液(混有Na₂CO₃)
加适量稀盐酸：Na₂CO₃ + 2HCl = 2NaCl + CO₂↑ + H₂O
② FeCl₂溶液(混有FeCl₃)
加过量铁粉：2FeCl₃ + Fe = 3FeCl₂
③ Mg粉(混有Al粉)
加NaOH溶液：2Al + 2NaOH + 6H₂O = 2Na[Al(OH)₄] + 3H₂↑
④ CO₂(混有SO₂)
饱和NaHCO₃溶液：SO₂ + 2NaHCO₃ = Na₂SO₃ + H₂O + 2CO₂

无机离子检验专项

Cl⁻ 检验： 稀硝酸酸化 + AgNO₃ → 白色沉淀
SO₄²⁻ 检验： 先加稀盐酸无现象，再加BaCl₂ → 白色沉淀
Fe³⁺ 检验： 加KSCN → 血红色
Fe²⁺ 检验： 加KSCN不变色，再加氯水变红；或K₃[Fe(CN)₆]→深蓝沉淀
NH₄⁺ 检验： 加强碱加热，湿润红色石蕊试纸变蓝：NH₄⁺ + OH⁻ (加热) = NH₃↑ + H₂O

无机工业流程链

氯碱工业： 2NaCl + 2H₂O (电解) = 2NaOH + H₂↑ + Cl₂↑
硫酸工业(接触法)： 2SO₂ + O₂ ⇌ 2SO₃ → H₂SO₄
侯氏制碱： NaCl + NH₃ + CO₂ + H₂O = NaHCO₃↓ + NH₄Cl
硝酸工业： NH₃ → NO → NO₂ → HNO₃
