🎯 五点作图法 · 核心方法

❶ 定相位点标准正弦五点相位:
0, π/2, π, 3π/2, 2π
❷ 坐标变换x = (相位 - φ)/ω
y = A·sin(相位) + b
❸ 描点连线 依次描出五点 → 光滑曲线 → 得一个周期图像
💡 五点决定波形轮廓，平移伸缩后依然精准定位！

📖 参数变化规律 | 正弦型函数 y = A·sin(ωx+φ)+b

A·振幅 : 改变最值范围，|A|越大，波峰越高，极值越大。
ω·角频率 : 周期 T=2π/|ω|，ω越大图像横向压缩，波形越密集。
φ·初相 : 图像整体左右平移，φ>0 左移 (x替换为x-φ/ω规则)。
b·纵移 : 平衡位置上下移动，b>0图像上移，最值同步改变。
