❄️ 文言文 · 五大特殊句式

冷色解析 · 标准句式 | 倒装专题细分 + 固定句式全览

📐 标准句式（现代汉语基准）

【结构】 (定)主 + [状] 谓 + (定)宾
🧷 例如：（勤奋的）学生 [认真] 学习 <文言文>。
📖 正常语序：主语在前，谓语居中，宾语在后；状语修饰谓语，定语修饰主宾。
📖 判断句 表等同/属性
🔍 讲解：表判断（是什么），通常借助“……者……也” “乃” “则” “非”等。翻译需要补出“是”。
✅ 陈胜者，阳城人也。（《陈涉世家》）→ 陈胜是阳城人。
✅ 此非曹孟德之诗乎？（《赤壁赋》）→ 这不是曹操的诗吗？
✅ 此则岳阳楼之大观也。→ 这就是岳阳楼的雄伟景象。
⚙️ 被动句 主语是接受者
💡 讲解：主语是动作接受者，宾语是动作发起者。标志：于、见、为、被 及 见……于…… / 为……所……，翻译加“被”。
✅ 臣诚恐见欺于王而负赵。（《廉颇蔺相如列传》）→ 我被大王欺骗。
✅ 身死人手，为天下笑。（《过秦论》）→ 被天下人耻笑。
✂️ 省略句 补全省略成分
✨ 讲解：主语、谓语、宾语或介词“于”“以”省略时，需根据语境补充翻译。
✅ 一鼓作气，再而衰，三而竭。（省谓语“鼓”）→ 第二次击鼓衰落。
✅ 便要(之)还家。（《桃花源记》）→ 邀请(渔人)回家。
✅ 又试之(以)鸡。（《促织》） → 又用鸡试验。
🔗 固定句式 惯用搭配集锦
🤝 讲解：一些固定的搭配，表达反问/疑问/感叹/揣度等语气。以下是例子：
不亦……乎？ → 不也……吗？ 例：学而时习之，不亦说乎？
得无……乎？ → 该不会……吧？ 例：览物之情，得无异乎？
何……为？ → 为什么要……呢？ 例：何辞为？（《鸿门宴》）
无乃……乎？ → 恐怕……吧？ 例：无乃不可乎？
如……何？ → 把……怎么样？ 例：如太行、王屋何？
孰与…… → 与……相比，谁更？ 例：我孰与城北徐公美？
🔄 倒装句 · 四大细分精讲 语序颠倒复位法
📌 宾语前置
讲解： 宾语位于主谓之间（正常宾在谓后）。
✔ 疑问句中疑问代词作宾语（安、何、谁等）
✔ 否定句中代词作宾语（未、不、莫+之/是）
✅ 沛公安在？ → “在安” → 沛公在哪里？
✅ 未之有也。 → 未有之也。
📍 状语后置
讲解： 修饰动词的词语放在动词之后，如介词结构“于/以……”放在谓语后作补语，翻译提前至动词前。
动词 + 于/以 + 名词（地点/对象）
✅ 战于长勺。 → 于长勺战。
✅ 醒能述以文者。 → 能以文述。
🏷️ 定语后置
讲解： 修饰主语和宾语的定语放在中心词后，常用“之……者”“……者”。
中心词 + 之 + 定语 + 者 / 中心词 + 定语 + 者
✅ 马之千里者。 → 千里马。
✅ 求人可使报秦者。 → 寻求可使报秦之人。
⚠️ 主谓倒装
讲解： 主语和谓语顺序对调，多用于强调感叹语气。
谓语 + 主语（甚矣，汝之不惠）
✅ 贤哉，回也！ → 颜回真贤良！
✅ 甚矣，汝之不惠！ → 你太不聪明了！
