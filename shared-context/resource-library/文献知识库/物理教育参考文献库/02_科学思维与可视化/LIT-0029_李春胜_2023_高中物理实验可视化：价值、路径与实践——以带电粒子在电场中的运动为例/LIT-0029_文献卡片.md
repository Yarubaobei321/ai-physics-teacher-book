# 高中物理实验可视化：价值、路径与实践——以“带电粒子在电场中的运动”为例

> 作者：李春胜、钟志鹏（无锡市玉祁高级中学）  
> 核验状态：**已核验**（以 YAML 题录字段和“引用信息”为准；核验来源与日期见 `metadata_source`、`verified_at`）。

## 一句话贡献

以手摇起电机、箔板、带电小球、手机视频和 Tracker 构建带电粒子运动的低成本类比实验，实现轨迹和速度变化可视化。

## 研究方法

- 单课时教学设计 + 自制教具开发
- 自制手摇发电机+锡箔纸+带电小球演示仪，把不可见的带电粒子运动「可视化」；用手机拍视频导入 Tracker 软件，自动跟踪并出 v-t/x-t 图

## 可借鉴点（对我有用）

1. 「视频 → Tracker 自动跟踪 → 图象分析」的数字实验路径，可直接迁移到机械能守恒：拍自由落体/单摆视频，Tracker 出速度/位移图，再算动能/势能，验证守恒。
2. 自制教具「用可见的带电小球类比不可见的带电粒子」的思路，启发生成机械能守恒的「可观测代理量」。

## 精读笔记

- 实验可视化两路径：①自制教具（低成本高质量）创新实验形式；②数字实验（Tracker）优化表征方式——结构清晰，可作本人 C2 方法分类参照。
- 直线加速器例题（课本原题）的四个学生疑点，都指向「带电粒子运动无法看清」，可视化是破题关键——与机械能守恒「能量不可见」同构。
- 强调 2017 课标「演示实验是师生共同探讨问题的学习方式」，可视化要服务于科学探究，而非炫技。
- 基金：江苏「十三五」重点课题「基于行知物理课程基地提升学科育人品质」。

## 研究问题

作者关注肉眼不可见且运动迅速的带电粒子过程，怎样通过自制教具和视频分析转化为学生可观察、可调节的实验任务。

## 研究方法与样本

采用自制教具开发和教学案例分析，设计加速与偏转两类活动并用 Tracker 处理视频；没有报告班级人数或量化学习结果。

## 核心证据与结论

装置用手摇起电机和箔板建立电场，以带电小球类比粒子；学生拍摄运动并在 Tracker 中标定、追踪位置和生成速度—时间图，再调节装置使小球完成加速或击中目标点。证据支持装置和分析流程可实施，未证明思维品质增益。

## 局限

宏观小球存在摩擦、空气阻力和电荷变化，与理想带电粒子模型不同；文章未量化电场、轨迹误差或学生成效，类比边界若不说明可能造成误解。

## 对应我的项目与论文

服务 C2、实验可视化和数智育才资源，可为机械能项目的视频追踪、实时图像和模型边界说明提供同刊案例。

## 与本人工作的差异化

原文针对电场运动的宏观类比教具，数据呈现偏定性；本人项目聚焦机械能守恒，可直接测量运动并把能量计算、误差和操作记录联动。

## 精读摘要

文章针对带电粒子运动肉眼不可见、速度快、课堂上常停留于理论推导的问题，开发由手摇起电机、箔板和带电小球组成的低成本类比装置。学生用手机拍摄小球运动，将视频导入 Tracker，完成比例标定和逐帧追踪，得到轨迹及速度—时间图；在加速和偏转任务中，还需调节装置参数，使小球达到预定状态或击中目标点。文章的价值是把自制教具、数字采集、数据图像和反向调参连接成完整探究链，适合启发实验可视化资源。它没有报告班级样本、学生作品评分或学习效果；宏观小球还受摩擦、空气阻力和电荷变化影响，与理想带电粒子存在重要差异。用于本人机械能项目时，可迁移手机追踪和参数调节流程，同时把模型边界、误差来源和失败记录明确纳入学生任务。
