## 单篇文献结构

每个 `LIT-xxxx` 单元包含 PDF 原文、全文 Markdown、文献卡片、正文实际引用的图片，以及必要时的版本附件。文献卡片提供贡献、问题、方法与样本、证据、局限、借鉴点、项目关系、差异化和页码锚点。

## 推荐阅读顺序

使用本库时，先定位并阅读对应的 `LIT-xxxx_文献卡片.md`，再根据问题决定是否打开同一单元的 `LIT-xxxx_全文.md`。只有需要核对原始页码、图表或版面时，才回查 PDF。

- 先读文献卡片：掌握题录、研究问题、方法、证据、局限和可借鉴点。
- 再读精校版全文：只在卡片无法回答具体论断、数据、段落或引用边界时打开。
- 最后回查 PDF：用于页码、图表、原始排版和卡片/全文存在疑问的核验。

不要默认批量读取全部全文；总台账、Bases 或 HTML 只用于定位候选文献。

## 筛选口径

- 来源等级、文章证据等级、课题相关性三维独立显示。
- “优先使用”默认选择来源 A/B、证据 A/B、相关性高的文献；人工收藏可以覆盖默认规则。
- “引用就绪”只包含题录已核验且关键字段完整的文献。

## 后续入库

将新 PDF 放入 `00_待入库/`，先运行 `ingest` 查看重复、题名和分类建议。人工确认后再正式编号、转换和入库。尚未转换且价值较低的旧论文不补转。
