# 无线速度传感器——基于Arduino和Flash的无线DIS实验

> 核验状态：**已核验**（以 YAML 题录字段和“引用信息”为准；核验来源与日期见 `metadata_source`、`verified_at`）。

## 一句话贡献

把无线光电门装到小车上、把多条等宽挡光片铺在轨道上，用蓝牙连续测得多个时刻速度，兼顾光电门精度与速度—时间过程记录。

## 研究问题

如何克服打点计时器摩擦、固定光电门只能测少数位置、超声测速误差大的限制，连续获得运动小车的高精度速度数据。

## 研究方法与样本

设计无线光电门、轨道挡光片、双蓝牙接收端和Flash软件四部分原型；让小车沿斜面运动，逐次记录挡光时间与中点时刻，绘图并用电子表格拟合加速度。

## 核心证据与结论

装置能在多个挡光片位置显示速度和对应时刻，形成速度—时间图并拟合加速度；文章给出部件、连接和实测图，但没有报告挡光片宽度误差、拟合数值和重复性。

## 局限

OCR虽不影响装置主线，但原文的具体芯片与部分数值难辨；没有校准、无线丢包、时钟同步、重复试验和传统仪器对照数据，教学效果也未测。

## 可借鉴点

可借鉴“传感器随物体运动、尺度件固定在环境中”的倒置设计，以及同时记录速度和中点时刻；本项目应增加校准、丢包和不确定度测试。

## 对应我的项目与论文

服务网页DIS、光电门测速度与ESP32Blockly方向，可作为无线传感器和真实—虚拟界面结合的直接工程先例。

## 与本人工作的差异化

该文采用Arduino、蓝牙与Flash的专用原型，本人平台采用现代网页和可编程硬件，还需提供更透明的源代码、设备测试与课堂数据。

## 精读摘要

文章比较三类传统测速方案：打点计时器能记录过程但受纸带摩擦影响；固定光电门精度高却只能测少数位置；超声测距连续但由距离差计算速度会放大误差。作者据此倒置光电门与挡光片的位置，把无线光电门装在小车上，在轨道布置多条等宽磁带挡光片，经蓝牙把挡光时间和中点时刻传给接收端，再由Flash界面显示速度、绘制速度—时间图。斜面小车案例能导出数据并拟合加速度，说明工程链路可工作。论文未报告挡光片宽度误差、无线丢包、时钟同步、重复性或传统仪器对照，无法量化精度优势。其价值主要是连续光电测速的结构创意和真实传感—虚拟界面结合思路。后续复现时还应公开芯片、程序、校准步骤与原始数据，并把仪器精度和学习效果分别验证。
