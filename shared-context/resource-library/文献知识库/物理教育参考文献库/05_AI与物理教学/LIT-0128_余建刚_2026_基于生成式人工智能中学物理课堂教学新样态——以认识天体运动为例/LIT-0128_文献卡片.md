# 基于生成式人工智能中学物理课堂教学新样态——以粤教版高中物理必修2《认识天体运动》为例

## 一句话贡献

构建教师—GenAI—学生“知识生成共同体”，用 GenAI 支持天体运动课的猜想—验证与交互模拟代码生成。

## 研究问题

GenAI 如何重塑中学物理课堂样态，支持学生在天体运动主题中经历科学发现过程。

## 研究方法与样本

粤教版必修2《认识天体运动》教学设计与课堂实施描述；含学生指令生成互动实验 HTML 的示例；无对照实验数据。

## 核心证据与结论

提出三元协同模型与课前—课中—课后环节；学生指令生成行星轨道速度模拟器等交互页面并做偏差/面积定律验证；强调从记忆定律转向验证规律。

## 局限

成效多为叙述；PDF 文末混入无关弹道导弹进动短文；生成交互页的物理正确性核验流程未系统化。

## 精读摘要

本文以粤教版高中物理必修2《认识天体运动》为载体，提出“教师—GenAI—学生”三元协同的知识生成共同体，并把课堂组织为课前自主探源、课中协作探究、课后个性作业三个环节。课前，学生借助 GenAI 认识椭圆、比较地心说与日心说；课中，利用交互 HTML 模拟和真实天文数据，依次探究椭圆轨道、开普勒第二定律的面积规律以及第三定律中半长轴与周期平方的关系；课后，生成分层作业和“寻找第二地球”等项目任务。文章的价值在于把“记忆定律”改造成“数据—模拟—猜想—验证—解释”的探究链，同时明确教师仍需承担任务设计、内容筛选和价值引导责任。本文主要是教学模式与案例描述，缺少对照实验和系统的学生学习成效数据；原 PDF 栏间混入相邻文章，已在全文中删除。
