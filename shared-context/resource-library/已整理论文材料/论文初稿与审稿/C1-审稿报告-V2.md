**先补素材，再投。** 严格说，V2.0 当前形态（图全占位 + 正文带`【需补充】`占位符 + 文末工作区清单）**不可直接投稿**——编辑初审会以"稿件未完成"退稿。投稿前必须完成的最小动作：

- **必做（不做即退稿）**：① 4 幅图至少图 1（结构图）、图 2（界面截图）、图 3（光电门对比图）成图；图 4 若补不到课堂照片，改为"网页 DIS 界面+数据流示意图"。② 清除全部`【需补充/需核验】`占位符与文末"待核验线索""占位清单"。③ 补著录项（作者单位+邮编+简介、课题编号）。④ 处理双重编码谱系瑕疵（§2.1）。
- **强烈建议（决定档次）**：补一组真实课堂实测数据替换/并列调试数据（§七-2），否则案例/数据停在 2 分，上限②。

### 目标期刊与栏目

- **主投**：《物理教师》——匹配度中高。该刊偏好"理论框架+完整案例+评价体系全须全尾型"（references/01）；V2.0 已补理论帽，但案例/评价体系仍弱。郭雅洁[2]同主题已发于该刊 2025(11)，说明该刊对此方向有接收先例。**栏目建议投"教学设计"或"实验研究"类，投稿信说明与郭雅洁[2]、王贤灿[5]的增量关系。投稿前务必通读该刊近 6 期同栏目文章对齐体例。**
- **备选**（按匹配度降序）：《物理教学》（偏好小切口深挖、数字化/DIS，本文 3.1 节光电门测速模型辨析够深可裁出单投，但全文偏长需精简）；《中学物理》（若降档）。

### 风险提示（按严重度降序）

1. **证据风险（最高，决定上限）**：案例/数据 2 分。即便图文齐全投稿，外审专家必追问"课堂证据在哪"。当前 V2.0 靠诚实标注（"功能验证≠课堂实测""未做量化成效结论"）规避了诚信风险，但**稿件档次被锁死在②**。冲①必须补实证。
2. **图未交付风险**：4 幅图全占位，无图的资源开发类稿件基本不可能过初审。
3. **工作区痕迹风险**：占位符/待核验清单若不清除即投，直接退稿。
4. **理论谱系风险（轻）**：双重编码/Mayer 归属瑕疵，应改级，熟悉 CTML 的外审会扣分。
