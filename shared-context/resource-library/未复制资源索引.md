## 使用方法

1. 本索引登记的所有资源**都在本机原位置**，未删除、未移动。
2. 需要时按绝对路径直接调取（打开文件或 cp 到工作区）。
3. 如果某类资源频繁需要，可考虑后续补充复制到项目资源库对应子目录。
4. 上传腾讯 ima 知识库时，本索引本身可以上传（作为"还有哪些资源在本机"的地图），但索引指向的实体文件按需上传。
