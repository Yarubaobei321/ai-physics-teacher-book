# 项目资源知识地图

> AI 进入项目资源库的第一站。这里按真实项目和证据组织，不按既有论文题目组织。

## 一、使用顺序

1. 在本页确定需要处理的真实项目。
2. 到 [PROJECT_INDEX.md](./PROJECT_INDEX.md) 核对所有权、状态和权威入口。
3. 到 [EVIDENCE_INDEX.md](./EVIDENCE_INDEX.md) 选择最多 5 份证据。
4. 按 [TASK_ROUTER.md](./TASK_ROUTER.md) 的顺序打开原件。
5. 研究问题和论文题目另行生成，不从旧稿或旧编号继承。

## 四、当前研究原则

- 论文02及其他现有成稿都视为端到端候选产物，不能作为“接近投稿”的状态依据。
- 论文方向可以重建、合并或放弃；真实项目、原始证据和作者裁决才是长期入口。
- 当前优先研究只用电脑内材料即可完成复核、重算、编码、对照或资源化的方向。
- 20个高考题交互模型因粗糙且未经作者人工审阅，退出活动论文清单；不得与质量较高的动量模型混为一组。
- 需要新增实验、课堂、问卷或访谈才能成立的方向，先标为后续项目。
- 原创性在系统文献碰撞前统一标为“未核验”，禁用“首次、填补空白”。
