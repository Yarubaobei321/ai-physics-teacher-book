# 任务路由

> 按任务选择项目和证据，不按旧论文代号加载材料。每轮默认最多选择3个项目、每个项目最多5份关键材料。

## 一、发现新的论文方向

读取顺序：

1. [KNOWLEDGE_MAP.md](./KNOWLEDGE_MAP.md)：选择真实项目。
2. [PROJECT_INDEX.md](./PROJECT_INDEX.md)：核对所有权、当前状态和权威入口。
3. [EVIDENCE_INDEX.md](./EVIDENCE_INDEX.md)：判断证据层和禁说项。
4. [CLAIMS.md](./CLAIMS.md)：查看尚未确认的研究假设和重复风险。
5. 进入 `physics-education-research-workflow` 的策划阶段，先定问题和证据上限，再决定是否读取旧稿。

旧论文完整稿默认排除。只有任务明确要求诊断、比较或追溯某个旧版本时才打开。

## 二、学生与AI共制物理作品

适用：过程—成品错位、物理核验、需求表达、跨模型错误、评价方法。

1. `物理论文/论文02-学生AI协作评价/README.md`
2. `研究数据/00-数据口径与复算说明.md`
3. `研究数据/02-主张证据矩阵.md`
4. 按问题选择2—4个脱敏案例或同题跨模型成品
5. `文献调研/横纵分析.md`，再按需进入统一文献库

状态规则：

- 论文02当前是**待用本流程重构的端到端产物**，不标记“接近投稿”。
- 25份数据线、四案例线和独立方法线分别登记，不自动合并。
- 旧30份和77份八学科审阅集不进入25份物理样本口径。

## 三、动量守恒交互模型

适用：作者决定审查6个质量较高的动量模型，或判断其论文、书稿与教学资源用途。

1. `/Users/yaril/个人文档/数智育才网站/AGENTS.md`
2. `/Users/yaril/个人文档/数智育才网站/public/simulations/momentum/`中的文件清单
3. 每次只点名1—2个模型，回查其题意、实现文件和配套GIF
4. 独立核对假设、守恒条件、极限情况、数值与动画一致性
5. 人工审阅记录确认后，再决定是否进入论文项目卡或书稿素材卡

20个高考题交互模型已被作者排除出活动论文路由。除非作者以后明确要求做质量修复，否则不要读取其源码、生成研究方向或与动量模型混合评价。

## 四、浏览器DIS或ESP32Blockly

适用：数据通道、平台架构、设备编排、可靠性和物理实验工具。

1. 对应源项目的 `AGENTS.md` 和 `README.md`
2. 点名协议、设备台账或实验模式文档
3. 点名测试、日志或代码文件
4. 资源库截图和历史总览只作辅助
5. 对应文献卡片和全文

当前边界：不新增光电门实测；不把软件测试写成整班真机实施或测量精度证据。

## 五、教师与AI共同开发资源

适用：需求表达、学科约束、验收、版本修正、继续教育课程。

1. [教师AI协作开发-项目卡片.md](./教师AI协作开发-项目卡片.md)
2. [继续教育课程设计-项目卡片.md](./继续教育课程设计-项目卡片.md)
3. 点名项目的需求、规则、验收清单和Git记录
4. 选择2—4个能显示错误、修正或边界的原始案例
5. 教师发展与AI资源开发文献卡片；按需读全文

只能写个人案例、设计方法或任务内错误治理。没有其他教师实施材料时，不写培训效果和普遍迁移。

## 六、课程与本地资料治理

适用：初高中衔接双版本、题目—知识点追溯、保守结构化、人审门禁。

1. 对应项目 `AGENTS.md` 或 `README.md`
2. 质量报告
3. 索引、来源哈希或人工复核入口
4. 仅打开点名的2—4个代表性转换案例
5. 需要比较时再进入相关课程或资料治理文献

版权规则：商业教辅正文不批量注入模型，不在论文或公开附件中重现题库。

## 七、图书写作

1. `docs/WORK_HANDOFF.md`
2. 读者版V2总纲及点名章节
3. 本入口的项目卡和证据索引
4. 只打开该章需要的项目原件
5. 核对作者贡献、图片授权和学生隐私

旧20章稿只作采石场；重构版只作事实/授权台账。旧“八篇论文到十八章”映射不再作为当前路由。

## 八、文献研究

1. 先读本篇已有 `文献调研/横纵分析.md` 或统一主库的文献卡片。
2. 需要概念、数字、引文和局限时再读同单元全文。
3. 正式引用回查PDF首页、页码、表图和原句。
4. 新颖性、撞车和“首次”必须另做可复现检索；卡片或AI调查不能证明原创性。

## 九、通用上下文锁

```yaml

excluded_sources: []

```
