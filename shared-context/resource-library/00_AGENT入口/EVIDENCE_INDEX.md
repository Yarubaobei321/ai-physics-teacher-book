# 证据索引

> 本页只回答“有什么材料、能支持到哪里、读取时有什么限制”。项目完成、网页可运行或文件很多，都不自动等于研究证据充分。

## 一、状态词

- **已核原件**：已打开一手文件或经过独立复算，可用于当前有限主张。
- **可复核**：原件存在，尚需按本轮问题重新检查。
- **历史快照**：只说明过去状态，不能覆盖当前源项目。
- **待补或缺失**：当前没有匹配证据。
- **受限**：涉及隐私、版权、署名或安全配置，只能定向读取。

## 三、当前最适合电脑内补强的证据动作

1. **静态核查**：回查公式、参数、边界条件、代码实现和题目原意。
2. **可重复运行**：在本机对网页、测试、导出和模型状态进行同口径复核。
3. **内容编码**：对脱敏对话、需求、错误、修正、反馈或版本记录建立明确编码规则。
4. **同题对照**：比较同一物理任务在不同模型、不同版本或过程/成品之间的差异。
5. **追溯性检查**：核对题目—模型—代码—界面—结论、原件—转换—人工复核之间是否可回溯。

这些动作可以形成新分析，但结果仍需作者理解、复核并确认后才能进入论文。

## 四、隐私、版权与署名

- 学生材料默认只使用P01—P25等脱敏编号；姓名映射不进入研究上下文。
- 77份八学科审阅页目前只限本地，不能与25份物理研究样本混数。
- 商业教辅原件、批量转换正文和题图不对外分发；论文只呈现方法、统计和少量经授权示例。
- 设备MAC、WiFi、服务器配置、部署密钥和本地访问记录不进入论文材料。
- 他人课件、装置、学生作品和图片必须登记原作者与授权，不作为本人独立成果。
