# 课程优化 v4

本文件夹是对 v3 课程材料的优化重制，与 `课程设计/` 下原 v3 文件**并列**，互不覆盖。v3 全部保留。

## 优化背景

第一轮优化（见同目录 `录课操作清单.md`）发现了若干问题：现有逐字稿有两处与 ZCode 官方文档不一致的快捷键；界面操作步骤写得不够细，录课时不好跟做；部分段落臃肿。本轮在操作清单基础上，把逐字稿和 PPT 一并重制。

## 课时风格分级（重要）

不是所有课时都"工具化"——按内容性质分级：

| 课时 | 风格 | 说明 |
|:--:|:--|:--|
| 第 1 课时（问题聚焦） | **保持原叙事风格** | WHY 价值观建立，重在感染力和故事感，不工具化；仅做必要的事实订正 |
| 第 2 课时（筑基） | **工具手册风格** | 操作最密集，强化"点哪、按什么键、出现什么算对"的可复制性 |
| 第 3 课时（实战） | **工具手册风格** | 全程开发实录，提示词和操作步骤为主线 |
| 第 4 课时（发布闭环） | **工具手册风格** | 部署/反馈/迁移的操作步骤为主线 |

> ✅ **四课时已全部完成**（含逐字稿 + 图文版 PPT + 对抗性审查自检）。每课时均经过对抗性审查流程：写完 → 用 Agent 审查找漏洞 → 据反馈修复 → 复核。

## v4 逐字稿相对 v3 的主要改动

### 第一轮（v4.0）

1. **修正错误快捷键**（与 ZCode 官方文档核实一致）
   - 文件管理器 `Cmd/Ctrl+Shift+E` → **侧栏 `Cmd/Ctrl+B`**
2. **补充 ZCode 官方确认的界面认知**：左侧栏三区块、官方快捷键、模型选择器与档位、登录三种方式
3. **强化操作可复制性**：每个关键操作前加 **【操作】** 标注；提示词全部代码块
4. **精简臃肿**：压缩开场回顾、合并辅助工具讲解
5. **融入"三 Agent 循环"真实案例**

### 第二轮（v4.1，依据官方文档 zcode.z.ai/cn/docs 全面核对）

> ⚠ 本轮纠正了 v4.0 的一处重要错误：**`Shift+Tab` 之前被我误删**。官方键盘快捷键文档**明确确认** `Shift+Tab` 可切换执行模式（输入框聚焦时）——已恢复并讲准四档名称。

1. **界面认知改为 ADE 式布局**：ZCode 是"对话驱动的 Agent 工作台"，**不是传统 IDE 的"左文件树+中编辑器+右聊天"三栏**。核心是中间对话工作区，输入框在底部，右侧按需弹面板。重画了 PPT 第6页布局图。
2. **恢复 `Shift+Tab`** + 补齐执行模式四档官方名称：变更前确认 / 自动编辑 / 计划模式 / 完全访问。
3. **新增"目标模式（Goal）"+ 案例**：可设定可校验的会话目标，AI 自己对照目标收尾。
4. **新增输入框符号系统** `@文件 /命令 $技能 #会话`、命令中心 `Ctrl+K`、推理强度 `Ctrl+T`。
5. **"Zread"订正为官方名称"仓库 Wiki"**；补免费额度数据（新用户 5 天、每日 500 万 Token）。
6. **嵌入官方截图**；**修复 PPT 堆叠现象**（逐页核算内容高度上限 5.05）。

### 第三轮（v4.2，融入"两个神级 Prompt" + 补充官方截图）

1. **新增"两个神级 Prompt"方法论**（贯穿全课的基础）：
   - **第一性原理**（管生成/找根因）——Prompt 后加"从第一性原理出发"，强制 AI 回到本质重新推导。逐字稿新增小节 + PPT P18。
   - **对抗性审查**（管验证/找漏洞）——让 AI 扮演恶意测试工程师找边界漏洞。逐字稿新增小节 + PPT P18/P19，附可复制的对抗审查 Prompt（用单摆页作对象）。
2. **新增 4 类官方截图**：执行模式四档菜单（P13）、目标模式总览（P14）、编辑历史（P11）、命令中心 Command（P11）。
3. **新增 2 页 PPT**：P18 两个神级 Prompt 总览、P19 对抗性审查案例。
4. **修复模型选择器截图过小**：P8 图片放大到 5.2 宽。
5. **做了两个版本**：图文详细版（含官方截图，适合回看自学）、实时演示版（精简画面靠现场操作，适合录制）。

### 第四轮（v4.2.1，对抗性审查自检修复）

> 用"对抗性审查"方法论审查自身内容，发现并修复了 12 个 🔴 致命问题：

1. **系统性页码错位**（最严重）：逐字稿曾按 28 页引用 PPT，实际只有 26 页。已全部对齐到真实 26 页（经 Agent 复核通过）。
2. **时间重叠**：第1节标题、节六七、节四五时间重叠；神级 Prompt 小节仅 1.5 分钟超时。已重排时间线。
3. **案例对象错误**：目标模式案例、对抗审查 Prompt 曾引用下一课时的 standing-wave.html（本课时尚不存在），已改为用本课时生成的单摆页。
4. **术语未定义**：Vibe Coding、MCP 首次出现处补了定义。
5. **目标模式入口模糊**：补充了更明确的位置描述（输入框上方的目标/Goal 控件）。
6. **脚手架获取前置步骤**：工装段开头补了"请先从课程资料下载并解压"的提示。

## 生成 PPT

```bash
cd "课程设计/课程优化v4"
npm install pptxgenjs          # 仅首次
node "build_pptx_第1课时.js"   # 第1课时
node "build_pptx_第2课时.js" full   # 第2课时图文版
node "build_pptx_第3课时.js"   # 第3课时
node "build_pptx_第4课时.js"   # 第4课时
```
