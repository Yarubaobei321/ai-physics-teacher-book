## 一、开场：最后一公里（00:00–02:00）

> **【画面：PPT第1页（封面），切第2页（发布三级阶梯总览）。】**

　　上一课时，我们一起做出了一个能用的驻波教学网页。但做出来，只完成了一半——它现在还躺在你的电脑里。这节课，我们解决"最后一公里"的三件事：**交付到学生手上、回收学情数据、迁移到下一个作品**。发布、反馈、迁移——合起来就是一个完整的**闭环**。

　　这节课操作比较多，建议边看边跟着做。涉及账号、价格等时效信息，我会随时提醒。

## 二、第1节 部署三级阶梯 + 合规要点（02:00–17:00）

> **【画面：切PPT第3页（部署三级阶梯总览）。】**

　　先说交付。我给大家三个台阶，从低到高，你按自己的情况选。

### （一）第一级：本地直用（02:00–04:00）

> **【画面：切PPT第3页第一级（本地直用）。】**

> **【操作】演示：把 standing-wave.html 拷到桌面或另一个文件夹 → 双击打开。】**

　　第一级，零成本零门槛。驻波页是单文件 HTML，不依赖外网，拷过去双击就能用。**没有网络也能上课**——这是单文件网页最大的好处。局限是版本容易乱，你改了一版、U盘里还是旧版。

> **◆ 台词**："够用，但只能你自己用、或拷给个别学生。"

### （二）第二级：校园网共享（04:00–06:00）

> **【画面：切PPT第3页第二级（校园网共享）。】**

　　第二级，放学校内网。三种做法：放学校内网服务器、放教师机的共享目录、或放学校资源平台。固定一个地址，校园网内学生用平板/手机直接访问。好处是**资源集中、能沉淀复用**。

> **【操作】PPT 讲示意图即可（不放真机，各校网络环境不同）。】**

> **◆ 台词**："找信息中心的老师帮个忙，通常十分钟搞定。这是我们最推荐的起步方式。"

> **◆ 合规定性（重要）**："这里有个关键结论先记住——**只有'公网部署'（公网 IP/域名、面向互联网任何人）才必须做 ICP + 公安备案；本地直用、校园网内网共享，都属校内教学，不强制备案。** 校园内网不是公众网，所以不用备案——别和公网搞混了。"

### （三）第三级：公网部署（06:00–12:00）

> **【画面：切PPT第3页第三级（公网部署）+ 第4页（云服务器购买要点）。】**

　　第三级，公网部署——让学生在校外、用流量也能访问。这一级稍微复杂，但跟着做也拆解得很清楚。

#### ① 买"轻量应用服务器"

> **【操作】打开阿里云或腾讯云官网（阿里云 aliyun.com、腾讯云 cloud.tencent.com），**先完成账号实名认证**（个人需身份证+人脸），然后进入"轻量应用服务器"购买页（阿里云可在搜索框直接搜"轻量应用服务器"，或访问 swas.console.aliyun.com；腾讯云搜 Lighthouse）。指出关键选项：】**
> - **地域**：选**深圳或广州**（离学生近、访问快、境内合规）
> - **配置**：最低档即可（静态网页几乎不吃资源，一年约一两百元）
> - **镜像**：选**宝塔面板**镜像（图形化管理，最适合零基础，省得敲命令行配环境）

> **【画面：购买过程敏感信息打码、支付快进；价格等时效信息片头注明录制日期。】**

> **◆ 踩坑分享**："我最早图省事建在境外节点，访问又慢又不稳，最后迁回境内。境内服务器 + 规范备案才是正道。这门课直接教大家走正道，不要重复我的弯路。"

#### ② 放行 80 端口（不这步会一直打不开）

> **【操作】服务器买好后，进入控制台 → 找到这台服务器的"防火墙/安全组" → 添加规则放行 **80 端口（HTTP）**。⚠ 这一步极易漏掉：云厂商默认不放行 80，不添加规则浏览器会一直转圈打不开。】**

#### ③ 上传文件 + IP 访问（本课时高光）

> **【操作】控制台展示服务器 IP 地址。打开宝塔面板（用控制台给的宝塔登录地址），左侧"文件"→进到网站根目录 `/www/wwwroot/默认站点/`（或宝塔里添加站点后的目录）→ 上传 standing-wave.html 到这个根目录。】**

> **【操作】浏览器新标签输入 `http://你的IP地址/standing-wave.html` → 回车 → 页面打开成功。（⚠ 文件必须传到 Web 根目录；若传到子目录，URL 要相应加路径，如 `http://IP/site/standing-wave.html`）】**

> **【操作】手机连流量，在手机浏览器地址栏输入 `http://IP地址/standing-wave.html` 验证 → 通了。（可选：用浏览器插件把 URL 生成二维码，手机扫码更方便）】**

> **🎬 此段放慢、完整展示，是本课时的高光；手机端建议投屏增强说服力。**

### （四）合规四件事（12:00–17:00）

> **【画面：切PPT第5页（合规四件事）。】**

　　公网部署，合规必须跟上。四件事，记一下：

| 事项 | 要点 |
|---|---|
| **ICP 备案** | 买域名 → 提交材料 → 管局审核 3–20 个工作日（多数 2–4 周，建议预留 4 周）。全程线上、不收费。**提前规划** |
| **公安备案** | ICP 备案、网站开通后 **30 日内**必须办，线上办理（全国互联网安全管理服务平台 beian.mps.gov.cn） |
| **版权** | 引用的图片/素材标来源；**优先用 CC0/免版权素材**（如 Pexels、Unsplash）；**中文字体用思源黑体等开源字体**，避免微软雅黑等商用字体 |
| **学生信息** | **不收集姓名学号等个人信息，数据最小化——能不收就不收**；成绩摘要只含题号不含姓名，发群前提醒学生不附身份信息 |

> **【画面：切PPT第6页（备案流程示意图）。】**

> **◆ 底线台词**："备案周期约 2–3 周，所以公网部署要提前规划；买域名、ICP 备案、公安备案，全程线上、不收费。我最想强调的是最后一条——**不收集学生个人信息，数据最小化，能不收就不收**。这是底线。"

## 三、第2节 学情反馈闭环（17:00–28:00）

> **【画面：切PPT第7页（闭环模型：开发→使用→反馈→迭代）。】**

　　资源发出去了，还差一件事——回收数据。**好资源不是一次做出来的，是用出来、改出来的。**

### （一）闭环模型

　　完整的闭环是这样：**教师开发 → 学生使用 → 数据反馈 → 资源迭代**，循环往复。怎么回收数据？我给大家一个轻量方案，人人能用。

### （二）轻量方案：成绩摘要 + 问卷（17:00–23:00）

> **【画面：切PPT第8页（轻量方案：成绩摘要+问卷）。】**

> **【操作】演示驻波页：做完习题后，页面底部自动生成一行成绩摘要（得分+错题号）→ 学生截图发班级群。展示页面底部嵌入的问卷入口（问卷星/腾讯问卷）。】**

　　这套方案分两步：第一，让页面自动生成"成绩摘要"，学生做完一截图就能发群里；第二，页面底部嵌一个问卷入口。两步加起来，你就能知道**哪些题错得多、学生卡在哪**。

> **【操作】展示"成绩摘要功能本身也是一句提示词加的"。在 ZCode 输入框粘贴下面这条提示词，回车。】**

#### ▶ 提示词：成绩摘要功能（驻波页）

```
请在习题区增加一个功能：当学生提交全部5道题后，在习题区底部自动显示
一行成绩摘要，格式为"本次练习：答对X题/共5题，错题：第N题"，
并提供"复制成绩"按钮方便学生截图或粘贴到班级群。
不要收集或上传任何个人信息，其他部分不要改动。
```

> **◆ 台词**："看，方法是一以贯之的——说清要什么、给格式、加约束（不收集个人信息）、强调'其他不要改动'。这就是第二课时讲的提示词四要素。"

### （三）进阶方案：微信生态（23:00–28:00）

> **【画面：PPT第8页下半部分（进阶·微信生态示意）。】**

　　想做得更深，还有进阶方案——公众号推送（扫码即学、零安装）+ 小程序收集答题数据。这一套门槛高些，但也能靠 AI 协作完成，是市级重点课题的方向。

> **【画面：展示课题阶段成果示意图。】**

> **◆ 真实闭环案例**："机械能守恒页那道'误差分析'题错误率最高，我让 AI 加了一句引导提示，推了第二版，错误率就降下来了。**好资源是用出来、改出来的。** 不知道这些，资源就是'死'的，做完放着；知道了，资源才会'生长'。"

## 四、第3节 迁移选题：三问选题法（28:00–35:00）

> **【画面：切PPT第9页（三问选题法）。】**

　　做完驻波页，下一个做什么？我给大家一个选题工具——**三问选题法**。这三个问题，帮你从根上想清楚：这个教学痛点，到底值不值得做成交互网页。

　　**第一问：是不是"实物难呈现、静态图讲不清"，学生最容易错、最难想象的点？**

　　**第二问：现有资源为什么解决不了？是不是非得交互网页？**

　　**第三问：做成后学生怎么用？课上演示、课后自测、单人还是协作？**

> **◆ 台词**："这三问，**占一个就值得做，全占了就赶紧做**。"

### （一）跨学科迁移演示（30:00–34:00）

> **【画面：切PPT第10页（跨学科迁移·英语不规则动词闯关）。】**

　　方法不绑定物理。我用英语学科演示一下——同样的框架，换个需求描述，做出一个英语练习页。

> **【操作】切到 ZCode → 新建一个任务/对话 → 在输入框粘贴下面这条提示词，回车。快进生成。内置浏览器预览英语页 30 秒。快速过一关演示。】**

#### ▶ 提示词：跨学科迁移（英语·不规则动词闯关）

```
你是一名熟悉初中英语教学的前端工程师。请制作一个单页HTML练习网页
"不规则动词闯关自测"，面向初二学生，在手机和平板浏览器上使用。要求：
1. 内置30个常考不规则动词（原形–过去式–过去分词）；
2. 闯关形式：每关10题，随机抽取，输入答案即时判定，
   答错显示正确答案；
3. 完成一关显示得分与用时，并提供"复制成绩"按钮；
4. 全部代码放在一个HTML文件中，不依赖外网资源；
5. 界面活泼但配色清爽。
```

> **◆ 台词**："换学科，换的只是那段需求描述。物理、英语、化学、生物、数学，每一位老师都能用。这就是我说'方法可平移'的意思。"

### （二）物理延伸（34:00–35:00）

> **◆ 台词**："物理这边呢，驻波是一维干涉，下一步可以扩展到二维——水波双源干涉，加强区、减弱区的图样，同一个框架追加需求就行。**一个选题做透了，自然会长出下一个选题。这就是可持续产出的能力。**"

## 五、课程总结与作业四（35:00–40:00）

### （一）全课回顾

> **【画面：切PPT第11页（全课程回顾导图：WHY→WHAT→HOW→DO）。】**

　　最后，把四课时串起来回顾一遍：

　　**第1课时（为什么）**：校本资源建设的主体只能是教师，AI 拆掉了技术的墙。

　　**第2课时（是什么）**：装好 ZCode、认清 ADE 界面、学会提示词四要素、用一道漏沙题看清工具差距、认识技能与工程化协作。

　　**第3课时（怎么做）**：从头做一个驻波教学网页，报错时给证据找根因、教师验物理、上线前对抗性审查。

　　**第4课时（用起来·今天）**：发布给学生、回收数据、迁移到自己的学科。

　　四节课，一条主线：**AI 写代码，教师提需求、做验收**。而其中最关键的一跳，是第2课时讲的"技能"——把你的经验沉淀成可复用的标准流程，**提示词决定这一次，技能决定每一次**。

### （二）作业四（收官作业）

> **【画面：切PPT第12页（作业四）。】**

　　**作业四是收官作业**：把你结业的作品真正发布出去——三级台阶任选其一（本地直用也行），配一种反馈方式（成绩摘要或问卷）。

　　提交：**一个可访问的链接，或一段部署录屏，再加一句话说明你用的反馈方式**。

> **◆ 收尾承诺**："优秀作品经同意后，会被收录到数智育才网站的学员作品栏目，并推荐给学校作为校本资源。"

### （三）结束语

> **【画面：切PPT第13页（结束语金句），停留10秒后停录。】**

　　最后，用一句话结束这门课：

　　**这门课分享的不是技术，是一种可能性：最懂学生的人，从此有能力亲手为学生打造资源。知识来源于你，格式交给 AI。**

　　我是黄老师，我们在作品里相见。
