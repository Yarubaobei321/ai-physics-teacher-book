## 一、使用说明

- 按"课时 → 操作点"顺序走，每个操作点都标了对应的逐字稿时间戳，方便对照台词。

## 三、第 1 课时 操作点（网站演示 + PPT）

> 本课时几乎无 ZCode 操作，核心是浏览器演示网站 + PPT 讲解。对应逐字稿 11:30–25:30。

### 操作点 1-1：打开网站首页　对应 11:30

- **【操作】** 浏览器地址栏输入 `shuzhiyucai.cn` 回车；全屏打开首页。
- **【操作】** 鼠标依次划过导航栏四个栏目：在线编程、网页版DIS、在线实验室、模拟实验室。

### 操作点 1-2：在线实验室 → 落体法页面　对应 12:30

- **【操作】** 点击"在线实验室" → 点击"落体法验证机械能守恒"。
- **【操作】** 从页首缓慢滚动到页尾，在以下区域停顿并配合台词：
  - 实验目的/原理区（示意图+公式）
  - 器材与步骤区
  - 数据记录表（强调：平板蓝牙连 ESP32 光电门，数据实时进表）

- **🎬** 守恒量面板（总动量/总能量数值）给特写，台词强调"这个数几乎不变"。
- **◆ 备用话术**：若该题解析不完整，提前换一道解析完整的题演示。

### 操作点 1-4：模拟实验室 → 小球曲面小车　对应 16:00

- **【操作】** 快速切到"悬挂圆环摆""小球与小环"等模型各看 5 秒。

### 操作点 1-5：学生作品评审报告　对应 18:30

### ⚠ 关于漏沙题的物理（务必讲对）

匀加速运动时空中沙粒排成的是**斜直线**（斜率 −g/a），**不是抛物线**——单颗沙子的运动轨迹才是抛物线。这是高考常见易错点。ZCode 实测做对了（斜直线），DeepSeek 说明文字写成了抛物线（错）。录制时务必按此讲，PPT 第17页也已据此订正。

## 五、第 3 课时 操作点（驻波实战）

> 本课时是全课核心，全程不间断开发。对应逐字稿 02:00–38:30。**建议预演一遍再正式录制。**

### 操作点 3-1：发 PRD 需求文档　对应 02:00

- **【操作】** 在 ZCode 打开"教学网页脚手架"项目 → AI 对话区粘贴以下提示词 → 回车。

**▶ P4 驻波 PRD 需求文档**

```
我是高中物理教师，准备开发《波的叠加与驻波》教学网页，面向高二学生，
在平板浏览器上使用。请先不要写代码，以产品经理身份输出一份需求文档，
内容包括：

1. 页面结构（原理讲解区、交互模拟区、读图练习区、配套习题区）；
2. 交互模拟的可调参数与显示要素：两列相向传播的等幅同频波，
   两列分波与合成波可分别显示或隐藏，支持暂停与逐帧播放，
   波节与波腹位置自动标注，频率与振幅滑块可调；
3. 读图练习区：给出一幅驻波图样，让学生读出波长和相邻波节间距；
4. 习题类型与数量：4–6道分层习题，必须包含针对"波节处没有波通过"
   这一误区的辨析题；
5. 平板适配要点。

请用表格呈现需求文档，等我确认后再进入开发。
```

- **【操作】** 等待 AI 输出 PRD 表格（可快进）→ 滚动展示 → 鼠标停在"显示要素"行 → 现场口头补充 → 回复确认。
- **◆ 预期**：AI 输出含页面结构、参数、习题规划的表格。
- **◆ 回复 AI**（确认+补充）：

```
确认需求，补充一点：合成波用粗实线，两列分波用不同颜色的细虚线。请开始开发，先输出页面骨架和原理讲解区。
```

### 操作点 3-4：交互模拟区开发　对应 17:00

**▶ P6 交互模拟区**

```
现在开发交互模拟区。要求：

1. 用canvas绘制：上方并排显示两列相向传播的等幅同频简谐波
  （红色细虚线向右传播、蓝色细虚线向左传播），
   下方显示它们的合成波（深色粗实线）；
2. 提供"显示/隐藏分波""显示/隐藏合成波"开关；
3. 提供"播放/暂停"按钮和"逐帧前进"按钮，逐帧步长为周期的1/16；
4. 合成波上自动标注波节（▽符号）和波腹（△符号）位置，
```

### B. 提示词四要素·速记卡

| 要素                 | 要写什么                       | 例子                                                                     |
| :------------------- | :----------------------------- | :----------------------------------------------------------------------- |
| **角色与背景** | AI 是谁、我是谁、给谁用        | "你是熟悉高中物理教学的前端工程师，我是高中物理教师，面向高一学生平板用" |

### C. 迭代三习惯·速记卡

1. **小步走**：一次只提一个修改点。
2. **先确认**：大改动让 AI 先复述方案再动手。
3. **给证据**：截图或报错原文直接喂，不要只说"不对，重做"。
   - 末尾永远加一句"**其他部分不要改动**"。

### D. 教学彩蛋：三 Agent 循环（讲"循环"概念时的真实案例）

> 用在**第 2 课时讲完技能、进入"循环/钩子"时**（逐字稿 §四(五)），或第 3 课时报错修复后点题"这就是循环"时。一段话即可，不喧宾夺主。

**可引用的真实故事（来自 Anthropic 工程师 2026 年公开演示）：**

> 2026 年 6 月，Anthropic（Claude 背后的公司）的工程师公开演示了怎么用 AI 从零做一个完整 App：他们用了**三个角色循环**——一个 **Planner（规划者）** 把模糊想法翻译成规格书，一个 **Generator（构建者）** 写代码，一个 **Evaluator（评判者）** 像真人一样打开浏览器点界面、测功能、打分，不通过就退回让构建者改，循环直到真正能用。同样的模型，单 agent 跑 20 分钟做出来的是半成品；三角色循环跑 6 小时，做出来的是能玩、能测的完整成品。

**一句收束（呼应课程主线）：**

> "赢家不会拥有最聪明的模型，会拥有最好的循环。"——这正是我们这节课讲的"提示词→工装→循环→钩子"那条线的方向：不是某一句提示词多聪明，而是你给 AI 搭的整套工作环境（规则、技能、模板、验收、版本管理）让智能体稳定地转起来。咱们今天学的"先复述需求、小步迭代、给证据修复、三查验收"，就是这个循环的最简版本。

**给黄老师的话**：这个故事能帮学员把"循环"从一个抽象词，变成"哦，连 Anthropic 都这么干"的真实认知，讲起来更有底气。
