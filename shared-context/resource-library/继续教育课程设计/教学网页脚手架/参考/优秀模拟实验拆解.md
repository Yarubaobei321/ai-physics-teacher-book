# 优秀模拟实验拆解（动量章节为例）

> 把"数智育才"网站 6 个动量模拟实验拆开看，提炼出可复用的套路。
> 这份文档既是教师的"抄作业"参考，也可作为上下文喂给 AI，让它"照着好作品的结构来做"。

## 一、六个模型一览

| 模型 | 物理情境 | 核心规律 |
|---|---|---|
| 小球与小环 | 轻绳连小球与套在光滑水平杆上的小环 | 水平动量守恒 + 机械能守恒 |
| 半圆槽小球 | 小球在光滑半圆槽内滑动，槽可动 | 动量守恒 + 机械能守恒 |
| 曲面小车 | 小球冲上/滑下可动曲面小车 | 动量守恒 + 能量转化 |
| 弹簧连接小球-木块 | 弹簧连接两体的接触与分离 | 动量守恒 + 弹性势能 |
| 悬挂圆环摆 | 悬挂圆环的类摆运动 | 机械能守恒 |
| 曲面滑块 | 滑块在曲面轨道上的运动 | 动量与能量 |

## 二、共通的"教学化结构"（这才是关键）

好的模拟实验不只是"会动"，它的价值在于这套结构：

1. **一句话情境** + 点明用到的物理规律。
2. **动态模拟** + **守恒量实时面板**：把抽象的"守恒"变成屏幕上一直不变的数字。
3. **原理分点说明**：回答"为什么会动""为什么质心不动""能量怎么转化"这类追问。
4. **引导性观察任务**：例如——
   - "改变初始角度，观察小球能否摆到另一侧同样高度。"
   - "打开速度方向，观察小环和小球的水平速度方向是否总相反。"
   - "比较 v-t 图中分速度与合速度，最低点时合速度是否最大？"
5. **误区辨析**：一句话点破，例如——
   - "'水平总动量守恒'不等于每个物体动量不变；它们互相拉动、速度一直在变，只是相加始终为零。"
6. **扩展思考**：留口子，例如——
   - "如果小环质量是小球两倍，质心线还在正中间吗？可作下一版扩展。"

## 三、共通的"技术套路"
- 单文件 HTML；**SVG** 画图（非 canvas）；`requestAnimationFrame` 主循环 + 每帧多 **substeps** 积分保精度。
- 守恒量面板既做教学展示，又当**科学性自检**：守恒量漂移 = 有 bug。
- KaTeX 写公式；育才蓝设计令牌统一视觉；aria/focus-ring/44px 触控做无障碍与平板适配。

## 四、给教师的迁移提示
做新课题时，先回答"我的模拟要让学生观察到什么、辨析掉哪个误区"，再套上面的结构和技术配方。把本文件连同《物理交互模拟》Skill 一起喂给 AI，产出质量会明显更接近成熟作品。
