# 育才设计令牌（Design Tokens）

> 从"数智育才"网站真实模拟实验页提炼的视觉规范。把它放进项目，让所有教学网页风格统一、专业克制。
> 用法：在提示词里说"套用《育才设计令牌》"，或直接把下面的 `:root` 变量贴进页面。

## 一、配色（CSS 变量，可直接复制）

```css
:root{
  color-scheme: light;
  --yucai-blue: #0b63c7;   /* 主色·育才蓝 */
  --yucai-50:  #eef7ff;
  --yucai-100: #d8ecff;
  --yucai-200: #b7dcff;
  --yucai-700: #074f9f;
  --yucai-800: #0a437f;
  --yucai-900: #0d3969;
  --ink:   #102033;        /* 正文·墨蓝 */
  --lab:   #f5f8fb;        /* 背景·实验室浅灰 */
  --slate-200: #e2e8f0;    /* 分隔线 */
  --slate-500: #64748b;    /* 次要文字 */
  --signal:  #f4a51c;      /* 强调·信号橙（分量/重点） */
  --emerald: #059669;      /* 正确·绿 */
  --danger:  #b8442b;      /* 提醒/合量·红 */
  --surface: rgba(255,255,255,0.92);
  --shadow-soft: 0 18px 60px rgba(16,32,51,0.12);
  --font-sans: Inter, ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif;
}
```

## 二、用色约定（物理图示）
- 合成量 / 总量：红（--danger），常用粗实线。
- 分量：橙（--signal）或蓝，常用细虚线。
- "正确/守恒"提示：绿（--emerald）。
- 主色育才蓝用于标题、主按钮、强调边框。

## 三、版式与适配
- 容器：`width: min(1120px, calc(100% - 32px))` 居中。
- 字号：正文 ≥16px、line-height 1.5；课堂投影关键数值放大并加粗。
- 圆角与卡片：浅灰描边 + `--shadow-soft` 柔和阴影。
- 深浅色：设置 `theme-color`；`viewport-fit=cover` 适配全面屏平板。

## 四、无障碍
- 可聚焦元素加 focus-ring（`:focus-visible` 显示蓝色描边）。
- 交互区加 `aria-label`；触控目标 ≥44×44px。

## 五、关于离线
- 站内成熟页用 KaTeX 的 CDN 加载公式。**课堂联网**时沿用即可；**严格离线**（课程默认约束）时，请改为内联必要样式、或用 HTML `<sub>/<sup>` 表达简单公式，避免任何外网依赖。
