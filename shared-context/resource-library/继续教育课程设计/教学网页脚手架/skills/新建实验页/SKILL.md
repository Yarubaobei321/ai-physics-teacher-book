# Skill：新建一个教学实验页

> 把"从零起一个三段式教学网页"的流程固化。在 ZCode 中让 AI 照此执行。

## 触发场景
当我说"按本 Skill 新建一个【课题】实验页"时执行。

## 输入（我会提供）
- 课题、学段、使用设备
- 已填好的 PRD（《PRD-需求文档模板》）

## 执行步骤
1. 读取项目规则 `AGENTS.md`，确认视觉与技术约束。
2. 以 `index.html` 为骨架，按 PRD 复述需求，待我确认。
3. 分步实现（每步完成即可预览）：
   - 第一步：原理讲解区图文与公式排版。
   - 第二步：交互演示区（参数、动画、即时数值），逐项验收。
   - 第三步：调用《生成分层习题》Skill 填充习题区。
4. 全部完成后，对照《验收清单》自检并报告结果。
5. 提示我保存版本（Git 提交）。

## 约束
- 单文件、不依赖外网、平板优先（同 AGENTS.md）。
- 一次只做一步，做完一步等我确认再继续。

## 完成标准
- 《验收清单》三查全部通过，可直接在平板打开使用。
