# Skill：物理交互模拟实验页

> 这是从"数智育才"网站真实在用的 6 个动量模拟实验（小球与小环、半圆槽小球、曲面小车、弹簧连接、悬挂圆环、曲面滑块）中提炼出的"高级配方"。
> 它比基础三段式更进一步，专门用于做"实物难呈现、必须靠动态模拟"的物理实验页。在 ZCode 中让 AI（GLM-5.2）照此执行。

## 触发场景
当我说"按本 Skill 做一个【课题】的交互模拟实验页"时执行。

## 输入（我会提供）
- 课题与物理情境：____________
- 涉及的守恒量 / 规律：____________（如动量守恒、机械能守恒）
- 学生典型误区：____________

## 一、页面分区（教学化，固定）
1. **页头 + Hero**：标题、一句话情境说明（含使用的物理规律）。
2. **模拟区**：SVG 动画 + 控件 + **守恒量实时面板**。
3. **原理说明区**：用 KaTeX 写公式；分点讲"为什么会这样"。
4. **引导性观察任务**：3–5 条"请观察……"的任务，把学生从"看热闹"引到"看门道"。
5. **误区辨析**：用一句话点破典型误区（例："水平总动量守恒，不等于每个物体的动量不变"）。
6. **扩展思考**：留一个"下一版可以加什么"的开放问题。
7.（可选）习题区：调用《生成分层习题》Skill。

## 二、技术配方（关键，照此实现）
- **渲染用 SVG**，不用 canvas：物体、轨迹、矢量箭头用 `createElementNS` 动态生成，缩放清晰、易标注。
- **动画用 requestAnimationFrame 主循环**；物理积分**每帧分多个 substeps**（如每帧 8–16 小步）以保证数值精度，避免快放时穿模/漂移。
- **守恒量实时面板**：每帧计算并显示系统总动量、总动能、机械能等；这块既是教学亮点，**也是天然的科学性自检**——若守恒量明显漂移，说明物理或积分有问题。
- **公式用 KaTeX**：课堂联网可用 CDN；若要严格离线，改为内联字体与样式（见《育才设计令牌》说明）。
- **视觉**：套用《育才设计令牌》（育才蓝 #0b63c7 等）。
- **无障碍与适配**：关键交互区加 `aria-label`，可聚焦元素加 focus-ring；`viewport-fit=cover`，平板触屏滑块/按钮 ≥44px，深浅色 `theme-color`。

## 三、控件标配
- 参数滑块（range）：质量、初速、角度、绳长、劲度系数等。
- 按钮：播放/暂停、单步、重置、显示/隐藏（分量、矢量、辅助线）。

## 四、执行步骤
1. 读取 `AGENTS.md` 与 `参考/育才设计令牌.md`，确认视觉与技术约束。
2. 复述需求（分区 + 守恒量 + 误区），待我确认。
3. 分步实现，每步可预览：① SVG 场景与静态布局 → ② 物理 step(dt) 与 substeps 积分 → ③ 守恒量面板 → ④ 控件联动 → ⑤ 原理/观察任务/误区/扩展 文案。
4. 用守恒量面板＋"取特殊点核对"做科学性自检，对照《验收清单》报告。
5. 提示我用 Git 保存版本。

## 完成标准
- 守恒量在整个动画过程基本不漂移；观察任务能引导学生发现规律；误区辨析准确；平板可用。
