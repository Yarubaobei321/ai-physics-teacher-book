# Skill：部署上线（三级路径）

> 把"把网页发布出去"的流程固化。按需要选择一级执行。

## 触发场景
当我说"按本 Skill 把当前网页发布"时执行，并告诉你目标级别。

## 第一级 · 本地直用（零成本）
1. 确认是单文件 HTML、不依赖外网。
2. 复制到教室一体机 / 学生平板，双击打开即用。
3. 生成一段"如何分发与打开"的简短说明给学生。

## 第二级 · 校园网共享
1. 上传到校内服务器 / 教师机共享文件夹 / 学校资源平台。
2. 生成校园网内访问链接与二维码（不依赖外网的前提下用本地库生成）。

## 第三级 · 公网部署
1. 列出国内云厂商（阿里云 / 腾讯云）轻量应用服务器选购要点（配置、带宽、计费）。
2. 给出文件上传与通过 IP / 域名访问的分步操作清单。
3. 提醒：域名需 ICP 备案（周期约 2–3 周），选择**境内节点**兼顾合规与速度。
4. 合规自检：HTTPS、不收集学生隐私、素材版权标注、作品署名授权。

## 完成标准
- 目标级别下可正常访问；对照《验收清单》"合规与署名"一节通过。
