# Skill：生成分层习题

> 把"出一套分层习题"这件反复要做的事，写成一份分步说明书。
> 在 ZCode 中让 AI 执行本 Skill，并把课题、知识点、误区作为输入。

## 触发场景
当我说"按本 Skill 为【某课题】生成一套分层习题"时执行。

## 输入（我会提供）
- 课题与知识点：____________
- 学生典型误区：____________
- 题量：基础 / 中等 / 挑战 各几题

## 执行步骤
1. 先复述：列出你将覆盖的知识点与误区，待我确认。
2. 按三档生成：
   - **基础**：直接套用概念 / 公式，考查记忆与识别。
   - **中等**：需两步推理或多概念结合。
   - **挑战 / 误区辨析**：直接针对我给出的学生误区设计判断或说理题。
3. 每题给出：题干、正确答案、**详解**（说清为什么对、错选项错在哪）。
4. 习题以可折叠详解的 HTML 片段输出，嵌入页面"配套习题区"。
5. 自检：答案是否科学正确？误区题是否真的击中误区？不确定处标注"请教师核对"。

## 输出格式
- 与 `index.html` 的 `#quiz` 区结构一致（`.quiz-item` + `<details>`）。

## 完成标准
- 对照《验收清单》"科学正确性"一节逐条通过。
