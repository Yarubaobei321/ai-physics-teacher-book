# 项目记忆

## 工作偏好

- **禁止并行处理**：由于网络不稳定，所有任务必须串行执行——完成一个课时，输出结果，再开始下一个。不要同时启动多个子代理。
- **优先使用更好工具**：只要电脑空间足够、工具能运行，就优先安装和使用更高效、更稳定的工具链；不要为了省事用现有低效工具硬做。安装前说明影响、回滚方法，并在需要联网或写入用户级目录时主动请求批准。
- **视频后期工作流**：课程视频字幕、独立字幕栏、章节进度条和 FFmpeg/libass 工具链见 `docs/video-postproduction-workflow.md`。后续课时优先复用该文档和 `scripts/add_subtitle_panel_chapter_bar.py`，先做短样验证，再跑全片；`scripts/add_chapter_progress_bar.py` 只用于已有字幕且不遮挡画面的旧流程。
