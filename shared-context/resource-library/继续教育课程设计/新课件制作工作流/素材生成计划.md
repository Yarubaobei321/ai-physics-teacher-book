## 生成规则

1. 严格串行：一次只生成一张。
2. 每个小节先用 `baoyu-article-illustrator` 的方式列出配图位置，再决定是否真的生成。
3. 流程图、发布架构、闭环模型优先用 `baoyu-diagram` 生成 SVG，保证文字和结构可靠。
4. 封面、课堂场景、概念隐喻用 `baoyu-image-gen`，且固定走 Codex/GPT Image 2 权益。
5. 高密度信息图用 `baoyu-infographic`，但中文文字多时要谨慎，必要时改用 HTML/SVG 承载文字。
6. 先读 prompt，再生成图。
7. 图片里少放文字；长中文标签尽量由 HTML 课件承载。
8. 图生成后先人工看可读性，再进入课件替换。
9. 如果图中文字乱码，不修图，直接改 prompt 重新生成。
