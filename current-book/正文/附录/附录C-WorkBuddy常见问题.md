# 附录 C　WorkBuddy 常见问题

先看问题出在哪里：任务还没开始，查账号、模型和工作方式；回复完成了却没文件，查实际路径；网页能打开但连不上设备，查浏览器；网页要交给别人，看第四节。书中示范用的是 WorkBuddy 5.6.2 和 5.7.7，界面变了，按任务、模型、工作空间和产物这几个功能找对应入口。

## 一、开始之前

**选不到书中的模型，或者名称不一样。** 选一个可用的模型继续，记下名称。换了模型，结果可能不一样，按第 3 章和附录 B 检查后再用。

**它只给方案，不生成文件。** 看当前的工作方式：默认方式直接执行，Plan 先给方案、确认后再执行，Ask 以问答为主。本书这类目标清楚的小任务，用默认方式即可。

**弹出权限确认，要不要打开“完全访问”。** 先看具体动作和路径是否属于这次任务，只处理这一次请求；日常保持默认权限。工作空间是主要读写文件的目录，每个任务单独建文件夹，原件另存副本。WorkBuddy 调用的模型在云端，学生材料交给它之前要核对授权。

## 二、文件和修改

**回复里有一段代码，文件夹里却没有文件。** 继续说：“请把结果保存到当前工作空间的 output/index.html，并告诉我实际路径。”然后去文件夹确认。回复里的代码和电脑上保存的文件，是两个结果。

**说已保存，仍找不到。** 核对任务当前的工作空间，让它给出完整路径；右侧“产物”里可以打开文件所在的文件夹。双击后看到源码，先查扩展名是不是成了 `index.html.txt`。

**改了很多轮，前面定好的条件被改掉了。** 把定好的条件写进 `input/需求.md`（模型条件、参数范围、哪些地方不许动），新开一个任务，先请它读文件并复述条件，确认后再改。每次只提一个修改，改完用同一组输入检查原来对的地方有没有被改坏。

**想回到上一版。** 每当一版可用，就存一个有意义的副本，例如“版本记录/01-基础过程.html”。恢复时说明准确文件，先保留当前版，再恢复：“请把网页恢复到‘修改前’那一版；当前这一版先另存到‘恢复前’文件夹。”

**同一套做法想反复用。** 先把有效要求写进项目说明，下次明确请它读取；流程稳定后，再整理成技能文件 `SKILL.md`。技能里写的物理条件，下次用时要按新的模型重新核对。

## 三、网页与设备连接

| 设备与浏览器 | 打开方式 | 普通计算页、模拟页 | 连蓝牙或 USB 串口 |
| --- | --- | --- | --- |
| 电脑上的 Chrome 或 Edge | 双击单文件网页 | 能用 | 通常不行，改用下面两种方式 |
| 电脑上的 Chrome 或 Edge | 本机地址 `http://localhost:端口` | 能用；多文件网页用这种方式 | 能连接，由教师在浏览器弹出的窗口里选择设备 |
| 电脑上的 Chrome 或 Edge | 正式发布的 HTTPS 地址 | 能用 | 能连接；有的轻量发布方式不允许连设备，要发布成独立网页应用 |
| 平板、手机微信、iPad Safari | 公开链接 | 能打开 | 多半不支持 USB，蓝牙要看浏览器和系统 |

“能连接”只是具备条件，第一次仍要实际点“连接”、看到新读数才算连上。需要本机地址时，可以请 WorkBuddy：“请在这个网页目录启动本机服务，给我能打开页面的地址。”这个 `127.0.0.1` 地址指向访问者自己的电脑，发给同事打不开。

**连上了，却没有读数。** 按通信路径查：USB 串口核对端口、波特率和文本格式；蓝牙核对服务、通知和数据包格式，两条路分开查。只改网页上的图表，不用重新烧录开发板；改采样、板上计算或板上显示屏，才涉及固件，烧录前保留原来的程序。

## 四、把网页交给同事和学生

网页要交给别人，有两种办法：把整个文件夹交给对方，由对方在自己电脑上打开；或者请 WorkBuddy 发布成公开链接。发布时可以这样说：

```text
请把“网页站点”这个文件夹发布成公开链接。发布前先列出会公开哪些文件，等我确认再发；出现收费或开通提示，先停下来告诉我。
```

要连开发板的网页，说明“发布成独立的网页应用”。发布前后各查几件事：

| 时机 | 检查 |
| --- | --- |
| 发布前 | 准备公开哪些文件？有没有学生姓名、照片、作品原件、私人笔记、密码和密钥？当前版本存了吗？ |
| 发布后 | 换一台设备、换一个浏览器打开；要连设备的，在电脑的 Chrome 或 Edge 上实际连一次 |
| 更新后 | 明确说“更新到原来的应用，保留原链接”，回原链接刷新；还是旧版，请它给更新过的脚本加版本号 |
| 每学期 | 哪些页面过时了、出错了、不适合再公开了 |

公开链接可以被转发，拿到的人都能打开；断网时公开链接打不开，课前把单文件网页拷进 U 盘，再准备几张截图。网站要收集学生作答时，事先告诉学生收什么、谁能看、留多久，统计的边界见第 8 章。

## 五、模型、打印与截图

**WorkBuddy 能调用 Blender 和 OpenSCAD 吗？** 能调用电脑上已经装好的软件。先让它检查已安装的软件，做一张低分辨率预览，到输出文件夹打开图片，再继续（第 14 章）。拿到 STL，先读出长、宽、高核对单位，再导入切片软件逐层查看；打印后量实际尺寸，放到使用场景里试。

**怎样留清楚的教学截图？** 收起无关的账号和聊天，把要判断的输入和结果放进画面；鼠标移出取景范围，等悬浮提示消失再截。有遮挡就重截，不要涂抹或补画。模型渲染图、结构示意和真实操作截图，在图注里分别写明。
