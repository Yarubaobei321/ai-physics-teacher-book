# 附录 A　提示词：怎样起步，怎样补

## 怎样用这份附录

书里的提示词都是简短的一版：教师自己想得到、写得出、容易改，只抓住必须由教师决定的事——教学问题、模型条件、自己算过的预期、哪些地方不许动，其余的交给 AI。背景材料要给足：教材的哪一节、教师用书、已有的学案和数据。

这份附录只收在哪一章都用得上的东西：第一条指令说清哪四件事，写不出来时的三句话，发现问题时怎样反馈，看到常见问题补哪一句，以及各章新增的协作方法。正文代码框里的提示词按章收在配套包的《全书提示词（按章）》里，可以直接复制改用。提示词里的文件名和路径，先换成自己工作空间里确实有的材料；做出来的东西，仍按第 3 章和附录 B 检查。

## 一、第一条指令的四件事

无论做哪一种资源，第一条指令都只需要说清四件事（第 7 章）：

| 要说清的 | 例子（第 7 章圆弧轨道） |
| --- | --- |
| 学生要看什么 | 滑块到“最高点”时并没有停住，两者一起向右运动 |
| 按什么条件算 | 滑块 1 kg，轨道 3 kg，半径 1 m，光滑，轨道可以水平移动 |
| 这一版先做哪些功能 | 播放、暂停、复位，显示时间、高度和两个物体的速度 |
| 用什么结果检查 | g=10 m/s² 时，最高点高度 0.6 m，两者速度都是 1 m/s；分离时滑块 −2 m/s，轨道 2 m/s |

最后一件最容易漏掉，也最重要。教师自己先算出一两个关键结果写进去，AI 做完就有了对照，教师也有了判断对错的依据。

一时写不全这四件事，可以先用一句话说出想让学生看清什么，再加一句“先问我一个你最需要知道的问题”；回答它的追问时，对照这四件事，看还缺哪一件（第 7 章第三节第 1 步）。

## 二、提示词写不好时的三句话

不知道怎么写的时候，用自己的话说出想要什么，再加上其中一句（第 2 章）：

```text
这个词是什么意思？用高中老师能懂的话说。
```

```text
先给我两三个方案，说说各自的好处和问题，我来选。
```

```text
先问我一个你最需要知道的问题。
```

## 三、发现问题时的反馈格式

看到不对的地方，反馈写清四件事：条件、操作、实际看到的、物理上应该是什么（第 7 章）。第 7 章第三节第 3 步有一个填好的例子。

```text
条件：（参数）
操作：（做了什么）
实际表现：（看到了什么，截图已附）
预期：（物理上应该是什么）
请检查原因，修正后复看此状态，并检查其他相关情况。
```

## 四、看到这些问题时，补一句

下面这些问题在各章反复出现。第一次不必预先写进提示词，看到了再补对应的一句：

| 看到的问题 | 可以补的一句 | 出现在 |
| --- | --- | --- |
| 课堂电脑断网时打不开或缺图 | 做成一个文件，不依赖联网下载的字体、图片或代码库 | 第 2、6、7 章 |
| AI 顺手装软件、改电脑环境，或者做起别的事 | 只做这个小任务，不安装软件；先检查已有工具 | 第 2、14 章 |
| 动画只在几个时刻对，读数是预先填好的答案 | 依据运动方程计算，不把期望值直接填进读数 | 第 7 章 |
| 画面和数字不同步 | 画面、读数和曲线来自同一个状态 | 第 7 章 |
| 向左的速度显示成正数，方向信息丢失 | 保留单位和正负号 | 第 7 章 |
| 一暂停速度就清零，学生误以为物体静止 | 暂停只冻结模拟时间，保留瞬时速度 | 第 7 章 |
| 改了数，屏幕上还留着上一次的结果 | 计算输入一变，旧结果立即撤下 | 第 2、6、7 章 |
| 填了 0、负数或坏数据，页面照样出数 | 不合理的输入拒绝计算并说明原因，空白不当成 0 | 第 2、4、6、11 章 |
| 原始记录被悄悄改了样 | 原始数据保持原样：不重排、不移动测点、不为好看删改 | 第 2、5、6、10 章 |
| 处理后找不回原始数据 | 校零等处理另存一份，原始列不动 | 第 11 章 |
| 跨过断点，算出一条并不存在的曲线、速度或面积 | 遇到断点重新开始，不跨段连线、拟合或积分 | 第 4、11 章 |
| 把算回来的数或后加的线当成测量 | 分开“测到的”和“算出的”“后加的” | 第 4、10 章 |
| 示例被当成实测 | 演示或构造数据始终标明“非实测” | 第 2、4、6、11 章 |
| 初态和末态混用，守恒比较失去意义 | 同一次碰撞的初态和末态都保留 | 第 16 章 |
| 把演示设定当成题目条件 | 题目给的和网页另加的设定分开标出 | 第 10 章 |
| 改坏了退不回去 | 改之前另存一份；输入保持原样，新文件另放 | 第 7、14 章 |
| 学生材料、私人笔记跟着公开 | 发布或更新前先列清单，等我确认 | 第 15、16 章，附录 C |
| AI 报告了它没有做过的检查 | 没有实际做的检查如实说明，不写成通过 | 第 2、3、5—7、16 章 |

## 各章新增的 AI 协作方法

基础操作在各章间复用，表中只列每章新增的方法。

| 章 | 新增的 AI 协作方法 |
| --- | --- |
| 2 纸带记录页 | 从一句话得到一份自己判断得了的文件；请 AI 帮着补全条件，再用答案已知的数据核对 |
| 3 物理审核 | 要求可复核的检查记录；请另一个 AI 只凭原始条件独立复算 |
| 4 传感器测速 | 先请 AI 读设备程序，说清设备发了什么；先分析历史记录，再写最小采集程序 |
| 5 超重与失重 | 让 AI 处理传感器数据，保留原始曲线、分段、说明尖峰来源 |
| 6 机械能守恒 | 先写数据约定，再请 AI 按约定做计算网页，用易错输入检查 |
| 7 动量模型 | 写清模型条件，由规律算出运动；先预测再显示；以核对过的网页为模板派生新模型 |
| 8 静电 | 先写教学脚本再做动画；用教材插图和画面约定审图；把模拟、动画和当堂诊断连成课堂网站 |
| 9 水槽测电势 | 按真实水槽尺寸计算 1∶1 预测底图，先审边界条件再审图 |
| 10 电势地形 | 照片整理成逐点核对的点表，测点叠到计算地形上；分清测的、算的和补的 |
| 11 电路拼图 | 让 AI 读入传感器表格，按真实时间积分、拟合，检查单位与零点 |
| 12 电学实验 | 先定讲解顺序，一页只讲一个关系；把分压电路拆成等效电路，答案点击后才显示，每个数自己复算 |
| 13 电磁感应 | 以真实装置的全部资料作上下文，做出对得上实测的模拟，把采样也放进模拟 |
| 14 三维模型 | 在 WorkBuddy 里调用建模软件出图、标注和做参数化试样；用实拍纠错，让一份状态同时驱动模型、刻度和电路图 |
| 15 学情诊断 | 请 AI 对应多份报告并先报异常；按教师定的规则归类、打分、原处批注 |
| 16 学生作品 | 请 AI 只读检查并按固定格式报告，再与学生原话和教师证据对照 |

| 能力 | 起步时可以这样做 | 书中在哪里练 |
| --- | --- | --- |
| 说清教学问题 | 用自己的话说出学生卡在哪里、想让他们看清什么；说不清时，请 AI 先问一个问题 | 第 2 章；各章第三节的提示词 |
| 持续协作 | 先做一个小任务，再把试用中看到的问题说具体，一次只改一件事 | 第 2、7 章 |
| 核查内容和来源 | 先写下预期再看结果；分清测的、算的、模型补的；问清 AI 说的“检查通过”查了什么 | 第 3 章；各章第四节 |
| 学会新概念 | 遇到滤波、网格、拟合、标定、切片、烧录，请 AI 用听得懂的话解释、给两三种做法，再用实际结果检验 | 第 4、5、9、10、14 章 |
| 组织学生学习 | 决定何时暂停、让学生预测什么、看学生留下的哪些证据；妥善处理学生数据和署名 | 各章第五节；第 15、16 章 |
