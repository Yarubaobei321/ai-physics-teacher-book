# 附录 D　各章需要准备什么

配套包按“第几章／文件名”整理，每份材料的用途、数据性质（实测、历史记录、构造、模型计算）和打开方式，见包里的《配套文件索引》。这里只列做各章时要准备的设备。

**每一章都要用的**：一台装好 WorkBuddy 的电脑（Windows 或 macOS）；Chrome 或 Edge 浏览器，要连开发板的网页只能用电脑上的这两种浏览器打开；一个专门的工作文件夹，每做一样东西，在里面新建一个子文件夹。

| 章 | 设备 |
| --- | --- |
| 2 | 打点计时器、小车和纸带（教材实验原有器材）；一台打印机 |
| 4 | 光电门（本书用双头光电门，经 ESP32 发送数据）；ESP32 开发板、HS-SR04P 超声波模块、USB 数据线、一块平整挡板。跟着做可以先用配套的样例和历史记录 |
| 5 | 电梯模型和自制压力传感器（严力耕老师团队的装置）；跟着做只用构造数据 |
| 6 | 三种方案所需的实验器材之一；跟着做用演示数列 |
| 8 | 手摇起电机、两块金属圆板和一棵小树模型；金属容器和铝箔条；透明塑料瓶、金属杆和铁丝；每组一台平板 |
| 9 | 水槽描绘仪（或一只浅的透明塑料盒加两根不锈钢条）、9 V 电池、数字电压表、按 1∶1 打印的底图和彩色小环 |
| 10 | 不需要器材，用第 9 章的测量记录 |
| 11 | 磁吸电路拼图（严力耕老师团队的装置）、电流传感器、万用表；分析页先用构造数据 |
| 12 | 不需要器材；有滑动变阻器时，可以贴纸条描一条曲线 |
| 13 | 转盘式电磁感应装置（王硕老师的装置）和微电压传感器；读数据、用模拟实验不需要器材 |
| 14 | Blender 和 OpenSCAD（都免费）；一台 3D 打印机，没有的话请通用技术或创客教室的老师帮忙打印；手边有游标卡尺和学生电表更好 |
| 15 | 作业平台导出的成绩和题卡；学生笔记的扫描件和名单 |

第 1、3、7、16 章不需要专门的器材。
