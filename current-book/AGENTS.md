## 截图前移开鼠标（作者 2026-10-09 确认）

- 使用 Computer Use 获取正文配图、操作截图或审阅截图之前，先把鼠标移动到取景范围之外、不遮挡内容的位置，再截图。
- 截图前确认鼠标指针及 Computer Use 的鼠标位置标记、点击提示、悬浮提示和选择浮层已消失；不能仅凭已移动鼠标就认定画面干净。
- 截图后实际查看图片；若仍含鼠标位置标记或相关浮层，调整鼠标位置后重新截图。不要用涂抹、重绘或生成式修补掩盖标记，不覆盖物理读数、模型条件或操作证据。
- 无法取得干净截图时保留原因并继续其他工作，不把受影响图片当作正文正式配图。
