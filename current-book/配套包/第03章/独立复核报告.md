## 0. 时间间隔 T 的独立判定（不照抄）

- 打点频率 f = 50 Hz → 每个打点周期 = 1/50 = 0.02 s。
- 原文条件：**相邻计数点之间还有 4 个计时点** → 相邻计数点之间被分成的打点周期个数 n = 4 + 1 = **5**。
- 计数点时间间隔 **T = n / f = 5 / 50 = 0.1 s**。

这一点是关键：题目说的是"之间还有 4 个**计时点**"（间隔点），不是"间隔 4 个周期"。因此 n = 5，T = 0.1 s。

## 1. 任务一：两组原始纸带数据的独立计算

位置单位 cm，计算前换算为 m（1 cm = 0.01 m）。速度 `v_k = (x_{k+1} − x_{k−1}) / (2T)`，时刻 `t_k = k·T`。

### 1.1 相邻段长（cm）

| 段 | 数据一 | 数据二 |
|---|---|---|
| s₁ = x₁−x₀ | 3.75 | 3.75 |
| s₂ = x₂−x₁ | 5.25 | 5.25 |
| s₃ = x₃−x₂ | 6.75 | 7.05 |
| s₄ = x₄−x₃ | 8.25 | 8.25 |
| s₅ = x₅−x₄ | 9.75 | 9.75 |
| s₆ = x₆−x₅ | 11.25 | 11.25 |

相邻段长差（连续性/均匀性检查）：数据一恒定 +1.50 cm；数据二为 +1.50, +1.80, +1.20, +1.50, +1.50 cm → 数据二在 s₃ 附近存在非均匀。

### 1.2 五点速度（m/s）与时刻（s）

| 速度点 | t (s) | 数据一 v (m/s) | 数据二 v (m/s) |
|---|---|---|---|
| v₁ | 0.1 | 0.450 | 0.450 |
| v₂ | 0.2 | 0.600 | 0.615 |
| v₃ | 0.3 | 0.750 | 0.765 |
| v₄ | 0.4 | 0.900 | 0.900 |
| v₅ | 0.5 | 1.050 | 1.050 |

### 1.3 v-t 最小二乘拟合 `v = k·t + b`（未加权 OLS，5 点等权）

| 量 | 数据一 | 数据二 |
|---|---|---|
| 斜率 k（= 加速度拟合值，m/s²） | **1.500** | **1.485** |
| 截距 b（m/s） | **0.300** | **0.311** |

- 数据一五点严格共线（残差全为 0），k = 1.500、b = 0.300 为精确值。
- 数据二非严格共线，k = 1.485、b = 0.3105（保留三位 0.311）。

### 1.4 六段分组逐差法加速度

`a = [(s₄+s₅+s₆) − (s₁+s₂+s₃)] / (9T²)`

| 量 | 数据一 | 数据二 |
|---|---|---|
| 分子 (s₄+s₅+s₆)−(s₁+s₂+s₃) | 0.135 m | 0.132 m |
| 9T² | 0.09 s² | 0.09 s² |
| a（m/s²） | **1.500** | **1.467** |

### 1.5 两种算法的对比（同源数据，非独立估计）

|  | 数据一 | 数据二 |
|---|---|---|
| 拟合斜率 k | 1.500 | 1.485 |
| 逐差法 a | 1.500 | 1.467 |
| 差值 | 0.000 | 0.018（≈1.2%） |

数据一两种处理完全一致（数据严格满足匀加速）；数据二出现约 0.018 m/s² 的偏差，来自 s₃ 的局部不均匀。

**注意：二者都取自同一组 7 个位置读数，不是两次独立测量。** 它们对同一组读数的局部不均匀敏感度不同，因而可以互相印证数据质量；但"两值之差"不代表两次独立测量的误差之差，不能据此谈统计意义上的独立性。

### 1.6 两种处理的「原始数据权重」说明（v2 已更正）

**（a）位置 → 速度点的实际使用关系（逐一列出）**

| 速度点 | 公式 | 用到的位置 |
|---|---|---|
| v₁ | (x₂−x₀)/(2T) | x₀, x₂ |
| v₂ | (x₃−x₁)/(2T) | x₁, x₃ |
| v₃ | (x₄−x₂)/(2T) | x₂, x₄ |
| v₄ | (x₅−x₃)/(2T) | x₃, x₅ |
| v₅ | (x₆−x₄)/(2T) | x₄, x₆ |

**出现次数统计（更正 v1）**：

| 位置 | x₀ | x₁ | x₂ | x₃ | x₄ | x₅ | x₆ |
|---|---|---|---|---|---|---|---|
| 出现次数 | 1 (v₁) | 1 (v₂) | 2 (v₁,v₃) | 2 (v₂,v₄) | 2 (v₃,v₅) | 1 (v₄) | 1 (v₅) |

即：**只有 x₂、x₃、x₄ 各出现 2 次；x₀、x₁、x₅、x₆ 各只出现 1 次**。v1 的"中间点都 2 次、端点 1 次"是错的。

**（b）出现次数 ≠ 斜率权重：真正展开线性组合**

等间隔五点（t = T, 2T, 3T, 4T, 5T）的 OLS 斜率，其标准式可代数展开为位置读数的线性组合：

> **k = [ 2·x₀ + 1·x₁ − 2·x₂ − 2·x₃ − 2·x₄ + 1·x₅ + 2·x₆ ] / (20 T²)**

即系数向量（同一量纲因子 1/(20T²) 下）为 **(+2, +1, −2, −2, −2, +1, +2)**，**系数之和 = 0**（对整体平移不变，符合物理）。

截距同样可展开：

> **b = [ −8·x₀ − 5·x₁ + 6·x₂ + 6·x₃ + 6·x₄ − 1·x₅ − 4·x₆ ] / (20 T)**

**独立核对（代数 + 数值，见 `output/斜率展开核对.txt`）**：

- 数值法：把单位向量 e_i 当位置代入 OLS，直接读出系数（T = 0.1 s）→ 与上式逐项相同，差 ~1e-15（浮点残差）。
- 闭式重建：数据一 k = 1.500 / b = 0.300、数据二 k = 1.485 / b = 0.3105，与直接 OLS 完全吻合。
- 结论：**出现次数与斜率系数不成比例**（x₀、x₆ 只出现 1 次，系数却最大 +2；x₂、x₃、x₄ 出现 2 次，系数是 −2；x₁、x₅ 出现 1 次，系数 +1 且符号为正）。所以不能拿出现次数当等效权重，必须用上面这组**带正负号的系数**描述。

**（c）六段逐差法**

形式上列 6 段，代数上 `s₄+s₅+s₆ = x₆−x₃`、`s₁+s₂+s₃ = x₃−x₀`，相减后

> **a = ( x₆ − 2·x₃ + x₀ ) / (9 T²)**

系数 (1, 0, 0, −2, 0, 0, 1)/(9T²)：**实际只用到 x₀、x₃、x₆ 三个位置**（权重 1, −2, 1），x₁、x₂、x₄、x₅ **完全抵消、不参与**。它并非"平均使用六段"。

> 数值核对：数据一 x₆−2x₃+x₀ = 45−2×15.75+0 = 13.5 cm = 0.135 m，÷9T²(0.09) → 1.500；数据二 = 45.30−2×16.05+0 = 13.20 cm = 0.132 m → 1.467，均与 1.4 一致。

**（d）小结**：拟合斜率用到全部 7 个位置（系数 +2,+1,−2,−2,−2,+1,+2，混合正负）；逐差法只用到 x₀、x₃、x₆（1,−2,1）。两者对局部读数误差的敏感方式不同，这是它们结果可能略有差异的原因，但**不能描述为"独立估计"**。

### 2.2 可复现的问题与影响

**问题定位**：`#nper` 预填值 = **4**。按页面自己的提示"n 为相邻计数点之间相隔的打点周期个数"，以及顶部"之间还有 4 个计时点"，正确值应为 **5**。填 4 是把"间隔点数"直接当成了"周期数"，少算 1 个周期。

**影响（以数据一为例，按页面脚本逻辑推算，未点击实测）**：

| 量 | 正确 n=5（T=0.1 s） | 页面 n=4（T=0.08 s） | 偏差 |
|---|---|---|---|
| 计数点时间间隔 T | 0.1 s | 0.08 s | ×0.8 |
| v₁ | 0.450 m/s | 0.5625 m/s | ×1.25 |
| v₂ | 0.600 | 0.750 | ×1.25 |
| v₃ | 0.750 | 0.9375 | ×1.25 |
| v₄ | 0.900 | 1.125 | ×1.25 |
| v₅ | 1.050 | 1.3125 | ×1.25 |

| 逐差法 a | 1.500 m/s² | 2.34375 m/s² | ×1.5625 |

规律：T 缩小为 0.8 倍后，所有速度放大 1.25 倍，加速度类结果放大 1.25/0.8 = 1.5625 倍。**页面不会自行报错**——`validate()` 只要求 n 为正整数，4 是合法正整数，因此页面会"照常给出"一组错误的 T 与加速度，学生若不核对条件就无法察觉。
