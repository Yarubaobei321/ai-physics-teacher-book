五、协议要点与限制

  • 双头 ESP32-gate 蓝牙通知恰含两个 32 位小端浮点数（8 字节）：速度 (m/s)、设备时间 (s)。不含原始时间差、不含设备事件序号。
  • 因此蓝牙行的「时间差原文 / Δt」留空，并注明未发送；禁止用 L/v 倒算后冒充测得的时间差。
  • USB 串口文本含「两门时间差是 … us」，可用 L / Δt 复算速度，另列「网页复算速度」；固件速度仍保存原值。
  • 设备时间是两束光触发时刻的平均值，不是浏览器接收时间。
  • 网页行号只是接收顺序，不是设备序号；无设备序号时不能声称能检测全部丢包。
  • 设备时间回退时另起记录段；相同包只标「疑似重复」。
  • 每行保留导入当时的 L，不随输入改变历史值。
  • 拒绝：错误字节长度、非有限数、非正的时间差；门间距 L 无效（空 / 0 / 负 / 非有限）时拦截本次导入与蓝牙通知，不追加记录，旧记录保留。
  • “相同包”判定比较来源 + 规范化原始字节/文本 + 全部包字段（速度、设备时间、时间差），不只看速度与时间。
