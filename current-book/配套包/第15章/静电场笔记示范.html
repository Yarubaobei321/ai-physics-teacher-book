01 基础公式

单位：E → N/C＝V/m；φ、U → V；W、E_p → J。

知识公式 / 条件
电荷q=±ne；e=1.60×10⁻¹⁹ C；孤立系统 Σq不变
库仑力F=k|Qq|/r²（真空、静止点电荷）
场强大小E=F/|q|；点电荷 E=k|Q|/r²
电势 / 电势差φ=Ep/q；UAB=φA−φB
力 / 功 / 能F=|q|E；WAB=qUAB=−ΔEp；Ep=qφ
方向+q：F与E同向；−q：反向。场强按矢量叠加。
静电平衡导体内部E=0；导体整体等势

02 六概念关系

上排：电场；下排：电荷的受力、做功与能量。

适用条件关键关系
匀强电场UAB=E d∥；d∥为A到B位移沿场方向的有符号分量
恒力做功WAB=Fs cosθ；θ为电场力与位移夹角
做功与能量WAB=qUAB=EpA−EpB=−ΔEp；W>0 ⇔ ΔEp<0
符号与零点q代正负号；φ、Ep的零点相对应；φ=0不等于E=0

03 正、负点电荷

x向右；无穷远零势。φ单位kQ/a，E单位kQ/a²；Q>0。

φ=kq/r；|E|=k|q|/r²。蓝：电场线；橙：等势线；两者垂直。x=0处无定义。

04 同种正电荷：连线 / 中垂线

电荷位于(−a,0)、(+a,0)；x向右、y向上；无穷远零势。

中点：E=0，φ=2kQ/a。φ沿连线为局部最小，沿中垂线为最大。

中垂线：Ex=0；φ=2kQ/√(a²+y²)；Ey=2kQy/(a²+y²)3/2。

纵轴单位：φ → kQ/a，E → kQ/a²；电荷处不连线。

静电场笔记示范 · 05

05 等量异种电荷：连线 / 中垂线

电荷位于(−a,0)、(+a,0)；x向右、y向上；无穷远零势。

左+Q，右−Q。中点：φ=0，Ex=2kQ/a²。两电荷之间E始终向右。

中垂线：φ=0，Ey=0；Ex=2kQa/(a²+y²)3/2>0。注意纵轴为Ex。

纵轴单位：φ → kQ/a，E → kQ/a²；电荷处不连线。

06 电容器充放电

固定R、C；τ=RC；以充电电流方向为正。

过程电压 / 电流
充电UC=U₀(1−e−t/τ)；I=(U₀/R)e−t/τ
放电UC=U₀e−t/τ；I=−(U₀/R)e−t/τ
