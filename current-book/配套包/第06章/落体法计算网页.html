点位用途：x0 与 x2 → v1、x3 与 x5 → v4（中心差分需相邻点），x1 为能量参考点，x6 仅作原始位置保存、不参与计算（计算范围不扩展到 n=5）。

公式与单位

位置换算：xₙ(m) = xₙ(cm) / 100
中心差分速度：vₙ = (xₙ₊₁ − xₙ₋₁) / (2T)（n=1 用 x₀、x₂；n=4 用 x₃、x₅）
高度变化：hₙ = xₙ − x₁　（点 1 为参考，h₁ = 0）
重力势能减少量：ΔEp = m·g·hₙ（J）
动能增加量：ΔEk = ½·m·(vₙ² − v₁²)（J）
本页 h 沿下落方向为正，因此 mghₙ 表示重力势能的减少量（不是"变化量"的通用写法）。
相对差异（保留正负号）：ε = (ΔEk − ΔEp) / ΔEp
ε < 0 表示动能增加量偏小（ΔEk < ΔEp）；ε > 0 表示动能增加量偏大，显示时带 “+”。当 ΔEp ≤ 0 时 ε 留空（分母非正，相对差异无意义）。
不使用 v = g·t 或 v = √(2gh)；速度一律由位置中心差分得到。

使用说明

  1. 填 m、g、T（均为正数），再逐格录入 x0…x6（cm）。输入可用“0”“0.”“0.79”等写法，不会清空其他格子。
  2. 结果表随输入实时重算；某项所需数据缺失时该格留空，不显示上一次的旧值。
  3. “载入演示数据”仅用于演示，始终标非实测；改动其中任一数值也不会变成“实测”。点“清空”回到“等待手动录入”。
  4. 位置不自增（未按点号递增）时，结果判为无效并保留你录入的原数；不做自动排序、不代替你改数；ΔEp ≤ 0 处 ε 留空。
  5. “导出 CSV”保存原输入、参数、单位、数据身份与计算值；“打印”输出当前页面。
  6. 本工具不判断“验证成功”；ε 的值（含正负号）由你自己结合实验误差分析。
