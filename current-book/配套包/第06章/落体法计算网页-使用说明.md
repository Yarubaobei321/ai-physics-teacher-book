# 落体法机械能守恒计算工具 — 使用说明

## 文件
- `落体法计算网页.html`：单文件、离线可用、无网络依赖。双击用浏览器打开即可。

## 入口
打开 `落体法计算网页.html` → 「参数」填 m、g、T → 「位置」逐格填 x0…x6（cm）→ 结果表与能量对比图实时更新。

## 计算约定（严格沿用输入 `数据约定-落体法.md`）
- 位置：`xₙ(m) = xₙ(cm)/100`
- 中心差分速度：`vₙ = (xₙ₊₁ − xₙ₋₁)/(2T)`，n=1…4；n=1 用 x0、x2；n=4 用 x3、x5
- 参考点：点 1；`hₙ = xₙ − x₁`
- `ΔEp = m·g·hₙ`（**重力势能减少量**）；`ΔEk = ½·m·(vₙ² − v₁²)`（**动能增加量**）
- 相对差异（**保留正负号**）：`ε = (ΔEk − ΔEp) / ΔEp`
  - `ε < 0`：动能增加量**偏小**（ΔEk < ΔEp）
  - `ε > 0`：动能增加量偏大，显示时显式带 **+**
  - 换算成百分数时同样带号，例如演示数据为 **−2.20%、+1.09%、−1.52%**
- 本页 h 沿下落方向为正，故 `mghₙ` 表示重力势能的**减少量**。
- `ΔEp ≤ 0` 时 ε 留空；**不使用** `v = g·t`、`v = √(2gh)`，**不自动排序**，**空值不按 0**

## 行为说明
| 场景 | 表现 |
|---|---|
| 参数 m/g/T 非正或非数 | 能量相关结果全部留空，并提示 |
| 某位置缺项 | 仅“依赖该点”的单元格留空，其余照算；不沿用旧值 |
| 坐标不按点号递增 | 提示点号/方向/抄录异常，**保留原数、不排序** |
| 输入 `0`、`0.`、`0.79` | 逐格保存，不清空其它输入格 |
| 载入演示数据后改动 | 仍标【非实测】，不会变成“实测” |
| 点“清空” | 结果清空，身份回到“等待手动录入” |

## 导出与打印
- 「导出 CSV」：含原输入、参数、单位、数据身份、计算结果与提示；UTF-8 BOM，Excel 可直接打开。
- 「打印」：浏览器打印当前页面（保留完整参数、七点原始位置、结果表与图表）。
