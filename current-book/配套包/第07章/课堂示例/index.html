操作说明
  • 情境：①低速 1/3、②低速 1/1、③低速 3/1（u = 4 m/s，弧内折返后底端分离）；④固定轨道（轨道被支架固定，u = 4 m/s）；⑤高速离轨（u = 6 m/s，到顶端离轨斜抛）。只提供这五种已定情境，不开放任意参数输入。
  • 先预测 / 显示结果：预测模式保留条件与问题，隐藏答案读数（只留「？」）、速度箭头、v-t 曲线与核验表，画面上的阶段结论改为提问，定位按钮禁用并改为中性名称；切回「显示结果」全部恢复。
  • 播放 / 暂停：暂停只冻结时间轴，保留该时刻的瞬时速度读数；再次播放从原状态接着走，不重置。
  • 复位：回到 t = 0 并暂停，保留当前情境；恢复默认条件为另设入口：回到情境①，并恢复 0.1× 慢放、显示箭头、显示结果。
  • 定位：按钮按当前情境生成（相对最高点 / 底端分离 / 离轨 / 飞行最高点 / 回落 …），一键跳到该状态并暂停，可从该状态继续播放。
  • ④ 固定轨道：滑块离开底端后沿地面向左匀速，继续保留 0.7 m 可见位移；轨道与支架始终不动。
  • ⑤ 高速离轨：分离后保留约 0.23 s 观察区间，轨道继续向右、滑块向左。
  • 观察区间结束时整个模拟暂停（画面与时间一起停），不会出现位置停住而时间继续走的情况。可视区域边缘不是物理墙。
  • 播放速度 0.05×–1× 只改变观看节奏，不改变运动本身。
  • vx-t / V-t 曲线只在游标（= 当前模拟时刻）之前绘制；纵轴含负值，0 线加粗；曲线与画面、读数取自完全相同的状态。
  • 颜色约定：滑块橙色（m）、轨道蓝色（M）、支架深灰（固定于地面）；地面刻度固定在世界坐标上，不随物体移动。
