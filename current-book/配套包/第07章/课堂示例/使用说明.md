# 滑块与圆弧轨道：使用说明

双击 index.html 打开模拟；备课时打开审核.html，将独立预期与程序结果对照。文件不引用联网字体、图片或代码库；在课堂电脑上首次离线打开和投影试用仍需实际确认。

## 先讨论两个问题

小物体到达相对轨道的最高点时，相对地面是否静止？它从底端返回，是否一定向左运动？先用“① 低速 1 / 3”，再用等质量和滑块较重的两组比较。

1. 选择情境，点击“先预测”，让学生画出速度方向并说明理由。
2. 学生完成判断后，点击“显示结果”。本版在预测时禁用定位按钮，显示结果后恢复。
3. 点击“相对最高点”或“底端分离”，观察位置与读数。继续播放，尤其留意等质量时滑块与地面标记的关系。
4. 切换情境会回到该组初态。“复位”保留当前情境，“恢复默认条件”回到第一组。

播放倍率只改变观看节奏。为便于观察，可以先用0.1倍，再比较0.5倍与1倍；模拟时间、位置与速度的对应关系不应改变。观察区间结束时，整个模拟暂停。

## 两种扩展

固定轨道：先判断支架对系统水平外力的影响，再比较最大高度和底端速度。离开底端后，滑块向左，轨道保持不动。

高速：依次使用“顶端离轨”“飞行最高点”“落回顶端”“底端分离”。飞行时两个物体的水平速度相同，所以滑块落回移动后的顶端；顶端离轨和飞行最高点是两个不同状态。
