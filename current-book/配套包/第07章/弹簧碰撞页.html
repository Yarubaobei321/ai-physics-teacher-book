物理核验

“独立预期”一列用与画面无关的另一条路径写出：分离后的速度用一维弹性碰撞公式，最大压缩量与共速时刻 A 的位移用动量守恒对时间积分，弹性势能峰值用能量差。“本页实际”一列来自页面上驱动画面与图像的那一套解析解。

模型范围与设定
  • 理想轻弹簧、光滑水平面；相对运动为简谐运动，解析解同时驱动画面、读数与曲线，不做数值积分。
  • 接触后分离：只取半个周期（相对速度由 +u₀ 变到 −u₀），弹簧恢复原长时 B 与弹簧分离，之后两者各自匀速。不模拟斜面，也不模拟第二次碰撞。
  • 弹簧固定在 A 上（连 A 的左侧），所以分离后弹簧跟着 A 一起走、长度回到原长；B 的右边缘与弹簧左端之间会出现并拉大空隙。画面上的“空隙”读数是实算出来的，不是画出来的装饰。
  • 弹簧原长是绘图设定，题目没有给出原长：基准为 1.00 m，并随该组参数允许的最大压缩量自动加长（留 20% 余量、向上取整到 0.1 m），以保证画面上弹簧始终有正长度、两物块不会互相穿透。当前取值见上方提示行。
  • 压缩量 δ = (u₀/ω)·sin(ωt)，0 ≤ t ≤ ts；t > ts 后 δ ≡ 0。位移由同一组速度函数积分得到，B 不会穿过弹簧或物块。
  • 时间轴末端随分离时刻联动：Tend = ⌈ts⌉ + 1，保证分离之后仍有一段可见的匀速过程；关键时刻按钮 0 / t₀ / ts / Tend 也随之生成。默认参数下正好是 0 / 1 / 2 / 3 s。分离之前不会显示“分离完成”。
  • 正文题给的两个近似值 0.36v₀t₀ 与 0.768v₀t₀ 是取整后的参考值：0.36 由解析解 (1−2/π) 取整，0.768 又用取整后的 0.36 反推，所以略大于解析解的 0.76394v₀t₀。本页不写死这两个数，全部按解析解实时计算。
  • 参数取非法值（质量或劲度系数不大于 0、vB0 ≤ vA0）时页面拒绝模拟并说明原因，不会给出画面。
