# 前言　这本书怎么用

## 写给谁

这本书写给高中物理教师，尤其是想用 AI 做点东西、又不知道从哪里开始的老师。

读这本书不需要会编程，不需要懂软件术语，也不需要会写长提示词。需要的是你本来就有的东西：知道学生卡在哪里，知道一个物理结论在什么条件下成立，看得出一个数对不对。AI 能替你写代码、画图、整理数据、起草说明；判断哪些东西能上课，仍然要靠教师。

## 读完能做成什么

各章联系高中物理教材与日常教学，围绕具体问题制作资源：

- 一张会计算的实验记录页（纸带、光电门、机械能守恒）；
- 一个能先预测、再观察的模拟网页（圆弧轨道、弹簧碰撞）；
- 一台为课堂定制的小传感器，以及接收数据的网页（超声波测速、力传感器）；
- 一套分组实验的配件、底图和数据整理方法（静电场描绘仪）；
- 一道高考题旁边的可操作模型；
- 一个教具的三维图或 3D 打印结构件；
- 一个能发给学生和同事的网站。

做成什么还在其次，更要紧的是这个过程：你在和 AI 一起做的过程中，看清它擅长什么、哪里必须由你判断，并且一次比一次做得好。

## 每一章怎样读

各章围绕以下几个部分展开：

| 部分 | 读什么 |
| --- | --- |
| 教学问题 | 对应教材哪一节，学生卡在哪里，旧办法为什么不够；末尾一小段说明本章在全书框架中的位置 |
| 先看成品 | 已经做成的资源，在课上能做什么 |
| 跟着做 | 在 WorkBuddy 里准备输入材料，提出需求，检查和修改结果 |
| 物理审核 | 怎样判断做出来的东西在物理上对不对 |
| 带进课堂 | 一份教学设计：放在什么时候教、易错点、教学流程、板书、怎样看学生的回答 |
| 同样的方法还能用在哪里 | 换一种资源或教学情境，继续使用本章的方法 |

“跟着做”里的提示词，正文给的是简略版：教师自己想得到、容易改，只写必须由教师决定的事。实际使用的详细版多由 AI 替作者起草，标明了来源，折叠放在后面，并说明多出来的每一句对应什么问题。第一次做，发简略版就够了；遇到相应的问题，再补那几句。全书的提示词汇总在附录 A。

## 需要准备什么

**每一章都要用的：**

- 一台电脑（Windows 或 macOS），装好 WorkBuddy。安装、登录、选择模型和工作模式的方法只在第 1 章讲一次。
- Chrome 或 Edge 浏览器。要连接开发板的网页，需要用电脑上的这两种浏览器打开；手机微信和 iPad 的 Safari 通常不能连接 USB 和蓝牙设备。
- 一个专门的工作文件夹。每做一样东西，就在里面新建一个子文件夹。

**部分章节要用的：**

| 章 | 设备 |
| --- | --- |
| 2 | 打点计时器、小车和纸带（教材实验原有器材） |
| 4、5 | ESP32 开发板；光电门或超声波测距模块；数据线 |
| 6 | 力传感器（称重模块）、ESP32、电机和电梯模型；或者用手机里的 Phyphox 代替 |
| 7 | 教材三种方案的实验器材之一 |
| 12—14 | 水槽式电场描绘仪、学生电源、电压表；手机或平板拍照 |
| 16 | 磁吸电路模块、电流传感器、万用表 |
| 17 | Blender（免费） |
| 18 | 一台 3D 打印机及其切片软件 |

没有某样设备，也可以读那一章：可以先看成品、审核方法和教学设计，再按条件准备器材。

## 关于 AI 的几句话

AI 的能力变化很快，书里的界面截图、模型名称和某一次的输出，过一段时间就会不一样。这本书想留下的是不随模型变化的东西：怎样把一个教学问题说清楚，怎样给出教师自己算过的检查结果，怎样判断 AI 做出来的东西在物理上能不能用。模型越强，这些判断越省力，但不会变得不需要。

书中写到“请另一个 AI 复查”时，指的是一种分工：一个 AI 做，另一个只拿原始条件和数据独立计算，最后由教师比较两份结果。用哪一个工具都可以。

学生的作品、照片和对话，书中一律去掉了身份信息。
