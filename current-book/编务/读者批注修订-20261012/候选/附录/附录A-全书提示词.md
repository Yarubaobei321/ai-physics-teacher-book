# 附录 A　全书提示词：简略版和详细版对照

## 怎样用这份附录

下面按章收录起步指令和详细参考。正文中的追问与纠正保留在各章，使用时先准备对应的输入材料。

- **简略版**：教师自己想得到、写得出、容易改的。只抓住必须由教师决定的事：教学问题、模型条件、自己算过的预期、哪些地方不许动。其余的交给 AI。
- **详细版**：由 AI 协助整理，补上格式、公式、检查与保存要求。各节标明文字来源；实际发送过的指令与为本书整理的参考分开说明。

建议的用法是：第一次可以只发简略版。做出来以后按第 3 章的方法检查，遇到哪个问题，就到详细版里找对应的那一句补上。不必一开始照抄详细版，也不必背下来。

## 一、简略版的四件事

无论做哪一种资源，第一条指令都只需要说清四件事（第 8 章）：

| 要说清的 | 例子（第 8 章圆弧轨道） |
| --- | --- |
| 学生要看什么 | 滑块到“最高点”时并没有停住，两者一起向右运动 |
| 按什么条件算 | 滑块 1 kg，轨道 3 kg，半径 1 m，光滑，轨道可以水平移动 |
| 这一版先做哪些功能 | 播放、暂停、复位，显示时间、高度和两个物体的速度 |
| 用什么结果检查 | g=10 m/s² 时，最高点高度 0.6 m，两者速度都是 1 m/s；分离时滑块 −2 m/s，轨道 2 m/s |

最后一件最容易漏掉，也最重要。教师自己先算出一两个关键结果写进去，AI 做完就有了对照，教师也有了判断对错的依据。

## 二、提示词写不好时的三句话

不知道怎么写的时候，用自己的话说出想要什么，再加上其中一句（第 1 章）：

```text
这个词是什么意思？用高中老师能懂的话说。
```

```text
先给我两三个方案，说说各自的好处和问题，我来选。
```

```text
先问我一个你最需要知道的问题。
```

## 三、发现问题时的反馈格式

看到不对的地方，反馈写清四件事：条件、操作、实际看到的、物理上应该是什么（第 8 章）。这条本身就很短，不分简略版和详细版。

```text
条件：（参数）
操作：（做了什么）
实际表现：（看到了什么，截图已附）
预期：（物理上应该是什么）
请检查原因，修正后复看此状态，并检查其他相关情况。
```

## 四、详细版里常见的补充句

各章的详细版里，下面这些句子反复出现。它们各自防止一类问题：

| 补充的句子 | 防止什么问题 | 出现在 |
| --- | --- | --- |
| 做成一个文件，不依赖联网下载的字体、图片或代码库 | 课堂电脑断网时打不开或缺图 | 第 2、8 章 |
| 依据运动方程计算连续过程，不能只在关键点填答案 | 动画只在几个时刻对，中间是凑的 | 第 3、8 章 |
| 画面位置和所有读数来自同一个状态 | 画面和数字不同步 | 第 3、8 章 |
| 保留单位和正负号 | 向左的速度显示成正数 | 第 5、8 章 |
| 暂停只冻结时间，保留瞬时速度 | 一暂停速度就清零 | 第 8 章 |
| 任何计算输入改变后，旧结果立即撤下 | 改了数，屏幕上还留着上一次的结论 | 第 2、8 章 |
| 分开“测到的”和“算出的”／“模型补出的” | 把模型补的部分当成测量 | 第 4、12 章 |
| 演示数据始终标明“非实测” | 演示数据被当成实验结果 | 第 7 章 |
| 原始数据保留，不覆盖 | 滤波或修改后找不回原始记录 | 第 6、18 章 |
| 题目给的和另加的设定分开标出 | 把教学设定当成题目条件 | 第 13 章 |
| 不合理的输入要拒绝计算并说明原因 | 质量填 0，或固定点落到极板之外 | 第 3、13 章 |
| 改之前先另存一份 | 改坏了退不回去 | 第 8、17 章 |
| 无法执行的检查请说明，实际结果留待查看后填写 | AI 报告了它其实没有做过的检查 | 第 3、8 章 |


## 五、按章使用

简略版便于教师按自己的课堂修改。详细版中的文件名和路径，应先换成自己工作空间里确实存在的材料；没有实测数据的练习保留“构造数据”说明。提示词可以帮助生成和检查资源，结果仍需按附录B核对。

### 第3章　把独立复算和网页检查分开

两版指令由 AI 依据独立复核任务整理。练习副本中人为设置了一处条件不一致，用来学习检查方法。

**简略版**

```text
请独立复算我给的两组纸带数据，说明计数点的时间间隔、五点速度、拟合加速度和六段逐差法加速度。先不要读其他任务的答案。再只读检查练习网页，把原纸带条件、输入框和计算公式逐项对照，给我能复现的差异。没有实际操作过的部分，请写清检查方式。
```

<details>
<summary>详细参考</summary>

```text
请完成两项独立物理复核，所有结果写入output，不修改input，不读其他任务的答案，不安装或发布。
任务一：原纸带由50Hz打点计时器记录，相邻计数点之间还有4个计时点。第O、1…6点位置(cm)分别为数据一0,3.75,9,15.75,24,33.75,45；数据二0,3.75,9,16.05,24.30,34.05,45.30。请自行确定相邻计数点的时间间隔，计算1…5点速度、v-t最小二乘拟合的斜率/截距、六段分组逐差法加速度，说明两种处理的原始数据权重。不要照抄既有结论。

```

</details>

<summary>详细参考</summary>

```text

- 双头蓝牙名称前缀 ESP32-gate，每次通知 8 字节，两个 32 位小端浮点数：偏移 0 是速度 m/s，偏移 4 是设备时间 s。不要把第一个数当时间差。数据服务 cddf1001-30f7-4671-8b43-5e40ba53514a，通知特征 cddf1002-30f7-4671-8b43-5e40ba53514a；选择设备时按需允许实验服务 cddf0001-30f7-4671-8b43-5e40ba53514a。

页面的行号是本地接收序号，不称设备事件号。相同数据包保留原文并标“疑似重复”；设备时间倒退另起记录段；断线、重连留可见记录，不跨段连线。没有设备序号时，不声称能检测所有丢包或计算准确丢包数。

```

</details>

### 第6章　用构造视重数据检查处理方法

两版指令均由 AI 依据本章材料与教学任务整理，可按自己的课堂修改。

**简略版**

```text
我想用一段视重数据讲超重和失重。请先做一组明确标“构造数据、非实测”的练习：0.5 kg 的物体随电梯从静止开始上升，先静止，再向上加速、匀速、减速，最后停住。把力、加速度和速度画出来，再加入小幅的高频振动，比较处理前后。请先告诉我每段应该看到什么，等我核对后再生成文件。
```

<details>
<summary>详细参考</summary>

```text
请在当前工作区生成一组构造练习数据，并制作可以在电脑上打开的分析结果。所有页面、图、CSV 和说明都注明“构造数据，非实测”。

1. 时间 t=i×0.01 s，i=0…300。m=0.500 kg，g=9.80 m/s²，向上为正。
2. 理想加速度：0.50≤t<1.00 时为 +1.00；2.00≤t<2.50 时为 -1.00；其他时刻为 0，单位 m/s²。F_ideal=m(g+a)。
```
