- 记录时间：2026-10-15

- 状态：**已被替代**，仅作过程存档。最终执行版本见《最终制作脚本.md》

## 一、需求原始描述

给高二学生讲静电平衡是怎样建立的，做一段 10 秒以内、不配音的动画，放在课件里。

画面要求：

1. 一块不带电的金属导体放进向右的匀强电场；
2. 自由电子向左移动，左边出现负电荷、右边出现正电荷；
3. 导体里感应电荷的电场向左，越来越强，最后和外电场抵消，电子不再定向移动；
4. 只画净电荷，不画中性的背景电荷；
5. 电荷不能画到导体外面；
6. 解释不要超过人教版教材的说法。

## 二、首轮分镜方案（原文）

方案总时长 **9.0 s**，五段，无旁白，只保留 2 处极简标注。

### 分镜表

| 段 | 时间 | 画面 | 学生看哪里 | 依据（人教版必修三"静电的防止与利用"） |
|---|---|---|---|---|
| S1 | 0.0–1.2s | 左右两块带电平行板（左＋右−），两条灰色箭头贯穿画面指向右；中央虚线框标"导体尚未进入" | 先看箭头方向 → 建立"电场向右" | 匀强电场 |
| S2 | 1.2–2.4s | 导体方框入场就位（灰底金属块），左右场线被截断成两段；导体**内部**保留一条向右灰箭头 | 看导体内部那条向右箭头——驱动电子的原因；两端干净无电荷 | 导体中的自由电子受电场力 |
| S3 | 2.4–5.0s | 内部出现青色箭头（电子定向移动）向左；左端浮出 2 个蓝"−"、右端浮出 2 个红"+" | 只盯青色箭头 + 两端刚冒出的 ± 符号 | 自由电子在电场力作用下发生定向移动，导体两端出现感应电荷 |
| S4 | 5.0–7.4s | 紫色向左箭头从短到长（表示感应电荷的电场增强）；青色箭头同步变短、变淡（电子在减速）；± 增至 3 对 | 看紫色箭头"长"、青色箭头"缩"——两者此消彼长 | 感应电荷产生的电场与外电场方向相反，逐渐增强 |
| S5 | 7.4–9.0s | 灰右箭头与紫左箭头**等长反向**，青色箭头消失；导体中央浮出"E 合 = 0"；两端 ± 定格 | 看两条等长反向的箭头 + 电子箭头消失这一刻 | 当导体内部合电场强度为零时，自由电子不再定向移动，导体达到静电平衡 |

### 配色语义（全片一致）

- **红 ＋／蓝 −** 为电荷
- **灰箭头 ＝ 外电场**
- **紫箭头 ＝ 感应电荷的电场**
- **青箭头 ＝ 电子定向移动**

### 已锁定的约束

1. 只画净电荷，导体内部不出现任何中性的正离子/自由电子背景点。
2. 所有 ± 符号画在导体轮廓内侧（内缩约 14px），一个都不越界。
3. 两端电荷数量始终相等（等量异种），画面里可以数得出来。
4. 全程无旁白、无解说字幕，只有"导体尚未进入"和"E 合 = 0"两处标注。

### 首轮方案中主动交代的两处"教材级简化"

1. **导体内部保留外电场箭头**，是为了让"两个场抵消"看得见。严格讲导体放入后外电场本身会畸变，但高中不讲，S2 那条灰箭头只是"外电场"的示意。
2. **外部场线在导体两侧被截断**，不画导体外部的感应场畸变。教材只要求"导体内部场强为零"，外部不管。

### 首轮的待定事项

| # | 事项 | 首轮建议 |
|---|---|---|
| P1 | 输出格式 | MP4（H.264，插 PPT 最稳）＋ 可选 GIF 循环版 |
| P2 | 画面比例/分辨率 | 16:9，1920×1080 |
| P3 | 电子移动的表示 | 用青色方向箭头（不画电子圆点） |
| P4 | S1 是否保留 | 保留，删掉可压到 8.0s |
| P5 | 是否画带电平行板 | 建议画 |
| P6 | 节奏 | 9.0s 偏紧，S3 只占 2.6s，可放宽到 12s |

## 三、首轮方案被否定的部分

| 首轮做法 | 否决理由 |
|---|---|
| 以青色箭头代表自由电子 | 不能"只用箭头代替"，必须跟踪带"−"号的小球向左移动 |
| 两端净电荷用带圆圈的符号 | 应改为**不带圆圈**的正负号 |
| 提出"外电场本身会畸变"的说法 | 该教学模型不采用此说法，须删去 |
| S1 导体从画面外滑入 | 改为从"已放入、尚未迁移"的起点开始 |
| 青色箭头随迁移"变短变淡" | 改由外场箭头恒长、感应场箭头渐长来表达，不使用"电子减速抖动"以外的附加语义 |
| 前版把外场与感应场线段拼接的读法 | 明确禁止把两种场拼成一条总场线 |
| "电子静止"的表述 | 改为"不再定向移动" |
