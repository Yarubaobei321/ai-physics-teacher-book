## 一、修改要求原文

> 先改脚本，再按下面的改法制作。
>
> **第一处：** 不要只用青色箭头代替自由电子，请跟踪三颗带"−"号的小球向左移动；这些是迁移示意，不是中性背景。两端净电荷用不带圆圈的正负号，始终成对等量；正号只在右端出现，不移动。
>
> **第二处：** 把"外电场本身会畸变"的说法删去。这个教学模型把给定外电场 E₀ 保持不变，感应电荷贡献 E′，变化的是合场；不要把两种场的线段拼成一条总场线。导体不必从画面外滑入，从已经放入、尚未迁移的起点开始。外场箭头始终向右、长度不变，感应场向左逐渐增强，到两者等长再停止定向迁移；显示"不再定向移动"，不写电子静止。净电荷在表面金属一侧，电子路径始终在导体内。加"过程示意，时间与位移经放大"。保持 9 秒、16:9、无声。
>
> 请制作独立、离线可打开的 HTML 动画，提供播放/暂停、重播、0—9秒时间滑块，以及"起点""迁移""平衡"三个定格按钮。并导出 1920×1080 MP4。只在以下目录保存：`/Users/yaril/个人文档/3 写作/图书出版/00_这本书的全部进展/编务/补图与整书更新-20261015/WorkBuddy动画`。把首轮分镜原文、这次修改要求和最终脚本另存为 markdown；文件名用中文，正文不要写其他 AI 工具品牌。不读取或改写其他项目，不安装新工具，不发布。若视频导出暂不可用，先完成 HTML 和记录，准确说明。

## 三、修改后新增/变更的关键设定

| 项目 | 首轮 | 本轮定稿 |
|---|---|---|
| 自由电子的表现 | 1 条青色方向箭头 | 3 颗带"−"号的小球，水平向左平移 |
| 电子的"减速"表达 | 青色箭头变短变淡 | 取消；小球的减速由位移—时间曲线本身表达 |
| 两端净电荷 | 带圆圈的 ± 符号 | 不带圆圈的正负号，纯字形 |
| 左端符号 | ＋ 与 − 都可能出现 | 只出现"−" |
| 外电场 E₀ | 灰箭头，隐含"会畸变"的说明 | 灰箭头，长度恒定为 380 px，删去畸变说法 |
| 感应场 E′ | 紫箭头，长度增长 | 同，但明确与 E₀ 分带绘制，禁止拼接 |
| 起点状态 | 导体从画面外滑入 | 导体已在位，从"尚未迁移"起 |
| 平行板 | 建议绘制 | 不绘制。原因：给定外电场 E₀ 是本模型的输入，画极板会在画面左侧引入"＋"号，与"正号只在右端出现"冲突 |
| 平衡文案 | "E 合 = 0" | 增补"自由电子不再定向移动" |
| 位移注记 | 无 | 新增"过程示意，时间与位移经放大" |
