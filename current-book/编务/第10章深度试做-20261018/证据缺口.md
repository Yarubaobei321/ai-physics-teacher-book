# 第 10 章证据缺口

本次候选已经完成；下列缺口限制结论，不以润色补齐。这里的“下一步”均为建议，尚未实施，也未联系或发送给任何人。

| 缺什么 | 为什么影响结论 | 怎样补；需要谁 |
| --- | --- | --- |
| 教师平行板照片所对应的单槽、同时段、带负载端电压 | 无法给出当时准确的总界面及接触压降，其他槽读数不能代填 | 作者查原始记录；若没有，明确历史缺失，另做带时间记录的新实验，不能补称为旧实验 |
| 同一探针往返读数、两探针同点零偏、仪表型号与输入电阻 | 无法量化探针漂移、分流和零示误差 | 作者或实物持有者补测；记录仪表精度、浸入深度、顺序与时间 |
| 水深分布、原照标尺/四角误差、环中心取点重复性 | 现有标准差与回归误差不构成完整不确定度；48.0/51.1 mm 的差异不能归因于倾斜 | 补测水深与调平条件、重复独立取点；现有记录只支持部分统计误差 |
| 两侧界面压降的分别测定 | 普通金属探针单个读数不能区分电极与探针的界面项 | 需要适当参比电极与电化学测量设计；由具备实验条件者评估，不在本章代为实施 |
| 三份学案前测填写时间与清晰原始预测图 | A/B 空白或浅笔迹不能判为不会画；E 的预测不能自动当作严格课前基线 | 作者查已留照片或纸件；不联系学生补写、不补造旧预测 |
| 不等差题的完整前后理由、独立迁移题 | 现有三份后测只写“不能”，不能证明概念理解增加 | 下一次教学保留同题解释及新情境解释；作者实施并保留原件。不能用事后访谈替换当时的作答 |
| 预测底图独立贡献的课堂记录 | 学案包含印刷参考图，学生测点可能受图形引导；无法区分水槽、底图和教师追问的作用 | 先独立预测/测量再叠图，保留各阶段产物；如要作因果主张，还需恰当研究设计 |
| 电势/等势面学生迷思研究的直接原文 | 本地检索未找到直接诊断证据，不能把器材论文写成学习研究 | 后续定向检索一手研究并读原文，核对对象、任务、样本；本次已明确未找到，不延长为全领域研究 |
| 作者本人当场发现、判断并纠正 AI 错误的具体经历 | 网格、箭头、闭合圈现有记录来自 AI 协作复查，不能改写为作者亲历 | 仅作者本人能补真实事件及当时对话、截图等；没有就维持现在的归属表述 |
| 底图 B 的正式修图裁决与新图 | 原图的方向线可能误导弱场判断，目前仅改候选图注 | 作者决定是否修改；本轮不改印刷底图、不替换配套文件 |
| 新写读数解释和匿名学案摘录的入书裁决 | 独立候选不等于作者已接受新的解释或采纳原始证据 | 作者审读；需要对外使用扫描图时另行核对授权与脱敏，本次只呈现匿名文字 |
