# 教师参考资料包

这是2026-10-02演示完成后的网页与代码，不需要依赖作者的原域名。

网页站点/index.html 是首页；第二版 /online-lab/motion-ultrasonic/ 已增加速度—距离图，第一版 /online-lab/motion-compare/ 保留。两个页面均可设置1～60秒，重复试次并限定显示时间范围。烧录页 /online-lab/motion-ultrasonic/flash/ 可选择第一版v10或第二版v11.1，适用经典ESP32、4MB闪存，不适用于C3/S3。

把此文件夹作为WorkBuddy工作目录，请它先说明文件、启动本机HTTP预览，给出localhost地址；网页根目录应指向“网页站点”。不要只双击HTML。具体提示词与复做步骤见旁边文件。

固件源码保留main.cpp、头文件、platformio.ini等；网页内firmware目录保存编译后的bin和校验清单。改图不用烧录。改传感器或采样程序则需编译、核对板型、烧录、实物验证。

蓝牙名称 Motion-Ultrasonic，仅第二版有蓝牙。USB115200。GPIO及电源表在测量页和烧录页列出。先断电接线，HS-SR04P的TRIG25/ECHO26，DHT11 DATA27，OLED SDA21/SCL22；第一版激光共用21/22，第二版蜂鸣器S32。普通5V HC-SR04 ECHO不得直连ESP32，蜂鸣器电源按实际模块额定值核对。

练习数据是真实保存记录：蓝牙数据来自2026-10-01，本机和线上USB来自2026-10-02。可在第二版导入JSON；其中存在明显波动和大残差，仅供功能复核，不把它们当作已经校准的匀速运动。原始记录不修改。
