# 随书配套材料

本包对应《序言　不会编程的物理老师，能用 AI 做成什么》与现行23章正文。先解压整个文件夹，再打开本页。各章材料按现行章号排列。

- [阅读新序言（含四张配图）](序言.html) · [序言Markdown](序言.md)
- [查看用途、数据性质与打开方法](配套文件索引.html)
- [极板移动前后的电势变化：电表放大版](第11章/电势变化-电表放大.html)

单文件网页可用 Chrome 或 Edge 打开。第8章课堂示例保留整个文件夹的目录关系；第20章先解压《测速网页起步包.zip》，把解压目录交给 WorkBuddy，在本机网页服务中打开。连接蓝牙或USB时须使用实际设备与相应浏览器权限。

实测、历史记录、构造数据与模型计算在各页或说明中标明。第11章自动候选点仍需逐点核对；第18章打印文件的狭缝是设计值，读谱图的波长是估算；第19章圆环模型尚未完成实体打印与入水验证，超声波模块从实拍建模的工程含照片估计尺寸。第9章9秒静电平衡动画是操作示范；第13章观察片由2023年原始实验片剪成，读数未补画；新序言提到的课堂动画和网站内容，请结合正文与配套索引访问。
