# 第06章 · 视重（构造数据）— 参数与算法说明

> 数据身份：**构造数据，非实测**。不是严力耕老师装置的原始数据，也不是新一次真实测量。

## 构造参数
- m = 0.5 kg，g = 9.8 m/s²，向上为正
- t_i = i×0.01 s，i=0…300（共 301 点），fs = 100 Hz
- 理想加速度 a：0.50≤t<1.00 → +1.00；2.00≤t<2.50 → −1.00；其余 → 0
- F_ideal = m(g+a)；F_raw = F_ideal + 0.05·sin(40πt)（**20 Hz 人为正弦干扰**）

## 滤波算法
- 类型：**二阶巴特沃斯低通**（Butterworth, order 2）
- 实现：RBJ 双二次（biquad）低通，Q = 1/√2，双线性变换预畸变（fc 预畸变角 w0 = 2πfc/fs）
  - fc=4Hz：b=[0.01335920, 0.02671840, 0.01335920]，a=[1, -1.64745998, 0.70089678]
  - fc=2Hz：b=[0.00362168, 0.00724336, 0.00362168]，a=[1, -1.82269493, 0.83718165]
- 单次前向（实时）：y[n]=b0x[n]+b1x[n−1]+b2x[n−2]−a1y[n−1]−a2y[n−2]，**稳态初值**（以首个样本 x[0] 的直流稳态出发，避免 4.9 N 直流被当成 0 起步的假暂态）
- 前后向零相位：前向 → 反转 → 同一次前向 → 反转；两次前向各用自己的稳态初值
- 端点处理：两端用稳态初值，故起止处暂态很小；**未**采用 scipy 的奇延拓，边缘仍会有轻微差异；前后向为非因果（零相位）
- 幅频响应：单次前向为 |H(f)|（二阶，−12 dB/oct）；前后向为 |H(f)|²（等效四阶，−24 dB/oct）；**两者不同**

## 20 Hz 干扰处的幅频响应（解析值）
| fc | 单次前向 \|H\| | 前向 dB | 前后向 \|H\|² | 前后向 dB |
|---|---|---|---|---|
| 4 Hz | 0.039968 | -27.97 | 0.001597 | -55.93 |
| 2 Hz | 0.010000 | -40.00 | 0.000100 | -80.00 |

## 加速度与积分
- a = F/m − g；梯形积分用**实际时间**步长，v0 = 0；**不强行**让末速度归零。
