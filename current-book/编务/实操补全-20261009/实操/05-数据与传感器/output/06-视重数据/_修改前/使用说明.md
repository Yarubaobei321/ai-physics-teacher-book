# 第06章 · 视重（构造数据）— 使用说明

## 数据身份（重要）
- **构造数据，非实测**。**不是**严力耕老师装置的原始数据，**也非**本轮真实测量。
- 图像全部是**数据图**（力/加速度/速度曲线），**不生成任何实验装置照片**。
- 真实力/加速度硬件本轮**未连接**。

## 入口
打开 `分析页.html` → 三张图分别勾选要看的曲线 → 下方查看实际统计与幅频响应。

## 构造（严格照 `synthetic-definition.md`）
- m=0.500 kg，g=9.80 m/s²，向上为正；t_i=i×0.01 s，i=0…300（301 点，fs=100 Hz）
- 0.50≤t<1.00 → 理想 a=+1.00；2.00≤t<2.50 → 理想 a=−1.00；其余 → 0
- `F_ideal = m(g+a)`；`F_raw = F_ideal + 0.05·sin(40πt)`（**20 Hz 人为正弦干扰**，非随机）

## 滤波（自实现二阶巴特沃斯低通 biquad）
- RBJ 双二次低通，Q=1/√2，双线性变换预畸变；系数见 `参数说明.md`。
- **单次前向（实时，因果）**：差方程 + **稳态初值**（以 x[0] 的直流稳态出发）。
- **前后向零相位**：前向 → 反转 → 再前向 → 反转；两次各用稳态初值；**非因果**、不能实时。
- 端点：两端稳态初值，暂态很小；未用 scipy 奇延拓，边缘仍有轻微差异。
- **幅频响应不同**：单次前向 `|H(f)|`（二阶，−12 dB/oct）；前后向 `|H(f)|²`（等效四阶，−24 dB/oct）。

## 加速度与积分
- `a = F/m − g`；梯形积分用**实际时间**，`v₀=0`；**不**强行让末速度归零。

## 实际结果（由 `分析程序.py` 运行得到）
力区间均值 (N)：

| 信号 | 静止 | +1平台 | −1平台 |
|---|---|---|---|
| 理想 / 原始 | 4.9000 | 5.4000 | 4.4000 |
| 4Hz 单次前向 | 4.9002 | 5.3440 | 4.4560 |
| 4Hz 前后向 | 4.9001 | 5.3720 | 4.4280 |
| 2Hz 单次前向 | 4.9001 | 5.2873 | 4.5127 |
| 2Hz 前后向 | 4.9004 | 5.3443 | 4.4557 |

加速度平台幅值（理想 ±1.00）：4Hz 前向 0.888 / 4Hz 前后向 0.944 / 2Hz 前向 0.775 / 2Hz 前后向 0.889。
∫a dt 与末速度 v(T) 均接近 0（量级 10⁻³~10⁻⁴），**未做归零校正**。

20 Hz 干扰处的解析幅频响应：4Hz → 前向 −27.97 dB、前后向 −55.93 dB；2Hz → 前向 −40.00 dB、前后向 −80.00 dB。
