# 第06章 · 视重（构造数据）— 参数与算法说明

> 数据身份：**构造数据，非实测**。不是严力耕老师装置的原始数据，也不是新一次真实测量。

## 构造参数
- m = 0.5 kg，g = 9.8 m/s²，向上为正
- t_i = i×0.01 s，i=0…300（共 301 点），fs = 100 Hz
- 理想加速度 a：0.50≤t<1.00 → +1.00；2.00≤t<2.50 → −1.00；其余 → 0
- F_ideal = m(g+a)；F_raw = F_ideal + 0.05·sin(40πt)（**20 Hz 人为正弦干扰**）

## 滤波算法与初始化
- 类型：**二阶巴特沃斯低通**（Butterworth, order 2）
- 实现：RBJ 双二次（biquad）低通，Q = 1/√2，双线性变换预畸变（w0 = 2πfc/fs）
  - fc=4Hz：b=[0.0133592000, 0.0267184001, 0.0133592000]，a=[1, -1.6474599811, 0.7008967812]（DC 增益 1.000000000000）
  - fc=2Hz：b=[0.0036216815, 0.0072433630, 0.0036216815]，a=[1, -1.8226949252, 0.8371816513]（DC 增益 1.000000000000）
- 单次前向（实时，因果）：y[n]=b0x[n]+b1x[n−1]+b2x[n−2]−a1y[n−1]−a2y[n−2]；
  **稳态初值**：x[-1]=x[-2]=x[0]，y[-1]=y[-2]=x[0]·DC增益。
  含 4.9 N 静重的力若用**全零初值**，会人为制造近 −g 的启动暂态（伪影），本程序不使用。
- 前后向零相位：前向 → 反转 → 同一次前向 → 反转；两次各用自身稳态初值；非因果、不能实时。
- 端点处理：两端稳态初值，暂态很小；**未**采用 scipy 的奇延拓。
- 恒定力自检：对恒定 4.9 N×301 点跑同一套滤波器，结果见 `统计与检查.md`。

## 幅频响应（按实际离散传递函数 H(e^{jω}) 计算）
`H(z)=(b0+b1 z⁻¹+b2 z⁻²)/(1+a1 z⁻¹+a2 z⁻²)`，单次前向 = `|H(e^{jω})|`，前后向 = `|H(e^{jω})|²`（等效阶数翻倍）。**不是**模拟域公式 `1/√(1+(f/fc)⁴)`。

| fc | 单次前向 \|H\| | 前向 dB | 前后向 \|H\|² | 前后向 dB |
|---|---|---|---|---|
| 4 Hz | 0.0302195674 | -30.39 | 0.0009132223 | -60.79 |
| 2 Hz | 0.0074984158 | -42.50 | 0.0000562262 | -85.00 |
## 统计区间
按运动状态划分，**左闭右开**（最后一段右端含 3.00 s）：
- 起始静止：0 ≤ t < 0.5
- 正加速：0.5 ≤ t < 1
- 匀速：1 ≤ t < 2
- 负加速：2 ≤ t < 2.5
- 结束静止：2.5 ≤ t ≤ 3
平台内部**观察窗口**（取中段以避开边沿，非真值）：
- 正加速平台内部：0.7 ≤ t < 0.9
- 负加速平台内部：2.2 ≤ t < 2.4

## 加速度与积分
- a = F/m − g；梯形积分用**实际时间**步长，v0 = 0；**不强行**让末速度归零。
