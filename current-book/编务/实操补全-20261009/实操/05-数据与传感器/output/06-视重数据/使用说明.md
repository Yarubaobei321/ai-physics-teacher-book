# 第06章 · 视重（构造数据）— 使用说明

## 数据身份（重要）
- **构造数据，非实测**。**不是**严力耕老师装置的原始数据，**也非**本轮真实测量。
- 图像全部是**数据图**（力/加速度/速度曲线），**不生成任何实验装置照片**。
- 真实力/加速度硬件本轮**未连接**。

## 入口
打开 `分析页.html` → 三张图分别勾选要看的曲线 → 下方查看实际统计与幅频响应。

## 构造（严格照 `synthetic-definition.md`）
- m=0.500 kg，g=9.80 m/s²，向上为正；t_i=i×0.01 s，i=0…300（301 点，fs=100 Hz）
- 0.50≤t<1.00 → 理想 a=+1.00；2.00≤t<2.50 → 理想 a=−1.00；其余 → 0
- `F_ideal = m(g+a)`；`F_raw = F_ideal + 0.05·sin(40πt)`（**20 Hz 人为正弦干扰**，非随机）

## 滤波（自实现二阶巴特沃斯低通 biquad）
- RBJ 双二次低通，Q=1/√2，双线性变换预畸变；系数见 `参数说明.md`。
- **单次前向（实时，因果）**：差方程 + **稳态初值**（x[−1]=x[−2]=x[0]，y[−1]=y[−2]=x[0]·DC增益）。
  含 4.9 N 静重的力若用**全零初值**会人为制造近 −g 的启动暂态（伪影）；本程序不使用全零初值。
- **前后向零相位**：前向 → 反转 → 再前向 → 反转；两次各用稳态初值；**非因果**、不能实时。
- 端点：两端稳态初值，暂态很小；未用 scipy 奇延拓，边缘仍有轻微差异。
- **幅频响应不同**，且按**实际离散传递函数**计算：`H(z)=(b0+b1z⁻¹+b2z⁻²)/(1+a1z⁻¹+a2z⁻²)`，z=e^{jω}；单次前向 `|H(e^{jω})|`，前后向 `|H(e^{jω})|²`（等效阶数翻倍）。**非**模拟域公式。

## 加速度与积分
- `a = F/m − g`；梯形积分用**实际时间**，`v₀=0`；**不**强行让末速度归零。
