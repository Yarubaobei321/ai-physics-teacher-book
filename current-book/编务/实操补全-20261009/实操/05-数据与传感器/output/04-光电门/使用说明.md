# 第04章 · 光电门记录导入工具 — 使用说明

## 数据身份
- 内置样例来自 `input/04-光电门/*-examples.txt`，均标 **构造检查样例，非实测**。
- 本页**不连接实物、不烧录、不安装、不发布**。

## 文件
| 文件 | 说明 |
|---|---|
| `index.html` | 单文件离线工具：蓝牙 8 字节 / USB 文本导入、记录表、CSV 导出、连接按钮（未接实物） |
| `检查结果.md` | 对本目录两个样例的实际解析核对结果 |

## 入口
打开 `index.html` → 选【蓝牙 8 字节通知】或【USB 串口文本】→ 点【载入样例】或粘贴内容 → 【解析并追加】→ 查看【记录表】→ 【导出 CSV】。

## 两种来源的区别（关键）
| | 蓝牙 ESP32-gate | USB 串口文本 |
|---|---|---|
| 内容 | 8 字节=速度(f32 LE)+设备时间(f32 LE) | 速度、设备时间、两门时间差(us) |
| 原始时间差 | **无**（留空，注明“未发送”） | 有（us） |
| 设备序号 | **无** | **无** |
| 网页复算速度 | 不可（没有 Δt） | 可用 `L / Δt`，另列，不改固件原值 |
| 数据身份 | 逐行标注，见下 | 逐行标注，见下 |

## 数据身份（逐行，不一律标样例）
- 点“载入样例”后解析 → **构造检查样例，非实测**；
- 自行粘贴/编辑输入框后解析 → **用户导入，未标注为实测**；
- 蓝牙实时通知 → **实时蓝牙，未标注为实测**。
记录表与导出 CSV 都带“数据身份”列，避免把自行导入的数据误标成样例。

## 规则
- 网页行号 = **接收顺序**，不是设备序号。
- 设备时间**回退** → 另起记录段。
- **相同包** → 只标“疑似重复”；判定比较**来源 + 规范化原始字节/文本 + 全部包字段**（速度、设备时间、时间差），**不只看速度与时间**——例如 USB `speed=1.25, time=12.5` 但 Δt=8000 us 与 4000 us 是**不同包**；仅全角/半角、空格等格式差异视为同一包。
- 无设备序号 → **不能**声称检测全部丢包。
- 每行保留导入**当时**的 L（默认 0.01 m = 固件 `GATE_DISTANCE_M`）；改 L 不重写历史行。
- **L 必须为正的有限数**；L 为空 / 0 / 负数 / 非有限时，**拦截本次导入与蓝牙连接回调**：不追加任何记录，原有记录保持不变，并给出提示。
- **拒绝**：错误字节长度、非十六进制、非有限数、非正的时间差。

## 连接按钮
按 `protocol.md` 的 UUID（服务 `cddf0001-…`、数据 `cddf1001-…`、通知 `cddf1002-…`）与 8 字节格式实现，**但本轮未连接实物、未验证**；`file://` 打开时 Web Bluetooth 通常不可用。

## 其它协议提醒（未在本页实现）
- 单头 `ESP32-sgate` 同为 8 字节，但语义是“遮光时间 s、设备时间 s”。
- 双 `ESP32-2gate` 为 16 字节（门号、速度 m/s、时间差 s、设备时间 s）。
- **不能**因为长度相同就混用；源码不等于现场板固件身份。

## 已验证 / 未验证
- **已做**：用 Node 运行页面内实际解析逻辑，核对了两个样例的全部行、错误长度行被拒绝、时间回退另起段、相同包标疑似重复、拒绝用例（错误长度/非十六进制/非正 Δt/非有限数）。
- **已做**：核对 L 拦截——L 取 `""` / `"0"` / `"-0.01"` / `"abc"` / `"1e999"` 时导入被拦截、行数与旧记录完全不变；恢复 0.01 后可正常导入；连接回调在 L 无效时返回错误且不入库。
- **已做**：核对重复包判定——相同 USB 行→标疑似重复；同 speed/time 但 Δt 8000/4000 us→**不标**；仅全角/空格差异→标；相同 BLE 十六进制（大小写不同）→标；不同 BLE→不标。
- **已做**：核对逐行数据身份——样例解析标“构造检查样例，非实测”，手动粘贴标“用户导入，未标注为实测”，CSV 身份行与逐行身份列一致。
- **未做**：未连接任何硬件、未在真实浏览器点击导入/下载、未验证连接按钮与真实设备通信。
