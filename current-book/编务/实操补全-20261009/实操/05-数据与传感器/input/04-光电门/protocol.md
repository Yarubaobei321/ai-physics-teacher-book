# 双头光电门实际协议与本次任务

来源：当前数智育才网站源码 programmingTemplates.ts 的 double-gate-speed 模板、photogate-protocol.ts、phyphox.ts 及 docs/dis-ble-devices.md。本次未连接实物，源码不等于现场板上固件身份。

双头名称前缀 ESP32-gate，默认 ESP32-gate01；固件间距 GATE_DISTANCE_M=0.01m；左右门GPIO26、25。蓝牙通知恰含两个32位小端浮点数（8字节）：速度m/s、设备时间s。没有原始时间差、没有设备事件序号。

数据服务UUID：cddf1001-30f7-4671-8b43-5e40ba53514a；通知特征：cddf1002-30f7-4671-8b43-5e40ba53514a；实验服务：cddf0001-30f7-4671-8b43-5e40ba53514a。

USB串口文本含：速度是 [number] m/s，时间是 [number] s，两门时间差是 [number] us。保存原文；微秒除以1000000得到秒。网页可用独立输入L除以原始时间差，另列网页复算速度。固件速度仍保存原值。

设备时间是两束光触发时刻的平均值，不是浏览器接收时间。单头ESP32-sgate同为8字节却是“遮光时间s、设备时间s”；两双头ESP32-2gate是16字节“门号、速度m/s、时间差s、设备时间s”。不能按长度相同就混用。

当前只完成双头样例导入和数据表，可实现连接按钮但不要连接实物。双头蓝牙行Δt留空，禁止用L/v倒算冒充测得的时间。无设备序号时不能准确报告丢包数。网页行号只是接收顺序；相同包标疑似重复，时间回退另起段。每行保存当时L，不随输入改变历史值。样例始终标“构造检查样例，非实测”，输出CSV保留来源、原文/原始字节、参数快照、原值、计算值、提示。
