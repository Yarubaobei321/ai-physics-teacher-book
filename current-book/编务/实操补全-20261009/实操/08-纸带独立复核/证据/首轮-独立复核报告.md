## 0. 时间间隔 T 的独立判定（不照抄）

- 打点频率 f = 50 Hz → 每个打点周期 = 1/50 = 0.02 s。
- 原文条件：**相邻计数点之间还有 4 个计时点** → 相邻计数点之间被分成的打点周期个数 n = 4 + 1 = **5**。
- 计数点时间间隔 **T = n / f = 5 / 50 = 0.1 s**。

这一点是关键：题目说的是"之间还有 4 个**计时点**"（间隔点），不是"间隔 4 个周期"。因此 n = 5，T = 0.1 s。

## 1. 任务一：两组原始纸带数据的独立计算

位置单位 cm，计算前换算为 m（1 cm = 0.01 m）。速度 `v_k = (x_{k+1} − x_{k−1}) / (2T)`，时刻 `t_k = k·T`。

### 1.1 相邻段长（cm）

| 段 | 数据一 | 数据二 |
|---|---|---|
| s₁ = x₁−x₀ | 3.75 | 3.75 |
| s₂ = x₂−x₁ | 5.25 | 5.25 |
| s₃ = x₃−x₂ | 6.75 | 7.05 |
| s₄ = x₄−x₃ | 8.25 | 8.25 |
| s₅ = x₅−x₄ | 9.75 | 9.75 |
| s₆ = x₆−x₅ | 11.25 | 11.25 |

相邻段长差（连续性/均匀性检查）：数据一恒定 +1.50 cm；数据二为 +1.50, +1.80, +1.20, +1.50, +1.50 cm → 数据二在 s₃ 附近存在非均匀。

### 1.2 五点速度（m/s）与时刻（s）

| 速度点 | t (s) | 数据一 v (m/s) | 数据二 v (m/s) |
|---|---|---|---|
| v₁ | 0.1 | 0.450 | 0.450 |
| v₂ | 0.2 | 0.600 | 0.615 |
| v₃ | 0.3 | 0.750 | 0.765 |
| v₄ | 0.4 | 0.900 | 0.900 |
| v₅ | 0.5 | 1.050 | 1.050 |

### 1.3 v-t 最小二乘拟合 `v = k·t + b`（未加权 OLS，5 点等权）

| 量 | 数据一 | 数据二 |
|---|---|---|
| 斜率 k（= 加速度拟合值，m/s²） | **1.500** | **1.485** |
| 截距 b（m/s） | **0.300** | **0.311** |

- 数据一五点严格共线（残差全为 0），k = 1.500、b = 0.300 为精确值。
- 数据二非严格共线，k = 1.485、b = 0.3105（保留三位 0.311）。

### 1.4 六段分组逐差法加速度

`a = [(s₄+s₅+s₆) − (s₁+s₂+s₃)] / (9T²)`

| 量 | 数据一 | 数据二 |
|---|---|---|
| 分子 (s₄+s₅+s₆)−(s₁+s₂+s₃) | 0.135 m | 0.132 m |
| 9T² | 0.09 s² | 0.09 s² |
| a（m/s²） | **1.500** | **1.467** |

### 1.5 两种算法的对比

|  | 数据一 | 数据二 |
|---|---|---|
| 拟合斜率 k | 1.500 | 1.485 |
| 逐差法 a | 1.500 | 1.467 |
| 差值 | 0.000 | 0.018（≈1.2%） |

数据一两种方法完全一致（数据严格满足匀加速）；数据二出现约 0.018 m/s² 的偏差，来自 s₃ 的局部不均匀。

### 1.6 两种处理的「原始数据权重」说明（重点）

两种方法对 7 个位置的利用方式并不相同：

**（a）v-t 拟合**：先由位置算 5 个速度点，再对 5 个点做**等权未加权**最小二乘。
- 每个速度点 v_k 用到两个位置 x_{k−1}、x_{k+1}；
- 因此中间位置 x₁…x₅ **各被使用 2 次**（出现在相邻两个速度点里），端点 x₀、x₆ **各被使用 1 次**；
- 结论：拟合结果对 5 个速度点等权，等效上中间位置权重更高、端点权重更低。

**（b）六段逐差法**：虽然形式上列出 6 段，但代数上
`s₄+s₅+s₆ = x₆−x₃`，`s₁+s₂+s₃ = x₃−x₀`，相减后
`(s₄+s₅+s₆) − (s₁+s₂+s₃) = x₆ − 2x₃ + x₀`。
- 即逐差法**实际只用到 x₀、x₃、x₆ 三个位置**，权重为 (1, −2, 1)；
- 中间位置 x₁、x₂、x₄、x₅ **完全抵消、不参与**；
- 结论：它并非"平均使用六段"，而是把权重集中在中点与两个端点。

> 数值核对：数据一 x₆−2x₃+x₀ = 45−2×15.75+0 = 13.5 cm = 0.135 m，除以 9T²=0.09 → 1.500 m/s²，与上表一致；数据二 = 45.30−2×16.05+0 = 13.20 cm = 0.132 m → 1.467 m/s²，一致。

两种方法对同一段运动给出两个独立估计，权重分布不同，因此对数据局部不均匀的敏感度也不同。
