# 小车纸带记录页

给高一学生做“探究小车速度随时间变化的规律”的单文件离线网页。输入频率 f、相邻计数点间打点周期数 n 和七个计数点到 O 的位置 x0 至 x6（cm）。T=n/f。位置换成m后，点1至5的速度 vk=(x(k+1)-x(k-1))/(2T)，时刻 kT。给出 v-t 散点和最小二乘拟合直线、斜率与截距。另算六段逐差法 a=((s4+s5+s6)-(s1+s2+s3))/(9T²)。

默认不填位置数据，教师可以手动输入以下构造数据来检查，页面不应把它们冒充实测，也不要增加自动载入示例按钮。f=50Hz，n=5。
数据一(cm)：0,3.75,9.00,15.75,24.00,33.75,45.00。
数据二(cm)：0,3.75,9.00,16.05,24.30,34.05,45.30。

保留原始位置、相邻段长、五点速度与时刻；小组名、装置说明与结论由学生填写，不生成结论。计算输入变化立即撤下旧计算和图像，小组名或结论变动不影响计算。频率与周期数必须正值、周期数整数；空数不能按零处理；x0可为0，各位置严格递增，遇异常保留输入提示教师核对，不重排。不联网，不存账号，不发送数据。提供计算、清空、打印；打印长文字全部展开，显示完整单位、负号和图像。提供CSV导出原始数据与计算结果，只有数据有效且最新才允许导出。

请保存为 output/小车纸带记录页.html；样式与脚本全部内嵌。检验应从页面实际计算取得，未做浏览器或打印试验要如实说明。不要安装工具、发布或读取工作区外其他文件。
