# 附录 B　物理审核清单

这份清单把第 3 章的十种方法，按资源类型整理成可以逐项勾选的表。用的时候不必每项都做：先做“每次都做”的三项，再按资源类型选。

## 一、每次都做的三项

| 序 | 检查 | 怎样做 | 通过的标准 |
| --- | --- | --- | --- |
| 1 | 先算再看 | 打开结果前，自己算出一个关键状态，写下来 | 页面上这个状态的数值与手算一致 |
| 2 | 分清数据身份 | 对每个数、每部分图问一句：测的、算的、模型补的、演示用的？ | 每一类都能说清来源，演示数据标明“非实测” |
| 3 | 查检查本身 | AI 说“检查通过”时，问它检查了什么、怎样检查的 | 列出实际检查对象、方法和结果；独立预期不由待检程序自证，未运行部分单列 |

## 二、十种方法速查

| 方法 | 一句话 | 主要例子 |
| --- | --- | --- |
| 1 先算再看 | 先写预期，再看结果 | 第 2、8、12 章 |
| 2 推到极端 | 特殊值下应当发生什么，事先说得出来 | 第 8、14、15 章 |
| 3 单位和量纲 | 每个输入和结果都看一眼单位 | 第 2、7 章 |
| 4 看过程 | 用中心位移差分近似中间时刻速度，减小步长观察误差，跨事件另查 | 第 8 章 |
| 5 数据身份 | 测的、算的、补的、设定的分开 | 第 8、14、15 章 |
| 6 不完美的数据和反例 | 有意加一点偏差，或给一个应当失败的输入 | 第 2、14 章 |
| 7 物理上是否可能 | 在相同参考零点与边界条件下，越界拟合参数提示数据或模型待查 | 第 14 章 |
| 8 读“所以” | 数值对了，解释的因果未必对 | 第 8 章 |
| 9 一次只改一件事 | 改前保存，改后同条件比较 | 第 8 章 |
| 10 另一个 AI 独立复查 | 只给数据不给结论；请它计算不请它评价；教师比较 | 第 3、12 章 |

## 三、按资源类型

### 计算页面（纸带、光电门、机械能守恒：第 2、4、7 章）

- [ ] 用答案已知的“完美”数据试一次，结果全对
- [ ] 用一组有意加了偏差的数据试一次，看算法实际用了哪些数据
- [ ] 按量的有效范围检查输入：质量、周期等须为正；坐标或速度的零与负值可有物理意义；必填空白不得默认为零
- [ ] 改一个输入，旧结果立即撤下或随之更新
- [ ] 单位：cm 与 m、ms 与 s 的换算；不输入质量时，能量比较的单位不是焦耳
- [ ] 演示数据标明“非实测”
- [ ] 打印一份：长文字完整，表格不断开

### 传感器与采集网页（第 4、5、6、16 章）

- [ ] 静止时读数的波动有多大，先测一段再说
- [ ] 表格里分开“设备发来的”和“网页算出的”
- [ ] 横轴用设备时间还是网页收到的时间，要写明
- [ ] 断线、重复、缺失有可见提示，不用上一个值填补
- [ ] 滤波：方法、截止频率写明；原始数据保留；比较滤波前后起止时刻
- [ ] 核对积分与状态变化：加速度面积等于末初速度差，首末静止才接近零；充放电面积比较须对应相同电容器的同一对端电压，有限截段不能硬要求相等
- [ ] 在电脑的 Chrome 或 Edge 上实际连接一次，看到新读数

### 模拟动画（第 8、9、11 章）

- [ ] 先算再看：关键状态（最高点、共速、分离、最大压缩）的数值
- [ ] 关键状态之后继续播放，看物体是否按规律接着运动
- [ ] 极端参数：一方质量趋于无穷大、两者相等、速度为零
- [ ] 位移差分与相应中间时刻速度相符到离散误差范围；减小时间步后误差应减小，事件切换另查
- [ ] 画面、箭头、数字、曲线游标来自同一状态
- [ ] 箭头注明参考系；正负号与方向一致
- [ ] 预测模式下，数字、箭头、曲线、提示文字、核验表全部隐藏
- [ ] 切换参数后，旧曲线和旧结论清除

### 照片与图像（第 13、14、17 章）

- [ ] 逐点核对：图上每个标注点，回到原照片找到它
- [ ] 颜色和数值的对应写明
- [ ] 底图没有被拉伸、裁剪或重画
- [ ] 缺测处不当成实测补点；必要的辅助推连、插值或模型重建单独标明
- [ ] 识别出的点里有没有导线、夹子等误认
- [ ] 三维模型：资料是不是这一款；同角度和实物照片比较；丝印文字和位置

### 模型与拟合（第 12、14 章）

- [ ] 测的和模型算的，在图上和表里分开
- [ ] 拟合出的参数在物理上可能吗（例如无内部电源、同一参考零点的导电层模型中电势应处于给定边界范围内；越界先核对数据与模型）
- [ ] 删去可疑点后结果变化大不大
- [ ] 模型的边界条件和实际装置一致（绝缘槽壁、电极形状）

### 题旁模型（第 10、15 章）

- [ ] 题目给的条件和另加的教学设定分开标出
- [ ] 用原题参数回归：每一问的答案都能复现
- [ ] 轨迹和状态是按规律算出来的，不是按答案画的
- [ ] 改初始条件，结果的变化方向与物理推理一致
- [ ] 不合理的输入拒绝计算并说明原因

### 学生用 AI 做的网页（第 20 章）

- [ ] 仅限本机处理的学生原件不交云模型；云端练习使用独立自编材料
- [ ] 按钮和滑块：操作前后，进入计算的量真的变了
- [ ] 数据来源：测量、公式生成、随机、手动输入
- [ ] 同一次事件的初态和末态能同时看到
- [ ] 选一组非默认输入手算，与页面比较
- [ ] 发现问题时，退回到证据链最早失效的那一步

### 文字材料（学案、讲稿、说明、AI 的解释）

- [ ] 物理表述准确；依据是不是教材和课程标准
- [ ] “所以”“因此”前后是否真有成立的关系
- [ ] 文字和数据、图像是否一致
- [ ] 课本图样（例如无限空间中的等势线）是否被照搬到不同的边界条件下

### 发布之前（第 19 章）

- [ ] 发布清单已逐项确认，不含未获授权的学生材料、私人笔记、账号密钥或不需公开的资料
- [ ] 当前版本已保存，能退回
- [ ] 换一台设备打开公开链接
- [ ] 更新后回原链接刷新，确认是新版

## 四、请另一个 AI 复查时

1. 新开一个任务，可以换一个模型。
2. 只给原始条件和原始数据，不给第一个 AI 的结论和审核页。
3. 请它计算具体的量，不请它评价“对不对”。
4. 两份结果由教师比较。一致不等于对；不一致时，回到物理上找原因。
