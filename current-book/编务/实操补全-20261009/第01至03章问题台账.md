| 第01章第三节“AI只在这个文件夹里读写，不会碰到其他文件” | 工作空间是主要文件组织与默认位置，不是绝对访问隔离。官方任务栏说明工作空间外仍可能经权限执行；完全访问还会对客户端各任务生效。 | 改为“把材料和成果集中在独立文件夹，便于看清处理范围；实际访问由权限设置与授权控制，工作空间不能替代备份和访问限制。” |
| 第01章第一节“网页、文档、图片…双击就能打开”与第02章开头“单文件离线” | 单个不依赖外部资源的普通HTML可以本地打开；蓝牙页、模块脚本、本地读取资源或外部依赖另有条件。当前句话泛指全部文件，后续硬件页易误用。 | 改为“生成的文件保存在其中；普通单文件网页可用浏览器打开，涉及蓝牙等功能按对应章用localhost或HTTPS访问并核对浏览器支持。” |
| 第01章第一节“任务的大小都在一两个晚上之内”；第五节“每个都能在一小时内做完” | 全书有硬件安装、打印、实物试用和拟合。不能保证所有读者此时限完成。 | 去掉必然时限，写“先做一个有明确输出的小任务，硬件和实物验证另留时间”。 |
| 第01章第四节“只有物理教师才能做”“每一次都是物理教师看出来”“都没有报错” | 绝对化归因不受全部案例支撑；有些是协作发现、脚本或独立检查暴露。 | 保留教师负责条件与采用判断，改为“需要物理教师参与判断”“这些问题在后续核对中被发现”，按真实作者原话保留具体案例。 |
| 第01章成品图注“300 mm水槽” | 第12/14章本轮有限模型采用内口294mm；300为外廓可能引起尺寸冲突。 | 图注明确“约300mm外廓（计算内口294mm）”，或只说有限水槽。 |
| 第02章“每隔4个点…”和正文多处“误当成4个周期” | 口语存在计点歧义，不宜要求读者猜“隔”包括几个端点。当前本轮真实反馈已改“相邻计数点间隔5个打点周期”。 | 全章示例优先写“相邻计数点之间还有4个计时点，共5个周期，T=0.1s”；书面约定始终n为周期数。 |
| 第02章第二/第三/五节瞬时速度公式 | 对匀变速直线运动，中间时刻速度等于这段平均速度；一般运动仅是短时间近似。实验正要探究是否匀变速，应说清近似层次。 | 首次公式旁加“用中心两段的平均速度近似该计数点瞬时速度；匀变速时该关系严格成立”。 |
| 第02章第四节与例2“六段全部用上”“用上的测量数据越多，单个测量误差的影响越小” | 段长形式使用多段不等于原始位置测量都独立参与。按本章累计位置输入，逐差式可化为(x6−2x3+x0)/(9T²)，其他位置抵消；误差相关性和权重决定精度，不能仅数数据个数。 | 保留选项D和化简比较，但收紧为“在本题规定的测量与误差条件下，分组逐差使用较长间隔并抵消部分中间项，是教材采用的较优处理；不能推广为所有测量误差必然更小”。本章页面同时列v-t拟合，说明两法权重不同。 |
| 第02章例1“把五个点交给记录页做最小二乘拟合” | 本章记录页固定输入位置并拟合瞬时v-t，不收题中的平均速度—时间点。这句可能诱导误操作。 | 改“另用表格或计算程序对这五个平均速度点拟合”，不声称本章既定页面已有通用拟合入口。 |
| 第02章例2末“先用检查数据二分别按A和D计算” | 真题A/D是8段公式，检查数据二只有6段，照抄公式缺s7/s8。 | 写“先按第四节六段对应的首末段法和分组逐差法比较，再迁移到这道八段题”。 |
| 第03章第三节“故意把n默认值改错” | n=4本身是合法条件；页面按T=4/f正确重算不是算法故障，若无明确原纸带周期证据，AI不应擅自判错或改回5。 | 不用“改默认n”冒充埋程序错。可用已声明纸带间隔与页面标签不一致的独立练习，或直接沿用真实纠正与两组数据核查。 |
| 第03章第四节2“电容器两板距离加倍，固定点的电势差应当减半…” | 缺保持电压/电荷、参考板、点是否仍在板间和哪两点固定。不同条件结论不同。 | 加“忽略边缘效应、恒压、参考板固定且点仍在板间；固定空间两点的电势差按1/d变化，固定相对板距比例两点的电势差不变”。 |
| 第03章第四节2“等量同种…沿连线最低、沿中垂线最高” | 适用于等量正点电荷且在中点附近；负电荷极值方向相反；沿连线跨电荷奇点不可说全域最低。 | 写“等量正点电荷，中点附近沿连线局部极小、沿中垂线局部极大”。 |
| 第03章第四节4“相邻位移除时间差和程序速度比较” | 前者为区间平均速度，后者可能是端点瞬时速度，直接要求相等会误报。 | 改为中心差分与中间时刻速度比较，逐步减小时间步观察误差收敛；跨碰撞/分离事件单独处理。 |
| 第03章第四节7“水槽里不可能…说明不是测量偏一点…问题出在水层导电能力不均匀” | 当前第14章候选已收紧。拟合越界只能提示数据/端电压/模型至少一项待查，不能唯一归因于水层不均。 | 同步第14章：均匀无内部电源模型中电势受边界约束；越界有效参数需复核，水层不均只是与形状差异相容的一种解释。 |
| 第03章第四节10“等量异种…等势线确实都围住某一个电荷” | 零电势的中垂面（截面为直线）是反例；有边界与三维/二维差异。 | 加“无限空间理想等量异种点电荷的非零等势线”，具体U/3、2U/3仍按有限槽模型判断。 |
| 第03章例题解析“合力指向轨迹弯曲内侧” | 合力还可有切向分量；严格是法向分量指向曲率中心。课本判断用法应避免理解为合力总沿法线。 | 改“合力在法向上的分量必须指向轨迹凹侧；把电场力分解到法向即可排除指向凸侧的图”。 |
