## 模型与限制

本页使用用于解释主要经过过程的单峰有效磁通近似，并非完整的磁场求解。

设顺时针转角为θ，θ=0为磁铁与线圈正对。采用：

- `f(θ) = exp[−(1−cosθ)/σ²]`，`σ=0.55`；
- 单匝磁通量 `Φ(θ)=Φ₀ f(θ)`；
- `θ(t)=−π/2 + ωt`，`ω=2πr/60`；
- `ℰ = −N Φ₀ ω f′(θ)`；
- 图中显示`Φ/Φ₀`与`ℰ/ℰᵣ`，其中ℰᵣ为800匝、60 r/min时的模型绝对峰值，保持固定。

单峰形式可看作对圆周相对距离所对应有效通量的平滑近似，形状参数未作实测标定。没有求解完整磁场、回磁通、磁铁有限尺寸、各匝磁链差异和传感器负载；不输出预测伏数，不模拟原装置复杂波形细节。由模型计算的曲线不能充当法拉第定律的实验验证。

磁铁位置、圆盘转动、两幅曲线、实时读数和关键帧均来自同一模型时间。改变转速会暂停并复位。播放倍率只改变观看时间；曲线横轴始终是物理模型时间，0—2 s。模型不作几何比例复刻。

正对时`f′(0)=0`，磁通量最大、电动势为零。接近与离开的电动势符号相反。在固定位置、固定几何下转速加倍，磁通量不变、电动势加倍。关键峰值角度由模型求得，约±30.67°，不是实测相位。

## 已完成的核对

- `node check-model.cjs`：独立时间差分核对`−dΦ/dt`关系，最大归一化差约`9.76×10⁻¹⁰`；检查正对极值、符号、速度倍率与周期、整圈电动势积分、静止与反极性边界、关键位置角度。
- 本地HTTP与`file://`两种入口均在浏览器运行；播放/暂停、复位、前后步进、拖动时间、转速切换、播放倍率、关键位置、页签及键盘切换均检查。
- 实际浏览器暂停等待后模型时间不变；60 r/min离开峰值为1，120 r/min同一位置为2；正对处显示通量1、电动势0。
- 4张历史图片均加载；模型与原图分别显示；相对链接检查无失效；无外部资源依赖。最终本地文件入口控制台错误0。
- 预习单按A4打印到临时PDF检查，1页，末尾说明完整；答案区在打印样式下隐藏。临时PDF仅作分页核对，不作为正式出版排版验收。

## 预习安排

1. 区分运动部件、固定部件和两种测量仪器。
2. 预测并核对接近、正对、离开时的磁通量与电动势。
3. 用曲线斜率解释正对处电动势为零。
4. 比较两档转速，辨认模型与历史实测的不同身份及坐标量程。

## 接续文件

- `model.js`：物理模型与关键位置，独立于界面。
- `app.js`：同一时刻驱动动画、图像和控件。
- `faraday-animation.html`、`style.css`：独立动画页面。
- `prestudy.html`：可打印预习材料与教师参考答案。
- `check-model.cjs`：可重跑的物理关系检查。
- `来源与验证.json`：源图片哈希、文件清单与本次验证结果。

网页不需要构建。修改模型后在此目录执行`node check-model.cjs`，再核对关键交互。后续若取得装置尺寸、磁铁极性、磁场或原始时序数据，再讨论更接近实物的定量模型；本轮不增加硬件采集任务。
